# JLU 课程资料重制版

吉林大学软件工程专业课程资料的重制版：重做的课件讲义 153 份，整理成自学向的笔记 328 篇，覆盖 34 门课。

## 这里面是什么

- **重制版PPT**：按原课件的知识点重新排版生成的讲义。公式、代码高亮、类图、流程图、表格都是矢量对象，可以在 PowerPoint 里直接编辑；例题补了完整过程，数值结果用脚本复核过，源课件里发现的错误在对应位置标了更正。
- **自学笔记**：把课件、作业和历年题改写成能独立看懂的 Markdown。公式用 `$...$` 书写，GitHub 网页端可直接渲染；每门课的 `自学笔记/README.md` 是该课的学习指南，写了资料清单、建议顺序和考试信息。原始材料里的电路图、数据流图和手写解答，凡是讲题用得上的都随笔记收在同目录的图片文件夹里。

## 怎么用

1. 想快速过一门课，先看该课 `自学笔记/README.md` 的建议学习顺序。
2. 讲义按章节命名，文件名里的序号就是课程顺序，下载下来用 PowerPoint 打开。
3. 笔记里的例题建议先自己做一遍再看解答，答案都在题目下方或文末。

## 说明

- 重制前的原始课件、教材扫描件和历年真题不在本仓库。笔记开头标注了各自的来源文件名，需要对照原件时按文件名去找。
- 讲义和笔记是按知识点重写的，和任课老师的课件不是一一对应，考试仍以老师的要求为准。
- 内容难免有疏漏或错误，发现问题欢迎提 issue。
