# JLU 课程资料重制版

吉林大学软件工程专业课程资料的重制版，覆盖 34 门课：重做的课件讲义 194 份，自学笔记 328 篇，笔记配图 1572 张。

## 这里面是什么

每门课的目录下有 `重制版PPT/` 和 `自学笔记/` 两部分，有的课只有其中一部分。

`重制版PPT/` 里是按原课件知识点重新排版的讲义。公式、代码高亮、类图、流程图和表格都是矢量对象，在 PowerPoint 里可以直接改。例题补了完整过程，数值用脚本复算过，源课件里的错误在原处标了更正。

`自学笔记/` 里是把课件、作业和历年题改写成能独立看懂的 Markdown，公式用 `$...$` 书写，GitHub 网页上能直接渲染。每门课的 `自学笔记/README.md` 是这门课的学习指南，列了资料清单、建议的阅读顺序和考试信息。原资料里讲题用得上的电路图、数据流图、状态图和手写解答都裁出来放进了笔记同目录的图片文件夹，各课沿用自己的文件夹名（`图/`、`images/`、`media/` 或 `img/`）。微积分 AⅢ 的原资料没有图，笔记里那 11 张是按题目给的方程用脚本画的。

## 怎么用

1. 想快速过一门课，先看该课 `自学笔记/README.md` 的建议学习顺序。
2. 讲义按章节命名，文件名里的序号就是课程顺序，下载下来用 PowerPoint 打开。
3. 笔记里的例题建议先自己做一遍再看解答，答案都在题目下方或文末。

## 说明

- 重制前的原始课件、教材扫描件和历年真题不在本仓库。笔记开头标注了各自的来源文件名，需要对照原件时按文件名去找。
- 讲义和笔记是按知识点重写的，和任课老师的课件不是一一对应，考试仍以老师的要求为准。
- 计算机组成原理没有单独的讲义，MIPS 体系的 9 份放在计算机原理与体系结构目录下，两门课共用。机器学习第 7 到 10 章的讲义合并了 A、B 两版课件的内容，两个目录各放一份。
- 军事理论、马原、习思想、毛概和形势与政策以文字论述为主，原资料里没有讲题要用的图，笔记不配图。其他课如果原资料缺图，该课自学指南的「配图」一节写了缺哪些。
- 内容难免有疏漏或错误，发现问题欢迎提 issue。
