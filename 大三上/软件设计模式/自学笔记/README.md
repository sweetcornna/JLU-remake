# 软件设计模式自学指南

这个文件夹整理自课程目录下的 70 份复习资料：历年题、期末笔记（考场版）里的文件A/文件B 和各类题目整理、期末资料里的 CSDN 教程和讲义、张欣佳老师布置的作业、2018 年的作业和答案、刘伟《Java设计模式》习题答案。原文件都还在原位置，没有改动。每份笔记开头写了它整理自哪些文件。

## 考试信息

以下摘自课程目录的 `README.md`（22 级学长的经验）：

- 开卷考试，但题量大、时间紧，不容易满绩。
- 22 级题型：选择题、简答题、分析题、设计题。22 级不考享元、备忘录、访问者、解释器。
- 22 级由张欣佳老师出题、陈伟老师修正补充，选择题和简答题大部分是张欣佳老师 PPT 里的原内容。建议考前先弄清是哪位老师出题，再仔细看该老师的 PPT 和例题。
- 设计题考的模式不算难，关键是速度：先把模式判断准，再快速画类图，代码不用写得很细，但要有注释。简答题可以适当少写。
- `期末笔记（考场版）` 里的文件A（知识点）和文件B（例题和答题模板）是学长带进考场的资料，各有目录。

历年卷卷首的说明（见 20、21）：2011、2014、2017、2018 级试题用 C++ 描述，答题可以用 C++、Java、C# 中的任意一种。

## 建议学习顺序

1. **打基础**：01。重点是六种类间关系的画法和七条原则的定义，做 32 的分析题检验。
2. **逐个学模式**：02、03、04、05。每个模式先看"意图"和类图，合上笔记自己默画类图、写关键代码，再看易混对比和典型题。每学完一类，做 10、11 里对应的选择填空题，做 30 或 31 里对应的作业题。
3. **横向整理**：06。练"看题认模式"，把联用例题的类图各默画一遍。
4. **背简答**：12，先背开头的高频题。
5. **做真题**：20、21，按届计时做完再对答案。22 级的题型和老师更接近 2017、2018 级。
6. **考前一天**：02 到 05 的章末速记、06 的速查表、12 的高频题。22 级不考的享元、备忘录、访问者、解释器只看速记。
