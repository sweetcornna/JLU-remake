# 考点速查

这一份是本目录 `01`–`08` 八份整理稿的汇总，来源同样是 `统计计算笔记（压缩）.pdf`（70 页手写批注版课堂笔记）。考前按这一份过公式和结论，卡住的地方回对应整理稿看推导。表里的页码指原笔记页，方便对照。

## 全课主线

整门课在回答两个问题。

第 2 章：**怎么造随机数**。先用同余法造均匀随机数，再用逆变换、变换、舍选、复合四种办法把均匀随机数变成任意分布，最后处理随机向量。

第 3、4 章：**造出来的随机数怎么用**。用来算积分和期望（3.1、3.2），用来把误差前面的常数压小（3.3 到 3.5），用来模拟排队系统（3.6），用来估计统计量自己的精度（3.7），用来在高维和有隐变量的情形下抽样与优化（3.8、第 4 章）。

一条贯穿全课的结论：随机模拟的误差阶是 $O_p(N^{-1/2})$，**这个阶改不掉**，所有方差缩减方法改的都是它前面的常数。精度每多一位小数， $N$ 要乘 100。

## 第 2.1–2.2 节：均匀随机数（详见 `01`）

### 递推与参数

$$x_n=(ax_{n-1}+c)\ (\mathrm{mod}\ M),\qquad R_n=\frac{x_n}{M}$$

$M$ 阶数， $a$ 乘数， $c$ 增量。 $c=0$ 是乘同余发生器（ $x_n\in[1,M-1]$，最大周期 $M-1$）， $c>0$ 是混合同余发生器（ $x_n\in[0,M-1]$，最大周期 $M$）。

### 必背结论

| 结论 | 内容 |
| --- | --- |
| 一、二阶矩 | $EX_n=\frac{M-1}{2}$， $\mathrm{Var}(X_n)=\frac{M^2-1}{12}$； $ER_n\approx\frac12$， $\mathrm{Var}(R_n)\approx\frac1{12}$ |
| 好发生器三条 | 周期足够长、统计性质符合均匀分布、序列之间独立性好 |
| 相关系数 | $\rho(1)\approx\frac1a-\frac{6c}{aM}\big(1-\frac cM\big)$，所以 $a$ 要取大 |
| Lemma 5.1 | $a$ 与 $M$ 互素、 $x_0$ 与 $M$ 互素时，乘同余法的周期等于 $a$ 对模 $M$ 的阶数 $V$ |
| 满周期 | 满周期时初值取 $0\sim M-1$ 中任意数都一样；某个初值不满周期则所有初值都不满周期 |
| 线性同余法缺点 | 周期不超过 $2^L$、作为多维随机数相关性大、分布不均匀 |

同余性质 4（ $ik\equiv jk\Rightarrow i\equiv j\ (\mathrm{mod}\ \frac{M}{\gcd(M,k)})$）是第 2.2.3 节两个证明的公共工具，先背它。

### KS 检验

统计量 $D=\max_k\delta_k$， $\delta_k=\max\{|F_n(x_{(k)})-F_0(x_{(k)})|,\ |F_0(x_{(k)})-F_n(x_{(k-1)})|\}$， $D<D_{n,\alpha}$ 就接受 $H_0$。 $F_n(x_{(k)})=k/n$，约定 $F_n(x_{(0)})=0$。课件用的不是标准形式，标准形式只有第一项。

## 第 2.3–2.4 节：非均匀随机数（详见 `02`）

### 四种方法的选用

| 方法 | 用在什么时候 | 代价 |
| --- | --- | --- |
| 逆变换法 | $F^{-1}$ 能显式求出 | 每个样本 1 个均匀随机数 |
| 变换法 | 能找到与已知分布的函数关系（Box-Muller、Gamma 由指数求和） | 看具体变换 |
| 舍选法 | $F^{-1}$ 求不出，但取值区间有限、密度有上界 $M$ | 平均迭代 $M(b-a)$ 次，每次 2 个随机数 |
| 复合法 | 密度能拆成若干个好抽样的密度的凸组合 | 先抽指示器 $I$，再抽 $Z_I$ |

### 常用分布的生成公式

| 分布 | 生成式 |
| --- | --- |
| 离散均匀 $\{1,\dots,m\}$ | $X=\mathrm{Int}(mU)+1$ |
| 几何 $\mathrm{Geom}(p)$ | $X=\mathrm{ceil}\big(\frac{\ln U}{\ln q}\big)$， $q=1-p$ |
| 指数 $\mathrm{Exp}(\lambda)$ | $X=-\lambda^{-1}\ln U$ |
| $\mathrm{Beta}(2,1)$ | $X=\sqrt U$ |
| 标准正态（Box-Muller） | $X=\sqrt{-2\ln U_1}\cos(2\pi U_2)$， $Y=\sqrt{-2\ln U_1}\sin(2\pi U_2)$ |
| 标准正态（极坐标法） | $V_i=2U_i-1$， $S=V_1^2+V_2^2\le1$， $X=V_1\sqrt{\frac{-2\ln S}{S}}$， $Y=V_2\sqrt{\frac{-2\ln S}{S}}$ |
| 泊松 $\pi(\lambda)$ | $N=\min\{n:U_1\cdots U_n<e^{-\lambda}\}-1$ |
| 多元正态 $N(\mu,\Sigma)$ | $\Sigma=CC^{\mathsf T}$（Cholesky， $C$ 下三角）， $X=\mu+CZ$， $Z\sim N(0,I)$ |

### 平均判断次数

这是本章最爱考的计算点，三档要分清。

| 算法 | 平均判断次数 | 量级 |
| --- | --- | --- |
| 逐个判断（二项） | $EX+1=np+1$ | $O(n)$ |
| 逐个判断（泊松） | $EX+1=\lambda+1$ | $O(\lambda)$ |
| 从 $\mathrm{floor}(np)$ 或 $\mathrm{floor}(\lambda)$ 双向判断 | $E|X-\text{均值}|+1$，泊松约 $1+0.798\sqrt\lambda$ | $O(\sqrt{\cdot})$ |
| 离散分布按概率降序重排 | $\sum_j j\,p_{(j)}$ | 看分布 |
| 舍选法 | $M(b-a)$（迭代次数服从几何分布） | 看 $M$ |

两条递推式别串：二项 $p_{k+1}=\frac{n-k}{k+1}\cdot\frac{p}{1-p}p_k$，泊松 $p_{k+1}=\frac{\lambda}{k+1}p_k$。

## 第 3.1–3.2 节：MC 积分的两条基本路线（详见 `03`）

计算 $I=\int_a^b h(x)\mathrm dx$。

| | 随机投点法 | 平均值法 |
| --- | --- | --- |
| 前提 | $0\le h(x)\le M$，区间有限 | 不需要 $h$ 有界 |
| 每点随机数 | 2 个 | 1 个 |
| 估计量 | $\hat I=\hat p\,M(b-a)$ | $\hat I=\frac{b-a}{N}\sum h(u_i)$ |
| 渐近方差 | $\frac{[M(b-a)]^2p(1-p)}{N}$ | $\frac{(b-a)^2\mathrm{Var}(h(U))}{N}$ |
| 精度 | 低 | 高（已证 $\mathrm{Var}(\hat I_1)-\mathrm{Var}(\hat I_2)=\frac{V(C)}{N}\int h(1-h)\ge0$， $M=1$ 时） |

两者都是无偏估计和强相合估计，误差都是 $O_p(N^{-1/2})$，高维时**误差阶不受维数 $d$ 影响**，这就是 MC 能对付维数诅咒的原因（网格法是 $O(N^{-2/d})$）。

投点估计 $\pi$ 的那套误差分析要会完整推： $\xi\sim B(N,\frac\pi4)\Rightarrow E\hat\pi=\pi$， $D\hat\pi=\frac{\pi(4-\pi)}{N}$，误差幅度 $\pm2\sqrt{\pi(4-\pi)/N}$。

两条工具公式（3.4、3.5.3 节都要用）：

$$E[E(X\mid Y)]=EX,\qquad \mathrm{Var}(X)=E[\mathrm{Var}(X\mid Y)]+\mathrm{Var}(E(X\mid Y))$$

## 第 3.3–3.5 节：方差缩减五法（详见 `04`）

| 方法 | 核心构造 | 方差 | 前提 |
| --- | --- | --- | --- |
| 重要抽样 | $\hat I=\frac1N\sum\frac{h(X_i)}{g(X_i)}$， $X_i\sim g$ | $\frac1N\mathrm{Var}\big(\frac hg\big)$，最优 $g^*=\frac{|h|}{\int|h|}$ | $g$ 形状像 $|h|$ 且好抽样 |
| 分层抽样 | $\hat I=\sum_j\frac{V(C_j)}{n_j}\sum_i h(X_{ji})$ | $\sum_j\frac{V^2(C_j)\sigma_j^2}{n_j}$，最优 $n_j\propto V(C_j)\sigma_j$ | 层内 $h$ 变化小 |
| 控制变量 | $Z(b)=X+bY$， $EY=0$ | $(1-\rho_{X,Y}^2)\mathrm{Var}(X)$， $b=-\frac{\mathrm{Cov}(X,Y)}{\mathrm{Var}(Y)}$ | $EY$ 已知， $\rho\ne0$（正负均可） |
| 对偶变量 | $Z=\frac{F^{-1}(U)+F^{-1}(1-U)}{2}$ | $\le\frac12\mathrm{Var}(X)$ | $F^{-1}$ 单调 |
| 条件期望 | 用 $E(Y\mid X)$ 的样本均值代替 $Y$ 的 | $\mathrm{Var}(E(Y\mid X))\le\mathrm{Var}(Y)$ | $X$ 与 $Y$ 不独立 |

### 贯穿例题 $\int_0^1e^x\mathrm dx=e-1$

渐近方差写成 $c/N$，比常数 $c$（数值都已用 Python 重算）：

| 方法 | $c$ | 相对平均值法 |
| --- | --- | --- |
| 随机投点法 | 1.71828 | 大 7.1 倍 |
| 平均值法 | 0.24204 | 基准 |
| 分层抽样（两层） | 0.06493 | $1/3.7$ |
| 重要抽样 $g=\frac23(1+x)$ | 0.02691 | $1/9.0$ |
| 控制变量 $Y=U-\frac12$， $b=-1.690$ | 0.00394 | $1/61.4$ |
| 对偶变量 | 0.00391 | $1/61.9$ |

### 贯穿例题：估计 $\pi$

| 方法 | $N\cdot\mathrm{Var}$ | 相对随机投点法 |
| --- | --- | --- |
| 随机投点法 | 2.6968 | 1 |
| 条件期望法（ $\sqrt{1-X^2}$ 替掉示性函数） | 0.7971 | $1/3.4$ |
| 对偶变量法 | 0.1097 | $1/24.6$ |
| 控制变量法（ $W=U^2-\frac13$， $b=0.7363$） | 0.0260 | $1/103.7$ |

这四种是**层层叠加**的，不是四条并列的路：后三种都建立在「先用条件期望把一维随机性消掉」之上。

## 第 3.6 节：排队系统（详见 `05`）

泊松过程五条要点： $\lambda$ 是单位时间平均到达数、 $1/\lambda$ 是平均间隔、 $P(t,t+\Delta t)=\lambda\Delta t+o(\Delta t)$、有马尔可夫性、有排斥性。 $E[N(t)]=D[N(t)]=\lambda t$。

M/M/1 的六个指标（ $\rho=\lambda/\mu<1$）：

| 量 | 公式 |
| --- | --- |
| $P_k$ | $\rho^k(1-\rho)$ |
| 总队长 $L$ | $\frac{\rho}{1-\rho}$ |
| 服务队长 $L_s$ | $\rho$（也是服务台忙碌比例） |
| 排队长 $L_q$ | $\frac{\rho^2}{1-\rho}$ |
| 总逗留时间 $W$ | $\frac{1}{\mu-\lambda}$ |
| 等待时间 $W_q$ | $\frac{\lambda}{\mu(\mu-\lambda)}$ |

Little 公式 $L=\lambda W$、 $L_q=\lambda W_q$，表里任何一格都能推出别的格。

从差分方程推到 $P_k=\rho^k(1-\rho)$ 的六步是大题，要点：一小段内「既来又走」是 $\Delta t$ 的二阶小量要扔掉； $k=0$ 的方程少一项；稳态令导数为 0；归一化定 $P_0$。

## 第 3.7 节：Bootstrap（详见 `06`）

四步流程：取原始样本估 $\hat F$；从 $\hat F$ 有放回抽 $B$ 个容量仍为 $n$ 的样本；每个算 $\hat\phi^{(b)}$；用这 $B$ 个值估 $\hat\phi$ 的分布特征。

三个公式的中心和分母不一样，这是最常丢分的地方：

$$SE=\sqrt{\frac{1}{B-1}\sum(\hat\theta^{(i)}-\bar\theta)^2},\quad \mathrm{MSE}=\frac1B\sum(\hat\theta^{(i)}-\hat\theta)^2,\quad \mathrm{bias}=\frac1B\sum(\hat\theta^{(i)}-\hat\theta)$$

SE 减的是 bootstrap 均值 $\bar\theta$ 且除 $B-1$；MSE 和 bias 减的是原始估计 $\hat\theta$ 且除 $B$。

两种置信区间：

| | 百分位数法 | Bootstrap-t 法 |
| --- | --- | --- |
| 排序对象 | $\hat\theta^\star$ | 枢轴量 $W^\star=\frac{\bar x^\star-\bar x}{s^\star/\sqrt n}$ |
| 区间 | $(\hat\theta^\star_{(k_1)},\hat\theta^\star_{(k_2)})$ | $\big(\bar x-W^\star_{(k_2)}\frac{s}{\sqrt n},\ \bar x-W^\star_{(k_1)}\frac{s}{\sqrt n}\big)$ |
| 下标 | 顺着走 | **交叉** |

$k_1=[B\alpha/2]$， $k_2=[B(1-\alpha/2)]$。

参数 bootstrap 与非参数 bootstrap 只差「新样本从哪来」：参数法先求 $\hat\beta$ 再从 $F(x;\hat\beta)$ 生成，非参数法直接从原始样本有放回抽。

## 第 3.8 节与第 4 章：MCMC 和 EM（详见 `07`、`08`）

细致平稳条件 $\pi_ip_{ij}=\pi_jp_{ji}$ 是平稳分布的**充分条件**，不必要。

MH 接受率 $\alpha(i,j)=\min\big\{\frac{\pi(j)Q(j,i)}{\pi(i)Q(i,j)},1\big\}$， $Q$ 对称时退化成 $\min\{\frac{\pi(j)}{\pi(i)},1\}$（Metropolis）。Gibbs 用条件分布当转移概率，所有试抽样都被接受，但第二步必须用**本轮刚更新**的分量。MCMC 的样本相关，燃烧期要丢掉。

EM 两步：E 步算 $Q(\theta,\theta^{(i)})=E_Z[\log P(Y,Z\mid\theta)\mid Y,\theta^{(i)}]$，M 步取 $\theta^{(i+1)}=\arg\max_\theta Q$。保证似然不减，收敛到局部最大，**对初值敏感**。Q 的第二个变元是常数，不对它求导。

双因素模型用 EM 补齐数据后，估计式就是 $\hat\mu=\bar x$、 $\hat\alpha_i=\bar x_{i\cdot}-\bar x$、 $\hat\beta_j=\bar x_{\cdot j}-\bar x$。

## 反复出现的几个技巧

复习时按技巧横着串一遍，比按章节竖着背省事。

1. ** $U$ 与 $1-U$ 同分布**。用来化简指数分布（ $-\lambda^{-1}\ln U$）、几何分布、 $\mathrm{Beta}(1,2)$ 的生成式（第 2.3 节），也是对偶变量法的出发点（第 3.5.2 节）。
2. **连乘代替求和取对数**。指数分布求和生成泊松写成 $U_1\cdots U_n\ge e^{-\lambda}$（p15），Gamma 分布同理（p16）。
3. **双期望定理加方差分解**。证条件方差公式（p25）、推分层抽样的方差上界（p35）、条件期望法（p41），三处用的是同一对公式。
4. **递推代替组合数**。二项和泊松的 $F(k+1)=F(k)+p_{k+1}$（p12、p13），避免阶乘溢出。
5. **从最可能的取值开始搜**。逆变换法把大概率排前面（p10），二项从 $\mathrm{floor}(np)$ 双向找（p12），泊松从 $\mathrm{floor}(\lambda)$ 双向找（p13），都是把 $O(n)$ 压成 $O(\sqrt n)$。
6. **用已知期望的辅助量做修正**。控制变量法（p37）、Rao-Blackwell（p41），两者的关系是：控制变量法加一个期望为 0 的量，条件期望法换成一个期望相同但方差更小的量。
7. **把样本当总体**。Bootstrap 整节（p51 起）。参数 bootstrap 再把「估计好的分布」当总体。
8. **构造一条链让平稳分布等于目标分布**。MCMC（p59 起）。这里用到的马氏链性质（不可约、非周期、正常返、唯一平稳分布）在 p46 排队那一节已经讲过一遍。

## 易错点清单

从八份整理稿里挑出最容易写错的。

- 误差阶写 $O_p(N^{-1/2})$，带下标 $p$。「精度提高一位小数， $N$ 乘 100」的方向别说反。
- 乘同余法最大周期是 $M-1$ 不是 $M$。
- $\mathrm{Var}(R_n)=\frac{M^2-1}{12M^2}$ 是精确值， $\frac1{12}$ 只是近似。
- 几何分布是 $\mathrm{ceil}$ 不是 $\mathrm{floor}$，因为 $\ln q<0$ 除过去要变号。
- 离散均匀 $X=\mathrm{Int}(mU)+1$，那个 $+1$ 别丢。
- Box-Muller 的 $U_1$ 管半径、 $U_2$ 管角度，不能对调。单位圆上均匀时是 $R^2\sim U(0,1)$ 不是 $R$。
- 舍选法的平均迭代次数是 $M(b-a)$， $M$ 要先求导找极值再定，区间不是 $[0,1]$ 时 $(b-a)$ 不能省。
- 多项分布用条件法时，试验次数和概率的分母**同时**往下扣。
- 随机投点法每点 2 个随机数，平均值法 1 个；渐近方差分母是 $N$ 不是 $N^2$。
- 比较两种积分法精度时要先归一化 $M=1$。
- 控制变量的最优 $b$ 带负号；控制变量要求 $EY$ 已知， $EY\ne0$ 时要换成 $Y-\mu_Y$。
- 最优分配用标准差 $\sigma_j$ 不是方差。
- 对偶变量法里 $X$ 与 $Y$ 不独立，算 $\mathrm{Var}(X+Y)$ 必须带 $2\mathrm{Cov}$。对偶变量法和控制变量法不叠加使用。
- 标准化重要抽样是强相合但**有偏**，普通重要抽样是无偏。
- M/M/1 的 $\rho=\lambda/\mu$ 不是 $\mu/\lambda$； $P_0=1-\rho$ 需要 $\rho<1$。
- Bootstrap 三个公式的中心和分母（见上面那一节），以及 bootstrap-t 区间下标交叉。
- 细致平稳是充分不必要；MH 的 $\min\{\cdot,1\}$ 里的 1 不能丢；Gibbs 第二步用本轮更新过的分量。
- EM 的 Q 函数第二个变元是常数；Jensen 不等式的权重要非负且和为 1。
