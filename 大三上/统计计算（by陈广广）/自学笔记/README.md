# 统计计算 自学指南

这份指南和同目录下的九份整理稿都来自 `统计计算笔记（压缩）.pdf`（70 页手写批注版课堂笔记）。原笔记是把老师课件打印出来、在空白处手写推导和补充，所以整理稿只收手写的那一层：定理怎么证、例题每一步的数怎么来、公式记哪几条、老师用红笔标过的地方。课件本身的完整内容在 `../重制版PPT/` 里，两边配合着看。

所有数值结论（积分值、渐近方差、置信区间端点、极大似然解、KS 检验表等）都用 Python 重算过，和原稿对不上的地方在原处写了「更正：原文作 …」。本机没有 R，笔记里出现的 R 代码是按 R 语义逐行推演后写进去的，没有实际运行。

## 建议学习顺序

1. 先看 `../重制版PPT/` 里对应章节的课件，把定义和结论过一遍。本课程已有六册重制版 PPT，覆盖第 0 到第 4 章：
   - [`第0章 绪论（重制版）.pptx`](../重制版PPT/第0章%20绪论（重制版）.pptx)
   - [`第1章 基础知识（重制版）.pptx`](../重制版PPT/第1章%20基础知识（重制版）.pptx)
   - [`第2章 随机数的产生和检验（重制版）.pptx`](../重制版PPT/第2章%20随机数的产生和检验（重制版）.pptx)
   - [`第3章 随机模拟（上）（重制版）.pptx`](../重制版PPT/第3章%20随机模拟（上）（重制版）.pptx)
   - [`第3章 随机模拟（下）（重制版）.pptx`](../重制版PPT/第3章%20随机模拟（下）（重制版）.pptx)
   - [`第4章 统计计算中的优化问题（重制版）.pptx`](../重制版PPT/第4章%20统计计算中的优化问题（重制版）.pptx)
2. 再看这里的整理稿，重点是课件上没有的推导过程和例题算法。按 `01` 到 `08` 的顺序走，编号和章节顺序一致。
3. 第 2 章和第 3 章是重头。第 2 章考生成算法和平均判断次数，第 3 章考渐近方差的计算与比较。
4. `04` 里那两张对照表（同一个积分六种方法、同一个 $\pi$ 四种方法）横向比着看一遍，比单独背五个方法的公式有用。
5. 几处从头到尾的手写推导按大题准备：Lemma 5.1（`01`）、Box-Muller（`02`）、两种积分法的方差比较（`03`）、最优 $b$ 的求导（`04`）、M/M/1（`05`）、最小二乘的两条性质（`06`）、双因素模型的 EM（`08`）。
6. 考前用 `09 考点速查.md` 过公式和易错点。

## 源资料里的考试线索

原笔记只在两处留下了和考试直接有关的批注，除此之外没有复习范围、题型或分值信息，所以下面只列这两条：

- p67「双因素模型用 EM 解」旁边用红笔写了**考过**。整理在 `08 最大似然与EM算法.md` 的「双因素模型：用 EM 解」一节。
- p33 重要抽样例题里，试投密度 $g(x)=\frac23(1+x)$ 旁边写着「定了，**考试不用自己求**」，意思是这类题会把 $g$ 给出来，要做的是算渐近方差。
