## 3.8.1 马氏链与 MCMC 的引入（原笔记 p59）

MCMC 全称马尔可夫链蒙特卡洛。它解决的问题是高维随机向量不好直接抽样，办法是造一条马氏链，让这条链的**平稳分布**正好是想要的目标分布，链跑久了以后的状态就近似服从目标分布。

手写批注特别标了一句：这样产生的样本**不是相互独立的**。这是 MCMC 相对前面几章方法最大的代价，后面 MH 和 Gibbs 的缺点栏里还会重复。

### 课件上那个数值例子说明了什么

转移矩阵

$$P=\begin{bmatrix}0.65 & 0.28 & 0.07\\ 0.15 & 0.67 & 0.18\\ 0.12 & 0.36 & 0.52\end{bmatrix}$$

从 $\pi_0=[0.21,0.68,0.11]$ 出发迭代，第 9 步以后稳定在 $[0.286,0.489,0.225]$；换成 $\pi_0=[0.75,0.15,0.1]$，同样收敛到 $[0.286,0.489,0.225]$。手写在旁边画箭头写了**和初始概率分布无关**。

直接算 $P^n$ 也一样：$P^{20}=P^{21}=\cdots=P^{100}$，三行完全相同，每一行都是平稳分布。批注写「反复乘，最后不变了」。

用 Python 解 $\pi P=\pi$、$\sum_j\pi_j=1$，得 $\pi=[0.2865,0.4885,0.2250]$，和笔记上的数一致。

### 马尔可夫链的收敛性质（手写整理的四条）

前提：一个**非周期**的马氏链，状态转移矩阵为 $P$，并且**任何两个状态是连通的**（不可约）。那么

1. $\lim_{n\to\infty}P_{ij}^{n}=\pi(j)$，极限与出发状态 $i$ 无关。
2. $\lim_{n\to\infty}P^{n}$ 的每一行都是 $\pi=[\pi(1),\pi(2),\dots]$。
3. $\pi(j)=\sum_{i=0}^{\infty}\pi(i)P_{ij}$。
4. $\pi$ 是方程 $\pi P=\pi$ 的**唯一非负解**，且 $\sum_i \pi(i)=1$。

第 3 条旁边手写了推导，思路就是全概率公式：

$$P(X_{n+1}=j)=\sum_{i=0}^{\infty}P(X_n=i)P(X_{n+1}=j\mid X_n=i)=\sum_{i=0}^{\infty}P(X_n=i)P_{ij}\xrightarrow{n\to\infty}\sum_{i=0}^{\infty}\pi(i)P_{ij}$$

### 实际怎么用

手写在页脚给了整条流水线：

1. $\pi_0(x)$ 取一个非常简单的分布，抽出 $x_0$。
2. 按 $\pi_{n+1}=\pi_n P$ 往下走，$x_1,x_2,\dots$。
3. 前面一段叫**燃烧期**（burn-in，笔记里写「老化期」），这段样本**不要**。
4. 怎么判断烧完了，画三种图：样本轨迹图（看是否逐渐收敛到某个样本附近）、自相关图、遍历均值图。

## 马氏链的遍历定理与细致平稳条件（原笔记 p60）

### 遍历定理

设正常返的不可约马氏链平稳分布为 $\pi$，$h(\cdot)$ 是状态空间 $S$ 上的有界函数，则

$$P\Big(\lim_{n\to\infty}\frac1n\sum_{k=0}^{n}h(X_k)=\sum_{x\in S}\pi_x h(x)\Big)=1$$

手写注解说这个式子**类似于独立同分布随机变量均值的强大数律**，当 $X$ 服从平稳分布时右端就等于 $E[h(X)]$。所以可以用 MCMC 求期望，这是 MCMC 能做积分估计的依据。

上面一条的前提，手写补了两点：状态有限多个、非周期且不可约；另外状态无穷但可数也行。

### 细致平稳条件

如果存在 $\{\pi_j,j\in S\}$，$\pi_j\ge 0$，$\sum_{j\in S}\pi_j=1$，使得

$$\pi_i p_{ij}=\pi_j p_{ji},\quad \forall i\ne j$$

就称这条马氏链是**细致平稳的**（detailed balance）。笔记在旁边用五角星标了「细致平稳条件（充分条件）」，强调它只是充分不必要。

手写的证明只有四行，值得背下来：

$$\sum_i \pi_i p_{ij}=\sum_i \pi_j p_{ji}=\pi_j\sum_i p_{ji}=\pi_j$$

写成矩阵形式就是 $\pi P=\pi$，所以满足细致平稳条件的马氏链，$\pi$ 就是它的平稳分布。

### 接受率是怎么凑出来的

目标平稳分布 $\pi(x)$ 和随便找的一个转移矩阵 $Q$ 一般不满足细致平稳条件：

$$\pi(i)Q(i,j)\ne\pi(j)Q(j,i)$$

引入一个 $\alpha(i,j)$，让它变成等式：

$$\pi(i)Q(i,j)\alpha(i,j)=\pi(j)Q(j,i)\alpha(j,i)$$

手写在两边画了对称的箭头，指出只要**交叉取**就行：

$$\alpha(i,j)=\pi(j)Q(j,i),\qquad \alpha(j,i)=\pi(i)Q(i,j)$$

代回去两边都是 $\pi(i)Q(i,j)\pi(j)Q(j,i)$，恒等式成立。于是取

$$P(i,j)=Q(i,j)\alpha(i,j)$$

$\alpha(i,j)$ 叫**接受率**，取值在 $[0,1]$，可以理解成一个概率值。批注写「本来不满足，引入后满足」。

## MCMC 抽样步骤（原笔记 p61）

1. 输入任意选定的转移矩阵 $Q$、平稳分布 $\pi(x)$，设定转移次数阈值 $n_1$ 和需要的样本个数 $n_2$。
2. 从任意简单概率分布抽样得到初始状态 $x_0$。
3. 对 $t=0$ 到 $n_1+n_2-1$：
   - 从条件概率分布 $Q(x\mid x_t)$ 抽样得到 $x_*$；
   - 从 $U[0,1]$ 抽 $u$；
   - 若 $u<\alpha(x_t,x_*)=\pi(x_*)Q(x_*,x_t)$，接受转移，$x_{t+1}=x_*$；
   - 否则 $x_{t+1}=x_t$。
4. 取 $(x_{n_1},x_{n_1+1},\dots,x_{n_1+n_2-1})$ 作为平稳分布的样本集。

页顶手写一行红字：**有问题，$\alpha$ 可能太小**。$\alpha=\pi(x_*)Q(x_*,x_t)$ 是两个小于 1 的数相乘，很容易接近 0，于是绝大多数试探点都被拒绝，链原地不动，效率极低。这句话就是下一节 MH 的动机。

## 3.8.2 Metropolis-Hastings 抽样（原笔记 p62）

### 改进的关键一步

MH 把接受率改成

$$\alpha(i,j)=\min\Big\{\frac{\pi(j)Q(j,i)}{\pi(i)Q(i,j)},\ 1\Big\}$$

手写解释了为什么可以这么改：细致平稳等式

$$\pi(i)Q(i,j)\alpha(i,j)\cdot\beta=\pi(j)Q(j,i)\alpha(j,i)\cdot\beta$$

**两边同乘一个数，平稳性不变，但能改变 $\alpha$ 的值**。既然等比例放大不影响等式，就把两个接受率一起放大到其中一个等于 1 为止，这样接受率尽可能大，又不破坏细致平稳。

### MH 抽样步骤

和上面的 MCMC 步骤逐行一样，只把 c) 里的判据换成

$$u<\alpha(x_t,x_*)=\min\Big\{\frac{\pi(x_*)Q(x_*,x_t)}{\pi(x_t)Q(x_t,x_*)},1\Big\}$$

批注在步骤旁写「其他都一样，仅改接受率」，考试写步骤时照这个模板套。

### 对称转移矩阵的简化

若 $Q$ 是**对称的**，即 $Q(i,j)=Q(j,i)$，接受率简化为

$$\alpha(i,j)=\min\Big\{\frac{\pi(j)}{\pi(i)},1\Big\}$$

这时的算法叫 **Metropolis 抽样法**。这一步很好记：只要比目标密度的比值。

### 随机游动 MH 算法

转移法则：从 $x^{(t)}$ 出发试转移到 $y$。若 $\pi(y)>\pi(x^{(t)})$，直接令 $x^{(t+1)}=y$（手写：新的点，概率变高）；否则独立抽 $U\sim U(0,1)$，取

$$x^{(t+1)}=\begin{cases}y, & U\le \pi(y)/\pi(x^{(t)})\\ x^{(t)}, & \text{其它}\end{cases}$$

页脚手写总结了一段话，抄下来当口述答案用：一般的 MH 抽样每一步先进行尝试，从上一步的状态进入一个新的状态，然后根据新的状态是否靠近目标分布来接受或拒绝抽样点；如果拒绝，就停留在上一步的状态，效率较低。

### MH 的三个缺点（手写，红笔列的）

1. 得到的样本都**不是独立的**。
2. **维度大时抽样不均匀**。
3. $\alpha$ 可能造成大部分样本被拒绝；对高维数据抽样时要知道联合分布，不好求。

第 3 条直接引出 Gibbs。

## 3.8.3 Gibbs 抽样（原笔记 p63）

页顶手写一句话点题：**核心是每一个维度上求条件概率**。右上角补了一句「在不同的维度上找细致平稳性」。

### 二维情形的推导

设 $\pi(x_1,x_2)$ 是二维联合分布。考察第一个特征维度相同的两点 $A(x_1^{(1)},x_2^{(1)})$ 和 $B(x_1^{(1)},x_2^{(2)})$，写出两条联合分布的分解式：

$$\pi(x_1^{(1)},x_2^{(1)})\,\pi(x_2^{(2)}\mid x_1^{(1)})=\pi(x_1^{(1)})\,\pi(x_2^{(1)}\mid x_1^{(1)})\,\pi(x_2^{(2)}\mid x_1^{(1)})$$

$$\pi(x_1^{(1)},x_2^{(2)})\,\pi(x_2^{(1)}\mid x_1^{(1)})=\pi(x_1^{(1)})\,\pi(x_2^{(2)}\mid x_1^{(1)})\,\pi(x_2^{(1)}\mid x_1^{(1)})$$

两式右端完全相同（笔记用波浪线把两串画在一起标「相等」），所以

$$\pi(A)\,\pi(x_2^{(2)}\mid x_1^{(1)})=\pi(B)\,\pi(x_2^{(1)}\mid x_1^{(1)})$$

这就是细致平稳条件，其中的转移概率取的是条件分布 $\pi(x_2\mid x_1^{(1)})$。同理，对固定 $x_2$ 的两点 $A(x_1^{(1)},x_2^{(1)})$ 和 $C(x_1^{(2)},x_2^{(1)})$ 有

$$\pi(A)\,\pi(x_1^{(2)}\mid x_2^{(1)})=\pi(C)\,\pi(x_1^{(1)}\mid x_2^{(1)})$$

结论：在 $x_2=x_2^{(1)}$ 这条直线上用 $\pi(x_1\mid x_2^{(1)})$ 作转移概率，任意两点之间的转移都满足细致平稳条件；在 $x_1=x_1^{(1)}$ 这条直线上用 $\pi(x_2\mid x_1^{(1)})$ 同理。

于是构造出 $\pi(x_1,x_2)$ 的状态转移矩阵（手写）：

$$P(A\to B)=\pi(x_2^{(B)}\mid x_1^{(1)}),\ \text{若 }x_1^{(A)}=x_1^{(B)}=x_1^{(1)}$$
$$P(A\to C)=\pi(x_1^{(C)}\mid x_2^{(1)}),\ \text{若 }x_2^{(A)}=x_2^{(C)}=x_2^{(1)}$$
$$P(A\to D)=0,\ \text{其它}$$

也就是只允许沿坐标轴方向走。

### 为什么 Gibbs 效率高

右上角的手写解释：仅在坐标轴方向尝试转移，用当前点的条件分布决定下一步的试抽样分布，**所有试抽样都被接受，不需要拒绝**，所以效率可以更高。前提是 $\pi(x)$ 的条件分布都能够比较容易地抽样。

### 二维 Gibbs 抽样步骤

1. 输入平稳分布 $\pi(x_1,x_2)$，设定转移次数阈值 $n_1$，需要的样本个数 $n_2$。
2. 随机初始化 $x_1^{(0)}$ 和 $x_2^{(0)}$。
3. 对 $t=0$ 到 $n_1+n_2-1$：
   - 从 $P(x_1\mid x_2^{(t)})$ 抽样得到 $x_1^{t+1}$；
   - 从 $P(x_2\mid x_1^{(t+1)})$ 抽样得到 $x_2^{t+1}$。

注意 b) 用的是**刚更新过的** $x_1^{(t+1)}$，不是 $x_1^{(t)}$。这是抄步骤时最容易写错的地方。

4. 取 $\{(x_1^{(n_1)},x_2^{(n_1)}),\dots,(x_1^{(n_1+n_2-1)},x_2^{(n_1+n_2-1)})\}$ 作为样本集。

### Gibbs 的三个缺点（手写，红笔列的）

1. 条件概率分布**难得到**。
2. 不一定要比 MH 好（笔记原文「不一定要优」）。
3. **一维时没法用**（只有一个维度就无从轮换）。

## 二维正态的 Gibbs 例子与多维推广（原笔记 p64）

### 例：二维正态分布

$N(\mu,\Sigma)$，其中 $\mu=(\mu_1,\mu_2)=(5,-1)$，

$$\Sigma=\begin{pmatrix}\sigma_1^2 & \rho\sigma_1\sigma_2\\ \rho\sigma_1\sigma_2 & \sigma_2^2\end{pmatrix}=\begin{pmatrix}1 & 1\\ 1 & 4\end{pmatrix}$$

左边手写把参数读了出来：$\sigma_1=1$，$\sigma_2=2$，$\rho=\frac12$。（用 $\rho\sigma_1\sigma_2=1$ 反解，$\rho=1/(1\times 2)=1/2$，已用 Python 核对。）

状态转移条件分布（手写）：

$$P(x_1\mid x_2)=N\Big(\mu_1+\rho\frac{\sigma_1}{\sigma_2}(x_2-\mu_2),\ (1-\rho^2)\sigma_1^2\Big)$$
$$P(x_2\mid x_1)=N\Big(\mu_2+\rho\frac{\sigma_2}{\sigma_1}(x_1-\mu_1),\ (1-\rho^2)\sigma_2^2\Big)$$

代进本题的数：$P(x_1\mid x_2)=N\big(5+\tfrac14(x_2+1),\ 0.75\big)$，$P(x_2\mid x_1)=N\big(-1+(x_1-5),\ 3\big)$。

（原笔记这两行只写了带 $\rho,\sigma_1,\sigma_2$ 的通式，没代数，代入结果是本整理稿补的。）

### 多维数据分布的 Gibbs

把二维的轮换扩展成一轮扫一遍所有维度。第 $t+1$ 轮：

- 从 $P(x_1\mid x_2^{(t)},x_3^{(t)},\dots,x_n^{(t)})$ 抽 $x_1^{t+1}$；
- 从 $P(x_2\mid x_1^{(t+1)},x_3^{(t)},\dots,x_n^{(t)})$ 抽 $x_2^{t+1}$；
- …
- 从 $P(x_j\mid x_1^{(t+1)},\dots,x_{j-1}^{(t+1)},x_{j+1}^{(t)},\dots,x_n^{(t)})$ 抽 $x_j^{t+1}$；
- …
- 从 $P(x_n\mid x_1^{(t+1)},\dots,x_{n-1}^{(t+1)})$ 抽 $x_n^{t+1}$。

规律：下标比 $j$ 小的都用 $t+1$ 代，下标比 $j$ 大的还用 $t$ 代。

### 两种扫描方式

**系统扫描 Gibbs**：每一轮按 $i=1,2,\dots,n$ 的固定顺序走一遍。

```text
从 π(x) 的取值区域任取一个初值 X^(0)
for t in 0:(N-1) {
    for i in 1:n {
        从条件分布 p(x_i | X_1*, ..., X_{i-1}*, X_{i+1}^(t), ..., X_n^(t)) 抽取 X_i*
    }
    X^(t+1) <- (X_1*, ..., X_n*)
}
```

手写注解：每一步从条件分布中抽样，所以能流从每一维抽样。

**随机扫描 Gibbs**：抽样的次序随机。

```text
从 π(x) 的取值区域任取一个初值 X^(0)
for t in 0:(N-1) {
    按概率 α = (α_1, ..., α_n) 随机抽取下标 i
    从条件分布 p(x_i | X_(-i)^(t)) 抽取 X_i*
    X^(t+1) <- (X_1^(t), ..., X_{i-1}^(t), X_i*, X_{i+1}^(t), ..., X_n^(t))
}
```

下标的抽样概率 $\alpha$ 是事先给定的。随机扫描一轮只更新一个分量，系统扫描一轮更新全部分量，这是两者写伪代码时的区别。

上面两段伪代码在课件里用的是 R 的写法（`for(t in 0:(N-1))`、`X^(t+1) <- ...`），照抄时注意 R 的赋值箭头是 `<-`，循环区间是 `0:(N-1)` 而不是 Python 的 `range`。

## 本节易错点

- 细致平稳条件是平稳分布的**充分条件**，不是必要条件。反过来说，平稳分布不一定细致平稳。
- 朴素 MCMC 的接受率 $\alpha=\pi(x_*)Q(x_*,x_t)$ 没有取 $\min$，所以可能极小；MH 的 $\alpha$ 带 $\min\{\cdot,1\}$，这个 1 不能丢。
- Metropolis 是 MH 在 $Q$ 对称时的特例，别把两个名字的适用条件写反。
- Gibbs 的第二步必须用本轮刚更新的分量。
- MCMC 产生的样本相关，不能当独立样本去套前面几章的方差公式。燃烧期的样本要丢掉。
