# 软件工程自学指南

这个文件夹是从课程目录下的 19 份复习资料整理出来的自学笔记，原文件都还在原位置，没有改动。知识点主要来自 `笔记/软件工程笔记.pdf`（按冯老师课件整理的笔记）和 `笔记/软件工程期末复习.pdf`；题目来自 `软件工程作业/` 里的 9 次作业、`学长学姐的资料/` 里的选择题库、简答、背诵稿和复习资料。章号沿用课件和教材《软件工程导论》第 6 版。笔记只整理了第 1、2、3、5、6、7、8、9、10、13 章（第 11 章面向对象设计只有标题），整理稿也按这些章组织。

## 建议学习顺序

1. 跟课阶段：每学完一章，先读对应的知识点稿（`01` 到 `09`），再做这一章的作业题（`20` 到 `22`，每份开头有作业和章节的对应表），最后翻 `11` 里本章的简答题。
2. 学到可行性研究、总体设计、测试、项目管理、面向对象这几章时，配合对应的大题稿练手：数据流图和 SD 映射看 `30`，McCabe、覆盖、等价类、MTTF 看 `31`，工程网络图看 `32`，用例图、顺序图、类图看 `33`。每类题先看"方法与步骤"和"易错点"，自己做完例题再对答案。
3. 考前两周：`20` 到 `22` 的选择、判断题整套刷两遍，错题回到知识点稿查；`12`、`13` 当加练。
4. 考前一周：背 `10` 的中英文术语和 `11` 开头列出的高频简答题；`30` 到 `33` 每类大题至少再完整做一道；最后用 `40` 对照历届回忆查漏。

## 整理说明

- 原稿里的错误都在原处写了"（更正：…）"。影响做题的几处：`复习01` 的 MTTF 题（2017 级）第二问算错，应再改正 140 个而不是 50 个；作业 7 第 19 题参考答案把 I→J 的机动时间写成 0（应为 5），手写答案把事件 B 的 LET 写成 12（应为 3）；作业 6 第 25 题条件组合覆盖的原答案漏算了一个到不了判定 d 的用例；作业 3 第 40 题 SD 映射的三个模块名和数据流图对不上；`软件工程背诵.md` 把程序流程图"随意转移控制"当成优点、把盒图"不能任意转移控制"当成缺点，正好说反；期末复习笔记第 10 页把好结构的扇入扇出位置说反；期末复习笔记第 72 页把各覆盖标准写成一条强弱直线，条件覆盖和判定覆盖其实互不包含；期末复习笔记第 73 页的英文陈述里 loosely coupled 和 module testing 两句定义错误。
- 作业题的原作答逐题核对过，选择、判断题没有发现能确定判错的作答。作业 2 第 31 题（用户故事的作用）作业答案是 AC，`软件工程选择题66791.doc` 同题答案是 A 和 D，两处都在题下说明了，以老师答案为准。
- 原稿没有答案的题，整理时补的答案都标了"（整理补充）"，拿不准的写了疑点。
- 计算题（环形复杂度、覆盖用例、MTTF、错误总数、EET/LET、COCOMO、成本效益）都用 Python 重新算过。
