## 一 基础与线性回归

### 1. 什么是特征归一化（规范化）？为什么要进行归一化？如何进行归一化？

**是什么**：一种数据预处理技术，把数据的特征缩放到相同的范围内（通常是 $[0,1]$ 或 $[-1,1]$），消除不同特征之间的量纲差异。

**为什么**：

1. 提高模型性能。基于距离的算法（K 近邻、SVM）对量纲非常敏感，量纲大的特征会在距离计算里占主导。
2. 加速收敛。基于梯度下降的优化算法（线性回归、逻辑回归、神经网络）收敛更快。
3. 增强可解释性。同一尺度便于可视化和比较。

**怎么做**：

| 方法 | 公式 | 结果范围 |
| --- | --- | --- |
| 最小-最大归一化 | $x' = \dfrac{x - x_{\min}}{x_{\max} - x_{\min}}$ | $[0, 1]$ |
| **Z-score 标准化（PPT 里用的这种）** | $x' = \dfrac{x - \mu}{\sigma}$ | 均值 0、标准差 1 |
| 最大绝对值归一化 | $x' = \dfrac{x}{\lvert x\rvert_{\max}}$ | $[-1, 1]$ |
| 单位向量归一化 | $x' = \dfrac{x}{\lVert x\rVert_2}$ | 模长 1 |

期末复习 PDF 给了一个 Z-score 的四步示例：算均值、算标准差、逐个代入公式、汇总。归一化后特征向量的均值为 0、标准差为 1。

### 2. 学习率是什么？过大过小分别有什么后果？怎么应对？

学习率 $\alpha$ 是梯度下降法的超参数，决定每次参数更新的步长：

$$\theta_j := \theta_j - \alpha\frac{\partial}{\partial\theta_j}J(\theta)$$

- **过小**：收敛速度慢，需要更多迭代次数才能达到最优解。
- **过大**：每次迭代可能越过极小值，导致无法收敛（损失曲线反而上翘）。

应对：尝试不同的学习率找合适的值；使用随机优化方法来动态调整学习率（第 4 章的 Adagrad、RMSProp、Adam 就是干这个的）。

### 3. 什么是随机梯度下降？什么是批量梯度下降？二者的优缺点（22 级真题）

| | 批量梯度下降 BGD | 随机梯度下降 SGD |
| --- | --- | --- |
| 更新时机 | 扫描完整个训练集后更新一次 | 每遇到一个样本后立即更新 |
| 更新公式 | $\theta_j := \theta_j + \alpha\sum_{i=1}^{m}(y^{(i)} - h_\theta(x^{(i)}))x_j^{(i)}$ | $\theta_j := \theta_j + \alpha(y^{(i)} - h_\theta(x^{(i)}))x_j^{(i)}$ |
| 优点 | 每次更新方向是全局梯度，稳定，不震荡 | 大样本集收敛快，单次迭代代价低 |
| 缺点 | 大样本集处理速度慢，每步都要遍历全部数据 | 可能发生震荡，无法精确收敛到全局极小值 |

结论：对大样本问题推荐 SGD。实际应用中最优解附近的任意解通常足够好，不需要精确收敛。

补充一句 mini-batch：用若干个样本的平均梯度作为更新方向，介于两者之间。

### 4. 全局极小值和局部极小值，梯度下降能找到哪个？

梯度下降法通常只能找到局部极小值，不保证全局极小值。但**线性回归的代价函数是凸函数，所以梯度下降可以保证找到全局极小值**。

### 5. 梯度下降法和正规方程法的对比

助记「学计归时特」：

| | 梯度下降法 | 正规方程法 |
| --- | --- | --- |
| 学习速率 | 需要设置 | 不需要 |
| 计算次数 | 需要多次迭代 | 不需要迭代 |
| 特征归一化 | 需要 | 不需要 |
| 时间复杂度 | $O(kn^2)$ | $O(n^3)$，要算 $X^{\mathrm{T}}X$ 的逆 |
| 特征数量 | $n$ 很大也能工作 | $n$ 很大时很慢 |

正规方程是解析解，但不是所有矩阵都可逆，有些可逆矩阵求逆也极其耗时，所以只有特征数较小时才考虑用它。

### 6. 局部加权线性回归的步骤？权值起什么作用？权值形式怎么选？

**步骤**：与普通线性回归类似，只是在拟合目标里给每个样本加了权值 $w^{(i)}$：

$$\min_\theta \sum_i w^{(i)}(y^{(i)} - \theta^{\mathrm{T}}x^{(i)})^2, \qquad \text{输出 } \theta^{\mathrm{T}}x$$

**权值的作用**：放大邻近点的贡献，缩小甚至忽略远距离点的贡献。

**权值形式**：

| 情形 | 权值 |
| --- | --- |
| $x$ 是标量 | $w^{(i)} = \exp\left(-\dfrac{(x^{(i)} - x)^2}{2\tau^2}\right)$ |
| $x$ 是向量 | $w^{(i)} = \exp\left(-\dfrac{(x^{(i)} - x)^{\mathrm{T}}(x^{(i)} - x)}{2\tau^2}\right)$ |
| 考虑特征相关性 | $w^{(i)} = \exp\left(-\dfrac{(x^{(i)} - x)^{\mathrm{T}}\Sigma^{-1}(x^{(i)} - x)}{2}\right)$ |

$\tau$ 是带宽参数，决定权值衰减的快慢：$\tau$ 小则衰减快，只看非常接近的点；$\tau$ 大则会考虑更远的点。$\Sigma$ 是协方差矩阵，也可以叫带宽。两者都是待定参数。

LWLR 是**非参数**方法，每预测一个新点都要重新解一次加权最小二乘。

### 7. 离群点是什么？怎么考？

离群点（Outlier）是显著偏离一般水平的观测对象，本质上仍是数据对象，也称异常值。离群点检测又称异常检测。

考法是 Pearson 与 Spearman 相关系数对离群点的敏感度：

| 相关系数 | 加离群点前 | 加离群点后 | 结论 |
| --- | --- | --- | --- |
| Pearson | $-0.1545128$ | $0.9775784$ | 对离群点非常敏感，一个极端值就能把「几乎无关」变成「强正相关」 |
| Spearman | $-0.184922$ | $-0.1165611$ | 变化很小，因为它基于秩次而不是原始值 |

答题要点：Pearson 在有离群点时会产生误导，Spearman 更稳健。

### 8. 什么是欠拟合/过拟合？为什么会产生？如何解决？

| | 欠拟合 | 过拟合 |
| --- | --- | --- |
| 定义 | 模型过于简单，捕捉不到数据中的重要模式 | 模型过于复杂，把训练数据的噪声也学进去了 |
| 训练集 | 高误差 | 低误差 |
| 测试集 | 高误差 | 高误差 |

**欠拟合原因**：模型过于简单、特征不足、数据噪声大、正则化过强。
**欠拟合解决**：增加模型复杂度、增加有意义的特征、降低正则化强度、换更复杂的算法。

**过拟合原因**：模型过于复杂、特征太多（尤其特征数远大于样本数）、数据量不足、正则化不足。
**过拟合解决**：增加训练数据、正则化（L1/L2）、减少特征、交叉验证、剪枝（决策树）、集成方法（随机森林、梯度提升）。

作业里还有一个从统计学习理论角度的答法（可以和上面拼起来答）：过拟合是因为待学习的函数类复杂性太高、表征能力太强，通过调参数可以在函数类里找到一个「完美」函数恰好穿过全部训练数据点，使训练误差为 0；但这个函数对未知样本误差很大。

### 9. 模型选择的奥卡姆剃刀法则

由 14 世纪方济会修士奥卡姆的威廉提出：「切勿浪费多余功夫去做本可以较少功夫完成之事」。用在模型选择上：如果关于同一个问题有许多种理论，每一种都能作出同样准确的预言，那么应该挑选其中**使用假定最少的**。

### 10. 岭回归和 LASSO 回归，哪种更容易获得稀疏解？为什么？

| | 目标函数 | 正则项 |
| --- | --- | --- |
| 岭回归 | $\min_{\boldsymbol{w}}\sum_{i=1}^{m}(y_i - \boldsymbol{w}^{\top}\boldsymbol{x}_i)^2 + \lambda\lVert\boldsymbol{w}\rVert_2^2$ | L2 |
| LASSO 回归 | $\min_{\boldsymbol{w}}\sum_{i=1}^{m}(y_i - \boldsymbol{w}^{\top}\boldsymbol{x}_i)^2 + \lambda\lVert\boldsymbol{w}\rVert_1$ | L1 |

**LASSO 更容易得到稀疏解。** 理由（画图答）：把正则项看成约束区域，L1 球在二维平面是菱形，四个尖角落在坐标轴上；L2 球是圆，处处光滑。平方误差项的等高线是椭圆，从外往里收缩，第一次接触约束区域的点就是解。菱形的角在坐标轴上，交点很容易落在角上，此时另一个参数必为 0；圆没有角，交点落在坐标轴上的概率很低。

### 11. 从概率的角度解释线性回归的损失函数（论述题）

链条是这样的：

1. 写出线性模型 $y^{(i)} = \theta^{\mathrm{T}}x^{(i)} + \varepsilon^{(i)}$。
2. 假设误差 $\varepsilon^{(i)}$ 独立同分布、服从 $N(0, \sigma^2)$。依据是中心极限定理，以及实际问题中很多随机现象是众多因素独立影响的综合反应。
3. 写出 $p(y^{(i)}\mid x^{(i)};\theta) = \frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(\theta^{\mathrm{T}}x^{(i)} - y^{(i)})^2}{2\sigma^2}}$。
4. 构造似然函数 $L(\theta) = \prod_i p(y^{(i)}\mid x^{(i)};\theta)$，取对数得 $\mathcal{L}(\theta) = m\log\frac{1}{\sqrt{2\pi}\sigma} - \frac{1}{2\sigma^2}\sum_i(\theta^{\mathrm{T}}x^{(i)} - y^{(i)})^2$。
5. 最大化 $\mathcal{L}(\theta)$ 等价于最小化 $\sum_i(h_\theta(x^{(i)}) - y^{(i)})^2$，也就是最小二乘的 $J(\theta)$。

结论：最小二乘回归对应着关于参数 $\theta$ 的最大似然估计。完整推导在 `02 线性回归.md` 的 2.10 节。

答完最好补一句：概率解释用了高斯噪声假设，但这些假设并不是最小二乘法成立的必要条件，没有这些假设最小二乘法依然好用。

## 二 逻辑回归与模型评估

### 12. 硬分类和软分类有什么差异？

- **硬分类**：输出离散的类别标签，模型直接给出样本属于哪一类（「类别 A」或「类别 B」）。
- **软分类**：输出连续的概率值，给出样本属于各个类别的概率。

### 13. 单位阶跃函数有什么缺点？

1. **不连续性**：在 $z = 0$ 处不连续，该点导数不存在。机器学习通常需要光滑的决策边界，才能用梯度下降优化。
2. **参数估计困难**：由于不连续，用梯度下降或其他基于梯度的算法估计参数 $\theta$ 变得困难甚至不可能。

### 14. 什么是 sigmoid 函数？它相较于单位跃迁函数的优势是什么？

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

特性：输出在 0 和 1 之间；S 形曲线；连续且可导。

四条优势：

| 方面 | sigmoid | 单位跃迁函数 |
| --- | --- | --- |
| 平滑性和可微性 | 连续平滑，导数处处存在，可用梯度下降 | 跳跃点处不可导 |
| 输出范围 | $(0,1)$，可解释为概率 | 只有 0 和 1，不能直接用于概率估计 |
| 梯度信息 | 每个输入点都能提供梯度，支持反向传播 | 跳跃点导数为零，提供不了有用的梯度 |
| 非线性 | 可以处理复杂的非线性关系 | 仅适用于线性分割 |

### 15. 对数几率回归的优点

三条：

1. 无需事先假设数据分布。
2. 得到「类别」的近似概率预测。
3. 可直接应用现有数值优化算法求取最优解。

### 16. 实现多分类回归的方式有哪些？

1. **One-vs-Rest（一对多）**：把一个多分类问题变成多个二分类问题，$K$ 类要训练 $K$ 个分类器。
2. **One-vs-One（一对一）**：每次选择两类数据做二分类，$K$ 类要训练 $\dfrac{K(K-1)}{2}$ 个分类器。
3. **使用 Softmax 函数**：直接输出 $K$ 类的概率分布。

分类器个数这一条是作业里的填空点，记牢 $K$ 和 $\frac{K(K-1)}{2}$。

### 17. 牛顿法主要用于求解什么问题？牛顿法的优势是什么？（22 级真题问的是「简述牛顿法求函数极值点的过程」）

**用途**：

1. 求解非线性方程 $f(\theta) = 0$，通过迭代不断调整 $\theta$ 让 $f(\theta)$ 逼近零。
2. 优化问题中找极值，即找使目标函数一阶导数为零的点。

**求极值点的过程**（按 22 级真题答）：

1. 要求 $f(\theta)$ 的极值，等价于求一阶导数的零点 $f'(\theta) = 0$。
2. 在当前点 $\theta_t$ 把 $f'$ 做一阶泰勒展开：$f'(\theta) \approx f'(\theta_t) + f''(\theta_t)(\theta - \theta_t)$。
3. 令右边为 0，解出下一个迭代点：$\theta_{t+1} = \theta_t - \dfrac{f'(\theta_t)}{f''(\theta_t)}$。
4. 多维情形把一阶导换成梯度、二阶导换成 Hessian 矩阵：$\theta := \theta - H^{-1}\nabla_\theta \ell(\theta)$。
5. 重复迭代直到收敛（梯度足够接近 0 或参数变化足够小）。

**优势**：通常比梯度下降法收敛更快，特别是当目标函数接近二次形式时。参数维度 $n$ 不大时牛顿法特别有效，因为 Hessian 矩阵的计算和求逆在计算上是可行的。

**局限**（一起记）：参数维度很大时 Hessian 矩阵庞大，计算和存储成本很高；Hessian 不是正定时牛顿法可能不稳定，实际要做修正（如拟牛顿法）。

### 18. 请解释什么是 Fisher scoring

先说牛顿法：迭代规则为

$$\theta := \theta - \frac{\ell'(\theta)}{\ell''(\theta)}$$

其中 $\ell'(\theta)$ 是对数似然函数的梯度（一阶导数），$\ell''(\theta)$ 是对数似然函数的 Hessian 矩阵（二阶导数）。每次迭代中参数 $\theta$ 根据当前梯度和 Hessian 的信息调整。

**Fisher 评分法是牛顿法的一种变种**，区别在于它用 Fisher 信息矩阵的期望值代替 Hessian 矩阵。应用于最大化逻辑回归对数似然函数 $\ell(\theta)$ 时，更新规则为：

$$\theta := \theta - \left[\mathbb{E}\big(\ell''(\theta)\big)\right]^{-1}\ell'(\theta)$$

Fisher 信息矩阵是对数似然函数二阶导数的期望值，因此通常更稳定，计算也更简单。

### 19. 似然和概率有什么区别和联系？什么是最大似然估计？

**区别**：概率描述了已知参数时随机变量的输出结果；似然用来描述已知随机变量输出结果时，未知参数的可能取值。

直接的判别方法：「XXX 的概率」中 XXX 只能是事件；「XXX 的似然」中 XXX 只能是参数。原稿举的例子是抛硬币：对于「一枚正反对称的硬币上抛十次」，可以问十次都正面朝上的**概率**是多少；对于「一枚硬币上抛十次」，可以问这枚硬币正反面对称的**似然**程度是多少。

**联系**：关于参数 $\theta$ 的似然函数在数值上等于给定参数 $\theta$ 后变量 data 的概率（两者数值相等，不是同一个函数）：

$$L(\theta \mid data) = P(data \mid \theta) = \prod_{i=1}^{N}P(x_i \mid \theta), \qquad data = (x_1, x_2, \dots, x_n)$$

似然函数的主要用法在于比较它的相对取值，数值本身不具备含义。似然函数乘以一个正的常数之后仍然是似然函数，取值不需要满足归一化条件：$\sum_x \alpha\cdot L(\theta\mid x) \neq 1$，$\alpha > 0$。

**最大似然估计**：似然函数取得最大值表示相应的参数能够使得统计模型最为合理。做法是先选取似然函数（一般是概率密度函数或概率质量函数），整理之后求最大值。实际应用中一般取似然函数的对数作为求最大值的函数，这样求出的最大值和直接求最大值得到的结果相同。似然函数的最大值不一定唯一，也不一定存在。

### 20. 偏差与方差的四种组合

| 组合 | 含义 |
| --- | --- |
| 高偏差、高方差 | 欠拟合且不稳定（不泛化） |
| 低偏差、高方差 | 过拟合且不泛化 |
| 高偏差、低方差 | 欠拟合但稳定 |
| 低偏差、低方差 | 理想状态，准确且稳定 |

记法是打靶图：偏差是弹着点的中心离靶心有多远，方差是弹着点散得有多开。

### 21. 模型评估方法和性能评价指标有哪些？

**模型评估方法**（评估模型的泛化能力）：

- 留出法（Holdout Method）
- 交叉验证（k-fold Cross-validation）
- 自助法（Bootstrapping）

**性能评价指标**：

| 指标 | 说明 |
| --- | --- |
| 准确率 accuracy | 预测正确的样本占总样本的比例 |
| 精确率（查准率）precision | 预测为正例的样本里真正是正例的比例 |
| 召回率（查全率）recall | 真实正例里被预测出来的比例 |
| 综合评价指标 F1 measure | $P$ 与 $R$ 的**调和平均** |
| 敏感性 Sensitivity / 真阳性率 TPR | 模型正确识别正例的能力，也就是召回率 |
| 假阳性率 FPR | 模型错误地把反例识别为正例的比例，等于 1 减去特异性 |
| ROC、AUC | ROC 是曲线，AUC 是 ROC 曲线下的面积；ROC 以 FPR 为横轴、TPR 为纵轴 |

### 22. 不同问题对 P 与 R 的偏重

- **推荐系统**更关心**查准率** P，因为用户更希望得到他们真正感兴趣的推荐。
- **重大疾病筛查**更关心**查全率** R（召回率），因为漏诊的后果可能非常严重。地震预测类似，每一个正例都希望预测出来。

### 23. 怎么根据 P-R 图判断模型性能？（两种标准）

先记方向：**P-R 图是从左上到右下**。

1. **包含关系**：如果一个学习器的 P-R 曲线被另一个的完全包住，则后者的性能优于前者。
2. **平衡点（BEP）**：平衡点是 $P = R$ 时的取值，这个值较大的学习器性能较好。曲线互相交叉时用它比较。

其他可以补充的点：

- 适用场景：相比 ROC 曲线，P-R 曲线更适合类别严重不平衡的问题，因为 precision 能反映正样本中的「误报」情况。
- 曲线的下降趋势：recall 逐渐提高时 precision 一般会下降，反映分类器需要在查全率和查准率之间权衡。
- 起点和终点：P-R 曲线通常从 $(0,1)$ 开始，表示阈值极高时只有极少数正样本被预测正确；终点趋于 $(1,0)$，表示阈值极低时所有样本都被预测为正样本。
- precision 高但 recall 低：模型预测得很准，但遗漏了很多正样本。
- recall 高但 precision 低：模型预测了很多正样本，但许多是误报。

### 24. 怎么根据 ROC、AUC 判断模型性能？

先记方向：**ROC 是从左下到右上**，横轴 FPR，纵轴 TPR。

AUC 是 ROC 曲线下面积的量化指标，取值范围 $[0, 1]$，值越高表示分类性能越好。**AUC = 0.5 时模型性能等同于随机猜测。**

一般来说，如果 ROC 是光滑的，基本可以判断没有太大的过拟合，这时调模型可以只看 AUC，面积越大一般认为模型越好。

## 三 人工神经网络

### 25. 人工神经网络有哪些特点？

1. 并行结构和并行处理。
2. 知识的分布存储。知识分布在整个系统中而不是存在特定的存储单元，要存储多个知识就需要很多连接；获取存储的知识采用「联想」的办法，类似人类和动物的记忆。联想记忆的两个主要特点是存储大量复杂数据的能力和自适应的特征抽取能力。
3. 快速的推理能力。
4. 容错性。
5. 自适应性。

### 26. 感知器在什么条件下可以收敛？

Minsky 和 Papert（1969）证明：**如果训练样例线性可分，并且使用了充分小的学习率 $\eta$，感知器的更新法则会收敛到正确的权值。** 否则不能保证收敛。

两个条件缺一不可，答题时都要写出来。

### 27. 梯度学习的改进优化算法有哪些？（作业题）

按解决的问题分三类：

| 类别 | 算法 |
| --- | --- |
| 动态学习率 | Adagrad、RMSProp |
| 处理梯度为 0 的情况 | Momentum（动量） |
| 综合方法 | Adam（RMSProp + Momentum） |

### 28. 卷积神经网络中为什么可以使用 ReLU 激活函数？（作业题）

**优势**：

1. 反向传播时可以避免梯度消失。
2. ReLU 会使一部分神经元的输出为 0，造成网络的稀疏性，减少参数的相互依存关系，缓解过拟合。
3. 相对 sigmoid 和 tanh，求导简单。sigmoid 这类函数算激活值要做指数运算，反向传播求误差梯度还涉及除法，计算量大；ReLU 整个过程的计算量节省很多。

**缺点**：

1. 左侧神经元输出为 0，导致神经元死亡，不再更新。
2. 输出非负，仍然存在 zigzag 现象（梯度更新方向被限制在同一象限，参数更新走 Z 字）。

### 29. Dropout 在测试时要做什么？

测试时使用完整的神经网络，但把每个神经元的输出乘以 $(1 - p\%)$，以补偿训练时的丢弃行为。

## 四 RBF 神经网络与 SOM

### 30. RBF Network 与常用的 Neural Network 相比，隐藏层有什么区别？（作业题）

| | 常用神经网络 | RBF 网络 |
| --- | --- | --- |
| 隐层计算 | Inner-product tanh：内积 + tanh 激活 | Distance Gaussian：距离 + 高斯激活 |
| 特性 | 全局特性 | 局部特性 |

一句话答法：经典网络的隐层算的是输入和权向量的内积再过 tanh，响应是全局的；RBF 网络的隐层算的是输入到中心的距离再过高斯函数，响应是局部的，离中心越远激活值越接近 0。

### 31. RBF 神经网络的扩展常数怎么确定？

扩展常数 $\delta$ 可以根据数据中心的最大距离 $d_{\max}$ 和中心数目 $M$ 来确定，例如

$$\delta = \frac{d_{\max}}{\sqrt{2M}}$$

### 32. 自组织特征映射神经网络中权重 $W$ 存储了什么信息？（作业题）

SOM 的权重存储了**竞争层每个节点的特征**。换句话说，每个竞争层节点的权向量就是该节点代表的那个原型向量（聚类中心），维度和输入样本相同。

### 33. 选择题：RBF 神经网络中隐藏层节点数

A. 小于样本数　B. 等于样本数　C. 大于样本数　D. 都有可能

**答案：B**（原稿标注）。这里说的是正则化 RBF 网络（插值型），每个训练样本对应一个基函数中心，所以隐层节点数等于样本数。

### 34. 选择题：广义 RBF 神经网络中隐藏层节点数

A. 远远小于样本数　B. 等于样本数　C. 远远大于样本数　D. 都有可能

**答案：A**（原稿标注）。广义 RBF 网络放弃了「每个样本一个中心」的插值约束，中心数目远小于样本数，这样才能控制规模和避免过拟合。

第 33、34 两题经常成对出现，区别就在「正则化/插值型」和「广义」这两个词上。

## 五 支持向量机

### 35. SVM 和 SVR 分别用于什么任务？（作业题）

- **SVM（支持向量机）** 主要用于**分类**。目标是找一个超平面把不同类别的数据点分开，并最大化两个类别之间的间隔（margin）。通过核函数把数据映射到高维空间，可以处理线性和非线性分类。
- **SVR（支持向量回归）** 主要用于**回归**。目标是拟合一个函数来预测连续的目标变量，在 $\varepsilon$ 不敏感区间内最小化预测误差。

### 36. SVR 与一般线性回归的区别

| 特性 | 一般线性回归 | 支持向量回归 SVR |
| --- | --- | --- |
| 损失函数 | 最小二乘法，残差的平方和 $L(w) = \sum_{i=1}^{N}(y_i - w\cdot x_i - b)^2$ | $\varepsilon$ 不敏感损失函数，允许一定范围内的误差 |
| 优化方法 | 最小二乘法，解析解 $w = (X^{\mathrm{T}}X)^{-1}X^{\mathrm{T}}y$ | 二次规划问题，使用拉格朗日乘子法和对偶问题求解 |

SVR 的优化问题：

$$\min_{w,b,\xi,\xi^*}\ \frac{1}{2}\lVert w\rVert^2 + C\sum_{i=1}^{N}(\xi_i + \xi_i^*)$$

$$\text{s.t.}\quad y_i - w\cdot x_i - b \le \varepsilon + \xi_i, \qquad w\cdot x_i + b - y_i \le \varepsilon + \xi_i^*, \qquad \xi_i,\ \xi_i^* \ge 0$$

（更正：原文把上面这个**优化目标**写成了「$\varepsilon$ 不敏感损失函数的定义」，还把松弛变量写成了 $\alpha_i,\alpha_i^*$。$\varepsilon$ 不敏感损失函数本身指的是单个样本上的损失 $L_\varepsilon(y, f(x)) = \max\big(0,\ \lvert y - f(x)\rvert - \varepsilon\big)$，也就是误差小于 $\varepsilon$ 时损失为零，否则损失为误差减去 $\varepsilon$；带 $\frac12\lVert w\rVert^2 + C\sum(\xi_i + \xi_i^*)$ 的那个式子是整个原问题的目标函数。$\alpha$ 在 SVM 里一般留给拉格朗日乘子，写成 $\xi$ 不容易混。）

总的说，SVR 通过正则化项和 $\varepsilon$ 不敏感损失，比一般线性回归更灵活也更抗噪；一般线性回归更简单，适用于线性关系明显的情况。

### 37. SVM 回归器的支持向量为什么具有稀疏性？

落在 $\varepsilon$ 带内部的样本，误差小于 $\varepsilon$，损失为 0，对目标函数没有贡献，它们对应的拉格朗日乘子为 0，不影响决策函数。只有落在 $\varepsilon$ 带边界上或外部的样本才有非零乘子，这些才是支持向量。所以大部分样本的乘子都是 0，解是稀疏的，决策函数只由少数支持向量决定。

### 38. 判断题：给定一个欧式空间和一个核函数 $K$，则只能得到唯一的高维特征空间 $H$ 以及从欧式空间到特征空间 $H$ 的映射 $f$，满足 $K(x,y) = f(x)\cdot f(y)$

**答案：错**（原稿标注）。同一个核函数可以对应多个不同的特征空间和映射。核技巧的意义恰恰在于只要知道核函数就够了，不需要也不必唯一确定 $\varphi$。

### 39. 判断题：对于线性可分的数据，感知器方法得到的分类超平面是不惟一的

**答案：对**（原稿标注）。感知机的损失函数只要求把样本分对，满足条件的超平面有无穷多个，具体收敛到哪个取决于初值和样本的更新顺序。

### 40. 判断题：对于线性可分的数据，线性可分支持向量机得到的分类超平面是惟一的

**答案：对**（原稿标注）。硬间隔最大化是一个严格凸的二次规划问题，最优解唯一，所以最大间隔分离超平面唯一。这一对判断题通常连着考，答案一个「不惟一」一个「惟一」，都是「对」。

### 41. 论述题：支持向量机（22 级真题）

分四问答，公式写在 `06 支持向量机.md`，这里给答题骨架：

1. **最优分类面的方程**：$w^{\mathrm{T}}x + b = 0$，决策函数 $f(x) = \operatorname{sign}(w^{\mathrm{T}}x + b)$。
2. **硬间隔最小化的目标函数、约束条件及几何意义**：$\min_{w,b}\frac12\lVert w\rVert^2$，约束 $y_i(w^{\mathrm{T}}x_i + b)\ge 1$。几何意义是两类支持向量所在的间隔边界之间的距离为 $\frac{2}{\lVert w\rVert}$，最小化 $\frac12\lVert w\rVert^2$ 就是最大化这个间隔；约束保证所有样本都被正确分类且落在间隔边界之外。
3. **软间隔最小化的目标函数、约束条件**：$\min_{w,b,\xi}\frac12\lVert w\rVert^2 + C\sum_i\xi_i$，约束 $y_i(w^{\mathrm{T}}x_i + b)\ge 1 - \xi_i$，$\xi_i\ge 0$。$C$ 是惩罚参数，权衡间隔大小和误分类程度。
4. **为什么要引入核函数？核方法的思想？** 因为现实中数据常常线性不可分，需要映射到高维空间才能线性可分；但显式构造映射 $\varphi$ 困难，而且映射后维数爆炸带来维数灾难（计算复杂度和存储需求都急剧增加）。核方法的思想是：对偶问题里样本只以内积 $x_i\cdot x_j$ 的形式出现，于是用核函数 $K(x_i, x_j) = \varphi(x_i)\cdot\varphi(x_j)$ 直接计算高维空间的内积，绕开显式映射。满足 Mercer 条件的函数都可以作为核函数。

## 六 聚类与降维

### 42. K-means 聚类算法的三个缺点（22 级真题）

1. **需要预先指定簇数 $K$**，而 $K$ 通常事先未知，只能靠肘部法之类的经验方法试。
2. **对初始聚类中心敏感**，不同初值可能收敛到不同的局部最优解。
3. **对异常值（离群点）很敏感**，因为簇中心用的是均值，一个极端点就能把中心拉偏。

还可以补充的缺点（答三个够了，多写无妨）：只适合球形、大小相近的簇，对非凸形状的簇效果差；只能处理数值型特征，需要定义均值。

对应的改进算法原笔记列了一张表，比如 K-medoids 把求平均值换成求中位数来抗异常值，K-means++ 改进初始中心的选取。

### 43. 主成分分析的原理及其实现过程（22 级真题）

**原理**：找一组正交的新坐标轴，使数据在第一个轴上的投影方差最大，第二个轴与第一个正交且方差次大，依此类推。保留方差大的前几个方向、丢掉方差小的方向，就在损失信息最少的前提下把维度降了下来。数学上这组方向就是数据协方差矩阵的特征向量，对应的特征值就是投影后的方差。

**实现过程**：

1. 对原始数据做中心化（每个特征减去自己的均值），量纲差异大时再标准化。
2. 计算协方差矩阵 $C = \frac{1}{m}X^{\mathrm{T}}X$（$X$ 已中心化）。
3. 求 $C$ 的特征值和特征向量。
4. 把特征值从大到小排序，取前 $k$ 个特征值对应的特征向量，标准化后按行组成投影矩阵 $P$。
5. $Y = PX$ 即为降到 $k$ 维后的数据。

$k$ 的选法：按累计贡献率 $\frac{\sum_{i=1}^{k}\lambda_i}{\sum_{i=1}^{n}\lambda_i}$ 达到某个阈值（如 85%）来定。

手算例子见 `11 计算与证明题精编.md`。

### 44. 选择题：PCA 是

A. 有监督学习　B. 无监督学习

**答案：B**（原稿标注）。PCA 只用到特征 $X$，完全不看标签 $y$。对比 LDA，LDA 要用标签算类间散度和类内散度，是有监督的降维。

### 45. 选择题：使用 PCA 对某高维数据 $W$ 降维，已知 $W$ 在正交的 $u_1, u_2, u_3$ 三个方向上的投影数据的方差分别为 30、25、51，应该先将数据投影到哪个方向？

A. $u_1$　B. $u_2$　C. $u_3$　D. 哪个都可以

**答案：C**（原稿标注）。PCA 按方差从大到小取主成分，51 最大，所以第一主成分方向是 $u_3$。

### 46. 变分自编码器（VAE）和自编码器（AE）相比有什么优势？（作业题）

| 方面 | VAE 相对 AE 的优势 |

| 生成能力 | VAE 能生成新数据样本，AE 主要重构输入数据 |
