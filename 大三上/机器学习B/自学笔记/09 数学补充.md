## 1 LMS 最小均方算法

LMS（Least Mean Squares，最小均方误差）是一种自适应滤波算法，常用于信号处理和机器学习。目的是通过最小化估计误差的均方误差来优化参数，让模型更准确地预测输出。

**关键点**：

- 目标：调整模型参数，使输出信号与期望信号之间的均方误差最小化。
- 应用：自适应滤波、预测、噪声消除、信道均衡。
- 步骤：初始化权重向量 → 计算当前输出与期望输出之间的误差 → 根据误差调整权重。

**算法公式**。设输入向量为 $\boldsymbol{x}(n)$，权重向量为 $\boldsymbol{w}(n)$，期望输出为 $d(n)$，实际输出为 $y(n)$。误差

$$e(n)=d(n)-\boldsymbol{w}(n)^{\top}\boldsymbol{x}(n)$$

权重更新

$$\boldsymbol{w}(n+1)=\boldsymbol{w}(n)+\mu\, e(n)\,\boldsymbol{x}(n)$$

$\mu$ 是学习率，控制权重更新的步长。

这两行就是随机梯度下降在平方误差 $E=\frac12 e^{2}$ 上的结果：$\frac{\partial E}{\partial w}=-e\,x$，取负梯度方向就是 $+\mu e x$。RBF 网络输出层权值的「最小均方算法」用的就是这条（见 `05 RBF神经网络与SOM.md` 5.4 节）。

## 2 箱线图

箱线图由一个矩形框（箱体）和一对对称的上下「胡须」组成。箱体表示数据中间 50% 的分布情况（四分位间距），上下胡须表示数据的范围。

**组成部分**：

| 元素 | 含义 |
| --- | --- |
| 最小值 Minimum | 数据集中的最小值，通常表示为胡须的下端 |
| 第一四分位数 $Q_1$ | 下四分位数，25% 的数据点比它小，箱体的下边界 |
| 中位数 Median（$Q_2$） | 数据的中间值，50% 的数据点比它小，箱体内的那条线 |
| 第三四分位数 $Q_3$ | 上四分位数，75% 的数据点比它小，箱体的上边界 |
| 最大值 Maximum | 数据集中的最大值，通常表示为胡须的上端 |
| 异常值 Outliers | 明显偏离数据其他部分的值，通常以独立的小圆点或星号标出 |

**怎么读**：

- 箱体（盒子）：从 $Q_1$ 到 $Q_3$，盒子的长度表示四分位距 $\mathrm{IQR}=Q_3-Q_1$。
- 胡须：从箱体两端向外延伸，表示数据的范围。通常延伸到 $Q_1-1.5\,\mathrm{IQR}$ 和 $Q_3+1.5\,\mathrm{IQR}$ 之内的最远数据点。
- 中位数线：盒子内部的那条线。中位数是统计学的专业名词，代表一个样本、种群或概率分布中的一个数值，它可将数值集合划分为数量相等的上下两部分。
- 异常值：落在胡须之外的数据点。

**用途**：比较不同数据集的分布情况；识别数据中的异常值和离群点；显示数据的对称性、偏态和多态。

**示例**。数据集（已排序）

$$5,\ 7,\ 8,\ 12,\ 13,\ 13,\ 16,\ 18,\ 21,\ 23,\ 24,\ 30$$

共 12 个数。按 Tukey 的分位数约定：

- 最小值：5
- 中位数 $Q_2$：第 6、7 个数的平均，$(13+16)/2=14.5$
- 下半部分 $5,7,8,12,13,13$ 的中位数即 $Q_1$：$(8+12)/2=10$
- 上半部分 $16,18,21,23,24,30$ 的中位数即 $Q_3$：$(21+23)/2=22$
- 最大值：30
- $\mathrm{IQR}=22-10=12$，下胡须界 $10-18=-8$，上胡须界 $22+18=40$，所有点都在界内，没有异常值。

（更正：原笔记这个例子给的是 $Q_1=12$、中位数 $=15$、$Q_3=22$。12 个数的中位数只能是第 6、7 个数的平均 14.5，写 15 是错的；$Q_1=12$ 也不符合任何常用约定，用 numpy 的线性插值法是 11，用 Tukey 法是 10。只有 $Q_3=22$ 对得上 Tukey 法。考试遇到这类题先问清用哪种分位数约定，或者直接按 Tukey 法算并写明。）

用 Python 核对一遍：

```python
import numpy as np
d = np.array([5, 7, 8, 12, 13, 13, 16, 18, 21, 23, 24, 30])
print(np.median(d))                      # 14.5
print(np.median(d[:6]), np.median(d[6:]))  # 10.0 22.0  (Tukey hinges)
print(np.percentile(d, [25, 50, 75]))    # [11.  14.5 21.5]  (numpy 默认线性插值)
```

**正态分布的箱线图**。原笔记配了一张对照图：对近似正态的数据，$Q_1\approx-0.6745\sigma$，$Q_3\approx 0.6745\sigma$，箱体盖住中间 50%；胡须端点 $Q_1-1.5\mathrm{IQR}\approx-2.698\sigma$、$Q_3+1.5\mathrm{IQR}\approx 2.698\sigma$，两侧各留 0.35% 落在胡须外。图上标的比例是 $0.35\%\ /\ 24.65\%\ /\ 50\%\ /\ 24.65\%\ /\ 0.35\%$。

这也解释了「1.5 倍 IQR」这个魔数的来历：正态数据下它大约对应 $\pm 2.7\sigma$，把 0.7% 的点判成异常值。

## 3 几率（Odds）

在统计和概率理论中，一个事件或者一个陈述的**发生比**（Odds，又称几率、几率比）是该事件发生和不发生的比率：

$$\mathrm{odds}=\frac{p}{1-p}$$

$p$ 是该事件或陈述的概率。

**例子**：一个人随机选择一星期 7 天中的一天，选择星期日的发生比是

$$\frac{1/7}{1-(1/7)}=\frac{1/7}{6/7}=\frac{1}{6}$$

不选择星期日的发生比为 $\frac{6}{1}=6$。

几率比其实是一种相对概率，日常不太使用几率比来描述概率。

它在这门课里的作用是逻辑回归：$\ln\frac{p}{1-p}=w^{T}x+b$ 就是对数几率（log odds / logit），所以逻辑回归又叫对数几率回归。$p$ 的取值范围是 $[0,1]$，几率的范围是 $[0,+\infty)$，对数几率的范围是 $(-\infty,+\infty)$，正好和线性函数的值域对上。

## 4 最优化问题：三种情形

先把地图摆清楚。一般的最优化问题写成

$$\min_{\boldsymbol{x}}\ f(\boldsymbol{x})$$

$$\text{s.t.}\quad h_i(\boldsymbol{x})=0\quad i=1,2,3,\dots,m$$

$$\qquad\quad\ \ g_j(\boldsymbol{x})\le 0\quad j=1,2,3,\dots,n$$

这里说的最优化问题通常指对给定的某一函数，求其在指定作用域上的**全局最小值**（最大值问题可以取负号转化成最小值问题）。三种情形对应三种工具：

| 情形 | 方法 |
| --- | --- |
| 1. 无约束条件 | 对变量求导并令其为 0，求得极值 |
| 2. 只有等式约束 | 拉格朗日乘子（或消元法） |
| 3. 等式约束和不等式约束 | KKT 条件 |

**（1）无约束条件**。最简单：函数对变量求导，令求导函数等于 0 的点可能是极值点，把结果带回原函数验证即可。

## 5 拉格朗日乘子法（等式约束）

设目标函数为 $f(x)$，约束条件为 $h_i(x)$：

$$\min_{\boldsymbol{x}}\ f(\boldsymbol{x}),\qquad \text{s.t.}\quad h_i(\boldsymbol{x})=0\ (i=1,\dots,m)$$

`s.t.` 表示 subject to（受限于）的意思。解决方法是消元法或者拉格朗日法。消元法比较简单，这里主要讲拉格朗日法，因为 KKT 条件是对拉格朗日乘子法的一种泛化。

定义拉格朗日函数

$$F(x,\lambda)=f(x)+\sum_{k=1}^{l}\lambda_k h_k(x)$$

其中 $\lambda_k$ 是各个约束条件的待定系数。然后解变量的偏导方程（这一步在找梯度共线）：

$$\frac{\partial F}{\partial x_i}=0,\qquad \frac{\partial F}{\partial \lambda_k}=0$$

如果有 $l$ 个约束条件、$n$ 个变量，就应该有 $l+n$ 个方程。求出的方程组的解就可能是最优化值（高等数学中提到的极值），把结果带回原方程验证就可得到解。（$\frac{\partial F}{\partial\lambda_k}=0$ 解出来的就是原来的约束 $h_k(x)=0$，所以约束自动被满足。）

### 例题：椭球内接长方体的最大体积

**题目**：给定椭球

$$\frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}}+\frac{z^{2}}{c^{2}}=1$$

求这个椭球的内接长方体的最大体积。

这是条件极值问题：在上面的约束下，求 $f(x,y,z)=8xyz$ 的最大值（长方体八个卦限各一块，所以是 $8xyz$，$x,y,z>0$）。这个问题实际上可以先根据条件消去 $z$（消元法）转化为无条件极值，但有时候这样做很困难甚至做不到，这时候就要用拉格朗日乘数法。

**解**。构造

$$F(x,y,z,\lambda)=f(x,y,z)+\lambda\varphi(x,y,z)=8xyz+\lambda\left(\frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}}+\frac{z^{2}}{c^{2}}-1\right)$$

对 $F(x,y,z,\lambda)$ 求偏导：

$$\frac{\partial F}{\partial x}=8yz+\frac{2\lambda x}{a^{2}}=0$$

$$\frac{\partial F}{\partial y}=8xz+\frac{2\lambda y}{b^{2}}=0$$

$$\frac{\partial F}{\partial z}=8xy+\frac{2\lambda z}{c^{2}}=0$$

$$\frac{\partial F}{\partial \lambda}=\frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}}+\frac{z^{2}}{c^{2}}-1=0$$

联立前面三个方程消去 $\lambda$。由第一、第二式

$$\lambda=-\frac{4a^{2}yz}{x}=-\frac{4b^{2}xz}{y}\ \Longrightarrow\ a^{2}y^{2}=b^{2}x^{2}\ \Longrightarrow\ bx=ay$$

同理由第一、第三式得 $az=cx$。带入第四个方程：用 $y=\frac{b}{a}x,\ z=\frac{c}{a}x$ 代入得 $\frac{3x^{2}}{a^{2}}=1$，所以

$$x=\frac{\sqrt3}{3}a,\qquad y=\frac{\sqrt3}{3}b,\qquad z=\frac{\sqrt3}{3}c$$

带入解得最大体积为

$$V_{\max}=f\!\left(\frac{\sqrt3}{3}a,\frac{\sqrt3}{3}b,\frac{\sqrt3}{3}c\right)=8\cdot\frac{\sqrt3}{3}a\cdot\frac{\sqrt3}{3}b\cdot\frac{\sqrt3}{3}c=\frac{8\sqrt3}{9}abc$$

$\frac{8\sqrt3}{9}\approx 1.5396$。椭球体积是 $\frac43\pi abc\approx 4.189\,abc$，内接长方体占了约 36.8%。

**Python 复算**（取 $a=2,b=3,c=5$，在椭球上随机撒点取体积最大者）：

```python
import numpy as np
a, b, c = 2.0, 3.0, 5.0
rng = np.random.default_rng(0)
best, arg = 0.0, None
for _ in range(400000):
    x = rng.uniform(0, a); y = rng.uniform(0, b)
    t = 1 - x*x/a**2 - y*y/b**2
    if t <= 0:
        continue
    z = c*np.sqrt(t)
    V = 8*x*y*z
    if V > best:
        best, arg = V, (x, y, z)
print(best, 8*np.sqrt(3)/9*a*b*c)      # 46.1878  vs  46.1880
print(arg, (a/np.sqrt(3), b/np.sqrt(3), c/np.sqrt(3)))
```

数值搜索得到 46.1878，解析解 $\frac{8\sqrt3}{9}\times 2\times 3\times 5=46.1880$，取到最大值的点也与 $(a/\sqrt3,\,b/\sqrt3,\,c/\sqrt3)\approx(1.155,\,1.732,\,2.887)$ 吻合。

### 为什么这么做可以求解最优化：几何直觉

举个二维的例子：

$$\min\ f(x,y),\qquad \text{s.t.}\ g(x,y)=c$$

画出 $z=f(x,y)$ 的等高线（图里是一圈圈蓝色虚线椭圆），绿线标出的是约束 $g(x,y)=c$ 的点的轨迹。箭头表示梯度，和等高线的法线平行。从梯度的方向看，显然有 $d_1>d_2$（外圈等高线的值更大）。

只有正好落在绿线上的点才可能满足要求。如果没有这条约束，$f(x,y)$ 的最小值应该落在最小那圈等高线内部的某一点上。加上约束之后，最小值点应该在哪里？应该在 $f(x,y)$ 的等高线正好和约束线**相切**的位置。因为如果只是相交，就意味着肯定还存在其它等高线在该条等高线的内部或者外部，使得新的等高线与约束线的交点的值更大或者更小；只有到等高线与约束曲线相切的时候，才可能取得最优值。

如果我们对约束也求梯度 $\nabla g(x,y)$（图中绿色箭头），很容易看出来：要想让目标函数的等高线和约束相切，则它们切点的梯度一定在一条直线上（$f$ 和 $g$ 的斜率平行）。

也即在最优化解的时候：

$$\nabla f(x,y)=\lambda\,\nabla\bigl(g(x,y)-c\bigr)$$

$\nabla$ 为梯度算子，$\lambda$ 是常数，可以是任何非 0 实数，表示左右两边同向或反向。移项即

$$\nabla\bigl[f(x,y)+\lambda(g(x,y)-c)\bigr]=0,\qquad \lambda\neq 0$$

那么拉格朗日函数 $F(x,y)=f(x,y)+\lambda(g(x,y)-c)$ 在达到极值时与 $f(x,y)$ 相等，因为 $F$ 达到极值时 $g(x,y)-c$ 总等于零。

简单地说：在 $F(x,\lambda)$ 取得最优化解的时候，也就是 $F(x,\lambda)$ 取极值（导数为 0）的时候，$f(x)$ 与 $g(x)$ **梯度共线**，此时就是在条件约束 $g(x)$ 下 $f(x)$ 的最优化解。

## 6 KKT 条件（不等式约束）

设目标函数 $f(x)$，不等式约束为 $g(x)$，有的教程还会添加上等式约束条件 $h(x)$。此时的约束优化问题描述如下：

$$\min_{\boldsymbol{x}}\ f(\boldsymbol{x})$$

$$\text{s.t.}\quad h_i(\boldsymbol{x})=0\ (i=1,\dots,m),\qquad g_j(\boldsymbol{x})\le 0\ (j=1,\dots,n)$$

定义不等式约束下的拉格朗日函数 $L$：

$$L(\boldsymbol{x},\boldsymbol{\lambda},\boldsymbol{\mu})=f(\boldsymbol{x})+\sum_{i=1}^{m}\lambda_i h_i(\boldsymbol{x})+\sum_{j=1}^{n}\mu_j g_j(\boldsymbol{x})$$

其中 $f(x)$ 是原目标函数，$h_i(x)$ 是第 $i$ 个等式约束条件，$\lambda_i$ 是对应的约束系数，$g_j$ 是不等式约束，$\mu_j$ 是对应的约束系数（也叫松弛变量）。

### KKT 条件的四条

如果一个点 $x^{*}$ 是满足所有约束的极值点，那么

$$\begin{cases}\nabla f(x^{*})+\sum_{k}\lambda_k\nabla h_k(x^{*})+\sum_{j}\mu_j\nabla g_j(x^{*})=0 & (1)\\[1mm] \mu_j\ge 0 & (2)\\[1mm] \mu_j\,g_j(x^{*})=0 & (3)\\[1mm] g_j(x^{*})\le 0 & (4)\end{cases}$$

### 逐条解读

**(1) 梯度条件**：极值点处函数的梯度是约束条件梯度的线性组合。同时，只有满足 $g_j(x^{*})=0$ 的那些不等式约束的梯度才会出现在加权式中，才有资格给人加权（不在边界上的约束由条件 (3) 强制 $\mu_j=0$）。

**(2) 乘子非负**：不等式约束的权值（KKT 乘子）必须大于等于 0，因为 $f(x)$ 和 $g(x)$ 的梯度方向必须相反。

这条的几何推导（原笔记讲得很清楚，值得背下来）：

假设某问题的可行域就是那张图里画的形状（仅为便于理解，实际可行域不一定长成这样），红色曲线表示 $g(x)=0$ 构成的曲面，围成的阴影区域表示 $g(x)<0$。

- **极值点肯定往可行域的边界靠**，不会在可行域中间某处（如果在中间，说明无约束最优就在里面，那这个约束等于没用）。所以边界上极值点处的函数值自然比可行域内的函数值小（这里最小化目标函数；如果是最大化，就是边界比里面大了），因此极值点处 $f$ 的梯度方向（函数值增大最快的方向）是**向里面**的。
- 而对于约束条件，可行域里 $g$ 的值比边界要小（可行域里 $g<0$，边界上 $g=0$），所以极值点处 $g(x)$ 的梯度方向**朝外面**。
- 二者必然方向相反，所以 KKT 乘子必然为正。

从这个推导过程也能明白为啥等式约束下不要求拉格朗日乘子必须为正：等式约束没有「里面」和「外面」之分，$h(x)=0$ 是一张曲面而不是一个区域，梯度共线就够了，同向反向都行。**等式约束的权值（拉格朗日乘子）的正负无要求。**

**(3) 互补松弛条件**：

- 若某个不等式约束在极值点取值**严格小于 0**，则这个约束条件**无效**，有没有这个约束根本影响不了结果，其 KKT 乘子为 0，即 $\mu_j=0$。
- 若极值点处不等式约束**取值等于 0**，这个约束就是**有效**的，可行域边界的构建有它出的一份力，则其 KKT 乘子为正。

这也是 KKT 乘子为什么又被称为松弛变量的原因：它让 $\le$ 变成了 $=$，把不等式约束变为了等式约束，通过它的引入使得约束变得简单了。

整个可行域是由 $g_j(x)\le 0$ 和 $h_k(x)=0$ 围成的，但实际上有些不等式约束没对边界的形成做出贡献，就对函数在极值点处的梯度无贡献（都没在边界肯定贡献不了梯度），所以根本不分配乘子。

**(4) 原始可行性**：解必须落在可行域里。

把这四条对照 SVM 看：$\mu_j$ 就是 $\alpha_i$，$g_j(x)\le 0$ 就是 $1-y_i(w\cdot x_i+b)\le 0$，条件 (3) 说的「$\alpha_i>0$ 的样本必须落在间隔边界上」就是支持向量的定义（见 `06 支持向量机.md` 6.3 节）。

## 7 对偶问题

### 为什么要研究对偶问题

原问题 (P)：

$$\min f(x),\qquad \text{s.t.}\ g_i(x)\le 0\ (i=1,\dots,m),\ h_i(x)=0\ (i=1,\dots,l),\ x\in X$$

三条理由（原 PPT 的三点，学长在旁边写了「个人理解：松弛」）：

1. (P) 是非凸问题，难以求解，需要寻找一个与 (P) **联系紧密、简单**的问题。
2. **弱对偶定理**给 (P) 的最优解定了一个**下界**，对于求解 (P) 非常有帮助。
3. 变量少、约束多的 (P)，可以通过互换约束变量和对偶变量**缩小问题规模**。

### 如何写出对偶

**第一步，处理约束 $g_i(x)$ 和 $h_i(x)$：引入拉格朗日函数**

$$\min\ L(x,\lambda,\mu)=f(x)+\sum_{i=1}^{m}\lambda_i g_i(x)+\sum_{i=1}^{l}\mu_i h_i(x),\qquad x\in X$$

这里有**两组变量**：约束变量 $x$、对偶变量 $\lambda,\mu$。约束被「吸收」进了目标函数，所以可行域从 $S$ 放宽成了 $X$（松弛）。

**第二步，对关于 $x$ 的函数取最小值**

$$d(\lambda,\mu)=\min_{x\in X}\left\{f(x)+\sum_{i=1}^{m}\lambda_i g_i(x)+\sum_{i=1}^{l}\mu_i h_i(x)\right\}$$

$d(\lambda,\mu)$ 称为**对偶函数**，也叫拉格朗日对偶函数。它是一个映射关系：给定一组 $\lambda$ 和 $\mu$，就会产生对应且固定的最小值。

### 对偶函数是原问题最优值的下界（弱对偶的推导）

设原问题的可行域是 $S=\{x\in X\mid g_i(x)\le 0,\ h_i(x)=0\}$，显然 $S\subseteq X$。逐步放缩：

$$d(\lambda,\mu)=\min_{x\in X}\left\{f(x)+\sum_i\lambda_i g_i(x)+\sum_i\mu_i h_i(x)\right\}$$

$$\le\ \min_{x\in S}\left\{f(x)+\sum_i\lambda_i g_i(x)+\sum_i\mu_i h_i(x)\right\}\qquad\text{（缩小集合约束，最小值只会变大或不变）}$$

$$\le\ \min_{x\in S}\{f(x)\}\qquad\text{（在 }\forall(\lambda,\mu),\ \lambda\ge 0\text{ 的前提下）}$$

第二个不等号的理由（学长的批注）：因为在可行域 $S$ 内，所以 $h_i(x)=0$，那一项直接消失；又根据 KKT 条件，不等式约束前的拉格朗日乘子 $\lambda_i\ge 0$，而可行域内 $g_i(x)\le 0$，所以 $\sum\lambda_i g_i(x)\le 0$，倒数第二行的后两项之和小于等于 0，因此推导出最后一行。

**结论**：

$$d(\lambda,\mu)\le\min_{x\in S}\{f(x)\}=v(P)$$

对于 $\forall(\lambda,\mu),\ \lambda\ge 0$，必有 $d(\lambda,\mu)\le v(P)$。$d(\lambda,\mu)$ 为对偶函数的值，$v(P)$ 为原问题 (P) 的最优值，即 $d(\lambda,\mu)$ 是 $v(P)$ 的**下界**。

### 对偶问题 (D)

既然每组 $(\lambda,\mu)$ 都给一个下界，那就找最紧的那个下界：

$$(\mathrm{D}):\quad \max\ d(\lambda,\mu),\qquad \text{s.t.}\ \lambda_i\ge 0,\ i=1,\dots,m$$

注意对偶问题里只对 $\lambda$（不等式约束的乘子）要求非负，$\mu$（等式约束的乘子）没有符号限制，理由就是上一节讲的。

### 对偶问题的几何解释

为了画图，假设原问题**只含一个不等式约束**：

$$(\mathrm{P}):\ \min f(x),\ \ g(x)\le 0,\ \ x\in X\qquad\Longleftrightarrow\qquad (\mathrm{D}):\ \max d(\lambda),\ \ \lambda\ge 0$$

拉格朗日函数 $L(x,\lambda)=f(x)+\lambda g(x)$，对偶函数

$$d(\lambda)=\min_{x\in X}\{f(x)+\lambda g(x)\}$$

观察发现 (P) 和 (D) 均与 $f(x)$、$g(x)$ 有关。为便于绘图和理解，把 $f(x)$ 和 $g(x)$ 做映射，建立二维空间集合

$$G=\left\{\begin{pmatrix}y\\z\end{pmatrix}\ \middle|\ g(x)=y,\ f(x)=z,\ x\in X\right\}$$

于是两个问题都变成了 $G$ 上的几何问题：

| | (P) | (D) |
| --- | --- | --- |
| 目标 | $\min z$ | $\max d(\lambda)$ |
| 约束 | $y\le 0$ | $\lambda\ge 0$ |
| 定义域 | $\binom{y}{z}\in G$ | $d(\lambda)=\min\limits_{\binom{y}{z}\in G}\{z+\lambda y\}$ |

**怎么看图**：考虑直线族 $\alpha=z+\lambda y$，即 $z=-\lambda y+\alpha$。这是一族斜率为 $-\lambda$、纵截距为 $\alpha$ 的直线。

- **内层 $\min$**：在给定 $\lambda$ 的情况下最小化截距，也就是把这条斜率固定的直线从下往上推，推到刚好碰到区域 $G$ 为止，此时的截距 $\alpha$ 就是 $d(\lambda)$。
- **外层 $\max$**：不同的 $\lambda$ 在内层对应不同的最小值，找出最大的那一个，也就是在所有斜率里挑一条能把截距顶得最高的支撑线。

$z^{*}$ 即为原问题 (P) 的最优解：$G$ 与 $y\le 0$ 那半平面相交的部分里最低的那个点。

**凸的情况**：$G$ 是一个凸区域（原图画成一个椭圆），支撑线能一直顶到 $z^{*}$ 那个点，$v(D)=v(P)$，对偶问题与原问题答案相同。

**非凸的情况**：$G$ 是一个有凹陷的区域（原图画成一个腰部内凹的形状），支撑线被凹陷挡住，只能顶到 $v(D)$ 这个位置，而 $z^{*}=v(P)$ 在更高处，两者不相等，中间那段差距就是对偶 gap。

### 弱对偶定理（天然存在的）

设 $v(P)$ 为原问题 (P) 的最优值，$v(D)$ 为对偶问题 (D) 的最优值，则

$$v(D)\le v(P)$$

完整的链条：

$$d(\lambda,\mu)\ \le\ v(D)\ \le\ v(P)\ \le\ f(x)$$

中间那段 $v(D)\le v(P)$ 的差距称为 **Duality Gap（对偶间隙）**。

**两条推论**：

1. 设 $\bar{x}\in S$，$(\bar\lambda,\bar\mu)$ 满足 $\bar\lambda\ge 0$，且 $d(\bar\lambda,\bar\mu)=f(\bar x)$，则 $v(D)=v(P)$，且 $\bar x$、$(\bar\lambda,\bar\mu)$ 分别是 (P) 和 (D) 的最优解。（找到一对上下界相等的可行解，就同时证明了两边都最优。）
2. 若 $v(P)=-\infty$，则 $d(\lambda,\mu)=-\infty$；若 $v(D)=+\infty$，则 $v(P)=+\infty$，问题 (P) 无可行解。

对偶 gap 为 0 时就是**强对偶**。

### 强对偶定理（需要一定条件）

**条件一（凸性）**：若集合 $X$ 为非空凸集，$f(x)$ 及 $g_i(x),\ i=1,\dots,m$ 是凸函数，$h_i(x),\ i=1,\dots,l$ 均为线性函数。

**条件二（Slater 条件 / Constraint Qualifications）**：假设存在 $\hat{x}\in X$，使得

$$g_i(\hat x)<0,\ i=1,\dots,m;\qquad h_i(\hat x)=0,\ i=1,\dots,l;\qquad 0\in\mathrm{int}\,h(X)$$

其中 $h(X)=\{(h_1(x),\dots,h_l(x))\mid x\in X\}^{T}$。这条要求原问题 (P) 存在**严格可行点**（所有不等式约束都取严格小于号）。

两条都满足，则有强对偶条件 $v(D)=v(P)$ 成立，$x,(\lambda,\mu)$ 分别为最优解。

SVM 的原问题恰好满足这两条：$\frac12\|w\|^2$ 是凸的，约束是线性的，线性可分时也存在严格可行点，所以可以放心用对偶问题替代原问题。

### 对偶问题的基本性质：对偶问题总是凸问题

**回顾原问题与对偶问题的关系链**：

$$\text{(P)}\ \xrightarrow[\text{（松弛）}]{\text{减少约束}}\ L(x,\lambda,\mu)=f(x)+\sum_{i=1}^{m}\lambda_i g_i(x)+\sum_{i=1}^{l}\mu_i h_i(x)$$

$$\xrightarrow[\text{（内层最小）}]{\text{两组变量：对偶变量}}\ d(\lambda,\mu)=\min_{x\in X}\left\{f(x)+\sum_{i=1}^{m}\lambda_i g_i(x)+\sum_{i=1}^{l}\mu_i h_i(x)\right\}$$

$$\xrightarrow[\text{（外层最大）}]{\text{两组变量：约束变量}}\ \text{(D)}:\ \max d(\lambda,\mu),\ \lambda_i\ge 0$$

最优值、最优解之间由强弱对偶定理连接。

**结论**：$\max d(\lambda,\mu)$ 等价于 $\min\ -d(\lambda,\mu)$，而 $-d(\lambda,\mu)$ 是**凸函数**，所以对偶问题永远是凸问题。

**怎么理解 $d(\lambda,\mu)$ 是凹函数**：

$$d(\lambda,\mu)=\min_{x\in X}\left\{f(x)+\sum_{i=1}^{m}\lambda_i g_i(x)+\sum_{i=1}^{l}\mu_i h_i(x)\right\}$$

关键的两句话：

- 一组凸函数取最大，得到的是凸函数。
- 一组凹函数取最小，得到的是凹函数。

假设 $X$ 只包含有限个点 $x^{1},x^{2},x^{3},x^{4}$，则

$$d(\lambda,\mu)=\min_{i=1,2,\dots,N}\left\{f(x^{i})+\lambda^{T}g(x^{i})+\mu^{T}h(x^{i})\right\}$$

对固定的 $x^{i}$，花括号里的东西是关于 $\lambda$ 和 $\mu$ 的**线性函数**（既是凸函数又是凹函数）。一堆线性函数逐点取最小，得到的是分段线性的凹函数。原笔记画了一张三维示意图：四个平面（编号 1 到 4）在 $\mu=0$ 的截面上交出一条黄色的折线，那条折线朝下凸，就是 $d(\lambda,0)$。

由这个例子可以看出对偶问题是个凸问题。这一点跟原问题凸不凸完全无关，这正是「对偶问题更简单、更容易求解」的根据。

## 8 线性代数：特征值与特征向量的求法

原笔记这一节只放了一个 CSDN 链接，没有正文。下面按标准做法补全，并给一个完整算例。

### 定义

设 $A$ 是 $n$ 阶方阵，若存在数 $\lambda$ 和**非零**向量 $\xi$，使得

$$A\xi=\lambda\xi$$

则称 $\lambda$ 是 $A$ 的**特征值**，$\xi$ 是 $A$ 的属于 $\lambda$ 的**特征向量**。

几何意义：$A$ 作用在 $\xi$ 上只改变长度不改变方向（$\lambda<0$ 时方向反向），$\xi$ 所在的直线是 $A$ 的不变子空间。

### 求法（四步）

把 $A\xi=\lambda\xi$ 移项得 $(\lambda E-A)\xi=0$，这是一个齐次线性方程组。它有非零解的充要条件是系数矩阵不满秩，即行列式为 0：

1. **写出特征多项式**：$f(\lambda)=|\lambda E-A|$，展开成 $\lambda$ 的 $n$ 次多项式。
2. **解特征方程** $|\lambda E-A|=0$，得到 $n$ 个特征值（含重数）。
3. **对每个特征值 $\lambda_i$，解齐次方程组** $(\lambda_i E-A)x=0$，求出基础解系，基础解系的非零线性组合就是属于 $\lambda_i$ 的全部特征向量。
4. （需要时）**标准化**：把每个特征向量除以自己的模长，变成单位向量。

两条检验用的性质：

$$\sum_{i=1}^{n}\lambda_i=\mathrm{tr}(A)=\sum_{i=1}^{n}a_{ii},\qquad \prod_{i=1}^{n}\lambda_i=|A|$$

算完一定要用这两条核对一遍，能省掉很多低级错误。

### 完整算例

求

$$A=\begin{pmatrix}3&2&4\\ 2&0&2\\ 4&2&3\end{pmatrix}$$

的特征值与特征向量。

**第 1 步，写特征多项式。**

$$|\lambda E-A|=\begin{vmatrix}\lambda-3&-2&-4\\ -2&\lambda&-2\\ -4&-2&\lambda-3\end{vmatrix}$$

第 1 列减第 3 列（$c_1-c_3$）先造零：

$$=\begin{vmatrix}\lambda+1&-2&-4\\ 0&\lambda&-2\\ -(\lambda+1)&-2&\lambda-3\end{vmatrix}=(\lambda+1)\begin{vmatrix}1&-2&-4\\ 0&\lambda&-2\\ -1&-2&\lambda-3\end{vmatrix}$$

第 3 行加第 1 行（$r_3+r_1$）：

$$=(\lambda+1)\begin{vmatrix}1&-2&-4\\ 0&\lambda&-2\\ 0&-4&\lambda-7\end{vmatrix}=(\lambda+1)\bigl[\lambda(\lambda-7)-8\bigr]=(\lambda+1)(\lambda^{2}-7\lambda-8)$$

$$=(\lambda+1)(\lambda-8)(\lambda+1)=(\lambda-8)(\lambda+1)^{2}$$

展开成标准形式 $\lambda^{3}-6\lambda^{2}-15\lambda-8$。

**第 2 步，解特征方程。** $(\lambda-8)(\lambda+1)^{2}=0$，得

$$\lambda_1=8\ (\text{单根}),\qquad \lambda_2=\lambda_3=-1\ (\text{二重根})$$

核对：$\sum\lambda_i=8-1-1=6=\mathrm{tr}(A)=3+0+3$，成立；$\prod\lambda_i=8\times(-1)\times(-1)=8=|A|$，成立。

**第 3 步，求特征向量。**

**$\lambda_1=8$**：解 $(8E-A)x=0$

$$8E-A=\begin{pmatrix}5&-2&-4\\ -2&8&-2\\ -4&-2&5\end{pmatrix}\xrightarrow{\text{初等行变换}}\begin{pmatrix}1&0&-1\\ 0&1&-\tfrac12\\ 0&0&0\end{pmatrix}$$

（做法：$r_1+r_3$ 得 $(1,-4,1)$；用它把另外两行消掉即可。）得到 $x_1=x_3,\ x_2=\frac12 x_3$。取 $x_3=2$：

$$\xi_1=\begin{pmatrix}2\\1\\2\end{pmatrix}$$

验算：$A\xi_1=(3\cdot2+2\cdot1+4\cdot2,\ 2\cdot2+0+2\cdot2,\ 4\cdot2+2\cdot1+3\cdot2)^{T}=(16,8,16)^{T}=8\xi_1$，成立

属于 $\lambda_1=8$ 的全部特征向量是 $k\xi_1\ (k\neq 0)$。标准化后 $\frac{1}{3}(2,1,2)^{T}$（因为 $\|\xi_1\|=\sqrt{4+1+4}=3$）。

**$\lambda_2=\lambda_3=-1$**：解 $(-E-A)x=0$

$$-E-A=\begin{pmatrix}-4&-2&-4\\ -2&-1&-2\\ -4&-2&-4\end{pmatrix}\xrightarrow{\text{初等行变换}}\begin{pmatrix}2&1&2\\ 0&0&0\\ 0&0&0\end{pmatrix}$$

秩为 1，基础解系有 $3-1=2$ 个向量。方程是 $2x_1+x_2+2x_3=0$，取自由变量 $(x_1,x_3)=(1,0)$ 和 $(0,1)$：

$$\xi_2=\begin{pmatrix}1\\-2\\0\end{pmatrix},\qquad \xi_3=\begin{pmatrix}0\\-2\\1\end{pmatrix}$$

验算：$A\xi_2=(3-4+0,\ 2+0+0,\ 4-4+0)^{T}=(-1,2,0)^{T}=-\xi_2$，成立；$A\xi_3=(0-4+4,\ 0+0+2,\ 0-4+3)^{T}=(0,2,-1)^{T}=-\xi_3$，成立

属于 $\lambda=-1$ 的全部特征向量是 $k_2\xi_2+k_3\xi_3$（$k_2,k_3$ 不同时为零）。

**小结**：这个例子里二重特征值配了 2 个线性无关的特征向量，所以 $A$ 可对角化。$A$ 是实对称矩阵，实对称矩阵必可对角化，而且属于不同特征值的特征向量必定正交，这里 $\xi_1\cdot\xi_2=2-2+0=0$、$\xi_1\cdot\xi_3=0-2+2=0$ 都验证了这一点。PCA 里的协方差矩阵就是实对称的，所以主成分方向天然互相垂直。

**Python 核对**：

```python
import numpy as np
A = np.array([[3, 2, 4], [2, 0, 2], [4, 2, 3]], float)
print(np.poly(A))          # [1. -6. -15. -8.]  即 λ³-6λ²-15λ-8
print(np.linalg.eigvals(A))  # [-1.  8. -1.]
```

### 考试里常见的 2 阶算例（PCA 用）

PCA 手算题里出现的协方差矩阵通常是 2 阶的，例如

$$C=\begin{pmatrix}\tfrac{6}{5}&\tfrac{4}{5}\\[1mm] \tfrac{4}{5}&\tfrac{6}{5}\end{pmatrix}$$

$$|C-\lambda I|=\begin{vmatrix}\tfrac65-\lambda&\tfrac45\\[1mm] \tfrac45&\tfrac65-\lambda\end{vmatrix}=\left(\frac65-\lambda\right)^{2}-\frac{16}{25}=(\lambda-2)\left(\lambda-\frac25\right)=0$$

得 $\lambda_1=2,\ \lambda_2=\frac25$。代回解齐次方程组：$\lambda=2$ 时 $-\frac45x_1+\frac45x_2=0$，即 $x_1=x_2$，取 $\xi_1=(1,1)^{T}$；$\lambda=\frac25$ 时 $\frac45x_1+\frac45x_2=0$，即 $x_1=-x_2$，取 $\xi_2=(-1,1)^{T}$。标准化后

$$\frac{1}{\sqrt2}\begin{pmatrix}1\\1\end{pmatrix},\qquad \frac{1}{\sqrt2}\begin{pmatrix}-1\\1\end{pmatrix}$$

两个特征向量正交，$\lambda_1=2>\lambda_2=0.4$，所以降到一维时取 $\frac{1}{\sqrt2}(1,1)$ 这个方向。完整的 PCA 算例见 `08 数据降维.md`。

注意这里用的是 $|C-\lambda I|=0$，和上面的 $|\lambda E-A|=0$ 只差一个整体符号 $(-1)^{n}$，解出来的 $\lambda$ 完全一样，两种写法都行。
