## 建议学习顺序

1. 先读 `01`，把 Flynn 分类、并行性等级、三个基本思想（时间重叠、资源重复、资源共享）这些名词过一遍，后面所有章节都要用。
2. 编程部分按 `02`（OpenMP）、`03`（MPI）、`04`（GPU）的顺序，配合上机作业写代码。原笔记里 OpenMP 和 MPI 的例子最多，建议边读边在本地跑。
3. `05`、`06` 是系统与平台部分，概念多、计算少，适合零散时间背。
4. `07`、`08`、`09` 是第 7 章体系结构，篇幅最大。Cache 一致性的状态转换表和三个加速比定律是考试重点。
5. `10`、`11` 是理论部分，PRAM/BSP/LogP 的参数含义和 PCAM 四步要能画图说明。
6. `12` 单独读，和考试关系不大，是论文阅读作业用的。

## 考试信息

原笔记里没有写考试时间、题型和分值，只在每章开头列了「考点」提问清单，问法基本是「简述…」「画图介绍…」「对比…」，可以推测简答题和画图题占比较大。笔记首页标了三个编程重点：OpenMP、MapReduce、OpenMPI。各章的考点原文都保留在对应整理稿的末尾。
