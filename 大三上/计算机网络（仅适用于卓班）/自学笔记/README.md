# 计算机网络 自学指南

这套笔记整理自 `笔记/计算机网络.pdf`（275 页，一份按章节写完整的课堂笔记，涵盖第一章到第十章）。原文按教材章节推进，这里改成按体系结构分层组织，从物理层一路往上到应用层，便于对照分层模型复习。

## 怎么用

第一遍按编号顺序读，`01` 先把分层模型和各层职责这条主线立起来，后面每一层再往里填。第二遍直接翻 `14 计算题精练.md` 和 `15 易混概念与考前速查.md`，这两份是刷题和考前突击用的。

原笔记里的图（时序图、拓扑图、帧格式图、Dijkstra 推演图）没法搬进 Markdown，对应位置写了"见原文第 X 页"，需要看图时翻 PDF。
