## 分层速查

| 层 | 数据单位 | 主要职责 | 典型设备 | 典型协议 |
| --- | --- | --- | --- | --- |
| 物理层 | 比特 Bit | 在介质上传比特流，定义机械/电气/功能/规程四特性 | 中继器、集线器 | EIA-232、X.21 |
| 数据链路层 | 帧 Frame | 相邻节点间可靠传输、差错控制、流量控制、链路管理 | 网桥、二层交换机、网卡 | HDLC、PPP、以太网 MAC、802.11 |
| 网络层 | 分组 Packet | 逻辑寻址、路由选择、拥塞控制、网际互连 | 路由器、三层交换机 | IP、ICMP、IGMP、ARP、RIP、OSPF、BGP |
| 传输层 | 报文 Message / 段 Segment | 端到端可靠传输、复用与分用、端到端流量与拥塞控制 | 无专用设备 | TCP、UDP |
| 会话层 | | 建立、管理、终止会话 | | |
| 表示层 | | 数据表示、加密、压缩、翻译 | | |
| 应用层 | | 为应用进程提供网络服务 | 网关 | DNS、SMTP、POP3、IMAP、FTP、HTTP |

TCP/IP 是四层（网络接口层、网络层、传输层、应用层），运行 TCP/IP 的网络通常按五层讲（把网络接口层拆成物理层和数据链路层）。应用层等同于 OSI 会话层、表示层、应用层三层之和。

## 易混概念对照

### 协议与服务

| | 协议 | 服务 |
| --- | --- | --- |
| 方向 | 水平的，对等层之间 | 垂直的，下层向上层提供 |
| 内容 | 通信规则：语法、语义、时序 | 通过服务原语调用的功能 |
| 可见性 | 对等实体之间约定 | 上层只看到服务，不关心实现 |

记这句就够：协议是水平的，服务是垂直的。

### 工作方式与服务（网络层）

"方式"说的是通信子网内部怎么传数据（网络层面向传输层），"服务"说的是子网向端系统提供什么。以虚电路方式工作的网络一般提供虚电路服务；以数据报方式工作的网络也可以提供虚电路服务，靠边缘节点做排序和重发把不可靠的内部变成对上可靠。TCP/IP 就是典型：IP 无连接，TCP 面向连接。

### 虚电路与数据报

| | 虚电路 | 数据报 |
| --- | --- | --- |
| 建立连接 | 传数据前先建，用完拆 | 不建 |
| 路由 | 只在建立时选一次 | 每个分组都选一次 |
| 顺序 | 按序到达 | 可能乱序，由传输层重排 |
| 分组携带的地址 | 只带虚电路号，开销小 | 每个分组带完整源和目的地址 |
| 故障 | 路径中断则整条虚电路失效 | 可以换路走 |
| 编号 | 虚电路号是局部的，每段链路可以不同 | |

### 拼接分割与分段合段

| | 拼接 Concatenation / 分割 Separation | 分段 Segmenting / 合段 Reassembling |
| --- | --- | --- |
| 触发条件 | 上层 PDU 太小 | 上层 SDU 太大 |

| 目的 | 减少头部开销 | 适应下层传输能力 |

### 冲突域与广播域

| | 冲突域 | 广播域 |
| --- | --- | --- |
| 所属层 | 物理层 | 数据链路层 |
| 定义 | 竞争同一物理信道的节点集合 | 能收到同一条链路层广播的节点集合 |
| 中继器、集线器 | 不分割，连出来还是一个 | 不分割 |
| 网桥、二层交换机 | 每个端口一个冲突域 | 不分割 |
| 路由器 | 分割 | 分割 |

### IP 地址与 MAC 地址

MAC 地址是数据链路层的设备 ID，六字节，前三字节是 IEEE 分配的厂商编号，后三字节是产品序列号。IP 地址是网络层逻辑地址，标识信源和信宿。传输过程中 IP 地址保持不变，每经过一个路由器 MAC 地址换一次。

### DNS 与 ARP

| | DNS | ARP |
| --- | --- | --- |
| 解析方向 | 域名 ↔ IP 地址 | IP 地址 → MAC 地址 |
| 跨越的层 | 应用层到网络层 | 网络层到数据链路层 |
| 作用范围 | 全球，单一分布式系统 | 一个局域网内 |
| 承载 | UDP 53 端口 | 以广播帧直接发 |

### CSMA/CD 与 CSMA/CA

| | CSMA/CD（以太网） | CSMA/CA（802.11） |
| --- | --- | --- |
| 思路 | 边听边说，发现冲突就停 | 先等再发，尽量不撞 |
| 信道空闲时 | 立即发（1-坚持） | 还要再等一个 IFS |
| 冲突检测 | 可以，发收信号比对 | 做不到，收发功率差太大，且发时关接收 |
| 确认 | 靠上层 | 停等机制，每帧都要 ACK，超时重传 |
| 特殊问题 | | 隐藏终端、暴露终端 |
| 可选机制 | | RTS/CTS 预约信道，靠 NAV 做虚拟载波侦听 |

### 隐藏终端与暴露终端

隐藏终端：有冲突但双方都没发现。A 向 B 发数据时 C 也要向 B 发，A 和 C 互相听不见，都以为信道空闲，结果在 B 处撞了。对 A 来说 C 是隐藏站点。

暴露终端：没冲突却白白不敢发。B 向 A 发数据时 C 想向 D 发，C 听见了 B，误以为信道忙，其实 C 发的信号影响不到 A，B 发的也影响不到 D。

一句话区分：隐藏终端听不见该听见的，暴露终端听见了不该在意的。

### 距离向量与链路状态

| | 距离向量 | 链路状态 |
| --- | --- | --- |
| 算法基础 | Bellman-Ford | Dijkstra（SPF） |
| 发什么 | 整张路由表 | 只发自己直连链路的状态（LSP） |
| 发给谁 | 只发给邻居 | 泛洪给全网所有路由器 |
| 频率 | 周期性，约 30 秒 | 非周期，有变化才发，约 30 分钟刷新一次 |
| 全网视图 | 不一致，靠迭代逼近 | 一致 |
| 收敛 | 慢，会有环路和计数到无穷 | 快，不易成环 |
| 边权 | 可以为负 | 必须非负 |
| 典型协议 | RIP | OSPF、IS-IS |

BGP 是路径向量协议，用增量的、触发式的更新，通告的是到目的地要经过的一串 AS 号。

### VLSM 与 CIDR

VLSM 把一个网划成几个连续的、大小不等的子网，解决内部地址浪费；CIDR 把几个连续的网络前缀合并成一条对外通告，解决路由表膨胀。方向正好相反。两者都依赖最长前缀匹配来保证转发选中最精确的那条。

### TCP 与 UDP

| | TCP | UDP |
| --- | --- | --- |
| 连接 | 面向连接，三次握手四次挥手 | 无连接 |
| 可靠性 | 确认重传、按序交付 | 不保证 |
| 首部 | 20 字节起，可带选项 | 固定 8 字节 |
| 流量控制 | 滑动窗口，窗口大小可变 | 无 |
| 拥塞控制 | 慢启动、拥塞避免、快重传、快恢复 | 无 |
| 广播多播 | 不支持 | 支持 |
| 校验和 | 覆盖首部、数据和 12 字节伪首部 | 同样覆盖伪首部 |

### POP3 与 IMAP

POP3 是脱机协议，邮件下载到本地、服务器上通常删掉，适合单设备、网络不稳的场景。IMAP 是联机协议，邮件留在服务器上由用户远程管理，适合多设备同步，但要一直连着网。

### 比特率与波特率

比特率是每秒传的比特数，单位 bps；波特率是每秒传的码元数，单位 Baud。关系式 $S = B\log_2 N$， $N$ 是一个码元能取的状态数。二进制调制时两者相等；QPSK 比特率是波特率的 2 倍；曼彻斯特编码一个比特占两个信号单元，波特率反而是比特率的 2 倍。谁大谁小取决于一个码元对几个比特。

### 报文交换与分组交换

两者都靠存储转发，区别只在转发的单位。报文交换整份报文在每个节点收完才转发，时延随报文长度和跳数线性放大，出错要整份重传。分组交换切成小块，流水线起来后总时延接近"分组数 + 跳数 − 1"个分组时间，出错只重传那一个分组。具体算例见 `14 计算题精练.md` 题 14。

## 课后讨论

### TCP/IP 是四层还是五层

TCP/IP 协议本身定义四层：网络接口层、网络层、传输层、应用层。五层模型把网络接口层进一步拆成物理层和数据链路层，更接近 OSI，教学和理论分析里更常见。四层的好处是概念简化，上手快；五层的好处是层次划分更细，便于对上不同功能和协议。考试答"TCP/IP 协议本身是 4 层，运行 TCP/IP 的网络大多按 5 层讲"最稳。

### 什么是接入网

接入网是用户端到服务提供商网络接入点之间的那一段，技术上包括 DSL、电缆调制解调器、光纤、卫星、WLAN 和移动网络。它是用户和互联网之间的最后一英里，直接决定用户能拿到多少带宽。原文标了【新教材】。

## 补充知识：信息论

这一段在原文最后，用来回答"如何量化信息"。

**信息量 = 被消除的不确定性。**

自信息量应当满足三条：

1. $I(x_i)$ 是 $p(x_i)$ 的严格递减函数。 $p(x_1) < p(x_2)$ 时 $I(x_1) > I(x_2)$，概率越小的事件发生后带来的信息量越大。
2. 极限情况： $p(x_i) \to 0$ 时 $I(x_i) \to \infty$； $p(x_i) = 1$ 时 $I(x_i) = 0$。
3. 可加性：两个相互独立的消息提供的信息量等于各自信息量之和。

满足这三条公理化条件的函数形式只能是对数。于是**自信息量**定义为事件发生概率的对数的负值：

$$I(x_i) = -\log_2 p(x_i)$$

把随机变量 $X$ 每个取值的自信息做统计平均，就得到**平均自信息量**，也叫信息熵、信源熵，用来表征整个信源的不确定度：

$$H(X) = E[I(x_i)] = -\sum_i p(x_i)\log_2 p(x_i)$$

这个式子和香农定理里的 $\log_2(1+S/N)$ 是同一套理论的两端：熵度量信源能产生多少信息，香农容量度量信道最多能搬走多少信息。
