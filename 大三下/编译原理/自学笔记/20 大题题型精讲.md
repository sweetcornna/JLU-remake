## 1. 写正则表达式

做法：先想清楚串的"骨架"（开头、结尾、必须出现的片段），骨架以外的部分用 `(a|b|c)*` 之类填充，最后检查边界情况（空串、只有一个字符的串）有没有漏。

| 语言 | 正则表达式 | 容易漏的地方 |
| --- | --- | --- |
| Σ={a,b,c}，以 a 开头且以 a 结尾 | `a(a\|b\|c)*a \| a` | 单个 `a` 也满足条件，要单独或上 |
| Σ={a,b,c}，至少三个字母，倒数第三个是 a | `(a\|b\|c)*a(a\|b\|c)(a\|b\|c)` | 最后两位是任意字母 |
| Σ={0,1}，含偶数个 1 | `(0\|10*1)*` | 两个 1 之间可以夹任意个 0 |
| Σ={0,1}，不含连续两个 1 | `(0\|10)* \| (0\|10)*1` | 串可以以单个 1 结尾 |
| Σ={0,1}，恰好含两个 1 | `0*10*10*` | |

## 2. 写出语言的文法

做法：看语言里哪些部分个数相等。相等的两部分用"两边同时长"的递归产生式，比如 `S → aSb`；各部分独立的，先用 `S → AB` 拆开再分别写。

```text
(1) L1 = { a bⁿ a | n ≥ 0 }
    S → aBa
    B → bB | ε

(2) L2 = { aⁿ bⁿ | n ≥ 1 }
    S → aSb | ab

(3) L3 = { aⁿ bⁿ cⁱ | n ≥ 1, i ≥ 0 }
    S → Sc | B
    B → aBb | ab

(4) L4 = { aⁱ bʲ | j ≥ i ≥ 1 }
    S → aSb | Sb | ab

(5) L5 = { a²ⁿ b³ⁿ | n ≥ 0 }
    S → aaSbbb | ε

(6) L6 = { aⁿ bⁿ aᵐ bᵐ | n, m ≥ 0 }
    S → AA
    A → aAb | ε

(7) L7 = { 1ⁿ 0ᵐ 1ᵐ 0ⁿ | n, m ≥ 0 }
    S → 1S0 | B
    B → 0B1 | ε

(8) L8 = { β a βʳ | β ∈ {0,a}*，βʳ 是 β 的逆序，例如 β = 00aa0 时 βʳ = 0aa00 }
    S → 0S0 | aSa | a
```

原稿把第 4 小题也编成了 (3)，这里按顺序改为 (4)。

几点说明：

- (3) 里 c 的个数和前面无关，所以先用 `S → Sc` 在右边长出任意个 c，再交给 B 生成等量的 a、b。
- (4) 里 b 可以比 a 多，`S → Sb` 负责多出来的 b。
- (6) 两段互不相关，结构相同，所以两段共用一个 A。
- (7) 外层 1 和 0 配对，内层 0 和 1 配对，从外往里写。
- (8) 是以中间的 a 为中心的回文，两边同时长出相同的符号。

## 3. 语法树

语法树的所有叶结点从左到右连起来就是一个句型。原稿的例子：

```text
G[E]:  E → E+E | E*E | (E) | i
句型 i*i+i 的一棵语法树：

E
├── E
│   ├── E ── i
│   ├── *
│   └── E ── i
├── +
└── E ── i
```

这个文法是二义的，`i*i+i` 还有一棵先做加法的树（根用 `E → E*E`）。求短语、简单短语和句柄的步骤：每个非叶子结点的子树叶子串是一个短语；只有一层（子结点全是叶子）的子树得到简单短语；最左边的简单短语是句柄。例题见 `03 文法与语法树.md`。

## 4. 提取公共前缀与消除左递归

这一类题一般问"判断文法是否为 LL(1)，不是的话变换成 LL(1) 文法"。答题分三步：

1. 指出文法的问题：有公共前缀，或者有直接、间接左递归，所以不是 LL(1)。
2. 做等价变换。
3. 求变换后每个产生式的 Predict 集，检查同一非终结符的各个 Predict 集两两不相交，下结论。

### 4.1 规则

**提取公共前缀**：`A → αβ₁ | αβ₂ | … | αβₙ` 变成 `A → αA'`，`A' → β₁ | β₂ | … | βₙ`。

```text
例  A → aB | aC | aD        B → bB | bD | c        D → d
变换后
    A  → aA'                A' → B | C | D
    B  → bB' | c            B' → B | D
    D  → d
```

**左递归**：只要文法中存在 A ⇒⁺ A…，就是左递归文法。形如 `A → Aα | β` 是直接左递归；`A → Bα | β`、`B → Aγ | η` 是间接左递归（A、B 是非终结符，α、β、γ、η 是任意符号串）。

**消除直接左递归**（文法不含回路和空产生式时适用）：

```text
A → Aα | β
变成
A  → βA'
A' → αA' | ε

一般情形
A  → Aα₁ | … | Aαₘ | β₁ | … | βₙ
变成
A  → β₁A' | … | βₙA'
A' → α₁A' | … | αₘA' | ε
```

**消除间接左递归**：先代入，变成直接左递归，再按上面的规则消除，最后删掉用不到的产生式。

```text
A → Bα | β        B → Aγ | η
把 B 代入 A：  A → Aγα | ηα | β      （也可以把 A 代入 B：B → Bαγ | βγ | η）
消除直接左递归：
A  → ηαA' | βA'
A' → γαA' | ε
```

### 4.2 练习 1：公共前缀

题目：判断下面的文法能否变换为 LL(1) 文法。

```text
G[S]:  S → A | B      A → aA | a      B → bB | b
```

解答：A 和 B 的两个候选式都有公共前缀，先提取：

```text
S  → A | B
A  → aA'          A' → A | ε
B  → bB'          B' → B | ε
```

Predict 集：

| 产生式 | Predict 集 |
| --- | --- |
| S → A | First(A) = {a} |
| S → B | First(B) = {b} |
| A → aA' | First(aA') = {a} |
| A' → A | First(A) = {a} |
| A' → ε | Follow(A') = {#} |
| B → bB' | First(bB') = {b} |
| B' → B | First(B) = {b} |
| B' → ε | Follow(B') = {#} |

S、A'、B' 各自的 Predict 集两两不相交，变换后是 LL(1) 文法。（原稿把 `First(aA')` 误写成 `First(aA)`，结果不受影响。）

### 4.3 练习 2：间接左递归

题目：判断下面的文法是否为 LL(1) 文法，如果不是，请变换。

```text
G[S]:  S → Aa | b      A → SB | cd      B → ab
```

解答：

(1) S ⇒ Aa ⇒ SBa，有间接左递归，不是 LL(1) 文法。

(2) 把 A 代入 S，得到直接左递归 `S → SBa | cda | b`，再消除：

```text
S  → cdaS' | bS'
S' → BaS' | ε
B  → ab
```

(3) Predict 集：

| 产生式 | Predict 集 |
| --- | --- |
| S → cdaS' | {c} |
| S → bS' | {b} |
| S' → BaS' | First(B) = {a} |
| S' → ε | Follow(S') = {#} |
| B → ab | {a} |

同一左部的 Predict 集不相交，是 LL(1) 文法。

### 4.4 练习 3：公共前缀加左递归

题目：同上，文法为

```text
G[A]:  A → aAB | a      B → Bb | d
```

解答：

(1) A 的两个候选式有公共前缀 a，B 有直接左递归，不是 LL(1) 文法。

(2) 变换后：

```text
A  → aA'          A' → AB | ε
B  → dB'          B' → bB' | ε
```

(3) 先求 Follow：A 是开始符号，# ∈ Follow(A)；由 `A' → AB` 得 First(B) = {d} ⊆ Follow(A)；由 `A → aA'` 得 Follow(A) ⊆ Follow(A')。所以 Follow(A') = {d, #}，Follow(B') = Follow(B) = Follow(A') = {d, #}。

| 产生式 | Predict 集 |
| --- | --- |
| A → aA' | {a} |
| A' → AB | First(AB) = {a} |
| A' → ε | Follow(A') = {d, #} |
| B → dB' | {d} |
| B' → bB' | {b} |
| B' → ε | Follow(B') = {d, #} |

是 LL(1) 文法。

## 5. First、Follow、Predict 集与 LL(1) 分析表

### 5.1 求法

**First(X)**，X 是单个符号：

- X 是终结符：First(X) = {X}。
- X 是非终结符，逐个看它的产生式：
  1. 有 `X → ε`，则 ε ∈ First(X)。
  2. 有 `X → a…`（a 是终结符），则 a ∈ First(X)。
  3. 有 `X → Y₁Y₂…Yₙ`，Y₁ 到 Yᵢ₋₁ 都能推出 ε，则 First(Y₁)−{ε}、…、First(Yᵢ₋₁)−{ε} 和 First(Yᵢ) 都并入 First(X)；如果 Y₁ 到 Yₙ 全都能推出 ε，ε 也并入 First(X)。
- 反复做，直到所有集合不再变化。

**First(α)**，α = X₁X₂…Xₙ 是符号串：X₁ 到 Xᵢ₋₁ 都能推出 ε 而 Xᵢ 不能，则 First(α) = (First(X₁)−{ε}) ∪ … ∪ (First(Xᵢ₋₁)−{ε}) ∪ First(Xᵢ)；如果每个 Xᵢ 都能推出 ε，First(α) 是所有 First(Xᵢ) 的并，含 ε。

**Follow(A)**：

1. 开始符号 S 的 Follow 集先放入 #，其他非终结符的 Follow 集初始为空。
2. 对每个形如 `B → xAα` 的产生式：ε ∉ First(α) 时，把 First(α) 并入 Follow(A)；ε ∈ First(α) 时，把 (First(α)−{ε}) ∪ Follow(B) 并入 Follow(A)。α 为空串时就是把 Follow(B) 并入。
3. 重复第 2 步，直到所有 Follow 集不再变化。

（原稿课件第 2 步写作 `Follow(A) := First(α)`，按第 3 步"重复直至收敛"的意思，应该是并入，不是覆盖。）

**Predict(A → α)**：ε ∉ First(α) 时等于 First(α)；ε ∈ First(α) 时等于 (First(α)−{ε}) ∪ Follow(A)。

**LL(1) 判定**：同一非终结符的所有产生式，Predict 集两两不相交。

### 5.2 例题：表达式文法

```text
① E  → TE'        ② E' → +TE'      ③ E' → ε
④ T  → FT'        ⑤ T' → *FT'      ⑥ T' → ε
⑦ F  → id         ⑧ F  → (E)
```

| 非终结符 | First | Follow |
| --- | --- | --- |
| E | { id, ( } | { #, ) } |
| E' | { +, ε } | { #, ) } |
| T | { id, ( } | { +, #, ) } |
| T' | { *, ε } | { +, #, ) } |
| F | { id, ( } | { *, +, #, ) } |

| 产生式 | Predict 集 |
| --- | --- |
| E → TE' | { id, ( } |
| E' → +TE' | { + } |
| E' → ε | Follow(E') = { ), # } |
| T → FT' | { id, ( } |
| T' → *FT' | { * } |
| T' → ε | Follow(T') = { +, ), # } |
| F → id | { id } |
| F → (E) | { ( } |

E' 的两个 Predict 集不相交，T' 的两个、F 的两个也不相交，所以是 LL(1) 文法。

### 5.3 例题：构造 LL(1) 分析表

```text
G[D]:  D → TL      T → int | float      L → id R      R → , id R | ε
```

Predict 集：

| 产生式 | Predict 集 |
| --- | --- |
| D → TL | { int, float } |
| T → int | { int } |
| T → float | { float } |
| L → id R | { id } |
| R → , id R | { , } |
| R → ε | Follow(R) = Follow(L) = Follow(D) = { # } |

把每个产生式填到"左部所在行、Predict 集里每个符号所在列"：

| | int | float | id | , | # |
| --- | --- | --- | --- | --- | --- |
| D | D → TL | D → TL | | | |
| T | T → int | T → float | | | |
| L | | | L → id R | | |
| R | | | | R → , id R | R → ε |

空白格是出错。

## 6. 递归下降子程序

对每个非终结符写一个过程：按当前单词 token 属于哪个产生式的 Predict 集选择产生式；产生式右部遇到终结符就调用 `Match`，遇到非终结符就调用对应过程；所有 Predict 集都不匹配时报错。

```text
G[Z]:  Z → aBa      B → bB | c
```

```pascal
procedure Z();
begin
  if token = a then
  begin
    Match(a); B(); Match(a)
  end
  else error()
end;

procedure B();
begin
  if token = b then
  begin
    Match(b); B()
  end
  else if token = c then Match(c)
  else error()
end;
```

## 7. 类型、标识符的内部表示与全局符号表

这部分的截图来自课件，是填符号表题的基础。约定：int、bool、char 各占 1 个单元，real（float）占 2 个单元，指针占 1 个单元。

### 7.1 类型的内部表示

| 类型 | 内部表示 | 各域的含义 |
| --- | --- | --- |
| 标准类型 | (Size, Kind) | intPtr → (1, intTy)，boolPtr → (1, boolTy)，charPtr → (1, charTy)，realPtr → (2, realTy) |
| 数组 | (Size, Kind=ArrayTy, Low, Up, ElemType) | 下界、上界，ElemType 指向元素类型 |
| 结构体、共用体 | (Size, Kind=structTy, FieldList) | 结构体的 Size 是所有域之和，共用体的 Size 是各域中的最大值；FieldList 指向域名表表头 |
| 枚举 | (Size, Kind=enumTy, ElemList) | ElemList 指向枚举常量表，表项为 (Name, Value) |
| 指针 | (Size, Kind=pointTy, Type) | Type 指向基类型的内部表示 |

域名表的表项是 (Name, TypePtr, Off, link)：Off 是该域相对结构体起始地址的偏移，共用体里所有域偏移都是 0，可以省略；link 指向下一个域。

课件例子：

| 声明 | 内部表示 |
| --- | --- |
| `typedef int A[10];` | (10, ArrayTy, 0, 9, IntPtr) |
| `typedef char B[5][10];` | (50, ArrayTy, 0, 4, →(10, ArrayTy, 0, 9, CharPtr))，二维数组是"元素为数组的数组" |
| `typedef struct DateType {int year, month, day;} datetype;` | (3, structTy, →域名表)，域名表：year intPtr 0，month intPtr 1，day intPtr 2（也可以写成 year → month → day → null 的链表） |
| `typedef struct { int j; int r[10]; } A;` | (11, structTy, →域名表)，域名表：j intPtr 0，r →(10, ArrayTy, 0, 9, IntPtr) 1 |
| `typedef union {char ch; int i; float f;} datatype;` | (2, structTy, →域名表)，域名表：ch charPtr 0，i intPtr 0，f realPtr 0 |
| `enum color {red, yellow, blue}` | (1, enumTy, →常量表)，red 0，yellow 1，blue 2 |
| `enum color {red=10, yellow=red+2, blue}` | (1, enumTy, →常量表)，red 10，yellow 12，blue 13 |
| `typedef int* T1;` | (1, pointTy, intPtr) |
| `typedef float* T2;` | (1, pointTy, realPtr) |

### 7.2 标识符的内部表示

| 标识符 | 内部表示 |
| --- | --- |
| 常量 | (Name, Kind=constKind, TypePtr, Value) |
| 变量 | (Name, Kind=varKind, TypePtr, Access, Level, Off, Value) |
| 类型 | (Name, Kind=typeKind, TypePtr) |
| 过程/函数 | (Name, TypePtr, Kind=routKind, Level, Off, Param, Class, Code, Size, Forward) |

变量的各域：

- Access = dir 表示直接变量，indir 表示间接变量。
- Level 是变量声明所在主程序、函数或过程的层数。
- Off 是变量相对所在主程序、函数或过程内存块起始地址的偏移。
- Value 是初值的内部表示指针，没有初值时为空。

过程/函数的各域：

- TypePtr 是函数返回值类型，过程为 NULL。
- **Level** 是过程/函数的层数。
- **Off** 只对形式过程/函数（作为参数传进来的函数）有效，是它在所属过程/函数内存块中的偏移。形式过程/函数占 2 个字节，用来存入口地址。
- Param 是参数表指针。参数表的结构和符号表相同，参数信息可以填进符号表，也可以单独建表。
- Class = actual 表示实在过程/函数，formal 表示形式过程/函数。
- **Code** 只对实在过程/函数有效，是它生成的目标代码的起始地址，目标代码生成时回填；形式过程/函数的 Code 为 NULL。
- **Size** 只对实在过程/函数有效，是它的活动记录所占内存区的大小，也要在目标代码生成以后回填。
- **Forward** 只对实在过程/函数有效，true 表示超前声明，false 表示不是。

课件例子：

```c
#define pai 3.14
const int count = 100;
```

| Name | Kind | TypePtr | Value |
| --- | --- | --- | --- |
| pai | constKind | realPtr | ↑〈3.14〉 |
| count | constKind | intPtr | ↑〈100〉 |

```c
int    x = 10;
float  y;
float* z;
```

当前层为 L，当前偏移为 off：

| Name | Kind | TypePtr | Access | Level | Off | Value |
| --- | --- | --- | --- | --- | --- | --- |
| x | varKind | intPtr | dir | L | off | ↑〈10〉 |
| y | varKind | realPtr | dir | L | off+1 | null |
| z | varKind | →(1, pointTy, realPtr) | indir | L | off+3 | null |

y 是 float，占 2 个单元，所以 z 的偏移是 off+3。

```c
typedef int t1;
typedef int t2[10];
```

| Name | Kind | TypePtr |
| --- | --- | --- |
| t1 | typeKind | intPtr，即 (1, intTy) |
| t2 | typeKind | →(10, ArrayTy, 0, 9, intPtr) |

```c
int f(int x, float* y, int inc(int a))
{
    /* f 的函数体 */
}
```

f 本身（层数为 L）：

| Name | TypePtr | Kind | Level | off | Param | Class | Code | Size | Forward |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| f | intPtr | routKind | L | | →参数表 | actual | | XXX | false |

f 的参数表：

| Name | Kind | TypePtr | Access/Class | Level | Off |
| --- | --- | --- | --- | --- | --- |
| x | varKind | intPtr | dir | L+1 | off₀ |
| y | varKind | →(1, pointTy, realPtr) | indir | L+1 | off₀+1 |
| inc | routKind | intPtr | formal，Param 指向 a | L+1 | off₀+2 |
| a | varKind | intPtr | dir | | |

inc 是形式函数，有偏移（存它的入口地址）。inc 的形参 a 只用于类型检查，不分配层数和偏移，所以最后两格为空（`编译原理笔记/编译原理学习笔记.pdf` 第 193 页的批注也这样解释）。f 的 Code 和 Size 要到目标代码生成后回填，截图里分别留空和写 XXX。

### 7.3 例题：驻留法全局符号表

题目：采用驻留法实现全局线性组织的符号表，给出扫描至下述程序段带下划线语句处时符号表的内容。（注：每个函数第一个形参可用的偏移为 off0，每个标识符的属性包括名字、种类、类型、层数和偏移。）

```c
void test(int j)
{   int x;
    x = j;
    {   int x;
        x = j;
        printf("x = %d", x);   }
    printf("x = %d", x);
}
void main()
{   char i;
    i = 'A';
    {   int i = 0;
        printf("i = %d", i);   }
    printf("i = %d", i);        /* 带下划线的语句 */
}
```

解答：

| 行号 | 名字 | 种类 | 类型 | 层数 | 偏移 | 跳转指针 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | test | routKind | null | 0 | | |
| 2 | j | varKind | intPtr | 1 | off0 | |
| 3 | x | varKind | intPtr | 1 | off0+1 | |
| 4 | x | varKind | intPtr | 1 | off0+2 | |
| 5 | # | | | | | → 3 |
| 6 | # | | | | | → 1 |
| 7 | main | routKind | null | 0 | | |
| 8 | i | varKind | charPtr | 1 | off0 | |
| 9 | i | varKind | intPtr | 1 | off0+1 | |
| 10 | # | | | | | → 8 |

读表要点：

- C 语言里函数内部的复合语句不另开一层，内层的 x、i 层数仍是 1，偏移接着外层往下排。
- 每退出一个局部化区，就在表尾加一个 #，它的指针指向这个局部化区开始之前的最后一项（即 `Scope[ℓ]-1`）。第 5 行的 # 关闭 `{ int x; }`，指向第 3 行；第 6 行的 # 关闭整个 test，指向第 1 行；第 10 行的 # 关闭 `{ int i = 0; }`，指向第 8 行。
- 带下划线语句还在 main 的函数体里，main 没有结束，所以表尾没有关闭 main 的 #。
- 查表时从表尾往前找，遇到 # 就沿指针跳过已经结束的局部化区。此时查 i，从第 10 行跳到第 8 行，找到的是 char 型的 i。

## 8. 四元式中间代码

### 8.1 常用四元式

| 类别 | 四元式 | 含义 |
| --- | --- | --- |
| 算术、逻辑、关系运算 | ADDI、ADDF、SUBI、SUBF、MULTI、MULTF、DIVI、DIVF、MOD、AND、OR、EQ、NE、GT、GE、LT、LE | 后缀 I 表示整型运算，F 表示实型运算 |
| 输入输出 | (READI, —, —, id) | 整数输入 |

| | (WRITE, —, —, id) | 输出 id |
| 类型转换 | (FLOAT, id₁, —, id₂) | id₂ := float(id₁) |
| 赋值 | (ASSIG, id₁, —, id₂) | id₂ := id₁ |
| 地址加 | (AADD, id₁, id₂, id₃) | id₃ := addr(id₁) + id₂，数组元素寻址用 |
| 标号定义 | (LABEL, —, —, label) | 定义标号 label |
| 转移 | (JMP, —, —, label) | 无条件转向 label |
| | (JMP0, id, —, label) | 若 id = 0，转 label |
| | (JMP1, id, —, label) | 若 id = 1，转 label |
| 过程调用 | (ENTRY, Label, Size, Level) | 子程序入口 |
| | (CALL, f, —, Result) | 过程或函数调用 |
| 传送参数 | VARACT、VALACT、FUNACT、PROACT | 分别传变参、值参、函数参数、过程参数 |

作业和历年题里也常用简写：`:=` 代替 ASSIG，`+ - * / <` 代替 ADDI 等，`[+]` 代替 AADD，控制语句用 (THEN, t, _, _)、(ELSE, _, _, _)、(ENDIF, _, _, _)、(WHILE, _, _, _)、(DO, t, _, _)、(ENDWHILE, _, _, _)。

### 8.2 例题：表达式

题目：将 `X*2 + A*(i+1)/(j+1)` 翻译成四元式序列，其中 i 和 j 为整型变量，X 和 A 为实型变量。

思路：按运算优先级从左到右生成；整型和实型混合运算前先用 FLOAT 把整型转成实型，运算符再选 F 版本。

```text
2. (MULTF, X, t1, t2)
3. (ADDI, i, 1, t3)
4. (FLOAT, t3, _, t4)
5. (MULTF, A, t4, t5)
6. (ADDI, j, 1, t6)
7. (FLOAT, t6, _, t7)
8. (DIVF, t5, t7, t8)
9. (ADDF, t2, t8, t9)
```

## 9. 中间代码优化

原稿总结了三种优化：

- 常数省略（常表达式节省）：运算分量都是已知常数时，编译时直接算出结果。数组下标是常数时，地址偏移也能算出来。
- 重复省略（公共表达式节省）：同一基本块里重复计算的表达式只算一次。
- 循环不变式外提：循环里值不变的运算提到循环前面。

### 9.1 常表达式节省

```text
源程序         中间代码              优化后
x := 10        (ASSIG, 10, -, x)     (ASSIG, 10, -, x)
y := x+1       (ADDI, x, 1, t1)      （删除，t1 = 11）
               (ASSIG, t1, -, y)     (ASSIG, 11, -, y)
x := a         (ASSIG, a, -, x)      (ASSIG, a, -, x)
z := y+5       (ADDI, y, 5, t2)      （删除，t2 = 16）
               (ASSIG, t2, -, z)     (ASSIG, 16, -, z)
```

x := a 之后 x 不再是常数，但后面没有再用 x，所以不影响。

### 9.2 基于值编码的公共表达式节省

题目：`a := b*c + b*c;  d := b;  e := d*c + b*c;`

做法：给每个变量、每个值分配一个编号（值编码）。四元式的运算符和两个运算分量的编码相同，说明结果相同，结果变量拿到同一个编码，记入等价表，这条四元式就可以省掉。赋值语句让左部变量取右部的编码。

| 序号 | 中间代码 | 映象码 | 变量获得的编码 | 等价表 | 优化后 |
| --- | --- | --- | --- | --- | --- |
| 1 | *, b, c, t1 | *, 1, 2, 3 | b=1，c=2，t1=3 | | 不变 |
| 2 | *, b, c, t2 | *, 1, 2, 3 | t2=3 | (t1, t2) | 节省 |
| 3 | +, t1, t2, t3 | +, 3, 3, 4 | t3=4 | | +, t1, t1, t3 |
| 4 | =, t3, -, a | | a=4 | | 不变 |
| 5 | =, b, -, d | | d=1 | | 不变 |
| 6 | *, d, c, t4 | *, 1, 2, 3 | t4=3 | (t1, t4) | 节省 |
| 7 | *, b, c, t5 | *, 1, 2, 3 | t5=3 | (t1, t5) | 节省 |
| 8 | +, t4, t5, t6 | +, 3, 3, 4 | t6=4 | (t3, t6) | 节省 |
| 9 | =, t6, -, e | | | | =, t3, -, e |

第 6 行是关键：d := b 之后 d 的编码和 b 一样是 1，所以 `d*c` 和 `b*c` 被认出是同一个值。优化后只剩 5 条：

```text
(*, b, c, t1)
(+, t1, t1, t3)
(=, t3, -, a)
(=, b, -, d)
(=, t3, -, e)
```

### 9.3 循环不变式外提

如果一个表达式在循环中值不变，就是该循环的不变表达式，可以提到循环外面算。循环不变式外提属于非局部优化。

```pascal
{ 外提前 }                      { 外提后 }
i := 1;                         i := 1;
while i <= 1000 do              t := x*y;
begin                           while i <= 1000 do
    a[i] := x*y;                begin
    i := i+1                        a[i] := t;
end;                                i := i+1
                                end;
```

外提策略有两种。以下面的循环为例，E1、E2 是循环不变式：

```pascal
for i := 1 to 100 do
    if x > 0 then a[i] := E1; else b[i] := E2;
```

- 凡是循环不变式都外提：先算 `t1 := E1; t2 := E2;`，循环里改用 t1、t2。
- 只外提一定被执行的循环不变式：E1、E2 分别在 then 和 else 分支里，每轮只执行其中一个，所以都不外提，循环保持原样。

判定方法：先把循环里所有被赋值的变量放进集合 LoopDef；然后依次看循环里的每条运算型四元式，如果它的两个运算分量都不在 LoopDef 里（常数，或者循环里没有被赋值的变量），它就是循环不变式，外提到 WHILE 之前，并把它的结果变量从 LoopDef 里删掉，这样依赖它的后续四元式也能被认出来。

例题：已知 `a: array[1..10][1..1000] of integer;`，优化下面的程序段。

```pascal
j := 1;
while j <= 1000 do
begin
    a[i][j] := 0;
    j := j+1;
end;
```

```text
优化前                          优化后
(ASSIG, 1, —, j)                (ASSIG, 1, —, j)
(WHILE, —, —, —)                (SUBI, i, 1, t2)
(LE, j, 1000, t1)               (MULTI, t2, 1000, t3)
(DO, t1, —, —)                  (AADD, a, t3, t4)
(SUBI, i, 1, t2)                (WHILE, —, —, —)
(MULTI, t2, 1000, t3)           (LE, j, 1000, t1)
(AADD, a, t3, t4)               (DO, t1, —, —)
(SUBI, j, 1, t5)                (SUBI, j, 1, t5)
(MULTI, t5, 1, t6)              (MULTI, t5, 1, t6)
(AADD, t4, t6, t7)              (AADD, t4, t6, t7)
(ASSIG, 0, —, t7)               (ASSIG, 0, —, t7)
(ADDI, j, 1, t8)                (ADDI, j, 1, t8)
(ASSIG, t8, —, j)               (ASSIG, t8, —, j)
(ENDWHILE, —, —, —)             (ENDWHILE, —, —, —)
```

优化前 LoopDef = {t1, t2, t3, t4, t5, t6, t7, t8, j}。i 在循环里没有被赋值，所以 `(SUBI, i, 1, t2)` 是不变式，外提后 t2 移出 LoopDef，接着 `(MULTI, t2, 1000, t3)`、`(AADD, a, t3, t4)` 也变成不变式。`(SUBI, j, 1, t5)` 用到 j，不能外提。优化后 LoopDef = {t1, t5, t6, t7, t8, j}（更正：原文作 `LoopDef={t1, t5, t6, t7, t8}`，漏了循环里仍被赋值的 j）。

(1) 给出该程序段代码的四元式中间代码。
