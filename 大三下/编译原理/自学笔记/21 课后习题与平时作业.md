### P36-6

题意：文法 G1 为 `N → D | ND`，`D → 0 | 1 | … | 9`。(1) G1 的语言是什么？(2) 给出 0127、34、568 的最左推导和最右推导。

解答：

(1) L(G1) 是由 0～9 组成的数字串（至少一位）。

(2)

```text
最左推导
N ⇒ ND ⇒ NDD ⇒ NDDD ⇒ DDDD ⇒ 0DDD ⇒ 01DD ⇒ 012D ⇒ 0127
N ⇒ ND ⇒ DD ⇒ 3D ⇒ 34
N ⇒ ND ⇒ NDD ⇒ DDD ⇒ 5DD ⇒ 56D ⇒ 568

最右推导
N ⇒ ND ⇒ N7 ⇒ ND7 ⇒ N27 ⇒ ND27 ⇒ N127 ⇒ D127 ⇒ 0127
N ⇒ ND ⇒ N4 ⇒ D4 ⇒ 34
N ⇒ ND ⇒ N8 ⇒ ND8 ⇒ N68 ⇒ D68 ⇒ 568
```

思路：最左推导每步替换最左边的非终结符，最右推导每步替换最右边的。N → ND 是左递归，数字串从右往左长出来，所以最右推导先确定个位。

### P36-7

题意：写一个文法，描述不以 0 开头的奇数。

解答：

```text
S → O | AO
A → AD | N
N → 2 | 4 | 6 | 8 | O
D → 0 | N
O → 1 | 3 | 5 | 7 | 9
```

思路：末位 O 必须是奇数；前面的部分 A 以非零数字 N 开头，后面接任意数字 D。只有一位时直接 S → O。（整理时枚举了 3 位以内的串，恰好是 1 到 999 中的全部奇数。）

### P36-8

题意：文法 `E → T | E+T | E-T`，`T → F | T*F | T/F`，`F → (E) | i`。给出 i+i*i 和 i*(i+i) 的最左推导、最右推导，并画出 i+i+i、i-i-i、i+i*i 的语法树。

解答：

```text
最左推导
E ⇒ E+T ⇒ T+T ⇒ F+T ⇒ i+T ⇒ i+T*F ⇒ i+F*F ⇒ i+i*F ⇒ i+i*i
E ⇒ T ⇒ T*F ⇒ F*F ⇒ i*F ⇒ i*(E) ⇒ i*(E+T) ⇒ i*(T+T) ⇒ i*(F+T)
  ⇒ i*(i+T) ⇒ i*(i+F) ⇒ i*(i+i)

最右推导
E ⇒ E+T ⇒ E+T*F ⇒ E+T*i ⇒ E+F*i ⇒ E+i*i ⇒ T+i*i ⇒ F+i*i ⇒ i+i*i
E ⇒ T ⇒ T*F ⇒ T*(E) ⇒ T*(E+T) ⇒ T*(E+F) ⇒ T*(E+i) ⇒ T*(T+i)
  ⇒ T*(F+i) ⇒ T*(i+i) ⇒ F*(i+i) ⇒ i*(i+i)
```

（更正：原文 i*(i+i) 的最右推导作 `E ⇒ T ⇒ F*T ⇒ F*F ⇒ F*(E) ⇒ … ⇒ F*(i+i) ⇒ i*(i+i)`。文法里没有 T → F*T，第二步不成立；应先用 T → T*F，把右边的 F 展开完，最后才把 T 换成 F、i。）

语法树：

```text
i+i+i                      i-i-i                      i+i*i
E                          E                          E
├── E                      ├── E                      ├── E ── T ── F ── i
│   ├── E ── T ── F ── i   │   ├── E ── T ── F ── i   ├── +
│   ├── +                  │   ├── -                  └── T
│   └── T ── F ── i        │   └── T ── F ── i            ├── T ── F ── i
├── +                      ├── -                          ├── *
└── T ── F ── i            └── T ── F ── i                └── F ── i
```

（更正：原稿第二、三棵树下面的标注写反了，画成乘法的那棵标成了 i-i-i，画成两个减号的那棵标成了 i+i*i。）

树的形状说明了两件事：E → E+T 是左递归，同级的 + 和 - 左结合，先算左边；乘法在更深一层的 T 里，优先级比加法高。

## 3 自顶向下分析（P81）

对应 `04 语法分析方法（LL1、递归下降、LR）.md`。

### P81-1

题意：文法 `S → a | ^ | (T)`，`T → T,S | S`。(1) 消除左递归，写出递归下降子程序；(2) 求 FIRST、FOLLOW 集，构造预测分析表，判断是否 LL(1) 文法。

解答：

(1) 按 T、S 的顺序消除左递归：

```text
S  → a | ^ | (T)
T  → ST'
T' → ,ST' | ε
```

递归子程序（sym 是当前输入符号，advance 读下一个符号，error 是出错处理）：

```pascal
procedure S;
begin
  if (sym = 'a') or (sym = '^') then advance
  else if sym = '(' then
  begin
    advance; T;
    if sym = ')' then advance
    else error
  end
  else error
end;

procedure T;
begin
  S; T'
end;

procedure T';
begin
  if sym = ',' then
  begin
    advance; S; T'
  end
end;
```

T' 可以推出 ε，所以当前符号不是逗号时什么也不做，直接返回。

(2)

| 非终结符 | FIRST | FOLLOW |
| --- | --- | --- |
| S | { a, ^, ( } | { ), `,`, # } |
| T | { a, ^, ( } | { ) } |
| T' | { `,`, ε } | { ) } |

预测分析表：

| | a | ^ | ( | ) | , | # |
| --- | --- | --- | --- | --- | --- | --- |
| S | S → a | S → ^ | S → (T) | | | |
| T | T → ST' | T → ST' | T → ST' | | | |
| T' | | | | T' → ε | T' → ,ST' | |

表中没有一格填两个产生式，是 LL(1) 文法。

### P81-2

题意：文法 `E → E+T | T`，`T → TF | F`，`F → F* | P`，`P → (E) | a | b | ^`。(1) 消除左递归后求各非终结符的 FIRST、FOLLOW；(2) 证明改写后的文法是 LL(1) 的；(3) 构造预测分析表；(4) 写递归下降子程序。

改写后的文法：

```text
E  → TE'          E' → +E | ε
T  → FT'          T' → T | ε
F  → PF'          F' → *F' | ε
P  → (E) | a | b | ^
```

(1)

| 非终结符 | FIRST | FOLLOW |
| --- | --- | --- |
| E | { (, a, b, ^ } | { #, ) } |
| E' | { +, ε } | { #, ) } |
| T | { (, a, b, ^ } | { +, ), # } |
| T' | { (, a, b, ^, ε } | { +, ), # } |
| F | { (, a, b, ^ } | { (, a, b, ^, +, ), # } |
| F' | { *, ε } | { (, a, b, ^, +, ), # } |
| P | { (, a, b, ^ } | { *, (, a, b, ^, +, ), # } |

(2) 文法没有左递归。有多个候选式的是 E'、T'、F'、P，逐个检查：

- E'：FIRST(+E) ∩ FIRST(ε) = ∅；E' 能推出 ε，FIRST(+E) ∩ FOLLOW(E') = {+} ∩ {#, )} = ∅。
- T'：FIRST(T) ∩ FIRST(ε) = ∅；FIRST(T) ∩ FOLLOW(T') = {(, a, b, ^} ∩ {+, ), #} = ∅。
- F'：FIRST(*F') ∩ FIRST(ε) = ∅；FIRST(*F') ∩ FOLLOW(F') = {*} ∩ {(, a, b, ^, +, ), #} = ∅。
- P：四个候选式的 FIRST 集 {(}、{a}、{b}、{^} 两两不相交。

所以改写后的文法是 LL(1) 文法。

(3) 预测分析表：

| | + | * | ( | ) | a | b | ^ | # |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| E | | | E → TE' | | E → TE' | E → TE' | E → TE' | |
| E' | E' → +E | | | E' → ε | | | | E' → ε |
| T | | | T → FT' | | T → FT' | T → FT' | T → FT' | |
| T' | T' → ε | | T' → T | T' → ε | T' → T | T' → T | T' → T | T' → ε |
| F | | | F → PF' | | F → PF' | F → PF' | F → PF' | |
| F' | F' → ε | F' → *F' | F' → ε | F' → ε | F' → ε | F' → ε | F' → ε | F' → ε |
| P | | | P → (E) | | P → a | P → b | P → ^ | |

(4)

```pascal
procedure E;
begin
  if sym in ['(', 'a', 'b', '^'] then begin T; E' end
  else error
end;

procedure E';
begin
  if sym = '+' then begin advance; E end
  else if (sym <> ')') and (sym <> '#') then error
end;

procedure T;
begin
  if sym in ['(', 'a', 'b', '^'] then begin F; T' end
  else error
end;

procedure T';
begin
  if sym in ['(', 'a', 'b', '^'] then T
  else if sym = '*' then error
end;

procedure F;
begin
  if sym in ['(', 'a', 'b', '^'] then begin P; F' end
  else error
end;

procedure F';
begin
  if sym = '*' then begin advance; F' end
end;

procedure P;
begin
  if sym in ['a', 'b', '^'] then advance
  else if sym = '(' then
  begin
    advance; E;
    if sym = ')' then advance
    else error
  end
  else error
end;
```

原稿把条件写成 `sym='(' or sym='a' or …`，这里合并成集合写法，意思相同。

### P81-3

题意：判断四个文法是否 LL(1) 文法。原稿没抄题，四个结论与 `10 选择题精编.md` 第 4-11 题的四个文法逐一吻合：

```text
(1) S → ABc      A → a | ε      B → b | ε
(2) S → Ab       A → a | B | ε  B → b | ε
(3) S → ABBA     A → a | ε      B → b | ε
(4) S → aSe | B  B → bBe | C    C → cCe | d
```

原稿按"LL(1) 文法的三个条件"判断（无左递归；同一非终结符各候选式的 FIRST 集两两不相交；某候选式能推出 ε 时，该非终结符的 FIRST 集与 FOLLOW 集不相交）：

(1) 是，满足三个条件。

(2) 不是，A 不满足条件 3。（整理补充：B 也不满足。FOLLOW(A) = FOLLOW(B) = {b}，FIRST(A) 和 FIRST(B) 都含 b。另外 A → B 与 A → ε 都能推出 ε，A 连条件 2 也不满足。）

(3) 不是，A、B 均不满足条件 3。FOLLOW(A) = FOLLOW(B) = {a, b, #}。

(4) 是，满足三个条件。

## 4 自底向上分析（P133、P134）

### P133-1

题意：文法 `E → E+T | T`，`T → T*F | F`，`F → (E) | i`，求句型 E+T*F 的短语、直接短语和句柄。

解答：

```text
E ⇒ E+T ⇒ E+T*F
```

- 短语：E+T*F，T*F
- 直接短语：T*F
- 句柄：T*F

思路：语法树根 E 下是 E、+、T，T 下是 T、*、F。以 E 为根的子树叶子串是 E+T*F，以第二层 T 为根的子树叶子串是 T*F，它只有一层，是直接短语；最左的直接短语是句柄。

解答：

```text

101. (j, -, -, 0)         外层循环的假出口，待回填
102. (j<, B, D, 104)
103. (j, -, -, 101)       假出口，与 101 串成链
```

### P219-12

题意：为 Pascal 的 for 语句 `for I := E1 to E2 do S` 设计翻译方案。

(1) 原稿只列出了以下几行，没有文字说明：

```text
MAXINT-5
MAXINT-4
MAXINT-3
MAXINT-2
MAXINT-1
MAXINT
```

整理注：从这组数看，这一小题讨论的是循环变量的终值接近 MAXINT 时，如果每轮先加 1 再判断是否超过终值，最后一次 I := I+1 会溢出。方法 2 在比较相等之后才做加 1，可以避开这个问题。这是整理时的理解，原稿没有写出来。

(2) 翻译模式，方法 1：

```text
S → F do M S1
F → for I := E1 to E2
I → id
M → ε

S → F do M S1   { backpatch(S1.nextlist, nextquad);
                  backpatch(F.truelist, M.quad);
                  emit(F.place ':=' F.place '+' 1);
                  emit('j≤,' F.place ',' F.end ',' M.quad);
                  S.nextlist := F.falselist }

F → for I := E1 to E2
                { F.falselist := makelist(nextquad);
                  emit('j>,' E1.place ',' E2.place ',0');
                  emit(I.place ':=' E1.place);
                  F.truelist := makelist(nextquad);
                  emit('j,-,-,-');
                  F.place := I.place;
                  F.end := E2.place }

I → id          { p := lookup(id.name);
                  if p <> nil then I.place := p
                  else error }

M → ε           { M.quad := nextquad }
```

方法 2：

```text
S → F S1
F → for id := E1 to E2 do

F → for id := E1 to E2 do
      { INITIAL := NEWTEMP;
        emit(':=,' E1.PLACE ', -,' INITIAL);
        FINAL := NEWTEMP;
        emit(':=,' E2.PLACE ', -,' FINAL);
        p := nextquad + 2;
        emit('j≤,' INITIAL ',' FINAL ',' p);
        F.nextlist := makelist(nextquad);
        emit('j, -, -, -');
        F.place := lookup(id.name);
        if F.place <> nil then
          emit(F.place ':=' INITIAL);
        F.quad := nextquad;
        F.final := FINAL }

S → F S1
      { backpatch(S1.nextlist, nextquad);
        p := nextquad + 2;
        emit('j<,' F.place ',' F.final ',' p);
        S.nextlist := merge(F.nextlist, makelist(nextquad));
        emit('j, -, -, -');
        emit('succ,' F.place ', -,' F.place);
        emit('j, -, -,' F.quad) }
```

原稿方法 2 里两处 `emit('j ,' …)` 的比较运算符没有印出来，按语义补成 `j≤`（初值不大于终值才进入循环）和 `j<`（未到终值才加 1 继续）；`if F.place nil then` 中间的运算符也缺了，补成 `<>`。`succ` 表示取后继（加 1）。这几个运算符都是整理时推断的。

### P270-9

题意：从答案看，程序为

```pascal
procedure P(x, y, z);
begin
  y := y + 1;
  z := z + x
end;

begin
  A := 2; B := 3;
  P(A+B, A, A);
  print A
end.
```

分别按传名、传地址、得结果、传值四种方式，程序打印的 A 是多少？

解答：

| 方式 | 做法 | 打印的 A |
| --- | --- | --- |
| 传名 | 调用处相当于把过程体抄过来，形参全部换成实参 | 9 |
| 传地址 | 形参单元存实参地址，对形参的访问都是间接访问 | 8 |
| 得结果 | 每个形参两个单元，一个存地址一个存值；过程里只改值，返回前按地址写回 | 7 |
| 传值 | 形参单元存实参的值，过程里的修改不影响实参 | 2 |

各方式的执行过程：

```text
传名
A := 2; B := 3;
A := A + 1;           // y := y + 1，y 换成 A，A = 3
A := A + (A + B);     // z := z + x，z 换成 A，x 换成 A+B，A = 3 + 6 = 9
print A               // 9

传地址
A := 2; B := 3; T := A + B;          // 表达式实参先算到临时单元 T
把 T、A、A 的地址抄进 J1、J2、J3
x := J1; y := J2; z := J3            // J2 = J3，都是 A 的地址
y↑ := y↑ + 1                         // A = 3
z↑ := z↑ + x↑                        // A = 3 + 5 = 8
print A                              // 8

得结果
A := 2; B := 3; T := A + B;
x1 := J1; x2 := T;                   // 第一个单元存地址，第二个单元存值
y1 := J2; y2 := A;
z1 := J3; z2 := A;
y2 := y2 + 1;  z2 := z2 + x2;        // y2 = 3，z2 = 2 + 5 = 7
x1↑ := x2; y1↑ := y2; z1↑ := z2      // 按顺序写回，A 先得 3，再被 z 写成 7
print A                              // 7

传值
A := 2; B := 3;
x := A + B; y := A; z := A;
y := y + 1; z := z + x;
print A                              // 2，过程调用不改变 A
```
