## 2012级

来源：`编译原理期末资料/吉林大学编译原理期末试题解答.pdf` 第 30–33 页为试题，第 34–36 页为解答。原卷没有标分值。

### 一、选择题

1. 有文法 G：

   ```text
   E → E*T | T
   T → T+i | i
   ```

   若 `1+2*8+6` 按该文法归约，则其值为（ ）。（原卷第二条产生式印作 `T→T+I | i`，I 应为 i。）

   A. 23　B. 42　C. 30　D. 17

2. 若符号表保留至目标代码生成阶段，则表达式 x+y 的中间代码 `(+, x, y, t1)` 和部分目标代码 `(ADD R, x)` 中的 x 分别代表什么含义（ ）。

   ①变量 x　②x 在符号表中的位置　③x 的值　④x 在内存中的相对地址

   A. ①②　B. ①③　C. ②③　D. ②④

3. 对于 LL(1) 和 LR(1) 分析法，输入流中的非终极符（ ）符号栈或分析栈。

   A. 都移入　B. 都不移入　C. 前者移入，后者不移入　D. 前者不移入，后者移入

4. 有语言 $L=\{a^nb^n \mid n>0\}$，则下列关于 L 的描述正确的是（ ）。

   - A. 识别 L 的正则表达式可以是 `aa*bb*`
   - B. 识别 L 的 DFA 可以是下面这个自动机（原卷为图，转写成转换表）：

     | 状态 | a | b |
     |---|---|---|
     | →A（初态） | B | |
     | B | B | C |
     | C（终态） | | C |

   - C. 识别 L 的正则文法可以是 `A→aB`，`B→aB | bC | b`，`C→bC | b`
   - D. 识别 L 的 2 型文法可以是 `S→aSb | ab`

5. 下列关于过程活动记录的相关描述错误的是（ ）。

   - A. 运行时过程活动记录的管理工作是由编译器生成的目标代码运行时完成的
   - B. 若目标代码确定，则目标代码生成阶段可以精确计算出每个过程活动记录的大小
   - C. 同一个函数被多次调用时所生成的所有过程活动记录的大小一定是相同的
   - D. 存在间接递归时，递归调用的函数的多个过程活动记录可能不止一个是活跃的

解答：1～5 BDDDD。

- 第 1 题：T 在 E 的下一层，所以 + 比 \* 先归约，两者都左结合，`1+2*8+6` 按 `(1+2)*(8+6)` 计算，得 42。
- 第 2 题：中间代码里的 x 是它在符号表中的位置（指针），目标代码里的 x 已经换成内存中的相对地址。
- 第 3 题：LL(1) 的输入流里只有终极符；LR 分析归约出的非终极符相当于回到输入流头部，再按 goto 表移入分析栈。
- 第 4 题：A、B、C 描述的都是 $a^mb^n$（m、n 独立），只有 D 保证 a、b 个数相等。
- 第 5 题：不论调用顺序如何，同一个函数的多个活动记录里只有最新那个是活跃的，所以 D 错（学习通章节测试同题的解析也是这样说的）。

#### 2. 静态链

设有如下含有嵌套定义的类 C 程序：

```c
int P(){
    int y, z, x;
    int Q(){ int y; Q的函数体; }
    int R(){ int x; int y; x = x + y + z; }
    P的函数体;
}
void main(){ 主函数体; }
```

若有调用链 (main, P, Q, P, R)，则运行时 5 个活动记录（省略部分内容）如下（原卷为图，动态链依次指向左边一个活动记录；原图最后一个记录标成 AR3(R)，应为 AR4(R)）：

| | AR0(main) | AR1(P) | AR2(Q) | AR3(P) | AR4(R) |
|---|---|---|---|---|---|
| 局部变量 | … | y / z / x | y | y / z / x | x / y |
| 静态链 | null | ? | ? | ? | ? |
| 动态链 | | → AR0 | → AR1 | → AR2 | → AR3 |

请回答，AR1～AR4 的静态链指针分别指向哪一个活动记录？语句 `x = x + y + z` 使用的 z 在哪一个活动记录中。

解答：AR1 的静态链为 null，AR2 指向 AR1，AR3 为 null，AR4 指向 AR3；z 在 AR3 中。

静态链指向直接外层函数最近一次的活动记录。P 定义在最外层，所以是 null；Q、R 都嵌套在 P 里，分别指向当时最新的 P 记录。R 里没有声明 z，沿静态链找到 AR3(P) 中的 z。

#### 3. 目标代码

```c
do{ S1;
    do{ S2;
    }until(x > 0);
}until(y > 0);
```

编写其目标代码，S 的目标代码用 S.code 表示。

解答：

#### 4. 简单短语

有如下文法的句型 `SmBa(SmA)`，请给出该句型的简单短语。

```text
S → SmA | A
A → AaB | B
B → (S) | a
```

解答：SmA、B。

语法树（缩进表示子结点）：

```text
S
├─ S
├─ m
└─ A
   ├─ A
   │  └─ B
   ├─ a
   └─ B
      ├─ (
      ├─ S
      │  ├─ S
      │  ├─ m
      │  └─ A
      └─ )
```

只有叶子作子结点的内部结点是 `A→B` 和括号里的 `S→SmA`，所以简单短语是 B 和 SmA，句柄是最左的 B。

#### 7. LL(1) 判断

"不含公共前缀和左递归的 2 型文法一定是 LL(1) 文法"，这种说法是否正确？若正确请证明之，否则请举例说明。

解答：错误。反例：

```text
S → AS | a
A → a
```

这个文法没有公共前缀，也没有左递归，但 `Predict(S→AS) = First(A) = {a}`，`Predict(S→a) = {a}`，两者相交，所以不是 LL(1) 文法。判断一个文法是不是 LL(1)，要看同一非终极符各产生式的 Predict 集是否两两不相交。

#### 8. 语法制导

设有文法 G：

```text
S → 1A0B
A → 1A | 1
B → 0B | 10
```

请在文法中插入相应的语义动作（并给出动作代码）完成以下功能：对输入文法 G 的句子，求其含有多少个 1。

解答：

```text
S → #init# 1 #ADD# A 0 B
A → 1 #ADD# A | 1 #ADD#
B → 0 B | 1 #ADD# 0
```

其中 init：`sum = 0`；ADD：`sum++`。每读到一个 1 就执行一次 ADD，句子分析完 sum 就是 1 的个数。

### 三、归约规范活前缀的最小 DFA

有如下文法：

```text
Z → aAc
A → bB | ba
B → dB | e
```

请给出识别该文法的所有归约规范活前缀的最小 DFA。

解答：这题用到派生定理：

1. 开始符产生式的右部是归约活前缀；
2. 如果 αAβ 是归约活前缀，且 A→π 是产生式，则 απ 也是归约活前缀；
3. 任何归约活前缀，都可按上述方法被派生。

本题所有归约规范活前缀为 aAc、abB、aba、abdB、abe、abddB、abde……，归纳起来是 aAc、aba、`abd*B`、`abd*e`。

原稿先画了一个未化简的状态图：0 -a→ 1，1 -A→ 2，2 -c→ 3，1 -b→ 4，4 -a→ 5，4 -d→ 6，6 -B→ 7，6 -e→ 8（3、5、7、8 为终态），再把终态 3、5、7、8 合并，得到最小 DFA：0 -a→ 1，1 -A→ 2，2 -c→ 3，1 -b→ 4，4 -a→ 3，4 -d→ 5，5 -B→ 3，5 -e→ 3。

（更正：原稿两张图都只接受 aAc、aba、abdB、abde 四个串，漏了 d 出现 0 次和 2 次以上的情况，和它自己归纳的 `abd*B`、`abd*e` 不一致。4 号状态还要有 B、e 到终态的边，5 号状态要有 d 的自环。）

正确的最小 DFA 如下（6 个状态，3 为唯一终态）：

| 状态 | a | b | c | d | e | A | B |
|---|---|---|---|---|---|---|---|
| →0 | 1 | | | | | | |
| 1 | | 4 | | | | 2 | |
| 2 | | | 3 | | | | |
| 3（终态） | | | | | | | |
| 4（读过 ab） | 3 | | | 5 | 3 | | 3 |
| 5（读过 abd⁺） | | | | 5 | 3 | | 3 |

4 和 5 不能合并：4 读 a 能到终态（aba），5 不能。用 LR(0) 项目集核对也一样：归约项目所在状态恰好由 aAc、aba、abB、abe、`abd+B`、`abd+e` 到达。

这个知识点（求规范句型的规范活前缀）比较容易被忽略，原稿提示教材 P70 有例题可以对照。

### 四、LR(1) 状态机

已知一个识别语言 $L=\{a^mb^n \mid n>m\ge 0\}$ 的 2 型文法如下：

```text
Z → S
S → aSb | B
B → Bb | b
```

（1）构造该文法的 LR(1) 归约规范活前缀状态机；（2）该文法是否为 LR(1) 文法？若是请构造 LR(1) 分析表，若不是请说明理由。

原稿此题未写解答。

解答（整理补充）：

（1）LR(1) 状态机共 14 个状态（`·` 表示圆点，逗号后是展望符）：

| 状态 | LR(1) 项目 | 转移 |
|---|---|---|
| I0 | [Z→·S, #]　[S→·aSb, #]　[S→·B, #]　[B→·Bb, #/b]　[B→·b, #/b] | S→I4，B→I3，a→I1，b→I2 |
| I1 | [S→a·Sb, #]　[S→·aSb, b]　[S→·B, b]　[B→·Bb, b]　[B→·b, b] | S→I8，B→I7，a→I5，b→I6 |
| I2 | [B→b·, #/b] | |
| I3 | [S→B·, #]　[B→B·b, #/b] | b→I9 |
| I4 | [Z→S·, #] | |
| I5 | [S→a·Sb, b]　[S→·aSb, b]　[S→·B, b]　[B→·Bb, b]　[B→·b, b] | S→I10，B→I7，a→I5，b→I6 |
| I6 | [B→b·, b] | |
| I7 | [S→B·, b]　[B→B·b, b] | b→I11 |
| I8 | [S→aS·b, #] | b→I12 |
| I9 | [B→Bb·, #/b] | |
| I10 | [S→aS·b, b] | b→I13 |
| I11 | [B→Bb·, b] | |
| I12 | [S→aSb·, #] | |
| I13 | [S→aSb·, b] | |

（2）不是 LR(1) 文法。I7 中 [S→B·, b] 要求遇 b 归约，[B→B·b, b] 要求遇 b 移入，移入-归约冲突。直观上看，读完 `ab` 再看到一个 b 时，要知道后面还剩几个 b 才能决定"B 结束归约成 S"还是"继续把 b 并进 B"，向前看一个符号不够。

### 五、（原卷缺题干）

试题页第四题之后直接是第六题，这里只有解答。从解答看，原题应是把文法改写成等价的 LL(1) 文法并构造 LL(1) 分析表，原文法大概是 `S→(L) | a`、`L→L=S | S`（这是根据解答推测的，原稿没有给出）。

### 六、中间代码

有类 C 语言程序：

```c
real F(real k){ return k + k; }
void Q(real x){
    real u, n[5];
    n[3] = 10; u = F(50);
    while(u > n[3])
        u = u - 2;
}
```

写出其中间代码。注：return 语句中间代码为 `(Return, -, -, var)`。

解答：

```text
(Entry, F, -, -)
(+, k, k, t1)
(Return, -, -, t1)
(Endfunc, -, -, -)
(Entry, Q, -, -)
(-, 3, 0, t2)
(*, t2, 2, t3)
([], n, t3, t4)
(=, 10, -, t4)
(ValACT, 50, offset, 2)
(Call, F, true, t5)
(=, t5, -, u)
(While, -, -, -)
(-, 3, 0, t6)
(*, t6, 2, t7)
([], n, t7, t8)
(>, u, t8, t9)
(Do, t9, -, -)
(-, u, 2, t10)
(=, t10, -, u)
(Endwhile, -, -, -)
(Endfunc, -, -, -)
```

（更正：原文传参写作 `(Varact, 50, offset, 2)`。k 是值参，应为 ValACT。按严格的类型处理，50 是整数、k 是 real，传参前还应有一条转换四元式，如 `(FLOAT, 50, -, t)`，再传 t；`编译原理笔记/编译原理学习笔记.pdf` 里同类例子就是这样写的。）

解答中 real 占 2 个单元，数组下界为 0，所以 `n[3]` 的地址是 `n + (3-0)*2`。

### 1. 短语、简单短语和句柄（5 分）

已知文法 G[S]：

```text
S → 1A | 0B | ε
A → 0S | 1AA
B → 1S | 0BB
```

给出句型 001B 的所有短语、所有简单短语及句柄。

解答：这类题先画语法树，再从上往下找短语。

```text
S
├─ 0
└─ B
   ├─ 0
   ├─ B
   │  ├─ 1
   │  └─ S
   │     └─ ε
   └─ B
```

- 短语：001B、01B、1、ε
- 简单短语：ε
- 句柄：ε

"1" 是 B→1S 这棵子树的叶子串（S 推出 ε），但这个 B 的子结点里有非叶子 S，所以 1 不是简单短语。

### 2. 简单优先关系矩阵（5 分）

已知文法 G[S]：

```text
S → a | b | (A)
A → SdA | S
```

完成下列表 1 的简单优先关系矩阵（行、列依次为 a、b、(、)、d、S、A、#），并判断 G[S] 是否为简单优先文法。

解答：原稿先列出各非终极符的首符号集 F 和尾符号集 L：

| | S | A |
|---|---|---|
| F | a, b, ( | a, b, ( |
| L | a, b, ) | a, b, ) |

（更正：原表只列了终极符。完整的应为 FIRST⁺(S) = {a, b, (}，FIRST⁺(A) = {S, a, b, (}；LAST⁺(S) = {a, b, )}，LAST⁺(A) = {S, A, a, b, )}。原稿的矩阵里 `( ⋖ S`、`A ⋗ )` 这几项已经按完整集合填了。）

简单优先关系矩阵（行是栈内符号，列是右边的符号；⋖ 低于，≐ 同级（原稿写作 ≅），⋗ 高于）：

| | a | b | ( | ) | d | S | A | # |
|---|---|---|---|---|---|---|---|---|
| a | | | | ⋗ | ⋗ | | | ⋗ |
| b | | | | ⋗ | ⋗ | | | ⋗ |
| ( | ⋖ | ⋖ | ⋖ | | | ⋖ | ≐ | |
| ) | | | | ⋗ | ⋗ | | | ⋗ |
| d | ⋖ | ⋖ | ⋖ | | | ⋖ | ≐ | |
| S | | | | ⋗ | ≐ | | | ⋗ |
| A | | | | ≐ ⋗ | | | | |
| # | ⋖ | ⋖ | ⋖ | | | ⋖ | | |

（更正：原稿 # 行把 ⋖ 填在 ) 列，应在 ( 列，# 与 ) 之间没有关系。已用 Python 按定义重算。）

结论：A 与 ) 之间同时有 ≐（来自 `S→(A)`）和 ⋗（A∈LAST⁺(A)，来自 `A→SdA`），关系不唯一，所以 G[S] 不是简单优先文法。原稿在这一格用蓝色标出了冲突，但没写结论。

### 5. LR(1) 项目集闭包与后继（15 分）

已知文法 G[E]：

```text
E → E+T | T
T → TF | F
F → F* | (E) | i
```

给出该文法 LR(1) 项目集 {[F→(·E), #/+/\*/(/i]} 的闭包，以及该项集闭包相对于文法符号 E、T、F 的后继 LR(1) 项目集闭包。

解答：主要考投影运算和闭包运算。2010 级软件学院卷第六题是同一题，那份解答写的是"与 2013 年试卷相同，略"，完整解答就在这里。

闭包：

```text
[F → (·E),  #/+/*/(/i]
[E → ·E+T,  )/+]
[E → ·T,    )/+]
[T → ·TF,   (/)/+/i]
[T → ·F,    (/)/+/i]
[F → ·F*,   */)/+/(/i]
[F → ·(E),  */)/+/(/i]
[F → ·i,    */)/+/(/i]
```

输入 E 后的后继：

```text
[F → (E·),  #/+/*/(/i]
[E → E·+T,  )/+]
```

输入 T 后的后继：

```text
[E → T·,    )/+]
[T → T·F,   )/+/(/i]
[F → ·F*,   */)/+/(/i]
[F → ·(E),  */)/+/(/i]
[F → ·i,    */)/+/(/i]
```

（更正：原稿这一组里 T→T·F 的展望符只写了 `(/i`，三个 F 项目只写了 `*/(/i`，都漏了 ) 和 +。T→·TF 在闭包里的展望符是 `(/)/+/i`，移过 T 后不变，F 项目再由它传下来。已用 Python 重算。）

输入 F 后的后继：

```text
[T → F·,    (/)/+/i]
[F → F·*,   */)/+/(/i]
```

#### 2. NFA 最简化

设非确定有限自动机 M=({x, y}, {a, b}, f, x, {y})，其中 f 的定义如下：f(x,a)={x,y}，f(x,b)={y}，f(y,b)={x,y}。请构造与 M 等价的最简确定有限自动机。

解答（整理补充）：子集法确定化：

| DFA 状态 | NFA 状态集 | a | b |
|---|---|---|---|
| A（初态） | {x} | B | C |
| B（终态） | {x, y} | B | B |
| C（终态） | {y} | | B |

最小化：先分成非终态 {A} 和终态 {B, C}。B 读 a 到 B（终态组），C 读 a 没有转移（到死状态），B、C 可区分，不能合并。所以上表的 3 个状态就是最简 DFA（不画死状态）。B 之后接受任意串，C 之后必须先读 b。

#### 3. 构造上下文无关文法

已知语言 $L=\{a^ib^j \mid j>i\ge 1\}$，试构造产生该语言的上下文无关文法。

解答（整理补充）：

```text
S → aSb | aBb
B → bB | b
```

S 两边同时加 a、b 保证 i≥1 且 a、b 配对，B 再补至少一个 b，所以 j>i。

#### 6. 运行时栈

对于下面的 C 语言程序，画出程序运行时第二次递归进入函数 f 后的运行时栈的内容是什么？要求：1. 详细刻画各活动记录数据信息包含的变量及其值；2. 管理信息的详细内容可以不用给出。

```c
int g(int s){
    s = s + 10;
    return s;
}
int f(int n){
    if(n <= 0)
        return 1;
    else
        return n * f(n - 1);
}
void main(){
    int k = 1;
    k = g(20);
    k = f(10);
}
```

解答（整理补充）：main 调 f(10) 是第一次进入 f，f(10) 调 f(9) 是第一次递归，f(9) 调 f(8) 是第二次递归。g(20) 此时早已返回，它的活动记录已经弹出，k 已被赋成 30。栈从底到顶：

| 活动记录 | 管理信息 | 数据区 |
|---|---|---|
| main | （略） | k = 30 |
| f（第一次调用） | （略） | n = 10 |
| f（第一次递归） | （略） | n = 9 |
| f（第二次递归，栈顶） | （略） | n = 8 |

各 f 记录里 `n-1` 的临时变量已算出，`n * f(n-1)` 还在等返回值。如果把"第二次递归进入"理解成第二次进入 f，栈顶就是 n = 9 的记录。活动记录的结构见 `08 运行时存储空间管理.md`。

### 四、中间代码生成与优化

给出如下程序段的四元式中间代码，并利用常表达式节省、公共表达式节省和循环不变式外提三种优化技术对中间代码进行优化。其中 A:array[1..100] of integer，整型变量占 1 个存储单元。

```pascal
a:=0;
j:=(a+1)*5;
while j<100 do
  begin
    a:=a+A[3];
    if a<10 then k:=0;
    else k:=x*y+x*y/5;
    j:=j=1;
  end
```

解答（整理补充）：原卷最后一句 `j:=j=1` 应为 `j:=j+1`，下面按 j:=j+1 做。四元式写法和优化方式照本文件 2014 级第四题的解答。

中间代码：

```text
1  (=, 0, -, a)
2  (+, a, 1, t1)
3  (*, t1, 5, t2)
4  (=, t2, -, j)
5  (WHILE, -, -, -)
6  (<, j, 100, t3)
7  (DO, t3, -, -)
8  (-, 3, 1, t4)
9  (*, t4, 1, t5)
10 ([], A, t5, t6)
11 (+, a, t6, t7)
12 (=, t7, -, a)
13 (<, a, 10, t8)
14 (THEN, t8, -, -)
15 (=, 0, -, k)
16 (ELSE, -, -, -)
17 (*, x, y, t9)
18 (*, x, y, t10)
19 (/, t10, 5, t11)
20 (+, t9, t11, t12)
21 (=, t12, -, k)
22 (ENDIF, -, -, -)
23 (+, j, 1, t13)
24 (=, t13, -, j)
25 (ENDWHILE, -, -, -)
```

优化过程：

- 常表达式节省：a=0 已知，2、3 算出 t1=1、t2=5，4 变成 `(=, 5, -, j)`；8、9 算出 t4=2、t5=2，10 变成 `([], A, 2, t6)`。
- 公共表达式节省：18 与 17 相同，删去 18，19 改用 t9。
- 循环不变式外提：`([], A, 2, t6)`、`(*, x, y, t9)`、`(/, t9, 5, t11)`、`(+, t9, t11, t12)` 的运算分量在循环里都不被修改，提到 WHILE 之前。

优化后：

确定化（原稿表格，空格表示没有转换）：

| --- | --- | --- | --- |

```text
{S5'}  {S0', S1', S2', S3', S4', D}
S2' 读 b 到终态，其余非终态读 b 都不到终态，分出 S2'
{S5'}  {S2'}  {S0', S1', S3', S4', D}
S1'、S4' 读 a 到 S2'，S0'、S3'、D 读 a 到 D，分成两组

{S5'}  {S2'}  {S1', S4'}  {S0', S3'}  {D}
```

| 状态 | 读 a | 读 b |
| --- | --- | --- |
| A = {S0', S3'}（初态） | | B |

| C = {S2'} | | E |
| E = {S5'}（终态） | C | A |

### 五、嵌套式语言与并列式语言

高级程序设计语言可以分为嵌套式语言（如 PASCAL 语言）和并列式语言（如 C 语言）两大类，请分析在编译过程中，对于嵌套式语言的处理和并列式语言的处理都有哪些区别？

解答：在编译过程中，嵌套式和并列式语言处理差别主要体现在符号表的管理和抽象地址映射两大方面。

1. 对于符号表的局部化处理，嵌套式语言使用了 Scope 栈，Scope 栈中的 Scope[L] 指向 L 层符号表的起始地址；并列式语言可以不使用 Scope 栈，用两个变量分别存储 0 层和 1 层的符号表地址即可。
2. 分配抽象地址的时候，并列式语言中并列的分程序可以共用（原文到此为止，意思是并列的分程序块可以共用同一段地址空间）。
3. 在抽象地址映射过程中，对于并列式语言，在活动记录中可以不为变量访问环境分配空间，使用两个寄存器分别存储静态区和当前活动记录首地址就可以完成抽象地址到物理地址的映射；对于嵌套式语言，在活动记录中必须为变量访问环境分配空间。

#### 3. 乔姆斯基文法分类

举例说明乔姆斯基文法分类的依据，以及各类文法表示能力的区别。

解答：根据产生式所受限制的不同，把文法分为四类：

- 0 型（短语结构文法）：α→β
- 1 型（上下文相关文法）：αAβ→αγβ
- 2 型（上下文无关文法）：A→α
- 3 型（线性文法/正则文法）：A→αB 或 A→α

正则文法这两条里的 α 是终极符串，通常写成 A→aB、A→a。

补充（整理补充）：表示能力 0 型 ⊃ 1 型 ⊃ 2 型 ⊃ 3 型。例如 `a*b*` 可以用 3 型文法描述； $\{a^nb^n\}$ 需要 2 型文法（`S→aSb | ab`），正则文法描述不了； $\{a^nb^nc^n\}$ 需要 1 型文法，上下文无关文法描述不了。

#### 1. LR(0)、SLR(1)、LR(1)

| S0 | S→·A\*B　S→·B　A→·\*B　A→·\*　B→·A | A→S1，B→S2，\*→S3 |
