## 1 编译引论

### 1-1（单选）

"用高级语言书写的源程序都必须通过编译，产生目标代码后才能投入运行。"这种说法正确与否？

A. 正确；B. 不正确；C. 不能确定

答案：B

解析：实现高级语言的方式包括编译、解释和转换，所以用高级语言编写的源程序可以通过解释方式或转换方式来实现运行。

来源：学习通 1-1；题型整理 p6。

### 1-2（单选）

编译程序必须完成的工作有（ ）。

① 词法分析 ② 语法分析 ③ 语义分析 ④ 中间代码生成 ⑤ 中间代码优化 ⑥ 目标代码生成

A. ①②③④⑤⑥；B. ①②③④；C. ①②③⑥；D. ①②③④⑤

答案：C

解析：源程序经过词法分析、语法分析和语义分析之后可以直接转换为目标程序。生成中间代码是为了方便优化和移植，所以中间代码生成和中间代码优化不是必须完成的工作。

来源：学习通 1-2；作业 2；题型整理 p6–7。2022 级期末选择题第 1 题考的也是这道。

### 1-3（单选）

以下关于高级语言实现方式的说法中错误的是（ ）。

- A. 编译方式与解释方式的根本区别在于是否生成目标代码
- B. 编译方式对源程序的处理是先翻译后执行
- C. 解释方式是按源程序中语句的动态顺序逐句地进行分析解释，并立即执行
- D. 解释方式并不对源程序进行翻译

答案：D

解析：解释方式也需要对源程序进行翻译，只不过是边翻译边执行，不生成目标程序。

来源：学习通 1-3；作业 1；题型整理 p7。

### 1-4（多选）

编译程序各阶段的工作都要涉及（ ）和（ ）。

A. 表格管理；B. 语法分析；C. 出错处理；D. 代码优化

答案：AC

解析：编译的各个阶段都涉及表格管理（存储各种中间数据）和出错处理。

来源：学习通 1-4；题型整理 p7。

## 2 形式语言与有限自动机

### 2-1（单选）

符号串集合 A = {a, b, c, d, …, z, A, B, C, D, …, Z}，下面对集合 A* 说法正确的是：

- A. 该集合是英文字母集合
- B. 该集合中符号串长度都相同
- C. 该集合是英文串集合或空串
- D. 该集合中符号串长度必定大于 1

答案：C

解析：A* 是英文字母集合 A 的各次幂的并，包含任意长度的英文串，也包含空串。

来源：题型整理 p17。

### 2-2（多选）

算术表达式 123+45.6，在词法分析后，下面的合法单词是：

A. 十进制数 123；B. 符号串 123；C. 运算符 +；D. 十进制数 45.6

答案：ACD

解析：词法分析后得到 3 个单词：常量十进制整数 123、运算符 + 和实数 45.6。

来源：作业 9；题型整理 p17–18。

### 2-3（多选）

字母表 Σ = {0, 1}，下面属于 Σ 的符号串的是：

A. 1；B. 000；C. ε；D. ∅

答案：ABC

解析：符号串是由字母表中的符号组成的任意有穷序列，可以不包含任何符号，称为空串 ε。∅ 表示空集，不是符号串。

来源：作业 10（原稿 D 选项的符号丢失，按题型整理补全）；题型整理 p18。

### 2-4（单选）

如果一个正则表达式所代表的集合是无穷的，则该正则表达式必含有的运算是：

A. 连接运算"・"；B. 或运算"|"；C. 闭包运算"*"；D. 括号"()"

答案：C

解析：连接和或运算只能从有限集合得到有限集合，只有闭包能产生无穷多个串。

来源：学习通 2-1。

### 2-5（单选）

设正则表达式 `r = (a|b|c)(x|y|z)`，则 L(r) 中元素个数是：

A. 9；B. 6；C. 18；D. 27

答案：A

解析：每个串前一部分是 a、b、c 之一，后一部分是 x、y、z 之一，共 3×3 = 9 种。

来源：作业 4；题型整理 p18。

### 2-6（单选）

与正则表达式 `(a*|b)*(c|d)` 等价的正则表达式是：

- A. `(a|b)*c|(a|b)*d`
- B. `a*(c|d)|b(c|d)`
- C. `a*(c|d)*|b(c|d)*`
- D. `a*(c|d)|b*(c|d)`

答案：A

解析：`(a*|b)*` 表示任意个 a、b 的任意排列，后面接一个 c 或 d。B、C 只能接 1 个 b；D 里的 a 和 b 不能混合出现。

来源：作业 5；题型整理 p18。

### 2-7（单选）

设正则表达式 `r = (a|b)(x|y)*`，则下面错误的正规集元素是：

A. abx；B. bxxx；C. a；D. bxyyxxy

答案：A

解析：前一部分只能是 a 或 b，后面是 x 或 y 的任意次连接；因为是星闭包，也可以不含 x 和 y。abx 的第二个字符是 b，不符合。

来源：作业 6（原稿题干里的正则表达式丢失，按题型整理补全）；题型整理 p18–19。

### 2-8（单选）

下述正则表达式中与 `(a*|b*)(c|d)` 等价的是：

- A. `a*(c|d)|b(c|d)`
- B. `a*(c|d)*|b(c|d)*`
- C. `a*(c|d)|b*(c|d)`
- D. `(a|b)*c|(a|b)*d`

答案：C

解析：用连接对或运算的分配律 `(A|B)C = AC|BC` 展开即得。D 的 `(a|b)*` 允许 a、b 混合，不等价。

来源：题型整理 p19。

### 2-9（单选）

设正则表达式 `r = (aa)+a+`，则下列正则表达式与 r 等价的是：

A. `a(aa)+`；B. `a(aa)+a`；C. `a+(aa)+`

答案：C

解析：r 表示长度不小于 3 的 a 串，C 也是。A 只能生成奇数个 a，B 只能生成偶数个 a。

来源：题型整理 p19（文字层丢了上标 +，按页面补全）。

### 2-10（多选）

正则表达式 `r = a*b*c`，则下列各符号串属于 L(r) 的是：

A. ac；B. `a*b*c`；C. abc；D. aabbc

答案：ACD

解析：B 是正则表达式本身，不是正则集里的串。

来源：作业 14（原稿题干和 B 选项丢失，按题型整理补全）；题型整理 p19。

### 2-11（单选）

不是 DFA 的构成成分的是：

A. 有穷字母表；B. 初始状态集合；C. 终止状态集合；D. 有限状态集合

答案：B

解析：DFA 只能有唯一确定的开始状态，不是状态集合。

来源：学习通 2-2；题型整理 p19。

### 2-12（单选）

下面关于 DFA 说法正确的是：

- A. 一个 DFA，可以通过多条路径识别一个符号串
- B. 一个 DFA 识别的语言是一个无限集合，则该 DFA 的状态数也得是无限个
- C. 一个 DFA 识别的语言是一个无限集合，则该 DFA 的状态图一定含有回路
- D. 一个 DFA 无法接受空串

答案：C

解析：DFA 每个状态的后继都是确定的，识别一个串只有一条路径，A 错；DFA 的状态数总是有限的，B 错；开始状态同时是终止状态时 DFA 能接受空串，D 错。

来源：题型整理 p20（原稿标为高频题）。

### 2-13（单选）

有限自动机 M 和 N 等价是指：

A. M 和 N 的字母表相同；B. M 和 N 状态数相等；C. M 和 N 状态数或有向边数相等；D. M 和 N 识别的字符串集合相同

答案：D

解析：M 和 N 等价当且仅当 L(M) = L(N)。

来源：学习通 2-3；作业 3；题型整理 p20。

### 2-14（单选）

下列说法不正确的是：

- A. 每个 NFA 都能找到与其等价的 DFA
- B. 每个 NFA 都能表示为正则表达式
- C. NFA 和 DFA 的区别是 DFA 没有空边并且每个状态接收同一个字符的后继状态唯一
- D. 自动机等价的最小 DFA 是唯一的

答案：C

解析：C 漏了一条：DFA 的开始状态也是唯一的。

来源：题型整理 p20。

### 2-15（单选）

是否存在这样一些语言，它们能被确定有限自动机识别，但不能用正则表达式表示？

A. 存在；B. 不存在；C. 无法判定是否存在

答案：B

解析：正则表达式和自动机在接受语言的能力上是等价的。

来源：作业 8；题型整理 p21。

### 2-16（多选）

以下说法正确的是：

- A. NFA 确定化后就成为最简 DFA
- B. 一个自动机的最简 DFA 是唯一的
- C. 没有等价状态的 DFA 是最简 DFA
- D. DFA 终止状态和非终止状态是不等价的

答案：BD

解析：和 NFA 等价的 DFA 可以有多个，但最简 DFA 只有一个。没有无关状态、也没有等价状态的 DFA 才是最简 DFA，所以 C 错。

来源：题型整理 p21。

### 2-17（多选）

与 DFA 相比，NFA 的非确定性体现在：

- A. 允许有多个开始状态
- B. 允许有多个终止状态
- C. 在没有任何输入的情况下允许进行状态转换
- D. 一个状态可以有多个不同后继状态

答案：AC

解析：DFA 也允许有多个终止状态，所以 B 错。D 错在说法不准：NFA 的非确定性是一个状态读同一个输入字符可以转向多个不同的后继状态，DFA 的一个状态读不同字符本来就可以有不同后继。

来源：学习通 2-4；作业 11；作业 12（题干为"NFA 的非确定性体现在"，其余相同）；题型整理 p21。

### 2-18（多选）

关于 NFA 的确定化说法正确的是：

- A. NFA 的确定化算法具有消除空边的功能
- B. 给定一个 NFA，一定存在一个 DFA，使得两者等价
- C. 一个 NFA 只能存在一个 DFA 与其等价
- D. NFA 确定化后会使得状态转换函数成为单值函数

答案：ABD

解析：确定化得到的 DFA 没有空边，状态转换函数是单值函数。与 NFA 等价的 DFA 可以有多个，只有最简 DFA 唯一，所以 C 错。

来源：题型整理 p22。

### 2-19（多选）

正则表达式和有限自动机的关系，以下说法正确的是：

- A. 一个正则表达式只能等价于一个确定的有限自动机
- B. 正则表达式、NFA 和 DFA 在接受语言的能力上是相互等价的
- C. 对任何形式正则表达式 r，都存在一个 NFA M，满足 L(M) = L(r)
- D. 一个正则表达式可以转化为一个等价的自动机，但自动机不一定都能表示为等价的正则表达式

答案：BC

解析：正则表达式和自动机接受语言的能力等价，一个正则表达式可能等价于多个自动机。能被有限自动机识别的语言一定能用正则表达式表示，所以 D 错。

来源：作业 13；题型整理 p22。

### 2-20（单选）

将识别各类单词的有限自动机合并后得到的有限自动机会：

A. 可能是 NFA，也可能是 DFA；B. 一定是 DFA；C. 一定是 NFA；D. 一定是最小的 DFA

答案：A

解析：用 ε 边把各个子自动机并起来得到的是 NFA；合并时做了确定化处理，得到的是 DFA。

来源：作业 7；题型整理 p22。

### 2-21（多选）

自动机实现的直接转向法，说法正确的是：

- A. 直接转向法是基于状态转换图实现的一种方法
- B. 直接转向法程序设计简单，但占用存储空间大
- C. 直接转向法是基于状态转换矩阵实现的一种方法
- D. 直接转向法占用存储空间小，但相应的程序较长

答案：AD

解析：自动机有两种实现方法。状态转换矩阵法程序短，但占用存储空间多；直接转向法基于状态转换图，占用空间小，但程序较长。

来源：题型整理 p22–23。

## 3 词法分析器的实现

### 3-1（单选）

词法分析器的输入是（ ）。

A. 单词符号串；B. 源程序；C. 语法单位；D. 目标程序

答案：B

解析：词法分析器把源程序的字符序列转换成等价的 token 序列，并检查词法错误，所以输入是源程序。

来源：学习通 3-1。

### 3-2（单选）

作为语法分析程序子程序的词法分析程序，它的返回结果是（ ）。

A. 单词属性值；B. 单词在符号表中的位置表示法；C. 单词的种别编码和语义值；D. 单词的种别编码

答案：C

解析：语法分析器每调用一次，词法分析器返回一个 token。token 是单词的机内表示，包含单词的种类信息和语义值。

来源：学习通 3-2。

### 3-3（单选）

将编译程序分成若干个"遍"是为了（ ）。

- A. 利用有限的机器内存并提高机器的执行效率
- B. 使程序的结构更加清晰
- C. 提高程序的执行效率
- D. 利用有限的机器内存但降低了机器的执行效率

答案：B

解析："遍"是对源程序或其中间表示从头到尾扫描一次并做加工处理。分成若干遍后，每遍执行不同的功能，编译程序的结构更清晰。

来源：学习通 3-3。

### 3-4（单选）

词法分析中能够发现以下（ ）错误。

A. 操作数类型不匹配；B. 标识符重复声明；C. 程序中出现非法符号；D. 除法溢出

答案：C

解析：四个选项里只有非法符号属于词法错误。A、B 是语义错误，D 是运行时错误。

来源：学习通 3-4。

### 3-5（单选）

编译程序中的语法分析器接受以（ ）为单位的输入，并产生有关信息供以后各阶段使用。

A. 表达式；B. 产生式；C. 单词；D. 语句

答案：C

解析：词法分析器输出 token 序列，语法分析器以单词为单位读入。

来源：学习通 3-5。

### 3-6（单选）

在词法分析阶段不能识别的是（ ）。

A. 标识符；B. 运算符；C. 四元式；D. 常数

答案：C

解析：四元式是中间代码，不是单词。

来源：学习通 3-6。

## 4 文法与自顶向下语法分析

### 4-4（单选）

下列哪些方法可以用于文法等价变换（ ）。

① 消除空产生式；② 消除左递归；③ 消除单产生式；④ 消除无用产生式；⑤ 消除开始符对应的产生式；⑥ 消除二义性句型

### 4-5（单选）

下列文法能够产生语言 L = {aⁿbbⁿ | n ≥ 1} 的是（ ）。

- A. Z → aZb | aAb | b，A → aAb | b
- B. A → aAb，A → b
- C. Z → AbB，A → aA | a，B → bB | b
- D. Z → aAb，A → aAb | b

答案：D

解析：两边的 a、b 个数相等且至少一个。A 和 B 都能直接推出 b，相当于 n = 0；C 不保证个数相等。写递归文法一定要有结束递归的产生式，本题是 A → b。

来源：题型整理 p43。

### 4-6（单选）

### 4-7（单选）

文法 T → T*F | F，F → T↑+P | P，P → (T) | a，句型 T*F↑+(T*F) 的简单短语是（ ）。

### 4-11（多选）

下列文法中属于 LL(1) 文法的是：

- A. G[S]：S → ABc，A → a | ε，B → b | ε
- B. G[S]：S → Ab，A → a | B | ε，B → b | ε
- C. G[S]：S → ABBA，A → a | ε，B → b | ε
- D. G[S]：S → aSe | B，B → bBe | C，C → cCe | d

答案：AD

解析（原稿解析把 A 选项的终结符 c 当成了非终结符，这里按 Python 复核结果重写）：

- A：Follow(A) = {b, c}，Follow(B) = {c}。Predict(A → a) = {a}，Predict(A → ε) = {b, c}；Predict(B → b) = {b}，Predict(B → ε) = {c}。不相交，是 LL(1)。
- B：Follow(A) = Follow(B) = {b}。Predict(B → b) 与 Predict(B → ε) 都是 {b}，冲突，不是 LL(1)。
- C：Follow(A) = Follow(B) = {a, b, #}。Predict(A → a) = {a} 与 Predict(A → ε) = {a, b, #} 相交，不是 LL(1)。
- D：没有 ε 产生式。S 的两个 Predict 集 {a} 与 {b, c, d}，B 的 {b} 与 {c, d}，C 的 {c} 与 {d}，都不相交，是 LL(1)。

来源：题型整理 p45–49。
