# 词法分析

整理自 `编译原理笔记/编译原理学习笔记.pdf` 第 11–42 页（第 2 章）、第 176–177 页（历年题部分的自动机补充）、第 194–211 页（旧版第 2 章，只取新版没有的内容），`编译原理笔记/编译原理期末题型整理.pdf` 第 1–2 页（高频考点）和第 11–39 页（第 2 章知识点、作业、例题），以及 `编译原理期末资料/吉林大学编译原理期末试题解答.pdf` 第 2 页"NFA 化成最小 DFA"一条。本章选择题统一收在 `10 选择题精编.md`。文中所有确定化、最小化结果都用 Python 脚本重新算过一遍。

## 本章要点

- 期末第一道大题就是自动机，常见问法有三种：给正则表达式或 NFA，求等价的最简 DFA；设计识别某类串的 DFA（如被 5 整除的二进制正整数）；给出自动机，写等价的正则表达式。旧版笔记把"NFA 到 DFA 的转换"标为必考，"正则表达式转 DFA"标为考试必考题型。自动机转正则考得相对少。
- 本章结构：一个核心是词法分析器的设计；两个工具是正则表达式和有限自动机（DFA、NFA）；三个转换算法是 NFA 确定化（子集构造法）、DFA 最小化（状态分离法）、正则表达式与自动机互转。
- 正则表达式、正则集、符号串要分清：`a*b*c` 是正则表达式，不是 `L(a*b*c)` 里的串。
- DFA 与 NFA 的三点区别：NFA 同一状态同一输入可以有多个后继、允许多个开始状态、允许空边。
- 确定化的初始状态是 NFA 初始状态集的 ε-闭包；每步都是"先求 a 转换，再求 ε-闭包"。
- 最小化从"终止 / 非终止"两组开始反复划分；最简 DFA 既没有等价状态，也没有无关状态，在同构意义下唯一。
- 设计 DFA 时注意题目是否排除前导 0、是否包含 0 本身和空串。

## 概念与解释

### 1. 词法分析的功能

词法分析程序是编译的第一步。它读入源程序的字符序列，逐个拼出单词，构造单词的内部表示（Token），同时检查词法错误。一句话：把字符序列转换成 Token 序列。

**单词**是语言中具有独立含义的最小语义单位。单词不是程序设计语言的语法概念，是编译程序引进的概念。`3.14*initial` 分成 `3.14`、`*`、`initial` 三个单词，`3.14` 不能再拆成 `3`、`.`、`14`。

例：程序片段

```text
VAR sum, first, count: real;
BEGIN
  sum := first + count * 10
END.
```

在计算机里是一串字符 `V A R ␣ s u m , ␣ f i r s t … E O F`，词法分析后得到单词序列 `VAR` `sum` `,` `first` `,` `count` `:` `real` `;` `BEGIN` `sum` `:=` `first` `+` `count` `*` `10` `END` `.`。

词法分析的具体工作：

1. 扫描字符流，识别关键字、标识符、常量、运算符、界符等单词；
2. 构造 Token，记录单词类别和属性值（名字、数值等）；
3. 剔除空白符、注释等对运行没有意义的内容（注释只起提示作用，词法分析不处理）；
4. 报告词法错误，如非法字符、数值格式错误。

词法分析器的两种接口

| 类型 | 工作方式 |
|---|---|
| 作为语法分析的子程序（附属式） | 语法分析器调用词法分析器，词法分析器从源程序读字符，每次返回一个 Token。词法、语法分析一遍扫描完成，实际编译器大多这样做 |
| 作为独立的一遍（独立式） | 词法分析器把整个字符流转换成 Token 流，再交给语法分析器。课上用这种方式讲，便于理解 |

单词的种类

| 种类 | 说明 | 例子 |
|---|---|---|
| 标识符 | 用户定义的名字，表示变量、常量、数组、函数等，每种语言有自己的命名规则 | `X1`、`classT` |
| 保留字 | 语言系统定义、有固定意义的字符串，是识别语法成分的依据 | `while`、`do`、`int`、`if` |
| 常量 | 整数、实数、字符、字符串常量 | `10`、`3.14`、`true` |
| 特殊符号：运算符 | 算术、逻辑、字符、赋值运算符 | `+`、`%`、`>=` |
| 特殊符号：界限符 | 语法上的分界符 | `,`、`;`、`{`、`}` |
| 特殊符号：控制符（格式符） | 控制格式 | 回车、空格、`EOF` |

标识符和常数的个数可以看作无穷多，特殊符号的个数有限，语言一确定就定下来了。

描述单词的工具：正则表达式（便于形式化描述词法规则）和自动机（执行识别过程）。二者可以互相转换。

### 2. 正则表达式

#### 2.1 基本概念

1. 字母表 Σ：元素的非空有穷集合，元素叫字母、符号或字符。例：Σ = {a, b, c, d}。
2. 符号串：字母表中符号组成的任意有穷序列。ε 表示空串，是任何字母表上的符号串。空串集 {ε} 有一个元素（空串），空集 ∅ 没有元素，二者不同。
3. 连接：α = abc，β = de，则 αβ = abcde。空串和任何串连接还是这个串本身。
4. 符号串的方幂：$\alpha^0=\varepsilon$，$\alpha^1=\alpha$，$\alpha^n=\alpha^{n-1}\alpha=\alpha\alpha^{n-1}$。
5. 符号串集合：元素都是 Σ 上符号串的集合。
6. 集合的乘积：AB = { xy | x ∈ A 且 y ∈ B }。A = {a, bc}，B = {de, f}，AB = {ade, af, bcde, bcf}。特别地，∅A = A∅ = ∅，{ε}A = A{ε} = A。
7. 集合的方幂：$A^0=\{\varepsilon\}$，$A^n=A^{n-1}A$。A = {a, b} 时 $A^2$ = {aa, ab, ba, bb}，$A^3$ = {aaa, aab, aba, abb, baa, bab, bba, bbb}。
8. 正闭包：$A^+=A^1\cup A^2\cup\cdots$。
9. 星闭包：$A^*=A^0\cup A^+$，比正闭包多一个空串。A = {ab, cd} 时，$A^+$ = {ab, cd, abab, abcd, cdab, cdcd, …}，$A^*$ = {ε, ab, cd, abab, …}。

闭包运算作用于符号串集合。

#### 2.2 正则表达式的定义

设 Σ 为有限字母表，Σ 上的正则表达式递归定义如下：

1. ε 和 ∅ 是正则表达式；
2. 对任何 a ∈ Σ，a 是正则表达式；
3. 若 r、s 是正则表达式，则 `(r)`、`r|s`（选择）、`rs`（连接）、`r*`（星闭包）、`r+`（正闭包）也是正则表达式；
4. 有限次使用上述规则构成的表达式才是 Σ 上的正则表达式。

正则集：同一个表达式在不同的语义解释下含义不同，比如 `1+1` 按算术运算得 2，按逻辑运算得 1。词法分析里用语义函数把正则表达式解释成符号串集合，这个集合叫正则表达式 e 的正则集，记作 L(e)：

| e | L(e) |
|---|---|
| ∅ | ∅ |
| ε | {ε} |
| a（a ∈ Σ） | {a} |
| `e1e2` | L(e1)L(e2) |
| `e1\|e2` | L(e1) ∪ L(e2) |
| `(e)` | L(e) |
| `e*` | (L(e))* |
| `e+` | (L(e))+ |

Σ = {a, b} 上的例子：

| 正则表达式 | 正则集 |
|---|---|
| `a\|b` | {a, b} |
| `ab` | {ab} |
| `(a\|b)(a\|b)` | {aa, ab, ba, bb} |
| `a*` | {ε, a, aa, aaa, …} |
| `ab*` | L(a)L(b*) = {a}{ε, b, bb, …}，以 a 开头、后跟任意个 b 的串 |
| `a(a\|b)*` | {a}{a, b}*，所有以 a 开头的串 |

#### 2.3 正则表达式的性质

- 优先级：`*` 和 `+` 最高，其次连接，`|` 最低；括号改变优先级。
- `A|B = B|A`（交换律），`A|(B|C) = (A|B)|C`（结合律）。
- `A(BC) = (AB)C`（连接结合律）。
- `A(B|C) = AB|AC`，`(A|B)C = AC|BC`（连接对选择的分配律）。
- `A** = A*`。
- `Aε = εA = A`（ε 是连接的单位元）。
- `b+` 可以写成 `bb*` 或 `b*b`，构造 NFA 时常这样替换。

#### 2.4 用正则表达式描述单词

设 `L = A|B|…|Z|a|b|…|z`（字母），`D = 0|1|…|9`（数字），`D1 = 1|2|…|9`（非零数字）。

| 单词 | 正则表达式 | 说明 |
|---|---|---|
| 标识符 | `L(L\|D)*` | 字母开头，后跟任意个字母或数字 |
| 整数 | `(+\|-\|ε)(D1D*)\|0` | 可选符号后接非零数字开头的数字串，或单独一个 0；`0` 在最外层，所以不允许 `+0` |
| 实数 | `(+\|-\|ε)(D1D*\|0).D*` | 在整数后加小数部分；这里 `0` 在括号里，`-0.5` 合法。这是简化写法，`1.`、`.5` 之类实际更复杂 |
| 保留字 | `while\|if\|for\|…` | 特殊符号都用枚举 |
| 运算符 | `+\|-\|*\|/\|…` | |
| 分界符 | `{\|}\|;\|…` | |
| 控制符 | `\t\|\0\|…` | |

正则表达式的其他应用：手机号码归属地识别、软件安全监测、程序分析（代码搜索、模式匹配）。

#### 2.5 正则表达式的局限性

正则表达式（以及和它等价的有限自动机）只有有限的记忆，下面这些语言描述不了：

- 配对或嵌套结构：任意层嵌套的括号 `()`、`(()())`；$\{a^nb^n\mid n\ge1\}$。
- 重复串：{ wcw | w 是 a、b 组成的串 }，两边的 w 必须相同；{ ww | w ∈ Σ* }。`(a|b)*c(a|b)*` 能描述"中间一个 c"的外形，却保证不了两边相同。
- 递归定义的结构，如算术表达式：n ∈ AE；(AE) ∈ AE；AE + AE ∈ AE。

这类语言要用上下文无关文法描述、用带栈的下推自动机识别，见 `03 文法与语法树.md`。

### 3. 确定有限自动机 DFA

#### 3.1 定义

DFA 是一个五元组 M = (S, Σ, S₀, f, Z)：

1. S：有穷状态集；
2. Σ：有穷字母表，元素叫输入字符；
3. S₀ ∈ S：**唯一**的初始状态；
4. f：状态转换函数 S × Σ → S，是**单值函数**。f(Sᵢ, a) = Sₖ 表示当前状态 Sᵢ 读入 a 后唯一地转到 Sₖ，Sₖ 叫 Sᵢ 的后继状态；
5. Z ⊆ S：终止状态集（接受状态集），可以为空。

被问"什么是自动机"时，回答它是一个五元组，再逐项说明，不要只说"状态怎么转换"。

DFA 的确定性体现在两点：初始状态唯一；对任何状态 s 和输入 a，f(s, a) 唯一确定下一个状态。课上的 DFA 允许有转换没画出来，没定义的转换默认进入死状态。

例：S = {0, 1, 2}，Σ = {a, b}，S₀ = 0，Z = {2}，f(0, a) = 1，f(0, b) = 2，f(1, a) = 2，其他转换未定义。

#### 3.2 两种表示

状态转换矩阵：行标是状态，列标是输入字符，元素是 f 的值。一般第一行是开始状态，或在状态右上角标 `+`；右上角标 `*`（或 `-`）的是终止状态。

状态转换图：结点表示状态，非终止状态画单圆圈，终止状态画双圆圈（或单圆圈标 `-`），开始状态用箭头指向（或标 `+`）；f(Sᵢ, a) = Sₖ 画成从 Sᵢ 到 Sₖ、标 a 的有向边。

例：DFA M = ({S, U, V, Q}, {a, b}, f, S, {Q})

| 状态 | a | b |
|---|---|---|
| S+ | U | V |
| U | Q | V |
| V | U | Q |
| Q* | Q | Q |

（整理补充）这个 DFA 接受的是所有含 `aa` 或 `bb` 子串的 a、b 串：U 表示刚读了 a，V 表示刚读了 b。

#### 3.3 DFA 接受的串

对 Σ* 中的串 t，如果存在一条从初始结点到某个终止结点的路径，路上所有边的标记连起来等于 t，就说 t 被 DFA M 接受（识别）。初始状态同时是终止状态时，M 接受空串 ε。M 接受的串的全体记作 L(M)。

| 自动机 | 转换 | 接受的语言 |
|---|---|---|
| M₁ | 0 -a→ 1 -b→ 2 -a→ 3，3 在 a、b 上自环；终态 3 | 以 `aba` 开头的串：{aba, abaa, abab, abaab, …} |
| M₂ | 0 -a→ 1，1 在 b 上自环；终态 1 | `ab*`：{a, ab, abb, …} |
| M₃ | 1 在 b 上自环；1 既是初态又是终态 | `b*`：{ε, b, bb, …} |

应用举例：自动售货机模型（待机、待选择、金额不足、冲调、待取等状态之间按投币、选择、超时、退款转换）；判断 0/1 串是否合法、识别被 3 整除的数，见典型题。

#### 3.4 用 DFA 描述单词

标识符 `l(l|D)*`（l 表示字母）：

| 状态 | l | D |
|---|---|---|
| 0+ | 1 | |
| 1* | 1 | 1 |

整数和实数（D1 = 1…9，D = 0…9）：

| 状态 | `+` 或 `-` | 0 | D1 | `.` | 含义 |
|---|---|---|---|---|---|
| 0+ | 3 | 2 | 1 | | 开始 |
| 1* | | 1 | 1 | 5 | 读了非零开头的整数 |
| 2* | | | | 5 | 读了单个 0 |
| 3 | | 4 | 1 | | 读了符号 |
| 4 | | | | 5 | 读了符号和 0，只能继续读小数点 |
| 5 | | 6 | 6 | | 读了小数点 |
| 6* | | 6 | 6 | | 小数部分 |

- 只看无符号整数，只用状态 0、1、2；带符号整数再加状态 3（3 读 D1 到 1）。
- 状态 5 不是终态，小数点后至少要有一位数字才进入终态 6。所以这个 DFA 对应的实数是 `(+|-|ε)(D1D*|0).DD*`，比上节正则表达式里的 `.D*` 严格。
- 符号后面读 0 进入状态 4，`+0` 不被接受，`+0.5` 可以。

特殊符号：从开始状态分别经 `{`、`+`、`EOF` 等边直接到各自的终态，每个分支一个符号。

保留字不在自动机上单独体现。`if` 这类保留字会和标识符一样停在标识符 DFA 的状态 1，所以另建一张保留字表，停在状态 1 的串再查一遍表，区分是保留字还是标识符。

#### 3.5 自动机的实现

直接转换法（直接转向法）：每个状态对应一段带标号的 `switch` 语句，每条边对应一个 `goto`。只适合状态比较少的情况。

```c
/* 非终止状态 i：读 a 到 j，读 b 到 k */
Li: switch (CurrentChar) {
    case 'a': goto Lj;
    case 'b': goto Lk;
    default:  Error();
}

/* 终止状态 i：多一个 Eof 分支 */
Li: switch (CurrentChar) {
    case 'a': goto Lj;
    case 'b': goto Lk;
    case Eof: Accept();   /* Eof 表示输入串结束 */
    default:  Error();
}
```

例：状态 0 在 a、b 上自环，0 -c→ 1 -c→ 2，2 是终态且在 a、b 上自环。状态 0 对应

```c
L0: switch (CurrentChar) {
    case 'c': goto L1;
    case 'a': goto L0;
    case 'b': goto L0;
    default:  Error();
}
```

不想用 `goto`，也可以用一个状态变量：`case 'a': state = Sj; break;`。

状态转换矩阵法：把自动机存进二维数组 `T[State][CurrentChar]`，程序查表跳转。

1. `State` 置为初始状态；
2. 读一个字符到 `CurrentChar`；
3. 若 `CurrentChar != Eof` 且 `T[State][CurrentChar] != error`，则 `State = T[State][CurrentChar]`，读下一个字符，重复第 3 步；
4. 若 `CurrentChar == Eof` 且 `State` 是终止状态，接受；否则报错。

两种方法的比较：状态转换矩阵法程序短，但占用存储空间多；直接转向法基于状态转换图，占用空间小，但程序较长。

#### 3.6 注意的问题

- 死状态：进入后再也到不了终止状态的非终止状态，它的所有转换都指回自己。课件的说法是"到终止状态没有通路，或者从开始状态没有通路到达"的状态，这类状态画图时可以缺省。
- 缺省状态：`switch` 里 `default` 分支去的地方，通常是错误处理或死状态。
- 缺省转换函数：状态转换矩阵里没填的项，默认转到死状态（或错误状态），表示输入不被接受。

#### 3.7 自动机等价

同一字母表上的自动机 M₁、M₂，若 L(M₁) = L(M₂)，则称二者等价。只看接受的串是否相同，和状态数、边数无关。

### 4. 非确定有限自动机 NFA

#### 4.1 定义

NFA 是五元组 M = (Σ, S, S₀, f, Z)：

- Σ：有穷字母表；
- S：状态集；
- S₀ ⊆ S：初始状态集（是集合，可以有多个）；
- f：S × (Σ ∪ {ε}) → 2^S，即从一个状态出发，读一个符号或读 ε，可以转到多个状态，也可以没有状态可转；允许 ε 边（空边）；
- Z ⊆ S：终止状态集。

#### 4.2 DFA 与 NFA 的三点区别

1. NFA 一个状态的不同出边可以标相同的符号（f 多值）；DFA 对同一输入只有一个确定的后继（f 单值）。
2. NFA 允许有多个开始状态；DFA 只有一个。
3. NFA 允许有空边；DFA 不允许。

终止状态可以有多个，这一点 DFA 和 NFA 一样，不是 NFA 独有的非确定性。

#### 4.3 为什么要用 NFA

NFA 描述问题方便，直接实现很麻烦；DFA 实现方便。所以描述问题时用 NFA，实现时转换成等价的 DFA。NFA 也是把任意正则表达式变成可实现的自动机的中间媒介。

例：用 NFA 描述整数，一条标 `+|-|ε` 的边就把"有无符号"都包进去了：

| 状态 | `+` | `-` | ε | 0 | D1 | D |
|---|---|---|---|---|---|---|
| 0+ | 1 | 1 | 1 | 3 | | |
| 1 | | | | | 2 | |
| 2* | | | | | | 2 |
| 3* | | | | | | |

（更正：原图状态 2 的自环标作 D₂，按整数的定义应为任意数字 D。）

定理：对每个 NFA A，都存在 DFA A′ 使 L(A) = L(A′)。NFA 和 DFA 识别语言的能力相同。

### 5. NFA 到 DFA 的转换（子集构造法）

#### 5.1 ε-闭包

设 I 是 NFA 状态集的子集，ε-closure(I) 定义为：

1. I 中的状态都属于 ε-closure(I)；
2. 从 ε-closure(I) 中的状态出发，经任意条 ε 边能到达的状态也属于 ε-closure(I)。

也就是 I 通过空边扩展出来的集合。

#### 5.2 a 转换 Ia

设 I = {S₁, …, Sₘ}，a ∈ Σ，J = f(S₁, a) ∪ … ∪ f(Sₘ, a)，则 **Ia = ε-closure(J)**。先对 I 里每个状态求读 a 的后继、取并集，再对并集求 ε-闭包。

下面几个例子和典型题 D1 用同一个 NFA N₁（初态 1，终态 6、7、9）：

| 状态 | a | b | ε |
|---|---|---|---|
| 1+ | {4, 5} | | {2} |
| 2 | | {3} | |
| 3 | | | {8} |
| 4 | | | {7} |
| 5 | | | {6} |
| 6* | | {9} | {2} |
| 7* | | {9} | |
| 8 | {9} | | |
| 9* | | | |

- ε-closure({1}) = {1, 2}。
- ε-closure({1, 5}) = {1, 2, 5, 6}。手算的办法：先把 1、5 抄下来，看 1 的空边加入 2，看 5 的空边加入 6，再看 2、6，6 有空边到 2（已在集合里），没有新状态，结束。
- {1, 2}a：J = f(1, a) ∪ f(2, a) = {4, 5} ∪ ∅ = {4, 5}；ε-closure({4}) = {4, 7}，ε-closure({5}) = {5, 6, 2}；所以 {1, 2}a = {2, 4, 5, 6, 7}。（更正：原文作 f(1, a) = {4}、f(2, a) = {5}；按图，1 读 a 同时到 4 和 5，2 没有 a 边，J 的结果不变。）

#### 5.3 确定化算法

1. DFA 的初始状态 I₀ = ε-closure(NFA 的初始状态集)，标记为未处理。
2. 只要还有未处理的状态 Iᵢ：标记为已处理；对每个 a ∈ Σ，算 J = move(Iᵢ, a)，Iⱼ = ε-closure(J)；Iⱼ 非空且没出现过，就加入 DFA 状态集并标为未处理；令 f_DFA(Iᵢ, a) = Iⱼ。
3. 含有 NFA 任一终止状态的 DFA 状态是终止状态。

考试时画一张表：第一列是 DFA 状态（NFA 状态子集），每个输入符号一列，从初始状态那一行开始填，表里新出现的子集依次追加成新的行，直到不再出现新子集。最后给子集重新编号、画图。

简便的消空边方法（适合简单情况）：

- 若有 S₁ -ε→ S₂ -a→ S₃，可以删掉这条 ε 边，加一条 S₁ -a→ S₃。例：0 -ε→ 1 -a→ 2，删去空边后加 0 -a→ 2。
- 若有 ε 环路（如 S₁ -ε→ S₂ -ε→ S₁），把环上的状态合并成一个。

### 6. DFA 的最小化

#### 6.1 定义

- **等价状态**：DFA 的两个状态 S₁、S₂，对任意输入串 x，从二者出发总是同时到达接受状态或同时到达非接受状态。
- **无关状态**：从开始状态没有通路到达它，或者从它出发没有通路到达任何终止状态。删掉无关状态不改变接受的语言。
- **最小（最简）自动机**：既没有无关状态，也没有等价状态的 DFA。
- 结论：任何 DFA 都能化成最简 DFA；同一个正则语言的最简 DFA 在同构意义下唯一。

#### 6.2 状态分离法（划分法）

判断两个状态等价很难，判断不等价相对容易，所以从粗到细不断拆分。

- 状态集 SSᵢ 对 a **不可区分**：SSᵢ 中所有状态读 a 后都落到当前划分的同一个组里。
- 状态集 SSᵢ 对 a **可区分**：读 a 后落到不同组里，说明组内状态不全等价，要按落点把 SSᵢ 拆开。没有 a 转换（到死状态）也算一种落点。

算法：

1. 初始划分 Π = {非终止状态集, 终止状态集}（有一个为空就只有一组）。
2. 对 Π 中每个组 P、每个符号 a，若 P 对 a 可区分，就把 P 拆成若干小组，使每个小组内的状态读 a 后落在同一组。一旦某个组被拆开，下一轮所有组都要重新检查。直到某一轮划分不再变化。
3. 每个组是最简 DFA 的一个状态；含原初始状态的组是初始状态；由原终止状态构成的组是终止状态；原 DFA 中 s ∈ Pᵢ 读 a 到 t ∈ Pⱼ，则最简 DFA 中 Pᵢ 读 a 到 Pⱼ。

试题解答里的口诀：画表格（确定化），合并等效状态，画自动机。

划分示意：DFA 有 1 -a→ 2 -b→ 3 -c→ 4，1 -d→ 5 -b→ 6 -c→ 7，1 -b→ 8 -a→ 6，终态 4、7。

```text
初始：{1,2,3,5,6,8}  {4,7}
第 1 轮（看 a、b、c、d 各自落到哪组，"-" 表示没有该转换）：
  1: a→非终  b→非终  c→-    d→非终
  2: a→-     b→非终  c→-    d→-       5 与 2 相同
  3: a→-     b→-     c→终   d→-       6 与 3 相同
  8: a→非终  b→-     c→-    d→-
  拆成 {1} {2,5} {3,6} {8} {4,7}
第 2 轮：2、5 读 b 都到 {3,6}，3、6 读 c 都到 {4,7}，不再变化
结果：{1}  {2,5}  {3,6}  {8}  {4,7}
```

8 读的是 a、2 和 5 读的是 b，落点相同也不能合并，因为是不同符号上的转换。（更正：原文把 {1,8} ∪ {2,5} ∪ {3,6} ∪ {4,7} 写成"初始划分"；初始划分只有终止、非终止两组，1 和 8 也不等价，最后各自成组。）

### 7. 正则表达式与自动机的相互转换

#### 7.1 正则表达式到 NFA

定理 1：对 Σ 上的每个正则表达式 R，存在 Σ 上的 NFA M（可以带 ε 边），使 L(M) = L(R)。

构造方法：

1. 先画初始状态 S 和唯一的终止状态 Z，S 到 Z 画一条边，标上整个 R。
2. 反复用下面三条规则分解边上的表达式，直到所有边上只剩 Σ 中的单个符号或 ε：

| 边上的标记 | 替换为 |
|---|---|
| A -`R1R2`→ B | A -R1→ C -R2→ B（新增状态 C） |
| A -`R1\|R2`→ B | A 到 B 两条并行边，分别标 R1、R2 |
| A -`R1*`→ B | A -ε→ C -ε→ B，C 上加标 R1 的自环 |

`R*` 的两条空边都不能省。如果把 `ab|d*` 画成 1 -a→ 3 -b→ 2、1 -ε→ 2、终态 2 上挂 d 自环（省掉了 C 和后一条空边），`abd` 也会被接受，但 `ab` 后面本来不能接 d。正确画法是让 d 的自环挂在一个新状态 C 上：1 -ε→ C -ε→ 2。

#### 7.2 自动机到正则表达式（状态消除法）

定理 2：对 Σ 上的任何 NFA（DFA 是它的特例）M，存在正则表达式 R 使 L(R) = L(M)。

1. 加一个新的开始状态 S，用 ε 边连到 M 的所有初始状态；加一个新的终止状态 Z，从 M 的所有终止状态用 ε 边连过去。（M 只有一个初态且没有入边时，可以直接当 S；只有一个终态且没有出边时，可以直接当 Z。）
2. 反复用下面的规则消去中间状态，直到只剩 S 和 Z，S 到 Z 边上的表达式就是答案：

| 原图 | 替换为 |
|---|---|
| P -R1→ Q -R2→ K（消去 Q） | P -`R1R2`→ K |
| P 到 Q 两条边 R1、R2 | P -`R1\|R2`→ Q |
| P -ε→ Q -ε→ K，Q 上有自环 R1 | P -`R1*`→ K |

一般情况下消去 Q：对每一对 P -`R_PQ`→ Q 和 Q -`R_QK`→ K，Q 的自环为 `R_QQ`（没有自环就不写），新边为 `R_PQ(R_QQ)*R_QK`；P 到 K 原来有边 `R_PK` 的，合并成 `R_PK|R_PQ(R_QQ)*R_QK`。所有经过 Q 的路径都处理完后删掉 Q。

### 8. 词法分析器的设计

设计步骤：确定接口 → 确定单词的结构（Token）→ 给出单词的描述（通常是正则表达式）→ 设计算法（实现 DFA）。

接口：附属式，语法分析器调用词法分析器，词法分析器从字符流 CharList 读字符、返回一个 Token；独立式，词法分析器把 CharList 处理成 TokenList，作为语法分析器的输入。

Token 结构：没有统一规定，至少包含两部分：单词的类型（语法信息，如保留字、标识符、常量、运算符）和单词的内容（语义信息，如标识符的名字、常量的值，或它们在表中的位置）。一种可行的设计是（类型, 内容）：

| 单词 | 类型 | 内容 |
|---|---|---|
| 标识符 | 统一编码，如 1 | 在标识符表中的位置 |
| 常量 | 统一编码，如 2 | 在常量表中的位置（或直接存值） |
| 保留字、特殊符号 | 每个符号一个预定义编码 | 空 |

例：`if (x>0) y=x;`，设 `if`、`(`、`)`、`>`、`=`、`;` 的编码依次为 4、5、6、7、8、9，得到

```text
<4,->  <5,->  <1,1>  <7,->  <2,1>  <6,->  <1,2>  <8,->  <1,1>  <9,->
 if     (      x      >      0      )      y      =      x      ;
```

其中 x 是标识符表第 1 项，y 是第 2 项，0 是常量表第 1 项。

工作过程分两部分：用 DFA 识别单词；针对不同单词生成 Token。

- 标识符：先查保留字表，是保留字就生成保留字 Token（类型为该保留字编码，内容为空）；不是就查标识符表，没有则加入，生成（标识符, 表中位置）。
- 常量：先把字符串转换成数值，查常量表，没有则加入，生成（常量, 表中位置或值）。
- 特殊符号：查特殊符号表得到编码，生成（编码, 空）。

查保留字表、特殊符号表是为了确定单词的类型；查标识符表、常量表是为了确定单词的内容，这时单词的类别已经由 DFA 的终止状态确定了。

要注意的问题：

- 名字（标识符）怎样存储和管理；
- 复合单词的识别，如 `:=`、`==`、`++`，要设计相应状态或向前看；
- 数的转换：字符串转数值，处理溢出等错误；
- 向前看若干字符：区分 `>` 和 `>=` 这类单词，按最长匹配原则；
- 空格、制表符、换行等控制字符通常作为分隔符跳过；
- 识别并跳过单行、多行注释。

## 易混对比

| 概念 | 是什么 | 例子 |
|---|---|---|
| ε | 空串，长度为 0 的符号串 | |
| {ε} | 只含空串的集合，有 1 个元素 | $A^0=\{\varepsilon\}$ |
| ∅ | 空集，没有元素 | ∅A = ∅ |
| 正则表达式 | 一种表示形式 | `a*b*c` |
| 正则集 L(e) | 正则表达式代表的串的集合 | L(`a*b*c`) = {c, ac, bc, abc, aabbc, …} |
| 星闭包 `e*` | 重复零次或多次，含空串 | `e* = e+ ∪ {ε}` |
| 正闭包 `e+` | 重复一次或多次，不含空串（除非 e 本身含空串） | `b+ = bb* = b*b` |

| 区别点 | DFA | NFA |
|---|---|---|
| 开始状态 | 唯一 | 可以是一个状态集 |
| 同一状态读同一符号 | 后继唯一，f 是单值函数 | 可以有多个后继，也可以没有 |
| 空边 | 不允许 | 允许 |
| 终止状态 | 可以有多个 | 可以有多个 |
| 描述与实现 | 实现方便 | 描述方便，直接实现困难 |
| 识别能力 | 正则语言 | 正则语言，与 DFA 等价 |

| 状态 | 判断方法 | 最小化时怎么处理 |
|---|---|---|
| 无关状态 | 从开始状态到不了，或者到不了任何终止状态 | 删除 |
| 死状态 | 非终止状态，进去后到不了终止状态（属于无关状态） | 画图时可以缺省，缺省的转换默认进入它 |
| 等价状态 | 对任意输入串，同时接受或同时拒绝 | 合并 |
| 终止状态与非终止状态 | 读空串就能区分 | 一定不等价，不能合并 |

| 说法 | 对错 | 原因 |
|---|---|---|
| NFA 确定化后就是最简 DFA | 错 | 确定化后还可能有等价状态，要再最小化 |
| 与某个 NFA 等价的 DFA 只有一个 | 错 | 等价的 DFA 可以有多个，最简 DFA 只有一个 |
| 没有等价状态的 DFA 就是最简 DFA | 错 | 还要没有无关状态 |
| DFA 识别无限语言，状态数也要无限 | 错 | 状态数总是有限的，状态图里一定有回路 |
| 存在 DFA 能识别、正则表达式描述不了的语言 | 错 | 二者能力等价 |
| 正则表达式能描述括号配对 | 错 | 需要上下文无关文法 |

| 实现方法 | 依据 | 程序 | 存储空间 |
|---|---|---|---|
| 状态转换矩阵法 | 状态转换矩阵，查表 | 短 | 大 |
| 直接转向法 | 状态转换图，每个状态一段 `switch` | 长 | 小，只适合状态少的情况 |

| 转换 | 算法 | 关键动作 |
|---|---|---|
| 正则表达式 → NFA | 分解构造法 | 连接加中间状态，选择画并行边，闭包画"ε、自环、ε" |
| NFA → DFA | 子集构造法 | 初态求 ε-闭包；每步先 move 再求 ε-闭包 |
| DFA → 最简 DFA | 状态分离法 | 先分终态、非终态，按落点反复拆分 |
| 自动机 → 正则表达式 | 状态消除法 | 两端加 S、Z 和空边，消串联、并联、自环 |

## 典型题

以下正则表达式都用程序枚举短串（长度 7 到 12 以内）和题意逐一比对过；自动机题的子集表、划分过程和最简 DFA 都用子集构造和划分算法重新算过，与原稿一致的不再注明。

### A. 写正则表达式

**A1（例题）Σ = {0, 1}，写出表示二进制数且为 2 的倍数的串的正则表达式。**

思路：先写全体串，再加"是二进制数"的限制，最后加"能被 2 整除"。

解答：

1. Σ 上所有串：`(0|1)*`；
2. 二进制数（不以 0 开头，或就是 0 本身）：`1(0|1)*|0`，排除了空串；
3. 2 的倍数就是最低位为 0：`1(0|1)*0|0`。

答案 `1(0|1)*0|0`，如 0、10、100、110。这类题别漏了 0 本身。

**A2（例题）Σ = {x, y, z}，写出包含偶数个 x 的所有串。**

解答：`((y|z)*x(y|z)*x)*(y|z)*`。`x(y|z)*x` 是一对 x，中间夹任意个非 x 字符；前面的 `(y|z)*` 允许每对 x 前有非 x 字符；外层星闭包重复零对或多对；最后再接任意个非 x 字符。前半部分是星闭包，后面直接连接即可。

**A3（例题）Σ = {x, y, z}，写出不包含连续两个 y 的所有串。**

解答：`(x|z|yx|yz)*(y|ε)`。`(x|z|yx|yz)*` 里每个 y 后面都紧跟 x 或 z，不会出现 yy；结尾的 `(y|ε)` 允许以单个 y 结尾。

**A4（作业）Σ = {a, b, c}，写出以 a 开头且以 a 结尾的串。**

解答：`a(a|b|c)*a|a`。单独一个 a 也满足条件，不能漏。

**A5（作业）Σ = {a, b, c}，写出由三个或更多字母构成、倒数第三个字母为 a 的串。**

解答：`(a|b|c)*a(a|b|c)(a|b|c)`。

**A6（2017 级期末）Σ = {0, 1}，写出只包含两个 1 的所有串。**

解答：`0*10*10*`。

### B. 设计 DFA

**B1（例题）设计 DFA，识别所有能被 3 整除的二进制数。**

思路：按余数设状态。二进制数后面接一个 0，值变成原来的 2 倍；接一个 1，变成 2 倍加 1。所以余数 r 读入 b 后变成 (2r + b) mod 3。

解答：状态 0、1、2 分别表示余 0、余 1、余 2。

| 状态 | 0 | 1 |
|---|---|---|
| 0+* | 0 | 1 |
| 1 | 2 | 0 |
| 2 | 1 | 2 |

题目没有要求去掉前导 0，所以 3 个状态就够（这个 DFA 也接受空串和 `011` 这类串）。要求排除前导 0 时，照 B2 的做法加一个只读 1 的初始状态。

**B2（作业；高频考点）设计 DFA，识别被 5 整除的二进制正整数（不包括有前导零的数）。**

思路：S0 是初始状态，只接受 1，用来处理前导 0；S1 到 S4 分别表示被 5 除余 1 到 4；S5 表示整除。读 1 时值乘 2 加 1，读 0 时值乘 2。

解答：

| 状态 | 0 | 1 |
|---|---|---|
| S0+ | | S1 |
| S1（余 1） | S2 | S3 |
| S2（余 2） | S4 | S5 |
| S3（余 3） | S1 | S2 |
| S4（余 4） | S3 | S4 |
| S5*（余 0） | S5 | S1 |

S0 读 0 没有转换（进入死状态），所以 `0`、`0101` 都不接受。校验：`101`（5）：S0→S1→S2→S5，接受；`1010`（10）：再读 0 仍在 S5，接受。这个 DFA 已经是最简的。

**B3（例题）设计 DFA，识别所有能被 3 整除的无符号十进制数。**

思路：一个数能被 3 整除当且仅当各位数字之和能被 3 整除，所以只要记录数字和除以 3 的余数。把数字按余数分成三类：`D0 = 0|3|6|9`，`D1 = 1|4|7`，`D2 = 2|5|8`。

解答：S0、S1、S2 表示余 0、余 1、余 2。

| 状态 | D0 | D1 | D2 |
|---|---|---|---|
| S0+* | S0 | S1 | S2 |
| S1 | S1 | S2 | S0 |
| S2 | S2 | S0 | S1 |

同样没要求去掉前导 0，只有 3 个状态。

**B4（考研题）给定一个字符串，判断是否合法：串由 0、1 组成，以 2 结尾；合法要求是不能出现两个 1 串。如 01012 非法，0112 合法。**

思路："1 串"指一段连续的 1。0112 只有一段 1，合法；01012 里两段 1 被 0 隔开，是两个 1 串，非法。状态按"已经见过几段 1"来设：0 表示还没遇到 1；1 表示正在第一段 1 里；2 表示第一段 1 已经结束；再遇到 1 就是第二个 1 串，进入非法状态 3；任何时候读到 2 结束，进入终态 4。

解答：

| 状态 | 0 | 1 | 2 |
|---|---|---|---|
| 0+ | 0 | 1 | 4 |
| 1 | 2 | 1 | 4 |
| 2 | 2 | 3 | 4 |
| 3（非法状态） | 3 | 3 | 3 |
| 4* | | | |

校验：0112 走 0→0→1→1→4，接受；01012 走 0→0→1→2→3→3，拒绝。

**E1（课堂例 1）将下面的 DFA 最小化。**

| 状态 | a | b |
|---|---|---|
| 1+ | 2 | 3 |
| 2 | | 4 |
| 3 | 2 | 3 |
| 4* | 5 | 6 |
| 5 | | 7 |
| 6* | 5 | 6 |
| 7* | 5 | 8 |
| 8* | 5 | 8 |

### G. 自动机 → 正则表达式

**G1（例题）有如下 NFA M，构造与之等价的正则表达式 r。**

NFA M（初态 1，终态 6）：

| 状态 | a | b |
|---|---|---|
| 1+ | 2 | |
| 2 | 3 | 4 |
| 3 | | 5 |
| 4 | 5 | |
| 5 | 5 | 6 |
| 6* | | |

思路：先在两侧加空边，再逐个消去中间状态。

解答：

```text
加 S、Z：S --ε--> 1 --a--> 2，2 --a--> 3 --b--> 5，2 --b--> 4 --a--> 5，5 自环 a，5 --b--> 6 --ε--> Z
消 3、4（串联）：2 --ab--> 5，2 --ba--> 5
合并并联：      2 --ab|ba--> 5
消 5（有自环）：2 --(ab|ba)a*b--> 6
消 2、6 及空边：S --a(ab|ba)a*b--> Z
```

答案：`r = a(ab|ba)a*b`。

### H. 简答题

**H1（高频考点）简述 DFA 和 NFA 有哪些主要区别。**

解答：①NFA 同一状态读同一符号可以有多个后继状态，状态转换函数多值；DFA 的状态转换函数是单值函数，后继唯一。②NFA 允许有多个开始状态（初始状态是集合）；DFA 只有唯一的开始状态。③NFA 允许 ε 边；DFA 不允许。二者识别语言的能力相同，NFA 描述方便，DFA 便于实现。

**H2 为什么要把 NFA 转换成 DFA？确定化后 DFA 的初始状态是什么？**

解答：NFA 描述问题方便，DFA 实现方便；NFA 是把任意正则表达式变成可实现的自动机的中间媒介。确定化后 DFA 的初始状态是 NFA 的初始状态，加上从初始状态出发经空边能到达的所有状态，即 ε-closure(S₀)。求转换时也要考虑空边，经过空边可能到达新的状态。

**H3 词法分析时 `a+++b` 怎样划分单词？**

（整理补充）按最长匹配原则，扫描器每次尽量读最长的合法单词：先读出标识符 `a`；接着 `++` 是合法运算符，而 `+++` 不是，于是得到 `++`；再读出 `+`，最后是 `b`。结果是 `a`、`++`、`+`、`b`。
