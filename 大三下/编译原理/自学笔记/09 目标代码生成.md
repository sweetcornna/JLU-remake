# 目标代码生成

`编译原理笔记/编译原理学习笔记.pdf` 第 176 页这一章只有一句"没来得及整理，2022 级考试的时候只考了选择题"，所以本文件主要从 `编译原理笔记/编译原理期末题型整理.pdf` 第 1 页的高频考点和第 117–121 页 15 道学习通单选题的解析里归纳知识点，另外用到学习笔记第 148–150 页讲寄存器优化、转移性四元式的几段。15 道单选题本身收在 `10 选择题精编.md`。

## 本章要点

- 考试以选择题为主。2022 级选择题第 5 题问"哪个四元式对应的目标代码中产生需要回填的语句"（`软件学院2022级编译原理真题回忆.pdf` 第 2 页）。
- 高频考点：要知道简单语句对应的目标代码长什么样，**赋值对应 2 条，运算对应 3 条**。
- 目标代码质量看**指令条数**和执行速度，条数越少、速度越快越好。
- 绝对机器语言目标代码地址已定位，能直接运行，但不能重定位，只能整个源程序一起编译，适合快速编译执行的小程序；可重定位目标代码由**装入程序**做重定位。
- 寄存器比内存快，能存原始数据和中间结果，运算对象在寄存器里的指令更短；**寄存器最优分配是不可判定的**。
- 目标代码生成阶段符号表的主要用途是**地址分配**。
- 过程语句和函数语句生成目标代码的主要区别是函数要处理**返回值**。
- 需要跳转指令的语句（goto、条件、循环）要用**回填**，赋值语句不用。while 语句里 WHILE 只记入口不跳转，DO 生成等待回填的半条跳转指令，ENDWHILE 生成跳回入口的指令并回填 DO。

## 概念与解释

### 1. 目标代码的形式与重定位

| 形式 | 特点 | 适用 |
| --- | --- | --- |
| 绝对机器语言目标代码 | 所有地址都已定位，在目标机上可以直接运行；不能重定位，缺乏灵活性，通常要把整个源程序一起编译，不能各模块分别独立编译 | 需要快速编译执行的小型程序 |
| 可重定位目标代码 | 地址与某个基地址或起始地址有关，装入时再定位 | 由装入程序处理重定位 |

**装入程序**负责把代码加载到内存以便执行，它处理所有与指定基地址或起始地址有关的可重定位地址，让可执行代码更灵活。

### 2. 目标代码的质量

常用目标指令的**条数**和**执行速度**衡量。同一个源程序翻译出的目标程序，指令条数越少、执行越快，质量越好。指令种类、字长、操作数个数不是衡量标准。

后端相关的优化（学习笔记第 145、148–149 页）：

- 寄存器优化：研究目标程序执行时怎样分配和剥夺目标机的寄存器。
- 目标代码优化：减少目标指令条数。例如两个运算分量都已在寄存器中，就直接运算，不必先存回内存再取出来。

### 3. 寄存器

- 寄存器是计算机系统里最重要的资源之一，存取速度比内存单元快得多。
- 可以保存原始数据和中间计算结果。
- 运算对象在寄存器中的指令比运算对象在内存单元中的指令短，执行也快。
- 寄存器的最优分配方案是不可判定的。

### 4. 符号表和活动记录在这一阶段的用途

- 目标代码生成阶段要根据符号表做**地址分配**；中间代码优化、语义检查、语法检查都不是这个阶段的任务。
- 过/函信息表里的目标代码入口地址和 AR 大小 Size 要等目标代码生成后回填，见 `05 语义分析与符号表.md`。
- 目标机确定以后，目标代码生成阶段可以精确算出每个过程活动记录的大小；同一个函数多次调用生成的 AR 大小相同；运行时 AR 的管理由编译器生成的目标代码在运行时完成。这几句来自学习通单选题第 4 题的正确选项，AR 本身见 `08 运行时存储空间管理.md`。

### 5. 过程与函数

为过程语句和函数语句生成目标代码时，一般认为主要区别只在于函数有返回值要处理，过程没有；其余部分可以同样处理。

### 6. 跳转指令与回填

四元式翻译成目标代码时，是否产生跳转指令由四元式种类决定（与 `07 中间代码优化.md` 里划分基本块用的是同一套分类）：

- **转移性四元式**一定产生跳转指令：`JMP`、`JMP0`、`JMP1`、`THEN`、`ELSE`、`DO`、`ENDWHILE`、`ENDPROC`、`ENDFUNC`。
- **标号性四元式**只起定位作用，不产生跳转指令：`LABEL`、`ENTRY`、`WHILE`、`ENDIF`。

**回填**：生成向前跳转的指令时，目标地址还没生成出来，只能先把地址空着（"半条指令"），等目标位置确定后再填上。goto 语句、条件语句、循环语句都要用跳转指令，而且跳转目的地址暂时无法确定，所以都要回填；赋值语句不用跳转指令，不需要回填。

while 语句 `while E do S` 的三个四元式：

| 四元式 | 生成目标代码时做什么 | 跳转指令 | 回填 |
| --- | --- | --- | --- |
| `(WHILE, -, -, -)` | 只记下循环入口地址 | 不产生 | 无 |
| `(DO, t, -, -)` | 条件不满足时要跳到循环结束后的下一条指令，这个地址还不知道，先生成半条跳转指令 | 产生 | 等待被回填 |
| `(ENDWHILE, -, -, -)` | 生成跳回循环入口的无条件跳转；此时出口位置已知，回填 DO 留下的半条指令 | 产生 | 做回填动作 |

条件语句 `if E then S1 else S2` 可以类比（整理补充，依据学习笔记第 150 页各四元式的跳转含义）：`THEN` 生成"E 为假时跳到 S2 开头"的指令，目标地址待回填；`ELSE` 生成"跳过 S2 到 ENDIF"的半条指令，并把 S2 的开头地址回填给 THEN；`ENDIF` 只定位，把当前地址回填给 ELSE。

### 7. 一条四元式对应几条目标指令

高频考点原话是"赋值对应 2 条，运算对应 3 条"。下面用示意指令说明为什么是这个数（整理补充；指令助记符只是示意，课程目标机的具体写法以课件为准）：

```text
(ASSIG, a, -, x)        MOV  R, a      ; 把 a 取到寄存器 R
                        MOV  x, R      ; 把 R 存入 x              共 2 条

(ADDI, a, b, t)         MOV  R, a      ; 取第一个运算分量
                        ADD  R, b      ; 与第二个运算分量相加
                        MOV  t, R      ; 结果存入 t               共 3 条
```

赋值是"取、存"两步，二元运算是"取、算、存"三步。这是逐条翻译、不做寄存器优化时的条数；如果运算分量已经在寄存器里，可以省掉取数指令。

## 易混对比

| 对比项 | 绝对机器语言目标代码 | 可重定位目标代码 |
| --- | --- | --- |
| 地址 | 已全部定位 | 相对基地址，装入时定位 |
| 能否直接运行 | 能 | 要由装入程序重定位 |
| 模块能否分别编译 | 不能，整个源程序一起编译 | 可以 |
| 适用 | 快速编译执行的小型程序 | 一般程序 |

| 语句 | 是否用跳转指令 | 是否需要回填 |
| --- | --- | --- |
| 赋值语句 | 否 | 否 |
| goto 语句 | 是 | 是 |
| 条件语句 | 是 | 是 |
| 循环语句 | 是 | 是 |

## 典型题

### 题 1：写出语句对应的目标代码条数（题型整理第 1 页高频考点）

题目（整理补充的练习）：`x := a + b * c`（均为整型变量）逐条翻译成目标代码，共多少条指令？

思路：先写四元式，再按"运算 3 条、赋值 2 条"数。

解答：

```text
(MULTI, b, c, t1)     3 条：取 b，乘 c，存 t1
(ADDI, a, t1, t2)     3 条：取 a，加 t1，存 t2
(ASSIG, t2, -, x)     2 条：取 t2，存 x
```

不做寄存器优化时共 8 条。t1、t2 的结果如果留在寄存器里直接用，条数还能减少，这就是目标代码优化要做的事。

### 题 2：哪些语句的翻译用到了回填技术（简答）

2020 级期末简答题问过"在目标代码生成过程中哪些语句的翻译用到了回填技术，请至少列举两种语句"（原卷见 `33 历年题（2016–2022级）.md`）。

答（依据学习通单选题第 14 题解析）：goto 语句、条件语句、循环语句。它们生成目标代码时都要用跳转指令，而跳转目的地址暂时无法确定，只能先空着，等以后回填。赋值语句不用跳转指令，不需要回填。

### 题 3：while 语句各四元式在目标代码生成时做什么

答（依据学习通单选题第 11、12 题解析）：入口四元式 `(WHILE, , ,)` 只标记入口地址，不生成跳转指令；DO 四元式 `(DO, t, _, _)` 在循环条件不满足时要跳到循环结束后的下一条指令，处理时生成半条指令等待回填；出口四元式 `(ENDWHILE, , ,)` 生成跳回循环入口的指令，并对 DO 留下的半条指令中的地址进行回填。
