## 建议学习顺序

1. 先读 01 把全课地图和术语过一遍，再读 02，把"大数据 → 云计算 → 集群/网格/云"这条线串起来。概念多但不难，主要是名词解释。
2. 03 单独占一块。MPI 那部分和后面的存储系统关系不大，但考试会考六个基本函数和五种群集通信，建议早点背完扔一边。
3. 04、05、06 是全课的理论内核。顺序不能换：先有单机存储引擎（04），再有事务和协议（05），最后才是把数据摊到多台机器上（06）。
4. 07、08、09、10 是四个真实系统。读法是每个系统都回答同样五个问题：数据怎么分布、副本怎么放、一致性保证到什么程度、故障怎么恢复、负载怎么均衡。01 里的对比表就是按这五个问题排的。
5. 11 放在最后，把所有数字算一遍。这门课的计算题几乎都是"给容量和单条元数据大小，问能支持多少数据"这种形式。

时间只剩一两天时的压缩路线见 01 末尾的"复习节奏建议"。

## 考试信息

源笔记里没有写复习范围、题型或分值，这里不做推测。从笔记的详略可以看出老师讲得最细的是 GFS、Dynamo、Bigtable 三个系统，以及一致性哈希、Paxos、LSM 树三个机制。
