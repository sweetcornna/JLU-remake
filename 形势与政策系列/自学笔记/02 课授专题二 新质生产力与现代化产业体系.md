# 课授专题二 建设与新质生产力相适应的现代化产业体系

整理自 `形势与政策3开卷宝典.pdf` 第一篇"课授专题"的专题二（PDF 第 11 至 16 页，页眉上印的页号是 7 至 12）。时事报告部分还有一讲专门讲新质生产力，两处重复的地方在 `05 时事专题 加快发展新质生产力.md` 里对照着看。

## 本专题脉络

四段：先定义两个概念（新质生产力、现代化产业体系）并说清两者关系，再讲为什么要建（三条意义），再讲现在什么样（四项现状、四项挑战），最后讲怎么建（六个强国加三中全会的四条机制）。定义那一段是全篇最需要逐字背的。

## 一、新质生产力与现代化产业体系

### （一）什么是新质生产力

官方定义出自 2024 年 1 月 31 日二十届中央政治局第十一次集体学习。拆成五句记：

1. 创新起主导作用；
2. 摆脱传统经济增长方式、生产力发展路径；
3. 具有高科技、高效能、高质量特征；
4. 符合新发展理念；
5. 是先进生产力质态。

配套的三句判断也常考：**特点是创新，关键在质优，本质是先进生产力**。

四个内涵，按"理念—要素—标志—催生"的顺序背：

| 序号 | 内涵 |
| --- | --- |
| 一 | 是符合新发展理念的先进生产力质态 |
| 二 | 以劳动者、劳动资料、劳动对象及其优化组合的跃升为基本内涵 |
| 三 | 以全要素生产率大幅提升为核心标志，具有高科技、高效能、高质量特征 |
| 四 | 由技术革命性突破、生产要素创新性配置、产业深度转型升级而催生 |

**内涵一：符合新发展理念。** 新发展理念五个字各自对应一层意思，原书每个都配了例子：

| 理念 | 在新质生产力里的含义 | 原书例子 |
| --- | --- | --- |
| 创新 | 涉及领域新、技术含量高 | 智能导盲犬：我国约有视障人士 1731 万名，现役导盲犬仅 400 多只，培训成本高周期长，人工智能加传感器和导航技术可以补这个缺口 |
| 协调 | 强化区域间、城乡间、产业间协同合作 | 安徽天长从"汗水农业"到"智慧农业" |
| 绿色 | 资源节约、环境友好型技术，绿色低碳循环可持续的生产方式 | 通榆县引进装备制造企业 10 家，装备制造业年产值可达 30 亿元以上，可生产制造风电全产业链，实现"一站式采购" |
| 共享 | 普惠性，成果共享 | 数字经济和数据要素边际使用成本极低 |
| 开放 | 学习国际先进技术，提升创新能力 | 进博会上高通的 5G 无界 XR 赛事设备 |

**内涵二：三要素的跃升。** 生产力三要素是劳动者、劳动对象、劳动资料。

- 劳动者：更高素质的劳动者是第一要素。新型劳动者分两类，一类是能创造新质生产力的创新型战略人才（顶尖科技人才、科技领军人才、卓越工程师、大国工匠、优秀企业家），一类是能熟练掌握新质生产资料的应用型人才。我国研发人员总量多年保持世界首位，研发人员全时当量从 2012 年的 325 万人增加到 2022 年的 635 万人。
- 劳动资料：更高精尖的劳动工具是动力源泉，新型生产工具更智能、更高效、更低碳、更安全。
- 劳动对象：更广泛的劳动对象是物质基础，获取物质和能量的范围扩展到深空、深海、深地。

要素流动的四个词也可能出填空：便捷化流动、网络化共享、系统化整合、协作化开发、高效化利用。

**内涵三：全要素生产率与三高。**

| 特征 | 含义 |
| --- | --- |
| 高科技 | 以科技创新为核心，知识技术密集，智能化，提升产业技术密集度和产品技术含量 |
| 高效能 | 优化资源配置，提升生产效率，提高整体经济效益 |
| 高质量 | 注重环境保护和可持续发展，优化产业链整体，降低能耗和排放 |

全要素生产率的定义（原书在时事报告第三讲的词语解释里）：经济增长中扣除劳动、资本等要素投入数量因素的贡献后的余值，也就是靠更有效配置资源实现的额外增长，通常表现为技术进步、体制改革和组织管理改善等无形要素的作用。

**内涵四：三个催生。**

- 技术革命性突破：每一次重大科技革命都始于划时代的颠覆性技术创新。当前两大方向是数字化和绿色化，两者融合催生大量新领域新赛道。
- 生产要素创新性配置：技术、资金、人才、劳动力、数据、土地、管理、知识等要素重新组合。例子是宁夏中卫西部云基地的数据中心，八个国家算力枢纽节点之一，数据中心向"智算中心"升级，"东数西算"工程带动效应明显。
- 产业深度转型升级：例子是江西樟树的中医药产业，仁和医药电商物流园投资 12 亿元，"云仓储+云物流"智慧物流模式，日分拣量约 11 万单，拣选准确率可达 99.99%。

### （二）什么是现代化产业体系

学理链条：产业 → 产业结构 → 产业体系。

内涵的"四梁八柱"，注意四个定位词不要串：

| 组成 | 定位 |
| --- | --- |
| 现代化的工业 | 基础和核心 |
| 现代化的农业 | 重要根基 |
| 现代化的服务业 | 重要支撑 |
| 现代化的基础设施 | 重要保障 |

目标要求是"三化三性"，六个词各带一句解释：

| 词 | 解释 |
| --- | --- |
| 智能化 | 把握人工智能等新科技革命浪潮 |
| 绿色化 | 实现人与自然和谐共生 |
| 融合化 | 提升产业体系整体效能 |
| 完整性 | 保持并增强产业体系完备、配套能力强的优势 |
| 先进性 | 高效集聚全球创新要素，自主拓展产业新赛道 |
| 安全性 | 实现重要产业链自主可控，确保国民经济循环畅通 |

前三个是"推进产业……"的动作，后三个是"建设具有……的现代化产业体系"的属性，这样分组就不容易记反。

### （三）两者的关系

产业是经济之本，是生产力变革的具体表现形式。发展新质生产力要求因地制宜，抓住高质量发展这个首要任务，培育壮大新兴产业、超前布局未来产业、完善现代化产业体系。简单说，新质生产力是内核，现代化产业体系是载体。

## 二、为什么意义重大（三条）

1. **推动高质量发展的必然要求。** 创新是高质量发展的第一动力。新质生产力以科技创新为主导，我国在全球创新指数中的排名升至第 12 位，全球百强科技创新集群数量跃居世界第一。产业体系是国民经济循环体系的动力和基础，要求各产业有序链接、高效匹配，实体经济、科技创新、现代金融、人力资源协同发展。
2. **赢得大国竞争主动的迫切需要。** 维护产业链供应链安全稳定，筑牢国家发展的安全根基。
3. **全面建设社会主义现代化国家的重大举措。** 别国经验表明，成功实现现代化的国家都经历过产业体系现代化，没有现代化产业就会掉队甚至落入"中等收入陷阱"。

## 三、现状与挑战

### 四项现状

| 方面 | 关键数据 |
| --- | --- |
| 工业核心竞争力明显增强 | 2023 年全部工业增加值 39.9 万亿元，占国内生产总值 31.7%；制造业增加值占全球比重超过 30%，连续 14 年位列全球第一；制造业创新能力从跟跑到并跑再到领跑 |
| 农业基础地位不断巩固 | 粮食产量连续 9 年稳定在 1.3 万亿斤以上；建成 10 亿亩高标准农田，农作物耕种收综合机械化率 73% |
| 服务业质量效益持续提升 | 就业"蓄水池"功能明显，撑起国民经济"半边天"，服务贸易连续多年位居世界第二 |
| 基础设施建设快速发展 | 2022 年末综合交通网总里程超过 600 万公里；特大型水利工程、三代核电、工业互联网跨越式发展；离岸深水港、枢纽机场建造技术进入世界先进或领先行列 |

### 四项挑战

1. **传统产业转型滞缓与新兴产业发展不充分。** 传统行业里企业规模小、结构单一、附加值低，例如纺织服装产品质量不高、品牌认知度低，钢铁污染排放大、绿色转型难，石化受长期粗放式增长影响结构性问题突出。新兴产业"高端产业、低端环节"问题突出，装备制造、航天航空、数字经济与发达经济体仍有较大差距。
2. **创新力和引领力不足。** 芯片、高端装备、新能源等领域的核心技术和关键零部件仍依赖进口，科技创新"跟跑"局面没有根本扭转。世界知识产权组织《2023 年全球创新指数报告》中我国排第 12 位；世界 500 强里制造业企业占比较大，但高新技术企业和独角兽企业中制造业企业数量较少。
3. **产业链供应链安全保障能力有待提升。** 高端芯片、先进材料制备、现代轨道交通、航空发动机的核心技术和关键零部件存在短板，部分关键节点可选择的合作方很少，美国的贸易保护行为加剧了风险。
4. **产业绿色转型面临较大压力。** 传统发展观念难以转变，农产品加工、石化、纺织服装、钢铁等行业能耗过高、环境污染问题仍然存在。

## 四、建设现代化产业体系的路径

### 顶层依据

- 党的二十大报告：坚持把发展经济的着力点放在实体经济上，推进新型工业化，加快建设制造强国、质量强国、航天强国、交通强国、网络强国、数字中国。
- 二十届三中全会《决定》"健全推动经济高质量发展体制机制"：以新发展理念引领改革，深化供给侧结构性改革，塑造发展新动能新优势。

### 六个强国（六条主线）

**1. 制造强国。** 实施产业基础再造工程和重大技术装备攻关工程，支持专精特新企业发展，推动制造业高端化、智能化、绿色化发展。

**2. 质量强国。** 依据是中共中央、国务院印发的《质量强国建设纲要》。

| 时间点 | 目标 |
| --- | --- |
| 到 2025 年 | 质量整体水平进一步全面提高，中国品牌影响力稳步提升，质量强国建设取得阶段性成效 |
| 到 2035 年 | 质量强国建设基础更加牢固，先进质量文化蔚然成风，质量和品牌综合实力达到更高水平 |

《纲要》从宏观经济发展、中观产业竞争、微观市场建设三个层面展开，路径包括区域质量、重点产品、建设工程、服务品质四大项，以及质量安全监管、质量基础设施、品牌建设三项制度性建设工程。七项重点工程：区域质量发展示范工程、重点产品质量阶梯攀登工程、建设工程质量管理升级工程、服务品质提升工程、中国品牌建设工程、质量基础设施升级增效工程、质量安全监管筑堤工程。

**3. 航天强国。** 三个关键词：重在"加快"、重在"全面"、重在"创新"。时间表要能排序：

| 时间 | 目标 |
| --- | --- |
| 2025 年 | 实现"十四五"规划圆满收官 |
| 2027 年 | 为实现建军一百年奋斗目标提供装备支撑 |
| 2030 年 | 推动我国跻身航天强国前列 |
| 2045 年 | 全面建成航天强国 |

**4. 交通强国。** 依据是《加快建设交通强国五年行动计划（2023—2027 年）》，构建十大行动框架，提出 53 项重点任务。十大行动：现代化综合交通基础设施建设、运输服务质量提升、交通运输服务乡村振兴和区域协调发展、交通运输科技创新驱动、交通运输绿色低碳转型、交通运输安全生产强化、交通运输开放合作提升、交通运输人才队伍建设、交通运输深化改革提升管理能力、加强党的建设。

**5. 网络强国。** 目标四句话：网络基础设施基本普及、自主创新能力明显增强、信息经济全面发展、网络安全保障有力（2014 年 2 月 27 日中央网络安全和信息化领导小组第一次会议提出）。

| 指标 | 数据 |
| --- | --- |
| 移动通信 | 从"3G 突破""4G 同步"到"5G 引领"；截至 2023 年 3 月底累计建成 5G 基站超过 264 万个 |
| 网民规模 | 从 2012 年 5.64 亿增长到 2022 年 12 月的 10.67 亿，互联网普及率从 42.1% 提升到 75.6% |
| 立法 | 出台《网络安全法》《数据安全法》《个人信息保护法》等网络领域立法 140 余部 |
| 数字经济 | 2021 年规模超 45 万亿元，连续多年世界第二，是 2012 年的 4 倍多，占 GDP 比重 39.8% |
| 政务服务 | 电子政务在线服务指数全球排名升至第九位；截至 2022 年 12 月全国一体化政务服务平台注册用户超 10 亿人 |
| 治理 | "清朗"系列专项行动，截至 2022 年 8 月针对"饭圈"乱象、直播和短视频乱象等开展 30 多项专项整治 |
| 国际合作 | 截至 2022 年 8 月与 81 个国家和地区的 274 个网络安全应急响应组织建立合作伙伴关系 |
| 公共服务 | 建成全球规模最大的线上教育平台和全国统一的医保信息平台，远程医疗覆盖超过全国 90% 的县区 |

**6. 数字中国。** 依据是《数字中国建设整体布局规划》。整体框架叫 **"2522"**，这是最容易考的一个编号：

| 数字 | 含义 |
| --- | --- |
| 2 | 夯实数字基础设施和数据资源体系"两大基础" |
| 5 | 推进数字技术与经济、政治、文化、社会、生态文明建设"五位一体"深度融合 |
| 2 | 强化数字技术创新体系和数字安全屏障"两大能力" |
| 2 | 优化数字化发展国内国际"两个环境" |

主要目标：到 2025 年基本形成横向打通、纵向贯通、协调有力的一体化推进格局，数字中国建设取得重要进展；到 2035 年数字化发展水平进入世界前列。服务经济社会发展的五个方向：做强做优做大数字经济，发展高效协同的数字政务，打造自信繁荣的数字文化，构建普惠便捷的数字社会，建设绿色智慧的数字生态文明。组织实施保障五句话：加强组织领导、健全体制机制、保障资金投入、强化人才支撑、营造良好氛围。

### 党的二十届三中全会的四条机制

原书在这一专题末尾单列，和 `08 三个文件速查.md` 里《决定》第三部分是同一批内容。

1. 健全因地制宜发展新质生产力体制机制：推动三个"性"（技术革命性突破、生产要素创新性配置、产业深度转型升级），加强关键共性技术、前沿引领技术、现代工程技术、颠覆性技术创新，建立未来产业投入增长机制；鼓励和规范发展天使投资、风险投资、私募股权投资，发展耐心资本。
2. 完善发展服务业体制机制：优化服务业核算，推进标准化建设，破除跨地区经营行政壁垒，健全生活性服务业多样化发展机制，规范中介服务机构。
3. 健全现代化基础设施建设体制机制：构建新型基础设施规划和标准体系，推进传统基础设施数字化改造，推进铁路体制改革，发展通用航空和低空经济。
4. 健全提升产业链供应链韧性和安全水平制度：打造自主可控的产业链供应链，重点是集成电路、工业母机、医疗装备、仪器仪表、基础软件、工业软件、先进材料；建设国家战略腹地和关键产业备份，完善国家储备体系。

## 易混对照

| 容易混的一组 | 区别 |
| --- | --- |
| 新质生产力的"三特征" / "三催生" | 三特征是高科技、高效能、高质量，说的是结果；三催生是技术革命性突破、生产要素创新性配置、产业深度转型升级，说的是来源 |
| 特点 / 关键 / 本质 | 特点是创新，关键在质优，本质是先进生产力。三个词各配一个，不要互换 |
| 生产力三要素 | 劳动者、劳动资料、劳动对象。劳动者是第一要素，劳动资料是动力源泉，劳动对象是物质基础 |
| 现代化产业体系四梁八柱 | 工业是基础和核心，农业是重要根基，服务业是重要支撑，基础设施是重要保障 |
| 三化 / 三性 | 智能化、绿色化、融合化是推进方向；完整性、先进性、安全性是体系属性 |
| 六个强国 | 制造强国、质量强国、航天强国、交通强国、网络强国、数字中国。注意最后一个叫"数字中国"而不是"数字强国" |
