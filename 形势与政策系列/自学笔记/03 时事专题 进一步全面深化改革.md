# 时事专题 进一步全面深化改革（第一讲）

整理自 `形势与政策3开卷宝典.pdf` 第二篇"时事报告"第一讲"改革的实践续篇 现代化的时代新篇"（PDF 第 18 至 27 页，页眉上印的页号是 14 至 23），包括正文三节和后面六个"链接"（权威声音、观点、数据、历史由来、国际视野、案例）。原书是《时事报告》体裁的长文，这里按考点压成要点，长段论述没有照抄。

## 本专题脉络

正文三节分别回答三个问题：过去十来年改革做了什么（把握历史主动）、这次三中全会要改什么（锚定关键领域）、靠什么保证改对（遵循改革规律）。考点最集中的是第二节的"总目标+七个聚焦+时间表"和第三节的"六个坚持"，以及链接四的历届三中全会对照表。

事件坐标：党的二十届三中全会于 2024 年 7 月召开，审议通过《中共中央关于进一步全面深化改革、推进中国式现代化的决定》（以下简称《决定》），通过时间是 2024 年 7 月 18 日。

## 一、把握历史主动：新时代改革的三条判断

原文分三个"第一、第二、第三"，各自一句话概括：

1. **党中央一以贯之推进改革，决心之大、变革之深、影响之广前所未有。** 十八大作出全面深化改革的战略部署；十八届三中全会确定总目标、战略重点、优先顺序、主攻方向、工作机制、推进方式和时间表路线图；此后历次中央全会的改革部署都纳入同一个盘子统筹推进，先后推出 3100 多项改革举措。
2. **改革是全方位、深层次、根本性的。** 从理论上正本清源、从制度上立柱架梁、从实践上有力推进。标志性成果比如创造性提出使市场在资源配置中起决定性作用和更好发挥政府作用。
3. **成就是历史性、革命性、开创性的。** 各领域基础性制度框架基本建立，许多领域实现历史性变革、系统性重塑、整体性重构。

第三条下面还有一串分领域的成果，记住"四个深刻变革"这个收束句就够：全面深化改革是一场思想理论的深刻变革、一场改革组织方式的深刻变革、一场国家制度和治理体系的深刻变革、一场人民广泛参与的深刻变革。

## 二、锚定关键领域：总目标、七个聚焦、时间表

### 1. 改革没有完成时（四个"迫切需要"）

| 迫切需要 | 指向 |
| --- | --- |
| 凝聚人心、汇聚力量，实现新时代新征程党的中心任务 | 把中国式现代化蓝图变为现实 |
| 完善和发展中国特色社会主义制度、推进国家治理体系和治理能力现代化 | 制度还有不完善、体系还不够健全的地方 |
| 推动高质量发展、更好适应社会主要矛盾变化 | 市场体系不健全、创新能力不适应、关键核心技术受制于人、城乡区域和收入分配差距较大 |
| 应对重大风险挑战、推动党和国家事业行稳致远 | 百年变局加速演进，"黑天鹅""灰犀牛"事件随时可能发生 |

### 2. 总目标与时间表

- 总目标：**继续完善和发展中国特色社会主义制度，推进国家治理体系和治理能力现代化。** 与十八届三中全会的总目标只差"继续"二字，是一脉相承的。
- 到 2035 年：全面建成高水平社会主义市场经济体制，中国特色社会主义制度更加完善，基本实现国家治理体系和治理能力现代化，基本实现社会主义现代化。
- 到 2029 年（中华人民共和国成立 80 周年）：完成《决定》提出的改革任务。《决定》以 5 年为期安排落实。
- 《决定》提出 300 多项重要改革举措。

### 3. 七个聚焦（对照十八届三中全会的"六个紧紧围绕"）

十八届三中全会提"六个紧紧围绕"，分别对应经济、政治、文化、社会、生态文明、党的建设六个领域的改革。《决定》提"七个聚焦"，**多出来的是安全领域**，其余六项内容也作了丰富。

| 领域 | 聚焦什么 | 提出的要求 |
| --- | --- | --- |
| 经济 | 构建高水平社会主义市场经济体制 | 推进高水平科技自立自强，推进高水平对外开放，建成现代化经济体系，加快构建新发展格局，推动高质量发展 |
| 政治 | 发展全过程人民民主 | 人民当家作主制度更加健全、协商民主广泛多层制度化发展、中国特色社会主义法治体系更加完善 |
| 文化 | 建设社会主义文化强国 | 坚持马克思主义在意识形态领域指导地位的根本制度，丰富人民精神文化生活 |
| 社会 | 提高人民生活品质 | 推动人的全面发展、全体人民共同富裕取得更为明显的实质性进展 |
| 生态文明 | 建设美丽中国 | 加快经济社会发展全面绿色转型，健全生态环境治理体系，推进生态优先、节约集约、绿色低碳发展 |
| 安全 | 建设更高水平平安中国 | 健全国家安全体系，强化一体化国家战略体系，创新社会治理体制机制和手段，有效构建新安全格局 |
| 党建 | 提高党的领导水平和长期执政能力 | 创新和改进领导方式和执政方式，健全全面从严治党体系 |

## 三、遵循改革规律：六个坚持

"六个坚持"是这一讲最该背的一组，原文说它是"成功密码"。

| 坚持 | 一句话要点 |
| --- | --- |
| 坚持党的全面领导 | 无论改什么、改到哪一步都要坚持党的领导，发挥党总揽全局、协调各方的领导核心作用 |
| 坚持以人民为中心 | 把促进社会公平正义、增进人民福祉作为出发点和落脚点，以人民群众获得感幸福感安全感作为检验改革成效的根本标准 |
| 坚持守正创新 | 既不走封闭僵化的老路，也不走改旗易帜的邪路；推进理论、实践、制度、文化等各方面创新 |
| 坚持以制度建设为主线 | 加强顶层设计、总体谋划，破立并举、先立后破，筑牢根本制度、完善基本制度、创新重要制度 |
| 坚持全面依法治国 | 在法治轨道上深化改革，做到改革和法治相统一，重大改革于法有据，及时把改革成果上升为法律制度 |
| 坚持系统观念 | 处理好经济和社会、政府和市场、效率和公平、活力和秩序、发展和安全等重大关系，增强改革系统性、整体性、协同性 |

《决定》原文里"六个坚持"是作为"进一步全面深化改革的原则"写的，措辞与这里基本一致，见 `08 三个文件速查.md`。

## 链接六 案例（论述题素材）

- **自贸试验区。** 2013 年至今分 7 批设立 22 个自贸试验区，覆盖东西南北中。国家层面已总结 7 批改革试点经验、5 批最佳实践案例，向全国复制推广 349 项制度创新成果。浙江聚焦油气全产业链累计形成 61 项制度创新成果；陕西杨凌是全国唯一农业特色鲜明的自贸片区，累计形成 70 多项创新案例，其中 7 项全国复制推广；福州自贸片区推出 20 批共 288 项创新举措，其中国家级首创 110 项。
- **以人民为中心。** 上海市长宁区虹桥街道是全国人大常委会法工委设立的首批基层立法联系点之一；北京 12345 市民热线话务大厅有 1700 多名工作人员，全年 7×24 小时受理市民诉求。
- **法治与改革同频。** 现行有效的 303 件法律中，十八届三中全会后新制定的有 78 件，其中 147 部法律先后累计修改 334 件次。授权改革的例子：2020 年 4 月全国人大常委会授权国务院在海南自由贸易试验区暂时调整适用土地管理法等 3 部法律的有关规定。制度成果上升为法规的例子：《中华人民共和国市场主体登记管理条例》。
- **世界贡献。** 截至 2024 年 3 月，我国提议筹建的亚洲基础设施投资银行已批准 260 个项目，批准融资总额超过 510 亿美元，动员 1600 亿美元资本。
- **一张营业执照。** 1980 年 12 月，开小杂货铺的章华妹领到中国第一份个体工商业营业执照（改革开放后第一张），地点在浙江温州。两年后温州个体工商企业注册数超过 10 万户。到 1987 年，全国城镇个体工商等各行业从业人员达到 569 万人。截至 2024 年 5 月底，我国民营经济主体总量 18045 万户，占所有经营主体的 96.4%，其中民营企业 5517.7 万户、个体工商户 12527.3 万户。

## 易混对照

| 容易混的一组 | 区别 |
| --- | --- |
| 六个紧紧围绕 / 七个聚焦 | 前者是十八届三中全会，六个领域；后者是二十届三中全会，多了安全领域 |
| 六个坚持 / 七个聚焦 | 六个坚持是原则（怎么改），七个聚焦是目标（改哪里） |
| 3100 多项 / 300 多项 | 十八大以来先后推出 3100 多项改革举措；《决定》这一次提出 300 多项重要改革举措 |
| 2029 年 / 2035 年 | 2029 年是《决定》改革任务的完成期限（建国 80 周年）；2035 年是基本实现社会主义现代化的时间节点 |
| 总目标的两句话 | 前一句"完善和发展中国特色社会主义制度"规定根本方向，后一句"推进国家治理体系和治理能力现代化"规定具体指向，只讲第二句是不完整的 |
| 十八届三中全会 / 二十届三中全会 | 前者是全面深化改革的"实践续篇"的起点，后者是"时代新篇"；前者总体完成了自己确定的改革任务，后者接着往下改 |
