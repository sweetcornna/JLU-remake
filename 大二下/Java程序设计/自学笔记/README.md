# Java 程序设计自学指南

这个目录整理自课程目录下的 `Java实验.pdf`，那是一份 9 页的实验题与参考代码汇编，共 8 道实验题。原文件没动，每个整理稿开头写了出处。

讲义内容不在这里重复，第 1、2 章看 `../重制版PPT/` 下的重制版课件，第 3 章往后看 `../课件/`。

## 资料清单

| 文件 | 内容 | 什么时候用 |
|---|---|---|
| `01 类与对象、异常处理.md` | 实验一 Point 与 Triangle 求面积、实验二 Scanner 累加并忽略非整数 | 学完第 3～5 章（类、对象、异常）后做 |
| `02 接口与反射、Swing 界面.md` | 实验三 ComputeTime 用接口解耦交通工具、实验四 ColorPane 九宫格按钮变色 | 学完接口和 GUI 两章后做 |
| `03 集合与文件读写.md` | 实验五 HashMap 模拟购物车、实验六 复制 `HelloWorldDemo.java` 到 `.txt` | 学完集合框架和 IO 流后做 |
| `04 多线程与套接字通信.md` | 实验七 5 个线程模拟售票、实验八 端口 1888 的客户机/服务器程序 | 学完线程和网络编程后做 |
| `10 常见错误速查.md` | 八道题里容易出错的地方汇总，按题型归类 | 考前过一遍，编程题卡住时查 |

每份整理稿都是"题目 → 原稿代码 → 逐段说明 → 运行结果 → 容易出错的地方"的结构。

标"更正：原文作 …"的是原稿写错、整理时改过的地方，一共两处，都在实验六：读文件用的绝对路径换成了相对路径，循环里多余的 `assert false;` 删掉了。标"整理补充"的是原稿缺失、整理时补上的内容：实验三的 `Car007.java`、实验四的题面、实验五的完整答案。另外实验三的原稿改用 `Scanner` 从标准输入读参数，和题面要求的命令行参数不一致，`02` 里两种写法都给了。

本机没有装 JDK，所有代码都是逐行人工核对的，数值结果用 Python 按 Java 语义（`double` 用 IEEE 双精度、`float` 用单精度、`Math.sqrt` 用正确舍入的平方根）算了一遍。**这些程序都没有真正编译运行过**，抄进 IDE 后自己跑一遍再交。

## 建议学习顺序

1. 先看[实验一、实验二](<01 类与对象、异常处理.md>)。这两题只用到类、构造方法、`Math` 和 `try-catch`，是后面几题的基础。
2. [实验三](<02 接口与反射、Swing 界面.md>)是八题里思路最值得琢磨的一道，要点是"新增交通工具不改旧代码"怎么做到。实验四的 Swing 代码长但重复，看懂一个按钮就看懂九个。
3. [实验五、实验六](<03 集合与文件读写.md>)是 API 使用题，记住 `HashMap` 的遍历写法和字节流四件套（`FileInputStream` / `BufferedInputStream` / `FileOutputStream` / `BufferedOutputStream`）。
4. [实验七、实验八](<04 多线程与套接字通信.md>)是期末编程题的常客。售票题要能默写 `synchronized` 双重判断，套接字题要能默写服务端和客户端各五六行的骨架。
5. 考前把 [`10 常见错误速查.md`](<10 常见错误速查.md>) 过一遍。
