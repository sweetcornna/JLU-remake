## 实验一 用 Point 类构建 Triangle 类求面积

题目：设计 Point 类并用此类构建一个三角形类（Triangle），编程求三角形的面积。请把程序代码和输出结果的截图提交到答案中。

### 参考代码

```java
import java.util.Scanner;   //用于读取输入

class Point {
    double x;
    double y;

    public Point(double i, double j) {
        x = i;
        y = j;
    }

    public double distance(Point p) {
        return Math.sqrt((p.x - this.x) * (p.x - this.x) + (p.y - this.y) * (p.y - this.y));
    }
}

class Triangle {
    Point a;
    Point b;
    Point c;

    public Triangle(Point x, Point y, Point z) {
        a = x; b = y; c = z;
    }

    public void Area() {
        double s1 = a.distance(b);    //计算a和b之间的距离
        double s2 = b.distance(c);
        double s3 = c.distance(a);
        if (s1 + s2 > s3 && s1 + s3 > s2 && s2 + s3 > s1) {
            double p = (s1 + s2 + s3) / 2;
            double area = Math.sqrt(p * (p - s1) * (p - s2) * (p - s3));
            System.out.println("此三角形面积为：" + area);
        } else
            System.out.println("此三边不能构成三角形");
    }
}

public class E1_03 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        double x1, x2, x3, y1, y2, y3;
        System.out.println("请输入第一个点的坐标(x,y)：");
        x1 = sc.nextDouble();
        y1 = sc.nextDouble();
        System.out.println("请输入第二个点的坐标(x,y)：");
        x2 = sc.nextDouble();
        y2 = sc.nextDouble();
        System.out.println("请输入第三个点的坐标(x,y)：");
        x3 = sc.nextDouble();
        y3 = sc.nextDouble();
        Point a = new Point(x1, y1);
        Point b = new Point(x2, y2);
        Point c = new Point(x3, y3);
        Triangle test = new Triangle(a, b, c);
        test.Area();
    }
}
```

### 思路

三个职责分给三个类：`Point` 只管坐标和两点距离，`Triangle` 只管三边和面积，`E1_03` 只管读输入。这种分法就是这道题的考点，把距离公式写进 `Triangle` 里也能出结果，但 `Point` 就成了只有两个字段的空壳。

`distance` 里的 `this` 指调用方法的那个点，`p` 是参数点，两点距离用的是勾股定理：

$$d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$$

面积用海伦公式， $p$ 是半周长：

$$S=\sqrt{p(p-a)(p-b)(p-c)},\quad p=\frac{a+b+c}{2}$$

三边先判断两边之和大于第三边，三个不等式都要写。三点共线时三条边恰好满足 $s_1+s_2=s_3$，`>` 是严格不等号，会走到 else 分支，所以共线的情况也被挡住了。

文件名必须是 `E1_03.java`，因为 `E1_03` 是 public 类。`Point` 和 `Triangle` 不带 public，可以和它写在同一个文件里。

### 运行结果

输入 `(0,0)`、`(4,0)`、`(0,3)`（三边 3、4、5 的直角三角形）：

```
请输入第一个点的坐标(x,y)：
0 0
请输入第二个点的坐标(x,y)：
4 0
请输入第三个点的坐标(x,y)：
0 3
此三角形面积为：6.0
```

输入 `(0,0)`、`(1,1)`、`(2,2)`（三点共线）：

```
此三边不能构成三角形
```

### 容易出错的地方

1. 海伦公式的浮点误差。输入 `(0,0)`、`(1,0)`、`(0,1)`，数学上面积是 0.5，程序会打印 `0.49999999999999983`；输入 `(0,0)`、`(2,0)`、`(1,1)` 会打印 `0.9999999999999996`。原因是斜边 $\sqrt2$ 存成 double 有误差，半周长和三个差值一连乘误差就放大了。程序本身没写错，交作业截图时看到这种结果不用慌。想要漂亮的数就用叉积公式，它只有加减乘，没有开方：

   $$S=\frac{1}{2}\left|(x_2-x_1)(y_3-y_1)-(x_3-x_1)(y_2-y_1)\right|$$

   对应代码 `double area = Math.abs((b.x-a.x)*(c.y-a.y) - (c.x-a.x)*(b.y-a.y)) / 2;`，上面两组输入会规规矩矩打印 `0.5` 和 `1.0`。

2. `Area()` 方法名大写开头。Java 的约定是类名大写、方法名小写，这里写成 `Area` 不影响编译，但和字段 `area` 容易看混。写成 `public double area()` 返回 double、由 main 负责打印会更好，求面积的类不该管输出。

3. `distance` 里漏写 `this`。`Point` 的字段是 `x`、`y`，参数点的是 `p.x`、`p.y`，如果写成 `(p.x - x)` 其实也对（`x` 默认就是 `this.x`），但写成 `(x - x)` 就恒等于 0，是常见笔误。

4. `nextDouble()` 读不到数会抛 `InputMismatchException`。输入时坐标之间用空格或回车都行，逗号不行，`0,0` 会直接崩。

5. 三角不等式只写一个条件。只判断 `s1 + s2 > s3` 的话，当 `s3` 不是最长边时，不合法的三边也会被放行，海伦公式里 `p - s` 出现负数，开方结果是 `NaN`，打印出来是 `此三角形面积为：NaN`。

## 实验二 累加整数，自动忽略非整数输入

题目（原稿标注：论述题, 5 分）：输入若干整数，并求和，直到结束标志 999 为止。在输入过程中，自动忽略掉输入的非整数。提示：用 Scanner 的 `nextInt()` 方法转换输入信息到整数，如果输入信息为非整数，方法将抛出名为 `InputMismatchException` 的异常，该异常封装在 `java.util` 包中。请把程序代码和输出结果的截图提交到答案中。

### 参考代码

```java
import java.util.InputMismatchException;
import java.util.Scanner;

public class catchFloat {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int number = 0;
        int sum = 0;
        System.out.println("请输入整数进行累加（结束标志为999）：");
        while (true) {
            try {
                int num = sc.nextInt(); //读到非整数则抛出InputMismatchException异常
                if (num == 999)
                    break;
                sum += num;
            } catch (InputMismatchException e) {
                System.out.println("输入的不是整数，已自动忽略。");
                sc.next();  // 忽略非整数输入
            }
        }
        System.out.println("所有输入整数的和为：" + sum);
    }
}
```

### 思路

`while(true)` 加 `break` 是"读到哨兵值才结束"的标准写法，因为退出条件在循环中间，用不了 `while(条件)`。

`try` 块只包住 `nextInt()` 和它后面两行，异常处理的范围要尽量小。

catch 里那句 `sc.next()` 是整道题的关键。`nextInt()` 抛异常时**不会**把出错的那个词从输入里取走，扫描位置还停在原处；如果不调用 `sc.next()` 把它读掉，下一轮 `nextInt()` 读到的还是同一个词，又抛异常，程序就死循环刷屏。`next()` 读一个以空白分隔的词，正好把它丢掉。

`999` 是结束标志，不计入累加，所以 `break` 写在 `sum += num` 前面。

### 运行结果

输入 `12 abc 30 3.5 -8 999`：

```
请输入整数进行累加（结束标志为999）：
12 abc 30 3.5 -8 999
输入的不是整数，已自动忽略。
输入的不是整数，已自动忽略。
所有输入整数的和为：34
```

12 + 30 + (-8) = 34。`abc` 和 `3.5` 各触发一次异常，`3.5` 虽然是数字但不是整数，`nextInt()` 一样拒收。

### 容易出错的地方

1. catch 里忘了 `sc.next()`，程序无限打印"输入的不是整数"。这是这道题最容易丢分的地方。
2. 捕获的异常类型写错。`InputMismatchException` 在 `java.util` 包里，不在 `java.lang`，必须 import。写成 `catch (Exception e)` 也能跑，但没答到题目要的点。
3. 把 `break` 写在 `sum += num` 后面，999 会被加进总和。
4. 输入流读完还在循环。如果用文件重定向输入而文件里没有 999，读到文件末尾时 `nextInt()` 抛的是 `NoSuchElementException`，catch 接不住，程序带异常退出。从键盘手敲输入不会遇到，按 Ctrl+Z（Windows）结束输入时会遇到。
5. 原稿第 7 行的 `int number = 0;` 声明了没用过，编译不报错，但交作业前删掉更干净。
6. 类名 `catchFloat` 小写开头，不符合命名约定，正规写法是 `CatchFloat`，文件名跟着改成 `CatchFloat.java`。
