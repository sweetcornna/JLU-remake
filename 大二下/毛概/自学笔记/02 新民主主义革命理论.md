# 新民主主义革命理论

整理自 `期末资料/毛概大题整理.pdf`（第二章，篇幅最全）、`期末资料/毛概PPT整理.pdf`（第二章）、`毛概思维导图（解忧）.pdf`，客观题考点对照 `学习通章节测试答案.pdf` 第 2.2.5 节。

## 本章要点

- 一条总路线（无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命），拆成"对象、动力、领导力量、性质和前途"四块。
- 三个纲领（政治、经济、文化）、一条道路（农村包围城市）、三大法宝（统一战线、武装斗争、党的建设）。
- 大题最常考：为什么资产阶级共和国方案行不通、为什么必须由无产阶级领导、农村包围城市道路的必然性与可能性、三大法宝的相互关系。

## 一、形成依据

### 1. 近代中国国情（基本依据）

毛泽东：认清中国社会的性质，就是说，认清中国的国情，乃是认清一切革命问题的基本的根据。

- 社会性质：半殖民地半封建社会。"半殖民地"指列强通过政治、经济、文化侵略，强迫清政府签订不平等条约，操纵中国的财政经济命脉和政治军事力量，中国没有完整主权和国家统一。"半封建"指侵略一方面促使自给自足的封建经济解体，另一方面地主阶级对农民的剥削依旧存在，并与买办资本和高利贷资本的剥削结合，在经济生活中占明显优势。
- 主要矛盾：帝国主义和中华民族的矛盾、封建主义和人民大众的矛盾，其中帝国主义和中华民族的矛盾是最主要的矛盾。
- 根本任务：推翻帝国主义、封建主义和官僚资本主义的统治，争取民族独立和人民解放。

### 2. 时代特征（新的选择）

- 俄国十月革命胜利，中国资产阶级民主革命的时代背景根本转换，从旧的世界资产阶级民主主义革命的一部分转变为世界无产阶级社会主义革命的一部分。
- 五四运动为标志，中国无产阶级开始作为独立的政治力量登上历史舞台，成为革命的领导力量，马克思列宁主义逐步成为指导思想。
- 中国革命要分两步走：第一步完成反帝反封建的新民主主义革命任务，第二步完成社会主义革命任务。

> 学习通有一道题问十月革命对中国革命的影响哪一项表述不正确，答案是"将中国革命推进到世界资产阶级民主革命的历史潮流中"，正好反了：十月革命使中国革命成为世界无产阶级社会主义革命的一部分。

### 3. 实践基础

- 旧民主主义革命的失败呼唤新的革命理论，新理论的形成包含对旧民主主义革命失败教训的深刻总结。
- 新民主主义革命的艰辛探索奠定了理论形成的实践基础。具体来说：统一战线理论源于两次国共合作的实践，中国革命道路理论源于建立和巩固农村根据地的实践，人民军队和革命战争理论源于革命战争的实践，党的建设理论源于党在领导革命中自身发展壮大的实践。

### 4. 为什么资产阶级共和国方案在中国行不通

这题几乎每年都出现在思考题里，答两层：

第一层，帝国主义不允许。西方列强来中国，目的是把中国变成殖民地或半殖民地，以便倾销商品、输出资本、获得廉价原材料和劳动力。中国一旦获得民族独立，列强就失去殖民利益，还会多一个竞争对手，这是它们不愿意看到的。所以在中国，资产阶级民主革命的任务除了消灭封建势力，还有反对帝国主义。

第二层，民族资产阶级自身力量软弱。中国民族资本主义经济一开始就受外国资本压迫、官僚买办资本排挤、封建生产关系束缚和封建官僚政府压榨，无法自由充分发展。国民经济中地主农业经济和个体农业经济占显著优势，资本主义经济只占很小一部分；民族资本里商业资本和金融资本占很大部分，民族工业大多规模小、经营分散、技术设备落后、劳动生产率低、产品缺乏竞争力。这种经济状态决定了民族资产阶级的政治态度：一方面同帝国主义、封建主义有矛盾，是革命力量之一；另一方面同它们并未完全断绝经济联系，没有彻底反帝反封建的勇气。这就是两面性，在戊戌变法和辛亥革命中都有充分体现。

结论：由民族资产阶级领导建立资产阶级共和国、发展资本主义，这条路在中国走不通。

## 二、新民主主义革命的总路线

1939 年，毛泽东在《中国革命和中国共产党》中第一次提出"新民主主义革命"的科学概念。1948 年 4 月，《在晋绥干部会议上的讲话》完整表述了总路线：无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命。

总路线的目的：推翻买办的封建的生产关系以及腐朽的政治上层建筑，从根本上解放被束缚的生产力。

### 1. 革命对象

分清敌友是革命的首要问题（《中国社会各阶级的分析》）。

| 对象 | 地位 | 理由 |
| --- | --- | --- |
| 帝国主义 | 首要对象 | 侵略战争使中国由独立的封建社会变成半殖民地半封建社会，是中国社会进步的最大障碍，是近代中国贫困落后和一切灾难祸害的总根源 |
| 封建地主阶级 | 主要对象 | 是帝国主义统治中国和封建军阀实行专制统治的社会基础，是中国经济现代化和政治民主化的主要障碍 |
| 官僚资本主义 | 对象之一 | 依靠帝国主义、勾结封建势力、利用国家政权发展起来的买办的封建的国家垄断资本主义，残酷剥削劳动人民、巧取豪夺民族工商业，严重束缚生产力 |

三者合称压在中国人民身上的"三座大山"。两个基本任务：对外推翻帝国主义压迫是民族革命，对内推翻封建地主阶级和官僚资产阶级压迫是民主革命。两个任务相互区别又相互联系，帝国主义是封建地主阶级的靠山，地主阶级是帝国主义统治中国的主要社会基础。

不同阶段主要对象不同，这是选择题常考点：

| 时期 | 主要对象 |
| --- | --- |
| 大革命时期（国共合作） | 帝国主义支持下的北洋军阀 |
| 土地革命战争时期 | 国民党新军阀 |
| 抗日战争时期 | 日本帝国主义 |
| 解放战争时期 | 美帝国主义支持下的国民党反动派 |

### 2. 革命动力

| 阶级 | 地位 | 要点 |
| --- | --- | --- |
| 无产阶级 | 最基本的动力，同时是领导力量 | 新的社会生产力的代表，近代中国最进步的阶级 |
| 农民阶级 | 主力军 | 占全国人口 80% 以上，贫雇农是最可靠的同盟军，中农是可靠的同盟军 |
| 城市小资产阶级 | 可靠的同盟者 | 包括知识分子、小商人、手工业者、自由职业者 |
| 民族资产阶级 | 动力之一 | 带两面性，既不可能充当革命的主要力量，也不可能是领导力量 |

农民问题是中国革命的基本问题。新民主主义革命实质上就是党领导下的农民革命，中国革命战争实质上就是党领导下的农民战争。理由三条：农民是革命最广大的动力和主力军；农民是革命军队的主要来源（红军、八路军和新四军、解放军绝大部分是穿着军装的农民）；长期武装斗争主要是党领导下的农民游击战争，广大农村是走向胜利的主要战略基地。

### 3. 领导力量

无产阶级的领导权是中国革命的中心问题，也是新民主主义革命理论的核心问题。区别新旧两种民主主义革命的根本标志，是领导权掌握在无产阶级手中还是资产阶级手中。

为什么只能由无产阶级领导：

1. 帝国主义不允许中国民族资产阶级建立独立的资产阶级共和国。
2. 中国民族资产阶级有软弱性和妥协性，不愿意也不能够彻底推翻帝国主义和封建势力。
3. 中国无产阶级强大且革命彻底，领导重任历史地落到它和它的政党肩上。

中国无产阶级除了与先进生产方式相联系、没有私人占有的生产资料、富于组织纪律性等一般优点外，还有三个自身特点：

1. 身受外国资本主义、本国封建势力和资产阶级三重压迫，压迫极具严重性和残酷性，所以在斗争中比任何别的阶级都坚决彻底。
2. 分布集中，有利于队伍的组织和团结，有利于革命思想传播和强大革命力量形成。
3. 成员大部分出身于破产农民，与农民有天然联系，便于结成亲密联盟。

怎样实现领导权（四条，按"关键、策略、支柱、保证"记）：

1. 建立以工农联盟为基础的广泛的统一战线，这是实现领导权的关键。
2. 同资产阶级建立统一战线时坚持独立自主原则，保持党在思想上、政治上和组织上的独立性，实行又联合又斗争的方针，这是坚持领导权的基本策略。
3. 建立和发展人民的革命武装力量，建立一支无产阶级领导的以农民为主体的强大革命武装，这是保证领导权的坚强支柱。
4. 加强无产阶级政党的建设，这是实现领导权的根本保证。

无产阶级实现对同盟者领导的两个基本条件（《关于目前党的政策中的几个重要问题》，1948）：率领被领导者向着共同敌人作坚决斗争并取得胜利；对被领导者给予物质福利，至少不损害其利益，同时给予政治教育。缺一条就不能实现领导。

### 4. 性质和前途

近代中国半殖民地半封建社会的性质和革命的历史任务，决定了中国革命属于资产阶级民主主义革命的范畴，而非无产阶级社会主义革命。但它已经超出旧式的、一般的资产阶级民主主义革命，属于新式的特殊的资产阶级民主主义革命。

新民主主义革命与旧民主主义革命相比的四个新内容和特点：

1. 处于世界无产阶级社会主义革命的时代，是世界无产阶级社会主义革命的一部分。
2. 革命的领导力量是中国无产阶级及其先锋队中国共产党（这是与旧民主主义革命的根本区别）。
3. 革命的指导思想是马克思列宁主义。
4. 革命的前途是社会主义而非资本主义。

新民主主义革命与社会主义革命的关系：

| | 新民主主义革命 | 社会主义革命 |
| --- | --- | --- |
| 性质 | 资产阶级民主主义革命范畴 | 无产阶级性质的革命 |
| 对待资本主义 | 没收官僚资本，打倒官僚资产阶级，争取和联合民族资产阶级，保护民族工商业 | 消灭资本主义剥削制度，改造小生产的私有制 |
| 要建立的政权 | 无产阶级领导的各革命阶级的联合专政 | 无产阶级专政 |

联系：两者互相联系、紧密衔接，中间不容横插一个资产阶级专政。民主主义革命是社会主义革命的必要准备，社会主义革命是民主主义革命的必然趋势。

两种错误倾向："左"的是"毕其功于一役"、搞所谓"无间断"革命，混淆两个革命的界限；右的是"二次革命论"，只看到区别没看到联系，主张民主革命胜利后先建立资产阶级专政的资本主义国家，放弃党对民主革命的领导权。

## 三、新民主主义的基本纲领

1940 年《新民主主义论》第一次完整提出新民主主义的经济纲领，并阐述了政治、经济和文化；1945 年《论联合政府》进一步与党的基本纲领联系起来具体阐述。

### 1. 政治纲领

推翻帝国主义和封建主义的统治，建立一个无产阶级领导的、以工农联盟为基础的、各革命阶级联合专政的新民主主义的共和国。

- 国体：无产阶级领导的、以工农联盟为基础，包括小资产阶级、民族资产阶级和其他反帝反封建的人们在内的各革命阶级的联合专政。
- 政体：民主集中制的人民代表大会制度。

> 判断题考点：新民主主义国家的国体是无产阶级专政（错，是各革命阶级的联合专政）。

### 2. 经济纲领（三大经济纲领）

1947 年《目前形势和我们的任务》首次把新民主主义经济纲领归纳为三条：

1. 没收封建地主阶级的土地归农民所有。这是新民主主义革命的主要内容。
2. 没收官僚资产阶级的垄断资本归新民主主义的国家所有。这是题中应有之义。通过没收官僚资本建立起具有社会主义性质的国营经济，居于领导地位，为向社会主义过渡奠定基础。
3. 保护民族工商业。这是新民主主义经济纲领中极具特色的一项，由中国落后的生产力和革命性质决定。

### 3. 文化纲领

新民主主义文化，就是无产阶级领导的人民大众的反帝反封建的文化，即民族的科学的大众的文化。

| | 内容 |
| --- | --- |
| 民族的 | 内容上反对帝国主义压迫，主张中华民族的尊严和独立；形式上有鲜明的民族风格、民族形式和民族特色，要有中国作风和中国气派 |
| 科学的 | 反对一切封建思想和迷信思想，主张实事求是、客观真理及理论和实践的一致性；尊重中国历史，反对民族虚无主义，以历史唯物主义态度对待古今中外文化 |
| 大众的 | 用革命文化教育和武装人民大众，同时以人民群众的实践作为创作源泉，坚持为人民大众服务的方向 |

新民主主义的政治、经济、文化相结合，就是新民主主义的共和国。

## 四、新民主主义革命道路

道路内容：农村包围城市、武装夺取政权。

### 1. 必然性（为什么只能走这条路）

1. 在半殖民地半封建的中国，内无民主制度而受封建主义压迫，外无民族独立而受帝国主义压迫。中国无产阶级不可能像资本主义国家那样先在城市长期公开合法斗争再组织武装起义。主要斗争形式只能是武装斗争，以革命的武装消灭反革命的武装，主要组织形式必然是军队。
2. 近代中国是农业大国，农民占人口绝大多数，是无产阶级可靠的同盟军和革命主力军。必须深入农村，从解决土地问题入手，组织、发动和武装农民。
3. 革命的敌人异常强大并长期占领中心城市，广大农村是国民党反动统治的薄弱地区，只能先在农村聚集力量。

### 2. 可能性（红色政权存在和发展的原因与条件）

1. 近代中国是多个帝国主义间接统治的经济落后的半殖民地国家，社会政治经济发展极端不平衡，四分五裂、军阀割据，存在不少统治薄弱环节。（客观，统治薄弱）
2. 广大农村深受反动统治阶级的多重压迫和剥削，人民革命愿望强烈，加之经历过大革命洗礼，群众基础好。（客观，群众基础）
3. 全国革命形势的继续向前发展。（客观，革命形势）
4. 相当力量的正式红军的存在。（主观，正式红军）
5. 党的领导的有力量及其政策的不错误。（主观，党的领导）

### 3. 道路的内容：三者关系

根本在于处理好土地革命、武装斗争、农村革命根据地建设三者之间的关系。

- 土地革命是民主革命的基本内容。
- 武装斗争是中国革命的主要形式，是农村根据地建设和土地革命的强有力保证。
- 农村革命根据地是中国革命的战略阵地，是进行武装斗争和开展土地革命的依托。

三者在党的领导下密切结合、有机统一。

### 4. 道路理论的意义

1. 实现了中国革命从城市走向农村的历史性转变和党的工作重心由城市向农村的转变，保存和发展了革命力量。
2. 揭示了中国革命发展的客观规律，指明了正确方向。
3. 丰富和发展了马克思主义关于暴力革命的学说，为殖民地半殖民地国家的人民解放斗争提供了重要经验。
4. 是党运用马克思主义立场观点方法分析解决中国革命具体问题的典范，对推进马克思主义中国化有重要方法论意义。
5. 指导中国完成了新民主主义革命，创建了中华人民共和国。

## 五、三大法宝

毛泽东在《〈共产党人〉发刊词》（1939）中总结了中国革命两次胜利和两次失败的经验教训，把统一战线、武装斗争、党的建设比作战胜敌人的三个主要法宝。

### 1. 统一战线

必要性：由中国半殖民地半封建社会的阶级状况决定，由中国革命的长期性、残酷性及发展的不平衡性决定。

可能性：半殖民地半封建社会诸多矛盾交织，客观上为利用这些矛盾建立和发展统一战线提供了可能。

四个历史阶段的形式（选择题常考）：

| 时期 | 统一战线 |
| --- | --- |
| 大革命时期 | 第一次国共合作的统一战线（国民革命联合战线） |
| 土地革命战争时期 | 工农民主统一战线 |
| 抗日战争时期 | 抗日民族统一战线 |
| 解放战争时期 | 人民民主统一战线 |

两个联盟：一是工人阶级同农民阶级、广大知识分子及其他劳动者的联盟，主要是工农联盟，这是统一战线的基础；二是工人阶级同非劳动人民的联盟，主要是与民族资产阶级的联盟。

四条实践经验：

1. 建立巩固的工农联盟。
2. 正确对待资产阶级，尤其是民族资产阶级，实行既联合又斗争的策略。
3. 采取区别对待的方针，坚持发展进步势力、争取中间势力、孤立顽固势力。
4. 坚持独立自主的原则，保持党在政治上、思想上和组织上的独立性。

### 2. 武装斗争

属性：武装斗争是中国革命的特点和优点之一。在半殖民地半封建的旧中国，无产阶级和人民群众无议会可以利用，无组织工人举行罢工的合法权利，帝国主义和封建主义凭借反革命暴力镇压，革命人民只有以武装的革命反对武装的反革命。

四条实践经验：

1. 坚持党对军队的绝对领导（"党指挥枪"）。这是建设新型人民军队的根本原则，是保持人民军队无产阶级性质和建军宗旨的根本前提，也是毛泽东建军思想的核心。
2. 建设全心全意为人民服务的人民军队。全心全意为人民服务是人民军队的唯一宗旨，是建设新型人民军队的基本前提。
3. 开展革命的政治工作。
4. 坚持正确的战略战术原则。

### 3. 党的建设

四条实践经验：

1. 必须把思想建设始终放在党的建设的首位。
2. 必须在任何时候都重视党的组织建设，关键是贯彻民主集中制这一根本组织原则。
3. 必须重视党的作风建设，逐步形成理论联系实际、密切联系群众、批评与自我批评三大优良作风。
4. 必须联系党的政治路线加强党的建设。

三大优良作风出自《论联合政府》（1945），是中国共产党区别于其他任何政党的显著标志。

### 4. 三者的关系（必背原句）

统一战线和武装斗争是中国革命的两个基本特点，是战胜敌人的两个基本武器。统一战线是实行武装斗争的统一战线，武装斗争是统一战线的中心支柱，党的组织则是掌握统一战线和武装斗争这两个武器以实行对敌冲锋陷阵的英勇战士。

## 六、新民主主义革命理论的意义

理论意义：

1. 以马克思列宁主义为指导，用具有原创性、中国气派中国风格的概念观点理论分析中国国情，开辟了马克思主义中国化的发展道路。
2. 强调把握国情、尊重人民利益、继承中华优秀传统文化，坚持一切从实际出发、具体问题具体分析，展现了中国化的方法论原则。
3. 不拘泥于已有结论，不照抄"本本"，体现了对待马克思主义应持有的科学态度。
4. 在反对各种错误思想倾向的过程中形成，是与党内教条主义错误思想斗争的结果。

实践意义：

1. 为探索一条适合中国国情的革命道路指明了正确方向。
2. 创造性地解决了无产阶级如何领导资产阶级民主革命的问题。
3. 反映了中国革命的客观规律，系统说明了革命的对象、动力、领导力量、性质和前途。
4. 明确回答了"中国向何处去"的问题。
5. 指导党领导人民于 1949 年建立中华人民共和国，实现民族独立、人民解放。

世界意义：中国新民主主义革命的胜利，是 20 世纪继俄国十月革命以后改变世界面貌的伟大历史事件，鼓舞和推动了世界被压迫民族和被压迫人民反抗帝国主义、殖民主义的斗争。
