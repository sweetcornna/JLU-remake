# 重要著作速查

合并自 `期末资料/毛概各会议及著作汇总资料.pdf` 和 `期末资料/毛概重大会议及重要著作汇总.pdf`，两份重复的著作只保留信息最全的一版，年份和篇名按更权威的表述统一，改动处注明"（更正：原文作 …）"。

背法：每篇先记住括号里那句"第一次/标志"，那是选择题的落点；再记内容要点，那是简答题的落点。

## 一、按年份排（主表）

| 1927 | 《湖南农民运动考察报告》 | 与上一篇合起来基本形成新民主主义革命总路线的基本思想 | 指出中国革命的中心问题是农民问题 |
| 1928 | 《中国的红色政权为什么能够存在？》 | 分析红色政权存在与发展的原因和条件 | 讲清根本原因、客观条件、主观条件 |
| 1930 | 《星星之火，可以燎原》 | 毛泽东思想形成的重要标志；初步提出农村包围城市的思想 | 建立红色政权的必要性及其作用；阐述红军和小块红色区域存在发展的可能性，提出以"乡村为中心"的思想；提出巩固和扩大农村革命根据地的路线和政策 |

| 1936 | 《中国革命战争的战略问题》 | 科学分析中国革命战争的四个特点 | 四个特点：中国是政治经济发展不平衡的半殖民地大国且经历了 1924–1927 年的革命；敌人强大；人民军队弱小；共产党的领导和土地革命。其中第 1、4 个特点决定人民军队可能发展并战胜敌人，第 2、3 个特点决定战争的持久性和艰苦性 |
| 1937 | 《实践论》 | 与《矛盾论》一起奠定了实事求是思想路线的哲学基础 | 揭示马克思主义认识论的本质特征：实践是认识的源泉、动力、目的，是检验认识真理性的唯一标准；揭示认识的辩证发展过程：第一次飞跃是感性认识上升到理性认识，第二次飞跃是由理性认识能动地飞跃到实践 |
| 1937 | 《矛盾论》 | 同上 | 坚持和发展了对立统一规律是辩证法实质和核心的思想；提出矛盾普遍性和特殊性及其辩证关系原理；论述矛盾同一性与斗争性的原理 |
| 1937 | 《中国共产党在抗日时期的任务》 | 论述最低纲领和最高纲领的关系 | 指出党的最高纲领是社会主义和共产主义，其在民主革命时期的纲领比国内任何党派更彻底，但与国民党一大宣布的三民主义纲领基本上不相冲突。还指出无产阶级通过政党实现政治领导的基本途径：提出政治口号和动员口号；行动起来成为模范；与同盟者建立适当关系；抓好共产党自身的队伍、思想及纪律 |
| 1938 | 《中国共产党在民族战争中的地位》 | 六届六中全会的报告，明确提出"马克思主义中国化"的历史任务；开始使用"实事求是"这个概念 | "共产党员应是实事求是的模范""只有实事求是，才能完成确定的任务""科学的态度是实事求是" |
| 1938 | 《战争和战略问题》 | 阐述中国革命的具体道路和形式 | "革命的中心任务和最高形式是武装夺取政权，是战争解决问题"；指明战争是中共主要的斗争形式；用发展的观点分析战争进程，确定党的军事战略转变 |
| 1938 | 《抗日游击战争的战略问题》《论持久战》 | 揭示抗日战争发展的基本规律 | 敌强我弱、敌退步我进步、敌小我大、敌寡助我多助；只有实行人民战争才能赢得胜利；作战形式上主要是运动战，其次是游击战 |
| 1939 | 《〈共产党人〉发刊词》 | 提出三大法宝；把党的建设称为"伟大的工程" | 统一战线是党的政治路线的一部分；武装斗争也是政治路线的重要部分；党的建设是中国革命胜利的重要保证，是三个法宝的中心一环。还阐明"马克思主义的理论和中国革命的实践相结合"这个根本的思想原则 |
| 1939 | 《中国革命和中国共产党》 | 首次提出"新民主主义革命"这一科学概念 | 精辟指出"认清中国的国情，乃是认清一切革命问题的根本依据"；系统阐明中国革命的对象、任务、动力、性质、前途和领导权，指出现阶段革命的主要对象是帝国主义和封建主义；阐明中国革命必须分为新民主主义革命和社会主义革命两步；揭示农村包围城市道路的必要性 |
| 1939 | 《青年运动的方向》 | 讲革命动力和革命性质 | 革命动力有无产阶级、农民阶级和其他阶级中一切愿意反帝反封建的人；中国革命的性质是资产阶级的民主主义革命，目的是建立人民民主的共和国 |
| 1939 | 《五四运动》 | 讲领导阶级 | 革命的领导阶级是工人阶级，离开工人阶级的领导不可能完成反帝反封建的民主革命 |
| 1940 | 《新民主主义论》 | 第一次完整地提出新民主主义的经济纲领；论述"新民主主义共和国"的国体和政体 | 论述新民主主义革命的基本特点（是世界无产阶级社会主义革命的一部分、领导者是无产阶级、前途是社会主义）；论证中国革命必须分两步走；制定政治、经济、文化三大纲领；指出 1919 年五四运动是新旧民主主义革命的分水岭 |
| 1940 | 《论政策》 | 讲抗日民族统一战线政策 | 批判"两个极端政策"；阐述抗日民族统一战线政策；提出在"区别上建立我们的政策"；提出处理国内阶级关系的基本政策。与《目前抗日统一战线中的策略问题》一起阐明策略总方针：发展进步势力，争取中间势力，孤立顽固势力 |
| 1940 | 《目前抗日统一战线中的策略问题》 | 提出"中间派"这一概念 | 中间派包括民族资产阶级、开明士绅和地方实力派（`毛概重大会议及重要著作汇总.pdf` 对这篇的篇名有《目前抗战统一战线中的策略问题》和《目前抗日民族统一战线中的策略问题》两种写法，统一用《目前抗日统一战线中的策略问题》） |
| 1940 | 《新民主主义的宪政》 | 阐述新民主主义的宪政思想 | 宪政就是民主政治；中国需要的民主政治，是合乎现在中国国情的新民主主义的民主 |
| 1940 | 《抗日根据地的政权问题》 | 提出"中间势力"概念 | 在三三制政权组成原则的划分中提出，主要指民族资产阶级和开明士绅 |
| 1941 | 《改造我们的学习》 | 科学解释了"实事求是"的含义，从此实事求是成为党的思想路线的集中概括 | 把主观主义分为教条主义和经验主义；解释"实事"是客观存在的一切事物，"是"是客观事物的内部联系即规律性，"求"是我们去研究；实事求是的本质是理论与实际相统一 |
| 1942 | 《整顿党的作风》 | 讲党的思想作风 | 要取得胜利必须解决党在思想作风方面的突出矛盾；坚持主观与客观、理论与实践的统一，反对各种形式的主观主义；揭示党内团结与斗争的辩证关系 |
| 1942 | 《反对党八股》 | 剖析党八股 | 剖析党八股产生的历史根源和阶级根源；指出主观唯心主义是党八股的主要哲学基础，形而上学是其最主要的思维模式（更正：`毛概各会议及著作汇总资料.pdf` 把年份写成 1943 年，本篇是 1942 年 2 月 8 日的演讲） |
| 1943 | 《关于领导方法的若干问题》 | 第一次从哲学高度对党的群众路线作了理论概括 | 明确提出在党的一切工作中，凡属正确的领导必须是"从群众中来，到群众中去"，如此无限循环，一次比一次更正确、更生动、更丰富；把群众路线与马克思主义的认识论、辩证法和历史唯物论有机统一起来 |
| 1944 | 同英国记者斯坦因的谈话 | 区分共产主义思想体系和共产主义社会制度 | 必须将共产主义思想体系与共产主义的社会制度区分开来；在中国现阶段，实现新民主主义政策是近期目标 |
| 1945 | 《论联合政府》 | 七大的政治报告；概括三大优良作风 | 阐明实现光明前途的客观依据和条件；把新民主主义革命的一般纲领具体化为现阶段的行动纲领；阐述废除国民党一党专政、建立民主联合政府的主张；掌握思想教育是团结全党进行伟大政治斗争的中心环节；概括三大优良作风（理论联系实际、密切联系群众、批评和自我批评）；"人民，只有人民，才是创造世界历史的动力"；提出生产力标准；提出人民战争必须实行"三结合"的武装力量体制；"只有经过新民主主义，才能达到社会主义，这是马克思主义的天经地义" |
| 1947 | 《目前形势和我们的任务》 | 第一次把新民主主义经济纲领归纳为三大经济纲领 | 三大经济纲领：没收封建阶级的土地归农民所有；没收以蒋介石、宋子文、孔祥熙、陈立夫为首的垄断资本归新民主主义国家所有；保护民族工商业。还提出土改的两个原则，概括了人民军队的十大军事原则 |
| 1948 | 《关于目前党的政策中的几个重要问题》 | 讲新民主主义政权性质和领导权条件 | 新民主主义政权是工人阶级领导的人民大众的反帝反封建的政权；无产阶级实现对同盟者领导必须具备的两个基本条件 |
| 1948 | 《将革命进行到底》 | 首次公开使用"人民民主专政"的概念 | 新年献词 |
| 1948 | 《在晋绥干部会议上的讲话》 | 完整表述新民主主义革命总路线；第一次明确提出"官僚资本主义"是中国革命的对象 | 总路线：无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命。其中"人民大众"指革命动力。还完整提出土地改革的总路线 |
| 1949 | 《论人民民主专政》 | 完整地提出人民民主专政的理论 | 建立人民民主专政的国家政权是中国社会发展的必由之路；总结国内外基本经验；本质特征是对人民实行民主、对敌人实行专政；领导者和阶级基础是工人阶级和工农联盟（这是决定国家政权性质的关键因素）；职能和历史任务；组织形式是人民代表大会；制定了新中国外交政策的基本原则 |
| 1949 | 《在中共七届二中全会上的报告》 | 实现伟大历史性转变的纲领；第一次明确提出执政党的建设问题 | 提出由新民主主义社会转变为社会主义社会的总任务和主要途径；阐明党的工作重心由乡村转移到城市；分析全国胜利后国家政权的性质和阶级斗争特点；提出"两个务必" |
| 1949 | 《中国人民政治协商会议共同纲领》 | 为新民主主义向社会主义转变提供重要理论基础 | 与七届二中全会报告并列 |
| 1950 | 《为争取国家财政经济状况的基本好转而斗争》 | 七届三中全会的报告 | 规定实现财政经济状况好转的三个条件：土地改革的完成；现有工商业的合理调整；国家机构所需经费的大量节减。还规定了八项工作 |
| 1950 | 《不要四面出击》 | 七届三中全会的讲话 | "不要四面出击""不可树敌太多"，应集中力量孤立和打击当前最主要的敌人；党对从新民主主义向社会主义的过渡采取谨慎稳妥的步骤；批评了可提早消灭资本主义、实行社会主义的思想 |
| 1956 | 《论十大关系》 | 标志着探索中国自己的社会主义建设道路的开始 | 以苏联经验为借鉴，论述十大关系；阐述积极因素和消极因素的辩证关系；辩证分析独立自主和学习外国的关系；提出"长期共存、互相监督""百花齐放，百家争鸣""把国内外一切积极因素调动起来，为社会主义事业服务"三个方针 |
| 1957 | 《关于正确处理人民内部矛盾的问题》 | 第一次系统阐述社会主义社会基本矛盾的学说和两类矛盾学说 | 明确提出社会主义基本矛盾的概念；提出两类社会矛盾的学说和处理方针；提出走中国工业化道路的思想；提出"统筹兼顾、适当安排"的方针；指出"百花齐放，百家争鸣"是繁荣文化艺术、促进科学进步的根本方针；提出判断言论和行动是非的六条标准 |

| 2001 | 江泽民 | 七一讲话 | 全面阐述"三个代表"重要思想的科学内涵和基本内容；指出看一个政党是否先进主要看它的理论和纲领是不是马克思主义的、是不是代表社会发展的正确方向、是不是代表最广大人民的根本利益 |

刘少奇在七大报告里概括的群众路线基本内容四条：一切为了人民群众、全心全意为人民服务的观点；一切向人民群众负责的观点；相信群众自己解放自己的观点；向人民群众学习的观点。

## 四、最容易记混的三组

1. 《中国革命和中国共产党》（1939）第一次提出"新民主主义革命"的概念，《在晋绥干部会议上的讲话》（1948）完整表述总路线。前者提概念，后者下定义。
2. 《新民主主义论》（1940）第一次完整提出经济纲领，《目前形势和我们的任务》（1947）归纳为"三大经济纲领"。前者是提出，后者是归纳。
3. 《反对本本主义》（1930）第一次使用"思想路线"这个概念，《改造我们的学习》（1941）第一次科学解释"实事求是"的含义，《中国共产党在民族战争中的地位》（1938）开始使用"实事求是"这个词。三篇的先后顺序是 1930、1938、1941。
