## 二、毛泽东思想的三次关键概括

| 次序 | 时间 | 人物与文献 | 内容 |
| --- | --- | --- | --- |
| 概念提出 | 1943 | 王稼祥《中国共产党与中国民族解放的道路》 | 明确提出并多次使用"毛泽东思想"这个概念 |
| 第一次概括 | 1945 | 刘少奇七大《关于修改党章的报告》 | 毛泽东思想就是"中国化的马克思主义"，作为党的指导思想正式确定下来 |
| 第二次概括 | 1981、1982 | 十一届六中全会《历史决议》、十二大党章 | 三句话：马克思列宁主义在中国的运用和发展；被实践证明了的关于中国革命和建设的正确的理论原则和经验总结；中国共产党集体智慧的结晶 |

相关的两个前置提法：1941 年张如心《论布尔什维克的教育家》最先用"毛泽东的思想"；1942 年邓拓纪念"七一"专论用了"毛泽东主义"。

## 三、几条容易串的总路线

| 名称 | 时间与出处 | 内容 |
| --- | --- | --- |
| 新民主主义革命总路线 | 1948《在晋绥干部会议上的讲话》 | 无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命 |
| 土地改革总路线 | 1948《在晋绥干部会议上的讲话》 | 依靠贫雇农，团结中农，有步骤、有分别地消灭封建剥削制度，发展农业生产 |
| 过渡时期总路线 | 1953 年 12 月 | 逐步实现国家的社会主义工业化，并逐步实现国家对农业、对手工业和对资本主义工商业的社会主义改造（一化三改） |
| 社会主义建设总路线 | 1958 年八大二次会议 | 鼓足干劲，力争上游，多快好省地建设社会主义 |
| 党在社会主义初级阶段的基本路线 | 1987 年十三大 | 领导和团结全国各族人民，以经济建设为中心，坚持四项基本原则，坚持改革开放，自力更生，艰苦创业，为把我国建设成为富强、民主、文明的社会主义现代化国家而奋斗 |

## 四、三大改造的三级形式

| 行业 | 萌芽（社会主义萌芽性质） | 中间（半社会主义性质） | 完成（社会主义性质） |
| --- | --- | --- | --- |
| 农业 | 农业互助组 | 初级农业生产合作社 | 高级农业生产合作社 |
| 手工业 | 手工业供销小组 | 手工业供销合作社 | 手工业生产合作社 |
| 资本主义工商业 | 初级形式的国家资本主义（加工订货、计划订货、统购包销、经销代销） | 个别企业的公私合营 | 全行业的公私合营 |

利润分配：前两个阶段是四马分肥（国家所得税、企业公积金、工人福利费、资方红利），全行业公私合营后改为定息。

## 五、现代化目标的演变

| 时间 | 出处 | 表述 |
| --- | --- | --- |
| 1954 | 一届人大一次会议周恩来《政府工作报告》 | 四个现代化的最初表述：现代化的工业、现代化的农业、现代化的交通运输业、现代化的国防。第一次使用"现代化"来规定目标 |
| 读苏联《政治经济学（教科书）》的谈话 | 毛泽东 | 提出除工业现代化、农业现代化、科学文化现代化外，还要加上国防现代化 |
| 1964 | 三届人大一次会议周恩来《政府工作报告》 | 现代农业、现代工业、现代国防和现代科学技术，并提出两步走 |
| 1987 | 十三大 | "三步走"：温饱、小康、基本实现现代化 |
| 1997 | 十五大 | 勾画第三步的三个阶段：2010 年翻一番、建党一百年制度更加完善、新中国成立一百年基本实现现代化 |

> 注意 1954 年的表述里有"交通运输业"，1964 年的表述里换成了"科学技术"。这两个版本最容易记混。

## 六、几个"关系"与"标准"

| 概念 | 内容 |
| --- | --- |
| 三个有利于 | 是否有利于发展社会主义社会的生产力；是否有利于增强社会主义国家的综合国力；是否有利于提高人民的生活水平 |
| 三个主体三个补充（陈云，1956 八大） | 国家经营和集体经营为主体、个体经营为补充；计划生产为主体、自由生产为补充；国家市场为主体、国家领导的自由市场为补充 |
| 两参一改三结合 | 干部参加劳动，工人参加管理，改革不合理的规章制度，干部、技术人员和工人三结合（鞍钢宪法） |
| 六条标准（1957） | 是否有利于团结全国各族人民、社会主义改造和建设、巩固人民民主专政、巩固民主集中制、巩固共产党的领导、社会主义的国际团结。其中最重要的是社会主义道路和党的领导 |
| 改革发展稳定 | 改革是动力，发展是目的，稳定是前提 |
| 三大法宝的关系 | 统一战线是实行武装斗争的统一战线，武装斗争是统一战线的中心支柱，党的组织是掌握这两个武器的英勇战士 |
| 革命道路三者关系 | 土地革命是基本内容，武装斗争是主要形式，农村革命根据地是战略阵地和依托 |

## 十、几组容易搞反的判断

| 说法 | 对错 | 正确表述 |
| --- | --- | --- |
| 新民主主义国家的国体是无产阶级专政 | 错 | 是各革命阶级的联合专政 |
| 社会主义制度在中国确立的标志是中华人民共和国的成立 | 错 | 是社会主义改造的胜利完成（1956 年底） |
| 新民主主义革命的性质是农民革命 | 错 | 是新式的特殊的资产阶级民主主义革命；说它"实质上是党领导下的农民革命"是另一回事 |
| 毛泽东在《论十大关系》中提出了优先发展重工业的中国工业化道路的思想 | 错 | 中国工业化道路的思想在《关于正确处理人民内部矛盾的问题》中提出，总方针是以农轻重为序 |
| "一国两制"说明两种制度在国家中的地位是均衡的、对等的 | 错 | 国家的主体部分实行社会主义制度，两者地位并不对等 |

| 党对军队绝对领导的根本原则和制度，是人民军队完全区别于一切旧军队的政治特质和根本优势 | 源卷标错 | 这句话本身符合党章表述，`毛概模拟题.pdf` 给的参考答案是 F，存疑，见 `30 客观题精编.md` 的说明 |
| 遵义会议事实上确立了毛泽东在党中央和红军的领导地位 | 对 | |
| 市场经济不等于资本主义，社会主义也有市场 | 对 | 南方谈话原话 |
| 邓小平理论是中国特色社会主义理论体系的开篇之作 | 对 | |
