## 一、新民主主义革命时期（1921–1949）

| 年份 | 会议 | 一句话记忆 |
| --- | --- | --- |
| 1922 | 中共二大 | 制定了党的最低纲领（民主革命阶段的反帝反封建纲领）和最高纲领，初步指出中国民主革命的性质、对象、动力；解决了革命对象问题 |
| 1923 | 中共三大 | 确定与国民党合作建立统一战线的方针，共同进行国民革命，但没有提出争夺革命领导权的问题 |
| 1924 | 国民党一大 | 第一次国共合作（国民革命联合战线）正式形成的标志 |
| 1925 | 中共四大 | 第一次提出无产阶级领导权和建立巩固的工农联盟的思想 |
| 1927 | 八七会议 | 毛泽东提出"政权是由枪杆子中取得的"；撤销陈独秀的总书记职务，结束右倾机会主义（投降主义）路线的统治；确定实行土地革命和武装反抗国民党反动派的总方针，把发动农民举行秋收起义作为当前主要任务 |
| 1929 | 古田会议 | 解决人民军队的建设问题，纠正红四军党内各种错误倾向，统一了认识，增强了团结。党对军队绝对领导的原则由此定型 |
| 1928 | 中共六大 | 明确规定没收地主阶级的一切土地，确定依靠贫雇农、联合中农的阶级路线，但土地所有权问题依然没有解决 |
| 1931 | 中共六届四中全会 | 王明"左"倾冒险主义开始占统治地位。四点表现：革命性质上混淆民主主义革命和社会主义革命的区别，把反资和反帝并列；革命形势上强调革命高潮的到来；革命道路上坚持以城市为中心；军事上搞教条主义，用所谓正规战争代替人民战争 |
| 1935 | 遵义会议 | 党第一次独立自主地运用马克思主义基本原理解决自己的路线、方针和政策；结束王明"左"倾冒险主义在党中央的统治，事实上确立毛泽东在红军和党中央的领导地位；是生死攸关的转折点，标志着党从幼年走向成熟 |
| 1935 | 瓦窑堡会议 | 批判党内长期存在的"左"倾关门主义，制定抗日民族统一战线的策略方针，彻底解决了联合民族资产阶级的问题；决定将"工农共和国"改为"人民共和国"；通过《关于目前形势与党的任务决议》，指出党既是无产阶级先锋队又是全民族先锋队，纠正了组织发展上的"左"倾关门主义错误 |
| 1935 | 榜罗镇会议 | 解决了俄界会议未能解决的在陕甘建立根据地的具体目的地问题，确定保卫与扩大陕北苏区根据地的战略决策 |
| 1935 | 共产国际七大 | 通过决议不再直接干涉各国党内的内部事务，为中国共产党独立自主地进行革命创造了较好的外部条件 |
| 1937 | 国民党五届三中全会 | 标志着抗日民族统一战线的初步形成 |
| 1937 | 国民党中央通讯社发布《中共中央为公布国共合作宣言》、蒋介石发表谈话 | 标志着抗日民族统一战线的正式形成 |
| 1938 | 中共六届六中全会 | 总结抗战以来的斗争经验，纠正王明右倾投降主义错误，明确党在民族战争中的地位；毛泽东作《论新阶段》报告，第一次提出"马克思主义中国化"；首次提出"四个服从" |
| 1940 | 延安各界宪政促进会 | 毛泽东发表《新民主主义的宪政》，指出宪政就是民主的政治 |
| 1944 | 国民参政会 | 林伯渠根据中共中央的指示正式提出建立民主联合政府的主张 |
| 1945 | 中共六届七中全会 | 通过《关于若干历史问题的决议》，正式宣布"党在奋斗的过程中产生了自己的领袖毛泽东，形成了中国化的马克思主义的思想体系即毛泽东思想" |
| 1945 | 中共七大 | 通过党章，把毛泽东思想确立为党的指导思想；刘少奇作《关于修改党章的报告》，第一次概括毛泽东思想的科学涵义；毛泽东作《论联合政府》，概括三大优良作风。政治路线是"放手发动群众，壮大人民力量，在我党的领导下，打败日本侵略者，解放全国人民，建立一个新民主主义的中国" |
| 1948 | 中共中央政治局会议（9 月） | 毛泽东首次提出建立无产阶级领导的以工农联盟为基础的"人民民主专政"问题 |
| 1949 | 中共七届二中全会 | 实现伟大历史性转变的纲领。两个转折：工作重心由乡村转到城市，中国由农业国转变为工业国、由新民主主义社会转变为社会主义社会。第一次明确提出执政党的建设问题，提出"两个务必"；提出"两个转变"同时并举的思想；规定引导个体经济朝集体化、现代化方向发展 |
| 1949 | 中国人民政治协商会议第一届全体会议 | 通过《共同纲领》，标志着中国共产党领导的多党合作和政治协商制度的形成 |

"两个务必"原文：务必使同志们继续地保持谦虚、谨慎、不骄、不躁的作风，务必使同志们继续地保持艰苦奋斗的作风。还要警惕资产阶级"糖衣炮弹"的侵蚀和攻击。

| 1956 | 中共八大 | 提出国内主要矛盾的新结论；作出把工作重点转移到社会主义建设上来的战略决策；坚持既反保守又反冒进、在综合平衡中稳步前进的经济方针；强调加强思想文化建设；提出执政党建设问题，重申反对个人突出、反对对个人歌功颂德。陈云在会上提出"三个主体，三个补充"；董必武指出依法办事是加强社会主义法制的中心环节（有法可依、有法必依）；邓小平作修改党章的报告，阐述执政党建设和加强党内外监督 |
| 1956 | 中共上海市第一次代表大会 | 最早提出"专政要继续，民主要扩大"的重要思想（更正：`毛概重大会议及重要著作汇总.pdf` 原文作"上海市党的一大"） |
| 1958 | 中共八大二次会议 | 通过"鼓足干劲，力争上游，多快好省地建设社会主义"的总路线；提出争取在 15 年或更短时间内在主要工业产品方面赶上和超过英国。会后全国掀起"大跃进"高潮（更正：`毛概各会议及著作汇总资料.pdf` 原文作"中国八大二次会议"） |

| 1962 | 扩大的中央工作会议（七千人大会） | 刘少奇进一步概括了群众路线的基本点：相信人民群众，相信他们能够自己解放自己，相信他们是历史的创造者；党必须根据群众的实践检验自己的工作，党的方针、政策、措施都必须"从群众中来，到群众中去" |
| 1964 | 第三届全国人民代表大会第一次会议 | 周恩来根据毛泽东的提议重新提出四个现代化的宏伟目标；正式提出两步走设想：第一步用 15 年时间即在 1980 年以前建成一个独立的比较完整的工业体系和国民经济体系，第二步在本世纪内全面实现农业、工业、国防和科学技术现代化，使我国国民经济走在世界前列 |

## 五、按主题串会议（考前扫一遍）

### 土地政策的演变

| 时间 | 文件或会议 | 政策 |
| --- | --- | --- |
| 1927 | 八七会议 | 确定土地革命和武装反抗国民党的总方针 |
| 1928 | 中共六大 | 没收地主阶级的一切土地，依靠贫雇农、联合中农；土地所有权问题未解决 |
| 1929 | 兴国县《土地法》 | 把井冈山《土地法》中的"没收一切土地"改为"没收一切公共土地及地主阶级的土地"，这是原则性的纠正。到 1931 年初基本形成一套比较可行的土地革命路线 |
| 抗日战争时期 | 党的政策 | 减租减息 |
| 1946 | 《关于清算地租及土地问题的指示》（《五四指示》） | 把减租减息的土地政策改变为没收地主土地的政策 |
| 1947 | 《中国土地法大纲》（全国土地会议通过，刘少奇主持） | 废除封建性和半封建性剥削的土地制度，实行耕者有其田 |
| 1947 | 《目前形势和我们的任务》 | 土改两项基本原则：必须满足贫雇农的要求；必须坚决地团结中农，不要损害中农的利益 |
| 1948 | 《在晋绥干部会议上的讲话》 | 完整提出土地改革总路线：依靠贫雇农，团结中农（阶级路线），有步骤、有分别地消灭封建剥削制度（总原则），发展农业生产（检验成功与否的根本标准） |

### 统一战线的四个阶段

| 时期 | 名称 | 标志 |
| --- | --- | --- |
| 国民革命时期 | 国民革命联合战线 | 国民党一大。阶级构成：无产阶级、农民阶级、小资产阶级、资产阶级；政治基础：新三民主义（旧三民主义与联俄、联共、扶助农工三大政策相结合） |
| 土地革命时期 | 工农民主统一战线 | 当时认为民族资产阶级已经全部成为反革命，一段时期内没有继续争取其同情和中立，犯了"左"倾关门主义错误，以王明为代表的"左"倾错误最为严重（更正：`毛概重大会议及重要著作汇总.pdf` 原文作"以王明为代表的'右'倾错误最为严重"，与同段的"左"倾关门主义自相矛盾） |
| 抗日战争时期 | 抗日民族统一战线 | 1937 年国民党五届三中全会标志初步形成，同年《中共中央为公布国共合作宣言》发表和蒋介石谈话标志正式形成。阶级构成多了民族资产阶级和以蒋介石为代表的大地主大资产阶级。四个特点：广泛的民族性和极大的复杂性；国共两党两个政权、两个军队的合作；双方没有共同遵守的共同纲领和固定的组织形式；处于既有利又极其复杂的国际环境中 |
| 解放战争时期 | 人民民主统一战线 | 1949 年中国人民政治协商会议通过《共同纲领》，标志着中国共产党领导的多党合作和政治协商制度形成 |

抗日民族统一战线的策略总方针（《目前抗日统一战线中的策略问题》《论政策》，1940）：发展进步势力，争取中间势力，孤立顽固势力。

"中间势力"的范围：用于分析三三制政权组成原则时，主要指民族资产阶级和开明士绅；用于分析抗日民族统一战线时，包括民族资产阶级、开明士绅和地方实力派。
