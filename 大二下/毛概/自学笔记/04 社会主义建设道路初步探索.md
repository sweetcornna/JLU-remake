# 社会主义建设道路初步探索的理论成果

整理自 `期末资料/毛概大题整理.pdf`（第四章）、`期末资料/毛概PPT整理.pdf`（第四章）、`毛概思维导图（解忧）.pdf`，客观题考点对照 `学习通章节测试答案.pdf` 第 2.4.6 节。

## 本章要点

- 两篇文献撑起整章：《论十大关系》（1956 年 4 月、5 月）和《关于正确处理人民内部矛盾的问题》（1957 年 2 月）。
- 三大理论成果：调动一切积极因素、正确认识和处理社会主义社会矛盾、走中国工业化道路。
- 经验教训六条，是论述题的常客。

## 一、背景

新中国成立初期我国搞社会主义建设主要是学习苏联经验，这在当时是必要的，也取得了一定成效。但盲目照搬苏联经验不符合中国国情，需要实现马克思主义同中国实际的"第二次结合"，积极探索符合中国特点的社会主义建设道路。

毛泽东在《论十大关系》里说："最近苏联方面暴露了他们在建设社会主义过程中的一些缺点和错误，他们走过的弯路，你们还想走？"

两次结合：

| | 内容 | 理论成果 |
| --- | --- | --- |
| 第一次结合 | 马克思主义同中国革命实际的结合，包括新民主主义革命（建立新中国）和社会主义革命（三大改造） | 毛泽东思想 |
| 第二次结合 | 马克思主义同中国社会主义建设实际的结合 | 发展了的毛泽东思想，以及后来的中国特色社会主义理论 |

## 二、调动一切积极因素为社会主义事业服务

### 1. 基本方针的提出

1956 年 4 月和 5 月，毛泽东先后在中央政治局扩大会议和最高国务会议上作《论十大关系》的报告，确定了一个基本方针："努力把党内党外、国内国外的一切积极的因素，直接的、间接的积极因素，全部调动起来"，为社会主义建设服务。

《论十大关系》标志着党探索中国社会主义建设道路的良好开端，是全党探索中国社会主义建设道路的先声。

### 2. 十大关系

前五条讲经济问题，后五条讲政治和思想文化领域的问题。

| 序号 | 关系 | 侧重 |
| --- | --- | --- |
| 1 | 重工业和轻工业、农业的关系 | 经济 |
| 2 | 沿海工业和内地工业的关系 | 经济 |
| 3 | 经济建设和国防建设的关系 | 经济 |
| 4 | 国家、生产单位和生产者个人的关系 | 经济 |
| 5 | 中央和地方的关系 | 经济 |
| 6 | 汉族和少数民族的关系 | 政治 |
| 7 | 党和非党的关系 | 政治（长期共存、互相监督） |
| 8 | 革命和反革命的关系 | 政治（分清敌我，化消极因素为积极因素） |
| 9 | 是非关系 | 政治（分清是非，采取"惩前毖后、治病救人"的方针） |
| 10 | 中国和外国的关系 | 对外（批判性学习一切民族一切国家的经验） |

> 更正：`毛概各会议及著作汇总资料.pdf` 把第八条写成"革命和非革命的关系"（更正：原文作"革命和非革命的关系"，应为"革命和反革命的关系"）。

《论十大关系》还提出了三个重要方针："长期共存、互相监督"（处理与民主党派关系，后来扩展为"长期共存、互相监督、肝胆相照、荣辱与共"十六字方针）、"百花齐放、百家争鸣"（文化方针）、"把国内外一切积极因素调动起来，为社会主义事业服务"（总原则）。

### 3. 贯彻基本方针的三条原则

1. 必须坚持中国共产党的领导。毛泽东多次强调"领导我们事业的核心力量是中国共产党"。他把"有利于巩固共产党的领导，而不是摆脱或者削弱这种领导"作为判断言论和行动是非的六条标准中最重要的一条。
2. 必须发展社会主义民主政治。党的八大提出要扩大社会主义民主，开展反对官僚主义的斗争，加强对国家工作的监督，着手系统地制定比较完备的法律，健全社会主义法制。
3. 必须正确认识社会主义发展阶段和建设规律。要在实践中积累经验、克服盲目性，大兴调查研究之风，总结正反两方面经验教训。毛泽东强调社会主义建设有艰难性、复杂性和长期性，建成社会主义不要讲得过早了。

## 三、正确认识和处理社会主义社会矛盾

出处：1957 年 2 月毛泽东作《关于正确处理人民内部矛盾的问题》的报告，第一次系统阐述了社会主义社会矛盾的学说。

### 1. 社会主义社会存在矛盾

矛盾是普遍存在的，社会主义社会同样存在矛盾，正是这些矛盾推动着社会主义社会不断向前发展。

### 2. 基本矛盾

社会主义社会的基本矛盾仍然是生产力与生产关系、经济基础与上层建筑的矛盾。

特点："又相适应又相矛盾"。一方面社会主义生产关系已经建立起来，与生产力是相适应的；另一方面它还很不完善，不完善的方面同生产力发展相矛盾。上层建筑与经济基础之间也是同样情况。相适应的方面是基本方面，相矛盾的方面是非基本方面。

由于这是非对抗性的矛盾，可以通过社会主义制度本身不断得到解决。这一点同以往社会的基本矛盾有根本不同。

### 3. 主要矛盾和根本任务

党的八大指出，社会主义改造完成以后，我国的主要矛盾已经是人民对于建立先进的工业国的要求同落后的农业国的现实之间的矛盾，已经是人民对于经济文化迅速发展的需要同当前经济文化不能满足人民需要的状况之间的矛盾。

根本任务：集中力量发展社会生产力，实现国家工业化，逐步满足人民日益增长的物质和文化需要。党中央提出把党和国家的工作重点转到技术革命和社会主义建设上来，要求全党学科学、学技术、学新本领。

### 4. 两类不同性质的矛盾

| | 敌我矛盾 | 人民内部矛盾 |
| --- | --- | --- |
| 实质 | 根本利益对立基础上的矛盾 | 根本利益一致基础上的矛盾 |
| 性质 | 对抗性 | 非对抗性 |
| 要分清 | 分清敌我 | 分清是非 |
| 解决方法 | 专政 | 民主 |

两类矛盾的存在是客观的，但不是固定不变的，在一定条件下可以相互转化。由于民族资产阶级具有两面性，工人阶级与民族资产阶级的矛盾属于人民内部矛盾。

人民内部矛盾占主导地位，正确处理人民内部矛盾是社会主义国家政治生活的主题。

### 5. 处理人民内部矛盾的具体方针（高频考点）

| 领域 | 方针 |
| --- | --- |
| 政治思想领域 | "团结-批评-团结"，采用说服、教育、讨论的方法 |
| 物质利益分配（国家、集体、个人） | "统筹兼顾、适当安排" |
| 人民群众和政府机关 | 坚持民主集中制，克服政府机关的官僚主义，同时加强对群众的思想教育 |
| 科学文化领域 | "百花齐放、百家争鸣" |
| 共产党和民主党派 | 在坚持社会主义道路和共产党领导的前提下"长期共存、互相监督" |
| 民族之间 | 各民族平等、团结互助 |

毛泽东的原话："思想斗争同其他的斗争不同，它不能采取粗暴的强制的方法，只能用细致的讲理的方法。"

### 6. 判断言论和行动是非的六条标准

根据我国宪法的原则提出，看是否有利于：团结全国各族人民；社会主义改造和社会主义建设；巩固人民民主专政；巩固民主集中制；巩固共产党的领导；社会主义的国际团结和全世界爱好和平人民的国际团结。其中最重要的是社会主义道路和党的领导。

### 7. 意义

科学揭示了社会主义社会的发展动力，为正确处理各种矛盾、创造良好的社会环境和政治环境提供了基本理论依据，也为社会主义改革奠定了理论基础。

## 四、走中国工业化道路

### 1. 问题的提出

在《关于正确处理人民内部矛盾的问题》中，毛泽东明确提出了中国工业化道路的问题，主要是指重工业、轻工业和农业的发展关系问题，要走一条有别于苏联的中国工业化道路。他的原话："我国的经济建设必须以重工业为中心，这一点必须肯定。但是必须同时注意发展农业和轻工业。"

总方针：以农业为基础，以工业为主导，以农轻重为序发展国民经济。

> 记法：苏联的路子是重轻农，中国的路子是农轻重。学习通那道题的四个选项就在"农轻重"和"重轻农"上做文章。

工业化发展思路是"两条腿走路"：重工业和轻工业并举、中央工业和地方工业并举、沿海工业和内地工业并举、大型企业和中小型企业并举。

### 2. 六条具体要求

1. 必须明确战略目标和战略步骤。战略目标是把中国建设成为一个具有现代农业、现代工业、现代国防和现代科学技术的强国。战略步骤是两步走：第一步建成一个独立的比较完整的工业体系和国民经济体系；第二步全面实现农业、工业、国防和科学技术现代化，使我国经济走在世界前列。
2. 必须采取正确的经济建设方针。党的八大提出既反保守又反冒进、在综合平衡中稳步前进的方针；毛泽东多次阐述统筹兼顾的方针；同时在自力更生的基础上积极争取外援。
3. 必须发展科学技术和文化教育。党中央提出"向科学进军"的口号，强调实现四个现代化关键在于科学技术现代化，要实行重点发展、迎头赶上的科技发展战略。
4. 必须重视知识分子工作。要建设一支宏大的工人阶级知识分子队伍。周恩来在 1956 年知识分子会议上提出知识分子是工人阶级一部分的观点。
5. 必须调整和完善所有制结构。毛泽东、刘少奇、周恩来提出把资本主义经济作为社会主义经济的补充的思想；朱德提出注意发展手工业和农业多种经营；陈云提出"三个主体，三个补充"。
6. 必须积极探索适合我国情况的经济体制和运行机制。

### 3. 陈云的"三个主体，三个补充"（必背）

| 主体 | 补充 |
| --- | --- |
| 国家经营和集体经营是工商业的主体 | 一定数量的个体经营是它的补充 |
| 计划生产是工农业生产的主体 | 按照市场变化而在国家计划许可范围内的自由生产是它的补充 |
| 国家市场是主体 | 一定范围内国家领导的自由市场是它的补充 |

这三条分别涉及所有制结构、生产、流通三个方面。陈云是在党的八大上提出的。

### 4. 经济体制和运行机制的探索

- 毛泽东：发展商品生产、利用价值规律，主张企业"两参一改三结合"（干部参加劳动，工人参加管理，改革不合理的规章制度，干部、技术人员和工人三结合）。这一经验来自鞍钢，被称为"鞍钢宪法"（更正：`毛概重大会议及重要著作汇总.pdf` 原文作"鞍干宪法"）。
- 刘少奇：使社会主义经济既有计划性又有多样性和灵活性，以及按经济办法管理经济。
- 陈云：建立适合于我国情况和人民需要的社会主义的市场。
- 邓小平：整顿工业企业，改善和加强企业管理，实行职工代表大会制度。

## 六、意义和经验教训

### 1. 三条意义

1. 巩固和发展了我国的社会主义制度。
2. 为开创中国特色社会主义提供了宝贵经验、理论准备、物质基础。
3. 丰富和发展了科学社会主义的理论和实践。

### 2. 六条经验教训（必背，记关键词：中国化、生产力、实际、法治、党建、对外）

1. 必须把马克思主义与中国实际相结合，探索符合中国特点的社会主义建设道路。
2. 必须正确认识社会主义社会的主要矛盾和根本任务，集中力量发展生产力。
3. 必须从实际出发进行社会主义建设，建设规模和速度要和国力相适应，不能急于求成。
4. 必须发展社会主义民主，健全社会主义法制。
5. 必须坚持党的民主集中制和集体领导制度，加强执政党建设。
6. 必须坚持对外开放，借鉴和吸收人类文明成果建设社会主义，不能关起门来搞建设。

## 七、改革开放前后两个历史时期的关系

这是一道思考题，答案来自习近平《关于坚持和发展中国特色社会主义的几个问题》。原话："我们党领导人民进行社会主义建设，有改革开放前和改革开放后两个历史时期，这是两个相互联系又有重大区别的时期，但本质上都是我们党领导人民进行社会主义建设的实践探索。"

中国特色社会主义是在改革开放历史新时期开创的，也是在新中国已经建立起社会主义基本制度并进行了 20 多年建设的基础上开创的。把握三点：

1. 如果没有 1978 年党果断决定实行改革开放并坚定不移推进，社会主义中国就不可能有今天的局面，可能遇到像苏联、东欧国家那样的亡党亡国危机。同时，如果没有 1949 年建立新中国并进行社会主义革命和建设，积累了重要的思想、物质、制度条件和正反两方面经验，改革开放也很难顺利推进。
2. 两个历史时期在思想指导、方针政策、实际工作上有很大差别，但两者绝不是彼此割裂的，更不是根本对立的。党在社会主义建设实践中提出的许多正确主张，当时没有真正落实，改革开放后得到了真正贯彻。
3. 对改革开放前的历史时期要正确评价，不能用改革开放后的历史时期否定改革开放前的历史时期，也不能用改革开放前的历史时期否定改革开放后的历史时期。
