## 第一章 毛泽东思想及其历史地位

### 单选题

1. 毛泽东思想是马克思列宁主义在中国的运用和发展，是被实践证明了的关于（ ）的正确的理论原则和经验总结，是中国共产党集体智慧的结晶。
   A 中国革命和建设　B 新民主主义革命　C 社会主义建设和改革　D 新民主主义革命和社会主义建设
   答案：A。"中国革命和建设"两个词都要有。

2. 下列关于党的七大表述正确的是（ ）
   A 完整表述了新民主主义革命的总路线　B 毛泽东作了《论新阶段》的报告　C 将马克思列宁主义与中国革命实践相统一的思想成果即毛泽东思想作为全党一切工作的指针　D 阐明了全党全国人民的奋斗目标是打败日本帝国主义，建立一个社会主义的中国
   答案：C。A 是 1948 年《在晋绥干部会议上的讲话》；B 是 1938 年六届六中全会；D 的七大政治路线是"建立一个新民主主义的中国"，不是社会主义的中国。

3. 下列关于十月革命对中国革命产生的影响表述不正确的是（ ）
   A 为中国革命提供了科学的指导理论　B 为中国的先进知识分子提供了新的认识国情的工具　C 使中国革命转变为世界无产阶级社会主义革命的一部分　D 将中国革命推进到世界资产阶级民主革命的历史潮流中
   答案：D。十月革命把中国革命带进的是世界无产阶级社会主义革命的潮流。

4. 在中国共产党的历史上，第一个明确提出"马克思主义中国化"的科学命题和重大任务，并深刻论证其必要性和极端重要性的是（ ）
   A 陈独秀　B 李大钊　C 毛泽东　D 王稼祥
   答案：C。出处是 1938 年六届六中全会《论新阶段》。

5. 不论过去、现在和将来，（ ）都是我们党的生命线和根本工作路线。
   A 实事求是　B 独立自主　C 群众路线　D 党的建设
   答案：C

6. 毛泽东把新民主主义革命和社会主义革命比喻为文章的上篇和下篇，形象地反映了（ ）的思想。
   A "毕其功于一役"　B "二次革命论"　C "无间断"革命　D 中国革命要分两步走
   答案：D

7. 毛泽东说辛亥革命"只把一个皇帝赶跑"是指（ ）
   A 没有推翻帝制　B 反帝反封建的革命任务没有完成　C 孙中山没有继续革命　D 袁世凯窃夺了胜利果实
   答案：B

8. 据《新民主主义论》中文化与政治经济关系的论述，毛泽东认为（ ）是经济工作和其他一切工作的生命线。
   A 政治宣传工作　B 思想政治工作　C 思想教育工作　D 文化传播工作
   答案：B

9. 十一届六中全会《决议》指出，毛泽东思想的活的灵魂有三个基本方面，即实事求是、（ ）、独立自主。
   A 党的建设　B 群众路线　C 统一战线　D 人民民主
   答案：B

10. 毛泽东在革命军队建设中规定了（ ）是人民军队的唯一宗旨。
    A 全心全意为人民服务　B 党指挥枪　C 一切依靠群众　D 三大纪律八项注意
    答案：A

11. 毛泽东思想初步形成于（ ）
    A 党的创立时期　B 土地革命战争前中期　C 抗日战争时期　D 解放战争时期
    答案：B。抗日战争时期是走向成熟。

12. 毛泽东思想形成的实践基础是（ ）
    A 中国工人运动的发展　B 马克思列宁主义在中国的传播　C 中国共产党领导人民进行革命和建设的成功实践　D 20 世纪前中期中国政局的变动
    答案：C

13. 毛泽东思想产生和形成的主要理论渊源是（ ）
    A 中国优秀的传统文化　B 马克思列宁主义　C 资产阶级民主思想　D 空想社会主义
    答案：B

14. （ ）在党的七大上，对"马克思主义中国化"从理论上作了进一步的阐述。
    A 毛泽东　B 刘少奇　C 邓小平　D 周恩来
    答案：B

15. 毛泽东在中共七大提出的，共产党人"区别于其他任何政党的显著标志之一"是指（ ）
    A 党的群众路线　B 党的三大作风　C 党的最低纲领　D 党的思想理论
    答案：B。出自《论联合政府》。

16. 中共十一届六中全会上，对毛泽东和毛泽东思想的历史地位做出评价的历史文献是（ ）
    A 《关于党的若干历史问题的决议》　B 《关于建国以来党的若干历史问题的决议》　C 《关于修改党章的报告》　D 《解放思想、实事求是，团结一致向前看》
    答案：B。A 是 1945 年六届七中全会通过的，别记混。

17. 实事求是的"求"的含义是（ ）
    A 研究　B 客观存在着的一切事物　C 规律性　D 发展
    答案：A。"实事"是 B，"是"是 C。

18. 实事求是思想路线的根本体现是（ ）
    A 尊重实践、尊重群众　B 尊重知识、尊重人才　C 尊重客观实际、尊重客观规律　D 发挥主观能动性，大胆创新
    答案：A

19. 中国共产党的思想路线是（ ）
    A 以经济建设为中心　B 解放思想实事求是　C 坚持四项基本原则　D 坚持马列主义毛泽东思想
    答案：B

20. 中国共产党的宗旨是全心全意为人民服务，这一宗旨是由（ ）
    A 党的性质决定的　B 党的纲领决定的　C 党的路线决定的　D 党的思想决定的
    答案：A

21. 马克思主义政党自身建设的根本任务是（ ）
    A 加强党的先进性建设　B 加强党的组织建设　C 加强党的思想建设　D 加强党的制度建设
    答案：A

22. 按照毛泽东提出的"三个世界"划分的理论，中国属于（ ）
    A 第一世界　B 第二世界　C 第三世界　D 介于第二世界和第三世界之间
    答案：C

23. 中国共产党一经诞生，就把（ ）确立为自己的初心和使命。
    A 实现共产主义　B 为中国人民谋幸福、为中华民族谋复兴　C 建设社会主义现代化强国　D 建立新中国

## 第二章 新民主主义革命理论

### 单选题

1. 新民主主义革命的领导力量是中国无产阶级及其先锋队中国共产党，指导思想是马克思列宁主义，前途是社会主义。上述特征决定了新民主主义革命的性质是（ ）
   A 无产阶级革命　B 农民阶级革命　C 新式的特殊的资产阶级民主主义革命　D 旧式的资产阶级民主主义革命
   答案：C

2. 毛泽东完整地表述了新民主主义革命总路线内容的著作是（ ）
   A 《中国革命和中国共产党》　B 《新民主主义论》　C 《在晋绥干部会议上的讲话》　D 《论人民民主专政》
   答案：C

3. 在诸多社会矛盾中，最主要的矛盾是（ ）
   A 生产关系和生产力的矛盾　B 帝国主义和中华民族的矛盾　C 经济基础和上层建筑的矛盾　D 封建主义和人民大众的矛盾
   答案：B。占支配地位的主要矛盾有两对，帝国主义和中华民族的矛盾是其中最主要的。

4. 新民主主义革命的最基本的动力是（ ）
   A 贫雇农　B 知识分子　C 无产阶级　D 工人和农民
   答案：C

5. 中国革命的中心问题是（ ）
   A 农民土地问题　B 统一战线问题　C 武装斗争问题　D 无产阶级的领导权问题
   答案：D。农民土地问题是中国革命的基本问题，别记混。

6. 新民主主义革命实质上是（ ）
   A 工人运动　B 中国共产党领导下的农民革命　C 封建社会的农民起义　D 无产阶级社会主义革命
   答案：B

7. 毛泽东第一次提出新民主主义革命的科学概念是在（ ）
   A 《中国革命和中国共产党》　B 《新民主主义论》　C 《在晋绥干部会议上的讲话》　D 《论人民民主专政》
   答案：A。1939 年。

8. 农村包围城市、武装夺取政权的道路，根本在于处理好（ ）
   A 土地革命、武装斗争、农村革命根据地建设三者之间的关系　B 统一战线、武装斗争、党的建设三者之间的关系　C 工人阶级、农民阶级、民族资产阶级三者之间的关系　D 进步势力、中间势力、顽固势力三者之间的关系
   答案：A。B 是三大法宝的关系，两题经常一起考。

9. 新民主主义革命的三大法宝是（ ）
   A 独立自主、群众路线、武装斗争　B 统一战线、武装斗争、党的建设　C 武装割据、土地革命、党的建设　D 实事求是、群众路线、统一战线

10. 加强中国共产党的思想建设的关键是（ ）
    A 贯彻民主集中制的组织原则　B 形成党领导一切的思想意识　C 以无产阶级思想克服和改造非无产阶级思想　D 确立现代自由和民主思想
    答案：C

11. 新民主主义革命的前途是（ ）
    A 建立新的资本主义制度　B 经过新民主主义过渡到社会主义　C 建立社会主义社会　D 实现共产主义

12. 近代中国社会最主要的矛盾是（ ）
    A 农民阶级和地主阶级的矛盾　B 帝国主义和中华民族的矛盾　C 封建主义和资本主义的矛盾　D 民族资本主义和帝国主义的矛盾
    答案：B

13. 实现无产阶级领导权的根本保证是（ ）
    A 坚持独立自主的原则　B 建立广泛的革命统一战线　C 建立强大的革命武装　D 加强无产阶级政党的建设

14. 近代中国的革命的性质是（ ）
    A 农民战争　B 资产阶级民主革命　C 无产阶级革命　D 社会主义革命

17. （ ）是中国革命的中心问题，也是新民主主义革命理论的核心问题。

18. 下列不属于新民主主义三大法宝的是（ ）

### 判断题

1. 新民主主义国家的国体是无产阶级专政。答案：错。国体是各革命阶级的联合专政。

   这一条存疑。"党对军队绝对领导的根本原则和制度"确实被表述为人民军队完全区别于一切旧军队的政治特质和根本优势，与党章和十九大报告的口径一致。原卷把它判为错，可能是想考"人民军队完全区别于旧军队的根本标志是全心全意为人民服务的宗旨"这个说法。考试遇到类似判断，按老师上课强调的口径答。
