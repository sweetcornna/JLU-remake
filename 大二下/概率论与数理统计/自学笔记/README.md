## 建议学习顺序

1. 先读 `03 考点与方法总结.md` 的"分值分布"和各节公式表，知道要考什么。
2. 按课件章节复习概率论部分（事件与概率、一维和二维随机变量、数字特征、极限定理），每学完一部分，到总结里找对应真题题号做掉。
3. 数理统计部分（抽样分布、参数估计、假设检验）题型固定，重点练矩估计、最大似然估计、无偏性、正态均值的置信区间和 t 检验。
4. 最后把 2022、2023 两套卷各完整做一遍，先不看解答，做完再对照订正。

## 考试信息

以下来自两年试卷本身：

- 两份都是第二学期期末考试卷，科目名《概率论与数理统计A》，试卷抬头为"公共数学教学与研究中心试题册"。选择题涂在答题卡上，其余题目写在答题卡指定区域，写在试题册上无效。
- 题型和分值两年相同：选择题 6 小题每题 3 分共 18 分，填空题 6 小题每题 3 分共 18 分，解答题 7 道共 64 分，满分 100。
- 2022 年解答题分值依次为 10、10、8、6、10、10、10；2023 年为 8、8、6、8、6、14、14。
- 按内容算，概率论部分两年分别占 72 分和 74 分，数理统计部分占 28 分和 26 分（明细见总结文件）。

课程目录 `README.md`（仓库说明）里的备考建议：这门课考试不难，掌握概率论部分至少能拿到 60% 的分数，想拿高分要认真学数理统计部分。这和上面的分值统计一致。
