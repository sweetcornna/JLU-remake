## 建议学习顺序

1. 先过 `01`。鸽巢原理的题不需要公式，练的是"把什么当盒子"，做完对后面几章的分组思路有帮助。
2. 再看 `02`。排列组合的公式表要背下来，非降路径和 Stirling 数是后面两章的基础。
3. `03` 和 `04` 可以并行。容斥原理和生成函数常常是同一道题的两种做法，比如多重集的 $r$-组合、有上界的整数解，两个文件里都有对应例子。
4. `05` 单独练手算，重点是特解的形式和代入初值这两步，原稿里错的几处都在这两步上。
5. `06` 最后看，内容很少。

## 已核对出的原稿错误

| 位置 | 原稿 | 更正 |
| --- | --- | --- |
| 3.1 | 共 14400 种 | $\binom{10}{5}\cdot 5!\cdot 5!=10!=3628800$，14400 只是 $5!\cdot 5!$ |
| 3.13 | 题干写 $x^4y^2x^2$ | 应为 $x^4y^2z^2$，系数 15120 |
| 3.15 | 末行把 $\binom{n+1}{2}$ 写成 $\frac{n(n+1)}{6}$ | 应为 $\frac{n(n+1)}{2}$ |
| 3.18（分水果） | 一般式右边 $\frac{2}{n+1}\binom{2n}{n}$ | 应为 $\frac{2}{n}\binom{2n-2}{n-1}$，$n=20$ 时为 3534526380 |
| 3.18（Stirling）、5.10 | $s(7,3)$ 作 1546 / 1524 | 都应为 1624，错在把 $s(n,1)$ 当成 1 |
| 3.21 (1) | PDF 版按 $2n$ 个座位算，得 $\binom{n+2}{2}$ | 题设是 $2n+1$ 个座位，答案 $\binom{n+1}{2}$，Word 版已改 |
| 4.6 | 两两交集只加了 5 项 | 漏 $\lvert A_3\cap A_4\rvert=1$，补上才等于它给出的 50 |
| 4.10 | 末行漏写系数 $n!$ | 交错和前面应乘 $n!$ |
| 4.11 | $\frac{10!\times 10!}{e^2}$ | 那是近似值，精确值 $D_{10}^2=1782120871521$ |
| 4.13 | 中间一步把同列两格的棋盘多项式写成 $1+x$ | 应为 $1+2x$，最终结果 $1+7x+12x^2+5x^3$ 正确 |
| 5.1 (2) | $\frac{-2x}{(1-2x)^2}$ | 应为 $\frac{-2x}{(1+2x)^2}$ |
| 6.2 (3) | $c_2=\frac{7}{36}$ | 应为 $\frac{7}{72}$ |
| 6.3 (1) | $c_2=10$ | 应为 $5$ |
| 6.3 (2) | 特解 $b_0=12,\ b_1=4$ | 应为 $b_0=\frac32,\ b_1=\frac12$，解为 $\frac{(n+3)(1-3^{n-1})}{2}$ |
| 6.3 (3) | $f(n)=4^{n-1}-3\cdot 2^n$ | 应为 $4^{n+1}-3\cdot 2^n$ |
| 2.7、大圆分球面 | 题干"超多 600 次"、递推写 $n>1$ | 分别应为"不少于 600 次"、$n\ge 1$ |

另外几处原稿只写了开头或只留了题目，笔记里补完并标了"整理补充"：2.12 的分组讨论、3.25、5.6、6.2 (2)、6.7、6.9 的求解，以及 6.8 缺失的行列式形状（按 $d_1,d_2$ 和递推式还原为三对角行列式）。

## 结果是怎么核对的

计数结果用 Python 做了枚举或公式对照，例如：非降路径按格递推（3.16、3.17、3.18），座位摆法、涂装方案、棋盘多项式直接枚举（3.21、4.13、4.14），递推关系逐项迭代后和通解比对（6.1–6.9），手镯涂色按旋转归类（第七章）。规模太大的题用小规模同构问题验证，比如 3.7 用 7 个人代替 15 个人。
