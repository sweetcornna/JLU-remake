## 建议学习顺序

1. 先看 `00 复习范围对照.md`，知道要考哪些节、计算题和应用题有哪几类。
2. 按章学 `01`～`09`。每章先读“本章要点”，再看正文，读完用“易混对比”和“易错点”自查。第4章篇幅最长，互斥算法和两类应用题都在这一章，多留时间。
3. 每学完一章，背 `10 名词解释.md` 和 `11`～`13` 里对应章节的题。
4. 计算题按 `00` 里的表逐类练：页面调度（第7章）、作业调度（第3章）、银行家算法和死锁检测（第5章）、磁头调度（第9章）、地址定位（第6章）、互斥算法（第4章）。
5. 应用题练 `04 互斥、同步与通信.md` 的“信号量与管程应用题”。
6. 考前用 `20 往届简答与教材习题索引.md` 自测，再过一遍 `14 选择题知识点.md`。

## 考试信息

`2024操作系统复习范围.docx` 写的是：

- 题型：名词解释、简答、计算、应用（单选可能不出）。
- 考试范围：1-9章。
- 计算：页面调度、作业调度、银行家算法、死锁检测算法、磁头调度、地址定位、互斥算法。
- 应用：信号量机制、管程机制。
- 具体节次见 `00 复习范围对照.md`。

课程目录 `README.md`（仓库作者的备考说明）里的几条建议：

- 计算和应用的题型老师会通知，不会超出复习范围，大题基本是模板题，最后一道 PV 操作题有一定难度。
- 想练管程题，可以看吉大的《计算机操作系统教程（第3版）习题与实验指导》，里面简答题和大题都有。
- `简答题/` 文件夹里的资料是往届学长学姐传下来的，操作系统没有固定题库，要自己再整理，名词解释和简答最好对着 PPT 的重点背。
