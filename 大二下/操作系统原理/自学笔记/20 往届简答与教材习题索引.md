## 2013级（英文题）

1. What is the purpose of a system call in an operating system?
   - 系统调用的目的，答案同 2015级第2题。
2. When an interrupt or a system call transfers control to the operating system, a kernel stack area separate from the stack of the interrupted process is generally used. Why?（原稿 separate 拼成了 seperate）
   - 题意：中断或系统调用把控制交给操作系统时，为什么要用独立于被中断进程的内核栈。
   - 源资料没有这道题的答案。整理补充的要点：
     - 用户栈指针由用户程序控制，可能是错的，甚至是恶意设置的，内核不能把自己的数据压到一个不可信的地址上。
     - 内核在栈上留下的数据如果放在用户空间，返回用户态后会被用户程序读到或改掉，既泄露信息，又可能破坏内核的执行。
     - 用户栈可能已经快满，内核再往上压数据会溢出。
   - 相关内容见 `11 简答题精编（第1-3章）.md` 第1章“何谓系统栈？何谓用户栈？”和第3章“中断发生时,旧的PSW和PC为何要压入系统栈?”。
3. For each of the following decimal virtual addresses, compute the virtual page number and offset for a 4-KB page and for an 8-KB page: 20000, 32768, 60000
   - 页号 = 地址整除页长，偏移 = 地址对页长取余。4 KB = 4096，8 KB = 8192。

   | 虚拟地址 | 4 KB 页：页号，偏移 | 8 KB 页：页号，偏移 |
   |---|---|---|
   | 20000 | 4，3616 | 2，3616 |
   | 32768 | 8，0 | 4，0 |
   | 60000 | 14，2656 | 7，2656 |

   - 验算：4×4096+3616=20000，14×4096+2656=60000。页长翻倍，页号减半，偏移不变（因为这三个地址除以 4096 得到的页号都是偶数）。
4. What are the conditions for a resource deadlock?
   - 死锁的四个必要条件：互斥、占有并等待（请求和保持）、不可剥夺、循环等待。
   - 答案见 `12 简答题精编（第4-6章）.md` 第5章“简述死锁的条件”。
5. Please list four methods for implementing files storage.
   - 题意是文件在磁盘上的存储分配方式。出题用的是《现代操作系统》的分法，四种是连续分配、链表分配、使用内存中表格的链表分配（FAT）、i 结点。（整理补充）
   - 本课程教材对应的是文件的物理结构：顺序结构、链接结构、索引结构、散列结构，见 `13 简答题精编（第7-9章）.md` 第8章“文件的物理组织有哪些形式？各自有什么特点？”。答题时可以把两种分法对应起来写。

第5题说明（整理补充）：

- 本课程教材讲的是临界区管理的三条正确性原则（互斥性、进展性、有限等待性），见 `12 简答题精编（第4-6章）.md` 第4章“画出临界区的框架，并介绍管理临界区的3个正确性原则”。
- 题目说“四个”，用的是《现代操作系统》2.3.2 的条件：
  - 任何两个进程不能同时处于临界区；
  - 不应对 CPU 的速度和数量做任何假设；
  - 临界区外运行的进程不得阻塞其他进程；
  - 不得使进程无限期等待进入临界区。

第8题说明（整理补充，依据是第3章笔记和简答题资料里关于中断现场的几道题）：

- 系统栈：中断发生时，硬件把被中断程序的 PSW 和 PC 压入系统栈，中断处理程序再把用到的寄存器压栈。中断处理完、不需要切换进程时，从系统栈恢复现场返回。
- PCB：中断处理后如果要切换进程，下降进程的现场从系统栈弹出，保存到它的 PCB 中；上升进程的现场从它的 PCB 恢复。
- 用户栈：如果中断事件由用户程序自行处理（如溢出、除数为零），断点要从系统栈弹出再压入用户栈。
- 对应的简答题：`11 简答题精编（第1-3章）.md` 第3章“中断发生时,旧的PSW和PC为何要压入系统栈?”“解释‘中断现场’与‘进程切换现场’的差异”“为什么保存在PCB中的现场都是核心级别的现场？”“如果中断由用户程序自行处理,为何需要将被中断程序的断点由系统栈弹出并压入用户栈?”。

第13题说明：

- 并行指两个或多个事件在同一时刻发生；并发指两个或多个事件在同一时间间隔内发生，宏观上同时，微观上交替。定义见 `01 操作系统概述.md` 1.1.2。
- 题目的六种情况，只有“进程与进程之间的并行”在单处理器上不会发生，其余五种都可能发生（整理补充）：
  - （1）进程与进程之间的并行：不会发生，同一时刻只有一个进程占用处理器；
  - （2）进程与进程之间的并发：可能；
  - （3）处理器与设备之间的并行：可能，设备工作时处理器可以运行别的程序；
  - （4）处理器与通道之间的并行：可能，通道执行通道程序时处理器可以继续计算；
  - （5）通道与通道之间的并行：可能；
  - （6）设备与设备之间的并行：可能。

第16、18、19题说明（整理补充，笔记和简答题资料里都没有答案，下面是答题要点）：

- 第16题：
  - 透明性：网络操作系统中，用户知道资源在哪台机器上，访问远程资源要显式指明机器；分布式操作系统对用户呈现为一个统一的系统，用户不必知道程序在哪台机器上运行、文件存在哪里。
  - 资源共享：网络操作系统通过网络通信共享资源，各机器仍各自管理自己的资源；分布式操作系统由系统统一管理和调度所有机器的资源，共享对用户透明。
- 第18题：集群一般由放在一起、通过高速局域网连接的一组计算机组成，对外表现为一台机器，主要目的是高性能计算、负载均衡或高可用；分布式系统的节点可以在地理上分散，各节点有一定自治性，重点在资源共享和协同完成任务。
- 第19题：云存储是把数据存放在由服务商通过网络提供的存储服务上，用户按需使用，不必关心底层存储设备；云计算是通过网络按需提供计算资源（服务器、存储、应用等）的服务模式，资源可以弹性伸缩，按使用量计费。
