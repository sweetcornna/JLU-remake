- 设备管理的功能：设备分配、设备处理、缓冲管理（有的书还加上虚拟设备）；目标：方便性、并行性、均衡性、独立性。

- I/O 控制方式：**程序控制查询（探询）** → **中断驱动** → **DMA** → **通道**。越往后 CPU 干预越少，CPU 与设备的并行程度越高。

- 缓冲用来缓和 CPU 与设备速度不匹配、减少中断次数、提高并行性；分单缓冲、双缓冲、循环缓冲、缓冲池。
- **SPOOLing**（假脱机）用磁盘上的输入井、输出井和常驻内存的输入输出进程，把独占设备改造成共享设备，也就是虚拟设备。

### 9.2.1 输入输出型设备与存储型设备

- 输入输出型设备包括：
  - 人机输入输出设备
  - 机机输入输出设备
- 存储型设备
  - 磁盘，磁带，光盘，U盘
- IO型设备
  - 扫描仪，打印机，鼠标，键盘，显示器
- 网络设备
  - 网卡，交换机，etc

### 9.2.2 块型设备与字符型设备

- 块型设备
- 字符型设备
- 时钟与显示器

### 9.2.3 独占型设备与共享型设备

- 共享型设备（块型）
  - 多个进程的IO操作以块为单位可以交叉
- 独占型设备（块型）
  - 多个进程的IO操作以块为单位不宜交叉
- 独占型设备（字符型）
  - 多个进程的IO操作以字符为单位不能交叉

### 9.2 设备的物理特性：磁盘块号换算

磁盘组有 l 个柱面、m 个盘面、每道 n 个扇区。三维地址（柱面号 i，盘面号 j，扇区号 k）和一维块号 b 按“相邻块在物理上最近”的原则编址，即先排满同一柱面，柱面内先排满同一盘面：

- 三维地址 → 块号：$b=i\cdot m\cdot n+j\cdot n+k$
- 块号 → 三维地址：$i=\lfloor b/(mn)\rfloor$，$j=\lfloor (b \bmod mn)/n\rfloor$，$k=(b \bmod mn) \bmod n$

课件的例子：l=2，m=3，n=3。块号 13 → i=⌊13/9⌋=1，13 mod 9=4，j=⌊4/3⌋=1，k=4 mod 3=1，即 1 号柱面 1 号盘面 1 号扇区；反过来 1×9+1×3+1=13。

### 9.4 设备的分配与去配

- 数据结构：设备控制块 UCB（设备标识、状态、相连通道、占有设备的进程），通道控制块 CCB（通道标识、状态、类型、占有通道的进程），系统设备表 SDT（设备类、总数、设备等待队列、UCB 表指针）。
- 独占型设备，用户的活动是“申请，使用，…，使用，释放”：
  - 申请：按设备类查 SDT 表 → 对该类设备的信号量做 P 操作 → 查 UCB 表找一台空闲设备分配。
  - 使用：分配通道 → I/O 传输 → 去配通道。
  - 释放：找到 SDT 表的对应入口 → 查 UCB 表去配 → 做 V 操作。
- 共享型设备，用户只有“使用，…，使用”，请求来自文件系统，每次读写一块，通常经过缓冲并排队优化。每次使用时分配通道、做 I/O、释放通道。
- 申请独占型设备时只指定设备类、不指定具体设备，这就是设备无关性的体现，理由见 `13 简答题精编（第7-9章）.md` 第9章。

## 易混对比

| I/O 控制方式 | CPU 干预频率 | 每次 I/O 传输单位 | 数据流向 | 特点 |
|---|---|---|---|---|
| 程序控制查询（探询） | 极高，一直轮询 | 字 | 设备 → CPU → 内存 | CPU 忙等，与设备完全串行 |
| 中断驱动 | 高，每个字中断一次 | 字 | 设备 → CPU → 内存 | CPU 与设备可以并行，中断太多开销大 |
| DMA | 中，一块传完中断一次 | 块（连续的若干块） | 设备 → 内存 | 没有指令系统，一次只能传一个数据块 |
| 通道 | 低，一组数据块传完才中断 | 一组块 | 设备 → 内存 | 有通道指令系统，可以执行通道程序，硬件复杂 |

| 磁盘调度算法 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| FCFS 先来先服务 | 按请求到达的次序 | 公平、简单 | 请求分散时寻道很长 |
| SSTF 最短查找时间优先 | 先服务离磁头最近的柱面 | 平均寻道时间短 | 磁道歧视，可能饥饿 |
| SCAN 扫描（电梯） | 沿一个方向服务到头再掉头 | 公平，效率较高 | 两端柱面等得比中间久；有磁头黏性 |
| C-SCAN 循环扫描 | 只在一个方向上服务，到头后快速回到另一端第一个请求 | 等待时间比较均匀 | 回扫的移动也要算进移动量 |
| N 步扫描 | 请求分成长度为 N 的子队列，逐个子队列用扫描算法 | 避免磁头黏性 | N=1 退化为 FCFS，N 很大接近 SCAN |
| 冻结扫描 | 一轮扫描只服务开始时已到的请求，新请求留到回程 | 避免磁头黏性 | |

| | 缓冲 buffering | 缓存 caching |
|---|---|---|
| 目的 | 缓和数据到达和离去速度不一致 | 提高访问速度 |
| 数据副本 | 同一数据只有一个副本 | 同一数据有多个副本 |
| 例子 | 打印输出先放缓冲区 | 远程文件的一部分预取到本地 |

| | 独占型设备 | 共享型设备 | 虚拟设备 |
|---|---|---|---|
| 使用方式 | 一段时间内只能给一个进程用 | 多个进程的 I/O 以块为单位可以交叉 | 用共享设备模拟出的多台独占设备 |
| 例子 | 打印机、磁带机、所有字符设备 | 磁盘 | SPOOLing 打印机 |

| | 逻辑设备 | 物理设备 |
|---|---|---|
| 谁用 | 用户程序里写的设备名 | 实际执行 I/O 的硬件 |
| 对应 | 对应一类设备 | 具体某一台 |
| 转换 | 操作系统通过系统设备表等把逻辑设备名映射到物理设备 | |

## 易错点

- DMA 和通道都能让数据在设备和内存之间直接传送；区别在于通道有自己的指令系统，DMA 没有。
- 通道没有独立的存储空间，通道程序和交换的数据都放在主机内存里。
- 时钟和显示器既不是块型设备，也不是字符型设备。
- SSTF 会饥饿；SCAN、C-SCAN 基本公平，但同一柱面请求不断时会有磁头黏性。
- C-SCAN 计算引臂移动量时要把回扫的那段距离算上（课件和参考书的例题都是这样算的）。
- 设备无关性是指用户程序使用逻辑设备名，由系统映射到物理设备。笔记附录名词表把它解释成“把设备当文件看待”，那是 UNIX 的实现手段，答题时先写前一种说法。
- 缓冲区不是越大越好：太大浪费空间（平均浪费半个缓冲区），太小 I/O 次数多、链指针也占空间。

- 计算题“磁头调度”：下面 9.9.2 有 FCFS、SSTF、SCAN、C-SCAN 的例图（请求序列 130、42、180、15、108、68、97，磁头在 53，总移动量分别是 630、314、203、319），9.9.3 是完整的例题（循环扫描，算寻道时间、旋转延迟、传输时间，总处理时间 185.4 ms）。做题时先写出服务顺序，再逐段算距离。
