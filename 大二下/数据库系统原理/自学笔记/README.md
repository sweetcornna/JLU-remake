# 数据库系统原理自学指南

这个文件夹把课程目录里的笔记、老师发的复习资料、历年题整理和教材课后习题答案，按"知识点 → 考试题型 → 课后习题"三层重新整理成 Markdown。教材是《数据库系统概念》第 6 版，章节号都按这本书。

每个文件开头写了整理自哪些原文件、哪几页。原稿答案有错的地方在原处标了"更正"，原稿没有答案、整理时补写的标了"整理补充"。

## 建议学习顺序

1. 按 01 到 11 的顺序过知识点。关系代数（02）、SQL（03、04）、E-R（06）、范式（07）、事务和并发（10、11）是考试大题的来源，这几份要细看。
2. 每学完一章，做对应的课后习题（30 起），检查概念是否真的懂了。时间紧时，先做和考试大题相关的第 2、3、4、6、7、8、14 章。
3. 知识点过完后做 21 到 25。先做 23 和 24，这两类题步骤固定，练几道就熟；22 和 25 需要多写几遍。
4. 考前一周背 20，再把 25 里的 SQL 重新默写一遍。

## 考试信息

以下内容来自课程目录的 `README.md`（学长的备考回忆），不是官方信息，以当年老师通知为准：

- 题型大致是选择（可能没有）、简答、应用。22 级软件学院的回忆版本是 5 道简答加分析题加最后一道 SQL 与关系代数大题。
- 反复出现的简答题有"中国有哪些自主设计的数据库""如何实现多表更新""两阶段封锁协议是什么，为什么要有严格两阶段封锁和强两阶段封锁"。
- 最后一道大题分值高（回忆是 20 分），给一整段题干，要求写 SQL 和关系代数，考过视图创建、关系代数里的排序、SQL 的 date 类型操作，比平时练习的单句 SQL 难。学长的建议是不会写代码也先用中文写出思路，第一小问里的判断别忘了写。
- E-R 图题主观性强，按题意把实体、联系、基数画清楚即可。
- 注意核对考试时间，当年出现过教务系统和通知时间不一致的情况。
