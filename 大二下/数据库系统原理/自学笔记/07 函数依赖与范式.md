# 函数依赖与范式

整理自 `笔记/数据库系统原理笔记.pdf` 第 93–111 页（第 8 章 关系模式设计）、`笔记/数据库期末复习题整理.pdf` 第 9–10 页的第 8 章名词和第 66–82 页的"范式相关整理"，以及 `老师资料/范式及范式分解.docx`。原稿里的公式和手写解答都在图片里，下面每一步推导都重新算过。

## 本章要点

- 数据冗余会带来更新异常、插入异常、删除异常。办法是把模式分解成更小的模式，分解必须**无损**，最好还能**保持依赖**。
- 函数依赖 $\alpha \rightarrow \beta$：任意两个元组在 α 上取值相同，在 β 上取值也相同。K 是超码当且仅当 $K \rightarrow R$。
- Armstrong 公理（自反律、增补律、传递律）正确有效且完备；合并律、分解律、伪传递律可以由它们推出。
- 属性闭包 $\alpha^+$ 是做题的基本工具：判超码、判某个依赖是否成立、求候选码、找无关属性、判保持依赖都要用。
- BCNF：$F^+$ 中每个非平凡依赖的左部都是超码。3NF 在此基础上放宽一条：$\beta - \alpha$ 中每个属性都属于某个候选码。BCNF 一定是 3NF。
- BCNF 分解一定无损，但不一定保持依赖；3NF 合成算法得到的分解无损又保持依赖，但可能留有冗余。
- 正则覆盖 $F_c$ 和 F 等价，不含无关属性，各依赖左部互不相同，而且不唯一。
- 二元分解 $\lbrace R_1, R_2 \rbrace$ 无损的判定：$R_1 \cap R_2$ 是 $R_1$ 或 $R_2$ 的超码。三个以上的分解用 chase 表格法。
- 判断原模式 R 是否属于 BCNF 或 3NF，只查 F 就够了；判断分解出来的子模式，要看 $F^+$ 在子模式上的投影。
- 多值依赖是函数依赖的推广。4NF：$D^+$ 中每个非平凡多值依赖的左部都是超码。4NF 一定是 BCNF。

## 1. 好的关系模式

### 冗余带来的问题

数据冗余可能造成数据不一致，表现为三种异常：更新异常、插入异常、删除异常。

笔记的例子：`bor_loan(customer_name, loan_number, amount)` 里，Curry、Hayes、Jackson 三人共用贷款 L-100，金额 10000 存了 3 遍。修改这笔贷款的金额要改 3 行。拆成 `loan(loan_number, amount)` 和 `borrower(customer_name, loan_number)` 后只要改 1 行。

### 分解时要注意什么

- 不是所有分解都有必要。`loan_amt_br(loan_number, amount, branch_name)` 本身没有冗余和不一致的问题，拆成 `loan(loan_number, amount)` 和 `loan_branch(loan_number, branch_name)` 后，按贷款号查分行名反而要多做一次自然连接。
- 有些分解会丢信息。`employee(employee_id, employee_name, telephone_number, start_date)` 按 `employee_name` 拆成 `(employee_id, employee_name)` 和 `(employee_name, telephone_number, start_date)`。如果有两个员工都叫 Kim，自然连接回来会得到 4 行，每个 `employee_id` 都和两个人的电话、入职日期各配了一次，其中 2 行是错的。元组变多了，但分不清哪些组合是真的，信息实际上丢了。
- 无损分解：分解后再做自然连接，得到的表和原表完全相同；否则叫有损分解。（更正：笔记在"无损分解"后面标的英文是 A Lossy Decomposition，lossy 指有损分解。）

### 设计目标

令 R 为关系模式，F 为 R 上的函数依赖集。先判断 R 是不是好的范式；不是的话，把 R 分解为 $\lbrace R_1, R_2, \dots, R_n \rbrace$，要求：

1. 分解后的 $R_1, R_2, \dots, R_n$ 都是好的范式；
2. 分解是无损的；
3. 最好还能保持函数依赖。

## 2. 第一范式

- 域原子性：属性域中每个取值都是不可再分的单元。
- 关系模式 R 的所有属性域都是原子的，R 就属于第一范式（1NF）。

## 3. 函数依赖

### 定义

设 $\alpha \subseteq R$，$\beta \subseteq R$。R 上的函数依赖 $\alpha \rightarrow \beta$ 成立，当且仅当：对 R 的任意合法关系 r，r 中任意两个元组 $t_1$、$t_2$，若 $t_1[\alpha] = t_2[\alpha]$，则 $t_1[\beta] = t_2[\beta]$。通俗地说，两个元组 α 部分相同，β 部分也一定相同，β 的取值由 α 决定。

函数依赖有两种用法：

- 判定关系是否满足函数依赖：关系实例 r 满足函数依赖集 F 的要求，就说 r 满足 F。
- 定义关系模式上的约束：只考虑 R 上满足 F 的关系，就说 F 在 R 上成立。

### 码和主属性

用函数依赖可以重新定义码：

- 超码：$K \subseteq R$，K 是 R 的超码当且仅当 $K \rightarrow R$。超码的值能唯一确定关系中的一个元组。
- 候选码：K 是 R 的候选码当且仅当 $K \rightarrow R$，并且不存在 $\alpha \subset K$ 使 $\alpha \rightarrow R$。候选码是最小的超码，删掉其中任何一个属性就不再是超码。
- 主码：一个关系有多个候选码时，选定其中一个作为主码。
- 主属性：包含在某个候选码中的属性。非主属性：不包含在任何候选码中的属性。

例：`bor_loan(customer_id, loan_number, amount)` 中有 `loan_number → amount`；`(customer_id, loan_number)` 是超码，也就是 `customer_id, loan_number → customer_id, loan_number, amount`。

### 几种函数依赖

- 平凡函数依赖：$\alpha \rightarrow \beta$ 是平凡的，当且仅当 $\beta \subseteq \alpha$。平凡依赖在任何关系上都成立，比如 `customer_name, loan_number → customer_name`、`customer_name → customer_name`。
- 完全函数依赖：$X \rightarrow Y$，并且对 X 的任何真子集 X' 都有 $X' \nrightarrow Y$，称 Y 完全函数依赖于 X。
- 部分函数依赖：$X \rightarrow Y$，但存在 X 的真子集 X' 使 $X' \rightarrow Y$，称 Y 部分函数依赖于 X。
- 传递函数依赖：X、Y、Z 是 R 中互不相同的属性集，$X \rightarrow Y$、$Y \nrightarrow X$、$Y \rightarrow Z$，称 Z 传递函数依赖于 X。

### 逻辑蕴含与 F 的闭包

- 逻辑蕴含：给定关系模式 R，如果每个满足 F 的关系实例 r(R) 也满足 f，就说 F 逻辑蕴含 f。例：$R = (A, B, C)$，$F = \lbrace A \rightarrow B, B \rightarrow C \rbrace$，F 逻辑蕴含 $A \rightarrow C$。
- F 的闭包 $F^+$：F 逻辑蕴含的所有函数依赖组成的集合，也就是只要 F 成立就必然成立的那些依赖。$F^+$ 是 F 的超集。

### Armstrong 公理

| 规则 | 内容 |
| --- | --- |
| 自反律 | 若 $\beta \subseteq \alpha$，则 $\alpha \rightarrow \beta$ |
| 增补律 | 若 $\alpha \rightarrow \beta$，γ 为属性集，则 $\gamma\alpha \rightarrow \gamma\beta$ |
| 传递律 | 若 $\alpha \rightarrow \beta$ 且 $\beta \rightarrow \gamma$，则 $\alpha \rightarrow \gamma$ |

Armstrong 公理是正确有效的（sound，推出来的依赖一定成立），也是完备的（complete，$F^+$ 中的依赖都能推出来）。由它们可以推出三条常用规则：

| 规则 | 内容 | 证明 |
| --- | --- | --- |
| 合并律 | 若 $\alpha \rightarrow \beta$ 且 $\alpha \rightarrow \gamma$，则 $\alpha \rightarrow \beta\gamma$ | $\alpha \rightarrow \beta$ 增补 γ 得 $\alpha\gamma \rightarrow \beta\gamma$；$\alpha \rightarrow \gamma$ 增补 α 得 $\alpha \rightarrow \alpha\gamma$；两者传递得 $\alpha \rightarrow \beta\gamma$ |
| 分解律 | 若 $\alpha \rightarrow \beta\gamma$，则 $\alpha \rightarrow \beta$ 且 $\alpha \rightarrow \gamma$ | 由自反律 $\beta\gamma \rightarrow \beta$、$\beta\gamma \rightarrow \gamma$，再分别和 $\alpha \rightarrow \beta\gamma$ 传递 |
| 伪传递律 | 若 $\alpha \rightarrow \beta$ 且 $\gamma\beta \rightarrow \delta$，则 $\alpha\gamma \rightarrow \delta$ | $\alpha \rightarrow \beta$ 增补 γ 得 $\alpha\gamma \rightarrow \gamma\beta$，再和 $\gamma\beta \rightarrow \delta$ 传递 |

### 求 F 的闭包

老师资料和笔记给的算法，改写成步骤：

1. 令 $F^+ = F$。
2. 对 $F^+$ 中每个函数依赖应用自反律和增补律，把得到的依赖加入 $F^+$。
3. 对 $F^+$ 中每一对能用传递律连起来的依赖，把得到的依赖加入 $F^+$。
4. 重复第 2、3 步，直到 $F^+$ 不再变化。

$F^+$ 通常非常大，做题时很少把它整个求出来，一般用下一节的属性闭包判断某个依赖在不在 $F^+$ 里。

## 4. 属性闭包

### 定义和算法

- 如果 $\alpha \rightarrow B$，称属性 B 被 α 函数确定。
- 在 F 下由 α 函数确定的所有属性组成的集合，叫 α 在 F 下的闭包，记作 $\alpha^+$。

算法：

```text
result := α
重复下面的过程，直到 result 不再变化：
    对 F 中每个函数依赖 β → γ：
        如果 β ⊆ result，就令 result := result ∪ γ
最后的 result 就是 α⁺
```

例子见典型题 3。

### 属性闭包的用途

- 判断 α 是否为超码：看 $\alpha^+ = R$ 是否成立。
- 验证函数依赖 $\alpha \rightarrow \beta$ 是否成立（是否属于 $F^+$）：看 $\beta \subseteq \alpha^+$ 是否成立。
- 计算 $F^+$：对 R 的每个属性子集 γ 求出 $\gamma^+$，对每个 $S \subseteq \gamma^+$ 写出 $\gamma \rightarrow S$。

## 5. BCNF

### 定义

具有函数依赖集 F 的关系模式 R 属于 BCNF（Boyce-Codd 范式），条件是：对 $F^+$ 中所有形如 $\alpha \rightarrow \beta$ 的函数依赖（$\alpha \subseteq R$，$\beta \subseteq R$），下面至少有一条成立：

- $\alpha \rightarrow \beta$ 是平凡的函数依赖（$\beta \subseteq \alpha$）；
- α 是 R 的一个超码。

换句话说，$F^+$ 中任何一个非平凡依赖，左部都必须是超码。

例 1（笔记）：`bor_loan(customer_id, loan_number, amount)` 中有 `loan_number → amount`。它不是平凡依赖，`loan_number` 也不是超码（一笔贷款可以对应多个顾客），所以 `bor_loan` 不属于 BCNF，`amount` 会重复存储。

例 2（老师资料）：`instr_dept(ID, name, salary, dept_name, building, budget)` 中 `dept_name → building, budget` 成立，`dept_name` 不是超码，所以不属于 BCNF。这个模式的主码是 `ID`，原稿在 `dept_name` 下面也画了下划线，应是排版残留。

### 怎么判定

- 判断原模式 R 是否属于 BCNF，只需检查 F 中的依赖，不用展开 $F^+$。原因：假如 $F^+$ 中有违例依赖 $X \rightarrow Y$，用 F 求 $X^+$ 时，第一条让 result 变大的依赖，左部包含在 X 里，因而也不是超码，它本身就违例。
- 判断分解后的子模式 $R_i$ 是否属于 BCNF，要看 $F^+$ 中只含 $R_i$ 属性的依赖。F 里跨几个子模式的依赖，推出来的依赖可能正好落在 $R_i$ 里。实际做法：对 $R_i$ 的属性子集 α，在 F 下求 $\alpha^+$。如果 $\alpha^+$ 含有 $R_i - \alpha$ 中的某些属性，但没有包含 $R_i$ 的全部属性，那么 $\alpha \rightarrow (\alpha^+ - \alpha) \cap R_i$ 就是违例依赖。例子见典型题 7、8。

### BCNF 分解算法

设 R 不属于 BCNF，则至少存在一个非平凡函数依赖 $\alpha \rightarrow \beta$，α 不是 R 的超码。用下面两个模式代替 R：

- $\alpha \cup \beta$
- $R - (\beta - \alpha)$；当 $\alpha \cap \beta = \emptyset$ 时直接写成 $R - \beta$

分出来的模式可能还有不属于 BCNF 的，就继续分，最后得到一组 BCNF 模式。写成步骤：

```text
result := {R}
计算 F⁺
当 result 中存在不属于 BCNF 的模式 Ri 时，重复：
    在 Ri 上找一个成立的非平凡依赖 α → β，要求 α → Ri 不在 F⁺ 中（α 不是 Ri 的超码），且 α ∩ β = ∅
    result := (result - {Ri}) ∪ {Ri - β} ∪ {α ∪ β}
```

每个 $R_i$ 最后都属于 BCNF，而且分解是无损的。无损的理由：每一步分出的两个模式是 $R_i - \beta$ 和 $\alpha \cup \beta$，因为 $\alpha \cap \beta = \emptyset$，两者的交集就是 α；又有 $\alpha \rightarrow \alpha\beta$，α 是 $\alpha \cup \beta$ 的超码，满足第 6 节的无损条件。

选违例依赖时，右部可以直接取 $\alpha^+ - \alpha$ 落在当前模式里的部分，一次分干净一些。选择顺序不同，结果可能不同，保持依赖的情况也可能不同（见典型题 20、21）。

## 6. 无损分解

### 定义

r(R) 是 R 上的关系，R 分解为 $R_1$ 和 $R_2$。如果对 R 上所有合法关系 r 都有 $\Pi_{R_1}(r) \bowtie \Pi_{R_2}(r) = r$，这个分解就是无损分解。

### 二元分解：交集法

$R_1$ 和 $R_2$ 是 R 的无损分解，只要下面两个函数依赖中至少有一个属于 $F^+$：

- $R_1 \cap R_2 \rightarrow R_1$
- $R_1 \cap R_2 \rightarrow R_2$

也就是 $R_1 \cap R_2$ 是 $R_1$ 或 $R_2$ 的超码。做法：

1. 求 $R' = R_1 \cap R_2$；
2. 求 $R'^+$；
3. $R'^+$ 包含 $R_1$ 或 $R_2$ 的全部属性，就是无损分解，否则不是。

复习资料里的等价写法是判断 $R_1 \cap R_2 \rightarrow R_1 - R_2$ 或 $R_1 \cap R_2 \rightarrow R_2 - R_1$ 是否成立。这个条件是充分条件；约束只有函数依赖时，它也是必要条件。

### 多元分解：chase 表格法

分解出三个及以上模式时，用复习资料里的表格法：

1. 画表：每一行对应一个分解出的模式 $R_i$，每一列对应 R 的一个属性 $A_j$。
2. 填初值：$A_j$ 属于 $R_i$，第 i 行第 j 列填 $a_j$；否则填 $b_{ij}$。
3. 用 F 中的每个函数依赖 $X \rightarrow Y$ 修改表格：找出在 X 的各列上符号完全相同的行，让这些行在 Y 的各列上也相同。修改规则：这几个符号里有 $a_j$，就都改成 $a_j$；全是 b，就统一改成其中一个（一般取行号最小的那个）。
4. 把 F 中的依赖一轮一轮地用，直到表格不再变化。某一行全变成 a，分解就是无损的；最后没有全 a 的行，就是有损的。中途出现全 a 行可以提前停。

注意每轮都要把 F 中的依赖全部过一遍，按一条依赖改完之后，前面用过的依赖可能又能改了。例子见典型题 16、17。

## 7. 保持依赖

函数依赖是重要的一致性约束，每次更新数据都要检查，开销很大。如果每个依赖都能在单个关系内检查，就不用先做连接，开销小得多。

- 限定：R 分解为 $R_1, R_2, \dots, R_n$，$F^+$ 中所有只包含 $R_i$ 中属性的函数依赖组成的集合 $F_i$，称为 F 在 $R_i$ 上的限定。检查 $F_i$ 中的依赖只需要看 $R_i$ 这一个关系。
- 保持依赖：如果 $(F_1 \cup F_2 \cup \dots \cup F_n)^+ = F^+$，分解就是保持依赖的。（更正：老师资料写作"如果分解是无损的，当如下等式成立"，这个等式定义的是保持依赖，和无损无关。）

判定方法一（按定义）：计算 $F^+$，对每个 $R_i$ 求出限定 $F_i$，令 $F' = F_1 \cup F_2 \cup \dots \cup F_n$，再计算 $F'^+$，看它是否等于 $F^+$。要算 $F^+$，太麻烦，只适合很小的题。

判定方法二（逐条检查 F 中的依赖，常用）。对 F 中的每个 $\alpha \rightarrow \beta$：

```text
result := α
重复下面的过程，直到 result 不再变化：
    对分解出的每个模式 Ri：
        t := ((result ∩ Ri) 在 F 下的闭包) ∩ Ri
        result := result ∪ t
如果 β ⊆ result，α → β 被保持；否则没有被保持
```

- 这里的闭包都是在原来的 F 下求的。每次都和 $R_i$ 取交集，表示只在 $R_i$ 内部讨论。
- 一轮下来 result 包含了 β，这条依赖就保持了，可以提前结束；result 没变化又不包含 β，就说明分解后的依赖推不出 $\alpha \rightarrow \beta$。
- 某条依赖的全部属性都在同一个 $R_i$ 里，它一定被保持，不用算。
- F 中有一条依赖没被保持，整个分解就不保持依赖。

无损分解不一定保持依赖：分解后，原来的一些依赖可能只有把几个关系做自然连接之后才能检验。BCNF 分解就不一定保持依赖，例子见典型题 9、10。（更正：笔记这里的小标题写作"BCNF分解不能保持依赖"，它举的第一种分解其实保持了依赖，准确的说法是不一定能保持。）

## 8. 正则覆盖

### 无关属性

去掉函数依赖中的一个属性后，函数依赖集的闭包不变，这个属性就是无关属性。设 F 是函数依赖集，$\alpha \rightarrow \beta \in F$：

- 左部：若 $A \in \alpha$，且 F 逻辑蕴含 $(F - \lbrace \alpha \rightarrow \beta \rbrace) \cup \lbrace (\alpha - A) \rightarrow \beta \rbrace$，则 A 在 α 中是无关的。
- 右部：若 $A \in \beta$，且 $(F - \lbrace \alpha \rightarrow \beta \rbrace) \cup \lbrace \alpha \rightarrow (\beta - A) \rbrace$ 逻辑蕴含 F，则 A 在 β 中是无关的。

两个方向正好相反。左部删掉属性后依赖变强了，要看原来的 F 能不能推出新依赖；右部删掉属性后依赖变弱了，要看新的依赖集还能不能推出原来的 F。

例子（老师资料、笔记）：$F = \lbrace A \rightarrow C, AB \rightarrow C \rbrace$，B 在 $AB \rightarrow C$ 中是无关的，因为 F 本身就有 $A \rightarrow C$，去掉 B 得到的依赖能由 F 推出。$F = \lbrace A \rightarrow C, AB \rightarrow CD \rbrace$，C 在 $AB \rightarrow CD$ 中是无关的，因为删掉 C 以后，仍然可以由 $A \rightarrow C$ 推出 $AB \rightarrow C$。

用属性闭包判断更方便：

| 位置 | 做法 |
| --- | --- |
| 左部 $A \in \alpha$ | 用当前的依赖集 F 计算 $(\alpha - A)^+$，如果包含 β，A 在 α 中无关 |
| 右部 $A \in \beta$ | 用 $F' = (F - \lbrace \alpha \rightarrow \beta \rbrace) \cup \lbrace \alpha \rightarrow (\beta - A) \rbrace$ 计算 $\alpha^+$，如果包含 A，A 在 β 中无关 |

（更正：笔记说"无关属性只可能出现在依赖一端超过一个属性的情况下"。左部只有一个属性时确实不会有无关属性，但右部只有一个属性时也可能无关。例如 $F = \lbrace A \rightarrow B, B \rightarrow C, A \rightarrow C \rbrace$，$A \rightarrow C$ 中的 C 是无关的：去掉它以后由 $A \rightarrow B$、$B \rightarrow C$ 仍能推出 $A \rightarrow C$，这条依赖整个可以删掉。）

### 正则覆盖的定义

正则覆盖 $F_c$ 是与 F 等价的最小函数依赖集，满足：

- F 逻辑蕴含 $F_c$ 中的所有依赖，$F_c$ 也逻辑蕴含 F 中的所有依赖；
- $F_c$ 中任何函数依赖都不含无关属性；
- $F_c$ 中各函数依赖的左部互不相同，即不存在 $\alpha_1 \rightarrow \beta_1$ 和 $\alpha_2 \rightarrow \beta_2$ 满足 $\alpha_1 = \alpha_2$。

### 求正则覆盖

```text
Fc := F
重复下面的过程，直到 Fc 不再变化：
    用合并律把 Fc 中左部相同的依赖合成一条，如 α → β1 和 α → β2 合成 α → β1β2
    在 Fc 中找一个左部或右部含有无关属性的依赖 α → β
    把这个无关属性从 α → β 中删掉
```

- 判断无关属性时，用的是当前的 $F_c$，不是最初的 F（老师资料特别注明了这一点）。复习资料说"左部看原来 F 上的闭包，右部看去掉检查属性后 F' 上的闭包"，这里的"原来"指当前这一步删属性之前的依赖集。
- 一般先查左部，再查右部。左部只有一个属性的依赖不用查左部。
- 右部删空了，整条依赖就去掉。
- 检查的顺序不同，得到的正则覆盖可能不同，所以正则覆盖不唯一。

## 9. 第三范式

### 定义

具有函数依赖集 F 的关系模式 R 属于 3NF，条件是：对 $F^+$ 中所有形如 $\alpha \rightarrow \beta$ 的函数依赖（$\alpha \subseteq R$，$\beta \subseteq R$），下面至少有一条成立：

1. $\alpha \rightarrow \beta$ 是平凡的函数依赖（$\beta \subseteq \alpha$）；
2. α 是 R 的一个超码；
3. $\beta - \alpha$ 中的每个属性 A 都包含在 R 的某个候选码中。不同的属性可以分别在不同的候选码里，不要求同属一个候选码。

老师资料对第 3 条的表述和教材一致。

- 满足 BCNF 一定满足 3NF，BCNF 只允许前两条。
- 3NF 是 BCNF 的最小放宽，放宽的目的是保证能做到保持依赖的分解。
- 例（笔记）：$R = (J, K, L)$，$F = \lbrace JK \rightarrow L, L \rightarrow K \rbrace$，候选码是 JK 和 JL。$JK \rightarrow L$ 中 JK 是超码；$L \rightarrow K$ 中 K 包含在候选码 JK 中。所以 R 属于 3NF，但因为 L 不是超码，R 不属于 BCNF。

### 3NF 允许数据冗余

还是上面的 R(J, L, K)，一个实例：

| J | L | K |
| --- | --- | --- |
| j1 | l1 | k1 |
| j2 | l1 | k1 |
| j3 | l1 | k1 |
| null | l2 | k2 |

"l1 对应 k1"这件事存了 3 遍；想记录"l2 对应 k2"，又没有对应的 J 值，只能填空值。

### 判定 3NF

- 判断原模式 R 是否属于 3NF，只检查 F 中的依赖即可，不用展开 $F^+$，理由和 BCNF 相同。（更正：老师资料原话是"判断第三范式只需要在 F 上进行，无需在 F+ 上"，这只对原模式 R 本身成立。判断分解出来的子模式是否属于 3NF，要用 $F^+$ 在子模式上的投影，候选码也要用子模式自己的候选码。）
- 第 3 条要求知道全部候选码。判断关系模式是否满足 3NF 是 NP 难问题，但下面的 3NF 合成算法是多项式时间的。

### 3NF 合成算法

1. 求 F 的正则覆盖 $F_c$。
2. 对 $F_c$ 中每个函数依赖 $\alpha \rightarrow \beta$，如果已有的模式都不包含 αβ，就新建模式 $R_i = \alpha\beta$。
3. 如果所有模式都不包含 R 的候选码，就再加一个模式，内容是 R 的任意一个候选码。
4. 如果一个模式被另一个模式包含，删掉被包含的模式。老师资料把这一步标为可选，写成循环：只要某个 $R_j$ 被另一个 $R_k$ 包含，就删掉 $R_j$。

得到的每个模式都属于 3NF，分解无损并且保持依赖。第 2 步让 $F_c$ 中每条依赖都落在某个模式里，所以保持依赖；第 3 步保证有一个模式含候选码，所以无损。

笔记提到 3NF 合成算法对输入顺序敏感：依赖处理的先后不同，第 2 步建出的模式可能不同。老师资料的例子加上第 4 步以后，两种顺序结果一样（见典型题 11）。

### BCNF 和 3NF 比较

| | BCNF | 3NF |
| --- | --- | --- |
| 无损分解 | 能做到 | 能做到 |
| 没有冗余 | 是 | 不一定 |
| 保持依赖 | 不一定 | 能做到 |

## 10. 范式的通俗定义

复习资料里给了一套通俗说法（国内教材常用），和上面用 $F^+$ 的定义对照着记：

| 范式 | 通俗定义 | 和前面定义的关系 |
| --- | --- | --- |
| 1NF | 属性不可再分 | 同第 2 节 |
| 2NF | 满足 1NF，并且每个非主属性都完全依赖于候选码 | 等价说法：任何候选码的真子集都不能函数决定非主属性 |
| 3NF | 满足 2NF，并且没有非主属性传递依赖于候选码 | 等价于第 9 节的定义：对非平凡依赖 $\alpha \rightarrow A$，A 是非主属性时 α 必须是超码 |
| BCNF | 满足 3NF，并且每个决定因素（非平凡依赖的左部）都包含候选码 | 同第 5 节的定义 |

（更正：复习资料对 2NF 的补充解释是"一个主属性如果不能单独做候选码，它就不能确定任何非主属性"，只说了单个属性，不完整。候选码是 ABC 时，AB 这样的真子集同样不能决定非主属性。）

（更正：复习资料对 3NF 的补充解释是"任何非主属性不依赖于其他非主属性"，也不完整。非主属性依赖于一个不是超码的主属性组，同样违反 3NF。例：$R(A, B, C, D)$，$F = \lbrace AC \rightarrow B, BC \rightarrow A, AB \rightarrow D \rbrace$，候选码是 AC 和 BC，D 是非主属性。候选码的真子集 A、B、C 的闭包都只有自己，没有部分依赖，R 属于 2NF；但 AB 全由主属性组成，$(AB)^+ = ABD$ 不是超码，$AB \rightarrow D$ 让 D 传递依赖于候选码 AC（$AC \rightarrow AB$，$AB \rightarrow D$），R 不属于 3NF。）

## 11. 第四范式

### 多值依赖

设 $\alpha \subseteq R$，$\beta \subseteq R$。R 上的多值依赖 $\alpha \twoheadrightarrow \beta$ 成立，条件是：对 R 的任意合法关系 r，r 中任意一对满足 $t_1[\alpha] = t_2[\alpha]$ 的元组 $t_1$、$t_2$，r 中都存在元组 $t_3$、$t_4$，使得

- $t_1[\alpha] = t_2[\alpha] = t_3[\alpha] = t_4[\alpha]$
- $t_3[\beta] = t_1[\beta]$，$t_3[R - \beta] = t_2[R - \beta]$
- $t_4[\beta] = t_2[\beta]$，$t_4[R - \beta] = t_1[R - \beta]$

（更正：笔记最后一个等式写作 $t_4[R - \beta] = t_1[\beta]$，应为 $t_4[R - \beta] = t_1[R - \beta]$。）

画成表就是"交错相等"：

| | α | β | R − α − β |
| --- | --- | --- | --- |
| $t_1$ | $a_1 \dots a_i$ | $a_{i+1} \dots a_j$ | $a_{j+1} \dots a_n$ |
| $t_2$ | $a_1 \dots a_i$ | $b_{i+1} \dots b_j$ | $b_{j+1} \dots b_n$ |
| $t_3$ | $a_1 \dots a_i$ | $a_{i+1} \dots a_j$ | $b_{j+1} \dots b_n$ |
| $t_4$ | $a_1 \dots a_i$ | $b_{i+1} \dots b_j$ | $a_{j+1} \dots a_n$ |

α 相同的元组里，β 部分的取值和其余属性的取值可以任意交叉组合。

### 多值依赖的性质

| 规则 | 内容 |
| --- | --- |
| 复制 | 若 $\alpha \rightarrow \beta$，则 $\alpha \twoheadrightarrow \beta$。可见函数依赖是多值依赖的特殊情况 |
| 结合 | 若 $\alpha \twoheadrightarrow \beta$，$\gamma \subseteq \beta$，存在 δ 使 $\beta \cap \delta = \emptyset$ 且 $\delta \rightarrow \gamma$，则 $\alpha \rightarrow \gamma$ |
| 自反 | $\alpha \twoheadrightarrow \alpha$ |
| 增广 | 若 $\alpha \twoheadrightarrow \beta$，则 $\alpha\gamma \twoheadrightarrow \beta$ |
| 相加 | 若 $\alpha \twoheadrightarrow \beta$，$\alpha \twoheadrightarrow \gamma$，则 $\alpha \twoheadrightarrow \beta\gamma$ |
| 投影 | 若 $\alpha \twoheadrightarrow \beta$，$\alpha \twoheadrightarrow \gamma$，则 $\alpha \twoheadrightarrow \beta \cap \gamma$，$\alpha \twoheadrightarrow \beta - \gamma$ |
| 传递 | 若 $\alpha \twoheadrightarrow \beta$，$\beta \twoheadrightarrow \gamma$，则 $\alpha \twoheadrightarrow \gamma - \beta$ |
| 伪传递 | 若 $\alpha \twoheadrightarrow \beta$，$\beta\gamma \twoheadrightarrow \delta$，则 $\alpha\gamma \twoheadrightarrow \delta - \beta\gamma$ |
| 补 | 对关系模式 R，若 $\alpha \twoheadrightarrow \beta$，则 $\alpha \twoheadrightarrow R - \alpha\beta$ |

- 多值依赖的闭包：D 表示函数依赖和多值依赖的集合，D 逻辑蕴含的所有函数依赖和多值依赖组成的集合叫 D 的闭包，记作 $D^+$。
- 平凡的多值依赖：$\beta \subseteq \alpha$ 或 $\beta \cup \alpha = R$ 时，$\alpha \twoheadrightarrow \beta$ 是平凡的。

### 4NF 的定义

具有依赖集 D 的关系模式 R 属于 4NF，条件是：对 $D^+$ 中所有形如 $\alpha \twoheadrightarrow \beta$ 的多值依赖（$\alpha \subseteq R$，$\beta \subseteq R$），至少满足一条：

- $\alpha \twoheadrightarrow \beta$ 是平凡的多值依赖；
- α 是 R 的一个超码。

每个函数依赖也是多值依赖，所以属于 4NF 的模式一定属于 BCNF。

D 在 $R_i$ 上的限定 $D_i$（类比函数依赖的限定）包括：

- $D^+$ 中所有只含 $R_i$ 属性的函数依赖；
- 所有形如 $\alpha \twoheadrightarrow \beta \cap R_i$ 的多值依赖，其中 $\alpha \subseteq R_i$，且 $\alpha \twoheadrightarrow \beta$ 属于 $D^+$。

### 4NF 分解

思路和 BCNF 分解一样：

```text
result := {R}
计算 D⁺
当 result 中存在关于 Di 不属于 4NF 的模式 Ri 时，重复：
    在 Ri 上找一个非平凡多值依赖 α →→ β，要求 α → Ri 不在 Di 中（α 不是 Ri 的超码），且 α ∩ β = ∅
    result := (result - {Ri}) ∪ {Ri - β} ∪ {α ∪ β}
```

其中 $D_i$ 是 $D^+$ 在 $R_i$ 上的限定。（更正：笔记伪代码这一行排版错乱，写成了"α →→ Ri ∉ Di"，条件应为函数依赖 $\alpha \rightarrow R_i$ 不在 $D_i$ 中。）例子见典型题 18。

## 12. 更多的范式

- 连接依赖：$R_1, R_2, \dots, R_n$ 是 R 的一个分解，如果 R 上的合法关系都满足"各投影做自然连接能无损恢复原关系"，即 $R = R_1 \bowtie R_2 \bowtie \dots \bowtie R_n$，就说 R 满足这个连接依赖。连接依赖是多值依赖的推广。
- 第五范式（5NF），也叫投影-连接范式（PJNF），用来消除连接依赖引起的冗余。常用定义：R 的每个非平凡连接依赖（没有哪个 $R_i$ 就是 R 本身）都能由 R 的候选码推出。（更正：笔记写作"对每个非平凡连接依赖，至少有一个 $R_i$ 是超码"，这只是 5NF 的必要条件，不能当定义用。）连接依赖缺少一套正确有效且完备的推理规则，所以 5NF 很少用。
- 域-码范式（DKNF）：要求所有约束都能由域约束和码约束推出，这样插入、删除、更新异常都不会出现。它要求把数据库中所有可能的约束都建模出来，实践中很少使用。

## 解题步骤

### 求候选码

1. 按属性在 F 中出现的位置分成四类：

   | 类别 | 含义 | 结论 |
   | --- | --- | --- |
   | L 类 | 只在依赖左部出现 | 一定属于每个候选码 |
   | R 类 | 只在依赖右部出现 | 一定不属于任何候选码 |
   | LR 类 | 左右两边都出现 | 不确定 |
   | N 类 | 左右两边都不出现 | 一定属于每个候选码 |

   （更正：复习资料手写稿把 L 类的结论写成"一定存在于某个候选码"，应为一定存在于每个候选码。）
2. 令 X = L 类属性 ∪ N 类属性，求 $X^+$。如果 $X^+$ 包含 R 的所有属性，X 就是唯一的候选码，结束。
3. 否则，给 X 依次加上 LR 类中的 1 个属性求闭包，闭包等于 R 的就是候选码；再依次试加 2 个、3 个……。已经包含某个候选码的组合不是最小的，直接跳过。
4. 可以最后再验证一下：每个候选码去掉任何一个属性后，闭包都不等于 R。

历年考试的候选码计算题（第 69 页那道）见 `23 范式计算题.md`。

### 判断属于哪个范式

1. 求出全部候选码，分出主属性和非主属性。
2. 把 F 中每个依赖的右部拆成单个属性，去掉平凡的，逐条检查 $\alpha \rightarrow A$：
   - α 是超码：这条依赖不违反任何范式。
   - α 不是超码，A 是主属性：违反 BCNF，不违反 3NF。
   - α 不是超码，A 是非主属性：违反 3NF。其中 α 是某个候选码的真子集时，是部分依赖，还违反 2NF。
3. 从高往低下结论：没有违例属于 BCNF；只有"A 是主属性"的违例，属于 3NF；有非主属性的违例但没有部分依赖，属于 2NF；有部分依赖，只属于 1NF（默认属性都是原子的）。

注意事项：

- 查 2NF 时，F 里不一定直接写出了部分依赖。稳妥的办法是：对每个候选码 K 和 K 中的每个属性 B，求 $(K - B)^+$，里面有非主属性就说明有部分依赖。例：$F = \lbrace A \rightarrow C, C \rightarrow A, AC \rightarrow D, AB \rightarrow E \rbrace$，候选码是 AB 和 BC，非主属性是 D、E。F 中没有"候选码真子集 → 非主属性"这种形式的依赖，但 $A^+ = ACD$，D 部分依赖于 AB，不属于 2NF。先求正则覆盖也能暴露出来（$AC \rightarrow D$ 的 C 是无关属性，变成 $A \rightarrow D$）。
- 以上步骤针对原模式 R。判断分解出来的子模式，要对子模式的属性子集求闭包，找出 $F^+$ 投影到子模式上的依赖。
- 复习资料的范式判断步骤是：先求 $F^+$，再求候选码，每个非平凡依赖的左部都是超码则为 BCNF，否则再看 $\beta - \alpha$ 中的属性是否都在候选码里判断 3NF。原模式 R 上用 F 代替 $F^+$ 就行。
- 历年考试的范式判断题（第 79 页那道）见 `23 范式计算题.md`。

### 求正则覆盖

1. 用合并律把左部相同的依赖合并。
2. 查左部有两个及以上属性的依赖 $\alpha \rightarrow \beta$：对 α 中每个属性 B，用当前依赖集求 $(\alpha - B)^+$，包含 β 就删掉 B。
3. 查右部：对 β 中每个属性 A，把这条依赖改成 $\alpha \rightarrow (\beta - A)$ 得到 $F'$，在 $F'$ 下求 $\alpha^+$，包含 A 就删掉 A；右部删空就删掉整条依赖。
4. 有变化就回到第 1 步，直到不再变化。

### BCNF 分解

1. 求候选码，在 F 中找违例依赖 $\alpha \rightarrow \beta$（非平凡，α 不是超码）。
2. 分成 $R_1 = \alpha \cup \beta$ 和 $R_2 = R - (\beta - \alpha)$。右部可以取 $\alpha^+ - \alpha$。
3. 分别检查 $R_1$、$R_2$。这一步必须看 $F^+$ 的投影：对子模式的属性子集在 F 下求闭包，再和子模式取交集，找出落在子模式里的违例依赖。
4. 重复直到所有子模式都属于 BCNF。只有两个属性的模式一定属于 BCNF。
5. 题目问到时，再检查是否保持依赖，写出丢掉了哪几条。

### 3NF 合成

1. 求 $F_c$。
2. $F_c$ 中每个 $\alpha \rightarrow \beta$ 建一个模式 αβ（左部相同的依赖已经合并，每个左部对应一个模式）。
3. 求候选码。没有任何模式包含候选码时，加一个由某个候选码构成的模式。
4. 删掉被其他模式包含的模式。
5. 结果一定无损并保持依赖。题目要求说明时，可以用交集法或 chase 表格法写出无损的理由。

### 判断无损

- 二元分解：求 $(R_1 \cap R_2)^+$，包含 $R_1$ 或 $R_2$ 的全部属性就无损。
- 三个以上的分解：chase 表格法，出现全 a 的行就无损。
- 分解是一步步二元分解得到的（比如 BCNF 分解），每一步都无损，整个分解就无损。

### 判断保持依赖

1. F 中某条依赖的属性全在某个子模式里，直接算保持。
2. 剩下的依赖用方法二：result 从 α 出发，不断用 $((\text{result} \cap R_i)^+ \cap R_i)$ 扩充，最后看 β 是否包含在 result 中。
3. F 中所有依赖都保持，分解才保持依赖；有一条不保持，就把它写出来作为理由。

## 易混对比

| 易混点 | 区别 |
| --- | --- |
| 超码 / 候选码 / 主码 | 能函数决定全部属性的属性集 / 最小的超码 / 从候选码中选定的一个 |
| 主属性 / 非主属性 | 属于某个候选码 / 不属于任何候选码 |
| 平凡 / 非平凡函数依赖 | $\beta \subseteq \alpha$，在任何关系上都成立 / $\beta \not\subseteq \alpha$ |
| 完全依赖 / 部分依赖 / 传递依赖 | X 的任何真子集都决定不了 Y / X 的某个真子集就能决定 Y / 经过中间属性集 Y 间接决定 Z，且 Y 决定不了 X |
| $F^+$ / $\alpha^+$ / $F_c$ | F 蕴含的所有函数依赖，是依赖的集合 / α 能决定的所有属性，是属性的集合 / 和 F 等价的最简依赖集，不唯一 |
| 左部无关属性 / 右部无关属性 | 用当前依赖集求 $(\alpha - A)^+$，看是否包含 β / 用改过的 $F'$ 求 $\alpha^+$，看是否包含 A |
| 无损分解 / 保持依赖 | 自然连接后能恢复原关系，用交集法或 chase 表格法判定 / 子模式上的依赖合起来和 F 等价，用 result 迭代判定；两者互不蕴含 |
| BCNF / 3NF | 非平凡依赖左部必须是超码，无冗余，不一定保持依赖 / 还允许 $\beta - \alpha$ 全是主属性，可能冗余，总能做到无损且保持依赖的分解 |
| BCNF / 4NF | 只考虑函数依赖 / 还考虑多值依赖，4NF 一定是 BCNF |
| 判断原模式 R / 判断子模式 $R_i$ | 只查 F / 要查 $F^+$ 在 $R_i$ 上的投影 |
| BCNF 分解 / 3NF 合成 | 按违例依赖一步步二分，无损，不一定保持依赖 / 按 $F_c$ 每条依赖建模式，再补候选码，无损且保持依赖 |
| 2NF 违例 / 3NF 违例 | 非主属性部分依赖于候选码 / 非主属性传递依赖于候选码（依赖于一个不是超码的属性集） |
| 函数依赖 / 多值依赖 | α 相同则 β 相同 / α 相同时 β 部分和其余部分可以任意交叉组合；函数依赖是多值依赖的特例 |
| 平凡函数依赖 / 平凡多值依赖 | $\beta \subseteq \alpha$ / $\beta \subseteq \alpha$ 或 $\alpha \cup \beta = R$ |

## 典型题与解答

### 题 1 关系实例满足哪些函数依赖（笔记）

题目：下面的关系 r 满足哪些函数依赖？

| A | B | C | D |
| --- | --- | --- | --- |
| a1 | b1 | c1 | d1 |
| a1 | b2 | c1 | d2 |

### 题 2 用 Armstrong 公理推导（笔记）

题目：$R = (A, B, C, G, H, I)$，$F = \lbrace A \rightarrow B, A \rightarrow C, CG \rightarrow H, CG \rightarrow I, B \rightarrow H \rbrace$。说明 $A \rightarrow H$、$CG \rightarrow HI$、$AG \rightarrow I$ 属于 $F^+$。

思路：找能首尾相接的依赖，缺属性就增补。

解答：

- $A \rightarrow H$：由 $A \rightarrow B$、$B \rightarrow H$，用传递律。
- $CG \rightarrow HI$：直接用合并律。只用三条公理的话：$CG \rightarrow I$ 增补 CG 得 $CG \rightarrow CGI$；$CG \rightarrow H$ 增补 I 得 $CGI \rightarrow HI$；再传递得 $CG \rightarrow HI$。
- $AG \rightarrow I$：由 $A \rightarrow C$、$CG \rightarrow I$ 直接用伪传递律。只用公理的话：$A \rightarrow C$ 增补 G 得 $AG \rightarrow CG$，再和 $CG \rightarrow I$ 传递。

### 题 3 求属性闭包和候选码（笔记、老师资料、复习资料）

题目：$R = (A, B, C, G, H, I)$，$F = \lbrace A \rightarrow B, A \rightarrow C, CG \rightarrow H, CG \rightarrow I, B \rightarrow H \rbrace$。求 $(AG)^+$，并判断 AG 是否为候选码。

思路：按算法反复扫描 F；再看 AG 的真子集是不是超码。

解答：

| 步骤 | 用到的依赖 | result |
| --- | --- | --- |
| 初值 | | AG |
| 1 | $A \rightarrow B$、$A \rightarrow C$ | ABCG |
| 2 | $CG \rightarrow H$（$CG \subseteq ABCG$） | ABCGH |
| 3 | $CG \rightarrow I$（$CG \subseteq ABCGH$） | ABCGHI |

$B \rightarrow H$ 的 H 已经在 result 里了。$(AG)^+ = ABCGHI = R$，AG 是超码。再求真子集：$A^+ = ABCH$，$G^+ = G$，都不是超码，所以 AG 是候选码。另外 A、G 只在左部出现（L 类），任何候选码都含 A 和 G，所以 AG 是唯一的候选码。

### 题 4 求正则覆盖（笔记、复习资料）

题目：模式 $(A, B, C)$ 上 $F = \lbrace A \rightarrow BC, B \rightarrow C, A \rightarrow B, AB \rightarrow C \rbrace$，求 $F_c$。

思路：先合并左部，再查左部无关属性，最后查右部。

解答：

1. 合并左部相同的依赖：$A \rightarrow BC$ 和 $A \rightarrow B$ 合并为 $A \rightarrow BC$，得 $\lbrace A \rightarrow BC, B \rightarrow C, AB \rightarrow C \rbrace$。
2. 查 $AB \rightarrow C$ 的左部。先查 A：$(AB - A)^+ = B^+ = BC$，包含 C，A 是无关属性，这条变成 $B \rightarrow C$，和已有的重复，得 $\lbrace A \rightarrow BC, B \rightarrow C \rbrace$。
3. 查 $A \rightarrow BC$ 的右部。先查 C：$F' = \lbrace A \rightarrow B, B \rightarrow C \rbrace$，$A^+ = ABC$ 包含 C，C 是无关属性，得 $\lbrace A \rightarrow B, B \rightarrow C \rbrace$。再查 $A \rightarrow B$ 的 B：去掉后只剩 $B \rightarrow C$，$A^+ = A$ 不含 B，不是无关属性。
4. $F_c = \lbrace A \rightarrow B, B \rightarrow C \rbrace$。

（更正：原笔记第 3 步的标题写作"检查左部"，实际检查的是右部。）

### 题 5 正则覆盖不唯一（笔记）

题目：模式 $(A, B, C)$ 上 $F = \lbrace A \rightarrow BC, B \rightarrow AC, C \rightarrow AB \rbrace$，求 $F_c$。

思路：$A \rightarrow BC$ 中 B 和 C 单独看都是无关属性，但不能同时删，先删哪个会导向不同结果。

解答：

- 先删 $A \rightarrow BC$ 中的 C，得 $\lbrace A \rightarrow B, B \rightarrow AC, C \rightarrow AB \rbrace$。这时 $C \rightarrow AB$ 中 A、B 都是无关属性：
  - 删 B 得 $C \rightarrow A$；再看 $B \rightarrow AC$，由 $B \rightarrow C$、$C \rightarrow A$ 能推出 A，A 无关。$F_c = \lbrace A \rightarrow B, B \rightarrow C, C \rightarrow A \rbrace$。
  - 删 A 得 $C \rightarrow B$；$B \rightarrow AC$ 里的 A、C 都删不掉。$F_c = \lbrace A \rightarrow B, B \rightarrow AC, C \rightarrow B \rbrace$。
- 先删 $A \rightarrow BC$ 中的 B，得 $\lbrace A \rightarrow C, B \rightarrow AC, C \rightarrow AB \rbrace$。这时 $B \rightarrow AC$ 中 A、C 都是无关属性：
  - 删 C 得 $B \rightarrow A$；再看 $C \rightarrow AB$，由 $C \rightarrow B$、$B \rightarrow A$ 能推出 A，A 无关。$F_c = \lbrace A \rightarrow C, B \rightarrow A, C \rightarrow B \rbrace$。
  - 删 A 得 $B \rightarrow C$；$C \rightarrow AB$ 里的 A、B 都删不掉。$F_c = \lbrace A \rightarrow C, B \rightarrow C, C \rightarrow AB \rbrace$。

四个结果都和 F 等价，也都不含无关属性。

### 题 6 银行模式的 BCNF 分解（笔记、复习资料）

题目：`R = (branch_name, branch_city, assets, customer_name, loan_number, amount)`，F 为 `branch_name → assets, branch_city` 和 `loan_number → amount, branch_name`，对 R 做 BCNF 分解。

思路：先求候选码，再按违例依赖二分，子模式上要看 $F^+$。

解答：

1. 候选码：`customer_name` 不出现在任何依赖中，`loan_number` 只在左部出现，两者必在每个候选码中；`(customer_name, loan_number)` 的闭包是全部属性，它是唯一候选码。
2. `branch_name → assets, branch_city` 非平凡，`branch_name` 不是超码，R 不属于 BCNF。分成 `R1 = (branch_name, branch_city, assets)` 和 `R2 = R - (β - α) = (branch_name, customer_name, loan_number, amount)`。
3. R1 中 `branch_name` 是主码，属于 BCNF。
4. R2 中 `loan_number → amount, branch_name` 成立，`loan_number` 不是 R2 的超码，继续分：`R3 = (loan_number, amount, branch_name)`，`R4 = (customer_name, loan_number)`。
5. R3 中 `loan_number` 是超码，其他属性的闭包在 R3 里只有自己，属于 BCNF；R4 只有两个属性，属于 BCNF。
6. 结果是 R1、R3、R4。两个依赖分别落在 R1 和 R3 中，这个分解也保持依赖。

### 题 7 BCNF 分解要看 F 的闭包（笔记）

题目：$R = (A, B, C, D, E)$，$F = \lbrace A \rightarrow B, BC \rightarrow D \rbrace$，对 R 做 BCNF 分解。

思路：分出子模式后，F 中跨模式的依赖可能推出子模式上的违例依赖。

解答：

1. 候选码：A、C 只在左部，E 不出现，$(ACE)^+ = ABCDE$，ACE 是唯一候选码。
2. $A \rightarrow B$ 中 A 不是超码。分成 $R_1 = (A, B)$，$R_2 = (A, C, D, E)$。
3. 只看 F 的话，$BC \rightarrow D$ 不在 $R_2$ 里，好像分解结束了。但 $(AC)^+ = ABCD$，$AC \rightarrow D$ 属于 $F^+$ 且全在 $R_2$ 中，AC 不是 $R_2$ 的超码（缺 E），$R_2$ 不属于 BCNF。
4. 分成 $R_3 = (A, C, D)$，$R_4 = (A, C, E)$。$R_3$ 中 AC 是超码，其余属性子集的闭包和 $R_3$ 取交集都只有自己；$R_4$ 中除 ACE 外没有能决定其他属性的子集。两者都属于 BCNF。
5. 结果 $\lbrace (A, B), (A, C, D), (A, C, E) \rbrace$。$BC \rightarrow D$ 没有保持：result 从 BC 出发，在 $R_1$ 上得 $B^+ \cap AB = B$，在 $R_3$、$R_4$ 上得 C，result 始终是 BC，不含 D。

### 题 8 另一道 BCNF 分解（复习资料）

题目：$R(A, B, C, D, E, G)$，$F = \lbrace A \rightarrow B, B \rightarrow C, AD \rightarrow G, D \rightarrow E \rbrace$，求 BCNF 分解。

思路：同题 7，子模式上的依赖从 $F^+$ 投影得到。

解答：

1. 候选码：A、D 只在左部，$(AD)^+ = ABCDEG$，AD 是唯一候选码。
2. $A \rightarrow B$ 违例，分成 $R_1 = AB$，$R_2 = ACDEG$。$R_1$ 中键为 A，属于 BCNF。
3. $R_2$ 上成立的依赖有 $A \rightarrow C$（由 $A \rightarrow B \rightarrow C$ 得到，F 里没有直接写）、$AD \rightarrow G$、$D \rightarrow E$，键为 AD，不属于 BCNF。按 $A \rightarrow C$ 分成 $R_{21} = AC$，$R_{22} = ADEG$。
4. $R_{21}$ 键为 A，属于 BCNF。$R_{22}$ 上有 $AD \rightarrow G$、$D \rightarrow E$，键为 AD，$D \rightarrow E$ 违例，分成 $R_{221} = DE$，$R_{222} = ADG$，两者都属于 BCNF。
5. 结果 $\lbrace AB, AC, DE, ADG \rbrace$，无损。$B \rightarrow C$ 没有保持，B 和 C 不在同一个模式里，用方法二算 result 也一直是 B。复习资料对这题的提醒是：判断子模式时要看 $F^+$。

### 题 9 两种分解的无损性和保持依赖（笔记）

题目：$R = (A, B, C)$，$F = \lbrace A \rightarrow B, B \rightarrow C \rbrace$，候选码 A，要求满足 BCNF。比较分解 (1) $R_1 = (A, B)$、$R_2 = (B, C)$ 和 (2) $R_1 = (A, B)$、$R_2 = (A, C)$。

思路：B 不是码，R 不属于 BCNF；无损用交集法，保持依赖看依赖能否落在子模式里。

解答：

- (1) $R_1$、$R_2$ 都属于 BCNF。$R_1 \cap R_2 = B$，$B \rightarrow BC$，B 是 $R_2$ 的超码，无损。$A \rightarrow B$ 在 $R_1$ 中，$B \rightarrow C$ 在 $R_2$ 中，保持依赖。
- (2) $R_1 \cap R_2 = A$，$A \rightarrow AB$，无损。但 B 和 C 不在同一个模式里，$B \rightarrow C$ 检查不了，不保持依赖。

### 题 10 BCNF 分解无法保持依赖（笔记）

题目：$R = (J, K, L)$，$F = \lbrace JK \rightarrow L, L \rightarrow K \rbrace$，候选码为 JK 和 JL。做 BCNF 分解，并判断 R 是否属于 3NF。

思路：L 不是码；任何把 R 拆开的分解都没有一个模式同时含 J、K、L。

解答：

- $L \rightarrow K$ 中 L 不是超码，R 不属于 BCNF。分成 $R_1 = (L, K)$，$R_2 = (J, L)$，两个模式都属于 BCNF。
- $R_1 \cap R_2 = L$，$L \rightarrow LK$，无损。
- $JK \rightarrow L$ 需要 J、K、L 同时出现才能检查，所以这个分解不保持依赖；R 的任何分解都保持不了 $JK \rightarrow L$。
- 3NF：$JK \rightarrow L$ 中 JK 是超码；$L \rightarrow K$ 中 K 包含在候选码 JK 中。R 属于 3NF，不用分解。

### 题 11 `cust_banker_branch` 的 3NF 合成（笔记、老师资料）

题目：`cust_banker_branch = (customer_id, employee_id, branch_name, type)`，F 为：(1) `customer_id, employee_id → branch_name, type`；(2) `employee_id → branch_name`；(3) `customer_id, branch_name → employee_id`。求 3NF 分解。

思路：先求 $F_c$，再按 3NF 合成算法走。

解答：

1. 求 $F_c$：依赖 (1) 右部的 `branch_name` 是无关属性，因为去掉后由 (2) 仍能从 `customer_id, employee_id` 推出 `branch_name`。其他属性都不无关（例如 `employee_id` 的闭包只有 `employee_id, branch_name`，推不出 `type`）。$F_c$ 为 `customer_id, employee_id → type`、`employee_id → branch_name`、`customer_id, branch_name → employee_id`。
2. 每条依赖建一个模式：`(customer_id, employee_id, type)`、`(employee_id, branch_name)`、`(customer_id, branch_name, employee_id)`。
3. 候选码：`customer_id` 只在左部；`(customer_id, employee_id)` 和 `(customer_id, branch_name)` 的闭包都是全部属性，这两个是候选码。第一个模式已经包含候选码，不用再加。
4. `(employee_id, branch_name)` 被 `(customer_id, branch_name, employee_id)` 包含，删掉。
5. 结果：`(customer_id, employee_id, type)`、`(customer_id, branch_name, employee_id)`。

笔记说 3NF 合成算法对输入顺序敏感，给了"另解"：先处理依赖 (3)，建出 `(customer_id, branch_name, employee_id)` 后，`employee_id → branch_name` 已经被包含，不会单独建 `(employee_id, branch_name)`。有了第 4 步，这道题两种顺序结果相同，老师资料也指出结果与依赖的处理顺序无关。第二个模式里 `employee_id → branch_name` 成立而 `employee_id` 不是超码，所以它属于 3NF（`branch_name` 在候选码里）但不属于 BCNF。

### 题 12 3NF 合成（复习资料）

题目：$U = \lbrace A, B, C, D, E, G \rbrace$，$F = \lbrace B \rightarrow G, CE \rightarrow B, C \rightarrow A, CE \rightarrow G, B \rightarrow D, C \rightarrow D \rbrace$，求 3NF 分解。

思路：先求 $F_c$，注意 $CE \rightarrow G$ 可以由 $CE \rightarrow B$、$B \rightarrow G$ 推出。

解答：

1. 合并左部相同的依赖：$B \rightarrow DG$，$CE \rightarrow BG$，$C \rightarrow AD$。

4. $F_c = \lbrace B \rightarrow DG, CE \rightarrow B, C \rightarrow AD \rbrace$。
5. 建模式 $R_1 = BDG$，$R_2 = BCE$，$R_3 = ACD$。
6. 候选码：C、E 只在左部，$(CE)^+ = ABCDEG$，CE 是唯一候选码。$R_2$ 包含 CE，不用再加。
7. $R_1$、$R_2$、$R_3$ 互不包含。3NF 分解为 $\lbrace BDG, BCE, ACD \rbrace$。

### 题 13 3NF 合成（复习资料）

题目：关系模式 r(A, B, C, D, E, F)，函数依赖集为 $\lbrace A \rightarrow BCD, BC \rightarrow DE, B \rightarrow D, D \rightarrow A \rbrace$，求 3NF 分解。（属性里也有一个 F，下面说"属性 F"时指这个属性。）

思路：$BC \rightarrow DE$ 的左部有无关属性；候选码要把不出现的属性 F 算进去。

解答：

1. 左部：$BC \rightarrow DE$ 去掉 C，$B^+$：由 $B \rightarrow D$ 得 BD，由 $D \rightarrow A$ 得 ABD，由 $A \rightarrow BCD$ 得 ABCD，由 $BC \rightarrow DE$ 得 ABCDE，包含 DE，C 是无关属性，变为 $B \rightarrow DE$，和 $B \rightarrow D$ 合并为 $B \rightarrow DE$。
2. 右部：$A \rightarrow BCD$ 中的 D，去掉后 $A^+$ 由 $A \rightarrow BC$、$B \rightarrow DE$ 仍含 D，D 无关，变为 $A \rightarrow BC$。$A \rightarrow BC$ 中的 B、C，$B \rightarrow DE$ 中的 D、E，逐个检查都不无关。
3. $F_c = \lbrace A \rightarrow BC, B \rightarrow DE, D \rightarrow A \rbrace$。
4. 建模式 $R_1 = ABC$，$R_2 = BDE$，$R_3 = AD$。

6. 三个模式都不包含候选码，任选一个加上，比如 $R_4 = AF$。
7. 没有包含关系。3NF 分解为 $\lbrace ABC, BDE, AD, AF \rbrace$。

### 题 14 判断是否保持依赖（复习资料）

题目：(1) $R(A, B, C, D)$ 分解为 $\lbrace R_1(A, B), R_2(B, C), R_3(C, D) \rbrace$，$F = \lbrace A \rightarrow B, B \rightarrow C, C \rightarrow D, D \rightarrow A \rbrace$；(2) $U = \lbrace A, B, C, D, E \rbrace$，$F = \lbrace A \rightarrow C, B \rightarrow C, C \rightarrow D, DE \rightarrow C, CE \rightarrow A \rbrace$，分解为 $R_1(AD)$、$R_2(AB)$、$R_3(BE)$、$R_4(CDE)$、$R_5(AE)$。判断是否保持函数依赖。

思路：属性全在某个子模式里的依赖直接算保持，其余用方法二。

解答：

(1) $A \rightarrow B$、$B \rightarrow C$、$C \rightarrow D$ 分别在 $R_1$、$R_2$、$R_3$ 中。只需检查 $D \rightarrow A$，result 从 D 开始：

| 轮 | 模式 | $\text{result} \cap R_i$ | 求闭包后与 $R_i$ 取交 | result |
| --- | --- | --- | --- | --- |
| 1 | $R_1(A, B)$ | 空 | 空 | D |
| 1 | $R_2(B, C)$ | 空 | 空 | D |
| 1 | $R_3(C, D)$ | D | $D^+ = ABCD$，交得 CD | CD |
| 2 | $R_1(A, B)$ | 空 | 空 | CD |
| 2 | $R_2(B, C)$ | C | $C^+ = ABCD$，交得 BC | BCD |
| 2 | $R_3(C, D)$ | CD | CD | BCD |
| 3 | $R_1(A, B)$ | B | $B^+ = ABCD$，交得 AB | ABCD |

result 含 A，$D \rightarrow A$ 被保持。四条依赖都保持，分解保持函数依赖。

(2) $C \rightarrow D$ 和 $DE \rightarrow C$ 在 $R_4(CDE)$ 中。检查 $A \rightarrow C$，result 从 A 开始：$R_1(AD)$ 上 $A^+ = ACD$，交得 AD，result = AD；$R_2(AB)$ 上 $A^+$ 交得 A；$R_3(BE)$ 交集为空；$R_4(CDE)$ 上 $D^+ = D$；$R_5(AE)$ 上得 A。第二轮 result 仍是 AD，不含 C，$A \rightarrow C$ 没有保持，所以分解不保持函数依赖。（用同样的方法可以验证 $B \rightarrow C$、$CE \rightarrow A$ 也没有保持。）

### 题 15 选择题：无损和保持依赖（复习资料第 75 页选择题 43）

题目：关系模式 `R<U, F>`，$U = \lbrace A, B, C, D, E \rbrace$，$F = \lbrace A \rightarrow BC, C \rightarrow D, BC \rightarrow E, E \rightarrow A \rbrace$，分解 $\rho = \lbrace R_1(ABCE), R_2(CD) \rbrace$ 满足（ ）。A. 具有无损连接性、保持函数依赖；B. 不具有无损连接性、保持函数依赖；C. 具有无损连接性、不保持函数依赖；D. 不具有无损连接性、不保持函数依赖。

### 题 16 chase 表格法：有损的例子（复习资料）

题目：属性集 ABCDEF，函数依赖集为 $\lbrace A \rightarrow BC, CD \rightarrow E, B \rightarrow D, BE \rightarrow F, EF \rightarrow A \rbrace$，判断分解 $\lbrace ABC, BD, BEF \rbrace$ 是否无损。

思路：三个模式，用 chase 表格法；每轮要把所有依赖都用一遍。

解答：初始表格：

| 模式 | A | B | C | D | E | F |
| --- | --- | --- | --- | --- | --- | --- |
| ABC | a1 | a2 | a3 | b14 | b15 | b16 |
| BD | b21 | a2 | b23 | a4 | b25 | b26 |
| BEF | b31 | a2 | b33 | b34 | a5 | a6 |

第一轮：

- $A \rightarrow BC$：A 列三个值各不相同，不改。
- $CD \rightarrow E$：(C, D) 三行各不相同，不改。
- $B \rightarrow D$：B 列全是 a2，D 列里有 a4，全改成 a4。
- $BE \rightarrow F$：(B, E) 为 (a2, b15)、(a2, b25)、(a2, a5)，各不相同，不改。
- $EF \rightarrow A$：(E, F) 各不相同，不改。

第二轮：$CD \rightarrow E$ 的 (C, D) 变成 (a3, a4)、(b23, a4)、(b33, a4)，仍各不相同；其他依赖也改不动。表格不再变化：

| 模式 | A | B | C | D | E | F |

| ABC | a1 | a2 | a3 | a4 | b15 | b16 |

### 题 17 chase 表格法、候选码和 3NF 分解（复习资料）

题目：关系模式 R(A, B, C, D, E)，$F = \lbrace A \rightarrow D, E \rightarrow D, D \rightarrow B, BC \rightarrow D, DC \rightarrow A \rbrace$。(1) 求 R 的候选码；(2) 判断 $\rho = \lbrace AB, AE, CE, BCD, AC \rbrace$ 是否为无损分解；(3) 将 R 分解为 3NF，并具有无损连接性和保持函数依赖。

思路：(1) 用 L/R/LR/N 分类；(2) chase 表格法；(3) 3NF 合成算法。

解答：

(1) C、E 只在左部出现，A、B、D 左右都出现。$(CE)^+$：由 $E \rightarrow D$ 得 CDE，由 $D \rightarrow B$ 得 BCDE，由 $DC \rightarrow A$ 得 ABCDE。CE 是唯一候选码。

(2) 初始表格：

| 模式 | A | B | C | D | E |
| --- | --- | --- | --- | --- | --- |
| AB | a1 | a2 | b13 | b14 | b15 |
| AE | a1 | b22 | b23 | b24 | a5 |
| CE | b31 | b32 | a3 | b34 | a5 |
| BCD | b41 | a2 | a3 | a4 | b45 |
| AC | a1 | b52 | a3 | b54 | b55 |

1. $A \rightarrow D$：AB、AE、AC 三行 A 都是 a1，D 列 b14、b24、b54 里没有 a，统一改成 b14。
2. $E \rightarrow D$：AE、CE 两行 E 都是 a5，D 列为 b14、b34，改成 b14。
3. $D \rightarrow B$：AB、AE、CE、AC 四行 D 都是 b14，B 列里有 a2，全改成 a2。
4. $BC \rightarrow D$：CE、BCD、AC 三行 (B, C) 都是 (a2, a3)，D 列里有 a4，全改成 a4。
5. $DC \rightarrow A$：CE、BCD、AC 三行 (D, C) 都是 (a4, a3)，A 列里有 a1，全改成 a1。

此时 CE 这一行是 a1、a2、a3、a4、a5，全是 a，分解是无损的。

| 模式 | A | B | C | D | E |
| --- | --- | --- | --- | --- | --- |
| AB | a1 | a2 | b13 | b14 | b15 |
| AE | a1 | a2 | b23 | b14 | a5 |
| CE | a1 | a2 | a3 | a4 | a5 |
| BCD | a1 | a2 | a3 | a4 | b45 |
| AC | a1 | a2 | a3 | a4 | b55 |

（最后的表格里 AB、AE 两行的 D 仍是 b14，是因为出现全 a 行就停了；继续用 $A \rightarrow D$ 还会改成 a4，不影响结论。）

(3) 复习资料没有给出这一问的解答，下面是整理补充。

1. 求 $F_c$：$BC \rightarrow D$ 去掉 B 得 $C^+ = C$，去掉 C 得 $B^+ = B$；$DC \rightarrow A$ 去掉 D 得 $C^+ = C$，去掉 C 得 $D^+ = BD$，左部都没有无关属性。每条依赖去掉后，左部的闭包都推不出原来的右部，也没有多余的依赖。$F_c = F$。
2. 建模式：AD、DE、BD、BCD、ACD。
3. 删掉被包含的模式：BD 被 BCD 包含，AD 被 ACD 包含，剩下 DE、BCD、ACD。
4. 这三个模式都不包含候选码 CE，加上模式 CE。
5. 3NF 分解为 $\lbrace DE, BCD, ACD, CE \rbrace$，无损且保持函数依赖。

### 题 18 4NF 分解（笔记）

题目：$R = (A, B, C, G, H, I)$，$D = \lbrace A \twoheadrightarrow B, B \twoheadrightarrow HI, CG \twoheadrightarrow H \rbrace$，做 4NF 分解。

思路：D 里没有函数依赖，R 的超码只有 R 本身；每一步找限定在当前模式上的非平凡多值依赖。

解答：

1. $A \twoheadrightarrow B$ 非平凡，A 不是 R 的超码。分成 $R_1 = (A, B)$，$R_2 = (A, C, G, H, I)$。
2. $R_2$ 上 $CG \twoheadrightarrow H$ 成立且非平凡，CG 不是 $R_2$ 的超码。分成 $R_3 = (C, G, H)$，$R_4 = (A, C, G, I)$。
3. 由 $A \twoheadrightarrow B$、$B \twoheadrightarrow HI$ 用传递性得 $A \twoheadrightarrow HI$，限定到 $R_4$ 上是 $A \twoheadrightarrow I$，非平凡，A 不是 $R_4$ 的超码。分成 $R_5 = (A, I)$，$R_6 = (A, C, G)$。
4. $R_1$、$R_3$、$R_5$、$R_6$ 都属于 4NF。结果为 $\lbrace (A, B), (C, G, H), (A, I), (A, C, G) \rbrace$。

### 题 19 综合题：学生选课（整理补充，自编）

题目：R(S, N, D, M, C, G)，S 学号，N 姓名，D 所在系，M 系主任，C 课程号，G 成绩。$F = \lbrace S \rightarrow N, S \rightarrow D, D \rightarrow M, SC \rightarrow G \rbrace$。(1) 求候选码；(2) R 最高属于第几范式；(3) 做 BCNF 分解，判断是否无损、是否保持依赖；(4) 用 3NF 合成算法分解。

思路：先分类求候选码，再看有没有部分依赖；分解时右部取左部的闭包。

解答：

(1) S、C 只在左部，D 左右都出现，N、M、G 只在右部。$(SC)^+ = SCNDMG$，SC 是唯一候选码。主属性 S、C，非主属性 N、D、M、G。

(2) $S \rightarrow N$ 中 S 是候选码 SC 的真子集，N 是非主属性，存在部分依赖，R 不属于 2NF，只属于 1NF。另外 $SC \rightarrow D$、$D \rightarrow M$ 说明 M 传递依赖于候选码，这也违反 3NF。

(3) $S^+ = SNDM$。按 $S \rightarrow NDM$ 分成 $R_1 = (S, N, D, M)$，$R_2 = (S, C, G)$。$R_1$ 上 $D \rightarrow M$ 成立，$D^+ \cap R_1 = DM$，D 不是 $R_1$ 的超码，再分成 $R_3 = (D, M)$，$R_4 = (S, N, D)$。$R_2$ 中 SC 是键，S、C 单独的闭包在 $R_2$ 里只有自己，属于 BCNF。结果 $\lbrace (D, M), (S, N, D), (S, C, G) \rbrace$。每一步都无损（$R_1 \cap R_2 = S$ 是 $R_1$ 的超码，$R_3 \cap R_4 = D$ 是 $R_3$ 的超码）。$S \rightarrow N$、$S \rightarrow D$ 在 $R_4$ 中，$D \rightarrow M$ 在 $R_3$ 中，$SC \rightarrow G$ 在 $R_2$ 中，保持依赖。

(4) $F_c = \lbrace S \rightarrow ND, D \rightarrow M, SC \rightarrow G \rbrace$（合并了 S 为左部的两条，其他没有无关属性）。建模式 SND、DM、SCG，SCG 含候选码，没有包含关系，结果和 (3) 相同。

### 题 20 综合题：多个候选码，3NF 但不是 BCNF（整理补充，自编）

题目：$R(A, B, C, D)$，$F = \lbrace AB \rightarrow C, C \rightarrow D, D \rightarrow A \rbrace$。(1) 求候选码；(2) 判断范式；(3) 做 BCNF 分解，比较两种分解顺序。

思路：B 只在左部；全部属性都是主属性时，R 至少属于 3NF。

解答：

(1) B 只在左部，A、C、D 左右都出现。$B^+ = B$；$(AB)^+ = ABCD$，$(BC)^+ = ABCD$，$(BD)^+ = ABCD$。候选码为 AB、BC、BD，A、B、C、D 都是主属性。

(2) $AB \rightarrow C$ 中 AB 是超码。$C \rightarrow D$ 中 $C^+ = ACD$，C 不是超码，但 D 是主属性；$D \rightarrow A$ 中 $D^+ = AD$，D 不是超码，A 是主属性。所以 R 属于 3NF，不属于 BCNF。

(3) 顺序一，先按 $C \rightarrow D$ 分：$R_1 = (C, D)$，$R_2 = (A, B, C)$。$R_2$ 上有 $C \rightarrow A$（由 $C \rightarrow D \rightarrow A$），C 不是 $R_2$ 的超码，再分成 $(A, C)$ 和 $(B, C)$。结果 $\lbrace CD, AC, BC \rbrace$，只保持了 $C \rightarrow D$，$D \rightarrow A$ 和 $AB \rightarrow C$ 都丢了。

顺序二，右部取 $C^+ - C = AD$，先按 $C \rightarrow AD$ 分：$R_1 = (A, C, D)$，$R_2 = (B, C)$。$R_1$ 上 $D \rightarrow A$ 违例，再分成 $(A, D)$ 和 $(C, D)$。结果 $\lbrace AD, CD, BC \rbrace$，保持了 $C \rightarrow D$ 和 $D \rightarrow A$，只丢了 $AB \rightarrow C$。

两种顺序的结果都无损。R 本身已经属于 3NF，只要求 3NF 时不必分解，所有依赖都能保持。

### 题 21 综合题：L/R/LR/N 分类、3NF 合成与 BCNF 分解（整理补充，自编）

题目：$R(A, B, C, D, E, G)$，$F = \lbrace A \rightarrow D, AB \rightarrow C, C \rightarrow B, D \rightarrow E \rbrace$。(1) 求全部候选码；(2) 判断范式；(3) 用 3NF 合成算法分解；(4) 做 BCNF 分解并判断是否保持依赖。

思路：G 不出现在 F 中，必须放进候选码；B、C 互相牵连，会有两个候选码。

解答：

(1) 分类：A 为 L 类；B、C、D 为 LR 类；E 为 R 类；G 为 N 类。$X = AG$，$(AG)^+ = ADEG$，不是全部属性。加一个 LR 属性：$(ABG)^+ = ABCDEG$，$(ACG)^+ = ABCDEG$，$(ADG)^+ = ADEG$。候选码为 ABG、ACG；再加两个属性的组合要么包含 B 或 C（已含候选码），要么只剩 D，不会有新的候选码。主属性 A、B、C、G，非主属性 D、E。

(2) $A \rightarrow D$ 中 A 是候选码 ABG 的真子集，D 是非主属性，存在部分依赖，R 只属于 1NF。

(3) F 没有无关属性，也没有多余依赖，$F_c = F$。建模式 AD、ABC、BC、DE；BC 被 ABC 包含，删掉；剩下的 AD、ABC、DE 都不含候选码，加上 ABG。3NF 分解为 $\lbrace AD, ABC, DE, ABG \rbrace$。其中 ABC 上有 $AB \rightarrow C$ 和 $C \rightarrow B$，候选码是 AB 和 AC，$C \rightarrow B$ 的 B 是主属性，所以 ABC 属于 3NF 但不属于 BCNF。

(4) 先按 $D \rightarrow E$ 分：$R_1 = (D, E)$，$R_2 = (A, B, C, D, G)$。$R_2$ 上 $A \rightarrow D$ 违例，分成 $R_3 = (A, D)$，$R_4 = (A, B, C, G)$。$R_4$ 上有 $AB \rightarrow C$、$C \rightarrow B$，$C \rightarrow B$ 违例，分成 $R_5 = (B, C)$，$R_6 = (A, C, G)$。$R_6$ 中只有 ACG 能决定全部属性，属于 BCNF。结果 $\lbrace DE, AD, BC, ACG \rbrace$，无损。$A \rightarrow D$、$C \rightarrow B$、$D \rightarrow E$ 保持；$AB \rightarrow C$ 没有保持：result 从 AB 出发，经 AD、DE 扩充到 ABDE，再也得不到 C。

如果一开始先按 $A \rightarrow D$ 分，$R_2 = (A, B, C, E, G)$ 上还有 $A \rightarrow E$（由 $A \rightarrow D \rightarrow E$），最后得到 $\lbrace AD, AE, BC, ACG \rbrace$，连 $D \rightarrow E$ 也丢了。
