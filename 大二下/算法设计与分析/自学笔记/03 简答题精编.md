## 一、算法与算法分析

### 1. 算法有哪些重要特性？算法分析主要包括哪两方面内容？

算法的定义：一组有穷的规则，规定了解决某一特定问题的一系列运算。

五个特性：

- 确定性：每种运算必须有确切定义，无二义性。
- 能行性：运算都是基本运算，原理上能用纸和笔在有限时间内完成。
- 输入：有 0 个或多个输入，算法开始前从特定对象集合中取值。
- 输出：有一个或多个输出，输出和输入有特定关系。
- 有穷性：执行有穷步运算后终止。

算法分析的两方面：

- 事前分析：确定每条语句的执行次数，求出该算法关于问题规模 $n$ 的时间限界函数。
- 事后测试：实际运行并作时空性能分布图。

背的时候注意"可读性"不在五个特性里，随堂测试考过这个。

## 二、五种方法的适用问题与设计思想

这五题问法一致，结构也一致：适用什么问题 + 设计思想 + 具体问题清单。答题时三块都要写。

### 2. 分治法适用的问题和求解思想

适用的问题：

- $n$ 取值相当大，直接求解非常困难甚至无法求出。
- 能把 $n$ 个输入分解成 $k$ 个不同子集，得到 $k$ 个可独立求解的子问题。
- 求出子问题的解之后，能找到适当方法把它们合并成整个问题的解。

求解思想，把整个问题分成若干小问题后分而治之：

- 分（Divide）：子问题与原问题具有相同特征，但规模更小。
- 治（Conquer）：反复使用分治策略，直到可以直接求解子问题为止（递归地求解）。
- 合（Combine）：将子问题的解组合成原问题的解。

具体问题：二分查找、归并排序、斯特拉森矩阵乘法、二维极大点。

### 3. 贪心法适用的问题和求解思想

适用的问题：有 $n$ 个输入，解是这 $n$ 个输入的某个子集，子集必须满足事先给定的条件。四个概念要写全：

- 约束条件：必须满足的条件。
- 可行解：满足约束条件的子集。
- 目标函数：衡量可行解优劣的预定标准，以函数形式给出。
- 最优解：使目标函数取极值（极大或极小）的可行解。

求解思想，一种"只顾眼前"的分级处理方法：

- 量度标准：根据问题性质选一个量度标准来评估每个输入的价值。
- 选择输入：按量度标准一次选择一个输入。
- 构建解：当前输入若能与已有的部分解结合且满足约束条件就加入，否则放弃。

具体问题：带有期限的作业调度、最小生成树、分数背包（允许取小数的那个）。

### 4. 动态规划法适用的问题和设计思想概要

适用的问题特点：

- 属于多阶段决策问题：可以分成若干阶段，每阶段作一次决策，第 $i$ 阶段的决策仅依赖于第 $i$ 阶段当前的状态。
- 每阶段决策确定后，得到一个决策序列，进而算出一个解。
- 适用于求最优解的多阶段决策问题（多阶段决策优化问题，或组合优化问题），问题描述中一定有目标函数。

设计思想概要，三步：

1. 证明该多阶段决策问题满足最优性原理。
2. 设计递推关系式。
3. 迭代实现程序。

第 3 步写"迭代"不写"递归"，随堂测试考过。

具体问题：多段图、货郎担、0/1 背包、可靠性设计、最优二分检索树、矩阵链乘积。

### 5. 回溯法适用的问题和设计思想

适用的问题特点：

- 适用于多阶段决策问题，也称组合问题。
- 解向量用元组表示，元素 $x_i$ 通常取自某个有穷集，$1\le i\le n$，$n$ 是问题规模。元组可以是固定长 $n$-元组，也可以是不定长 $k$-元组（$k\le n$）。
- 问题满足多米诺性质。
- 问题寻找满足约束条件的一个解或所有解（组合搜索）；有时寻找最优解（组合优化），这时问题中还有目标函数。

设计思想：

1. 针对问题定义解空间树结构：元组、显式约束条件、隐式约束条件。
2. 检验问题满足多米诺性质。
3. 以深度优先方式搜索解空间树，搜索中用限界函数（隐式约束条件）避免无效搜索：
   - 根结点先成为活结点，同时是当前扩展结点。从当前扩展结点向纵深移到一个新活结点，该活结点成为新的扩展结点。
   - 当前扩展结点不能再向纵深移动时成为死结点，回溯到最近的一个活结点，使它成为新的扩展结点。
   - 直到找到所要求的解，或解空间中已无活结点为止。

具体问题：n-皇后、子集和数、图着色。

影响回溯法效率的三个因素（另一道题单独问过）：

| 因素 | 通俗说法 | 说明 |
| --- | --- | --- |
| 生成下一个 $x_k$ 的时间 | 生成一个结点的时间 | |
| 满足显式约束的 $x_k$ 的数目 | 子结点的数量 | |
| 限界函数 $B_k$ 的计算时间 | 检验结点的时间 | 能大幅减少生成的结点数，但计算时间和剪枝程度要折中 |
| 对所有 $i$ 满足 $B_i$ 的 $x_k$ 的数目 | 通过检验的结点数量 | 这个因素会导致不同实例产生的结点数不同 |

多米诺性质是回溯法提高效率的关键：怎么合理设置限界函数，在省下限界函数计算时间的同时尽可能多剪枝。

### 6. 分支限界法适用的问题和设计思想

适用的问题特点：

- 与回溯法类似，适用于求解组合数较大的问题，特别是组合优化问题（求最优解）。
- 解向量表达、显式约束条件、隐式约束条件、解空间、解空间树这些概念与回溯法完全相同。
- 两者的主要区别在于 E-结点（扩展结点）的处理方式不同。

设计思想：

1. 针对问题定义解空间树结构：元组、显式约束条件、隐式约束条件。
2. 检验问题满足多米诺性质。
3. 假设当前要找一个答案结点，按下面方式搜索解空间树：
   - 如果根结点 $T$ 是答案结点，输出 $T$，结束；否则令 $T$ 是当前扩展结点 $E$。
   - 生成 $E$ 的所有儿子结点，逐个判断儿子 $X$：若 $X$ 是答案结点，输出到根的路径并结束；若 $X$ 满足约束函数 $B$，把 $X$ 加入活结点表；否则舍弃 $X$。
   - 从活结点表中选出下一个结点成为新的 E-结点，重复上述操作。活结点表为空则算法以失败结束。

具体问题：15 谜、带有期限的作业调度（奖励变为惩罚）、0/1 背包。

## 三、贪心专题

### 7. 举例说明贪心算法中将目标函数直接作为量度标准不一定能得到最优解

用分数背包：$M=6$，$(p_1,p_2,p_3)=(6,4,3)$，$(w_1,w_2,w_3)=(6,2,1)$。

把目标函数（效益值）直接当量度标准，先取效益最大的第 1 件，$w_1=6$ 正好装满，解 $(1,0,0)$ 的效益是 6，背包再也装不下别的。最优解是 $(0.5,1,1)$，效益 $0.5\times6+4+3=10$，重量 $3+2+1=6$ 也没超。

按 $p_i/w_i$ 降序（分别是 $1,2,3$）才能拿到 10：先装第 3 件（$w=1$，$p=3$），再装第 2 件（$w=2$，$p=4$），剩下容量 3 装第 1 件的一半，得 $3+4+3=10$。

顺带一句，按重量最小也不行。$M=10$、$p=(1,20)$、$w=(1,10)$：先拿轻的那件只能再装第 2 件的 0.9，效益 $1+18=19$；直接整件装第 2 件效益 20。

### 8. 贪心方法设计求解的核心问题是什么？给出贪心方法解决背包问题的形式化描述

核心问题是**选择能产生问题最优解的最优量度标准**。

分数背包的形式化描述：给定 $n$ 件物品，第 $i$ 件重 $w_i$、效益 $p_i$，背包容量 $M$。取 $x_i\in[0,1]$ 表示第 $i$ 件装入的比例。

- 约束条件：$\sum_{i=1}^{n} w_i x_i \le M$，$0\le x_i\le 1$。
- 可行解：满足上述约束的向量 $(x_1,\dots,x_n)$。
- 目标函数：$\sum_{i=1}^{n} p_i x_i$。
- 最优解：使目标函数取最大值的可行解。

求解步骤：

1. 按单位重量效益 $p_i/w_i$ 从大到小排序。
2. 依次考虑每件物品，剩余容量装得下就整件装入。
3. 遇到第一件装不下的，按剩余容量装入其一部分，$x_i=\text{剩余容量}/w_i$，然后停止。
4. 后面的物品 $x_i=0$。

（更正：原稿这一题的答案是聊天机器人生成的，把约束条件写成了一段题目描述，公式写成 `( w_i )` 这种没渲染的形式，而且第 2、3 步只说"剩余容量能容纳就加入背包"，漏掉了最后那件按比例装入的步骤。漏掉这一步就变成 0/1 背包的贪心，得不到分数背包的最优解。正文已按分数背包改写。另外原稿在这里用的符号是 $v_i$ 和 $W$，课程 PPT 用的是 $p_i$ 和 $M$，这里统一成课程符号。）

## 四、动态规划专题

### 9. 什么是最优性原理？举一个最优性原理不成立的例子

最优性原理：无论过程的初始状态或者初始决策是什么，其余的决策都必须相对于初始决策所产生的状态构成一个最优决策序列。

不成立的例子：

- 多段图问题，以乘法作为路径长度且出现负权边时。
- 含负长度环的任意两点间最短路径问题。

成立的例子：流水线调度问题、货郎担问题。

## 五、回溯与分支限界专题

### 10. 回溯法和分支限界法的状态空间生成方式有何不同？简述两种方法的基本思想

状态空间生成方式的区别：

- 回溯法：当前 E-结点 $R$ 一旦生成一个新儿子结点 $C$，$C$ 立刻变成新的 E-结点；检测完以 $C$ 为根的子树后，$R$ 再次成为 E-结点，生成下一个儿子。
- 分支限界法：当前结点一旦成为 E-结点，就一直处理到变成死结点为止。它生成的儿子结点全部加入活结点表，再从活结点表中选择下一个新的 E-结点。

基本思想：

- 回溯法从根结点出发按深度优先策略搜索解空间树。判断 E-结点是否包含问题的解，不包含就跳过以该结点为根的子树，逐层向祖先结点回溯；包含就进入该子树继续深度优先搜索。
- 分支限界法从根结点出发，生成当前 E-结点的全部儿子之后，再选择新的活结点成为 E-结点，重复这个过程。为提高效率会用限界函数和成本估计函数剪枝。

### 11. 解释术语：状态空间树、显式约束、隐式约束、问题状态、解状态、答案状态、活结点、E-结点、死结点、限界函数。回溯法运行时状态空间树的结点没有全部遍历到，为什么没有丢解？

术语：

| 术语 | 含义 |
| --- | --- |
| 状态空间树 | 基于解空间画成的树形结构 |
| 显式约束 | 限定每个 $x_i$ 只从一个给定集合上取值，可以与所求解问题的实例有关也可以无关 |
| 隐式约束 | 规定问题实例的解空间中那些实际上满足规范函数的元组，描述了 $x_i$ 必须彼此相关的情况 |
| 问题状态 | 解空间树中的每一个结点确定所求解问题的一个问题状态 |
| 解状态 | 这样一些问题状态 $S$：由根到 $S$ 的那条路径确定了解空间的一个元组 |
| 答案状态 | 这样一些解状态 $S$：由根到 $S$ 的路径确定了问题的一个解（满足隐式约束条件） |
| 活结点 | 已经生成，但它的所有儿子结点还没有全部生成的结点 |
| E-结点 | 当前正在生成其儿子结点的活结点 |
| 死结点 | 不再进一步扩展，或其儿子结点已全部生成的结点 |
| 限界函数 | 所求解问题需要求一个使某限界函数 $P(x_1,x_2,\dots)$ 取极大值（或极小值，或满足该限界函数）的向量，表示问题的约束条件或目标 |

加限界的深度优先生成方法就是回溯法。回溯法在包含问题所有解的解空间树中按深度优先策略从根结点出发搜索，搜索到任一结点时先判断该结点是否肯定不包含问题的解，肯定不包含就跳过以它为根的子树、逐层向祖先回溯。**没有遍历的结点都是已经判定为无解的**，所以不会丢解。

### 12. 给出 LC 分支限界检索中活结点表使用的数据结构，并阐述 LC 分支限界检索的检索策略

数据结构：**堆**（极大堆或极小堆构成的优先队列）。题目点明了是 LC 分支限界所以用堆；FIFO 分支限界法用队列。这一问随堂测试以填空题形式考过。

检索策略：

1. 初始化：把根结点放入活结点表（优先队列）。
2. 循环：只要活结点表不为空就重复执行
   - 从活结点表中选择成本估计函数值最小（或最大）的结点作为当前扩展结点（E-结点）。
   - 生成当前 E-结点的所有子结点，并计算它们的成本估计函数值。
   - 把这些子结点按成本估计函数值的大小插入活结点表。
   - 任何时候找到目标解就结束搜索。
3. 终止：活结点表为空或找到目标解时算法结束。

### 13. LC 检索是否每次都能选出具有最小结点成本函数的结点作为下一个 E-结点？简述理由

不能。要满足以下两点，LC 检索才能保证找到最小成本的答案结点（如果存在）：

1. 对每一个结点 $X$ 都有成本估计函数 $\hat c(X)\le c(X)$，且对答案结点有 $\hat c(X)=c(X)$。
2. 采用改进后的算法 LC1，在从活结点表中删除元素时判断它是否为答案结点。

相关的一道判断题："计算成本函数的工作量与解决原问题的工作量一样"判**对**。说的是精确成本函数 $c(\cdot)$：要算准一个结点的真实成本，等于把它子树里的问题解完，所以才退一步用估计函数 $\hat c(\cdot)$。（更正：原稿在这道判断题旁边注"应该就是说并不会增加算法的最高时间复杂度"，方向反了，这句话恰恰是在说精确成本函数太贵。）

## 六、NP 专题

### 14. 简述 COOK 定理

COOK 定理指出 SAT 问题是 NP 完全的，即任何 NP 问题都可以在多项式时间内归约为 SAT 问题。这表明如果能在多项式时间内解决 SAT，那么所有 NP 问题都能在多项式时间内解决。

### 15. 简述 P 问题、NP 问题、NPC 问题，并解释 P 和 NP 之间、NP 和 NPC 之间的关系

1. P 问题是所有可在多项式时间内用确定算法求解的判定问题的集合，即给定输入大小为 $n$，存在一个多项式 $p(n)$ 使得算法可以在 $O(p(n))$ 时间内找到问题的解。
2. NP 问题是所有可在多项式时间内用不确定算法求解的判定问题的集合，即能用不确定算法在多项式时间里猜出一个解并验证一个解。
3. 一个问题是 NPC 问题需要满足两个条件：$L\in NP$；任何 NP 问题都可以在多项式时间内归约为 $L$。
4. P 和 NP 的关系：所有 P 问题都是 NP 问题，即 $P\subseteq NP$。所有可以在多项式时间内用确定算法求解的问题，其解也可以在多项式时间内验证。但 NP 问题不一定都能在多项式时间内求解，即 $P$ 不一定等于 $NP$。
5. NP 和 NPC 的关系：NPC 问题是 NP 问题中最难的一类，所有 NP 问题都可以在多项式时间内归约为任何一个 NPC 问题。如果能在多项式时间内解决一个 NPC 问题，那么所有 NP 问题都能在多项式时间内解决。

### 16. 简述什么是 NP 难问题，什么是 NP 完全问题，什么是可满足性问题。SAT 是否为 NP 难问题，是否为 NP 完全问题？

（原稿这一题没有写答案。下面的要点是按同一份材料里第 15、14 题的答案和随堂测试的选项补的，答题时按这个骨架写。）

- NP 难问题（NP-hard）：$L$ 是 NP 难，当且仅当任何 NP 问题都能多项式归约到 $L$。**不要求 $L$ 自己属于 NP**。
- NP 完全问题（NPC）：$L$ 是 NPC，当且仅当 $L\in NP$ 且 $L$ 是 NP 难。比 NP 难多了 $L\in NP$ 这个条件。
- 可满足性问题（SAT）：给定一个合取范式的布尔公式，判定是否存在一组变元赋值使公式取真。
- SAT 既是 NP 难问题也是 NP 完全问题。由 COOK 定理，任何 NP 问题都能多项式归约到 SAT，所以它是 NP 难；SAT 本身能在多项式时间内验证一组赋值，属于 NP，所以它是 NPC。

### 17. NP 难问题和 NP 完全问题有什么区别？

（原稿这一题同样没有写答案，下面按第 16 题的定义补。）

区别只有一条：NP 完全问题必须自己也属于 NP，NP 难问题不要求。所以 NPC $\subseteq$ NP 难，NP 难里还包含一些连"多项式时间内验证一个解"都做不到的问题（比如停机问题这类不可判定问题，也是 NP 难）。

随堂测试用两道单选把这个区别考了出来：

- 存在 NP 难问题 $L'$ 使 $L'\le_p L$，则 $L$ 是 **NP 难**问题（推不出 NPC，因为不知道 $L$ 在不在 NP 里）。
- 存在 NPC 问题 $L'$ 使 $L'\le_p L$，**且 $L\in NP$**，则 $L$ 是 **NPC** 问题。

### 18. 请给出三个 NP 问题的例子

原稿列了五个，都是 NPC：0/1 背包问题、子集和问题、恰好覆盖问题、旅行商问题（货郎担）、图着色问题。答三个即可，因为 NPC 都属于 NP。

### 19. 如何证明一个问题是 NP 完全问题？

两步：

1. 证明问题 $L$ 是 NP 问题：给定一个候选解，能在多项式时间内检查它是否是正确的解。
2. 已知一个 NPC 问题 $L'$，证明 $L'\le_p L$：找到一个算法，把 $L'$ 的任意实例转换为 $L$ 的实例并保持问题的解集不变，而且这个归约过程要在多项式时间内完成。

注意归约方向是"已知的 NPC 归约到待证的问题"，写反了就证不出任何东西。
