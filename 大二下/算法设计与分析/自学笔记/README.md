# 算法设计与分析 自学指南

这一套笔记整理自 `笔记/算法整理.pdf`（31 页，含简答题整理、时间复杂度整理、学习通随堂测试、程序题与力扣题）。

定位是考前速查，不复述讲义。概念、算法流程、例题推演请看 `重制版PPT/` 里的七份课件；这里只放考点清单、解题套路、复杂度推导和易错点。

## 建议学习顺序

1. 先看 `01`，对照自己的听课情况圈出没把握的章。
2. 圈到的章去看 `重制版PPT/` 对应那一份，把算法流程走一遍。
3. 回来做 `04` 的随堂测试题，错题回 `01` 的易错点核对。
4. 考前两天集中背 `02` 和 `03`。
5. `05` 留给大题，重点是把递推式写清楚，代码其次。

## 考试信息

来自课程目录下的 `README.md`（学长的备考记录）：

- 题型主要是选择题和大题。
- 选择题几乎都出自 PPT 和作业题，前几题常从"导引"这一章出，这一章要逐页看。
- 大题先考虑时间复杂度和空间复杂度。能写递推就别写递归。最后一题把递推表达式写出来就能拿到分，题型和某道作业题或 PPT 上的题接近。
- 答题顺序：先用中文写思路，再写代码。
- 平时分看学习通答题和作业完成情况。

原稿没有写分值分布和具体年份，这里不做推测。随堂测试每题 5 分，是学习通上的分值，和期末卷无关。
