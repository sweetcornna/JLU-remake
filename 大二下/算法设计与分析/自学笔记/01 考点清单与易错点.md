# 01 考点清单与易错点

整理自 `笔记/算法整理.pdf`。概念定义和算法流程看 `重制版PPT/` 对应课件，这里只写"考什么"和"错在哪"。

## 按章考点清单

### 第 2 章 导引

对应 `重制版PPT/第2章 算法导引（重制版）.pptx`。学长的备考记录说选择题前几道常从这一章出，要逐页看。

必背：

- 算法的五个特性：**确定性、能行性、有穷性、输入、输出**。可读性不是其中之一，这是原题考点。
- 算法分析的两方面：**事前分析**（数出每条语句执行次数，求出关于 $n$ 的时间限界函数）和**事后测试**（实测并作时空性能分布图）。
- 渐进记号的运算规则，见 `02 复杂度推导速查.md` 的"记号运算"一节。
- 量级排序： $O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3)$，再往上是非多项式 $O(2^n) < O(n!) < O(n^n)$。

易错点：

- 构造数据集时"规模越大越有利于分析"是错的。要的是最好、最坏和有代表性的数据，不是最大的数据。
- $\Theta(f)+\Theta(g)=\Theta(\min(f,g))$ 错，应该是 $\Theta(\max(f,g))$，也等于 $\Theta(f+g)$。
- $\Omega$ 的两个等式在同一次测试里都判"对"：已知 $g(n)=\Omega(f(n))$ 时， $\Omega(f)+\Omega(g)$ 既 $=\Omega(f)$ 也 $=\Omega(g)$。这类等式是单向读的，意思是"左边集合里的每个函数都落在右边集合里"，不是两边相等。 $a+b \ge c_1 f$ 所以属于 $\Omega(f)$， $a+b \ge c_2 g$ 所以也属于 $\Omega(g)$，两句话不冲突。

### 第 4 章 分治法

对应 `重制版PPT/第4章 分治法（重制版）.pptx`。

必背：

- 分(Divide) / 治(Conquer) / 合(Combine) 三步，子问题与原问题同型但规模更小。
- 设计分治算法最重要的步骤是**子问题的划分和合并**。这题四个选项分别对应贪心（最优量度标准）、动态规划（递推关系式）、回溯（状态空间树和限界函数），别记混。
- 四个具体问题：二分查找、归并排序、斯特拉森矩阵乘法、二维极大点。
- 以比较为基础的**分类**（排序）算法时间下界 $\Omega(n\log n)$；以比较为基础的**检索**算法时间下界 $\Omega(\log n)$。

易错点：

- 原稿在"4 分治"一节里写"以比较为基础的检索算法的时间下界是 $O(\log n)$"并自己打了问号"究竟是 $\Omega$ 还是 $O$"。（更正：原文作 $O(\log n)$，下界要用 $\Omega$，应为 $\Omega(\log n)$。）同一份材料里随堂测试第 1 题答案选的就是 $\Omega(n\log n)$ 而不是 $O(n\log n)$，选项 A、B 用 $O$ 就是故意挖的坑。
- 斯特拉森的改进点是**把 8 次子矩阵乘法减到 7 次**，加法次数反而变多了。说它"针对矩阵加法运算过多进行改进"是错的。
- 分治不是任何情况下都优于蛮力。矩阵乘法直接按 $8T(n/2)+dn^2$ 分治，解出来还是 $\Theta(n^3)$，和蛮力同阶。
- 三分查找最坏情况**不如**二分。每层多一次比较，层数只按 $\log_3$ 减少，总比较次数是二分的 $2/\log_2 3 \approx 1.26$ 倍。
- "二分查找是最坏情况下的最优算法"这句话判"对"，注意限定语是"最坏情况下"。

### 第 5 章 贪心法

对应 `重制版PPT/第5章 贪心法（重制版）.pptx`。

必背：

- 四件套：约束条件、可行解、目标函数、最优解。
- 贪心设计的**核心问题是选择能产生问题最优解的量度标准**，注意是"能产生问题最优解的"，不是随便一个量度标准。
- 三个具体问题：带有期限的作业调度、最小生成树、分数背包（允许取小数的那个）。
- 定理 5.3：设 $J$ 是 $k$ 个作业的集合， $\sigma=i_1,i_2,\dots,i_k$ 使得 $d_{i_1}\le d_{i_2}\le\cdots\le d_{i_k}$。 $J$ 是可行解，当且仅当 $J$ 中作业能按 $\sigma$ 的次序处理而不违反任何期限。

易错点：

- 目标函数直接当量度标准会错。标准反例： $M=6$， $(p_1,p_2,p_3)=(6,4,3)$， $(w_1,w_2,w_3)=(6,2,1)$。按效益值最大先取 $p_1$，背包装满了，解 $(1,0,0)$ 效益只有 6；最优解是 $(0.5,1,1)$，效益 10。按 $p/w$ 降序才能拿到 10。
- 按重量最小也不是好量度。 $M=10$， $p=(1,20)$， $w=(1,10)$：先拿轻的那件，剩 9 的容量只能装 0.9 件第二件，效益 $1+18=19$；直接装第二件效益 20。
- 定理 5.3 判的是**集合**可行性，选择题给的往往是**具体调度次序**。原题 $(p)=(100,10,15,20)$、 $(d)=(2,1,2,3)$ 问哪个调度不可行，答案 D（ $J_3,J_2,J_4$）：按这个次序 $J_2$ 排在第 2 个时刻完成，而 $d_2=1$，违约。但 $\{J_2,J_3,J_4\}$ 作为集合重排成 $J_2,J_3,J_4$ 是可行的。看清题目问的是次序还是集合。
- 作业有不同处理时间时，定理 5.3 **仍然成立**。判断题说"不成立"是错的。
- 带期限作业调度：朴素 JS 算法 $O(n^2)$，用集合树（并查集）优化后接近 $O(n)$。判断题里写"由 $O(n^3)$ 降到接近 $O(n^2)$"是错的，两个数量级都错了。
- 贪心法**求不了**货郎担问题，TSP 是 NPC 问题。
- 分数背包贪心（不算预排序）是 $O(n)$，不是 $\Theta(n^2)$。

### 第 6 章 动态规划

对应 `重制版PPT/第6章 动态规划（重制版）.pptx`。

必背：

- 设计动态规划最重要的步骤是**最优性原理和递推关系式**。
- 三步走：先证明满足最优性原理，再设计递推关系式，最后用**迭代**实现程序。第三步写"递归"就算错，随堂测试考过。
- 最优性原理：无论初始状态或初始决策是什么，其余决策都必须相对于初始决策产生的状态构成一个最优决策序列。
- 六个具体问题：多段图、货郎担、0/1 背包、可靠性设计、最优二分检索树、矩阵链乘积。

易错点：

- **最优性原理不是对所有多阶段决策问题都成立**。不成立的例子：多段图以乘法定义路径长度且有负权边时；含负长度环的任意两点间最短路径问题。成立的例子：流水线调度、货郎担。
- 不适合动态规划的是**矩阵乘法问题**（那是分治）；动态规划里的是**矩阵链乘积问题**（加括号决定乘法顺序）。这两个名字差一个字，是常考陷阱。
- 最适合动态规划的是**可靠性设计**。带期限作业调度属于贪心或分支限界，8 皇后属于回溯，排序属于分治。
- 子问题规模不能任意跳，要从小规模往大规模推。
- 0/1 背包 $\Theta(nM)$ 在最坏情况下**是指数阶**。因为 $M$ 不是输入规模，输入 $M$ 只需要 $m=\lceil\log M\rceil$ 位， $\Theta(nM)=\Theta(n2^m)$，这叫伪多项式。0/1 背包是 NPC。
- 迭代法和序偶对法**没有谁在数量级上绝对更优**。序偶对法是 $O(\min\{2^n,\ n\sum P_j,\ nM\})$，取的是最小值，所以最坏情况下不会比迭代法的 $\Theta(nM)$ 差。（更正：原稿这道判断题的解析是聊天机器人风格的空话，真正的理由就是序偶对法的界里含 $nM$ 这一项。）
- 多阶段决策问题**不一定**具备重叠子问题性质，但用动态规划求解的时候一定满足最优性原理。最优子结构决定"能不能用动态规划"，重叠子问题决定"迭代比递归快多少"，两者作用的环节不同。

### 第 7 章 回溯法

对应 `重制版PPT/第7章 回溯法（重制版）.pptx`。

必背：

- 解向量用元组表示，可以是**定长 $n$-元组**，也可以是**不定长 $k$-元组**（ $k\le n$）。说"必须表示成 $n$-元组"是错的。
- 设计三步：先定义解空间树（元组、显式约束、隐式约束），再检验多米诺性质，最后深度优先搜索并用限界函数剪枝。
- 活结点 / E-结点 / 死结点：已生成但儿子没全生成的是**活结点**；活结点中正在生成儿子的是 **E-结点**；不再扩展或儿子已全生成的是**死结点**。
- 解状态：由根到 $S$ 的路径确定了解空间的一个元组。答案状态：解状态中那些路径还满足隐式约束、构成问题一个解的。
- 三个具体问题：n-皇后、子集和数、图着色。
- 为什么不遍历全部结点也不丢解：被剪掉的子树已经判定为"肯定不包含问题的解"，剪掉的都是无解分支。

易错点：

- 影响效率的三个因素要分清楚：生成下一个 $x_k$ 的时间（生成一个结点的时间）、满足显式约束的 $x_k$ 数目（子结点数量）、限界函数 $B_k$ 的计算时间（检验结点的时间）。限界函数能大幅减少结点数，但计算时间和剪枝力度要折中。
- 状态空间树结点数的算法是**等比数列求和**，别只算叶子： $m$ 叉、 $n$ 层的树共 $1+m+m^2+\cdots+m^n$ 个结点。3 顶点 3 颜色的图着色： $1+3+9+27=40$。
- 子集和问题 $n=4$ 定长元组是完全二叉树：问题状态（全部结点） $2^5-1=31$ 个，解状态（叶子） $2^4=16$ 个。（更正：原文把 31 写成 $2^6+2^5$，那个算式等于 96；正确写法是 $2^5-1=31$，或 $1+2+4+8+16$。）
- n-皇后**不考虑任何隐式约束**是 $O(n^n)$；加上"同列不能重复"这条隐式约束才降到 $O(n!)$。填空题特意写了"不考虑任何隐式约束条件"。
- 与实例相关的状态空间树叫**动态树**，与实例无关的叫静态树。
- n 皇后问题对 $n\ge 4$ 的每个值都有解。

### 第 8 章 分支限界法

对应 `重制版PPT/第8章 分支限界法（重制版）.pptx`。

必背：

- 和回溯法的区别**只在 E-结点的处理方式**。解向量表示、显式约束、隐式约束、解空间、解空间树这些概念完全相同。
- 回溯法：E-结点 R 一生成儿子 C，C 立刻变成新 E-结点；检测完 C 的子树后 R 重新成为 E-结点。
- 分支限界法：一个结点成为 E-结点后一直处理到变成死结点，生成的儿子全部加入活结点表，再从活结点表里挑下一个 E-结点。
- 活结点表的数据结构：**LC 分支限界用堆**（极大堆或极小堆的优先队列），**FIFO 分支限界用队列**。
- 三个具体问题：15 谜、带有期限的作业调度（奖励改成惩罚）、0/1 背包。

易错点：

- FIFO 分支限界更接近**广度优先**，不是深度优先。队列先进先出，先扩展最早生成的结点。
- 最小成本 FIFO 分支限界里，成本估计函数**有用**：拿估计值和成本上界 $U$ 比较就能剪枝。说它起不到优化作用是错的。
- LC 检索**不能**保证每次都选出最小成本结点，要满足两个条件才能保证找到最小成本答案结点：一是对每个结点 $X$ 都有 $\hat c(X)\le c(X)$ 且对答案结点有 $\hat c(X)=c(X)$；二是采用改进算法 LC1，在从活结点表中删除元素时判断是否为答案结点。
- "计算成本函数的工作量与解决原问题的工作量一样"判**对**。这说的是精确成本函数 $c(\cdot)$，正因为算它和直接解原问题一样费劲，才要退而用估计函数 $\hat c(\cdot)$。（更正：原稿在这题旁边注"应该就是说并不会增加算法的最高时间复杂度"，理解反了。）
- 0/1 背包能用回溯、分支限界、动态规划求解，**贪心不行**。

### 第 9 章 NP 完全问题

对应 `重制版PPT/第9章 NP 完全问题（重制版）.pptx`。

必背：

- P：能用确定性算法在多项式时间内求解的判定问题。NP：能用不确定性算法在多项式时间内求解（即多项式时间内猜一个解并验证一个解）的判定问题。
- $P \subseteq NP$，但 $P$ 是否等于 $NP$ 未知。
- $L$ 是 NPC 需要两个条件： $L \in NP$，且任何 NP 问题都能多项式归约到 $L$。
- NP 难只要满足"任何 NP 问题都能多项式归约到它"，**不要求自己属于 NP**。所以 NPC = NP 难 ∩ NP。
- COOK 定理：SAT 是 NP 完全的。若 SAT 有多项式时间算法，则所有 NP 问题都有。
- 证明 $L$ 是 NPC 的两步：先证 $L\in NP$（给定候选解能多项式时间验证），再找一个已知的 NPC 问题 $L'$ 证 $L'\le_p L$（把 $L'$ 的任意实例多项式时间转换成 $L$ 的实例且保持解集不变）。
- 常见 NPC：0/1 背包、子集和、恰好覆盖、旅行商（货郎担）、图着色。

易错点：

- "非 P 问题都能转化为 NP 问题"是**错的**。非 P 是指不能在多项式时间内求解，NP 是指能在多项式时间内验证，有些问题连验证都做不到多项式时间。
- 归约方向要记牢：已知 NP 难 $L'$ 且 $L'\le_p L$，则 $L$ 是 **NP 难**（不一定在 NP 里，所以推不出 NPC）；已知 NPC $L'$ 且 $L'\le_p L$ 且 $L\in NP$，则 $L$ 是 **NPC**。多的那个条件 $L\in NP$ 就是区别。
- NPC 都是 NP，但 NP 不都是 NPC。
- 一个优化问题通常可以改写成判定问题，这句话是对的。

## 大题怎么答

学长的备考记录写着：先用中文写思路再写代码，能用递推就别用递归，最后一题把递推表达式写出来就能拿分。据此的答题模板：

1. 判断用哪种方法，一句话说清理由（是否满足最优性原理 / 是否需要搜索全部组合 / 子问题能否独立求解）。
2. 定义状态。写清楚下标的含义和取值范围，这是递推式的地基。
3. 写递推关系式和边界条件。边界（ $i=0$、 $X<0$、 $S=\varnothing$）单独列一行，别塞进主式子里。
4. 说明计算顺序（从小规模到大规模、按阶段 $i$ 递减还是递增）。
5. 写时间和空间复杂度，并说明是怎么数出来的：状态数 × 每个状态的转移代价。
6. 有余力再写伪代码或 C++ 代码。
