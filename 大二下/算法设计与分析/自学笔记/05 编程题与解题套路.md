## 一、大题通用套路

学长的备考记录写了两条：能用递推就别用递归，先用中文写思路再写代码。落到卷面上：

1. 定状态。写清楚下标含义和取值范围，例如" $f_i(X)$ 表示只考虑前 $i$ 件物品、容量为 $X$ 时的最大效益"。状态定错了后面全错。
2. 写递推式和边界。边界单独列一行。
3. 说计算顺序。是按 $i$ 从小到大填表，还是按阶段从后往前推。
4. 算复杂度。时间 = 状态数 × 每个状态的转移代价，空间 = 表格规模（能滚动就写滚动后的）。
5. 代码放最后写，写不完也不影响前面的分。

二分类题目另有一套模板，见下面第二节。

## 二、程序题 1：分治法，二分查找

### 原题

数组先递减后递增，找到最小值。原稿标注这题和力扣 162 寻找峰值是同一套模板。

### 力扣 162 寻找峰值

给定相邻元素互不相等的数组 `nums`，返回任一峰值元素的下标（峰值指严格大于左右相邻元素的位置，数组两端视作负无穷）。

原稿的题解用的是**开区间二分模板**：

```cpp
class Solution {
public:
    int findPeakElement(vector<int> &nums) {
        int left = -1, right = nums.size() - 1; // 开区间 (-1, n-1)
        while (left + 1 < right) {              // 开区间不为空
            int mid = left + (right - left) / 2;
            if (nums[mid] > nums[mid + 1]) right = mid; // 蓝色
            else left = mid;                            // 红色
        }
        return right;
    }
};
```

思路：把每个下标染色，`nums[i] > nums[i+1]` 的染蓝（峰值在它或它左边），否则染红（峰值在它右边）。二分维持不变量"`left` 永远是红色，`right` 永远是蓝色"，循环结束时 `right` 就是第一个蓝色位置，也就是峰值。

三个细节，考试和面试都爱考：

- 开区间写 `(-1, n-1)` 而不是 `(-1, n)`，因为下标 `n-1` 必然是蓝色（右边是负无穷），不需要检查。
- `mid = left + (right - left) / 2` 而不是 `(left + right) / 2`，避免两数相加溢出。
- 循环条件是 `left + 1 < right`，开区间里还有元素时才继续。

回到原题"先递减后递增找最小值"：原稿说把 `>` 改成 `<` 就符合题意。确实如此。改完之后染色规则变成"`nums[mid] < nums[mid+1]` 的位置在谷底或谷底右边"，二分收敛到第一个这样的位置，就是最小值下标。

复杂度：时间 $O(\log n)$，空间 $O(1)$。

核对：随机生成 3000 组相邻互不相等的数组跑 `findPeakElement`，返回的下标全部是合法峰值；再随机生成 3000 组"先严格递减后严格递增"的数组跑改 `<` 的版本，返回位置的值全部等于数组最小值。两个版本都没有反例。

## 三、程序题 2：动态规划，商店选址

### 原题

在一条呈直线的公路两旁有 $n$ 个位置 $x_1,x_2,\dots,x_n$ 可以开商店，在位置 $x_i$ 开商店的预期收益是 $p_i$， $i=1,2,\dots,n$。如果任何两个商店之间的距离必须至少为 $d$，那么如何选择开设商店的位置使总收益最大？

原稿说这题类似力扣 198 打家劫舍，把 `f` 数组的初始条件设一下，再把递推方程改成 `f[i]=max(f[i-1], f[i-d]+nums[i])` 即可。

### 这个递推式有问题

（更正：原稿把"位置距离至少为 $d$"当成了"下标之差至少为 $d$"。只有当 $n$ 个位置在数轴上等距排布、间距恰好为 1 时两者才等价；题目给的 $x_i$ 是任意位置，下标差和距离没有关系。）

反例（已用穷举验证）：

| $x$ | $p$ | $d$ | 原稿下标法 | 正确答案 |
| --- | --- | --- | --- | --- |
| $(0,1,2,100)$ | $(1,1,1,1)$ | 2 | 2 | 3 |
| $(0,5,6,7,20)$ | $(3,4,4,4,3)$ | 4 | 6 | 10 |

第一行的道理：正确解选 $x=0,2,100$ 三个位置，两两距离分别是 2 和 98，都不小于 $d=2$；而下标法选完下标 0 和 2 之后，下标 3 与下标 2 只差 1，被下标规则挡住了，明明位置差 98。第二行同理， $x=0$ 与 $x=5$ 距离 5、 $x=5$ 与 $x=20$ 距离 15，选 $0,5,20$ 收益 $3+4+3=10$，下标法只拿到 6。

### 正确写法

先把位置按 $x$ 升序排好（题目一般已经有序）。设 $f[i]$ 表示只考虑前 $i$ 个位置时的最大收益：

$$f[i]=\max\big(f[i-1],\ p_i+f[j(i)]\big),\qquad f[0]=0$$

其中 $j(i)$ 是满足 $x_j \le x_i - d$ 的最大下标（没有这样的 $j$ 时取 0）。两种选择的含义：不在 $x_i$ 开店，收益就是 $f[i-1]$；在 $x_i$ 开店，那么前一家店必须落在 $x_i-d$ 及其左边，能用的最好结果就是 $f[j(i)]$。

$j(i)$ 的求法： $x$ 有序，用二分查找，整体 $O(n\log n)$；因为 $j(i)$ 随 $i$ 单调不减，也可以用双指针做到 $O(n)$。空间 $O(n)$。

C++ 伪代码：

```cpp
// x 升序, p 与 x 同序, 下标从 1 开始
vector<long long> f(n + 1, 0);
int j = 0;                       // 双指针, 指向最后一个满足 x[j] <= x[i]-d 的位置
for (int i = 1; i <= n; ++i) {
    while (j + 1 <= i - 1 && x[j + 1] <= x[i] - d) ++j;
    f[i] = max(f[i - 1], p[i] + f[j]);
}
return f[n];
```

原稿的下标法什么时候能用：题目明确说 $n$ 个位置等距、相邻间距为 1（或者干脆给的就是下标而不是坐标），这时"距离至少 $d$"等价于"下标至少差 $d$"，`f[i]=max(f[i-1], f[i-d]+p[i])` 才成立。力扣 198 就是 $d=2$ 的这种特例，所以原稿套模板套出了问题。

核对：三种实现（原稿下标法、正确的位置法、 $2^n$ 穷举）在上表四组数据上对比，位置法和穷举全部一致，下标法在两组上偏小；另外在"位置等距为 $0..n-1$、 $d=3$"的 200 组随机收益上，下标法与穷举全部一致，说明它只在等距情形正确。

## 四、力扣热题：动态规划

原稿把这一部分标为"力扣热题整理"。题目描述在下面压成一句话，重点是递推式和它为什么这么写。

### 198 打家劫舍

沿街房屋各有金额 `nums[i]`，相邻两间不能同时偷，求最大金额。

递推式： $f[i]=\max(f[i-1],\ f[i-2]+nums[i])$。含义是第 $i$ 间偷或不偷，偷就得从 $i-2$ 转移。

原稿给了两种写法。写法一补两个哨兵位，不用单独处理边界：

```cpp
class Solution {
public:
    int rob(vector<int> &nums) {
        int n = nums.size();
        vector<int> f(n + 2);
        for (int i = 0; i < n; ++i)
            f[i + 2] = max(f[i + 1], f[i] + nums[i]);
        return f[n + 1];
    }
};
```

写法二原地改 `nums`，省掉额外数组，但要手写 `i==1` 的边界：

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        for (int i = 1; i < n; ++i) {
            if (i == 1) nums[i] = max(nums[i], nums[i-1]);
            else nums[i] = max(nums[i-1], nums[i-2] + nums[i]);
        }
        return nums[n-1];
    }
};
```

写法一的 `f` 下标整体右移 2 位，所以循环里写的是 `f[i+2]`、`f[i+1]`、`f[i]`，返回 `f[n+1]`。这种"加哨兵换掉边界判断"的技巧考试写伪代码时很省事。

复杂度：时间 $O(n)$，空间写法一 $O(n)$、写法二 $O(1)$（滚动两个变量还能进一步降到 $O(1)$）。

核对：两种写法在 2000 组随机数组（ $n\le 12$）上与 $2^n$ 枚举的结果完全一致，示例 `[1,2,3,1]` 得 4、`[2,7,9,3,1]` 得 12，与题目给的输出相符。

### 279 完全平方数

给定整数 $n$（ $1\le n\le 10^4$），返回和为 $n$ 的完全平方数的最少数量。

递推式： $dp[i]=\min_{j^2\le i}\{dp[i-j^2]+1\}$， $dp[0]=0$。这是完全背包：物品是 $1^2,2^2,3^2,\dots$，容量是 $n$，每种物品可以用无限次。

```cpp
class Solution {
public:
    int numSquares(int n) {
        vector<int> dp(n + 1, INT_MAX);
        dp[0] = 0;
        for (int i = 0; i <= n; i++) {          // 遍历背包
            for (int j = 1; j * j <= i; j++) {  // 遍历物品
                dp[i] = min(dp[i - j * j] + 1, dp[i]);
            }
        }
        return dp[n];
    }
};
```

复杂度：时间 $O(n\sqrt n)$，空间 $O(n)$。

核对： $n=12$ 得 3， $n=13$ 得 2，与题目示例一致。

### 322 零钱兑换

给定面额数组 `coins` 和总金额 `amount`，每种硬币无限枚，求凑出总金额的最少硬币数，凑不出返回 -1。数据范围 `1 <= coins.length <= 12`，`1 <= coins[i] <= ` $2^{31}-1$，`0 <= amount <= ` $10^4$。

递推式： $dp[i]=\min_{c\in coins,\ c\le i}\{dp[i-c]+1\}$， $dp[0]=0$。和 279 是同一个模型，物品换成任意面额。

```cpp
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        int n = coins.size();
        sort(coins.begin(), coins.end());
        int dp[amount+1];
        memset(dp, 0x3f, sizeof(dp));
        dp[0] = 0;
        for (int i = 1; i <= amount; ++i) {
            for (int j = 0; j < n; ++j) {
                if (coins[j] > i) break;
                dp[i] = min(dp[i], dp[i-coins[j]] + 1);
            }
        }
        return dp[amount] == 0x3f3f3f3f ? -1 : dp[amount];
    }
};
```

两个实现技巧：先给 `coins` 排序，内层循环遇到 `coins[j] > i` 就 `break`；用 `memset` 填 `0x3f` 得到 `0x3f3f3f3f`，这个值够大又不会在加 1 时溢出。

复杂度：时间 $O(amount\times|coins|)$，空间 $O(amount)$。

核对：`coins=[1,2,5], amount=11` 得 3，`coins=[2], amount=3` 得 -1，`coins=[1], amount=0` 得 0，与三个示例一致。

### 139 单词拆分

给定字符串 `s` 和字典 `wordDict`，判断 `s` 能否拆成字典里的若干个单词（单词可重复使用）。

递推式： $dp[i]=\bigvee_{0\le j<i}\big(dp[j]\wedge (s[j..i)\in wordDict)\big)$， $dp[0]=\text{true}$。 $dp[i]$ 表示 `s` 的前 $i$ 个字符能否拆开。

```cpp
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        auto wordDictSet = unordered_set<string>();
        for (auto word : wordDict) wordDictSet.insert(word);
        auto dp = vector<bool>(s.size() + 1);
        dp[0] = true;
        for (int i = 1; i <= s.size(); ++i) {
            for (int j = 0; j < i; ++j) {
                if (dp[j] && wordDictSet.find(s.substr(j, i - j)) != wordDictSet.end()) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[s.size()];
    }
};
```

字典先转成 `unordered_set` 是为了把查找降到 $O(1)$。复杂度：时间 $O(n^2)$ 次查找，每次查找还要 $O(n)$ 做子串哈希，所以是 $O(n^3)$ 量级；空间 $O(n+\sum|word|)$。

核对：`"leetcode"` 配 `["leet","code"]` 为 true，`"applepenapple"` 配 `["apple","pen"]` 为 true，`"catsandog"` 配 `["cats","dog","sand","and","cat"]` 为 false，与三个示例一致。

### 300 最长递增子序列

给定数组 `nums`，求最长严格递增子序列的长度。

递推式： $ans[i]=\max\{ans[j]+1 : j<i,\ nums[j]<nums[i]\}$，初值全为 1，答案取 $\max_i ans[i]$。注意答案是整个数组的最大值，不是 `ans[n-1]`，因为最长子序列不一定以最后一个元素结尾。

```cpp
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(n, 1);
        for (int i = 1; i < n; ++i) {
            for (int j = 0; j < i; ++j) {
                if (nums[j] < nums[i]) ans[i] = max(ans[i], ans[j] + 1);
            }
        }
        return *max_element(ans.begin(), ans.end());
    }
};
```

复杂度：时间 $O(n^2)$，空间 $O(n)$。用贪心加二分维护"长度为 $k$ 的递增子序列的最小结尾"可以降到 $O(n\log n)$，原稿没写这个版本。

核对：`[10,9,2,5,3,7,101,18]` 得 4，`[0,1,0,3,2,3]` 得 4，`[7,7,7,7,7,7,7]` 得 1，与三个示例一致。

### 152 乘积最大子数组

给定整数数组 `nums`，求乘积最大的非空连续子数组的乘积。

这题的关键是**同时维护最大值和最小值**。负数乘一个负数会变成很大的正数，所以以 $i$ 结尾的最小乘积也要存着，下一步可能翻身成最大。

递推式：

$$maxF[i]=\max\{maxF[i-1]\cdot nums[i],\ nums[i],\ minF[i-1]\cdot nums[i]\}$$
$$minF[i]=\min\{minF[i-1]\cdot nums[i],\ nums[i],\ maxF[i-1]\cdot nums[i]\}$$

中间那项 `nums[i]` 代表"从这里重新开始"。

```cpp
class Solution {
public:
    int maxProduct(vector<int>& nums) {
        vector<int> maxF(nums), minF(nums);
        for (int i = 1; i < nums.size(); ++i) {
            maxF[i] = max(maxF[i-1] * nums[i], max(nums[i], minF[i-1] * nums[i]));
            minF[i] = min(minF[i-1] * nums[i], min(nums[i], maxF[i-1] * nums[i]));
        }
        return *max_element(maxF.begin(), maxF.end());
    }
};
```

这份代码用了两个数组，所以第二行里的 `maxF[i-1]` 还是上一轮的值，没有被刚算出的 `maxF[i]` 污染。如果改写成滚动变量，一定要先把旧的 `maxF` 存到临时变量再更新，否则会错。

复杂度：时间 $O(n)$，空间 $O(n)$（滚动可降到 $O(1)$）。

核对：`[2,3,-2,4]` 得 6，`[-2,0,-1]` 得 0，与示例一致；另外在 3000 组随机数组（长度 $\le 8$、元素在 $[-10,10]$）上与枚举所有子数组的结果逐一比对，没有差异。

### 416 分割等和子集

给定只含正整数的非空数组 `nums`，判断能否分成两个元素和相等的子集。

转化成 0/1 背包：设总和为 $S$， $S$ 是奇数直接返回 false；否则取 $target=S/2$，问"能否挑出若干个数恰好凑到 $target$"。

递推式（原稿用的是价值型写法）：

$$f[i+1][c]=\begin{cases}f[i][c] & c<nums[i]\\ \max\{f[i][c],\ f[i][c-nums[i]]+nums[i]\} & c\ge nums[i]\end{cases}$$

最后判断 $f[n][target]==target$。 $f[i][c]$ 的含义是"前 $i$ 个数在容量 $c$ 内能凑到的最大和"，它等于 $target$ 就说明恰好凑满。

```cpp
class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int n = nums.size(), sum = 0;
        for (int num : nums) sum += num;
        if (sum % 2) return false;
        int target = sum / 2;
        int f[n+1][target+1];
        memset(f, 0, sizeof(f));
        f[0][0] = 0; // 边界条件
        for (int i = 0; i < n; ++i) {
            for (int c = 0; c <= target; ++c) {
                if (c < nums[i]) f[i+1][c] = f[i][c];
                else f[i+1][c] = max(f[i][c], f[i][c-nums[i]] + nums[i]); // 0-1 背包模板
            }
        }
        return f[n][target] == target;
    }
};
```

复杂度：时间 $O(n\cdot S)$，空间 $O(n\cdot S)$，可以压成一维 $O(S)$，一维时容量要**倒序**遍历，否则同一个数会被用两次。

核对：`[1,5,11,5]` 为 true（拆成 `[1,5,5]` 和 `[11]`），`[1,2,3,5]` 为 false，与示例一致。

### 32 最长有效括号

给定只含 `(` 和 `)` 的字符串，求最长有效括号子串的长度。

原稿写"由于本人用的是栈方法而非动态规划，贴一个题解链接"，链接指向力扣官方题解页 `https://leetcode.cn/problems/longest-valid-parentheses/solutions/314683/`，本身没有抄代码。这题在这份材料里只有题目，没有解答。

栈法的一句话思路：栈里存下标，栈底始终放"最后一个未匹配的右括号下标"作为哨兵，遇到 `(` 压下标，遇到 `)` 先弹栈，弹空了就把当前下标压进去当新哨兵，否则用当前下标减栈顶更新答案。时间 $O(n)$，空间 $O(n)$。

## 五、力扣热题：二分查找

### 74 搜索二维矩阵

给定每行非严格递增、且每行第一个数大于前一行最后一个数的 $m\times n$ 矩阵，判断 `target` 是否存在。

这两条性质合起来说明：把矩阵按行展开成一维数组后整体有序。所以直接在 $[0, mn)$ 上二分，用 `matrix[mid/n][mid%n]` 取值。下标换算是这题的全部考点。

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = matrix.size(), n = matrix[0].size();
        int left = -1, right = m * n;
        while (left + 1 < right) {
            int mid = left + (right - left) / 2;
            int x = matrix[mid / n][mid % n];
            if (x == target) return true;
            (x < target ? left : right) = mid;
        }
        return false;
    }
};
```

`(x < target ? left : right) = mid;` 这个写法是三元运算符返回左值，等价于 `if (x < target) left = mid; else right = mid;`。写伪代码时建议展开，别为了短而牺牲可读性。

复杂度：时间 $O(\log(mn))$，空间 $O(1)$。

核对：矩阵 `[[1,3,5,7],[10,11,16,20],[23,30,34,60]]` 查 3 得 true、查 13 得 false，与两个示例一致。
