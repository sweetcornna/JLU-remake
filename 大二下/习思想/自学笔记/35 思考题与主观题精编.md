## 第十三章 维护和塑造国家安全

### 47. 如何认识新时代我国国家安全形势的新变化？

1. **外部环境**：世界战略格局、全球治理体系、综合国力竞争进入深度变迁的历史进程；气候变化、粮食安全、能源安全等全球性问题日趋尖锐复杂；地区热点和局部冲突此起彼伏。
2. **内部环境**：重点领域关键环节改革任务艰巨，科技创新存在卡点瓶颈，粮食、能源、资源、金融和产业链供应链安全面临重大考验，意识形态领域存在不少挑战。
3. **风险形态**：各类风险成因多样、彼此交织，关联度高、传导快、共振强，一定条件下容易演化升级。
4. 结论：距离实现中华民族伟大复兴的目标越近，越要准备经受风高浪急甚至惊涛骇浪的重大考验。

### 48. 如何理解总体国家安全观的丰富内涵？

分三块答：基本内涵、「总体」的含义、「十个坚持」。

基本内涵是五个「以」，顺序不能乱：

1. 以**人民安全**为宗旨。
2. 以**政治安全**为根本。
3. 以**经济安全**为基础。
4. 以**军事、科技、文化、社会安全**为保障。
5. 以**促进国际安全**为依托。

「总体」的关键是四个「强调」：强调「大安全」理念；强调系统思维和方法，统筹维护国家安全和塑造国家安全；强调维护国家安全要贯穿党和国家工作各方面全过程，把安全和发展置于同等重要地位；强调打总体战。

主要内容集中体现为**「十个坚持」**：坚持党对国家安全工作的绝对领导；坚持中国特色国家安全道路；坚持以人民安全为宗旨；坚持统筹发展和安全；坚持把政治安全放在首要位置；坚持统筹推进各领域安全；坚持把防范化解国家安全风险摆在突出位置；坚持推进国际共同安全；坚持推进国家安全体系和能力现代化；坚持加强国家安全干部队伍建设。

### 49. 为什么说统筹发展和安全是我们党治国理政的一个重大原则？

- 发展解决的是**动力**问题，是推动国家和民族赓续绵延的根本支撑；安全解决的是**保障**问题，是确保国家和民族行稳致远的坚强柱石。
- 发展具有基础性、根本性，是解决安全问题的**总钥匙**，发展就是最大的安全；安全是发展的条件和保障。两者是一体之两翼、驱动之双轮，必须同步推进。
- 要以**新安全格局保障新发展格局**，牢牢守住安全发展这条底线。

### 50. 为什么要把维护政治安全放在维护国家安全的首要位置？

1. 政治安全涉及国家**主权、政权、制度和意识形态**的稳固，是一个国家最根本的需求，是一切国家生存和发展的基础条件。
2. 政治安全决定和影响经济安全、军事安全、社会安全等各领域安全。没有政治安全的保障，其他领域的安全无从谈起。
3. 政治安全是人民安居乐业的根本保障，没有这块基石，人民的美好生活就如同空中楼阁。

## 第十五章 坚持「一国两制」和推进祖国统一

### 55. 如何准确把握「一国」和「两制」的关系？

- 「一国两制」方针是一个完整的体系。**维护国家主权、安全、发展利益是「一国两制」方针的最高原则**，在这个前提下港澳保持原有的资本主义制度长期不变，享有高度自治权。
- 「一国」是实行「两制」的**前提和基础**，「两制」从属和派生于「一国」，并统一于「一国」之内。「一国」原则愈坚固，「两制」优势就愈明显；「一国」底线越牢，「两制」空间就越大。
- 「一国」之内的「两制」**并非等量齐观、比肩并列**。国家的主体必须实行社会主义制度，社会主义制度是中华人民共和国的根本制度，中国共产党领导是中国特色社会主义最本质的特征，特别行政区所有居民应该自觉尊重和维护国家的根本制度。
- 配套记中央全面管治权与高度自治权的关系：中央对包括特别行政区在内的所有地方行政区域拥有全面管治权，全面管治权是授权高度自治的前提和基础，高度自治权是中央行使全面管治权的体现，两者是源与流、本与末的关系；高度自治并非完全自治，也不等于分权，而是中央授予的地方事务管理权。

### 56. 如何理解香港、澳门与祖国内地同发展、共繁荣的道路必将越走越宽广？

- 港澳的显著优势是**背靠祖国、联通世界**。香港是我国内地最大的外资来源地、对外投资最大目的地、对外贸易最大转口地；澳门是我国与葡语国家经贸往来的重要平台。
- 四个「积极主动」：积极主动推动国家全面开放；积极主动参与粤港澳大湾区建设；积极主动参与国家治理实践；积极主动促进国际人文交流。
- 建设粤港澳大湾区是党中央立足全局和长远作出的重大决策，也是保持港澳长期繁荣稳定的重大举措。

### 57. 为什么说祖国完全统一一定要实现，也一定能够实现？

1. 实现祖国完全统一是由中华民族伟大复兴的时和势决定的，是不可阻挡的**历史潮流**。今天我们比历史上任何时期都更接近、更有信心和能力实现这一目标。
2. 民族复兴、国家统一是大势所趋、大义所在、民心所向。中华文明具有突出的**统一性**，国家统一永远是中国核心利益的核心。台湾问题因民族弱乱而产生，必将随着民族复兴而解决。
3. 台湾前途在于国家统一，台湾同胞福祉系于民族复兴。两岸关系和平发展要两岸同胞共同推动、共同维护、共同分享。
4. 统一是历史大势，是正道；「台独」是历史逆流，是绝路。我们愿意为和平统一创造广阔空间，但绝不为各种形式的「台独」分裂活动留下任何空间。

## 第十六章 中国特色大国外交和推动构建人类命运共同体

### 58. 为什么说当今世界百年未有之大变局加速演进？

先说两面：一面是世界多极化、经济全球化、社会信息化、文化多样化深入发展，和平、发展、合作、共赢的历史潮流不可阻挡；另一面是不稳定性不确定性突出，全球性问题加剧。

三条具体表现：

1. **国际力量对比深刻变化**。一大批新兴市场国家和发展中国家走上发展快车道，多个发展中心在世界各地区逐渐形成。
2. **新一轮科技革命和产业变革深入发展**。
3. **国际体系和国际秩序深度调整**。二战后建立的国际秩序和全球治理体系不适应的地方越来越多，发展中国家在国际事务中的代表性和发言权不断扩大。

结论：世界之变、时代之变、历史之变正以前所未有的方式展开，世界进入新的动荡变革期。

### 59. 为什么我国要坚定奉行独立自主的和平外交政策？

- 坚持走和平发展道路，是党根据时代发展潮流和我国根本利益作出的**战略抉择**，是新时代中国外交的基本原则。
- 走和平发展道路既是对国际社会关注中国发展走向的回应，更是中国人民对实现自身发展目标的自信和自觉。
- 独立自主意味着中国始终根据事情本身的是非曲直决定自己的立场和政策，维护国际关系基本准则，维护国际公平正义。
- 和平发展是双向的：既要通过维护世界和平发展自己，又要通过自身发展维护世界和平。
- 中国走和平发展道路并非权宜之计，也非外交辞令，而是从历史、现实、未来的客观判断中得出的结论。

### 60. 如何理解构建人类命运共同体是世界各国人民前途所在？

总目标是建设**持久和平、普遍安全、共同繁荣、开放包容、清洁美丽**的世界。五条各配一套做法。

| 目标 | 做法 |
| --- | --- |
| 持久和平 | 对话协商，大国小国一律平等，构建对话不对抗、结伴不结盟的伙伴关系，形成新型国际关系 |
| 普遍安全 | 树立共同、综合、合作、可持续的安全观，统筹应对传统和非传统安全威胁 |
| 共同繁荣 | 推进开放、包容、普惠、平衡、共赢的经济全球化 |
| 开放包容 | 坚持交流互鉴，促进和而不同、兼收并蓄的文明交流，要对话不要对立，要交流不要取代 |
| 清洁美丽 | 倡导绿色、低碳、循环、可持续的生产生活方式，共建地球生命共同体 |

### 61. 如何理解全球发展倡议、全球安全倡议、全球文明倡议？

三大倡议各自的关键词要分清。

- **全球发展倡议**：六个坚持，即坚持发展优先、坚持以人民为中心、坚持普惠包容、坚持创新驱动、坚持人与自然和谐共生、坚持行动导向。落实方向是塑造有利发展环境、提振全球发展伙伴关系、维护全球产业链供应链稳定。
- **全球安全倡议**：坚持共同、综合、合作、可持续的安全观；尊重各国主权和领土完整、不干涉别国内政；遵守联合国宪章宗旨和原则；重视各国合理安全关切；通过对话协商以和平方式解决分歧和争端；统筹维护传统领域和非传统领域安全。
- **全球文明倡议**：四个倡导，即尊重世界文明多样性、弘扬全人类共同价值、重视文明传承和创新、加强国际人文交流合作。落实上以文明交流超越文明隔阂、文明互鉴超越文明冲突、文明包容超越文明优越。

### 62. 如何坚持真正的多边主义，完善全球治理体系？

- 多边主义最基本的道理：国际上的事情要由各国商量着办，要按大家同意的规矩办，要兼顾各国利益和关切。
- 四条内涵：坚持开放包容，不搞封闭排他；坚持以国际法则为基础，不搞唯我独尊；坚持协商合作，不搞冲突对抗；坚持与时俱进，不搞故步自封。
- 「真正的」三个字是关键：不能以多边主义之名行单边主义之实，不能搞有选择的多边主义。
- 要求：坚持以联合国宪章宗旨和原则为基础的国际关系基本准则，反对以意识形态划线，反对针对特定国家的阵营化和排他性小圈子，反对一切形式的单边主义、脱钩、断供。

## 第十七章 全面从严治党

### 63. 如何认识全面从严治党的重大意义？

- 一句话总纲：全面建设社会主义现代化国家、全面推进中华民族伟大复兴，**关键在党，关键在全面从严治党**。党的十八大以来，党中央把全面从严治党纳入「四个全面」战略布局。
- 加强党的自身建设是推进伟大事业、进行伟大斗争、实现伟大梦想的必然要求。
- 加强党的自身建设是把党锻造成坚强有力的马克思主义执政党的迫切需要。以自我革命精神解决党内存在的突出问题，落实党要管党、从严治党的任务比以往任何时候都更繁重更紧迫。

### 64. 为什么要把党的政治建设摆在首位？

- 党的政治建设是**党的根本性建设**。把政治建设纳入党的建设总体布局并摆在首位，是新时代党对马克思主义党建理论的重大创新。
- 旗帜鲜明讲政治是马克思主义政党的根本要求。任何政党都有政治属性、政治使命、政治目标、政治追求。
- **保证全党服从中央，维护党中央权威和集中统一领导，是党的政治建设的首要任务**。团结统一是党的生命。
- 发挥政治建设的统领性作用，要把准政治方向、站稳政治立场、营造良好政治生态、提高政治能力。

### 65. 如何理解一体推进不敢腐、不能腐、不想腐？

三者相互依存、相互促进，定位不能混。

| 内容 | 定位 | 抓手 |
| --- | --- | --- |
| 不敢腐 | 前提 | 严格执纪执法增强制度刚性，保持零容忍震慑，持续加压 |
| 不能腐 | 关键 | 科学配置权力，加强重点领域监督机制改革和制度建设，深化源头治理 |
| 不想腐 | 根本 | 加强理想信念教育、提高党性觉悟、涵养廉洁文化，正本清源、固本培元 |

一体推进要求三者同时发力、同向发力、综合发力，把不敢腐的震慑效能、不能腐的制度约束、不想腐的思想教育优势融于一体。

### 66. 如何理解以伟大自我革命引领伟大社会革命？

- 原话：要以伟大自我革命引领伟大社会革命，以伟大社会革命促进伟大自我革命，确保党始终成为坚强领导核心。
- 中国共产党的奋斗史就是一部伟大自我革命和伟大社会革命相互促进的历史。伟大社会革命锻造和成就伟大的党，伟大自我革命保障和推动伟大的事业。
- 以伟大自我革命引领伟大社会革命是新时代中国特色社会主义发展的显著特点。新时代坚持和发展中国特色社会主义是一场艰巨而伟大的社会革命，要求党以更清醒的自觉、更坚定的决心、更高的标准进行自我革命。
- 党的自我革命永远在路上，推进新时代党的建设新的伟大工程必须一以贯之进行下去。配合记「自我革命是跳出治乱兴衰历史周期率的第二个答案」，第一个答案是人民监督。
