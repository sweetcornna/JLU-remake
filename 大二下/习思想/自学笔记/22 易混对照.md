# 易混对照

把两份题集里反复设陷阱的地方集中起来。做题时丢分最多的地方，是把「根本」「关键」「核心」「首要」这类定语安错位置，或者把提法张冠李戴，内容本身倒大多背过。考前扫一遍这份表最划算。

## 一、提法的四个层次

| 提法组 | 定位 | 出处 |
| --- | --- | --- |
| 十个明确 | 主体内容，四梁八柱，发挥统摄作用 | 党的十九大、十九届六中全会 |
| 十四个坚持 | 基本方略，治国理政各方面的理论分析和政策指导 | 党的十九大 |
| 十三个方面成就 | 对新时代伟大实践的科学总结 | 党的十九届六中全会 |
| 六个必须坚持 | 世界观、方法论和贯穿其中的立场观点方法 | 党的二十大 |

这四组「内在贯通、有机统一，共同构成习近平新时代中国特色社会主义思想的科学体系」。选择题里问「主体内容」选十个明确，问「世界观方法论」选六个必须坚持，问「基本方略」选十四个坚持。

## 二、提出、确立、写入党章、载入宪法

| 动作 | 主体 | 时间 |
| --- | --- | --- |
| 明确习近平同志党中央的核心、全党的核心地位 | 党的十八届六中全会 | 2016 年 10 月 |
| 把习近平新时代中国特色社会主义思想写入党章、确立为党必须长期坚持的指导思想 | 党的十九大 | 2017 年 10 月 |
| 把习近平新时代中国特色社会主义思想载入宪法 | 十三届全国人大一次会议 | 2018 年 3 月 |
| 指出党确立了「两个确立」 | 党的十九届六中全会 | 2021 年 11 月 |

记忆口诀：先有全会明确核心，再有党代会写入党章，然后全国人大修宪载入宪法，最后全会把「两个确立」讲清楚。党章是党代会改，宪法是全国人大改，主体不能混。

## 三、总任务、总目标、总体布局、战略布局、中心任务

| 名称 | 内容 |
| --- | --- |
| 总任务 | 实现社会主义现代化和中华民族伟大复兴 |
| 全面深化改革总目标 | 完善和发展中国特色社会主义制度，推进国家治理体系和治理能力现代化 |
| 全面依法治国总目标 | 建设中国特色社会主义法治体系，建设社会主义法治国家 |
| 总体布局 | 五位一体 |
| 战略布局 | 四个全面 |
| 新时代新征程党的中心任务 | 团结带领全国各族人民全面建成社会主义现代化强国、实现第二个百年奋斗目标，以中国式现代化全面推进中华民族伟大复兴 |

题干里出现「战略抉择」，配的是「四个全面」战略布局；出现「总体布局」，配的是「五位一体」。两个「总目标」分属改革和法治，别对调。

## 四、根本制度、基本制度、重要制度

| 层次 | 例子 |
| --- | --- |
| 根本领导制度 | 党的领导制度（党的十九届四中全会明确） |
| 根本政治制度 | 人民代表大会制度 |
| 根本制度（意识形态领域） | 坚持马克思主义在意识形态领域指导地位的制度 |
| 基本政治制度 | 中国共产党领导的多党合作和政治协商制度、民族区域自治制度、基层群众自治制度 |
| 基本经济制度 | 公有制为主体多种所有制共同发展、按劳分配为主体多种分配方式并存、社会主义市场经济体制 |
| 重要制度 | 在根本制度和基本制度基础上形成的一系列制度 |

马克思主义在意识形态领域指导地位的制度是**根本制度**，选项里常放「基本制度」「重要制度」「基本政策」来混淆。

## 五、各种「第一」「最」「根本」

| 说法 | 对应内容 |
| --- | --- |
| 第一生产力 | 科技 |
| 第一资源 | 人才 |
| 第一动力 | 创新 |
| 马克思主义政党第一位的能力 | 政治领导力 |
| 关系党的事业兴衰成败第一位的问题 | 道路问题 |
| 党的政治建设的首要任务 | 保证全党服从中央，维护党中央权威和集中统一领导 |
| 党的领导的最高原则 | 党中央集中统一领导 |
| 「一国两制」方针的最高原则 | 维护国家主权、安全、发展利益 |
| 中国特色社会主义最本质的特征 | 中国共产党领导 |
| 中国特色社会主义制度的最大优势 | 中国共产党领导 |
| 根本价值立场 | 坚持人民至上 |
| 我们党的生命线和根本工作路线 | 群众路线 |
| 维护社会公平正义的最后一道防线 | 公正司法 |
| 解决安全问题的总钥匙 | 发展 |
| 国家安全的根本 | 政治安全 |
| 国家安全的宗旨 | 人民安全 |
| 建军之本、强军之魂 | 党对人民军队的绝对领导 |
| 人民军队的立军之本 | 政治建军 |

「政治安全是根本、人民安全是宗旨」这一对最容易写反，记住总体国家安全观的五个「以」的顺序是宗旨、根本、基础、保障、依托。

## 六、必由之路、关键一招、重要法宝

- **五个必由之路**：坚持党的全面领导（坚持和发展中国特色社会主义的必由之路）、中国特色社会主义（实现中华民族伟大复兴的必由之路）、团结奋斗（中国人民创造历史伟业的必由之路）、贯彻新发展理念（新时代我国发展壮大的必由之路）、全面从严治党（党永葆生机活力、走好新的赶考之路的必由之路）。
- 第五章另有一句：**改革开放**是坚持和发展中国特色社会主义的必由之路，同时是决定当代中国命运的**关键一招**、党和人民大踏步赶上时代的**重要法宝**。这句话和「五个必由之路」里的第一条句式一样，主语不同，看清楚题干问的是哪一组。
- 「自主创新是我们攀登世界科技高峰的必由之路」属于第七章，别和上面两组混。
- 判断题陷阱：「政治建设是党永葆生机活力、走好新的赶考之路的必由之路」是**错**的，主语应该是全面从严治党。

## 七、三组「谁是基础、谁是关键、谁是目标」

| 组别 | 基础 / 前提 | 关键 | 目标 / 根本 |
| --- | --- | --- | --- |
| 共建共治共享 | 共建是基础 | 共治是关键 | 共享是目标 |
| 不敢腐、不能腐、不想腐 | 不敢腐是前提 | 不能腐是关键 | 不想腐是根本 |
| 教育、科技、人才 | 教育是关键基础 | 科技是关键力量 | 人才是关键支撑 |

强军目标三条是另一种搭配：听党指挥是灵魂，能打胜仗是核心，作风优良是保证。

## 八、民主相关的几组「最」

- 全过程人民民主是**最广泛、最真实、最管用**的民主。选项里出现「最典型」是错的。
- 全过程人民民主是**全链条、全方位、全覆盖**的民主。选项里出现「全方面」是错的，正确的是全链条、全方位、全覆盖。
- 人民代表大会制度是坚持党的领导、人民当家作主、依法治国有机统一的**根本政治制度**。
- 协商民主是中国社会主义民主政治中**独特的、独有的、独到的**民主形式。

## 九、「一国」和「两制」

- 「一国」是实行「两制」的**前提和基础**，「两制」从属和派生于「一国」，并统一于「一国」之内。
- 中央对包括特别行政区在内的所有地方行政区域拥有**全面管治权**；全面管治权是授权高度自治的前提和基础，高度自治权是中央行使全面管治权的体现，两者是源与流、本与末的关系。
- 高度自治并非完全自治，也不等于分权，而是中央授予的地方事务管理权。
- 「一国」之内的「两制」并非等量齐观、比肩并列，国家的主体必须实行社会主义制度。

| 提法 | 说的是什么 |
| --- | --- |
| 生态兴则文明兴，生态衰则文明衰 | 生态与文明兴衰的关系 |
| 绿水青山就是金山银山 | 生态与经济发展的关系 |

判断题陷阱：「实现『双碳』目标是别人让我们这样做」是**错**的，教材的说法是我们自己必须要做。

## 十一、新发展理念对应的问题

创新对应发展动力，协调对应发展不平衡，绿色对应人与自然和谐共生，开放对应发展内外联动，共享对应社会公平正义。多选题常把某一条的定语换掉，比如把「绿色注重解决社会公平正义问题」放进选项。

## 十二、法治体系五个子体系的形容词

完备的法律规范体系、高效的法治实施体系、严密的法治监督体系、有力的法治保障体系、完善的党内法规体系。这五个形容词和五个体系是固定搭配，题目里常互换。

## 十三、几处判断题里的常见错法

- 「党的领导是全面的，所以党组织包揽包办一切事情」是错的。党的领导是全面的、系统的、整体的，但不等于包揽包办。
- 「民主并非国家制度，而是默认的准则」是错的。马克思主义认为民主首先而且主要是一种国家制度。
- 「世界上存在高人一等的『自由民主』和唯我独尊的『普世价值』」是错的。
- 「从世界历史看，法治是国家强盛的唯一途径」这类绝对化表述通常是错的。
- 「我们已战胜所有风险挑战」这类绝对化表述也是错的。
