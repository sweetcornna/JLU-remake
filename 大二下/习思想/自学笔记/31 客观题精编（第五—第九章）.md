## 第五章 全面深化改革开放

### 单选题

1. （ ）是决定当代中国命运的关键一招，也是决定实现“两个一百年”奋斗目标、实现中华民族伟大复兴的关键一招。
   A 中国式现代化　B 中国特色社会主义　C 改革开放　D 小康社会
   答案：C。故选C。

2. （ ）是坚持和发展中国特色社会主义的必由之路。
   A 改革开放　B 中国共产党领导　C 坚持以人民为中心　D 社会主义道路
   答案：A。改革开放是坚持和发展中国特色社会主义的必由之路。

3. （ ）是完成新时代目标任务的必然要求。
   A 全面建设社会主义现代化国家　B 全面深化改革开放　C 全面依法治国　D 全面从严治党
   答案：B。全面深化改革开放是完成新时代目标任务的必然要求。

4. 2013年11月，（ ）通过《中共中央关于全面深化改革若干重大问题的决定》，对全面深化改革进行总体擘画，确定了全面深化改革的总目标……
   A 党的十八届三中全会　B 党的十八届五中全会　C 党的十九届三中全会　D 党的十九届六中全会
   答案：A。选项A十八届三中全会正确。

5. 坚持和完善社会主义基本经济制度，充分发挥（ ）在资源配置中的决定性作用。
   A 市场　B 社会　C 政府　D 组织
   答案：A。坚持和完善社会主义基本经济制度，充分发挥市场在资源配置中的决定性作用。

6. （ ），是开启改革开放事业的思想前提，也是新时代全面深化改革开放的思想前提。
   A 解放思想　B 实事求是　C 与时俱进　D 开拓创新
   答案：A。解放思想，是开启改革开放事业的思想前提，也是新时代全面深化改革开放的思想前提。

7. （ ），是改革开放的鲜明特征和首要任务。
   A 解放思想　B 人民生活水平提高　C 解放和发展社会生产力　D 共同富裕
   答案：C。解放和发展社会生产力是改革开放的鲜明特征和首要任务。

8. （ ），是一个国家现代化的重要标志。
   A 国家治理体系和治理能力现代化　B 实现全体人民共同富裕　C 社会主义大繁荣大发展　D 进入世界发达国家行列
   答案：A。国家治理体系和治理能力现代化，是一个国家现代化的重要标志。故选A。

9. 推进国家治理体系和治理能力现代化，必须坚定中国特色社会主义（ ）。
   A 道路自信　B 理论自信　C 制度自信　D 文化自信
   答案：C。推进国家治理体系和治理能力现代化，必须坚定中国特色社会主义制度自信。故选C。

10. （ ）是党和人民在长期实践探索中形成的，具有多方面的显著优势。
    A 科学社会主义　B 中国式现代化　C 中国特色社会主义道路　D 中国特色社会主义制度
    答案：D。党的十九届四中全会提出，“中国特色社会主义制度是党和人民在长期实践探索中形成的科学制度体系”，强调“我国国家制度和国家治理体系具有多方面的显著优势”。总的来看，中国特色社会主义制度是当代中国发展进步的根本制度保障，是具有明显制度优势、强大自我完善能力的先进制度。

11. （ ），是富有中国特色、符合中国国情的改革方法。
    A 顶层设计　B 摸着石头过河　C “猫论”　D 全面深化改革开放
    答案：B。“摸着石头过河”是邓小平领导改革开放的态度和方法。2012年12月，习近平总书记在十八届中央政治局集体学习时指出：“摸着石头过河，是富有中国特色、符合中国国情的改革方法。摸着石头过河就是摸规律。”他说：今天我们还“要采取试点探索、投石问路的方法，取得了经验，达成了共识，看得很准了，感觉到推开很稳当了，再推开，积小胜为大胜”。故选B。

12. （ ），是新时代坚持和发展中国特色社会主义的根本动力。
    A 全面深化改革开放　B 共同富裕　C 中华民族伟大复兴　D 社会主义现代化强国
    答案：A。全面深化改革开放，是新时代坚持和发展中国特色社会主义的根本动力。故选A。

13. 历史唯物主义认为，（ ）是推动人类社会发展最活跃最具有革命性的因素。

15. 社会主义事业是一项全新事业，没有现成的方案和固定的模式，只有坚持（ ）基本原则，结合新的实际大胆探索创新，才能把社会主义事业推向前进。

### 多选题

1. 只有社会主义才能救中国，只有改革开放才能（ ）。
   A 发展中国　B 发展世界　C 发展社会主义　D 发展马克思主义
   答案：ACD。选项ACD正确。

2. 全面深化改革开放是一场（ ）。
   A 思想理论的深刻变革　B 改革组织方式的深刻变革　C 国家制度和治理体系的深刻变革　D 人民广泛参与的深刻变革
   答案：ABCD

3. 全面深化改革开放是在多年改革开放基础上的深化，是一场（ ）的制度创新。
   A 全面　B 系统　C 整体　D 多元
   答案：ABC。全面深化改革开放是一场全面、系统、整体的制度创新。故选ABC。

4. 新时代的改革开放是全方位、深层次、根本性的，取得的成就是（ ）的。
   A 历史性　B 现实性　C 革命性　D 开创性
   答案：ACD。新时代的改革开放取得的成就是历史性、革命性、开创性的。故选ACD。

5. 社会主义改革开放的出发点和落脚点，是（ ）。
   A 为了更好实现和维护人民利益　B 为了让老百姓过上好日子　C 为了巩固中国共产党的执政之基　D 为了实现中华民族伟大复兴
   答案：AB。社会主义改革开放的出发点和落脚点，是为了更好实现和维护人民利益、为了让老百姓过上好日子。

6. 要把（ ）作为根本标准，审视我们的各项改革开放措施，哪里不符合人民需要，哪里就需要调整……
   A 社会发不发展　B 人民满意不满意　C 高兴不高兴　D 现代化能否实现
   答案：BC。要把人民满意不满意、高兴不高兴作为根本标准，审视我们的各项改革开放措施。

7. 必须（ ）既是改革的目的，又是改革的条件。
   A 有利于人民生活水平提高　B 有利于进一步解放思想　C 进一步解放和发展社会生产力　D 进一步解放和增强社会活力
   答案：BCD。注意“进一步解放思想”前面有个“有利于”。邓小平在南方谈话期间提出“三个有利于”，即是否有利于发展社会主义社会的生产力，是否有利于增强社会主义国家的综合国力，是否有利于提高人民的生活水平，是判断改革和一切工作是非得失的标准。这里注意与习思想“三个进一步解放”的异同点。

8. 全面深化改革总目标是：（ ）。
   A 完善和发展中国特色社会主义制度　B 推进国家治理体系和治理能力现代化　C 以中国式现代化推进中华民族伟大复兴　D 实现共同富裕
   答案：AB。全面深化改革总目标是：完善和发展中国特色社会主义制度、推进国家治理体系和治理能力现代化。

9. （ ）是我国社会主义现代化建设的三个重要支点。
   A 改革　B 发展　C 稳定　D 共赢
   答案：ABC。改革、发展、稳定是我国社会主义现代化建设的三个重要支点。

10. 当前改革又到了一个新的历史关头，要（ ）。
    A 立足新发展阶段　B 贯彻新发展理念　C 构建新发展格局　D 推动高质量发展
    答案：ABCD。当前改革又到了一个新的历史关头，要立足新发展阶段、贯彻新发展理念、构建新发展格局、推动高质量发展。四个选项均正确。
