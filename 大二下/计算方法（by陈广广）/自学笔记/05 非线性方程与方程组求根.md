## 一、预报校正开方算法

用来求 $\sqrt{a}$，也就是解方程 $x^2-a=0$。这一段是整章的引子，牛顿法其实就是它的一般化。

### 1.1 推导顺序

设已有近似值 $x_0$，要找校正量 $\Delta x$，使 $x_0+\Delta x$ 更接近 $\sqrt a$。

1. 希望 $(x_0+\Delta x)^2\approx a$，展开得 $x_0^2+2x_0\Delta x+\Delta x^2\approx a$。
   笔记在这一行旁边批注：**就是说 $\Delta x$ 太小了**，所以下一步才敢丢掉二阶项。
2. $\Delta x$ 很小，略去二阶项 $\Delta x^2$，得 $x_0^2+2x_0\Delta x\approx a$。
3. 解出校正量：

$$\Delta x=\frac{1}{2}\Bigl(\frac{a}{x_0}-x_0\Bigr)$$

4. 校正值：

$$x_1=x_0+\Delta x=\frac{1}{2}\Bigl(\frac{a}{x_0}+x_0\Bigr)$$

### 1.2 预报校正公式

$$\boxed{\ x_{k+1}=\frac{1}{2}\Bigl(x_k+\frac{a}{x_k}\Bigr)\ }$$

给定初值 $x_0>0$，反复迭代即得 $\sqrt a$。

初值要求 $x_0>0$ 这一条别漏。取负初值收敛到 $-\sqrt a$，取 $x_0=0$ 直接除零。

### 1.3 演算例（整理补充，$a=2$，$x_0=1$）

| $k$ | $x_k$ |
| --- | --- |
| 0 | $1$ |
| 1 | $1.5$ |
| 2 | $1.416666666666667$ |
| 3 | $1.414215686274510$ |
| 4 | $1.414213562374690$ |
| 5 | $1.414213562373095$ |

$\sqrt2=1.414213562373095$。四步就到 10 位准确，正确数字位数大致每步翻倍，这正是平方收敛的样子。

## 二、非线性方程与根

### 2.1 根（零点）

有 $x^*$ 使 $f(x^*)=0$，则称 $x^*$ 是方程 $f(x)=0$ 的**根**，也叫 $f(x)$ 的**零点**。

### 2.2 $m$ 重根

笔记写的条件是：存在正整数 $m$ 和函数 $g$，满足

$$0<g(x^*)<+\infty$$

则 $x^*$ 是 $m$ 重根。

笔记这里省掉了分解式本身，完整写法是 $f(x)=(x-x^*)^m g(x)$，配上 $g(x^*)\neq0$（有限且非零）。$m=1$ 时叫单根。

### 2.3 主要求解方法

**迭代法**。整章后面的二分法、不动点迭代、牛顿法、割线法都是迭代法的具体形式。

## 三、二分法

### 3.1 基本思想

把有根区间 $[a,b]$ 逐步对分，通过检验对分点处函数值 $f(x)$ 的符号，决定如何把原有根区间 $[a,b]$ 丢掉一半，让剩下的区间仍然是 $f(x)=0$ 的有根区间。

### 3.2 算法 3.1

```
输入: a, b, f(x);  输出: x
While (b-a) >= ε do
    x := a + (b-a)/2
    If sign(f(x)) = sign(f(a)) Then
        a := x          # 找符号相同的赋值
    else
        b := x
    End
End
x := a + (b-a)/2
```

笔记在 `If sign(f(x))=sign(f(a))` 旁边批注：**找符号相同的赋值**。意思是中点与左端点同号，说明根在右半边，于是把左端点挪到中点。这一步方向容易写反，记住「同号的那一端被替换掉」。

### 3.3 手算步骤

1. 先确认 $f(a)f(b)<0$，即 $[a,b]$ 确实是有根区间。
2. 算中点 $x=a+\dfrac{b-a}{2}$，算 $f(x)$。
3. 比较 $\operatorname{sign} f(x)$ 与 $\operatorname{sign} f(a)$：同号则 $a:=x$，异号则 $b:=x$。
4. 重复到区间长度小于精度要求，取最后的中点作为近似根。

### 3.4 误差与迭代次数

| 量 | 公式 |
| --- | --- |
| 迭代 $k$ 次后的区间长度 | $\dfrac{b-a}{2^k}$ |
| 取中点作近似解时的误差 | 小于 $\dfrac{b-a}{2^{k+1}}$ |
| 达到事先给定允许误差 $\varepsilon$ 所需次数 | 只需 $k$ 满足 $\dfrac{b-a}{2^{k+1}}<\varepsilon$ |

次数估计不用解对数方程，直接凑 2 的幂更快：把 $\dfrac{b-a}{\varepsilon}$ 算出来，找到比它大的最小的 $2^{k+1}$。

### 3.5 易错点

笔记用红笔标了一条：

> 二分法**只能求单根或奇数重实根**，不能求偶数重根以及虚根。

道理在于偶数重根两侧 $f$ 同号，$f(a)f(b)<0$ 这个入口条件根本进不去。

### 3.6 演算例（整理补充）

**次数估计**：$[a,b]=[1,2]$，要求误差 $<10^{-3}$。

$\dfrac{1}{2^{k+1}}<10^{-3}\Rightarrow 2^{k+1}>1000\Rightarrow k+1\ge10\Rightarrow k\ge9$。

取 $k=9$，此时误差上界 $\dfrac{1}{2^{10}}=0.0009765625<10^{-3}$，$k=8$ 时是 $0.001953125$，不够。

**对分过程**：$f(x)=x^3-x-1$ 在 $[1,2]$ 上，$f(1)=-1<0$，$f(2)=5>0$。

| 步 | 当前区间 | 中点 | $f(\text{中点})$ | 与 $f(a)$ 同号？ | 新区间 |
| --- | --- | --- | --- | --- | --- |
| 1 | $[1,2]$ | $1.5$ | $0.875$ | 否 | $[1,1.5]$ |
| 2 | $[1,1.5]$ | $1.25$ | $-0.296875$ | 是 | $[1.25,1.5]$ |
| 3 | $[1.25,1.5]$ | $1.375$ | $0.224609375$ | 否 | $[1.25,1.375]$ |
| 4 | $[1.25,1.375]$ | $1.3125$ | $-0.051513671875$ | 是 | $[1.3125,1.375]$ |
| 5 | $[1.3125,1.375]$ | $1.34375$ | $0.082611083984375$ | 否 | $[1.3125,1.34375]$ |

真根 $x^*=1.32471795724$。五步之后区间长 $0.03125$，收敛慢得很，这就是二分法的老毛病。

## 四、不动点迭代法

一句话概括笔记的开头：逐步逼近，反复校正，逐步精确化。

### 4.1 迭代格式怎么来的

$$f(x)=0\iff x=\varphi(x)\ \Longrightarrow\ x_{k+1}=\varphi(x_k)$$

把方程改写成 $x=\varphi(x)$ 的形式，就能**构造迭代序列**。$\varphi(x)$ 叫迭代函数，$x_{k+1}=\varphi(x_k)$ 叫迭代格式（迭代过程），$k$ 是迭代次数。

### 4.2 不动点

凡满足方程 $x=\varphi(x)$ 的点叫该方程的**不动点**。

取初始迭代值 $x_0$，记 $x_1=\varphi(x_0)$，$x_2=\varphi(x_1)$，$\dots$，得迭代数列 $\{x_k\}$。当 $k$ 充分大时，如果 $\{x_k\}$ 有极限 $x^*$ 存在，即

$$\lim_{k\to\infty}x_k=x^*$$

则在迭代式两边同时取极限：

$$x^*=\lim_{k\to\infty}x_{k+1}=\lim_{k\to\infty}\varphi(x_k)=\varphi(x^*)$$

这表明 $x^*$ 为等价方程 $x=\varphi(x)$ 的不动点，即 $x^*$ 为方程 $f(x)=0$ 的根。

笔记在极限那一行旁批注：极限**成立就是收敛的，不成立就是发散的**。

### 4.3 用迭代法求根的两个基本问题

1. 化等价方程，构造迭代函数；
2. 研究迭代数列 $\{x_k\}$ 的收敛性、收敛速度及误差估计。

考试的大题基本就照这两问出：先让你把方程改写成几种 $\varphi$，再让你判哪个收敛、收敛多快。

### 4.4 几何解释（图 3.4 的四种情形）

画法是两条线：$y=\varphi(x)$ 和 $y=x$。从 $x_k$ 竖直打到曲线得 $y_{k+1}=\varphi(x_k)$，再水平打到直线 $y=x$ 上，得到 $y_{k+1}=x_{k+1}$，如此折线前进。

| 图 | 条件 | 折线形状 | 结果 |
| --- | --- | --- | --- |
| (a) | $\varphi'(x^*)>1$ | 单向台阶，越走越远 | 迅速发散 |
| (b) | $\varphi'(x^*)<-1$ | 向外螺旋 | 迅速发散 |
| (c) | $0<\varphi'(x^*)<1$ | 单向台阶，越走越近 | 迅速收敛 |
| (d) | $-1<\varphi'(x^*)<0$ | 向内螺旋 | 迅速收敛 |

归纳成两句（笔记原话）：

- 图 a、图 b，根 $x^*$ 附近 $\lvert\varphi'(x)\rvert>1$，迭代序列 $\{x_k\}$ 迅速发散。
- 图 c、图 d，根 $x^*$ 附近 $\lvert\varphi'(x)\rvert<1$，迭代序列 $\{x_k\}$ 迅速收敛。

笔记用红笔标的结论：

> 对于等价方程 $x=\varphi(x)$，**应选择 $\lvert\varphi'(x)\rvert<1$ 的 $\varphi(x)$**。

导数为正是台阶形单调逼近，导数为负是螺旋形交错逼近，选择题爱考这个区别。

### 4.5 收敛性定理

假定方程 $x=\varphi(x)$ 满足：

1. $\varphi(x)$ 在 $[a,b]$ 上连续；
2. 当 $x\in[a,b]$ 时，$\varphi(x)\in[a,b]$（有界，也就是映回自身）；
3. $\varphi'(x)$ 存在，且对任取 $x\in[a,b]$ 有 $\lvert\varphi'(x)\rvert\le L<1$。

则方程 $x=\varphi(x)$ 在 $[a,b]$ 上存在唯一不动点 $x^*$；且对任取 $x_0\in[a,b]$，由迭代格式 $x_{k+1}=\varphi(x_k)$，$k=0,1,2,\dots$ 所定义的 $\{x_k\}$ 收敛于唯一不动点 $x^*$，即 $\lim\limits_{k\to\infty}x_k=x^*$。

笔记在旁边的三条批注：

- $[a,b]$ 可取任意有限大小的区间，所以**此定理为大范围收敛定理**。
- $L$ 越小，收敛越快。
- 条件 3 可放宽：若对于 $[a,b]$ 上任意两点 $x_1,x_2$，有 $\lvert\varphi(x_1)-\varphi(x_2)\rvert\le L\lvert x_1-x_2\rvert$ 且 $L<1$，则定理仍然成立（不要求导数存在，只要 Lipschitz 条件）。

验证顺序固定：先验 $\varphi$ 连续，再验区间自映射，最后估 $\lvert\varphi'\rvert$ 的上界 $L$。第二条最容易漏，很多人只算导数就下结论。

### 4.6 两个误差估计

同时成立的两个式子，用途不同，别记混：

$$\lvert x^*-x_k\rvert\le\frac{1}{1-L}\lvert x_{k+1}-x_k\rvert$$

> 可作为上机控制迭代中止的条件。右边只用到相邻两次迭代值，程序里随算随判。

$$\lvert x^*-x_k\rvert\le\frac{L^k}{1-L}\lvert x_1-x_0\rvert$$

> 可用于估计满足指定误差精度所需的最少迭代次数 $k$。右边只用到第一步的迭代量，还没开始算就能预估次数。

记忆口诀：**第一式事后判停，第二式事前估次数**。

### 4.7 演算例（整理补充）

**两种等价变形的对比**。仍取 $f(x)=x^3-x-1=0$，根 $x^*=1.3247179572$，初值 $x_0=1.5$。

写法一：$x=\varphi_1(x)=\sqrt[3]{x+1}$，$\varphi_1'(x^*)=0.18995$，绝对值小于 1，应当收敛。

| $k$ | $x_k$ |
| --- | --- |
| 0 | $1.5$ |
| 1 | $1.357208808$ |
| 2 | $1.330860959$ |
| 3 | $1.325883774$ |
| 4 | $1.324939363$ |
| 5 | $1.324760011$ |

写法二：$x=\varphi_2(x)=x^3-1$，$\varphi_2'(x^*)=3(x^*)^2=5.2646>1$，应当发散。

| $k$ | $x_k$ |
| --- | --- |
| 0 | $1.5$ |
| 1 | $2.375$ |
| 2 | $12.396484$ |
| 3 | $1904.0028$ |
| 4 | $6.902\times10^{9}$ |

同一个方程，改写方式不同，一个收敛一个炸掉，这就是「应选 $\lvert\varphi'\rvert<1$」的直观后果。另外看写法一：误差每步大约缩小到原来的 $0.19$ 倍，是固定比例缩小，线性收敛的典型特征。

**用第二个误差估计式算次数**。设 $L=0.25$，$\lvert x_1-x_0\rvert=0.1$，要求误差 $\le10^{-6}$：

$$\frac{0.25^k}{1-0.25}\times0.1\le10^{-6}$$

$k=8$ 时左边为 $2.03\times10^{-6}$，不够；$k=9$ 时为 $5.09\times10^{-7}$，满足。所以最少迭代 9 次。

## 五、稳定性与收敛阶

### 5.1 稳定性

**收敛的迭代法总是稳定的**。

### 5.2 收敛阶

设迭代格式 $x_{k+1}=\varphi(x_k)$ 收敛于方程 $x=\varphi(x)$ 的不动点 $x^*$，如果迭代误差 $e_k=x_k-x^*$ 满足渐近关系

$$\frac{\lvert e_{k+1}\rvert}{\lvert e_k\rvert^p}=\frac{\lvert x_{k+1}-x^*\rvert}{\lvert x_k-x^*\rvert^p}\longrightarrow C\neq0,\qquad k\to+\infty,\ p>0$$

则称此迭代格式是 **$p$ 阶收敛的**。

| $p$ | 叫法 |
| --- | --- |
| $p=1$ | 线性收敛 |
| $p>1$ | 超线性收敛 |
| $p=2$ | 平方收敛，或二次收敛 |

笔记红笔批注：**不动点迭代法就是线性收敛的**。（牛顿法是平方收敛，割线法介于两者之间，属于超线性。）

### 5.3 $p$ 与 $C$ 的对照

| 情形 | 结论 |
| --- | --- |
| $p$ 越高 | 收敛速度越快 |
| $p=1$ | $C<1$ 才收敛 |
| $p>1$ | $C$ 任意都收敛 |
| $p<1$ | 都不收敛（更正：原文作 $p<0$；收敛阶定义里已经要求 $p>0$，这一行写成 $p<0$ 不落在定义域内，按上下文应是 $p<1$） |

两句总结：**$p$ 越大收敛越快；$p$ 相同时，$C$ 越小收敛越快**。

## 六、牛顿迭代法

笔记开头点出它和不动点迭代的区别：不动点迭代法是直接从 $f(x)$ 化出迭代格式 $\varphi(x)$，而牛顿迭代法是用泰勒展开。

### 6.1 基本思想

非线性函数 $f(x)$ 线性化。

假设 $f(x)=0$ 有近似根 $x_k$，且 $f'(x_k)\neq0$。

1. 在 $x_k$ 处泰勒展开：

$$f(x)=f(x_k)+f'(x_k)(x-x_k)+\frac{f''(x_k)}{2!}(x-x_k)^2+\cdots+\frac{f^{(n)}(x_k)}{n!}(x-x_k)^n+\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_k)^{n+1}$$

2. 只留线性部分作近似表示：

$$f(x_k)+f'(x_k)(x-x_k)=0$$

3. 解出根：

$$x=x_k-\frac{f(x_k)}{f'(x_k)}$$

### 6.2 迭代公式

$$\boxed{\ x_{k+1}=x_k-\frac{f(x_k)}{f'(x_k)},\qquad k=0,1,\dots\ }$$

这就是**牛顿迭代法**，又叫**切线法**。

手算步骤：给 $x_0$ → 算 $f(x_k)$ → 算 $f'(x_k)$ → 代公式得 $x_{k+1}$ → 判 $\lvert x_{k+1}-x_k\rvert$ 是否够小。分母是导数值，每步都要重算，别拿 $f'(x_0)$ 一路用到底。

### 6.3 几何解释

每次过 $x_k$ 的点 $P(x_k,f(x_k))$ 引切线，切线交 $x$ 轴于 $x_{k+1}$。所以叫切线法。

图上是 $P_k\to P_{k+1}\to P_{k+2}$ 一串切线，横坐标 $x_k>x_{k+1}>x_{k+2}>\cdots\to x^*$。

### 6.4 收敛性与收敛阶

对于 $f(x)=0$，若 $f'(x)\neq0$，则迭代函数写成

$$x=\varphi(x)=x-\frac{f(x)}{f'(x)}$$

**定理 3.2**：设函数 $f(x)$ 在根 $x^*$ 附近有二阶连续导数，且 $f'(x^*)\neq0$，则存在 $x^*$ 的邻域

$$D=\{x\mid\lvert x-x^*\rvert\le\delta\}$$

使对任意 $x_0\in D$，由迭代公式所定义的序列 $\{x_k\}$ 收敛到方程 $f(x)=0$ 的根 $x^*$，且有

$$\lim_{k\to\infty}\frac{x^*-x_{k+1}}{(x^*-x_k)^2}=-\frac{f''(x^*)}{2f'(x^*)}$$

即 Newton 迭代法是**平方收敛**的。

笔记圈出的两个前提：二阶连续导存在、一阶导不为 0。另外红笔标了「一阶导不为 0」对应的是单根，重根时牛顿法降为线性收敛。

笔记的 PS：**$\delta$ 能找到，但可能很小，对初值敏感**。定理只保证局部收敛，初值离根远了照样发散，所以才有下一节的初值条件。

### 6.5 初值的选择

假定方程 $f(x)=0$ 在 $[a,b]$ 区间上有二阶连续导数（原文写作「有二阶连续函数」），且满足：

1. $f(a)f(b)<0$，即两端**符号相反**；
2. $f'(x)\neq0$，$x\in[a,b]$，即**一阶导不为 0**；
3. $f''(x)$ 在 $[a,b]$ 上**不变号**，即二阶导不变号。

那么对于任意 $x_0\in[a,b]$，只要满足

$$\boxed{\ f(x_0)f''(x_0)>0\ }$$

则以 $x_0$ 为初始值所产生的牛顿迭代序列 $\{x_k\}$ 必定收敛到 $f(x^*)=0$ 的唯一实根 $x^*$。

实操：三条前提确认后，端点 $a$、$b$ 各代一次 $f\cdot f''$，谁为正就从谁出发。这一步是送分题，别去凑中点。

### 6.6 演算例（整理补充）

$f(x)=x^3-x-1$，$f'(x)=3x^2-1$，$f''(x)=6x$，取 $x_0=1.5$。

第一步手算：$f(1.5)=\dfrac{7}{8}$，$f'(1.5)=\dfrac{23}{4}$，

$$x_1=1.5-\frac{7/8}{23/4}=\frac{31}{23}=1.34782608696$$

| $k$ | $x_k$ | 误差 $\lvert x_k-x^*\rvert$ |
| --- | --- | --- |
| 0 | $1.5$ | $1.753\times10^{-1}$ |
| 1 | $1.3478260869565$ | $2.311\times10^{-2}$ |
| 2 | $1.3252003989509$ | $4.824\times10^{-4}$ |
| 3 | $1.3247181739991$ | $2.168\times10^{-7}$ |
| 4 | $1.3247179572448$ | $4.378\times10^{-14}$ |

误差比 $\dfrac{e_{k+1}}{e_k^2}$ 依次为 $0.903$、$0.931$、$0.9319$，而 $\left\lvert-\dfrac{f''(x^*)}{2f'(x^*)}\right\rvert=0.93189$，定理 3.2 的极限关系对上了。

另外验证初值条件：$[a,b]=[1,2]$，$f(1)f(2)=-5<0$；$f'(x)=3x^2-1$ 在 $[1,2]$ 上恒正；$f''(x)=6x>0$ 不变号。端点里 $f(2)f''(2)=5\times12>0$，所以 $x_0=2$ 是安全初值。$x_0=1.5$ 也满足 $f(1.5)f''(1.5)>0$。

## 七、割线法（弦截法）

### 7.1 公式

**差商替代微商**。把牛顿公式里的 $f'(x_k)$ 换成差商 $\dfrac{f(x_k)-f(x_{k-1})}{x_k-x_{k-1}}$：

$$\boxed{\ x_{k+1}=x_k-\frac{x_k-x_{k-1}}{f(x_k)-f(x_{k-1})}f(x_k),\qquad k=1,2,\dots\ }$$

笔记标的关键点：**需要给 2 个初值** $x_0$ 和 $x_1$，公式从 $k=1$ 起算。

### 7.2 几何解释

图 3.6 画的是过 $(x_{k-1},f(x_{k-1}))$ 和 $(x_k,f(x_k))$ 的割线（弦）交 $x$ 轴于 $x_{k+1}$。牛顿法用切线，割线法用弦，名字就是这么来的。

### 7.3 手算步骤

1. 给两个初值 $x_0$、$x_1$，算出 $f(x_0)$、$f(x_1)$。
2. 代公式得 $x_2$。
3. 丢掉 $x_0$，用 $(x_1,x_2)$ 算 $x_3$，依次滚动。
4. 每步只需要算一次新的 $f$，不用算导数，这是它比牛顿法省事的地方。

### 7.4 演算例（整理补充）

$f(x)=x^3-x-1$，$x_0=1$，$x_1=1.5$：

| $k$ | $x_k$ |
| --- | --- |
| 0 | $1$ |
| 1 | $1.5$ |
| 2 | $1.2666666667$ |
| 3 | $1.3159616733$ |
| 4 | $1.3252141140$ |
| 5 | $1.3247138858$ |
| 6 | $1.3247179554$ |

同样的初值区域，牛顿法 4 步到 $10^{-14}$，割线法 6 步到约 $10^{-9}$。慢一点，但省掉了求导。

## 八、解非线性方程组的牛顿迭代法

### 8.1 问题

非线性方程组

$$f_i(x_1,x_2,\dots,x_n)=0,\qquad i=1,2,\dots,n$$

精确解记为 $x^*=(x_1^*,x_2^*,\dots,x_n^*)^{\mathsf T}$。

### 8.2 线性化

每个非线性方程 $f_i(x_1,x_2,\dots,x_n)=0$ 在 $x^{(k)}=(x_1^{(k)},x_2^{(k)},\dots,x_n^{(k)})^{\mathsf T}$ 点作泰勒展开，舍去关于 $x_j-x_j^{(k)}$ 的二次及以上的项（**截断到线性部分，转为了求解线性方程**）：

$$f_i(x)\approx f_i(x^{(k)})+(x_1-x_1^{(k)})\frac{\partial f_i(x^{(k)})}{\partial x_1}+\cdots+(x_n-x_n^{(k)})\frac{\partial f_i(x^{(k)})}{\partial x_n}=0,\quad i=1,\dots,n$$

记 $x^*$ 的第 $k+1$ 次近似值为 $x^{(k+1)}=(x_1^{(k+1)},x_2^{(k+1)},\dots,x_n^{(k+1)})^{\mathsf T}$，并记偏导简写

$$\partial_j f_i(x)=\frac{\partial f_i(x)}{\partial x_j}$$

上面 $n$ 个式子写成向量形式：

$$\begin{bmatrix}f_1(x^{(k)})\\ f_2(x^{(k)})\\ \vdots\\ f_n(x^{(k)})\end{bmatrix}+\begin{bmatrix}\partial_1f_1&\partial_2f_1&\cdots&\partial_nf_1\\ \partial_1f_2&\partial_2f_2&\cdots&\partial_nf_2\\ \vdots&\vdots&&\vdots\\ \partial_1f_n&\partial_2f_n&\cdots&\partial_nf_n\end{bmatrix}_{x=x^{(k)}}\begin{bmatrix}x_1^{(k+1)}-x_1^{(k)}\\ x_2^{(k+1)}-x_2^{(k)}\\ \vdots\\ x_n^{(k+1)}-x_n^{(k)}\end{bmatrix}=0$$

### 8.3 矩阵形式与 Jacobi 矩阵

$$F(x^{(k)})+F'(x^{(k)})\bigl(x^{(k+1)}-x^{(k)}\bigr)=0$$

其中

$$F'(x^{(k)})=\begin{bmatrix}\partial_1f_1(x)&\partial_2f_1(x)&\cdots&\partial_nf_1(x)\\ \partial_1f_2(x)&\partial_2f_2(x)&\cdots&\partial_nf_2(x)\\ \vdots&\vdots&&\vdots\\ \partial_1f_n(x)&\partial_2f_n(x)&\cdots&\partial_nf_n(x)\end{bmatrix}_{x=x^{(k)}}$$

叫做 $F(x)$ 于点 $x^{(k)}$ 处的 **Jacobi 矩阵**。

排列方式要记牢：**第 $i$ 行是第 $i$ 个方程，第 $j$ 列是对第 $j$ 个变量求偏导**。行列写反是最常见的失分点。

### 8.4 牛顿迭代公式

若 $F'(x^{(k)})$ **可逆**（这是前提），得牛顿法的迭代公式：

$$x^{(k+1)}=x^{(k)}-\bigl[F'(x^{(k)})\bigr]^{-1}F(x^{(k)}),\qquad k=0,1,\dots$$

改写成两步：

$$\begin{cases}x^{(k+1)}=x^{(k)}+\Delta x^{(k)}\\[4pt] F'(x^{(k)})\,\Delta x^{(k)}=-F(x^{(k)})\end{cases}$$

下面那个方程叫**牛顿方程**。笔记强调的操作顺序：**先求解牛顿方程，得到 $\Delta x^{(k)}$，再计算 $x^{(k+1)}$**。

真上手算时不要去求逆矩阵。解一个 $n$ 阶线性方程组比求逆省事得多，而且数值上更稳，这也是第 2 章高斯消元那一套在这里的用处。

### 8.5 手算步骤

1. 写出 $F(x)=(f_1,\dots,f_n)^{\mathsf T}$，求出 Jacobi 矩阵 $F'(x)$ 的符号表达式。
2. 代入当前迭代点 $x^{(k)}$，算出数值向量 $F(x^{(k)})$ 和数值矩阵 $F'(x^{(k)})$。
3. 解线性方程组 $F'(x^{(k)})\Delta x^{(k)}=-F(x^{(k)})$，得修正量 $\Delta x^{(k)}$。
4. $x^{(k+1)}=x^{(k)}+\Delta x^{(k)}$。
5. 判 $\Vert\Delta x^{(k)}\Vert$ 是否够小，不够就回到第 2 步。

### 8.6 演算例（整理补充）

解

$$\begin{cases}x^2+y^2-4=0\\ y-x^2=0\end{cases}$$

$$F(x,y)=\begin{bmatrix}x^2+y^2-4\\ y-x^2\end{bmatrix},\qquad F'(x,y)=\begin{bmatrix}2x&2y\\ -2x&1\end{bmatrix}$$

取 $x^{(0)}=(1,1)^{\mathsf T}$。

第一步手算：$F(x^{(0)})=(-2,0)^{\mathsf T}$，$F'(x^{(0)})=\begin{bmatrix}2&2\\-2&1\end{bmatrix}$。

解牛顿方程 $\begin{bmatrix}2&2\\-2&1\end{bmatrix}\Delta x=\begin{bmatrix}2\\0\end{bmatrix}$，得 $\Delta x^{(0)}=\bigl(\tfrac13,\tfrac23\bigr)^{\mathsf T}$，于是 $x^{(1)}=\bigl(\tfrac43,\tfrac53\bigr)^{\mathsf T}$。

| $k$ | $x^{(k)}$ | $y^{(k)}$ |
| --- | --- | --- |
| 0 | $1$ | $1$ |
| 1 | $1.33333333$ | $1.66666667$ |
| 2 | $1.25320513$ | $1.56410256$ |
| 3 | $1.24962682$ | $1.56155439$ |
| 4 | $1.24962107$ | $1.56155281$ |

精确解 $y^*=\dfrac{-1+\sqrt{17}}{2}=1.5615528128$，$x^*=\sqrt{y^*}=1.2496210677$。四步收敛，方程组的牛顿法同样是平方收敛。

## 公式速查

| 方法 | 迭代公式 | 需要的初值 | 收敛阶 |
| --- | --- | --- | --- |
| 预报校正开方 | $x_{k+1}=\frac12\bigl(x_k+\frac{a}{x_k}\bigr)$ | 1 个，$x_0>0$ | 2 |
| 二分法 | $x=a+\frac{b-a}{2}$，按符号弃半 | 有根区间 $[a,b]$ | 线性，比值 $\frac12$ |
| 不动点迭代 | $x_{k+1}=\varphi(x_k)$ | 1 个 | 1（线性） |
| 牛顿法 | $x_{k+1}=x_k-\frac{f(x_k)}{f'(x_k)}$ | 1 个 | 2（单根时） |
| 割线法 | $x_{k+1}=x_k-\frac{x_k-x_{k-1}}{f(x_k)-f(x_{k-1})}f(x_k)$ | 2 个 | 超线性 |
| 方程组牛顿法 | $F'(x^{(k)})\Delta x^{(k)}=-F(x^{(k)})$，$x^{(k+1)}=x^{(k)}+\Delta x^{(k)}$ | 1 个向量 | 2 |

误差与次数：

| 用途 | 式子 |
| --- | --- |
| 二分法 $k$ 次后区间长 | $\frac{b-a}{2^k}$ |
| 二分法取中点的误差 | $<\frac{b-a}{2^{k+1}}$ |
| 不动点迭代，事后判停 | $\lvert x^*-x_k\rvert\le\frac{1}{1-L}\lvert x_{k+1}-x_k\rvert$ |
| 不动点迭代，事前估次数 | $\lvert x^*-x_k\rvert\le\frac{L^k}{1-L}\lvert x_1-x_0\rvert$ |
| 牛顿法误差极限 | $\lim\limits_{k\to\infty}\frac{x^*-x_{k+1}}{(x^*-x_k)^2}=-\frac{f''(x^*)}{2f'(x^*)}$ |

## 易错点汇总

1. 二分法只能求单根或奇数重实根，偶数重根和虚根求不了。
2. 二分法里替换端点的判据是「与 $f(a)$ 同号就换 $a$」，方向别写反。
3. 二分法误差上界的分母是 $2^{k+1}$（因为取的是中点），区间长度才是 $2^k$。
4. 不动点迭代的收敛性定理有三条前提，区间自映射 $\varphi([a,b])\subseteq[a,b]$ 最容易漏验。
5. 定理里的 $L$ 是 $\lvert\varphi'\rvert$ 在整个 $[a,b]$ 上的一致上界，不是某一点的导数值。
6. 两个误差估计式用途不同：带 $\lvert x_{k+1}-x_k\rvert$ 的判停，带 $L^k\lvert x_1-x_0\rvert$ 的估次数。
7. 牛顿法每步都要重算 $f'(x_k)$。
8. 牛顿法初值条件是 $f(x_0)f''(x_0)>0$，注意是 $f$ 乘 $f''$，不是 $f'$。
9. 牛顿法平方收敛的前提是单根（$f'(x^*)\neq0$），重根时掉回线性。
10. 割线法要给两个初值，公式从 $k=1$ 开始。
11. Jacobi 矩阵行列顺序：行对应方程编号 $i$，列对应变量编号 $j$。
12. 方程组牛顿法解牛顿方程，不求逆矩阵。
