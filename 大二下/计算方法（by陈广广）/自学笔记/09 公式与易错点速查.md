# 公式与易错点速查

这一份是汇总页，来源是同目录下 `01` 到 `08` 八个文件（它们又整理自 `计算方法笔记本（压缩）.pdf` 第 2 到 54 页）。前半是最容易记混的公式，后半是整理时用 Python 复算对出来的原稿错误，考前扫一遍就行。

## 一页公式

### 误差

$$e^{*}=x^{*}-x,\qquad e_{r}^{*}=\frac{e^{*}}{x},\qquad |e^{*}|\le 0.5\times 10^{m-n}\Leftrightarrow x^{*}\ \text{有}\ n\ \text{位有效数字}$$

$x^{*}=\pm 0.a_{1}a_{2}\cdots a_{n}\times 10^{m}$， $m$ 从标准型读， $n$ 是有效位数。乘除的误差限要带上另一个因子的绝对值，相对误差用 $\mathrm{d}\ln$ 记： $e_{r}^{*}(xy)=e_{r}^{*}(x)+e_{r}^{*}(y)$。

函数值的误差 $e^{*}(f(x))\approx |f'(x^{*})|e^{*}(x)$，导数大的表达式精度差。

### 直接法

计算量（乘除法次数）：Gauss 消元加回代 $\dfrac{n^{3}}{3}+n^{2}-\dfrac{n}{3}$；平方根法 $\dfrac{n^{3}}{6}+\dfrac{n^{2}}{2}-\dfrac{2}{3}n$，存储 $\dfrac{n(n+1)}{2}$；追赶法约 $5n$ 次。

| 分解 | L | 中间 | U |
| --- | --- | --- | --- |
| Doolittle | 单位下三角 | | 上三角 |
| Crout | 下三角 | | 单位上三角 |
| LDU | 单位下三角 | 对角 D | 单位上三角 |
| Cholesky | 下三角 $A=LL^{T}$ | | |
| $LDL^{T}$ | 单位下三角 | 对角 D | $L^{T}$ |

解方程一律拆成 $Ly=b$、 $Ux=y$ 两步。 $\det(A)=(-1)^{s}u_{11}\cdots u_{nn}$， $s$ 是换行次数。

### 范数与迭代

$$\|x\|_{\infty}\le\|x\|_{2}\le\|x\|_{1}\le\sqrt{n}\,\|x\|_{2}\le n\|x\|_{\infty}$$

$\|A\|_{\infty}$ 按行求和取最大， $\|A\|_{1}$ 按列求和取最大， $\|A\|_{2}=\sqrt{\rho(A^{T}A)}$。 $\rho(A)\le\|A\|_{p}$， $\operatorname{cond}(A)=\|A\|\|A^{-1}\|\ge 1$。

迭代 $x^{(k+1)}=Mx^{(k)}+g$ 收敛的充要条件是 $\rho(M)<1$； $\|M\|<1$ 只是充分条件。

$$\text{Jacobi}:\ M=D^{-1}(L+U);\qquad \text{Gauss-Seidel}:\ M=(D-L)^{-1}U$$

$$\|x^{(k)}-x^{*}\|\le\frac{\|M\|^{k}}{1-\|M\|}\|x^{(1)}-x^{(0)}\|$$

### 方程求根

二分法： $k$ 次后区间长 $\dfrac{b-a}{2^{k}}$，取中点的误差 $\dfrac{b-a}{2^{k+1}}$。

不动点迭代要三条： $\varphi$ 连续、 $\varphi([a,b])\subseteq[a,b]$、 $|\varphi'|\le L<1$。次数估计由 $\dfrac{L^{k}}{1-L}|x_{1}-x_{0}|\le\varepsilon$ 反解。

牛顿法 $x_{k+1}=x_{k}-\dfrac{f(x_{k})}{f'(x_{k})}$，2 阶收敛，误差常数 $\left|\dfrac{f''(x^{*})}{2f'(x^{*})}\right|$；不动点迭代一般 1 阶。割线法用差商代替导数，需要两个初值。

方程组的牛顿法：解牛顿方程 $F'(x_{k})\Delta x_{k}=-F(x_{k})$，再 $x_{k+1}=x_{k}+\Delta x_{k}$。

### 特征值

规范化乘幂法一轮：取 $x^{(k)}$ 中带符号的最大分量 $\max_{k}$，规范化 $y^{(k)}=x^{(k)}/\max_{k}$，迭代 $x^{(k+1)}=Ay^{(k)}$。主特征值是 $\max_{k+1}$，特征向量是 $y^{(k+1)}$，收敛速度看 $|\lambda_{2}/\lambda_{1}|$。

反幂法把第三步换成解 $Ax^{(k+1)}=y^{(k)}$，先 LU 分解一次，不求逆。平移 $B=A-\lambda_{0}I$，结果加回 $\lambda_{0}$。

雅可比旋转：选非对角绝对值最大元， $\tan 2\theta=\dfrac{2a_{ij}}{a_{jj}-a_{ii}}$， $A_{k+1}=P_{k}^{T}A_{k}P_{k}$（两边都乘）。

Givens：消对角线下方的 $a_{ji}$，取 $\cos\theta=\dfrac{a_{ii}}{\sqrt{a_{ii}^{2}+a_{ji}^{2}}}$、 $\sin\theta=\dfrac{a_{ji}}{\sqrt{a_{ii}^{2}+a_{ji}^{2}}}$，只左乘 $P$。

### 插值

$$L_{n}(x)=\sum_{i=0}^{n}l_{i}(x)y_{i},\qquad R_{n}(x)=\frac{f^{(n+1)}(\xi)}{(n+1)!}\omega_{n+1}(x)$$

$$N_{n}(x)=f[x_{0}]+f[x_{0},x_{1}]\,(x-x_{0})+\cdots,\qquad f[x_{0},\dots,x_{n}]=\frac{f^{(n)}(\xi)}{n!}$$

加一个节点只补一项，前面的不用重算。差商与节点次序无关。埃尔米特插值把有导数条件的节点重复写一次，差商表里对应的一阶格直接填导数值。

### 数值积分

| 公式 | 代数精度 | 余项 |
| --- | --- | --- |
| 梯形 $\frac{b-a}{2}(f_{0}+f_{1})$ | 1 | $-\frac{1}{12}(b-a)^{3}f''(\eta)$ |
| 辛普森 $\frac{b-a}{6}(f_{0}+4f_{1}+f_{2})$ | 3 | $-\frac{b-a}{180}h^{4}f^{(4)}(\eta)$ |
| 柯特斯 $\frac{b-a}{90}(7f_{0}+32f_{1}+12f_{2}+32f_{3}+7f_{4})$ | 5 | $-\frac{8h^{7}}{945}f^{(6)}(\eta)$ |

$n$ 为奇数时代数精度是 $n$， $n$ 为偶数时是 $n+1$。这条我用 sympy 从 $n=1$ 到 $n=6$ 逐个验证过。

龙贝格外推的分母依次是 $2^{2}-1=3$、 $2^{4}-1=15$、 $2^{6}-1=63$，指数每次加 2。

整理时每份公式和例题都用 numpy 或 sympy 复算过，下面是对出来的问题，详细说明在各自文件里。

## 手算自查清单

考前把这几条在草稿纸上各写一遍，写不出来就回去翻对应文件。

1. 浮点数个数式子末尾的 $+1$（零）有没有丢。
2. 三种矩阵范数哪个按行、哪个按列。
3. 迭代收敛判断先算 $\rho(M)$， $\|M\|\ge 1$ 不代表发散。
4. 二分法题目问的是区间长度还是中点误差。
5. 牛顿法初值要满足 $f(x_{0})f''(x_{0})>0$。
6. 乘幂法取的是带符号的最大分量，不是绝对值。
7. 雅可比旋转两边乘 $P^{T}$ 和 $P$，Givens 只左乘一次。
8. 差商表里重复节点的那一格填导数值。
9. 复合求积的 $h$ 是小区间长度，单区间公式里的 $h$ 不一样。
10. 龙贝格分母是 $3,15,63$。
