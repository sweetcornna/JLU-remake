# 计算方法 自学指南

这一套笔记整理自课程目录里的手写复习笔记本 `计算方法笔记本（压缩）.pdf`（54 页）。原件是扫描的手写稿，PDF 自带的文字层全是乱码，所以整理时是把每一页渲染成图片逐页读出来的。

课程目录里另有一套重制版讲义 `重制版PPT/`，覆盖第 1 到第 6 章和总复习。讲义负责把概念和推导讲一遍，这套笔记不重复讲义内容，只留下考点、解题步骤、公式和例题。

## 建议学习顺序

1. 先读 `01 考点清单与复习优先级.md`，知道哪几块必须动手算、哪几块只要能写出定义。
2. 按章节顺序看重制版讲义，看完一章立刻翻对应的笔记文件，照着解题步骤把例题手算一遍。
3. 计算量大的几块（LU 分解、迭代法收敛判断、插值多项式构造、龙贝格填表）单独多练，这几块最容易在小地方算错。
4. 考前一天只看 `01` 和 `09`。

## 源资料里提到的考试信息

只有笔记本里写到的部分，别的没有：

- 第一章四道简答标了分值：科学计算的流程 5 分、计算方法的特点 4 分、浮点数四则运算注意点 3 分、误差来源 4 分。
- 笔记里多处用"常考 / 可考 / 考点"区分优先级，并写明乔列斯基分解和 $LDL^{T}$ 分解"总复习里没有，所以不考"。
- 提到过 2018 年卷子第一大题第 4 小问考了二分法的误差估计，问的是分母取 $2^{k}$ 还是 $2^{k+1}$。
- 多处标了教材页码（书 P1、P40-43、P65-72、P122-135 等），对应教材章节。
