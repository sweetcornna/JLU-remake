每个文件的结构都一样：先是本章要点（几句话说明这章考什么），然后是名词解释，再是按主题分组的简答题，最后是易混对比表格。表格是整理时归纳的，源资料里没有。

## 建议学习顺序

1. 按 01 到 09 的顺序过一遍，每章先看"本章要点"再看正文，名词解释部分适合直接背。
2. 涉及画图的题（进程状态转换图、中断处理流程、地址映射流程、管程组成、作业状态转换）的原图已经裁进笔记，看懂以后合上笔记自己画一遍，比死记有用。
3. 计算类的点集中在第 6、7、9 三章：有效访问时间 EAT、页框与页内地址的位数划分、越界条件、磁盘调度的磁头移动量、位示图的字节位定位。这些要动手算，光看不行。
4. 最后用 `10 选择题知识点速记.md` 查漏，里面标了几处原稿算错或说反的地方，注意区分。
