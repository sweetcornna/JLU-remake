## 2004级 A卷（2005年冬）

来源 `历年考试题/2004级C++A-2005年冬天.doc`（试卷，红字标了选择题答案和判断题的错误之处，另有 18 条原稿批注）和 `历年考试题/2004级C++A-2005年冬天-解答参考.doc`（解答参考，蓝字写选择题、第五至七大题的答案，红字标出判断题里错误的论述，另有 6 条批注，和试卷里的批注重复）。2005-2006学年第1学期，满分100分，考试时间2006年1月8日。

两份文件题目相同，只有单选第 1 题措辞差一个字（见该题）。第三、四大题解答参考没有写答案，下面照录原稿批注并补全。

### 一、单选题（共10分，每题1分）

1. 已知f1和f2是同一类中的两个成员函数，若f1的实现代码体内不能调用f2，则最可能的情况是：
   - (A) f1和f2都是静态函数
   - (B) f1是静态的，f2不是
   - (C) f1不是静态的，f2是静态的
   - (D) f1和f2都不是静态函数

   答案：B。静态成员函数没有 `this`，不能直接调用非静态成员函数；反过来非静态函数调用静态函数没问题。解答参考的红字说明："本题有点问题，D的情况也可能出现，如f1是常成员函数，而f2不是"。（试卷版题干作"则可能的情况是"，解答参考改成"最可能的情况是"。）

2. 一个对象所占的内存空间中可以保存下面哪类数据？
   (A) 静态数据成员　(B) 内联函数代码　(C) 所有成员函数的入口地址　(D) 虚函数表的入口地址

   答案：D。有虚函数的类，每个对象里存一个虚表指针；静态数据成员全类一份，函数代码都不在对象里。

3. 下面关于new 和delete操作符的说法，哪个是不正确的：
   - (A) 使用new操作符，可以动态分配全局堆中的内存资源。
   - (B) 用new申请的数组，必须用delete[] 释放。
   - (C) 用new申请的空间，即使不调用delete释放掉，当程序结束时也会自动释放掉。
   - (D) 执行语句 `A * p=new A[100];` 时，类A的构造函数会被调用100次。

   答案：C。C++ 语言不保证 `new` 出来的空间会自动释放，不 `delete` 就是内存泄漏，对象的析构函数也不会执行。（现代操作系统在进程结束时会回收整个进程的内存，但那是操作系统的行为，考试按 C 不正确作答。）

4. 下列哪种函数可以是虚函数：
   (A) 自定义的构造函数　(B) 拷贝构造函数　(C) 静态成员函数　(D) 析构函数

   答案：D。构造函数（包括拷贝构造）和静态成员函数都不能是虚函数。

5. C++的最小编译单位是：
   (A) 工程中每个.cpp和.h文件　(B) 工程中每个.cpp文件　(C) 工程中每个.h文件　(D) 工程中所有文件

   答案：B。每个 .cpp 文件连同它 `#include` 进来的头文件构成一个编译单元，.h 文件不单独编译。

6. 下面表达式中不可能作为左值（赋值运算符左侧）的是：
   (A) `a=b`　(B) `*p`　(C) `f(a,b)`　(D) `&a`

   答案：D。取地址的结果是一个临时的地址值，不能被赋值。C++ 里 `a=b` 的结果是 a 本身，可以作左值；`f` 返回引用时 `f(a,b)` 也可以。

7. 在实现函数 `A& f(A & obj)` 时，下面的哪一个表达式可以出现在return 语句中？
   (A) `new A( )`　(B) `obj`　(C) `&obj`　(D) `new A(obj)`

   答案：B。返回类型是 `A&`，要返回一个 A 对象；A、C、D 的类型都是 `A*`。

8. 判断类A的两个对象a1与a2是否是同一个对象的方法是：
   - (A) 利用调试器，查看a1与a2各成员数据的值是否相等
   - (B) 重载 == 运算符，用它来判断各成员数据的值是否相等。
   - (C) 判断这两个对象的地址值是否相等。
   - (D) 比较创建时使用的构造函数的实参是否相同。

   答案：C。成员值相等只说明内容一样，地址相同才是同一个对象。

9. 已知obj是一个对象,下面哪一个表达式是不可能出现的？
   (A) `obj.100`　(B) `!obj`　(C) `obj++`　(D) `obj,100`

   答案：A。`.` 后面只能是成员名。B、C 重载了对应运算符就合法，D 是逗号表达式，本来就合法。

10. 下面哪种情况不属于函数重载：
    - (A) 类中定义的运算符函数
    - (B) 同一个名字，参数个数不同
    - (C) 派生类中重新定义了一个和基类中的原型完全相同的函数
    - (D) 类中定义了两个同名、同参数表的函数，但其中一个是常成员函数

    答案：C。重载要求在同一作用域里。派生类重新定义同原型函数，是覆盖（基类函数为虚函数时）或隐藏。D 中有没有 `const` 是重载的区分条件。

### 二、判断正误，对于你认为错误的论述，说明原因或举出反例。（每题2分，共20分）

解答参考把错误的论述整句标红（第 1、2、3、5、7、8、9 题），第 4、6、10 题没标，即为正确。

1. 使用语句 `A a=dynamic_cast<A>(b);`，可以将派生类B的对象b强制转换为基类A的对象。

   答案：错误。`dynamic_cast` 的目标类型只能是指针或引用（或 `void*`），写成对象类型编译报错（clang："target type must be a reference or pointer type"）。派生类对象赋给基类对象直接写 `A a = b;` 即可，或者用 `static_cast<A>(b)`。

2. 在同一个类中，可以定义重载的成员函数 `void f(int& anInt);` 和 `void f(int anInt);`。

   答案：错误（解答参考标红；原稿批注："有二义性，无法确定重载函数"）。用 int 变量调用 `f(n)` 时两个版本匹配程度一样，编译报 "call to member function 'f' is ambiguous"。严格说，这两个声明本身能通过编译，`f(10)` 这种用字面量调用的也能确定选 `f(int)`；答题时写明"用变量调用会二义，这组重载没法正常使用"比较稳妥。

3. 虚拟继承的概念是为了实现多态性的要求而引入的。

   答案：错误。原稿批注："虚函数是为了多态性，虚基类是为了菱形结构"。虚拟继承解决的是菱形继承中公共基类在派生类对象里有多份拷贝、访问时二义的问题。

4. 若常量成员函数（用const 修饰的成员函数）中调用同一个类中的虚函数f，那么函数f也一定是一个常量成员函数。

   答案：正确。常成员函数里 `this` 是 `const A*`，通过它只能调用常成员函数，与 f 是不是虚函数无关。（这里指对当前对象调用 f；若在函数里另建一个非常量对象去调用，则不受限制。）

5. 类D以public方式继承类B，若在这两个类中以同样的方式分别声明了一个同名的整型成员变量x，那么，为类D的对象分配内存空间时，不需要为类B中声明的x分配空间。

   答案：错误。D 的对象里包含完整的 B 子对象，`B::x` 和 `D::x` 各占一份空间，`D::x` 只是在名字上隐藏了 `B::x`，仍可用 `d.B::x` 访问。（原稿批注只写了"先构造基类，后构造子类"，没说到点上。）

6. 实例化派生类对象时，一定会调用到基类的某一个构造函数。

   答案：正确。派生类构造时先构造基类子对象，初始化列表没写就调用基类的默认构造函数。

7. 如果类A是类B的友员，类D以public继承方式从类B继承，则类A也是类D的友员。

   答案：错误。友元关系不能继承，A 不能访问 D 自己新增的私有成员。

8. 对于任意按照语言规范定义并实现的类A，系统都可以为它提供一个无参数的构造函数，因此，在任何情况下都可以用 `new A;` 的方式产生A类的对象。

   答案：错误。原稿批注："如果自定义了构造函数，那么系统就不会提供无参的函数"。例如只定义了 `A(int)`，`new A;` 就编译不过。另外抽象类、构造函数为私有的类也不能这样创建对象。

9. 异常是程序运行过程中产生的错误。

   答案：错误。异常指程序运行时出现的非正常情况（如内存不足、文件打不开、除数为 0），可以预料并用 `try`/`catch` 处理，不一定是程序错误；语法错误等编译期错误也不属于异常。

10. 设有函数说明 `void f(const int&);` 则在调用该函数时，提供的参数既可以int型变量，又可以是int型常量。

    答案：正确。`const int&` 可以绑定变量、常量，也可以绑定字面量产生的临时量。

### 三、指出下列程序代码中存在的错误并说明错误原因。（每题5分，共10分）

1. 原卷分四栏排版，这里按顺序合并：

   ```cpp
   #include<iostream.h>
   class A{
   public:
   	A( ) { }
   private:
   	int  a;
   };
   class B{
   public:
   	B( ) { }
   private:
   	int  b;
   };
   class C : public A, B {
   public:
   	C( ) { }
   private:
   	int  c;
   };
   void main()
   {
      C c;
      cout << c.a << c.b ;
      cout << c.c <<endl ;
   }
   ```

   答案（原稿批注只标了 `cout << c.a << c.b ;` 一行，说"子类不能直接访问基类的成员变量"，下面补全）：

   - `c.a`：a 是 A 的私有成员，在 main 里不能访问（在 C 的成员函数里也不能）。
   - `c.b`：b 是 B 的私有成员。另外 `class C : public A, B` 中 B 前面没写继承方式，`class` 默认私有继承，即使 b 是公有的，在类外通过 C 的对象也访问不到。
   - `c.c`：c 是 C 自己的私有成员，main 里同样不能访问。原稿批注漏了这一处。

   clang 报三个错：`'a' is a private member of 'A'`、`'b' is a private member of 'B'`、`'c' is a private member of 'C'`。一种改法：继承方式写成 `public A, public B`，三个类各加一个公有的取值函数（如 `int GetA() const { return a; }`），main 里调用 `c.GetA()` 等。改完能编译运行。

2. 

   ```cpp
   //交换A类的两个对象a和b的值
   void  MySwap(A& a, A& b)
   {
        A& temp=a;
        a=b;
        b=temp;
   }
   ```

   答案：错在 `A& temp=a;`（原卷红字标出）。temp 是 a 的引用，也就是 a 的别名，并没有保存 a 原来的值；执行 `a=b;` 后 temp 跟着变成 b 的值，`b=temp;` 等于 b 给自己赋值，结果 a、b 都等于原来的 b。改为 `A temp=a;`。实测：a=1、b=2 调用原函数后得到 a=2、b=2，改后得到 a=2、b=1。

   （更正：原稿批注说"temp是对象a的浅拷贝"。这里根本没有拷贝，temp 就是 a 本身。）

### 四、回答下列各题（每题4分，共20分）

1. 说明为什么不能在类的静态成员函数的实现体中使用this 指针。

   - 原稿批注：静态成员函数是类的函数，和对象无关，而 this 指向的是对象的首地址。
   - 补充：静态成员函数可以不通过对象调用（`A::f()`），调用时没有对象地址可传，编译器也不给它传隐含的 `this` 参数。

2. 举例说明protected关键字的两种用法和相应目的。

   原稿批注只写了"修饰成员函数或者成员变量；修饰保护继承"，补全如下（整理补充）：

   - 修饰成员：`class B { protected: int x; };`。类外不能访问 x，B 的派生类的成员函数可以访问。目的是对外隐藏实现，同时留给派生类使用。
   - 指定继承方式：`class D : protected B { };`。B 的公有和保护成员在 D 中都变成保护成员。目的是 D 和 D 的派生类内部可以使用 B 的功能，但 D 的使用者不能调用这些接口，也不能把 D 的对象当 B 用（类外不能把 `D*` 转换成 `B*`）。

3. 类的数据成员在哪些情况下必须在初始化列表中进行初始化。

   - 原稿批注：常量数据成员；引用数据成员；需要调用基类带参数的构造函数时。
   - 补充：成员对象所属的类没有默认构造函数时，也必须在初始化列表里给出参数。

4. 说明出现在下面头文件中的预处理指令的作用。

   ```cpp
   #ifndef  __MYFILE_H_
   #define  __MYFILE_H_
       …   //头文件内容
   #endif   //__MYFILE_H_
   ```

   - 这是头文件保护（包含警戒），防止同一个编译单元里同一个头文件被包含多次，造成类型等重复定义的编译错误。
   - 过程：第一次包含时宏 `__MYFILE_H_` 未定义，于是定义它并编译头文件内容；之后再被包含（比如 a.h 和 b.h 都包含了它），宏已经定义，`#ifndef` 到 `#endif` 之间整段跳过。
   - （更正：原稿批注作"包含警戒，保证多文件不会交叉编译"。它管的是一个 .cpp 内部的重复包含，不同 .cpp 文件各自编译，互不影响。）

5. 为了能够将类B的对象赋值给类A的对象，在定义这两个类时可以采取哪些手段？至少说明两种不同的处理方法。

   原稿批注写了"B 继承 A；重载 A 的赋值运算符"，完整列出如下：

   - 让 B 公有继承 A：派生类对象可以直接赋给基类对象（只复制基类部分）。
   - 在 A 中重载赋值运算符：`A& operator=(const B& b);`。
   - 在 A 中定义转换构造函数 `A(const B& b);`：`a = b;` 时先把 b 转成临时的 A 对象，再调用 A 的赋值运算符。
   - 在 B 中定义类型转换函数 `operator A() const;`，效果同上。

### 五、阅读下面两个类的定义和部分实现代码，完成3个问题。（共10分）

```cpp
#include<iostream.h>
class Base {
friend ostream& operator<<(ostream&, const Base& );
public:
    virtual ~Base( ) {}
private:
    virtual void Out(ostream & os) const =0;
};
class D1:public Base {
public:
    D1(int n):x(n),y(n*n) { }
    virtual ~D1( ) { }
private:
virtual void Out(ostream & os) const
      { os << "Data=" << x+y << endl; }
    int  x, y;
};
class D2:public Base {
public:
    D2(int n):y(n) {}
    virtual ~D2( ) {}
private:
    virtual void Out(ostream & os) const
       { os << "Data=" << y << endl; }
    int y;
};
int main( )
{
    D1 d1(10);
    D2 d2(20);
    cout<<d1;
    cout<<d2;
    return 0;
}
```

（原卷分四格排版，`int　 x,　y;` 里的全角空格已改成半角。）

1. 实现Base类中声明的友元函数 `operator<<`，使得程序的两行输出分别为Data=110和Data=20。(4分)

   解答参考：

   ```cpp
   ostream& operator<<(ostream& os, const Base& b)
   {  b.Out(os);  return os; }
   ```

   解答参考原文开头多写了 `friend`。在类外定义友元函数时不能再写 `friend`，上面已去掉；如果直接写在 Base 类体里，就保留 `friend`。友元函数可以访问 Base 的私有成员 `Out`，`Out` 是虚函数，传入 d1、d2 时分别调用 `D1::Out`、`D2::Out`。实测输出 `Data=110`、`Data=20`。

   （更正：解答参考和原稿批注还给了第二种写法 `os<<"Data=" << b.x+b.y << endl;`，并把 `os`、`return` 误写成首字母大写。Base 里没有 x、y 成员，这种写法编译不过，只能用第一种。）

2. 说明为什么重载 `<<` 操作符时，不能将其定义成类的成员函数形式。（3分）

   解答参考：`<<` 操作符是一个二元运算符，其左操作数总是一个流对象，不可能是本类对象。

   补充一句：写成成员函数时左操作数必须是本类对象，调用就变成 `d1 << cout`，和习惯用法相反；而 ostream 是标准库的类，我们也没法给它加成员。

3. 举例说明将Base类的析构函数定义成虚函数的目的或作用。（3分）

   解答参考：指向派生类对象的指针（或引用）总可以赋值给 Base 类的指针（或引用），如 `Base* pb = new D1(10);`。若析构函数定义成非虚函数，则执行 `delete pb;` 时只调用基类的析构函数，没有调用派生类的析构函数，这样会造成释放不完整。

   （解答参考原文例子写作 `new D1(10,20)`，D1 只有一个参数的构造函数，已改成 `new D1(10)`。）

### 六、写出下面程序的运行结果（每题5分，共10分）

1. 

   ```cpp
   #include <iostream.h>
   #include <string.h>
   char&  f(char * sz ,  int i )
   {
       return sz[strlen(sz)-i-1];
   }
   void main()  {
   	char sz[]="ABCDEFG";
       for(int i=0; i<strlen(sz); i++ )
          f(sz,i) = sz[i];
       cout << sz << endl;
   }
   ```

   运行结果（解答参考与原稿批注相同，实测一致）：

   ```text
   ABCDCBA
   ```

   `f(sz,i)` 返回倒数第 i+1 个字符的引用，循环把前半段镜像复制到后半段：i=0 时 `sz[6]='A'`，i=1 时 `sz[5]='B'`，i=2 时 `sz[4]='C'`，i=3 时 `sz[3]` 赋给自己。从 i=4 起是把后半段抄回前半段，而后半段已经是镜像后的值，字符串不再变化。

2. 

   ```cpp
   #include <iostream.h>
   class A {
   public:
   	static int count;
   	A( )        {display( ); count++;  }
   	virtual ~A( ) { count--;  display( ); }
   	virtual void display( )
   { cout << 'A' << count << endl; }
   };
   class B : public A {
   public:
   	B( )       {display( ); count++; }
   	virtual ~B( ) {count--; display( ); }
   	  virtual void display( )
   {cout << 'B' << count << endl;}
   };
   int A::count=0;
   void main( )
   {	A* p=new B;
   	p->display( );
   	delete p;
   }
   ```

   运行结果（解答参考与原稿批注相同，实测一致）：

   ```text
   A0
   B1
   B2
   B1
   A0
   ```

   - `new B`：先执行 A 的构造函数。构造函数里调用虚函数不发生多态，调用的是 `A::display`，输出 A0，count 变 1；再执行 B 的构造函数，输出 B1，count 变 2。
   - `p->display()`：对象已构造完，动态绑定到 `B::display`，输出 B2。
   - `delete p`：析构函数是虚的，先 `~B`，count 变 1，输出 B1；再 `~A`，count 变 0，析构函数里同样不发生多态，输出 A0。

### 七、（共20分，每问题10分）

一个游戏中有多种怪物(Monster)，怪物之间可能要发生战斗(fight)，每场战斗都是一个怪物与另一怪物之间的一对一战斗。**每个**怪物都有自己的生命值(hitpoint)、攻击力值(damage)和防御力值(defense)，**每种**怪物都有各自特有的攻击(attack)方式，产生相应的攻击效果；战斗时，两个怪物依次攻击对方，即怪物a首先攻击怪物b，然后轮到怪物b攻击怪物a，之后，怪物a再次攻击怪物b，…，直到一方生命值为0。

1. 请根据你对上述描述的理解，定义并实现怪物类Monster，成员的设计可以任意，但要求该类至少有一个不带virtual修饰的成员函数fight，用来描述与另外一个怪物进行战斗的过程，该函数的实现可为Monster类的任意派生类所复用（派生类不需重新定义及实现）。不必考虑怪物的生命值减少至0后如何处理。
2. 作为怪物的特例，猫和狗的攻击效果如下表所示。在Monster的基础上，以继承手段定义并实现这两个类。

| 猫进攻导致对方的生命值减少量 | 狗进攻导致对方的生命值减少量 |
| --- | --- |
| `(猫的攻击力值 * 2 - 对方的防御力值)`，若上式小于1，则取1 | `(狗的攻击力值 - 对方的防御力值 + 5) * 2`，若上式小于2，则取2 |

解答参考（成员名 `demage` 是原文拼写，照录）：

```cpp
#include<iostream.h>
class Monster
{
public:
    Monster(int hp,int att,int def)
        :hitpoint(hp),demage(att),defense(def) {}
    virtual ~Monster() {}
    bool  fight(Monster &  other);
    virtual void attack(Monster & other)=0;
    void  ReduceHP(int harm)
    {   hitpoint-=harm; if(hitpoint<0) hitpoint=0;  }
    int   GetHP() const         {return hitpoint;}
    int   GetDemage() const     {return demage;}
    int   GetDefense() const    {return defense;}
protected:
    int hitpoint;
    int demage;
    int defense;
};
bool  Monster::fight(Monster &  other)
{
    while(true) {
        attack(other);
        if(other.GetHP()<=0) return true;
        other.attack(*this);
        if(hitpoint<=0) return false;
    }
}
class Dog:public Monster
{
public:
    Dog(int hp,int att,int def):Monster(hp,att,def) {}
    virtual ~Dog() {}
    virtual void attack(Monster & other)
    {
        int harm=(demage-other.GetDefense()+5)*2;
        if (harm<2) harm=2;
        other.ReduceHP(harm);
    }
};
class Cat:public Monster
{
public:
    Cat(int hp,int att,int def):Monster(hp,att,def) {}
    virtual ~Cat() {}
    virtual void attack(Monster & other)
    {
        int harm=demage*2-other.GetDefense();
        if (harm<1) harm=1;
        other.ReduceHP(harm);
    }
};
void main()
{
    Dog d(100,10,7);
    Cat c(120,8,9);
    if(d.fight(c))
        cout<<"Win"<<endl;
    else
        cout<<"Lost"<<endl;
}
```

设计要点：

- `fight` 是普通成员函数，写一次，所有派生类直接复用；循环里调用的 `attack` 是纯虚函数，实际执行哪种攻击由对象的真实类型决定。这是"模板方法"的思路，题目特意要求 fight 不带 virtual，就是要这样写。
- 派生类只需实现 `attack`。`attack` 里要改对方的生命值，而 C++ 的 protected 不允许通过另一个 `Monster&` 访问它的保护成员，所以基类提供了公有的 `ReduceHP` 和 `GetDefense`。

实测输出 `Win`：狗每次造成 (10−9+5)×2=12 点伤害，猫每次造成 8×2−7=9 点，10 轮后猫的生命值降到 0，狗还剩 19。

原稿批注里另有一份写法基本相同的代码（类名小写，`fight` 写在类体里），其中 `virtual ~monster();` 只声明没有定义，真正创建对象时会链接失败，要补上函数体 `{}`。

### 一、单选题（共10分，每题1分）

1. C++中解决命名冲突的机制是：
   (A) 虚基类　(B) 虚函数　(C) 函数重载　(D) 名字空间

   答案：D。

2. 若类A的一个对象所占的内存空间中包含虚函数表的入口地址，则：
   - (A) 类A不能有静态数据成员
   - (B) 类A中公有的成员函数一定是虚的
   - (C) 类A中至少有一个成员函数是虚的
   - (D) 类A的析构函数一定是虚的

   答案：C。对象里有虚表指针，说明类里有虚函数（自己声明的或从基类继承的），但不要求所有成员函数或析构函数都是虚的。

3. 任意一个类，析构函数的个数最多是：
   (A) 不限个数　(B) 1　(C) 2　(D) 3

   答案：B。析构函数没有参数，不能重载。

4. 下列关于this指针的说法，哪个是正确的：
   - (A) this指针一定指向常量型数据
   - (B) this指向的数据不可更改
   - (C) 静态成员函数中也可以访问this指针
   - (D) this指针本身可直接作为成员函数的返回值

   答案：D。例如 `A* f() { return this; }`。只有常成员函数里 `this` 才指向常量；静态成员函数没有 `this`。

5. 在类定义中，为说明成员的访问权限，private, protected, public 可以出现次数为：
   (A) 次数没有具体限定　(B) 每种至多一次　(C) public 至少一次　(D) 每种至少一次

   答案：A。三个关键字可以按任意顺序出现任意多次，也可以一个都不写（class 默认私有）。

6. 下面哪种定义方式是正确的，并且使得p可以作为函数 `void f( A* const pp);` 的实参：
   (A) `A * p = new A;`　(B) `A a; A* p = a;`　(C) `const A* p = new A;`　(D) `A a; const A* p = a;`

   答案：A。形参 `A* const` 的 const 修饰指针本身，只影响函数里能不能改 pp，实参是普通的 `A*` 就行。B、D 把对象赋给指针，编译不过；C 的 `const A*` 不能隐式转换成 `A*`。

7. obj是类A的一个对象，执行语句 `const A& aA= obj;`，则下列说法正确的是：
   - (A) 类A的拷贝构造函数会被调用
   - (B) 类A的赋值函数会被调用
   - (C) `&aA` 的值就是 `&obj`
   - (D) 语句 `obj.f( );` 等价于语句 `aA.f( );`

   答案：C。引用只是别名，不产生新对象。D 不对：aA 是常引用，只能调用 f 的 const 版本，f 不是常成员函数时 `aA.f()` 编译不过；f 有 const 和非 const 两个重载时，两句调用的版本也不同。（无答案版题干误作"obj的类A的一个对象"。）

8. 下面关于访问类A的私有数据成员的说法，错误的是：
   - (A) 类A的友元函数可以访问类A的私有成员。
   - (B) 类A的友元类中的非静态成员函数可以访问类A的私有成员。
   - (C) 类A的嵌套类中的非静态成员函数可以访问类A的私有成员。
   - (D) 类A中的非静态成员函数可以访问类A的私有成员。

   答案：C。按出题时的 C++98 标准，嵌套类对外围类没有特殊访问权限。C++11 起标准改了，嵌套类也算外围类的成员，可以访问外围类的私有成员，clang 实测 C 的写法能编译；按现行标准四个说法都对，这题只能按老标准作答。

9. 类A中有唯一的一个成员函数f，且f是公有的静态或非静态成员函数，对于类A的一个对象a，执行语句 `a.f(100);` 成功，那么f 的函数原型不可以是：
   (A) `A& f( int, int=50 );`　(B) `void f(int& ) ;`　(C) `const A * f(const int );`　(D) `A f( const int&);`

   答案：B。字面量 100 不能绑定到非常量引用 `int&`，`const int&` 可以。

10. 下面关于类的成员函数描述不正确的是：
    - (A) 静态成员函数内可以直接访问类的非静态成员数据
    - (B) 静态成员函数内可以直接访问类的静态成员数据
    - (C) 非静态成员函数可以直接访问类的非静态成员数据
    - (D) 非静态成员函数可以直接访问类的静态成员数据

    答案：A。静态成员函数没有 `this`，不知道该访问哪个对象的非静态成员。

### 二、判断正误，对于你认为错误的论述，说明原因或举出反例。（每题2分，共20分）

以下"原答案"是带答案版的蓝字。

1. 认真负责的程序员不应该写出 `obj=obj;` 形式的语句，因此在实现一个类的赋值运算函数时，强调必须判断是否自赋值是没有必要的。

   答案：错误（整理补充）。自赋值常常是间接发生的，比如 `a[i] = a[j]` 而 i 等于 j，或 `*p = *q` 而 p、q 指向同一个对象。类里有指针成员时，赋值函数一般先 `delete` 自己的旧空间再从右边拷贝，自赋值时右边的空间已经被释放了。实测一个先 `delete[]` 再 `strcpy` 的字符串类，不判断自赋值时 `b = *q`（q 指向 b）之后内容变成乱码。

   （另一版本本题作："重载流操作符 `<<` 和 `>>` 时，如果第一个参数的类型为ostream 和istream，那么这个重载函数既可以用于标准输入输出流，也可以用于文件流上。"原答案：对，ostream 和 istream 是标准输入输出流、文件流、字符串流的基类。补充：参数要写成引用 `ostream&`、`istream&`，流对象不能拷贝，传引用才能接收派生的文件流对象。）

2. 在同一个类中，可以定义重载的成员函数 `void f(int);` 和 `virtual void f(int);`。

   答案：错误。原答案："这属于重复定义"。两者参数表相同，`virtual` 不参与区分重载，clang 报 "class member cannot be redeclared"。

3. 抽象类不会产生实例，所以不需要有构造函数。

   答案：错误。原答案："被派生时需要它的构造函数"。抽象类可以有数据成员，创建派生类对象时先调用抽象基类的构造函数初始化这部分数据。

4. 类A有一个非静态的成员函数f，其函数原型是：`void A::f( ) const`，则该函数被调用时，一定是通过类A或类A的某后裔类的一个用const修饰符说明的常量对象调用的。

   答案：错误。原答案："常函数可以由变量对象或常量对象调用"。

5. 异常必须在其产生的当前函数中捕获，而不能在外层函数中捕获该异常。

   答案：错误。原答案："可以在外层捕获，并且这是最常见的用法"。异常沿调用链向外传播，直到遇到类型匹配的 `catch`。

6. 只要程序中没有 `A a1 = a2;` 和 `A a1(a2);` 形式的代码，类A的拷贝构造函数就不会被调用。

   答案：错误。原答案："参数传递或函数返回时也调用拷贝构造函数"。例如有 `void g(A x);`，调用 `g(a)` 时用 a 拷贝构造形参 x。

7. 在protected继承方式下，派生类对象的指针不能直接转换成指向基类对象的指针。

   答案：正确。原答案："否则基类中的公有成员由不可见变为可见，权限被放大"。补充：这指的是在类外（如 main 里），clang 报 "cannot cast 'PD' to its protected base class"；在派生类自己的成员函数里可以转换。

8. 若静态成员函数中调用了一个函数f，那么f 一定不是虚函数。

   答案：错误（更正：原答案作"对"，理由是"静态成员函数不能是虚函数，因为虚函数入口需要保存在对象中的虚函数表中，而静态成员函数不属于对象"）。原理由讲的是静态函数自己不能是虚函数，和题目问的不是一回事。静态成员函数没有 `this`，不能直接调用本类的虚函数，但可以通过对象、指针或引用调用虚函数，而且照样发生多态：

   ```cpp
   class V {
   public:
       virtual ~V() {}
       virtual void f() { cout << "V::f" << endl; }
       static void s(V* p) { p->f(); }   // 静态成员函数里调用虚函数
   };
   class W : public V {
   public:
       virtual void f() { cout << "W::f" << endl; }
   };
   // W w; V::s(&w); 实测输出 W::f
   ```

9. 若要实例化一个含有引用型数据成员的类，那么只能使用构造函数初始化列表来初始化该数据成员。

   答案：正确。原答案："没有别的办法"。引用必须在定义时绑定，构造函数体里写 `r = x;` 是给引用的对象赋值，不是初始化。补充两个特例：没有构造函数的聚合类可以写 `S s = { x };` 直接初始化引用成员；C++11 起也可以在类内给引用成员写默认初始值。

10. 构造函数的函数体中，不能使用return语句；但在实现该类的自动类型转化函数时，必须有return 语句。

    答案：错误（更正：原答案作"对"）。构造函数体里可以写不带返回值的 `return;` 提前结束，比如 `A(int x) { if (x < 0) return; v = x; }`，实测能正常编译运行；不能写的是带返回值的 return。后半句没问题，类型转换函数 `operator int()` 要返回一个值。

### 三、回答下列各题（每题4分，共20分）

1. 举例说明static关键字的用法和相应目的（至少3种）。

   原答案：

   ```cpp
   void f() { static int a; /*…*/ }   // 函数体内的静态变量，每次调用该函数时值保持不变
   static int a;                     // 全局的静态变量，约束作用域为所在文件
   class A { static int a; /*…*/ };  // A的静态成员，类似全局变量，需用A::a访问
   ```

   补充两种：静态成员函数 `class A { static void g(); };`，不依赖对象，用 `A::g()` 调用，只能直接访问静态成员；写在文件作用域的 `static void h() {}`，函数只在本文件可见。

2. 举例说明类的数据成员在哪些情况下必须在初始化列表中进行初始化（至少3种）。

   原答案：

   - 基类不提供无参的构造函数
   - 成员对象不提供无参的构造函数
   - 有常量成员或引用成员

3. 举例说明虚拟继承的作用和目的。

   原答案：虚拟继承的目的是使基类在派生类中只保留一个副本，从而避免二义性。

   例子（整理补充）：

   ```cpp
   class Person  { public: int id; };
   class Student : virtual public Person {};
   class Teacher : virtual public Person {};
   class TA : public Student, public Teacher {};   // TA 里只有一份 Person
   // TA t; t.id = 7;  不用虚拟继承时这句报二义性
   ```

4. 举例说明成员函数 `A& f( ) const;` 和成员函数 `A& f( );` 的区别。

   原答案：`A& f( ) const` 是常函数，隐含的 this 指针是常指针，因此在 f 中不能修改对象成员的值。举例略。

   补充（整理补充）：

   - 原答案"常指针"的说法不准确。普通成员函数里 `this` 本来就不能被赋值（相当于 `A* const`），常成员函数的区别在于 `this` 指向常量对象，类型相当于 `const A* const`。
   - 常对象只能调用 const 版本；普通对象两个都能调，两个同时存在时优先调用非 const 版本，所以二者可以构成重载。
   - 例子：`const A ca; ca.f();` 调用 const 版本。const 版本里写 `return *this;` 会编译报错（`const A` 不能绑定到 `A&`），实际代码一般写成 `const A& f() const;`。

5. 有类A的对象a，任意给出一种解决方案，使得程序支持下面的表达式：`a=10+a;`

   原答案：

   ```cpp
   class A {
       A(int);  //转换构造函数
       friend const A operator+(const A,const A); //重载+
   };
   ```

   补充：原答案漏写了 `public:`，`A(int)` 在 class 里默认私有，main 里无法用它把 10 转换成 A。`operator+` 必须写成友元或普通函数：写成成员函数时左操作数必须已经是 A 对象，`10 + a` 里的 10 不会被转换。加上 `public:` 并补全函数体后实测，a 原值为 5 时执行 `a=10+a;` 得到 15。

### 四、指出下列程序代码中存在的错误并说明错误原因。（每题5分，共10分）

（带答案版本大题作"指出下列程序代码中存在的错误或不足，说明原因"。）

1. 

   ```cpp
   #include<iostream.h>
   class A  {
   public:
     virtual ~A(  ) { }
     virtual void f( )
       {cout<<"A::f( )"<<endl;}
   };
   class B:public A {
   public:
      void f(int n)
         {cout<<"A::f(int)"<<endl;}
      void g(int m)  { f( ); f(m); }
   };
   void main()
   {
      B b ;
      b.g(1);
   }
   ```

### 七、（共20分，每问题10分）果树年产值（无答案版）

每个品种的果树都有各自的结果期，果树的结果期是指果树从种植到结果经历的年数。在进行经济预算时，一棵果树的年产值与品种、结果期、树龄相关。某果农从2007年1月开始承包果园，目前，果园中有苹果树和桃树，可以根据下表中公式进行年产值预算。为帮助果农估算每年年末果园总年产值，请按要求编写程序：

1. 用类描述苹果树、桃树，设计时必须考虑未来可能种植新的品种，可以添加你认为必要的类，不必考虑果树的死亡情况。

   | 苹果树的预计年产值（结果期=5年） | 桃树的预计年产值（结果期=3年） |
   | --- | --- |
   | `= 0`（`树龄<结果期`） | `= 0`（`树龄<结果期`） |
   | `= 1200+(树龄-结果期)x50`（`结果期<=树龄<=结果期+10`） | `= 1500-(树龄-结果期)x(树龄-结果期-20)x10`（`结果期<=树龄<=结果期+20`） |
   | `= 2000-树龄x60`（`结果期+10<树龄<=结果期+15`） | `= 400`（`树龄>结果期+20`） |
   | `= 200`（`树龄>结果期+15`） | |

2. 作为一个例子，假设果园中只有一棵已生长6年的苹果树、一棵已经生长5年的桃树、一棵已经生长2年的桃树。请利用上一问题的结果，编写完整程序，分别输出果园今年的年总产值和明年的年总产值。

原卷无答案，下面是整理补充。

设计要点：

- 抽象基类 `FruitTree` 保存树龄和结果期，提供"长一岁"和"求年产值"的接口；各品种的公式不同，放进纯虚函数由派生类实现。
- `AppleTree`、`PeachTree` 公有继承 `FruitTree`，构造时把各自的结果期（5、3）传给基类。以后种新品种，再派生一个类即可。
- 果园类 `Orchard` 用基类指针保存所有果树，求总产值时逐个调用虚函数，这部分代码不随品种增加而改动。

```cpp
#include <iostream>
#include <vector>
using namespace std;

class FruitTree {
public:
    FruitTree(int age, int bearingYears) : age(age), bearing(bearingYears) {}
    virtual ~FruitTree() {}
    void Grow() { ++age; }                          // 过一年，树龄加 1
    double Output() const { return OutputAt(age); }
protected:
    virtual double OutputAt(int a) const = 0;       // 按树龄计算年产值
    int age;       // 树龄
    int bearing;   // 结果期
};

class AppleTree : public FruitTree {
public:
    explicit AppleTree(int age) : FruitTree(age, 5) {}
protected:
    virtual double OutputAt(int a) const {
        if (a < bearing) return 0;
        if (a <= bearing + 10) return 1200 + (a - bearing) * 50;
        if (a <= bearing + 15) return 2000 - a * 60;
        return 200;
    }
};

class PeachTree : public FruitTree {
public:
    explicit PeachTree(int age) : FruitTree(age, 3) {}
protected:
    virtual double OutputAt(int a) const {
        if (a < bearing) return 0;
        if (a <= bearing + 20) return 1500 - (a - bearing) * (a - bearing - 20) * 10;
        return 400;
    }
};

class Orchard {
public:
    ~Orchard() {
        for (size_t i = 0; i < trees.size(); ++i) delete trees[i];
    }
    void Plant(FruitTree* t) { trees.push_back(t); }
    double Total() const {
        double sum = 0;
        for (size_t i = 0; i < trees.size(); ++i) sum += trees[i]->Output();
        return sum;
    }
    void NextYear() {
        for (size_t i = 0; i < trees.size(); ++i) trees[i]->Grow();
    }
private:
    vector<FruitTree*> trees;
};

int main() {
    Orchard o;
    o.Plant(new AppleTree(6));
    o.Plant(new PeachTree(5));
    o.Plant(new PeachTree(2));
    cout << "今年总产值: " << o.Total() << endl;
    o.NextYear();
    cout << "明年总产值: " << o.Total() << endl;
    return 0;
}
```

运行结果（把题目给的树龄当作今年的树龄）：

```text
今年总产值: 3110
明年总产值: 4810
```

手算核对：今年苹果树 6 岁，1200+(6-5)×50=1250；5 岁桃树 1500-2×(2-20)×10=1860；2 岁桃树未到结果期，为 0；合计 3110。明年三棵树分别为 1300、2010、1500，合计 4810。

### 二、判断正误，对于你认为错误的论述，说明原因或举出反例。（共20分，每题2分）

参考答案 PDF 把错误的论述标红（下面写"参考答案标红"）。PDF 第 3、4、9 题的题目与定稿不同，定稿这三题是整理补充。

1. 类的所有成员函数都可以访问类中静态成员函数，但静态成员函数不能访问类的非常量成员函数，只能访问类的常量成员函数（用const 修饰的成员函数）。

   答案：错误（参考答案标红后半句）。常成员函数也是非静态成员函数，同样要通过对象调用。静态成员函数没有 `this`，常成员函数和非常量成员函数都不能直接调用；通过对象调用时两种都可以。实测在静态函数里直接调用 const 成员函数，clang 报 "call to non-static member function without an object argument"。

2. 在同一个类中，可以定义重载的成员函数 `int f(int anInt=100);` 和 `void f(int anInt);`。

   答案：错误（参考答案标红）。两个函数参数表相同，只有返回类型不同，不能构成重载（默认参数也不参与区分），clang 报 "functions that differ only in their return type cannot be overloaded"。

3. 私有继承中，基类中所有成员对派生类来说都是不可见的。

   答案：错误（整理补充）。私有继承时，基类的 public 和 protected 成员在派生类中变成 private 成员，派生类的成员函数仍然可以访问；只有基类的 private 成员派生类访问不到（这一点与继承方式无关）。

   （初稿和 PDF 本题作"类的私有成员不能被派生类继承。"参考答案标红，即错误：基类的私有成员也被继承，在派生类对象里占空间，只是派生类不能直接访问。）

4. 只要一个类存在一个公有的无参的构造函数，就一定可以用这个类创建对象。

   答案：错误（整理补充）。反例：抽象类有公有无参构造函数也不能创建对象（clang："variable type 'Abs' is an abstract class"）；析构函数是私有的类，也不能在类外定义局部对象。

   （初稿和 PDF 本题作"派生类的成员函数个数一定多于基类中成员函数的个数。"参考答案标红，即错误：`class D : public B {};` 这样的派生类一个新成员函数也没有。）

5. 类D以public方式继承类B，若在这两个类中以同样的方式分别声明了一个同名的整型成员变量x，那么，为类D的对象分配内存空间时，不需要为类B中声明的x分配空间。

   答案：错误（参考答案标红）。和 2004 级判断第 5 题相同：D 的对象里 `B::x` 和 `D::x` 各有一份。初稿把这道题整题标了红。

6. 在任何情况下，都不可能通过构造函数的初始化列表对类的静态成员变量进行初始化。

   答案：正确（参考答案未标红，PDF 措辞为"类的静态成员变量不能通过构造函数的初始化列表初始化。"）。静态成员变量属于整个类，要在类外定义并初始化，如 `int B::count = 0;`；写进初始化列表 clang 报 "does not name a non-static data member or base class"。

   （初稿本题作"若将基类的析构函数设为私有，那么不能创建其派生类对象。"答案：正确（整理补充）。派生类的构造和析构都要调用基类的析构函数，基类析构函数私有时派生类无权调用，实测定义派生类对象或 `new` 派生类对象都编译不过。例外是基类把派生类声明为友元。）

7. 使用形如 `virtual class A：public class B { };` 的语法可以声明一个虚基类。

   答案：错误（参考答案标红）。`virtual` 写在继承列表里，修饰基类：`class A : virtual public B { };`。

8. 一个函数在基类中没有声明为虚函数，但在派生类中被重写时被声明为虚函数，那么基类中的这个函数也会被看作是虚函数。

   答案：错误（参考答案标红）。虚函数性质只向下传递。基类的 f 不是虚函数，通过基类指针调用 f 时仍然调用基类版本；实测 `B8* p = &d8; p->f();` 输出 `B8::f`。

9. 类中的非静态成员函数越多，则该类产生的对象所占内存空间就越大。

   答案：错误（整理补充）。成员函数的代码全类共享一份，不存放在对象里；实测只有一个 int 成员的类，加 4 个成员函数前后 `sizeof` 都是 4。只有第一个虚函数会让对象多出一个虚表指针。

   （初稿本题作"内联函数可以提高程序执行的效率，但会增加可执行程序的大小。"PDF 改成"如果编译器以内联的方式处理一个函数，则可以提高程序执行的效率，但可能会增加可执行程序的大小。"参考答案未标红，即正确。初稿的说法太绝对：`inline` 只是建议，编译器可以不展开；很短的函数展开后代码反而可能变小。）

10. 若不考虑继承，则protected访问控制等同于private。

    答案：正确（参考答案未标红）。protected 和 private 的区别只在派生类能否访问，不考虑继承时两者都只允许本类成员和友元访问。

### 三、指出下列程序代码片断中存在的不合理之处，并简要说明理由。（共10分，每题2分）

PDF 与定稿题目相同，没有答案，以下为整理补充。每个片段都放进完整程序实际编译过（A 是含成员函数 `f` 的类）。

1. 

   ```cpp
   A* pa;
   pa->f( );
   ```

   pa 没有初始化，是野指针，通过它调用成员函数是未定义行为。f 恰好不访问成员数据时可能"碰巧能运行"，访问数据就可能崩溃。改为 `A* pa = new A;` 或让它指向一个已有对象。

2. 

   ```cpp
   A* pa=new A[10];
   delete pa;
   ```

   `new[]` 分配的数组要用 `delete[] pa;` 释放。用 `delete` 是未定义行为，通常只析构第一个元素，还可能破坏堆；clang 给出警告 "'delete' applied to a pointer that was allocated with 'new[]'"。

3. 

   ```cpp
   A  obj( );
   obj.f( );
   ```

   `A obj( );` 被当成函数声明（一个无参、返回 A 的函数 obj），没有创建对象，`obj.f( )` 编译报错。要调用无参构造函数定义对象，写 `A obj;`。

4. 

   ```cpp
   class A {
       const int a=0, b=0;
   };
   ```

   C++98 不允许在类定义里给非静态数据成员写初值（clang 在 `-std=c++98` 下提示这是 C++11 扩展），const 成员应在构造函数初始化列表里初始化：`A() : a(0), b(0) {}`。C++11 起这种写法合法，但每个对象的 a、b 都固定为 0，这种所有对象共用的常量改成 `static const int a = 0;` 更合理，不用每个对象存一份。

5. 

   ```cpp
   A& f( ){
      return A( );
   }
   ```

   `A( )` 是临时对象，函数返回时就销毁了，返回它的引用是悬空引用。标准 C++ 里非 const 引用不能绑定临时对象，clang 直接报错；即使改成 `const A&` 能编译，引用的对象也已经不存在。改为按值返回：`A f( ) { return A( ); }`。

### 四、回答下列各题（每题4分，共20分）

1. 可以用 `class A;` 的语法形式声明一个类，该语法中并没有指出类的具体内容。请举例说明这种声明形式在编程时有何用处？

   - 这叫前向声明。声明之后、定义之前，A 是不完整类型，只能用来定义指针和引用、声明以 A 为参数或返回值的函数，不能创建对象、访问成员。
   - 用处一：两个类互相引用。
   - 用处二：头文件里只用到某个类的指针或引用时，用前向声明代替 `#include`，减少头文件依赖，改动那个类时少重新编译一些文件。

   ```cpp
   class B;                    // 前向声明
   class A { B* pb; };         // 只用到 B 的指针
   class B { A a; };           // B 里包含 A 的对象，A 必须先完整定义
   ```

2. 说明 `A* const p = new A;` 和 `A * p=new A;` 在含义上有什么不同？

   - `A* const p`：p 是常指针，初始化后不能再指向别的对象（`p = new A;` 编译报错），必须在定义时初始化；但可以通过 p 修改它指向的对象。
   - `A* p`：普通指针，可以随时改指向。
   - 两者都不限制修改对象；不允许通过指针修改对象的是 `const A* p`。

3. 拷贝构造函数的使用场合有哪些？至少列举3种不同情况。（PDF 作"说明拷贝构造函数的使用场合，至少列举3种不同情况。"）

   - 用已有对象初始化新对象：`A a2(a1);`、`A a2 = a1;`、`new A(a1)`。
   - 对象按值传递给函数形参：`void g(A x);` 调用 `g(a1)`。
   - 函数按值返回对象：`A h() { A t; return t; }`（编译器可能省略这次拷贝）。
   - 按值抛出、按值捕获异常；标准容器存入元素（如 `vector<A>` 的 `push_back`）。

4. 如何定义类A，使得它的对象a可以作为函数 `void f(int)` 的实参。

   在 A 中定义类型转换函数 `operator int()`，调用 `f(a)` 时自动转换：

   ```cpp
   class A {
   public:
       A(int v) : val(v) {}
       operator int() const { return val; }   // 类型转换函数，没有返回类型，要有 return
   private:
       int val;
   };
   // A a(100); f(a);  实参 a 被转换成 100
   ```

5. 定义并实现一个类时，在哪些情况下必须使用初始化列表？至少列举３种情况。

   - 有 const 数据成员。
   - 有引用数据成员。
   - 成员对象所属的类没有默认构造函数。
   - 基类没有默认构造函数，需要给基类构造函数传参数。

   （PDF 本题作"把一个类的析构函数设为虚函数有什么意义？"答案同 2004 级第五大题第 3 问：用基类指针 `delete` 派生类对象时，析构函数是虚函数才会先调用派生类的析构函数，否则派生类部分的资源不能释放。）

- 第 4 题"纯虚函数给出缺省实现有什么意义？"要点（整理补充）：纯虚函数可以在类外给出函数体。派生类仍然必须覆盖它（基类还是抽象类），但覆盖版本里可以用 `Base::f()` 显式调用这份缺省实现，复用公共代码，同时强制每个派生类考虑自己的实现。纯虚析构函数必须给出函数体，因为派生类析构时一定会调用它。
