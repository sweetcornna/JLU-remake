## 2002级 A卷（2003年冬）

来源：`历年考试题/2002级C++试题A-2003冬天.doc`，满分 100 分。答案情况：选择题有红字；文档末尾附有一份参考答案（九道大题都有，第七、九题只给了部分代码）；另有 27 条原稿批注。红字、参考答案、批注之间有出入的地方在题下说明。

### 一、单项选择（每题1分，共10分）

1. 下面列出的基类中的哪部分能被派生类自动继承：

   A. 基类中的构造函数　　B. 基类中的虚析构函数　　C. 基类中重载的赋值操作　　D. 基类中的私有成员

   答案：D（参考答案作 D；原卷红字标的是 C，不对）。私有成员会被继承，占着派生类对象的空间，只是派生类不能直接访问。构造函数、析构函数不继承。派生类会隐式生成自己的 `operator=`，把基类的赋值运算隐藏掉：基类定义 `Base& operator=(int)` 后，派生类对象写 `d = 5;` 实测编译报错。

2. 对于全局函数 `int f(void)`，与其等价的函数原型为：

   A. `int& f( );`　　B. `int f( ) const;`　　C. `int* f( );`　　D. `const int f( );`

   答案：D。返回 `int` 这类内置类型的值时，加不加 `const` 用起来一样，调用结果都只能当右值。A、C 返回类型变了；B 的 `const` 只能修饰非静态成员函数，全局函数这样写直接报错。

3. 类 A 中有唯一的一个成员函数 f，且 f 是公有的静态或非静态成员函数，对于类 A 的一个对象 a，执行语句 `a.f(100);` 成功，那么 f 的函数原型不可以是：

   A. `A& f( int, int=50 );`　　B. `void f(int& ) ;`　　C. `const A * f(const int );`　　D. `A f( const int&);`

   答案：B。字面量 100 不能绑定到非常量引用 `int&`（原稿批注："没有被引用的地址"）。D 是常量引用，可以绑定临时量。

4. 关于异常和 C++ 提供的异常处理机制不正确的说法是：

   A. 能够改变程序的执行顺序　　B. 异常可以是对象　　C. 用户不能自定义异常类型　　D. 异常可以用 catch 进行捕捉处理

   答案：C。任何类型都能当异常抛出，自定义异常类很常见。

5. 在不考虑强制类型转换的情况下，关于类中常量成员函数的下列说法不正确的是：

   - A. 常量成员函数中不能修改本类中的非静态数据成员。
   - B. 常量成员函数中可以调用本类中的任何静态成员函数。
   - C. 常量成员函数的返回值只能是 void。
   - D. 若常量成员函数中调用虚函数 f，那么函数 f 在本类中也一定是一个常量成员函数。

   答案：C。常量成员函数的返回类型没有限制。D 是对的：在 `const` 成员函数里通过 `this` 调用非 `const` 的 f，clang 报 `function is not marked const`。

6. 任意一个类，析构函数的个数最多是：

   A. 不限个数　　B. 1　　C. 2　　D. 3

   答案：B。析构函数没有参数，不能重载。

7. 在 C++ 程序中，对象之间的相互通信可以通过：

   A. 继承实现　　B. 调用成员函数实现　　C. 封装实现　　D. 函数重载实现

   答案：B。对象之间"发消息"就是调用对方的成员函数。

8. 下面模板定义中不正确的是：

   - A. `template<class Q> Q F(Q x) { return Q + x; }`
   - B. `template<class Q> Q F(Q x) { return x + x; }`
   - C. `template<class T> T F(T x) { return x * x; }`
   - D. `template<class T> T F(T x) { return x > 1; }`

   答案：A（参考答案）。Q 是类型名，不能参与 `Q + x` 这样的运算，clang 报 `'Q' does not refer to a value`。D 语法没问题，`bool` 会转换成 T 返回，`F(5)` 输出 1。

9. 对类型转换函数说明正确的是：

   - A. 转换函数不能被派生类继承
   - B. 一个类中只能有一个类型转换函数，以免错误调用
   - C. 类型转换函数不能带参数，但可以指定返回类型
   - D. 转换函数能对所属类中对象进行类型转换

   答案：D（更正：参考答案作 A，参考答案下面自己也备注了"答案可能有误，我认为应该是 D"；原卷红字标的是 D）。转换函数会被继承：基类定义 `operator int() const`，派生类对象 `int n = y;` 可以编译运行。一个类可以有多个转换函数（转成不同类型）。转换函数既不能带参数，也不能写返回类型（原稿批注），所以 C 错。

10. 下面关于类的成员函数描述不正确的是：

    - A. 静态成员函数内可以直接访问类的非静态成员数据
    - B. 静态成员函数内可以直接访问类的静态成员数据
    - C. 非静态成员函数可以直接访问类的非静态成员数据
    - D. 非静态成员函数可以直接访问类的静态成员数据

    答案：A。静态成员函数没有 `this` 指针，不知道访问哪个对象的非静态成员。

### 二、判断正误，对于你认为错误的论述，说明原因或举出反例（每题2分，共20分）

1. 在 public 继承方式下，基类中被说明为 protected 和 private 的成员只能被其派生类的成员函数访问，不能被其它的函数访问。

   答案：错误。基类的 private 成员派生类的成员函数也访问不了（参考答案、原稿批注都是这个理由）。另外基类自己的成员函数和友元当然能访问这两类成员。

2. 如果派生类的成员函数的原型与基类中被定义为虚函数的成员函数原型相同，那么，这个函数自动带有虚函数的特性。

   答案：正确。派生类里不写 `virtual` 也是覆盖，照样是虚函数。

3. 一个类中的成员函数重载（overload）可以用 const 修饰符、函数原型的参数个数、对应位置的参数的类型和返回值类型为依据。

   答案：错误。返回值类型不能作为重载依据，只差返回类型的两个函数会报重定义。

4. 无法产生对象的类一定是抽象类。

   答案：错误。反例：构造函数全部声明为 private 或 protected 的类，没有纯虚函数，但在类外也无法产生对象。

5. 在任何形式的继承方式（public、protected 和 private）下，基类类型的指针都可以指向其派生类对象。

   答案：错误。在类外（比如 `main` 里），只有 public 继承时派生类指针才能转成基类指针；private、protected 继承时 clang 报 `cannot cast 'DPriv' to its private base class 'Base'`。（更正：原稿批注判为"正确"，并说 private 继承下"基类指针不能访问派生类对象中的任何成员"，这个说法不成立。）补充：在派生类自己的成员函数或友元里，私有基类的转换是允许的。

6. 若在类 Base 和派生类 Derived 中，分别声明一个同名的私有整型成员变量 `int x;`，那么通过 Derived 类的实例对象，无论如何也访问不到基类 Base 中的成员变量 x 的值。

   答案：错误。Base 里提供一个公有函数（如 `int getX() const { return x; }`），Derived 对象调用 `d.getX()` 拿到的就是 Base 部分的 x。原稿批注还提到友元、类型转换等办法。

7. 在静态成员函数的实现代码体内不能使用 this 指针，在非静态的成员函数实现代码体内可以使用 this 指针。

   答案：正确。原稿批注补充：友元函数也不能用 `this`，它不是成员函数。

8. 在继承过程中，带有虚函数的类作为基类时，该类称作虚基类。

   答案：错误。带虚函数的基类一般叫多态基类。虚基类是用 `virtual` 修饰继承方式的基类，比如 `class B : virtual public A` 里的 A。

9. 在不考虑出现运行时异常的情况下，若一个程序的 main 函数代码体是空，则这个程序不会有输入，也不会产生任何输出结果。

   答案：错误。全局对象、静态对象在 `main` 之前构造，构造函数里可以输出。实测定义一个全局对象，构造函数里 `cout`，`main` 为空也会打印。

10. 构造函数的初始化列表中的内容，不会影响构造对象中成员数据的初始化顺序。

    答案：正确。成员按在类中声明的顺序初始化，和初始化列表里的书写顺序无关。

### 三、回答下列各题（共20分）

1. 说明类中的 public、protected 和 private 成员函数分别在 public、protected 和 private 继承方式下在派生类中的可访问性。（4分）

   答案（参考答案的表格）：

   | 继承方式 \ 基类中的访问权限 | public | protected | private |
   | --- | --- | --- | --- |
   | public 继承 | 可访问，相当于 public | 可访问，相当于 protected | 不可访问 |
   | protected 继承 | 可访问，相当于 protected | 可访问，相当于 protected | 不可访问 |
   | private 继承 | 可访问，相当于 private | 可访问，相当于 private | 不可访问 |

   记法：基类 private 成员在任何继承方式下派生类都不能直接访问；其余成员的权限取"原权限"和"继承方式"中更严的那个。

2. 类的哪些成员在缺省时可以由编译器自动给出？（4分）

   答案：
   - 不带参数的（默认）构造函数
   - 拷贝构造函数
   - 析构函数
   - 赋值运算 `operator=`

   参考答案还写了"相关的 new、delete 运算"，这两个用的是全局版本，对类对象默认可用。C++11 以后还会自动生成移动构造函数和移动赋值运算。

3. 如何判断一个类 A 的两个对象 a1 和 a2 是否是同一个对象？（3分）

   答案：比较地址，`&a1 == &a2` 成立就是同一个对象。（更正：原稿批注另说"或者判断两者的成员变量是否完全一致"，这不对，两个不同对象的内容完全可以相同。）

4. 针对类 A 和类 B，如何设计使得它们的对象可以直接或间接地存放在同一个数组中？（3分）

   答案：让 A 和 B 都从同一个类 X 派生，数组元素类型用 `X*`，数组里存 A、B 对象的地址。（参考答案写"`X*` 或 `X&`"，C++ 没有引用数组，只能用指针。）

5. 对运算符进行重载时，有的运算符只能重载为类的成员函数，有的只能重载为全局函数，还有的两者均可以，针对上三种情况各举一例。（3分）

   答案：
   - 只能是成员函数：赋值 `=`，另外还有 `[]`、`()`、`->`。
   - 只能是全局函数：插入运算符 `<<`、提取运算符 `>>`（左操作数是 `ostream`/`istream`，没法写成自定义类的成员）。
   - 两者均可：`+`、`<` 等。

   （更正：原稿批注把 `+=` 列为"只能重载为成员"，`+=` 也可以写成全局函数。）

6. 在哪些情况下实现一个类的构造函数时，必须使用初始化列表？至少给出三种不同情况。（3分）

   答案：
   - 基类没有不带参数的构造函数，需要显式调用基类带参构造函数。
   - 类中有常量（`const`）数据成员。
   - 类中有引用数据成员。
   - 原稿批注补充：成员对象所属的类没有默认构造函数。

### 四、阅读下面两个类的定义和部分实现代码，完成4个问题（每题3分，共12分）

```cpp
class Base {
public:
	Base(int value=0):x(value) {}
	virtual ~Base() {}
	Base(const Base& rhs):x(rhs.x) {}
	Base& operator =(const Base& rhs)
	{x=rhs.x; return *this;}
private:
	int x;
};

class Derived:public Base {
public:
	Derived(int v):Base(v),y(v) { }
	virtual ~Derived() {}
	Derived(const Derived& rhs);
	Derived& operator=(const Derived& rhs);
private:
	int y;
};
```

（1）实现类 Derived 的赋值运算 `Derived& operator=(const Derived&)`。

参考答案：

```cpp
Derived& operator=(const Derived& aD)
{
	Base::operator=(aD);   // 先让基类部分赋值，x 是 Base 的私有成员，只能这样复制
	y = aD.y;
	return *this;
}
```

（2）实现类 Derived 的拷贝构造函数 `Derived(const Derived&)`。

参考答案：

```cpp
Derived(const Derived& aD)
{
	operator=(aD);
}
```

这样写能用（Base 有默认参数，先构造出 x=0，再由赋值运算复制），更规范的写法是用初始化列表：

```cpp
Derived::Derived(const Derived& rhs) : Base(rhs), y(rhs.y) {}
```

两种写法实测 `Derived d3(d1); d2 = d1;` 后 x、y 都正确复制（输出 `5 5`）。

（更正：原稿批注给的两段代码只复制了 `y`，没有处理基类部分。实测批注版本拷贝构造出的对象 x 为 0（Base 走了默认构造），赋值后 x 保持原值 9 不变。）

（3）拷贝构造函数原型的参数类型说明中，const 修饰符的作用是什么？为什么使用引用的形式？

答案：
- `const`：函数里不会改动被拷贝的对象（原稿批注）；同时常量对象、临时对象也能作为实参被拷贝（参考答案："使实际参数既可以是变量，又可以是常量"）。
- 引用：如果按值传参，传参本身又要调用拷贝构造函数，会无限递归。用引用也省掉一次拷贝。标准 C++ 里写成 `Derived(Derived rhs)` 直接编译报错。

（4）通常在什么情况下，一个类需要自定义并实现拷贝构造函数和赋值运算？

答案：类里有指针（或引用）数据成员，特别是指针指向构造时动态申请的堆内存时（原稿批注："需要用到堆内存时"）。编译器生成的版本只做浅拷贝，两个对象会共用同一块内存，析构时重复释放，所以要自己写深拷贝。

### 五、写出下面程序的运行结果（5分）

```cpp

class A {
public:
	A( )  { cout << "A" << endl; }
	~A( ) { cout << "~A" << endl; }
};

class B  {
public:
	B( )	   { f(  );  cout << "B" << endl;}
	virtual void f( )  { cout << "B::f" << endl; }
	virtual ~B( )    { cout << "~B" << endl; }
};

class D: public B {
public:
	D( )	     { cout << "D" << endl;   }
	void f( )	 { cout << "D::f" << endl;  }
	virtual ~D( ) { cout << "~D" << endl; }
private:
	A  a;
};

void main( )
{
	B* pB = new D;
	pB->f( );
	delete pB;
}
```

原卷把 `class D` 误排成 `Class D`，已改正。

运行结果：

```text
B::f
B
A
D
D::f
~D
~A
~B
```

参考答案和原稿批注给的结果一致，编译运行核对无误。

- B 的构造函数里调用虚函数 `f()`，这时 D 部分还没构造，调用的是 `B::f`。

- 析构函数是虚的，`delete pB` 从 D 开始：D 的析构函数体、成员 a、基类 B，和构造顺序相反。

### 七、为类 A、B、C 补充定义，使 add 函数能工作（10分）

题目：下面是对类 A、类 B 和类 C 的部分定义和函数 add 的完整定义及实现。其中，`void add(A& obj1,A& obj2)` 函数实现体中的语句 `obj1+obj2` 的含义为：obj1 和 obj2 中对应的同名成员变量 va、vb、vc 分别相加，若对象中无相应的成员变量，则按 0 处理，即对于 `add(a1,a2)` 含义为 `a1.va=a1.va+a2.va, a1.vb=a1.vb+a2.vb, a1.vc=a1.vc+a2.vc`，若其中的某数据分量不存在则按 0 计算。为保证 add 函数功能，必须对这三个类进行必要的补充，请完整实现（包括定义声明和实现）它们。

```cpp
class A{
private:
   int va;
};

class B:public A{
private:
   int vb;
};

class C:public B{
private:
   int vc;
};

void add(A& obj1,A& obj2)
{
  obj1=obj1+ obj2;
}
```

参考答案思路：`add` 的两个参数都是 `A&`，实际可能是 A、B、C 任一种对象，所以 `+` 必须写成虚函数，再用虚函数 `get_va`、`get_vb`、`get_vc` 取对方的分量，没有的分量在 A 里默认返回 0。参考答案代码：

```cpp
class A {
private:
	int va;
public:
	A(int n):va(n) {}
	virtual int get_va(){return va;}
	virtual int get_vb(){return 0;}
	virtual int get_vc(){return 0;}
	virtual A& operator+(A& obj){va+=obj.get_va();return *this;}
	void printf(){cout << get_va() <<','<<get_vb()<<','<<get_vc()<<endl;}
};

class B: public A {
private:
	int vb;
public:
	B(int n1,int n2):A(n1),vb(n2){}
	virtual int get_vb(){return vb;}
	virtual A& operator+(A& obj){
		A::operator+(obj);
		vb+=obj.get_vb();return *this;}
};

class C: public B {
private:
	int vc;
public:
	C(int n1,int n2,int n3):B(n1,n2),vc(n3){}
	virtual int get_vc(){return vc;}
	virtual A& operator+(A& obj){B::operator+(obj);vc+=obj.get_vc();return *this;}
};
```

说明：
- 这里的 `operator+` 直接把结果累加到左操作数上并返回它自己，`obj1=obj1+obj2` 最后是自赋值，没有副作用。
- 实测：`A a(1); B b(10,20); C c(100,200,300);` 依次执行 `add(c,b)`、`add(b,c)`、`add(a,c)`、`add(c,a)`，各对象分量依次为 `110,220,300`、`120,240,0`、`111,0,0`、`221,220,300`，符合题意。

（更正：原稿批注给的代码在每个类里各写了一个非虚的 `operator+`，只加本类新增的那个分量。`add` 里 `obj1`、`obj2` 的静态类型都是 `A&`，永远只调用 `A::operator+`，vb、vc 从来不会相加。实测 `add(c1,c2)` 之后 `c1.vc` 仍是 5。）

### 八、去掉类 D 的多重继承（8分）

题目：下面是一段完整的程序，其中类 D 由类 B1 和类 B2 经过多重继承派生，请你只改变类 D 的定义和实现，使其去掉多重继承，其它代码不作任何变化，并保持程序原有功能不变。

```cpp
class B1 {
public:
	virtual void f( ) const{ }
};

class B2 {
public:
	virtual void g( )const { }
};

class D : public B1,public B2 {
public:
	void func( ) const{ f ( ); g( ); }
};

void F(const B1& aB1) {
	aB1.f( );
}

void FF(const B2& aB2) {
	aB2.g( );
}

void main( )  {
	D d; 	d.func( );
	F(d);	FF(d);
}
```

答案思路（参考答案）：D 只保留对 B1 的 public 继承，B2 改成 D 的成员对象；`FF(d)` 需要把 D 转成 `const B2&`，给 D 加一个类型转换函数。

参考答案原文的代码写成 `D(const &B2 aB2): m_B2(aB2);`，大小写也不统一（`m_B2`/`m_b2`），编译不过；而且它要求构造时传入 B2，`main` 里的 `D d;` 就不能用了。按同样思路改正后（已编译运行，在 f、g 里加输出后四次调用都正确转发）：

```cpp
class D : public B1 {
public:
	void func( ) const { f( ); m_b2.g( ); }
	operator const B2&( ) const { return m_b2; }   // 让 FF(d) 能拿到 B2 部分
private:
	B2 m_b2;
};
```

原稿批注给了另一种写法：B1、B2 都改成成员，D 里提供 `operator B1&()`、`operator B2&()` 两个转换函数，再写 `f()`、`g()` 转发给成员。这个版本也能编译运行，结果相同。

### 九、设计简单字典类（10分）

题目：类 L 的对象 objL 和类 R 的对象 objR 构成一个二元组 (objL,objR)，把其中的一个对象称作左元，如 objL；另一个称作右元，如 objR。一个简单字典（Dictionary）由若干个这样的二元组按一定条件构成，其条件是：所有二元组的左元类型都是 L，所有二元组的右元类型都是 R；任何两个二元组的左元的值（对象内容）不能相同，右元的值可以相同；一个字典具有的基本操作是：在满足前述条件约束下，可将任何两个对象构成的二元组加入字典中；任给一对象，可知它是否作为左元出现在字典中，若在，可返回与其对应的右元。现请你定义并实现这样的字典类，在 main 函数中给出使用这个字典的例子代码。不用考虑模板，允许将二元组中的元素设计成指针或引用形式。

参考答案思路：
- 类 `Pair` 保存一个二元组，成员是 `L*` 和 `R*`，提供 `getL()`、`getR()`。
- 类 `Dictionary` 用数组保存若干 `Pair`，记录当前个数。
- 加入：先查左元是否已存在，不存在才加入。
- 查询：逐个比较左元，找到返回对应右元，找不到返回 0。

参考答案给的是不完整的示意代码，有 `reuturn`、`line`/`lines`、`Rows`/`rows` 这类笔误，比较左元时比的是指针地址（题目要求比较对象内容，参考答案在注释里提到可以比较 `getVal()`），找到后还 `new` 了一个右元的副本返回，会泄漏内存。按原思路整理成能编译的版本如下（L、R 是为了演示补的示例类，只要求 L 能用 `==` 比较内容）：

```cpp
#include <iostream>
#include <cstring>
using namespace std;

// 示例用的左元、右元类型
class L {
public:
	L(const char* s = "") { strncpy(word, s, 31); word[31] = '\0'; }
	bool operator==(const L& other) const { return strcmp(word, other.word) == 0; }
	const char* get() const { return word; }
private:
	char word[32];
};

class R {
public:
	R(int v = 0) : value(v) {}
	int get() const { return value; }
private:
	int value;
};

class Pair {
public:
	Pair(L* l = 0, R* r = 0) : aL(l), aR(r) {}
	L* getL() const { return aL; }
	R* getR() const { return aR; }
private:
	L* aL;
	R* aR;
};

class Dictionary {
public:
	Dictionary() : lines(0) {}
	// 左元内容已存在或字典已满时返回 false
	bool add(L* aL, R* aR) {
		if (find(aL) != 0 || lines >= MAX) return false;
		rows[lines++] = Pair(aL, aR);
		return true;
	}
	// 找到返回对应右元，找不到返回 0
	R* find(const L* aL) const {
		for (int i = 0; i < lines; i++)
			if (*rows[i].getL() == *aL) return rows[i].getR();
		return 0;
	}
private:
	enum { MAX = 200 };
	Pair rows[MAX];
	int lines;
};

int main() {
	L apple("apple"), pear("pear"), apple2("apple");
	R one(1), two(2);
	Dictionary dict;
	cout << dict.add(&apple, &one) << endl;   // 1
	cout << dict.add(&pear, &one) << endl;    // 1，右元可以相同
	cout << dict.add(&apple2, &two) << endl;  // 0，左元内容重复
	R* r = dict.find(&apple2);
	if (r) cout << apple2.get() << " -> " << r->get() << endl;
	L banana("banana");
	if (!dict.find(&banana)) cout << "banana not found" << endl;
	return 0;
}
```

运行结果：

```text
1
1
0
apple -> 1
banana not found
```

原稿批注给的是用 `std::map` 实现的模板类。题目说了不用考虑模板，而且 `std::map` 要求左元类型能用 `<` 比较，可以当作思路参考。

### 一、用简短语言回答下列问题（共20分，每题2分）

下面的答案取自原稿批注，逐条核对过，有问题的地方写了更正。

1. 如果表达式中出现 `a::b` 的形式，则 a 可能是什么样的语言成分。

   答案：
   - 类名（包括 struct、union），如 `A::count`、`Base::f()`。
   - 命名空间名，如 `std::cout`。
   - a 也可以省略，`::b` 表示全局作用域里的 b。

   （更正：原稿批注还写了"类的对象名"，不对。`obj::b` 编译报错 `'obj' is not a class, namespace, or enumeration`，对象访问成员用 `.` 或 `->`。）

2. 已知 A 是某种类型，且有定义：`A * p;` 则表达式 `p+1` 中 1 所表示的字节数是多少？请用表达式给出。

   答案：`sizeof(A)`。指针加 1 跳过一个 A 类型对象的大小。

3. 静态数据成员应该在程序的什么位置进行初始化？

   答案：在类外、全局作用域里定义并初始化，写法是 `类型 类名::成员名 = 初值;`，例如 `int Time::count = 0;`。一般放在类的实现文件（.cpp）里，不放在头文件里，避免重复定义。

4. 类的 protected 访问权限下的成员和 private 访问权限下的成员的不同点是什么？

   答案：protected 成员可以被派生类的成员函数（和友元）访问，private 成员派生类不能直接访问。对类外的普通函数来说，两者都不能访问。

5. C++ 程序中抽象类的标志是什么？

   答案：类中至少有一个纯虚函数，即声明后面加 `= 0` 的虚函数，如 `virtual float getArea() const = 0;`。

6. 如何定义的函数可以将其调用结果作为赋值运算的左值？

   答案：返回类型是（非常量）引用的函数，如 `int& min(int& a, int& b);`，可以写 `min(x, y) = 100;`。

7. new 运算和 malloc 函数都可以申请空间，它们的主要区别是什么？

   答案：
   - new 分配后会调用构造函数初始化对象，malloc 只分配原始内存。
   - new 按类型自动计算大小，返回该类型的指针；malloc 要自己写字节数，返回 `void*`，需要强制转换。
   - new 是运算符，可以重载；malloc 是库函数。
   - new 申请的用 delete 释放（会调用析构函数），malloc 申请的用 free 释放。

8. 解决多重继承中名称冲突的问题的主要手段是什么？

   答案：
   - 用作用域运算符写明是哪个基类的成员，如 `d.B1::f()`。
   - 在派生类中重新定义同名成员，把基类的同名成员隐藏掉。
   - 多个基类又有共同基类（菱形继承）时，用虚基类（`virtual public`）让公共基类只保留一份，消除二义性。

9. 基类的哪些成员是不可以被子类继承的？

   答案：构造函数（包括拷贝构造函数）、析构函数、赋值运算。原稿批注还写了友元函数：友元不是成员，友元关系也不会继承。

10. 静态成员函数不可以访问所在类的非静态成员的主要原因是什么？

    答案：静态成员函数不依赖对象调用，没有 `this` 指针，不知道要访问哪个对象的非静态成员。

### 二、判断对错（共20分）

原卷写的是"每题10分"，10 道题共 20 分，应为每题 2 分。答案取自原稿批注，已核对。

### 七、把 float 数分解为整数和小数部分（5分）

原卷有几处排版错误，已改正：`Class Circle` 改 `class`，`pubic` 改 `public`；Point、Circle、GraphicContainer 三处的 `};` 被排进了行尾注释里，已移出。

答案（整理补充）：

- 数组里存的是 `Graphic*`，只复制指针（浅拷贝）会让两个容器共用同一批图形对象，析构时重复释放。
- 深拷贝要新建每个图形的副本，但拷贝构造函数只知道元素是 `Graphic*`，不知道实际是 Circle 还是 Rectangle，没法直接 `new Circle(...)`。
- 解决办法：在 Graphic 里增加纯虚函数 `clone()`，每个子类返回 `new 子类(*this)`，按实际类型复制自己（"虚拷贝构造"）。同时给 Graphic 加虚析构函数，通过基类指针 delete 才安全。

```cpp
#include <iostream>
using namespace std;

class Point {
public:
	Point(float x = 0, float y = 0) : m_x(x), m_y(y) {}
	float getX( ) const { return m_x;}
	float getY( ) const { return m_y;}
private:
	float m_x;  float m_y;  //横纵坐标
};

class Graphic {
public:
	virtual float getArea( ) const = 0;
	virtual Graphic* clone( ) const = 0;   // 新增：复制自己
	virtual ~Graphic( ) { }                // 新增：虚析构
};

class Circle: public Graphic {
public:
	Circle(float r, const Point& c) : m_radius(r), m_centrePoint(c) {}
	float getArea( ) const { return 3.14159f * m_radius * m_radius; }
	Graphic* clone( ) const { return new Circle(*this); }
private:
	float  m_radius;//半径
	Point  m_centrePoint;//圆心
};

class Rectangle : public Graphic {
public:
	Rectangle(const Point& ul, const Point& br) : m_upLeftPoint(ul), m_bottomRightPoint(br) {}
	float getArea( ) const {
		float w = m_bottomRightPoint.getX() - m_upLeftPoint.getX();
		float h = m_upLeftPoint.getY() - m_bottomRightPoint.getY();
		return w * h;
	}
	Graphic* clone( ) const { return new Rectangle(*this); }
private:
	Point m_upLeftPoint;//左上点
	Point m_bottomRightPoint;//右下点
};

class GraphicContainer {
public:
	GraphicContainer( ) {m_sum =0; }
	GraphicContainer(const GraphicContainer& );
	~GraphicContainer( ) { for (int i = 0; i < m_sum; i++) delete m_buffer[i]; }
	void add(const Graphic& g) { if (m_sum < 100) m_buffer[m_sum++] = g.clone(); }
	float totalArea( ) const {
		float s = 0;
		for (int i = 0; i < m_sum; i++) s += m_buffer[i]->getArea();
		return s;
	}
private:
	GraphicContainer& operator=(const GraphicContainer&);  // 本题不要求，先禁用
	Graphic * m_buffer[100];  int  m_sum; //m_buffer中存放有效数据的个数。
};

// 题目要求的拷贝构造函数
GraphicContainer::GraphicContainer(const GraphicContainer& other)
{
	m_sum = other.m_sum;
	for (int i = 0; i < m_sum; i++)
		m_buffer[i] = other.m_buffer[i]->clone();   // 按实际类型深拷贝
}

int main()
{
	GraphicContainer c1;
	c1.add(Circle(1, Point(0, 0)));
	c1.add(Rectangle(Point(0, 2), Point(3, 0)));
	GraphicContainer c2(c1);
	cout << c1.totalArea() << " " << c2.totalArea() << endl;
}
```

```text

```

### 一、单项选择（共20分，每题2分）

1. 已定义了一个类 A 并有语句 `A* pa=new A(5);` 那么以下说法正确的是：

   - A. 该语句会创建 A 类的一个对象，并将此对象的地址赋给指针 pa；
   - B. 该语句会创建 A 类的 5 个对象，且它们的地址是连续的；
   - C. 当指针变量 pa 超出其作用域时，pa 和为对象分配的空间都将被自动释放；
   - D. 类 A 中一定有一个显式定义的构造函数和一个显式定义的虚析构函数；

   答案：A。`new A(5)` 用参数 5 构造一个对象；创建 5 个对象要写 `new A[5]`。pa 超出作用域时只有指针变量本身消失，堆上的对象要手动 `delete`。类 A 有一个能接受 int 的构造函数就行，不要求虚析构函数。

2. 定义类 A 的非静态成员函数 `A& f(A& one)` 时，需有语句 `return exp;` 则 exp 不能是：

   A. 类 A 中类型为 A 的静态数据成员　　B. f 中用语句 `A a = one;` 定义的量 a　　C. one　　D. `*this`

   答案：B。a 是局部对象，函数返回后就销毁了，返回它的引用是悬空引用。静态成员、参数引用的对象、`*this` 在函数返回后都还存在。

3. 在一个类中，下列哪些成员可以是多个？

   A. 无参构造函数　　B. 析构函数　　C. 原型相同的非静态成员函数　　D. 静态成员函数

   答案：D。无参构造函数、析构函数只能有一个；原型相同的函数是重复定义。

4. 对类 T 中的下列成员，若不考虑代码优化，一般来说它们中的哪个执行起来最慢？

   A. 缺省的无参构造函数　　B. 缺省的拷贝构造函数　　C. `T f( ) { T t; return t; }`　　D. 不能判定 A、B、C 哪个最慢

   答案：C。不优化时，C 要先默认构造局部对象 t，返回时再拷贝构造一个临时对象，还要析构 t，工作量包含了 A 和 B。

5. 对函数原型为 `int& min(int& a, int& b);` 的全局函数，下列语句块哪个是错误的：

   - A. `int x=10,y=5;    min(x,y)=100;`
   - B. `int x=10,y=5, z;  z=min(x,y+=x);`
   - C. `int x=10,y=5;    min(x,10)=y;`
   - D. `int x=10,y=5;    x=min(x,y);`

   答案：C。字面量 10 不能绑定到非常量引用 `int&`，实测报 `no matching function for call to 'min'`。（原稿批注的理由写成"min(x,10) 的返回值不一定是整型引用"，没说到点上。）B 能编译：C++ 里 `y+=x` 的结果是左值 y，实测 z 为 10。A 执行后 y 变成 100。

6. 关于拷贝构造函数错误的说法有：

   - A. 拷贝构造函数是一种特殊的构造函数，且不能在类中进行函数重载。
   - B. 若自定义派生类的拷贝构造函数，那么也必须自定义基类的拷贝构造函数。
   - C. 拷贝构造函数只能有一个参数，且为常量引用或非常量引用。
   - D. 拷贝构造函数不允许在函数体中使用 return 语句。

   答案：B（解答参考、红字一致）。基类用编译器生成的拷贝构造函数就行，派生类的拷贝构造函数在初始化列表里调用它即可。

   提示：严格按标准，A、C、D 也不准确。一个类可以同时有 `X(X&)` 和 `X(const X&, int n = 0)` 两个拷贝构造函数（重载），后者还带了有默认值的第二个参数；构造函数体里可以写不带值的 `return;`。这三点实测都能编译运行。考试按 B 答。

7. 下列对虚基类声明正确的是：

   A. `class virtual B: public A`　　B. `class B: virtual public A`　　C. `class B: public A virtual`　　D. `virtual class B: public A`

   答案：B。`virtual` 写在继承方式前后都可以（`public virtual A` 也对），但必须在基类名前面。

8. 若有语句 `A*const p=new B;`，其中类 B 是从类 A 直接派生得到的，那么下列说法错误的是：

   - A. 若要执行语句 `p->f( );`，那么类 A 中一定有一个与 `f( )` 函数匹配的函数声明。
   - B. 类 B 一定是通过 public 继承方式从类 A 派生的。
   - C. 类 B 的构造函数中，至少有一个无参的或提供全部缺省参数的构造函数。
   - D. 通过指针 p，只能访问类中的常量成员函数或静态成员函数。

   答案：D（解答参考作 D；更正：原卷红字标的是 B）。`A*const p` 是指针本身为常量，指向的对象不是常量，通过 p 可以调用非 `const` 成员函数，实测 `p->f()` 调用非常量成员函数正常。A 对：编译时按 p 的静态类型 A 查找 f。C 对：`new B` 不带参数。B 在类外成立，类外只有 public 继承才能把 `B*` 转成 `A*`（只有写在 B 自己的成员函数里，私有继承才允许这样转换）。

9. 下面说明的哪个数据不能作为类 T 的数据成员定义。

   A. `T* pT`　　B. `class Q{ } q1,q2;`　　C. `static T t;`　　D. `const T t;`

   答案：D（解答参考作 D；更正：原卷红字标的是 C，原稿批注说 C "会形成无限递归"）。在类 T 的定义里 T 还是不完整类型，非静态成员不能是 T 类型（加不加 `const` 都一样），实测报 `field has incomplete type 'const T'`。静态成员不占对象空间，只是一个声明，可以是本类类型，`static T t;` 实测能编译，需要在类外再定义。A 是指针，可以；B 在类里定义嵌套类 Q 并声明两个 Q 类型成员，也可以。

10. 下列哪种运算符可以被重载：

    A. `sizeof`　　B. `::`　　C. `?:`　　D. `[ ]`

    答案：D。`sizeof`、`::`、`?:`、`.`、`.*` 不能重载。

### 二、回答下列各题，可以举例说明（共15分，每题3分）

1. 说明基类中的 public、protected 和 private 成员分别在 public、protected 和 private 继承方式下在派生类中的可访问性。

   解答参考："重点是基类中的任何 private 在派生类中都是不可访问的。"

   完整答案（原稿批注）：
   - public 继承：基类的 public 成员在派生类中仍是 public，protected 仍是 protected，private 不可访问。
   - protected 继承：基类的 public、protected 成员在派生类中都变成 protected，private 不可访问。

2. 若类 A 有私有数据成员 `int n`，哪些情况下，在一个函数的函数体中能够直接访问 A 类的数据成员 n。（至少三种）

   答案（原卷题目里红字给出的例子，解答参考相同）：
   - a) A 的非静态成员函数访问本对象的 n：`void A::f( ) { int k=n;}`
   - b) A 的成员函数访问同类其他对象的 n：`void A::g(A& one) { n+=one.n; }`
   - c) A 的友元函数：`int h(A& one) {return one.n;}`

   还可以补充（整理补充）：A 的友元类的成员函数；A 的静态成员函数通过对象访问，如 `static void s(A& one) { one.n = 0; }`。

3. 哪些情况下，定义构造函数时必须使用初始化列表。（至少三种）

   答案（解答参考）：
   - a) 有常量数据成员
   - b) 有引用数据成员
   - c) 使用基类的带参数的构造函数初始化

   还可以补充：成员对象所属的类没有默认构造函数。

4. 将一个基类的析构函数定义为虚函数的作用和目的是什么？

   答案：
   - 解答参考：如基类 A、子类 B，`A* p=new B;` 当 `delete p;` 时，若无虚析构函数，只析构基类部分。
   - 原稿批注补充：派生类的析构函数不会被调用，派生类里申请的资源得不到释放，造成内存泄漏。

### 三、判断正误，只需回答"正确"或"错误"（共10分，每题1分）

解答参考："2468 正确，其他错误"。下面补上理由。

1. this 指针既可以是指向常量对象的非常量指针，也可以是指向非常量对象的常量指针。

   答案：错误。this 本身不能被修改（`this = 0;` 实测报 `expression is not assignable`），在任何成员函数里都是常量指针：普通成员函数中相当于 `A* const`，常量成员函数中相当于 `const A* const`。原卷红字标出了"非常量指针"，批注写"常量指针"。

2. 即使不创建类的实例对象，也可以在 main 函数中访问该类的公有静态成员函数。

   答案：正确。直接写 `类名::函数名()` 调用。

3. 在一个函数体内不允许定义其它函数，同样在一个类中也不允许定义其它类。

   答案：错误。函数体内确实不能定义函数，但类里可以定义嵌套类，函数体里也可以定义局部类，实测都能编译。（更正：原稿批注写"函数和类都可以嵌套"，C++ 里函数不能嵌套定义。）

4. 若想在一个 cpp 文件中使用一个模板类，那么在预编译后，此文件必须含有该模板类的全部声明和定义。

   答案：正确。编译器要在使用模板的地方按实际类型生成代码，所以必须看到完整定义，模板类一般整个写在头文件里。

5. 在捕获异常时，异常会进行自动类型转换并按照异常类型的同一性进行匹配。

   答案：错误。catch 匹配不做普通的类型转换，实测 `throw 1;` 不会被 `catch (double)` 捕获。只允许少数转换，比如派生类异常对象被基类类型的 catch 捕获。

6. 一个抽象类的后裔类，既可以是抽象类，也可以是具体类。

   答案：正确。派生类实现了全部纯虚函数就是具体类，否则仍是抽象类。

7. 类 A 中的转换函数可定义为：`int operator A( ) const {return 0;}`。

   答案：错误。转换函数不能写返回类型（原卷红字标出了 `int`），实测报 `conversion function cannot have a return type`。正确写法如原稿批注：`operator int( ) const {return 0;}`。

8. 类的多个实例对象可共享本类的虚拟表。

   答案：正确。虚函数表每个类只有一份（原稿批注："在静态内存中存储"），同类的各个对象里的虚表指针都指向它。

9. 用 const 修饰的成员函数只能通过常量对象调用。

   答案：错误。非常量对象也能调用 `const` 成员函数，实测通过。反过来，常量对象只能调用 `const` 成员函数。

10. 类 B 是类 A 的派生类，类 C 是类 A 的友员类，那么类 C 也是类 B 的友员类。

    答案：错误。友元关系不能继承，C 访问 B 自己新增的私有成员，实测报 `'own' is a private member of 'B'`。

### 四、指明下列各程序中存在的不符合 C++ 语言规范之处（每题一处），说明你的理由或依据（25分，每小题5分）

解答方式可参考下面的例子。

```cpp
// 例子程序
#include <iostream.h>
class  A  {
protected:
	void f( ) { cout << "A::f( )" << endl;}
};
void main( )  {	A a; 	a.f( );   }
```

对例子程序可以解答如下：成员函数 f 被说明成 protected，这与 main 函数中对它的使用：`a.f( )` 语句不符。理由是：一个类中 protected 访问权限下的成员除了可用于实现该类、实现该类的派生类或后裔类、实现友员外，不能被使用。

（1）

```cpp
#include <iostream.h>
class Complex  {
public:	Complex(float r=0.0,float i=0.0)
		: rPart(r), iPart(i)  { 	}
private:	float rPart;	float iPart;
};

void main( )  {
	Complex c1;
Complex c2(3.14);
	Complex c3(c2);
c1 = c2;
	cout << c1 << c2 <<c3 << endl;
}
```

答案：错在 `cout << c1 << c2 <<c3 << endl;`。解答参考：没有针对插入运算符 `<<` 进行关于 Complex 类型数据（对象）的定义（运算符重载）。实测报 `invalid operands to binary expression ('ostream' and 'Complex')`。

改法：在类里加友元函数

```cpp
friend ostream& operator<<(ostream& os, const Complex& c)
```

```cpp
{
```

```cpp
      {cout<<n<<" ";}

    int n;

         {array[0]=new A(n1);  array[1]=new A(n2); }

{ delete array[0];  delete array[1];  }

{

           array[1]->Show( );
        }

```

原卷第二行多打了一个 `clas`（写成 `clas class  A`），已删去。

1）（5分）定义并实现类 B 的赋值函数，使得类 B 对象间能够进行深赋值。

2）（5分）定义并实现类 B 的完成深拷贝的拷贝构造函数。

答案（解答参考，原稿批注相同）：

```cpp
    B(const B& rhs) {
        array[0]=new A(*rhs.array[0]);
        array[1]=new A(*rhs.array[1]);
    }
    B& operator=(const B& rhs) {
        if (this!=&rhs) {
            delete array[0];delete array[1];
            array[0]=new A(*rhs.array[0]);
            array[1]=new A(*rhs.array[1]);
        }
        return *this;
    }
```

- 实测 `B b1(1,2), b2(3,4); B b3(b1); b2 = b1; b1 = b1;` 后三个对象都输出 `1 2`，程序正常结束。

### 八、重新设计类 B 和函数 f（共10分）

题目：小王编写一个程序时，定义了类 B 和全局函数 f，部分代码如下：

```cpp
class B {
  public:
B(int n):data(n) {}
int Data( ) const {return data;}
void g1( );
    void g2( );
void g3( );
  private:
const int data;
};

void f( B& b ) {
int condition= b.Data( );      if(condition ==1)    { b.g1( );}
else if(condition ==5) { b.g2( );}
else if(condition == 9) { b.g3( );}
}
```

当把此程序交给用户试用时，针对函数 f，用户提出了一项新的要求：当 condition 为 100 时，依次执行 b 的成员函数 `g1( )` 和 `g2( )`。经过进一步了解，小王获悉：以后可能还要增加处理 condition 的值是其它数值时的情况，但这些需要分别处理的不同条件值的个数肯定不多。小王希望他写出的代码既能满足上述要求，又不用每次都改写 f 的代码。请你帮小王重新设计，使得新设计能够满足小王的愿望。简要说明你的设计思想，给出实现代码。

解答参考：将 B 类作为一个基类，并由它派生出条件分别为 1、5、9 等的子类。

设计思想：
- 在 B 中增加虚函数 `process()`，表示"这个对象按自己的条件该做什么"，默认什么也不做；析构函数设为虚函数。
- 每个条件值对应一个子类，在子类构造函数里把条件值传给 B，在 `process()` 里调用相应的 g 函数。
- f 只调用 `b.process()`，靠动态绑定执行对应子类的版本。以后新增条件时只加一个子类，f 不用改。

实现代码（整理补充，已编译运行）：

```cpp
#include <iostream>
using namespace std;

// 基类：保留原来的数据和 g1/g2/g3，把"按条件做什么"做成虚函数
class B {
public:
	B(int n) : data(n) {}
	virtual ~B() {}
	int Data( ) const { return data; }
	void g1( ) { cout << "g1 "; }
	void g2( ) { cout << "g2 "; }
	void g3( ) { cout << "g3 "; }
	virtual void process( ) {}          // 默认什么也不做
private:
	const int data;
};

class B1 : public B {                   // condition == 1
public:
	B1( ) : B(1) {}
	void process( ) { g1( ); }
};
class B5 : public B {                   // condition == 5
public:
	B5( ) : B(5) {}
	void process( ) { g2( ); }
};
class B9 : public B {                   // condition == 9
public:
	B9( ) : B(9) {}
	void process( ) { g3( ); }
};
class B100 : public B {                 // 新需求：condition == 100
public:
	B100( ) : B(100) {}
	void process( ) { g1( ); g2( ); }
};

// f 以后不用再改
void f( B& b ) {
	b.process( );
}

int main( ) {
	B1 b1; B5 b5; B9 b9; B100 b100;
	f(b1); f(b5); f(b9); f(b100);
	cout << endl;
}
```

运行结果：

```text
g1 g2 g3 g1 g2
```

另一种思路：不派生子类，在 B 里放一张"条件值到成员函数指针序列"的小表，f 按 `Data()` 查表依次调用；新增条件时只往表里加一行。

### 三、判断下列的论述是否正确（回答：正确或错误），对于你认为错误的论述，说明你判断的理由（可以举反例）（20分，每题4分）

1. 假设类 D 以 public 继承方式继承了类 B，f 是子类 D 中定义的一个非静态成员函数，在包括 B 在内的任何一个 D 的祖先类中没有关于 f 的定义。那么，无论 f 如何实现，对于在 main 函数中用子类 D 说明产生的对象 d 来说，它在执行 f 时，永远不会直接或间接地访问到（它所拥有的）在类 B 中以 private 形式说明的数据成员。

   答案：错误。f 虽然不能直接访问 B 的私有数据，但可以调用 B 的 public 或 protected 成员函数间接访问。反例：B 有私有成员 x 和公有函数 `int getX() const { return x; }`，D 里写 `int f() const { return getX(); }`，`d.f()` 实测返回了 B 里 x 的值。原稿批注也判错，理由写的是"可以使用友元函数"，那需要 B 事先把 D 声明为友元，调用 B 的公有函数更直接。

2. 类 A 有一个非静态的成员函数 f，其函数原型是：`void A::f( ) const`，则该函数被调用时，一定是通过类 A 或类 A 的某后裔类的一个用 const 修饰符说明的常量对象调用的。

   答案：错误。非常量对象也可以调用常量成员函数，实测 `A a; a.f();` 正常。`const` 只表示 f 里不能修改对象的数据成员（原稿批注）。

3. 类 A 有一个非静态的成员函数 f，若其函数原型是：`void A::f(const int& anInt)`，那么，该函数被调用时，形式参数 anInt 是实际参数的引用，不需要为它分配空间，并且在执行过程中，不会改变实际参数的数值。若把 f 的函数原型改变为：`void A::f(int anInt)`，则形式参数 anInt 是实际参数的一个拷贝，该函数被调用时，需要为 anInt 分配空间，并用实际参数为它初始化。如果不考虑是否需要为参数 anInt 分配空间，并且，在 f 的函数体内没有对参数 anInt 进行任何数值改变的语句，则用这两种方式定义的函数 f 的作用是一样的。

   答案：错误（更正：原稿批注判为"正确"）。f 虽然不直接改 anInt，但可能通过别的途径改掉实参，引用版本能看到这个变化，拷贝版本看不到。反例：

   ```cpp
   class A {
   public:
       A() : n(5) {}
       void byRef(const int& anInt) { n = 0; cout << anInt << endl; }
       void byVal(int anInt)        { n = 0; cout << anInt << endl; }
       void test() { n = 5; byRef(n); n = 5; byVal(n); }
   private:
       int n;
   };
   ```

   `test()` 里把成员 n 作为实参传进去，函数体改的是 n，没有改 anInt。实测 `byRef` 输出 0，`byVal` 输出 5。

4. 若类 A 的所有构造函数、析构函数、赋值运算用 protected 访问权限进行修饰，并且，类 A 中没有任何用 static 修饰的成员函数，那么，类 A 不能产生任何对象，进而可以得出结论：定义并实现类 A 对编写一个需要产生对象的程序来说，没有任何用处，定义并实现类 A 的代码是冗余代码。

   答案：错误。protected 的构造函数、析构函数可以被派生类调用。从 A 派生出 Sub，`Sub s;` 能正常创建对象并使用 A 里定义的公有函数（实测通过）。这种类专门用来当基类，原稿批注说的"通过多态发挥作用"也是这个意思。另外 A 的友元也能创建 A 的对象。

5. 对一个类来说，赋值运算是一个很基本，也很重要的操作，因此，定义一个类时，即使程序员不为它定义并实现赋值运算，编译器也会为该类自动产生一个。一个类的赋值运算可看作该类的一个成员函数。若用某个类 A 和它的两个非常量对象 a1、a2 举例来说，类 A 中用 public 访问权限修饰的赋值运算的用途主要体现在两种场合，场合一是：若 a1 和 a2 均有定义，且因类 A 有赋值运算，则可以写出代码 `a1 = a2`；场合二是：若 a2 有定义，且因类 A 有赋值运算，则可写出代码 `A a1 = a2`。

   答案：错误（更正：原稿批注判为"正确"）。
   - `A a1 = a2;` 是定义 a1 时的初始化，调用的是拷贝构造函数。实测在类里给拷贝构造函数和 `operator=` 各加一句输出，`A a1 = a2;` 输出 `copy ctor`，`a1 = a2;` 才输出 `operator=`。
   - "编译器一定会自动产生赋值运算"也不成立：类里有 `const` 数据成员或引用成员时，编译器生成的赋值运算是删除的，`a1 = a2;` 实测报 `copy assignment operator is implicitly deleted`。

### 五、实现 MyString 类（15分）

题目：已知某程序中类 MyString 是自定义的一个用来描述字符串的类，它在 main 函数中使用情况如下：

```cpp
void main( )  {
	MyString s1("Hello ");	MyString s2("World!");
	cout << s1.getString() << s2.getString( ) << endl;
	MyString s3(s1); 	cout << s3.getString( ) << endl;
	s3 = s1 + s2; 	    cout << s3.getString( ) << endl;  }
```

程序执行时，输出结果如下：

```text
Hello World!
Hello
Hello World!
```

根据以下已知条件，完成对 MyString 类的定义和实现。

（1）可以使用 iostream.h 中定义的类及相关内容。

（2）可以使用 string.h 中定义的如下函数：
- `int strlen(const char* );` 用于计算标准表示的字符串长度；
- `char* strcpy( char *strDestination, const char *strSource );` 用于将 strSource 串拷贝给 strDestination。返回的是 strDestination 串，一般不用。
- `char* strcat( char *strDestination, const char *strSource );` 用于将 strSource 串接于 strDestination 串后。返回的是 strDestination 串，一般不用。

本题目要求：根据上述已知条件，不借用其它标准函数库或类库，遵循上面程序输出结果，完成 MyString 类的定义和实现。

答案（整理补充）：

从 main 的用法倒推需要哪些成员：
- `MyString s1("Hello ")`：以 `const char*` 为参数的构造函数，按长度 `new` 一块内存，把串拷进去。
- `MyString s3(s1)`：拷贝构造函数，必须深拷贝。
- `s1 + s2`：`operator+`，返回一个新的 MyString 对象，内容是两串相连。
- `s3 = ...`：赋值运算，同样深拷贝，先判断自赋值，释放旧内存。
- `getString()`：返回内部字符串的 `const char*`。
- 析构函数 `delete[]` 释放内存。

```cpp
#include <iostream>
#include <cstring>
using namespace std;

class MyString {
public:
	MyString(const char* s = "") {                // 用 C 风格字符串构造
		str = new char[strlen(s) + 1];
		strcpy(str, s);
	}
	MyString(const MyString& other) {             // 深拷贝：MyString s3(s1);
		str = new char[strlen(other.str) + 1];
		strcpy(str, other.str);
	}
	~MyString() { delete[] str; }
	MyString& operator=(const MyString& other) {  // 深赋值：s3 = s1 + s2;
		if (this != &other) {
			delete[] str;
			str = new char[strlen(other.str) + 1];
			strcpy(str, other.str);
		}
		return *this;
	}
	MyString operator+(const MyString& other) const {  // 连接，结果是新对象
		char* buf = new char[strlen(str) + strlen(other.str) + 1];
		strcpy(buf, str);
		strcat(buf, other.str);
		MyString result(buf);
		delete[] buf;
		return result;
	}
	const char* getString() const { return str; }
private:
	char* str;
};

int main( )  {
	MyString s1("Hello ");	MyString s2("World!");
	cout << s1.getString() << s2.getString( ) << endl;
	MyString s3(s1); 	cout << s3.getString( ) << endl;
	s3 = s1 + s2; 	    cout << s3.getString( ) << endl;  }
```

运行输出与题目给出的三行一致（第二行 `Hello` 后面带着 s1 里的那个空格）。C++17 和 `-std=c++11 -fno-elide-constructors` 两种编译方式结果相同，因为构造、析构函数里没有输出。

如果不写拷贝构造函数和赋值运算，编译器生成的版本只复制指针，s3 和 s1、以及 `s1 + s2` 产生的临时对象会共用同一块内存。实测三行照样能打印出来，但程序结束时同一块内存被 `delete[]` 两次，异常退出。

### 六、消除 Male 和 Female 的双向依赖（10分）

题目：在如下定义和实现的两个类 Male 和 Female 中，各自存在着指向对方对象的指针成员。且已知在运行时刻，对于任意 Male 类对象 m，若 `m.pWife` 的值不空，则有 `m.pWife->getHusband( )==&m`；同时，对任何 Female 类对象 f，若 `f.pHusband` 的值不空，有 `f.pHusband->getWife( ) == &f`，即：若 m 内的指针指向 f，则 f 内的指针指向 m，反之亦然。这种情况称为双向依赖。现请你在不改变这两个类已有的各成员函数的原型及功能的条件下，重新实现这两个类，使得两个类之间不存在双向依赖。允许增加类，允许增加成员函数，也允许修改成员数据。

```cpp
class Female;
class Male{
public:
	  Female* getWife( ) const
{ return pWife; }
	  // 其它方法及实现，略。
private:
	  Female*  pWife;   };

class Female {
public:
	 Male* getHusband( ) const
{ return pHusband; }
		//其它方法及实现，略。
private:
		Male*   pHusband;
};
```

原卷题干把 Female 误打成 Felmale，已改正。

原稿批注的思路：抽出一个抽象基类 Person（含纯虚函数 `Print()` 和虚析构函数），让 Male、Female 都继承它，分头文件存放。这样做 Male 里仍有 `Female* pWife`，Female 里仍有 `Male* pHusband`，两边的指针还是要保持一致，双向依赖并没有消除。

答案（整理补充）：
- 双向依赖的麻烦在于同一个配对关系存了两份（m 里一份、f 里一份），修改时必须两边同时改，否则就不一致。
- 增加一个"婚姻登记"类 Marriage，配对关系只在这里存一份。Male、Female 去掉互相指向的指针成员，`getWife()`、`getHusband()` 的原型不变，改为向 Marriage 查询。
- Marriage 只需要 Male、Female 的前向声明（只用到指针），Male、Female 只依赖 Marriage，两个类之间不再互相保存对方。
- 题目规定的函数原型里必须出现 `Female*`、`Male*`，所以名字上的引用去不掉；去掉的是数据上的互相指向，结婚、离婚只改 Marriage 里的一条记录，`m.getWife()->getHusband() == &m` 自动成立。

```cpp
#include <iostream>
using namespace std;

class Male;
class Female;

// 婚姻登记：配对关系只在这里保存一份
class Marriage {
public:
	static bool marry(Male* m, Female* f);
	static void divorce(const Male* m);
	static Female* wifeOf(const Male* m);
	static Male* husbandOf(const Female* f);
private:
	struct Couple { Male* husband; Female* wife; };
	enum { MAX = 100 };
	static Couple couples[MAX];
	static int count;
};

class Male {
public:
	Female* getWife( ) const { return Marriage::wifeOf(this); }
	// 其它方法及实现，略。
};

class Female {
public:
	Male* getHusband( ) const { return Marriage::husbandOf(this); }
	// 其它方法及实现，略。
};

Marriage::Couple Marriage::couples[Marriage::MAX];
int Marriage::count = 0;

bool Marriage::marry(Male* m, Female* f) {
	if (wifeOf(m) || husbandOf(f) || count >= MAX) return false;
	couples[count].husband = m;
	couples[count].wife = f;
	count++;
	return true;
}
void Marriage::divorce(const Male* m) {
	for (int i = 0; i < count; i++)
		if (couples[i].husband == m) { couples[i] = couples[--count]; return; }
}
Female* Marriage::wifeOf(const Male* m) {
	for (int i = 0; i < count; i++)
		if (couples[i].husband == m) return couples[i].wife;
	return 0;
}
Male* Marriage::husbandOf(const Female* f) {
	for (int i = 0; i < count; i++)
		if (couples[i].wife == f) return couples[i].husband;
	return 0;
}

int main() {
	Male m; Female f;
	cout << (m.getWife() == 0) << endl;              // 1
	Marriage::marry(&m, &f);
	cout << (m.getWife()->getHusband() == &m) << endl; // 1
	cout << (f.getHusband()->getWife() == &f) << endl; // 1
	Marriage::divorce(&m);
	cout << (f.getHusband() == 0) << endl;           // 1
}
```

```text
1
1
```
