### 一、单选题（共12分，每题2分）

1. C++ 中解决命名冲突的机制是：
   (A) 友元　(B) 虚函数　(C) 函数重载　(D) 名字空间

   答案：D。不同名字空间里的同名标识符互不冲突。

2. 下列哪个不应该出现在头文件中：
   (A) `extern int count;`　(B) `const int count=10;`　(C) `void fun( ) {/* 略 */}`　(D) `class Time {/* 略 */};`

   答案：C。普通函数的定义放在头文件里，头文件被多个 .cpp 包含时，链接会报重复定义。A 只是声明；B 的全局 `const` 常量默认只在本文件内可见，每个文件各有一份，不冲突；D 类定义可以出现在多个编译单元里。

3. 下列哪个属于函数重载：
   (A) `int fun( );`　`float fun( );`
   (B) `int fun(int);`　`int fun(int, int=10);`
   (C) `int fun(int);`　`int fun(const int &);`
   (D) `int fun(int *);`　`int fun(int *const);`

   答案：B（参考答案作"(B)"，加了括号）。A 只有返回类型不同，不能重载；D 形参的顶层 `const` 会被忽略，两个是同一个函数，clang 报 `redefinition of 'fun'`。

   提示：严格按语言规则，C 的两个声明也能同时存在（形参类型 `int` 和 `const int&` 不同），也算重载；B 和 C 的问题一样，都是调用 `fun(5)` 时二义（实测两者都报 `call to 'fun' is ambiguous`）。这道题 B、C 都说得通，考试按参考答案选 B。

4. 定义类 A 的成员函数 `A* f(A a) const` 时，下列哪个适合作为函数返回值：
   (A) `&a`　(B) 类 A 中定义的类型为 `A*` 的静态数据成员　(C) `this`　(D) `dynamic_cast<A *>(&a)`

   答案：B。`a` 是按值传入的形参，函数返回后就销毁，A、D 返回的都是悬空地址；`f` 是常成员函数，里面 `this` 的类型是 `const A*`，不能当 `A*` 返回，clang 报 `cannot initialize return object of type 'A *' with an rvalue of type 'const A *'`。

5. 不同的对象收到同一消息可以产生完全不同的结果，这一现象称作：
   (A) 继承　(B) 多态　(C) 动态绑定　(D) 静态绑定

   答案：B。动态绑定是实现多态的手段，题干描述的现象叫多态。

6. 若类 A 仅在其成员函数 `fun` 中定义并使用了类 B 的一个对象，类 A 其他部分的代码都不涉及类 B，那么类 A 与类 B 的关系最可能是：
   (A) 依赖　(B) 继承　(C) 聚合　(D) 组合

   答案：A。B 只作为局部变量临时用到，没有成为 A 的成员，属于依赖。

### 二、判断正误，对于你认为错误的论述，说明原因或举出反例（共20分，每题2分）

1. 代码 `double dval; float *pi = &dval;` 中会发生隐式类型转换，因此不存在语法错误。

   答案：错误。`double*` 不能隐式转换成 `float*`，clang 报 `cannot initialize a variable of type 'float *' with an rvalue of type 'double *'`。（更正：原答案的理由是"double 占 8 字节，float 占 4 字节，转换不安全"。字节数不是关键，就算两种类型一样大，比如 `int*` 和 `unsigned*`，不同类型的指针之间也没有隐式转换；能隐式转换的只有转成 `void*`、派生类指针转基类指针等少数情况。）

2. 已知类 A，且语句 `const A a; a.fun( );` 是合法的，则 `fun( )` 一定是常成员函数。

   答案：错误。`fun` 也可以是 A 的静态成员函数。

3. 类 B 继承类 A，那么 `sizeof(B)` 的值大于 `sizeof(A)` 的值。

   答案：错误。是大于或等于。比如 `class A {}; class B : public A {};`，实测两者的 `sizeof` 都是 1。

4. 单参构造函数一定可以被用来执行隐式类型转换。

   答案：错误。不一定，比如用 `explicit` 修饰的构造函数；构造函数是私有的，在类外也用不了。

5. 类中没有声明虚函数，则不会为该类生成虚拟表。

   答案：错误。不一定。如果基类中有虚函数，派生类即使自己没写 `virtual`，也有自己的虚函数表。

6. 异常必须在其产生的当前函数中捕获，而不能在外层函数中捕获该异常。

   答案：错误。可以在外层捕获。例如 `try { f( ); } catch(...) { }`，`f()` 里没有 try-catch，`f()` 抛出的异常照样被外层的 `catch(...)` 捕获。

7. 由于抽象类不能实例化，但能派生新类，所以抽象类中的构造函数和拷贝构造函数应该是 protected 的。

   答案：错误。抽象类本来就不能直接创建对象，构造函数写成 public 或 protected，都只有派生类构造时能用上，没有"应该是 protected"的必要。（更正：原答案的理由是"构造函数和拷贝构造函数应为 public"，这同样说得太绝对，两种写法都可以。）

8. 虚函数可以访问虚函数和非虚函数，但非虚函数不能访问虚函数。

   答案：错误。非静态的非虚成员函数可以调用虚函数，而且调用时照样有多态效果。实测：基类非虚函数 `nf()` 里调用虚函数 `vf()`，通过基类引用对派生类对象调用 `nf()`，执行的是派生类的 `vf()`。（原答案写作"非虚函数的非静态函数可访问虚函数"，语序颠倒。）

9. 重载的析构函数应与重载的构造函数一一对应。

   答案：错误。析构函数没有参数，不能重载，一个类只有一个析构函数。

10. 假设类 A 及其祖先类中均不含有指针型或引用型数据成员，执行代码块 `{ A a; A b(a); }` 时，即便使用类 A 的缺省拷贝构造函数也可能造成内存泄露。

    答案：正确。题目只限制了 A 自己的指针和引用成员。A 可以有类类型的对象成员，那个类内部持有指针，而它的拷贝构造、析构写得不配套时，拷贝 A 照样会泄漏或重复释放；A 的构造函数也可能申请资源，把地址存在别处。

### 三、回答下列各题（每题4分，共28分）

#### 1. 找出多文件程序的问题

某个 C++ 应用程序由 1 个 .h 文件和 2 个 .cpp 文件组成，各文件如下：

```cpp
//fun.h
class A {
public:
void fun(int = 0);
};
```

```cpp
// fun.cpp
void A::fun(int num = 0)
{ /* 略 */ }
```

```cpp
//main.cpp
int main( )
{    A obj;
obj.fun( );
return 0;
}
```

请指出程序代码中存在哪些问题或有待改进的地方？如何改进？

答案：

- `fun.h` 最好加上包含警戒（`#ifndef FUN_H` / `#define FUN_H` / `#endif`）。
- `fun.cpp` 中应 `#include "fun.h"`，否则不认识类 A。
- `main.cpp` 中应 `#include "fun.h"`。
- `fun` 的缺省参数在类定义和类外实现里都写了。缺省值只能写一次，一般写在头文件的声明里，实现处去掉 `= 0`。把三个文件合在一起编译，clang 报 `redefinition of default argument`。

#### 2. 三种 string 参数的区别

已知字符串类 `string`，请说明函数 `void fun(string);`、`void fun(string &);` 和 `void fun(const string&);` 之间在语义和使用上的区别。

答案：

- `void fun(string)`：传值。调用时用 `string` 的拷贝构造函数构造一个新字符串给 `fun` 用，函数里改形参不影响实参。实参可以是任意 `string` 对象，也可以是 `char*` 字符串（先转换成 `string`）。
- `void fun(string&)`：传引用。不调用拷贝构造函数，`fun` 里对参数的修改直接影响实参。实参必须是非 const 的 `string` 变量，不能是常量、字符串字面量或临时对象（实测 `fun("abc")` 报 `no matching function`）。
- `void fun(const string&)`：传常引用。也不拷贝，但 `fun` 里不能修改参数。实参可以是变量、`const` 对象，也可以是 `char*` 字符串（编译器生成临时 `string` 绑定上去）。

参考答案里"实参可以是 `char*`"两句是后加的红字批注，实测成立。

#### 3. 能否对局部对象显式调用析构函数

答案：参考答案作"不可以。若可以，就会产生诸如构造了一个对象，却调用了多次析构函数的情形。所以禁止显式调用析构函数。"

（更正：语法上并不禁止。`obj.~A();` 能编译通过，实测析构函数执行了两次：一次是显式调用，一次是离开作用域时自动调用。同一个对象析构两次是未定义行为，析构函数里有 `delete` 就会重复释放。所以结论应该是"语法上可以写，但不应该对局部对象这样做"。显式调用析构函数只用于定位 `new`（placement new）创建的对象。）

#### 4. 允许在类外创建多个实例，但禁止派生

```cpp
class    A {
public:  A(int n):val(n) {   }
private:  int val;
};
```

请问如何修改类 A 的设计，使得既可以在类外得到类 A 的多个实例，又能够禁止从类 A 派生其它类？

参考答案：构造函数设为私有，另外提供一个公有静态函数创建对象。

```cpp
class A {
public:
    static A * CreateA(int n) { return new A(n); }
private:
    A(int n):val(n) { }
private:
    int val;
};
```

- 类外调用 `A::CreateA(1)`、`A::CreateA(2)` 可以得到多个对象，用完要 `delete`。
- 派生类的构造函数必须调用基类构造函数，而 A 的构造函数是私有的，实测写 `class B : public A { public: B() : A(1) { } };` 报 `base class 'A' has private constructor`。
- C++11 起直接写 `class A final { … };` 就能禁止派生。

#### 6. 必须使用初始化列表的情况

请举例说明在哪些情况下，实现自定义构造函数必须使用初始化列表（至少给出 4 种）？

答案：

- 类中含有 `const` 修饰的数据成员（常数据成员），如 `const int num;`。
- 类中含有引用型数据成员，如 `int& a;`。
- 类中含有对象成员，但该成员的类型没有无参构造函数，必须在初始化列表中指明相应的有参构造函数。
- 基类没有无参构造函数，必须在初始化列表中指明基类的有参构造函数。

#### 7. 为派生类 B 实现深拷贝和深赋值

A 和 B 类的部分代码如下：

```cpp
class A
{
public:
A(int n1,int n2)
{ array[0] = n1; array[1] = n2;}
private:
    int  array[2];
};

class B: public A {
public:
B(int m1,int m2,int m3)
:A(m1,m2),p(new int(m3)) {}
~B( ) { delete p; }
private:
    int * p;
};
```

参考答案：

```cpp
B::B(const B& rhs)
:A(rhs)
{
    p = new int(*rhs.p);
}

B& B::operator=(const B& rhs) {
    if ( this!=&rhs) {
       A::operator=(rhs);
       delete p;
       p= new int(*rhs.p);
    }
    return *this;
}
```

要点：

- 拷贝构造函数要在初始化列表里写 `A(rhs)` 拷贝基类部分，不写的话会调用 A 的无参构造函数，而 A 没有，编译报错。
- 赋值函数要显式调用 `A::operator=(rhs)` 复制基类部分，并判断自赋值。
- 实测：`B b2(b1); b3 = b1;` 之后修改 `b1` 指向的值，`b2`、`b3` 不受影响，说明是深拷贝；`b3 = b3;` 也正常。
- 类里还要在声明中加上 `B(const B&);` 和 `B& operator=(const B&);` 两个原型。

### 四、适配第三方三角形类（5分）

某绘图程序已存在矩形（Rect）、椭圆（Ellipse）两种图形元素。现要将三角形（Triangle）图形元素加入该程序以实现功能扩充。已知某第三方类库中提供了 XTriangle 类，且完全满足程序新增的 Triangle 图形元素所需的功能，但 XTriangle 不是由 Shape 派生而来，而且由于缺少 XTriangle 类的源代码，不能从 XTriangle 类直接派生子类。请在下边给出的类的基础上，利用 XTriangle 类，定义并实现 Triangle 类。

```cpp
class Shape {
public: virtual ~Shape( ){ }
  virtual void Draw( )=0;
};

class Ellipse:public Shape{
public: virtual ~ Ellipse ( ) { }
      virtual void Draw ( ) { /*略 */ }
};

class Rect:public Shape {
public:
 Rect ( ) { /*略 */}
virtual ~Rect ( ) { }
virtual void Draw ( )  { /*略 */ }
};

//第三方类库中提供的XTriangle类定义
class XTriangle {
public:
virtual ~ XTriangle ( );
void DrawIt( ) ;
};
```

参考答案思路：Triangle 公有继承 Shape，内部保存一个 XTriangle 对象的指针，`Draw()` 转调 `DrawIt()`（**适配器**的对象组合写法）。

```cpp
class Triangle: public Shape {
public:
   Triangle( ):pXTriangle(new XTriangle) { }
   virtual ~Triangle() { delete pXTriangle; }
   virtual void Draw( ) { pXTriangle->DrawIt( ); }
private:
   XTriangle * pXTriangle;
   Triangle(const Triangle&);              // 禁止拷贝，避免两个对象 delete 同一指针
   Triangle& operator=(const Triangle&);
};
```

（更正：原答案成员声明为 `pXtriangle`，`Draw` 里写成 `pXTriangle`，大小写不一致，编译不过，这里统一成 `pXTriangle`。禁止拷贝的两行是整理时加的：Triangle 持有 `new` 出来的指针，默认拷贝会让两个对象析构时重复 `delete`。也可以直接用 `XTriangle` 对象做成员，不用指针。）给 XTriangle 补上空实现后编译运行，`Shape* s = new Triangle; s->Draw();` 输出 `XTriangle::DrawIt`。

### 六、导弹飞行仿真系统（8分）

现欲开发一款导弹飞行仿真系统，该系统主要模拟不同型号导弹的发射方式与飞行特征。需要模拟的导弹型号及其特征如下表所示。

| 导弹型号 | 发射方式（LaunchMode） | 飞行特征（FlyBehavior） |
| --- | --- | --- |
| 中华（ChinaA） | 海基型（SeaLaunch） | 亚音速飞行（SubSonicFly） |
| 红鸟（RedBirdB） | 空基型（AirLaunch） | 亚音速飞行（SubSonicFly） |
| 东风（SpringC） | 陆基型（LandLaunch） | 超音速飞行（SuperSonicFly） |
| 远征（ExpeditionD） | 海基型（SeaLaunch） | 超音速飞行（SuperSonicFly） |

```cpp
#include <iostream>
using namespace std;

struct Point { int x, y; };
class Printer { };                     // 第三方类，示意
class Bitmap { };
class MyPic;

class DeviceWithOption {               // "设备 + 输出选项"的抽象
public:
    virtual ~DeviceWithOption() { }
    virtual bool Process(MyPic& pic) = 0;
};

class MyPic {
public:
    bool SendTo(DeviceWithOption& dwo) { return dwo.Process(*this); }   // 只剩一个函数、一个参数
};

class PrinterWithOption : public DeviceWithOption {
public:
    PrinterWithOption(Printer& printer)
        : prt(printer), marginLeft(0), marginTop(0), marginRight(0), marginBottom(0), alignKind(0) { }
    void SetMargin(int l, int t, int r, int b) { marginLeft = l; marginTop = t; marginRight = r; marginBottom = b; }
    void SetMargin(Point lt, Point rb) { SetMargin(lt.x, lt.y, rb.x, rb.y); }
    void SetAlign(int kind) { alignKind = kind; }
    virtual bool Process(MyPic&) {
        cout << "打印：留白 " << marginLeft << "," << marginTop << "," << marginRight << "," << marginBottom
             << " 对齐方式 " << alignKind << endl;
        return true;
    }
private:
    Printer& prt;
    int marginLeft, marginTop, marginRight, marginBottom, alignKind;
};

class BitmapWithOption : public DeviceWithOption {
public:
    BitmapWithOption(Bitmap& b) : bmp(b), xOffset(0), yOffset(0), transparent(0), mask(0) { }
    void SetOffset(int x, int y) { xOffset = x; yOffset = y; }
    void SetTransparent(int t) { transparent = t; }
    void SetMask(int m) { mask = m; }
    virtual bool Process(MyPic&) {
        cout << "输出到位图：偏移 " << xOffset << "," << yOffset << " 透明度 " << transparent << " 掩码 " << mask << endl;
        return true;
    }
private:
    Bitmap& bmp;
    int xOffset, yOffset, transparent, mask;
};

// 情况 b：新增打印方向选项，从 PrinterWithOption 派生
class OrientedPrinterOption : public PrinterWithOption {
public:
    OrientedPrinterOption(Printer& p) : PrinterWithOption(p), landscape(false) { }
    void SetLandscape(bool b) { landscape = b; }
    virtual bool Process(MyPic& pic) {
        cout << (landscape ? "横打，" : "竖打，");
        return PrinterWithOption::Process(pic);
    }
private:
    bool landscape;
};

int main() {
    MyPic pic;
    Printer printer;
    Bitmap bmp;
    PrinterWithOption po(printer);
    po.SetMargin(10, 20, 10, 20);
    po.SetAlign(1);
    pic.SendTo(po);
    BitmapWithOption bo(bmp);
    bo.SetOffset(5, 5);
    bo.SetTransparent(50);
    pic.SendTo(bo);
    OrientedPrinterOption oo(printer);
    oo.SetLandscape(true);
    pic.SendTo(oo);
    return 0;
}
```


第 1 问参考答案思路：文件格式和操作系统是两个独立变化的维度，拆成两个继承体系（**桥接模式**）。`OS` 抽象类声明纯虚函数 `Display(StandardVideoStream*)`，`WinOS`、`LinuxOS` 实现；`VideoPlayer` 保存一个 `OS*`，`Play` 先调用纯虚函数 `Decode` 把文件解析成标准视频流，再交给 `OS` 显示；`RMVB_Player`、`MPG_Player`、`AVI_Player` 实现各自的 `Decode`。

参考答案代码的问题：`OS` 里写的是 `void Display(StandardVideoStream* pStream)=0;`，漏了 `virtual`，实测报 `'Display' is not virtual and cannot be declared pure`；`class WinOS : OS` 漏了 `public`，默认私有继承，`new WinOS()` 不能转换成 `OS*`；`VideoPlayer` 没有虚析构函数，也没有释放 `OS` 对象。修正后的代码（已编译运行）：

```cpp
#include <iostream>
#include <string>
using namespace std;

class StandardVideoStream { /* 略 */ };          // 标准视频流类（已知类）

class OS {                                       // 实现部分：与操作系统相关的播放
public:
    virtual ~OS() { }
    virtual void Display(StandardVideoStream* pStream) = 0;
};
class WinOS : public OS {
public:
    void Display(StandardVideoStream*) { cout << "在 Windows 上播放标准视频流" << endl; }
};
class LinuxOS : public OS {
public:
    void Display(StandardVideoStream*) { cout << "在 Linux 上播放标准视频流" << endl; }
};

class VideoPlayer {                              // 抽象部分：与格式相关的解析
public:
    VideoPlayer(OS* pOS) : pOS_(pOS) { }
    virtual ~VideoPlayer() { delete pOS_; }
    void Play(const string& fileName) {
        StandardVideoStream* pStream = Decode(fileName);   // 解析与操作系统无关
        pOS_->Display(pStream);                            // 播放与操作系统相关
        delete pStream;
    }
protected:
    virtual StandardVideoStream* Decode(const string& fileName) = 0;
private:
    OS* pOS_;
    VideoPlayer(const VideoPlayer&);
    VideoPlayer& operator=(const VideoPlayer&);
};
class RMVB_Player : public VideoPlayer {
public:
    RMVB_Player(OS* pOS) : VideoPlayer(pOS) { }
protected:
    StandardVideoStream* Decode(const string& f) { cout << "解析 RMVB 文件 " << f << endl; return new StandardVideoStream; }
};
class MPG_Player : public VideoPlayer {
public:
    MPG_Player(OS* pOS) : VideoPlayer(pOS) { }
protected:
    StandardVideoStream* Decode(const string& f) { cout << "解析 MPG 文件 " << f << endl; return new StandardVideoStream; }
};
class AVI_Player : public VideoPlayer {
public:
    AVI_Player(OS* pOS) : VideoPlayer(pOS) { }
protected:
    StandardVideoStream* Decode(const string& f) { cout << "解析 AVI 文件 " << f << endl; return new StandardVideoStream; }
};

int main( ){
    //在Windows操作系统上播放demo.rmvb视频文件
    VideoPlayer * vp = new RMVB_Player( new WinOS( ) ) ;
    vp->Play ("demo.rmvb");
    delete vp;
    return 0;
}
```

```text
解析 RMVB 文件 demo.rmvb
在 Windows 上播放标准视频流
```
