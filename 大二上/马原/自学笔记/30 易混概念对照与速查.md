# 易混概念对照与速查

把三份资料（`马哲知识点导图（不含政经）.pdf`、`2023版马原课后思考题.pdf`、`客观题/选择判断多选（网上随便找的）.pdf`）里最容易混的概念、最常考的"之最"和经典著作年份拉成表，考前一晚扫一遍。著作和年份是核对过的，用来判断客观题里的出处类选项。

## 一、成对概念对照

### 唯物论

| 对照 | 关键区别 |
| --- | --- |
| 朴素唯物主义 / 形而上学唯物主义 / 辩证唯物主义 | 分别把物质理解为具体实物、原子等粒子、一切客观存在。前两者的共同问题是把哲学的物质范畴等同于自然科学的物质结构 |
| 主观唯心主义 / 客观唯心主义 | 前者以人的感觉、观念为本原（心外无物），后者以脱离个人的客观精神为本原（绝对精神、上帝） |
| 可知论 / 不可知论 | 回答的是哲学基本问题的第二方面，即思维和存在有没有同一性 |
| 运动 / 静止 | 运动无条件、绝对；静止有条件、相对。否认静止是相对主义诡辩论，否认运动是形而上学 |
| 时间 / 空间 | 时间是持续性、顺序性，特点是一维性；空间是广延性、伸张性，特点是三维性 |
| 物质决定意识 / 意识的能动作用 | 前者讲起源、本质；后者讲目的性计划性、创造性、指导实践、调控行为生理 |

### 辩证法

| 对照 | 关键区别 |
| --- | --- |
| 同一性 / 斗争性 | 同一性有条件、相对；斗争性无条件、绝对。这个"绝对相对"的搭配几乎年年考 |
| 矛盾的普遍性 / 特殊性 | 共性无条件、绝对，个性有条件、相对；共性寓于个性之中 |
| 主要矛盾 / 矛盾的主要方面 | 主要矛盾是多个矛盾之间比，决定事物发展进程；矛盾的主要方面是一个矛盾内部比，决定事物的性质 |
| 两点论 / 重点论 | 两点论是有重点的两点论，反对均衡论；重点论是看到两点中的重点，反对一点论 |
| 量变 / 质变 / 度 | 量变是数量增减和排列次序变动，质变是根本性质的变化，度是保持质的数量界限，两端叫关节点 |
| 部分质变 / 质变 | 总的量变过程中阶段性、局部性的部分质变仍属于量变过程 |
| 辩证否定 / 形而上学否定 | 辩证否定是自我否定、是发展和联系的环节、实质是扬弃；形而上学把否定看成外力作用下的全盘抛弃 |
| 真象 / 假象 / 错觉 | 真象和假象都是客观的、都是本质的表现，假象从反面歪曲地表现本质；错觉是主观的感觉偏差，属于认识范畴 |
| 必然 / 偶然 | 必然源于根本矛盾、居支配地位；偶然源于非根本矛盾和外部条件、居从属地位，是必然的表现形式和补充 |
| 现实 / 可能 | 可能标志发展方向，现实标志当前状况；要区分好的可能与坏的可能、现实的可能与抽象的可能 |
| 客观辩证法 / 主观辩证法 | 后者是前者在人的思维中的反映，二者本质统一、形式不同 |

### 认识论

| 对照 | 关键区别 |
| --- | --- |
| 唯物主义反映论 / 唯心主义先验论 | 从物到感觉和思想，还是从思想和感觉到物 |
| 旧唯物主义反映论 / 能动的反映论 | 前者离开实践和辩证法，把认识看成照镜子式的被动接受 |
| 感性认识 / 理性认识 | 形式分别是感觉、知觉、表象和概念、判断、推理；特点分别是直接性具体性和间接性抽象性 |
| 第一次飞跃 / 第二次飞跃 | 实践到认识、认识到实践；第二次飞跃更重要 |
| 真理的绝对性 / 相对性 | 绝对性讲确定性和发展的无限性，相对性讲广度和深度的有限性 |
| 实践标准的确定性 / 不确定性 | 确定性指实践是唯一标准且终将作出裁决，不确定性指具体实践有局限、检验是个过程 |
| 真理尺度 / 价值尺度 | 合规律性与合目的性；成功的实践是二者的统一 |
| 知识性认识 / 评价性认识 | 前者求"真"，结果不以主体意志为转移；后者求"善美"，结果与评价主体直接相关 |
| 价值的主体性 / 客观性 | 主体性指价值以主体为中心，客观性指价值关系本身不依赖人的主观意识 |

### 唯物史观

| 对照 | 关键区别 |
| --- | --- |
| 社会存在 / 社会意识 | 社会存在包括自然地理环境、人口因素、物质生产方式；社会意识包括社会心理和社会意识形式 |
| 社会意识形态 / 非社会意识形态 | 前者有阶级性（政治法律思想、道德、艺术、宗教、哲学），后者无阶级性（语言学、逻辑学、自然科学） |
| 观念上层建筑 / 政治上层建筑 | 政治上层建筑居主导地位，国家政权是整个上层建筑的核心 |
| 生产力 / 生产关系 | 生产力是生产的物质内容（劳动者、劳动资料、劳动对象），生产关系是生产的社会形式（所有制、人与人关系、分配关系） |
| 经济基础 / 上层建筑 | 经济基础是生产关系的总和，上层建筑是意识形态及相应的制度、组织和设施 |
| 社会革命 / 改革 | 革命是社会形态的质变、阶级斗争的最高形式；改革是同一社会形态内部的自我完善 |
| 社会形态更替的必然性 / 人们的历史选择性 | 规律客观不可违背，但不排斥人们在遵循规律基础上的历史选择 |
| 人民群众 / 历史人物 | 人民群众是历史的创造者；历史人物能加速或延缓历史进程，不能改变总方向 |

### 政治经济学（第四、五章）

| 对照 | 关键区别 |
| --- | --- |
| 使用价值 / 价值 | 使用价值是商品的自然属性，价值是凝结在商品中的无差别的人类劳动，是社会属性 |
| 具体劳动 / 抽象劳动 | 具体劳动创造使用价值，抽象劳动形成价值。劳动二重性是理解政治经济学的枢纽 |
| 价值 / 交换价值 / 价格 | 价值是内容，交换价值是价值的表现形式，价格是价值的货币表现 |
| 私人劳动 / 社会劳动 | 二者的矛盾是私有制商品经济的基本矛盾，也是商品拜物教的根源 |
| 不变资本 / 可变资本 | 按在剩余价值生产中的作用划分。不变资本是生产资料部分，价值转移不增殖；可变资本是购买劳动力的部分，能带来剩余价值。这组划分揭露剥削的秘密 |
| 固定资本 / 流动资本 | 按价值周转方式划分。固定资本是厂房机器等，流动资本包括原材料和劳动力部分。注意可变资本属于流动资本，但流动资本不都是可变资本 |
| 绝对剩余价值 / 相对剩余价值 | 前者靠延长工作日，后者靠缩短必要劳动时间，以全社会劳动生产率提高为条件 |
| 相对剩余价值 / 超额剩余价值 | 超额剩余价值是个别企业率先提高劳动生产率获得的，各企业追逐超额剩余价值的结果是全社会相对剩余价值的产生 |
| 剩余价值率 / 利润率 | 剩余价值率 $m' = m/v$，反映剥削程度；利润率 $p' = m/(c+v)$，反映资本增殖程度，总是小于剩余价值率 |
| 资本积聚 / 资本集中 | 积聚靠剩余价值资本化，会增大社会资本总额；集中靠兼并和股份公司，不增大社会资本总额 |
| 自由竞争 / 垄断 | 垄断从自由竞争中产生，但没有消除竞争，竞争反而更激烈 |
| 私人垄断 / 国家垄断资本主义 | 后者是垄断资本与国家政权相结合，是资本主义生产关系的部分质变 |

## 四、马克思主义产生的条件速查

- 经济社会根源：资本主义生产力和生产关系的矛盾运动，19 世纪上半叶资本主义大工业的发展。
- 阶级基础：无产阶级作为独立的政治力量登上历史舞台，标志是 19 世纪三四十年代的三大工人运动，即 1831 年和 1834 年法国里昂工人的两次起义、1838 年开始延续十年的英国宪章运动、1844 年德国西里西亚纺织工人起义。
- 直接理论来源：德国古典哲学（黑格尔的辩证法、费尔巴哈的唯物主义）、英国古典政治经济学（劳动价值论）、英法空想社会主义（圣西门、傅立叶、欧文）。
- 自然科学前提：细胞学说、能量守恒和转化定律、生物进化论。

## 五、常考数字组合

- 马克思主义的三个组成部分：马克思主义哲学、马克思主义政治经济学、科学社会主义。
- 马克思主义的五个基本特征：科学性、人民性、实践性、发展性，以及科学性与革命性的统一。
- 唯物辩证法的内容：两大特征、三大规律、五对范畴。
- 实践的三个基本特征：客观实在性（直接现实性）、自觉能动性、社会历史性。
- 实践的三种基本形式：物质生产实践、社会政治实践、科学文化实践，另有派生的虚拟实践。
- 真理的四个特性：客观性、一元性、绝对性、相对性。
- 价值的四个特点：主体性、客观性、多维性、社会历史性。
- 社会发展的五大动力：社会基本矛盾、阶级斗争、社会革命、改革、科学技术。
- 五种社会形态：原始社会、奴隶社会、封建社会、资本主义社会、共产主义社会（社会主义社会是其第一阶段）。
- 中国式现代化的五个特征：人口规模巨大、全体人民共同富裕、物质文明和精神文明相协调、人与自然和谐共生、走和平发展道路。
