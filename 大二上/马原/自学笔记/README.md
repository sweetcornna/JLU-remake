## 这套稿子里的几个标记

- （更正：原文作 X）：原题库答案或文字有错，已经改掉，括号里是原样子。
- （题库原答案为 X，存疑：…）：答案按原样保留，但和教材口径对不上，后面写了理由，考试以老师讲的为准。
- （题库中重复出现）：题库里同一道题出现过多次，这里只留一道。
- 加粗的是要背的关键词，公式用 `$...$` 写，GitHub 上能正常渲染。

## 建议学习顺序

1. 先看 `01`–`04` 四份提纲，把主线串起来：唯物论说世界是什么，辩证法说世界怎样存在，认识论说人怎么认识世界，唯物史观说社会怎么发展。这套导图不含政治经济学（第四、五章）和科学社会主义（第六、七章），那部分看教材加 `11`。
2. 每过完一章，做 `20`–`22` 里对应章节的题。错题回提纲里定位知识点，别只记答案字母。
3. 主观题背 `10`、`11`。课后思考题一共 39 道：导论 4 道，第一至第五章各 5 道，第六章 6 道，第七章 4 道。先背题干里的关键词和答题框架，再补细节。
4. 考前一晚看 `30`，重点是相近概念的边界，比如同一性与斗争性哪个绝对、共性寓于个性还是反过来、不变资本与固定资本的两种划分依据。

## 考试信息

课程目录的 `README.md` 是上一届学长写的备考说明，里面提到：2022 级这门课考得比较简单，客观题不难，主观题全部出自课后思考题，第四章当年只考了客观题。这是个人经验，年级不同题型可能变。三份被整理的资料本身没有写考试范围、题型和分值，所以这里不列。
