# 知识点提纲：唯物史观

整理自 `马哲知识点导图（不含政经）.pdf` 第 16–20 页，原图是思维导图，这里转写成文字提纲。唯物史观回答"人类社会如何发展"，四条线：社会生活中有什么、社会怎样发展、社会为什么发展、谁在推动发展。

## 一、社会历史观的基本问题

**社会存在与社会意识的关系问题是社会历史观的基本问题。**

- 唯物史观：社会存在决定社会意识。
- 唯心史观：社会意识决定社会存在。它的两个根本缺陷是：至多考察了人的活动的思想动机，没有进一步考究思想动机背后的物质动因和经济根源；不懂得人民群众在社会历史发展中的决定作用。

### 社会存在

社会存在是社会生活的物质方面，包括自然地理环境、人口因素和物质生产方式。其中自然地理环境和人口因素是社会发展的**影响因素**，物质生产方式是社会发展的**决定力量**。

物质生产方式由生产力和生产关系构成。

**生产力的三要素**

| 要素 | 说明 |
| --- | --- |
| 劳动者（主体） | 生产力中最活跃的因素 |
| 劳动资料（中介） | 其中最重要的是生产工具，生产工具是生产力发展水平的客观标志 |
| 劳动对象（客体） | 进行物质资料生产的前提 |

**生产关系的三方面**：生产资料所有制关系、生产中人与人的关系、产品分配关系。其中**生产资料所有制关系最基本、起决定作用**，它决定了生产关系的性质（公有制还是私有制）。

### 社会意识

社会意识是社会生活的精神方面，按层次分：

- 低层次的社会心理：感知、情绪、情感、心态、习俗，以感性认识为主。
- 高层次的社会意识形式，以理性认识为主，又分两类：
  - 社会意识形态（观念上层建筑），有阶级性，包括政治法律思想（居核心和主导地位）、道德、艺术、哲学、宗教。
  - 非社会意识形态，无阶级性，包括语言学、逻辑学、心理学、自然科学。

### 社会存在与社会意识的辩证关系

**社会存在决定社会意识**：社会存在是社会意识内容的客观来源，社会意识是社会物质生活过程的主观反映；随着社会存在的发展，社会意识也相应地、或迟或早地发生变化和发展。

**社会意识具有相对独立性**，表现在：

1. 社会意识与社会存在发展的不完全同步性和不平衡性。可能超越社会存在（比如对共产主义的科学预见），也可能落后于社会存在（比如残留的封建思想）。导图举的例子：近代英法经济发达但哲学不算突出，近代德国经济落后却出现了古典哲学的高峰。
2. 社会意识内部各种形式之间相互影响，各自具有历史继承性（道德与法律相互影响，"百善孝为先"这类观念代代相传）。
3. **社会意识对社会存在具有能动的反作用**，这是相对独立性最突出的表现。先进的社会意识促进社会发展，落后的社会意识阻碍社会发展。

方法论：这条原理第一次正确解决了社会历史观的基本问题，是社会历史观革命性变革的基础。改变落后的社会意识，根本办法是改变产生它的社会存在。

## 二、社会发展的两对基本矛盾

### 第一对：生产力与生产关系

生产力是生产的物质内容，生产关系是生产的社会形式（更正：原图作"社会形势"），二者共同构成社会的生产方式。

**辩证关系**

- 生产力决定生产关系：生产力的状况决定生产关系的性质；生产力的发展决定生产关系的变化。
- 生产关系对生产力具有能动的反作用：适合生产力发展状况时起促进作用，不适合时起阻碍作用。

**矛盾运动规律：生产关系一定要适合生产力状况的规律**

- 从内容看：生产力状况决定一定生产关系的产生及其变化发展的方向和形式；生产关系反作用于生产力。
- 从过程看：生产关系对生产力总是从基本相适合，到基本不相适合，再到基本相适合；生产关系总是从相对稳定，到新旧更替，再到相对稳定。

方法论：这条规律第一次科学确立了生产力发展是"社会进步的最高标准"，是马克思主义政党制定路线、方针、政策的重要依据。

### 第二对：经济基础与上层建筑

**经济基础**是由社会一定发展阶段的生产力所决定的生产关系的总和，实质是社会一定发展阶段上的基本经济制度。

**上层建筑**是建立在一定经济基础之上的意识形态以及相应的制度、组织和设施，分两部分：

- 观念上层建筑（社会意识形态）：政治法律思想、道德、艺术、宗教、哲学等。
- 政治上层建筑（居主导地位）：政治法律制度（国家政治制度、立法司法制度和行政制度）以及政治组织及设施（政党、军队、警察、法庭、监狱等）。其中**国家政权是整个上层建筑的核心**。

**辩证关系**

- 经济基础决定上层建筑：经济基础的需要决定上层建筑的产生，经济基础的性质决定上层建筑的性质，经济基础的变化发展决定上层建筑的变化发展及其方向。
- 上层建筑对经济基础具有反作用：上层建筑为自己的经济基础的形成和巩固服务；反作用的性质（促进还是阻碍）取决于它所服务的经济基础的性质，归根到底取决于它是否有利于生产力的发展。

**矛盾运动**：新建立的上层建筑总有不完善之处，不能完全适应经济基础的要求；上层建筑一旦形成又具有相对独立性，经济基础的变化不会立即在上层建筑中反映出来，于是出现上层建筑落后于经济基础的情况。当生产力的发展要求变革陈旧的经济基础，而上层建筑仍然维护它时，矛盾趋于尖锐化。

**规律：上层建筑一定要适合经济基础状况的规律。** 内容是经济基础决定上层建筑的产生、性质和发展变化的方向；上层建筑的反作用取决于并服务于经济基础的性质和要求。

方法论：在促进生产力发展的同时，加快上层建筑领域的改革。

## 三、社会形态更替

**社会形态**是同生产力发展一定阶段相适应的经济基础与上层建筑的统一体，具有全面的、具体的、历史的特点。它由三部分构成：经济形态（经济基础，社会的骨骼系统）、政治形态（政治上层建筑）、意识形态（观念上层建筑，社会的血肉系统）。

社会形态更替的四组特性，根源在于社会发展的客观必然性与人们的历史选择性：

1. **统一性**：从原始社会、奴隶社会、封建社会、资本主义社会到共产主义社会五种社会形态的依次更替，是社会历史运动的一般过程和一般规律。
2. **多样性**：就某一个民族或国家而言，社会形态更替会有跳跃性。近代中国从封建社会到半殖民地半封建社会，1956 年三大改造完成后进入社会主义社会，跳过了资本主义充分发展的阶段。多样性不否定人类总体历史进程，仍受总体历史进程制约。
3. **必然性与人们的历史选择性**：更替的过程和规律是客观的，发展趋势确定不移，归根结底是社会基本矛盾运动的结果，其中生产力的发展具有决定意义；规律的客观性并不排斥人们在遵循客观规律的基础上对某种社会形态的历史选择。
4. **前进性与曲折性**：五种社会形态的依次更替体现了人类社会的发展进步；社会历史前进过程中也会出现反复、停滞和倒退（袁世凯复辟帝制、东欧剧变和苏联解体），曲折前进是历史发展的普遍规律。

## 四、社会发展的五大动力

| 动力 | 地位 | 内容 |
| --- | --- | --- |
| 社会基本矛盾 | 根本动力 | 生产力和生产关系的矛盾、经济基础和上层建筑的矛盾 |
| 阶级斗争 | 阶级社会发展的直接动力 | 社会基本矛盾在阶级社会中的直接表现 |
| 社会革命 | 重要动力 | 阶级斗争的最高形式，是社会形态的质变 |
| 改革 | 重要动力 | 同一社会形态内部，调整、变革不适合生产力发展要求的生产关系和上层建筑的某些部分及环节 |
| 科学技术 | 重要动力 | 通过影响生产方式、生活方式和思维方式推动社会发展 |

**社会基本矛盾为什么是根本动力，五条**

1. 囊括社会空间：生产力、生产关系（经济基础）和上层建筑囊括了社会生活的基本领域，形成社会有机体的基本结构，即经济结构、政治结构和观念结构。
2. 贯穿社会时间：存在于每一个社会形态中，贯穿人类社会发展过程的始终。
3. 规定社会性质：规定了各种社会形态、社会制度的基本性质。
4. 引起社会矛盾：是其他一切社会矛盾的根源，决定并制约其他社会矛盾的存在和解决。
5. 形成社会规律：三者之间本质的、必然的联系形成了社会发展的基本规律，即两个"一定要适合"。

其中要记住三句话：生产力是社会基本矛盾运动中最基本的动力因素，是人类社会发展和进步的最终决定力量；生产力和生产关系的矛盾是"一切历史冲突的根源"；社会基本矛盾在不同社会形态中有不同的表现形式和解决方式。

**科学技术的两重性**：科学技术能够通过促进经济和社会发展造福人类，运用不当也会带来消极后果。要靠合理的社会制度保障科学技术的正确运用，始终使科学技术为人类社会的健康发展服务。

## 五、人民群众在历史发展中的作用

### 两种历史观的对立

- 唯心史观即英雄史观，抹杀人民群众的历史作用，宣扬少数英雄人物创造历史。
- 唯物史观认为人民群众是历史的创造者。

### 考察历史创造者的三条原则

1. 立足于现实的人及其本质（一切社会关系的总和）来把握历史的创造者。
2. 立足于整体的社会历史过程来探究谁是历史的创造者。整体的社会历史并非个体历史的简单堆砌，而是无数追求自己目的的人的活动形成的合力。
3. 从社会历史发展的必然性入手来考察。只有促进历史进步发展的力量才属于历史创造者的行列。

### 人民群众

人民群众是一个历史范畴：从质上说，指一切对社会发展起推动作用的人；从量上说，指社会人口中的绝大多数。在不同历史时代，人民群众包含不同的阶级、阶层和集团，但最稳定的主体部分始终是从事物质资料生产的劳动群众。

**三大作用**：人民群众是社会物质财富的创造者；是社会精神财富的创造者；是社会变革的决定力量。

方法论：坚持马克思主义群众观点，贯彻党的群众路线。人民至上是马克思主义的政治立场，坚持以人民为中心的发展思想体现了马克思主义政党的政治立场和执政理念。

### 个人在社会历史中的作用

- 普通个人属于人民群众范畴。历史人物是一定历史事件的主要倡导者、组织领导者或思想理论、科学文化的主要代表人物，其中起进步作用的是杰出人物。
- 作用的两面：新的历史任务往往由具有进步意义的历史人物首先发现或提出来；但任何历史人物都要受社会发展客观规律的制约，不能决定和改变历史发展的总进程和总方向。
- 历史人物的出现体现必然性与偶然性的统一。时势造英雄是必然性，具体由谁来充当这个角色、做了哪些具体的事，带有偶然性。
- 方法论：正确认识和处理群众、阶级、政党、领袖的关系。
