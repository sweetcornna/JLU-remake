# 03 Cache 性能计算

整理自 `题型整理.pdf` 第 9–10 页（△Cache 访问性能计算一节）。两道题都是 Patterson 教材风格的多级 Cache 性能题，例 1 和 [第5章 存储器例题（重制版）](<../重制版PPT/第5章 存储器例题（重制版）.pptx>) 的例 3 是同一道，课件里有完整讲解；17 种 Cache 优化技术在 [体系结构 03 Cache 性能分析与优化（重制版）](<../重制版PPT/体系结构 03 Cache 性能分析与优化（重制版）.pptx>)。

## 解题步骤

手写稿把公式抄在题目右边，照着用就行：

```
平均存储器访问时间 AMAT = 命中时间 + 缺失率 × 缺失代价
总的 CPI = 基本 CPI + 每条指令的存储器阻塞周期数
缺失代价（周期数）= 缺失代价（时间）÷ 时钟周期时间
```

两级 Cache 时：

```
总的 CPI = 基本 CPI + 一级 Cache 每条指令的阻塞 + 二级 Cache 每条指令的阻塞
一级阻塞 = 一级缺失率 × 一级缺失代价，一级缺失代价 = 二级命中时间 ÷ 一级命中时间
二级阻塞 = 二级缺失率 × 二级缺失代价，二级缺失代价 = 访问主存时间 ÷ 一级命中时间
```

三点要盯住：

1. 题目说"一级 Cache 的命中时间决定了周期时间"，那时钟周期就等于命中时间，缺失代价要先除以它换成周期数再进 CPI。
2. 二级缺失率给的是全局缺失率还是局部缺失率，算法不一样。这两道题按全局缺失率处理，和教材例题一致。
3. 只有部分指令访存时（例 2），要按比例加权：不访存的指令只有取指那一次访存开销，访存指令多一次。

## 例 1：加二级 Cache 之后（p9 第 2 题）

主存访问时间 100 ns，两个处理器一级 Cache 的数据：

|  | 一级容量 | 一级缺失率 | 一级命中时间 |
| --- | --- | --- | --- |
| P1 | 1 KB | 2.5% | 0.2 ns |
| P2 | 2 KB | 2% | 0.25 ns |

1）一级命中时间决定周期时间，各自的时钟频率、AMAT 是多少？基本 CPI 为 1.0 时总的 CPI 各是多少？

2）给 P1 加一个二级 Cache（512 K，缺失率 0.5%，命中时间 5 ns），P1 的 CPI 是多少？性能提升了多少？

第 1 问：

$$P1 频率 = \frac{1}{0.2\text{ns}} = 5\text{GHz},\qquad P2 频率 = \frac{1}{0.25\text{ns}} = 4\text{GHz}$$

$$P1\ AMAT = 0.2 + 2.5\%\times100 = 2.7\text{ns},\qquad P2\ AMAT = 0.25 + 2\%\times100 = 2.25\text{ns}$$

$$P1\ CPI = 1 + 2.5\%\times\frac{100}{0.2} = 13.5,\qquad P2\ CPI = 1 + 2\%\times\frac{100}{0.25} = 9$$

第 2 问：一级 Cache 的缺失由二级 Cache 处理，所以一级缺失代价按二级命中时间算。

$$一级缺失代价 = \frac{5\text{ns}}{0.2\text{ns}} = 25\ 个周期,\qquad 二级缺失代价 = \frac{100\text{ns}}{0.2\text{ns}} = 500\ 个周期$$

$$CPI = 1 + 2.5\%\times25 + 0.5\%\times500 = 1 + 0.625 + 2.5 = 4.125$$

$$性能提升 = \frac{13.5}{4.125} = 3.27\ 倍$$

复算：4.125 和 3.27 都正确。顺带一提，这时的 AMAT = 0.2 + 2.5%×5 + 0.5%×100 = 0.825 ns，课件里也是这个数。

如果把 0.5% 理解成二级 Cache 的局部缺失率，第三项应是 $2.5\%\times0.5\%\times500 = 0.0625$，CPI 就成了 1.69。原稿按全局缺失率做，和教材例题口径一致，跟着做就行。

## 例 2：36% 的指令需要访存（p10 第 3 题）

访问主存需要 80 ns，所有指令中有 36% 需要访存。

|  | 容量 | 缺失率 | 命中时间 |
| --- | --- | --- | --- |
| P1 | 2 KiB | 8.0% | 0.64 ns |
| P2 | 4 KiB | 6.0% | 0.85 ns |

基本 CPI 为 1.0，两者总的 CPI 是多少？哪个处理器更快？

思路：一条指令至少取指一次，访存指令还要多访存一次，所以按比例拆开：

```
实际 CPI = 无须访存指令的 CPI × 无须访存比例 + 需要访存指令的 CPI × 需要访存比例
访存指令的 CPI = 1 + 缺失率 × 缺失代价周期数
```

$$P1\ CPI = 1\times64\% + \left(1 + 8.0\%\times\frac{80}{0.64}\right)\times36\% = 0.64 + 11\times0.36 = 4.6$$

$$P2\ CPI = 1\times64\% + \left(1 + 6.0\%\times\frac{80}{0.85}\right)\times36\% \approx 0.64 + 6.647\times0.36 = 3.03$$

原稿写到这里就下结论"P2 更快"。这一步理由不足：两台机器的时钟周期不同（周期由命中时间决定），要比每条指令的平均执行时间。

$$P1: 4.6\times0.64 = 2.94\text{ns},\qquad P2: 3.03\times0.85 = 2.58\text{ns}$$

结论仍然是 P2 更快，但要把这一步写出来（补充）。

复算：$80/0.64=125$，P1 的 CPI = 4.6；$80/0.85\approx94.12$，P2 的 CPI = 3.0329。两个 CPI 与原稿一致。

原稿右边还写了一种等价写法：把括号拆开直接写成 $1 + 8.0\%\times\frac{80}{0.64}\times36\%$，注意这时第一项的 1 已经含了取指那一次，结果一样。

## 小结

- AMAT 只看存储器，CPU 时间才反映整机。题目问"哪个快"，答案要落到时间上。
- 缺失代价在 AMAT 里用时间（ns），在 CPI 里用周期数，别混。
- 多级 Cache 的一级缺失代价是"访问下一级的时间"，不是"访问主存的时间"。
