## 解题步骤

三种格式先记死：

| 格式 | 字段 | 用在哪 |
| --- | --- | --- |
| R 型 | op(6) rs(5) rt(5) rd(5) shamt(5) funct(6) | `add`、`sub`、`and`、`or`、`slt` |
| I 型 | op(6) rs(5) rt(5) 常数或地址(16) | `addi`、`lw`、`sw`、`beq`、`bne` |
| J 型 | op(6) 目标地址(26) | `j`、`jal` |

地址计算就两条公式，手写稿右栏反复在写：

```
分支（beq/bne，PC 相对寻址）：
    目标地址 = (PC + 4) + 符号扩展(16 位偏移) × 4
    反过来求偏移：偏移 = (目标地址 − (PC + 4)) ÷ 4
跳转（j/jal，伪直接寻址）：
    目标地址 = (PC + 4) 的高 4 位 ‖ (26 位地址 × 4)
    反过来求地址字段：字段 = 目标地址 ÷ 4（前提是高 4 位相同）
```

左移 2 位就是乘 4，因为 MIPS 指令按字对齐，地址一定是 4 的倍数。起始地址比较小（比如 1000、2000）时 PC 高 4 位全是 0，跳转只需算低位。

五种寻址方式，题目常问"这条指令是什么寻址"：

| 方式 | 形式 | 例子 |
| --- | --- | --- |
| 立即数寻址 | 操作数写在指令里 | `addi $s0, $s0, 4` |
| 寄存器寻址 | 操作数在寄存器里 | `add $s2, $s2, $s1` |
| 基址寻址 | 寄存器内容 + 偏移量 | `lw $s1, 0($s0)` |
| PC 相对寻址 | PC+4 + 偏移量×4 | `beq`、`bne` |
| 伪直接寻址 | PC+4 高 4 位拼 26 位×4 | `j` |

## 例 1：给出 Start、Exit、Target 的地址与寄存器变化（p16 第 7 题，10 分）

程序段顺序调入起始地址为 2000 的内存单元。寄存器初值等于其编号值，存储单元中的数值等于其存储单元地址值。问执行完后哪个寄存器的值发生变化，变成多少。

| 地址 | 指令 | 执行情况 |
| --- | --- | --- |
| 2000 | `Start: sub $10, $4, $7` | 执行 |
| 2004 | `beq $1, $3, Target` | $1=1，$3=3，不相等，不跳转 |
| 2008 | `j Exit` | 跳转到 Exit |
| 2012 | `Target: and $12, $2, $5` | 跳过 |
| 2016 | `or $13, $2, $6` | 跳过 |
| 2020 | `add $14, $4, $2` | 跳过 |
| 2024 | `slt $15, $6, $7` | 跳过 |
| 2028 | `or $13, $6, $2` | 跳过 |
| 2032 | `add $14, $2, $2` | 跳过 |
| 2036 | `sw $15, 102($2)` | 跳过 |
| 2040 | `Exit: lw $4, 56($8)` | 执行 |

解：每条指令占 4 个地址，顺序排下来 Start = 2000，Target = 2012，Exit = 2040。

红笔提醒：这题问的是地址值，不是 Start、Target、Exit 在指令机器码里的那个数值字段。

执行过程：先做 `sub`，再做 `beq` 比较，$1 ≠ $3 不跳转，继续执行 `j Exit`，直接跳到 Exit 处，中间的指令都不执行，最后执行 `lw`。（更正：原稿红笔这句写成"直接跳转到 Target 处"，代码旁的箭头画的是指向 Exit，应为"跳转到 Exit 处"，是笔误。）

寄存器变化：

- $10 变为 $4 − $7 = 4 − 7 = −3。
- $4 变为 Memory[$8 + 56] = Memory[8+56] = Memory[64] = 64（存储单元的值等于地址值）。

复算：两个结果正确。

## 例 2：写出循环里每条指令的地址（p16 第 5 题）

机器字长 32 位，PC 高四位为 0000，循环的机器码连续存放：

| 地址 | 标号 | 代码 | 说明 |
| --- | --- | --- | --- |
| 40000H | LOOP: | `slt $t2, $s0, $t1` | |
| 40004H | | `beq $t2, $s0, 10` | 条件转移至 DONE |
| 40008H | | `addi $t1, $t1, -2` | |
| 4000CH | | `addi $s2, $s2, 1` | |
| 40010H | | `j 10000H` | 转移到 LOOP |
| …… | | …… | |
| 40030H | DONE: | `add $t3, $s1, $s2` | |

解：`j 10000H` 的 26 位地址字段左移 2 位就是 LOOP 的地址，$10000H\times4 = 40000H$，再拼上 PC+4 的高 4 位 0000，所以 LOOP 在 40000H，后面每条加 4。

DONE 用 `beq` 的偏移算：`beq` 在 40004H，PC+4 = 40008H，偏移 10 表示 10 条指令，$10\times4 = 40_{10} = 28H$，所以 DONE = 40008H + 28H = 40030H。

红笔：十六进制加减想不明白可以转二进制算；H 表示十六进制。

复算：40000H、40030H 都正确。

## 例 3：LOOP 和 OUT 对应的数值（p17 第 10 题；讲题 docx 计算题 3）

程序段顺序调入起始地址为 1000（十进制）的内存单元：

```
LOOP: lw   $s1, 0($s0)        (1) 1000
      add  $s2, $s2, $s1      (2) 1004
      addi $s0, $s0, 4        (3) 1008
      addi $t1, $t1, 1        (4) 1012
      slti $t2, $t1, 100      (5) 1016
      bne  $t2, $zero, LOOP   (6) 1020
      j    OUT                (7) 1024
      add  $s2, $s2, $s1      (8) 1028
OUT:  lw   $s2, 0($s3)        (9) 1032
```

10.1 指令（6）中 LOOP 和指令（7）中 OUT 对应的数值。

`bne` 在 1020，PC+4 = 1024，目标是 1000：

$$1020 + 4 + LOOP\times4 = 1000 \Rightarrow LOOP = -6$$

`j` 的目标是 1032，起始地址不大，PC+4 的高 4 位为 0：

$$4\times OUT = 1032 \Rightarrow OUT = 258$$

10.2 指令（1）（2）（3）的寻址方式：(1) 基址寻址，(2) 寄存器寻址，(3) 立即数寻址。

10.3 指令（6）和（7）的两点区别：

① 指令（6）是不相等时跳转（条件转移），指令（7）是无条件跳转。

② 指令（6）把指令中低 16 位符号扩展到 32 位后左移 2 位，再与 PC+4 相加得到目标地址；指令（7）直接将指令中低 26 位左移 2 位得 28 位，再与 PC+4 的高 4 位相连得到目标地址。

复算：LOOP = (1000 − 1024)/4 = −6，OUT = 1032/4 = 258，都正确。这道题在讲题 docx 里也给了同样的答案（原文用红字标出 LOOP、OUT）。

## 例 4：给定二进制数列，译码并执行（p18 第 2 题）

采用教材给定的 MIPS 指令格式，已知：

```
A: 0010 0001 0011 0011 1011 0000 0010 0000
B: 0000 1010 1011 0010 1010 1101 0111 0110
C: 0001 0110 1011 0011 0010 1101 0111 0010
D: 1000 1101 1001 0000 0000 0000 0000 0100
PC: 0000 0011 1011 0001 1000 0010 1101 1100
```

内存里 10H 单元存 10H，12H 存 12H，20H 存 20H，依此类推（每个单元的值等于它的地址）。$t0~$t7 的寄存器号为 8~15，初值等于寄存器号；$s0~$s7 的寄存器号为 16~23，初值等于寄存器号的 2 倍。

1）A 是 `addi` 指令，目的寄存器名和执行后其中的数据。

按 I 型拆：op = 001000，rs = 01001 = 9 = $t1，rt = 10011 = 19 = $s3，立即数 = `1011 0000 0010 0000`B = B020H。

目的寄存器是 19 号，名字是 $s3；源寄存器 $t1 的值是 9（1001B）。

原稿的答案是"源寄存器的值加上后 16 位立即数"，写成 `1011 0000 0010 1001`B。（更正：`addi` 的立即数要先符号扩展，B020H 的最高位是 1，扩展后是 FFFFB020H = −20448，所以 $s3 = 9 + (−20448) = −20439 = FFFFB029H。原稿只算了低 16 位。）

2）B 是跳转指令，跳转到的地址。

op = 000010，26 位地址 = `10 1011 0010 1010 1101 0111 0110`，左移 2 位得 28 位，再拼上 PC+4 的高 4 位 0000：

```
0000 1010 1100 1010 1011 0101 1101 1000  = 0ACAB5D8H
```

3）C 是 `bne` 指令，目的地址。

op = 000101，rs = 10101 = 21 = $s5（值 42），rt = 10011 = 19 = $s3（值 38），两者不相等，跳转。偏移 = `0010 1101 0111 0010`B = 2D72H，左移 2 位 = B5C8H。

```
PC = 03B182DCH，PC + 4 = 03B182E0H
目的地址 = 03B182E0H + B5C8H = 03B238A8H
       = 0000 0011 1011 0010 0011 1000 1010 1000
```

4）D 是 `lw` 指令，目标寄存器的名称和内容。

op = 100011，rs = 01100 = 12 = $t4（值 12 = 01100B），rt = 10000 = 16 = $s0，偏移 = 4。

内存地址 = 12 + 4 = 16 = 10H，10H 单元的数据是 10H，放入 $s0。所以目标寄存器是 $s0，内容为 10H。

5）`lui $s0, 61` 后 $s0 的值。

红笔在这里写了"不学"，没作答。补充：`lui` 把 16 位常数放进目标寄存器的高 16 位，低 16 位清 0，$61 = 003DH$，所以 $s0 = 003D0000H。

复算：0ACAB5D8H、03B238A8H、$s0 = 10H 都与原稿一致；A 问按符号扩展得 FFFFB029H。

## 常见坑

- 忘了 PC+4。分支和跳转都以下一条指令的地址为基准。
- 偏移量是"指令条数"，不是字节数，乘 4 之后才是字节。
- 立即数是有符号的，最高位为 1 一定要符号扩展。
- 反过来求偏移时结果可能是负数（例 3 的 −6），写成补码 16 位就是 FFFAH。
