## 建议的顺序

先看 01，把简答题的说法背下来，简答部分基本是原题。接着按计算题的难度爬：02 和 03 只是套公式，04、05、06 要动手写二进制，07 要能默画数据通路，08 和 09 是最费时间的两块，考试里也是大题。

09 里第 10 题（虚存 + TLB + Cache + 连续读 100 个字）是手写稿花了整整两页分析的题，原稿两个版本的答案还不一致，建议单独留一晚上做。

## 从题目里看到的考试信息

只写材料里明确有的，别的没有依据。

- 题干标分值的有 3 分、4 分、10 分、12 分、15 分几档，10 分以上的都是计算题或综合大题。
- 手写稿的红笔批注里有几句是奔着考试写的：除法器"考试的话用第一版除法的方法吧，书上有例题 P127"；存储层次题"考试最好把更新过的 Cache 与 TLB 完整画下来"；缺页那一支"考试考不了这种情况"；`lui` 旁边写着"不学"。
- 印刷题目里出现过两次"采用教材中给定的 MIPS 指令格式/流水线"，说明格式和五段流水线的命名以教材（Patterson & Hennessy）为准。
