# 04 浮点数与 IEEE 754

整理自 `题型整理.pdf` 第 11–12 页（△IEEE754 一节）和 `PPT/讲题20231113.docx` 的计算题 2。讲题 docx 的计算题 2 就是下面的例 3。

格式、隐含 1、移码的道理在 [第3章 计算机的算术运算（重制版）](<../重制版PPT/第3章 计算机的算术运算（重制版）.pptx>) 里，这里只练编码和加减。

## 解题步骤

单精度 32 位：S（1 位）+ E（8 位，移码，偏移 127）+ M（23 位，隐含最高位的 1）。真值 $=(-1)^S\times1.M\times2^{E-127}$。

十六进制转二进制时按 4 位一组展开，然后在第 1 位后、第 9 位后画两条竖线，分成 S | E | M 三段。手写稿全程这么做，很不容易错。

加减法按五步走：

1. 两个数分别写成 $\pm1.xxx\times2^k$。十进制转二进制时整数部分除 2 取余，小数部分乘 2 取整。
2. 对阶。小阶向大阶看齐，小的那个尾数右移，右移几位阶码就加几。
3. 尾数求和（减法先变补或者直接列竖式相减）。
4. 规格化。结果写回 $1.xxx\times2^k$ 的形式，左规右规都可能。
5. 按 IEEE 754 编码回去：S 写符号，E = k + 127 化成 8 位二进制，M 取小数点后 23 位不足补 0，最后四位一组转十六进制。

题目说"结果以 IEEE 754 表示"就一定要走到第 5 步，只写成 $1.xxx\times2^k$ 会丢分（例 3 的原稿就停在了这一步）。

## 例 1：$F2 = $F0 + $F1（p11 第 4 题）

两个单精度浮点寄存器 `$F0 = C1F20000H`、`$F1 = 42510000H`，执行 `add.s $F2, $F0, $F1`，问 $F2 的值。

展开 F0：

```
S  E         M
1  1000 0011  111 0010 0000 0000 0000 0000
```

阶码 $131-127=4$，所以 $F0 = -1.111001_2\times2^4$。

展开 F1：

```
S  E         M
0  1000 0100  101 0001 0000 0000 0000 0000
```

阶码 $132-127=5$，所以 $F1 = 1.1010001_2\times2^5$。

对阶：F0 右移一位变成 $-0.1111001_2\times2^5$。尾数求和：

```
   1.1010001
 - 0.1111001
 -----------
   0.1011000
```

$$F2 = 0.1011000_2\times2^5 = 1.011_2\times2^4$$

规格化后 S=0，E = 4+127 = 131 = 1000 0011，M = 011 0000…0：

```
0100 0001 1011 0000 0000 0000 0000 0000
 4    1    B    0    0    0    0    0
```

所以 $F2 = 41B00000H。

复算：F0 = −30.25，F1 = 52.25，和为 22 = $1.011_2\times2^4$，编码 0x41B00000。原稿正确。

## 例 2：A = −5.25，B = 7.125，求 A − B（p11 第 1 题）

先转二进制： $5_{10}=101_2$， $0.25_{10}=0.01_2$，所以 $A = -101.01_2 = -1.0101_2\times2^2$。

$7_{10}=111_2$， $0.125_{10}=0.001_2$，所以 $B = 111.001_2 = 1.11001_2\times2^2$。

两数阶码都是 2，不用对阶。A − B 是两个负贡献相加，直接把尾数相加再取负：

```
   1.0101
 + 1.11001
 ---------
  11.00011
```

$$A - B = -11.00011_2\times2^2 = -1.100011_2\times2^3$$

S=1，E = 3+127 = 130 = 1000 0010，M = 100 0110 0…0：

```
1100 0001 0100 0110 0000 0000 0000 0000
 C    1    4    6    0    0    0    0
```

所以 A − B = C1460000H。

复算：A − B = −12.375 = $-1.100011_2\times2^3$，编码 0xC1460000。原稿正确。

## 例 3：(BE800000)₁₆ + (41000000)₁₆（p12 第 9 题；讲题 docx 计算题 2）

要求写出详细步骤，计算过程和结果都用 IEEE 754 表示。

展开第一个数：

```
1  011 1110 1  000 0000 0000 0000 0000 0000
S     E              M
```

阶码 $125-127=-2$，所以 $(BE800000)_{16} = -1.0_2\times2^{-2} = -0.25$。

展开第二个数：

```
0  100 0001 0  000 0000 0000 0000 0000 0000
S     E              M
```

阶码 $130-127=3$，所以 $(41000000)_{16} = 1.0_2\times2^{3} = 8$。

对阶：小阶向大阶看齐，第一个数右移 5 位， $-1.0_2\times2^{-2} = -0.00001_2\times2^3$。

尾数求和：

$$(-0.00001_2 + 1.0_2)\times2^3 = 0.11111_2\times2^3$$

规格化（左规一位）：

$$= 1.1111_2\times2^2 = 7.75$$

原稿到这里就停了。题目要求结果用 IEEE 754 表示，还要编码回去（补充）：S=0，E = 2+127 = 129 = 1000 0001，M = 1111 0…0。

```
0100 0000 1111 1000 0000 0000 0000 0000
 4    0    F    8    0    0    0    0
```

所以结果 = (40F80000)₁₆。

复算：−0.25 + 8 = 7.75，单精度编码 0x40F80000。原稿的计算过程正确，缺最后一步。

## 例 4：B = −7.25，C = 0.5125，求 B + C（p12 第 1 题，10 分）

这道题原稿只写了转二进制的竖式，没做完。它的坑在 C：0.5125 是无限循环小数，写不尽。

B 很简单： $B = -7.25 = -111.01_2 = -1.1101_2\times2^2$。

C 用乘 2 取整：

| 步 | 乘 2 后 | 取出的整数位 |
| --- | --- | --- |
| 1 | 1.025 | 1 |
| 2 | 0.05 | 0 |
| 3 | 0.1 | 0 |
| 4 | 0.2 | 0 |
| 5 | 0.4 | 0 |
| 6 | 0.8 | 0 |
| 7 | 1.6 | 1 |
| 8 | 1.2 | 1 |
| 9 | 0.4 | 0 |

从第 5 位起 0011 开始循环： $0.5125 = 0.1000\,0011\,0011\,0011\ldots_2 = 1.0000110011\ldots_2\times2^{-1}$。

（更正：原稿指数写成 $2^{1}$，应为 $2^{-1}$，因为 0.5125 小于 1。）

对阶：C 右移 3 位变成 $0.0010000011001100\ldots_2\times2^2$。尾数相减（B 为负，绝对值大）：

```
   1.1101000000000000000000
 - 0.0010000011001100110011
 ------------------------------
   1.1010111100110011001101
```

$$B + C = -1.10101111001100110011\ldots_2\times2^2 = -6.7375$$

S=1，E = 2+127 = 129 = 1000 0001，尾数取 23 位并舍入，参考结果：

```
1100 0000 1101 0111 1001 1001 1001 1010
 C    0    D    7    9    9    9    A
```

也就是约 (C0D7999A)₁₆。末尾一两位取决于舍入方式（就近舍入还是截断），考试时把保护位、舍入位、粘贴位的处理写出来，比硬凑最后一位更稳。

复算：Python 按单精度算 $-7.25+0.5125$ 得 0xC0D7999A，与上面一致。

## 常见坑

- E 是移码不是补码，单精度偏移量 127，算真值要减 127，编码要加 127。
- 尾数有隐含的 1，写 $1.M$，编码时只写小数点后面的部分。
- 对阶是小阶向大阶看齐，不能反过来，否则会丢有效位。
- 十进制小数不一定能精确表示，遇到 0.5125、0.1 这种要说明"二进制写不尽，按 23 位截断并舍入"。
