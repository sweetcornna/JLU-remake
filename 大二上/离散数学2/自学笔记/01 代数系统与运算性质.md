## 本章要点

- 二元代数运算是映射 $f:S\times S\to S$，关键词是"两个输入、结果唯一、结果仍在 $S$ 里"。
- 六条运算性质：交换、结合、幂等、分配、吸收、消去。前四条在后面每一章都会再出现。
- 代数系统 $(S,f_1,\dots,f_m)$ 只要求集合非空、每个运算封闭。
- 贯穿全章的一个原则：证明"满足"要对所有元素验证，证明"不满足"给一个反例就够。

## 一、二元代数运算

### 1. 定义

设 $S$ 是非空集合。$S\times S$ 到 $S$ 的一个映射

$$f:S\times S\to S,\qquad f(a,b)=c$$

称为 $S$ 上的一个**二元代数运算**，通常写成 $a*b=c$。

判定三个要点：

1. 两个输入 $a,b$ 都取自 $S$；
2. 每一对有序输入 $(a,b)$ 只对应一个结果 $c$（结果唯一）；
3. 结果 $c$ 仍属于 $S$（**封闭性**）。

输入是有序对，所以 $a*b$ 与 $b*a$ 可以不相等，二元运算本身不要求交换律。

把 $S^n$ 到 $S$ 的映射叫作 $n$ 元代数运算。运算不局限于加减乘除，映射的复合、集合的交并、逻辑联结词都算。

### 2. 运算表

有限集上的一个二元运算，等价于一张填满的表：第 $x$ 行第 $y$ 列的格子写 $x*y$。

$S=\{a,b\}$ 上一个运算的例子：

| $*$ | $a$ | $b$ |
|---|---|---|
| $a$ | $a$ | $a$ |
| $b$ | $b$ | $b$ |

表里所有结果都落在 $S$ 中，运算就是封闭的。

**运算个数**：若 $|S|=n$，表有 $n^2$ 个格子，每格有 $n$ 种填法，所以 $S$ 上的二元运算共有

$$n^{n^2}$$

个。例如 $|S|=2$ 时是 $2^4=16$ 个，$|S|=3$ 时是 $3^9=19683$ 个。

### 3. 常见例子

| 集合 | $+$ | $-$ | $\times$ | $\div$ |
|---|---|---|---|---|
| $\mathbb N$ 自然数 | 是 | 否（$1-2=-1\notin\mathbb N$） | 是 | 否 |
| $\mathbb Z$ 整数 | 是 | 是 | 是 | 否（$1\div 2\notin\mathbb Z$） |
| $\mathbb R^*=\mathbb R\setminus\{0\}$ | 否（$1+(-1)=0\notin\mathbb R^*$） | 否 | 是 | 是 |

其他常见的二元代数运算：

- $n$ 阶实矩阵：矩阵加法、矩阵乘法；
- 幂集 $\rho(S)$：交 $\cap$、并 $\cup$；
- 真值集合 $\{0,1\}$：$\land,\lor,\to,\leftrightarrow$；
- 非空集合 $A$ 上的全体映射 $M(A)$：映射的复合；
- $A$ 上的全体双射 $B(A)$：映射的复合（双射复合仍是双射）。

同一个运算换个集合就可能不封闭，判断时要同时盯住集合和运算。

### 4. 练一练

| 题 | 结论 | 理由 |
|---|---|---|
| $A=\{\varnothing,\{a\},\{b\}\}$，运算 $\cap$ | 是 | 任意两元素之交仍是 $\varnothing$、$\{a\}$ 或 $\{b\}$ |
| $A=\{\varnothing,\{a\},\{b\}\}$，运算 $\cup$ | 不是 | $\{a\}\cup\{b\}=\{a,b\}\notin A$ |
| $A=\{0,2,4\}$，普通加法 | 不是 | $2+4=6\notin A$ |
| $S=\{2^n\mid n\in\mathbb N\}$，普通加法（习题 6.1-2） | 不是 | $2+4=6$ 不是 2 的幂 |
| $S=\{2^n\mid n\in\mathbb N\}$，普通乘法 | 是 | $2^m\cdot 2^n=2^{m+n}\in S$ |

习题 6.1-1：在 $Z_6$ 的剩余类加法下，$W_1=\{[0],[3]\}$ 与 $W_2=\{[0],[2],[4]\}$ 封闭（例如 $[3]+[3]=[0]$，$[2]+[4]=[0]$），都是二元运算；$W_3=\{[1],[3],[5]\}$ 不封闭，因为 $[1]+[1]=[2]\notin W_3$。

验证"是"要把所有元素对都算一遍（$|A|=3$ 就是 9 对），验证"不是"给一个跑出集合的结果即可。

## 二、六大运算性质

### 1. 交换律

对任意 $a,b\in S$：

$$a*b=b*a$$

- 满足：整数加法、整数乘法、集合的交与并。
- 不满足：整数减法、矩阵乘法（一般 $AB\ne BA$）。
- 正例（有理数上 $a\odot b=a+b-ab$）：$a\odot b=a+b-ab=b+a-ba=b\odot a$。
- 反例（$S=\{a,b\}$，$a*b=b$ 而 $b*a=a$）。

有限集上有个读表技巧：交换律成立当且仅当运算表关于主对角线对称。

### 2. 结合律

对任意 $a,b,c\in S$：

$$(a*b)*c=a*(b*c)$$

元素顺序不动，只改变先算哪一步。

- 满足：整数加法、整数乘法、矩阵加法、矩阵乘法、集合的交与并、映射的复合。
- 不满足：整数减法，$(1-2)-3=-4$ 而 $1-(2-3)=2$。
- 正例（非空集合 $A$ 上 $a\odot b=b$，永远取右边那个）：$(a\odot b)\odot c=b\odot c=c$，$a\odot(b\odot c)=a\odot c=c$，两边都是 $c$。
- 正例（正整数集 $A$ 上 $a\odot b=a+b+ab$）：两边展开都等于 $a+b+c+ab+bc+ac+abc$。看穿它的窍门是 $a\odot b=(a+1)(b+1)-1$，结合律从乘法继承下来。

结合律在运算表里看不出来，要验证全部 $n^3$ 组 $(a,b,c)$；否定只需一组反例。

### 3. 幂等律

两层概念要分清：

- **幂等元**：某个元素 $a$ 满足 $a*a=a$。
- **幂等律**：$S$ 中每个元素都是幂等元。

集合的交与并满足幂等律：$A\cap A=A$，$A\cup A=A$。

整数乘法的幂等元只有 $0$ 和 $1$；整数加法的幂等元只有 $0$。两者都不满足幂等律。

推论：$a$ 是幂等元时，对任意正整数 $n$ 有 $a^n=a$。

### 4. 分配律

设 $*$ 与 $+$ 是 $S$ 上的两个二元代数运算。若对任意 $a,b,c$ 都有

$$a*(b+c)=(a*b)+(a*c)\qquad\text{(左)}$$
$$(b+c)*a=(b*a)+(c*a)\qquad\text{(右)}$$

则称 $*$ 对 $+$ 满足分配律。

**分配律有方向**。整数乘法对加法满足分配律；加法对乘法不满足：$1+(2\times3)=7$，而 $(1+2)\times(1+3)=12$。

运算不可交换时，左右两式都要验。

一个抽象例子：$A=\{\alpha,\beta\}$，规定 $\alpha+u=\alpha$、$\beta+u=u$（$+$ 的结果由左因子决定），$\alpha*u=u$、$\beta*\beta=\alpha$（$\alpha$ 是 $*$ 的单位元）。

- $+$ 对 $*$ 满足分配律：取 $x=\alpha$ 时左边 $=\alpha+(y*z)=\alpha$，右边 $=(\alpha+y)*(\alpha+z)=\alpha*\alpha=\alpha$；取 $x=\beta$ 时左边 $=\beta+(y*z)=y*z$，右边 $=(\beta+y)*(\beta+z)=y*z$。右分配同理。
- $*$ 对 $+$ 不满足：$\beta*(\alpha+\beta)=\beta*\alpha=\beta$，而 $(\beta*\alpha)+(\beta*\beta)=\beta+\alpha=\alpha$，两者不等。

### 5. 吸收律

若对任意 $a,b\in S$ 同时有

$$a*(a+b)=a,\qquad a+(a*b)=a$$

则称 $*$ 与 $+$ 满足吸收律。两个等式必须同时成立，它描述的是两个运算之间的关系。

- 集合的交与并满足：$A\cap(A\cup B)=A$，$A\cup(A\cap B)=A$。
- 自然数上 $a*b=\max\{a,b\}$、$a+b=\min\{a,b\}$ 满足：$\max\{a,\min\{a,b\}\}=a$，$\min\{a,\max\{a,b\}\}=a$。取 $a=3,b=5$ 试一下：$\max\{3,\min\{3,5\}\}=\max\{3,3\}=3$。
- 整数的 $\times$ 与 $+$ 不满足：$2\times(2+3)=10\ne 2$。

### 6. 消去律

对任意 $a,b,c\in S$：

$$a*b=a*c\Rightarrow b=c\qquad\text{(左消去)}$$
$$b*a=c*a\Rightarrow b=c\qquad\text{(右消去)}$$

左右两条都成立才叫满足消去律。

- 满足：整数加法、矩阵加法、非零整数集 $\mathbb Z^*$ 上的乘法、整数减法。
- 不满足：整数乘法，因为 $0\cdot1=0\cdot2$ 而 $1\ne2$；矩阵乘法，非零矩阵也可能消不掉。

"约分"不是天然合法的，先确认运算满足消去律。

## 三、性质速查表

| 运算 | 交换 | 结合 | 幂等 | 消去 | 备注 |
|---|---|---|---|---|---|
| $\mathbb Z$ 加法 $+$ | 是 | 是 | 否 | 是 | $+$ 对 $\times$ 不满足分配律 |
| $\mathbb Z$ 乘法 $\times$ | 是 | 是 | 否 | 否 | $\times$ 对 $+$ 满足分配律；因子 $0$ 使消去失败 |
| $\mathbb Z$ 减法 $-$ | 否 | 否 | 否 | 是 | 左右都能消去 |
| $n$ 阶矩阵加法 | 是 | 是 | 否 | 是 | 与整数加法性质相同 |
| $n$ 阶矩阵乘法 | 一般否 | 是 | 否 | 否 | $\times$ 对 $+$ 满足分配律 |
| 幂集 $\rho(S)$ 交 $\cap$ | 是 | 是 | 是 | 否 | $\cap$ 对 $\cup$ 满足分配律；与 $\cup$ 配对满足吸收律 |
| 幂集 $\rho(S)$ 并 $\cup$ | 是 | 是 | 是 | 否 | $\cup$ 对 $\cap$ 满足分配律；与 $\cap$ 配对满足吸收律 |

注：分配律和吸收律讲的是两个运算之间的关系，所以写在备注列里；表格里"幂集交、并的消去律为否"指的是 $A\cap B=A\cap C$ 推不出 $B=C$（取 $A=\varnothing$ 即可）。

## 四、同一套规律，两个世界

集合代数 $(\rho(S),\cap,\cup)$ 与命题代数 $(S,\land,\lor)$ 满足完全一样的规律：

| 规律 | 集合代数 | 命题代数 |
|---|---|---|
| 幂等律 | $A\cap A=A$，$A\cup A=A$ | $A\land A=A$，$A\lor A=A$ |
| 交换律 | $A\cap B=B\cap A$，$A\cup B=B\cup A$ | $A\land B=B\land A$，$A\lor B=B\lor A$ |
| 结合律 | $(A\cap B)\cap C=A\cap(B\cap C)$ | $(A\land B)\land C=A\land(B\land C)$ |
| 分配律 | $A\cap(B\cup C)=(A\cap B)\cup(A\cap C)$ | $A\land(B\lor C)=(A\land B)\lor(A\land C)$ |
| 吸收律 | $A\cap(A\cup B)=A$，$A\cup(A\cap B)=A$ | $A\land(A\lor B)=A$，$A\lor(A\land B)=A$ |
| 德摩根律 | $(A\cap B)^c=A^c\cup B^c$ | $\lnot(A\land B)=\lnot A\lor\lnot B$ |

近世代数的方法就是不看对象的具体含义，只按运算遵循的规律给结构分类。这张表在第七章会原样再来一次：交换加结合加吸收得到格，再加分配律得到分配格，再加 $0$、$1$ 和余元素就是布尔代数。

## 五、代数系统

设 $S$ 是非空集合，$f_1,\dots,f_m$ 是 $S$ 上的若干个代数运算，把集合和运算当成一个整体看，记作

$$(S,f_1,\dots,f_m)$$

叫作一个**代数系统**。

例子：$(\mathbb Z,+)$、$(\mathbb Z,\cdot)$、$(\mathbb Z,+,\cdot)$、$(\rho(S),\cap,\cup)$、$(\{0,1\},\land,\lor)$；取 $Z_0$ 为偶数集，$(Z_0,+)$、$(Z_0,\cdot)$、$(Z_0,+,\cdot)$ 也都是；令 $\oplus$ 求最大公约数、$\odot$ 求最小公倍数，则 $(\mathbb Z,\oplus,\odot)$、$(\mathbb N,\oplus,\odot)$ 也是。

$(\mathbb N,-)$ 不是代数系统，因为减法在 $\mathbb N$ 上不封闭（$1-2=-1\notin\mathbb N$）。

判断代数系统两步走：集合非空；每个指定的运算都封闭。

## 六、解题模板

**判断是不是二元运算**：任取 $a,b\in S$，算出 $a*b$，检查是否仍在 $S$ 中。找到一个跑出 $S$ 的结果就立刻否定。

**判断某条性质**：写出定义的等式，对任意元素证明；要否定就给一个具体反例。涉及两个运算时注意方向（分配律）和配对（吸收律的两个式子）。

**判断代数系统**：先验集合非空和每个运算封闭，再看题目额外要求的性质。

**例题（习题 6.1-5）**：设 $+$ 和 $*$ 是集合 $S$ 上的两个二元代数运算，对 $S$ 中任意 $x,y$ 都有 $x+y=x$。求证 $*$ 对 $+$ 满足分配律。

关键条件是"$+$ 的结果永远等于左边那个元素"。设 $x,y,z\in S$ 任意。

左分配：

$$x*(y+z)=x*y,\qquad (x*y)+(x*z)=x*y$$

第一式因为 $y+z=y$，第二式因为 $u+v=u$。两边都等于 $x*y$。

右分配：

$$(y+z)*x=y*x,\qquad (y*x)+(z*x)=y*x$$

两边都等于 $y*x$。所以 $*$ 对 $+$ 满足分配律。$\blacksquare$

## 七、易错点

1. 二元运算只要求封闭，不要求交换。$a*b\ne b*a$ 照样可以是二元运算。
2. 交换律改顺序，结合律改括号。$(a*b)*c=a*(b*c)$ 里元素的先后顺序从没变过。
3. 分配律有方向。"$*$ 对 $+$ 满足"和"$+$ 对 $*$ 满足"是两个不同的命题。
4. "存在幂等元"和"满足幂等律"含义不同。整数乘法有幂等元 $0$、$1$，却不满足幂等律。
5. 整数乘法不能随手消去，因子为 $0$ 时会失败。
6. 判断封闭要验证全部元素对，只验一两对不算。

## 八、自测

先遮住答案作答。

1. 为什么自然数减法不是 $\mathbb N$ 上的二元运算？
2. 三元素集合上一共有多少个二元运算？
3. 矩阵乘法满足结合律吗？交换律呢？
4. 为什么整数乘法不满足消去律？
5. $(\mathbb N,-)$ 是代数系统吗？
6. $\rho(S)$ 上的交与并满足吸收律吗？写出两个等式。

答案：

1. 不封闭，例如 $1-2=-1\notin\mathbb N$。
2. $3^9=19683$。
3. 满足结合律 $(AB)C=A(BC)$；一般不满足交换律，$AB\ne BA$。
4. $0\cdot1=0\cdot2$，但 $1\ne2$。
5. 不是，减法在 $\mathbb N$ 上不封闭。
6. 满足：$A\cap(A\cup B)=A$ 与 $A\cup(A\cap B)=A$。

## 附：背景（了解即可）

代数的研究对象从方程变成结构，起点是五次方程的根式解问题。一元一次方程约公元前 1700 年就有解法，二次方程公元前几世纪巴比伦人已会解，三次方程在中国见于 7 世纪唐代王孝通《缉古算经》的近似解法、在西方见于 16 世纪意大利的卡丹公式，四次方程由费拉里化归为一个三次方程和两个二次方程。五次方程让欧拉、高斯、拉格朗日等人先后失败，直到 19 世纪伽罗瓦（1811-1832）证明五次及以上的一般方程没有根式解，并在证明中引入了"群"。

后续发展：1911 年施泰尼茨《域的代数理论》，1920 至 1930 年诺特与阿廷的奠基性工作，1930 至 1931 年范·德·瓦尔登根据两人讲稿写成《近世代数学》两卷，标志学科成熟（1955 年第四版更名《代数学》）。
