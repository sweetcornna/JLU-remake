## 建议学习顺序

这门课是一条链，后面每一节都在用前面的结论，跳着学会卡住。推荐按下面的顺序走：

1. **6.1 代数系统**（笔记 01）。先把"封闭"和"唯一"两个词抠清楚，再把交换、结合、幂等、分配、吸收、消去六条运算律背熟。这六条在第七章的格里会原样再来一遍，前期花的时间后面全能赚回来。
2. **6.2 群**（笔记 02）。判群五项（非空、封闭、结合、有壹、有逆）要能默写，否定一个群要能准确说出失败在哪一关。置换乘法的约定是 $(\sigma\tau)(x)=\sigma(\tau(x))$，从右往左算，这里出错会连累后面所有涉及 $S_n$ 的题。
3. **6.3 子群与陪集**（笔记 03）。先掌握判别条件二（非空加 $ab^{-1}\in H$），再学周期和循环群，最后到陪集与拉格朗日定理。拉格朗日定理是整章的出口，选择题几乎都从它推。
4. **6.4 同态与同构**（笔记 04）。核是正规子群、同态像同构于商群，这两句话串起全节。学之前把 6.3 的陪集和正规子群再看一遍。
5. **6.5 环与域**（笔记 05）。把整数环当原型，每见一个新结构就问一句：整数的哪条规律在这里还成立。主线是环 → 整区 → 体 → 域。
6. **第七章 格与布尔代数**（笔记 06）。可以和第六章并行学。核心技能是画哈斯图、在图里找钻石格 $M_3$ 和五角格 $N_5$。
7. 考前用 **笔记 07** 过一遍易错点和自测题，再配合课程根目录下的历年真题和习题解答刷题。

每一册都可以按"读 PPT → 读笔记的本章要点 → 做笔记末尾的自测题 → 回头补漏"的循环走一遍。
