### 命令说明：lsblk

`lsblk` 列出系统中的块设备，包括硬盘、分区、U 盘、SD 卡等，以树形显示设备和分区的层次关系。输出示例（原稿给出的，不是作业环境的真实输出）：

```text
NAME   MAJ:MIN RM   SIZE RO TYPE MOUNTPOINT
sda      8:0    0 465.8G  0 disk
├─sda1   8:1    0   512M  0 part /boot/efi
├─sda2   8:2    0   244M  0 part /boot
└─sda3   8:3    0 465.1G  0 part
  ├─vg0-root 253:0    0    50G  0 lvm  /
  ├─vg0-swap 253:1    0   7.9G  0 lvm  [SWAP]
  └─vg0-home 253:2    0 407.2G  0 lvm  /home
```

| 列 | 含义 |
| --- | --- |
| NAME | 设备名。`sda` 是第一块硬盘，`sda1` 到 `sda3` 是它的分区 |
| MAJ:MIN | 主设备号和次设备号 |
| RM | 是否可移动设备，1 表示可移动 |
| SIZE | 大小 |
| RO | 是否只读，1 表示只读 |
| TYPE | 类型：`disk` 磁盘，`part` 分区，`lvm` 逻辑卷 |
| MOUNTPOINT | 挂载点 |

这个例子里有一块硬盘 sda，分成 3 个分区，sda3 上又建了三个 LVM 逻辑卷，分别挂载到 `/`、交换空间和 `/home`。作业要求虚拟机建两块虚拟硬盘，所以在 openEuler 上执行时，TYPE 为 `disk` 的设备应该有两个。

（更正：原稿说 lsblk 会显示"文件系统类型"。默认输出里没有这一列，要看文件系统类型需要用 `lsblk -f`。）

### 命令说明：uname -a

`uname` 打印系统信息，`-a` 表示全部（all）。各项也可以用单独的选项取出：

| 选项 | 含义 | 示例 |
| --- | --- | --- |
| `-s` | 内核名称 | Linux |
| `-n` | 网络节点主机名 | myhostname |
| `-r` | 内核发行版本 | 4.15.0-29-generic |
| `-v` | 内核版本（含编译时间） | #31-Ubuntu SMP Tue Jul 17 15:39:52 UTC 2018 |
| `-m` | 机器硬件名称 | x86_64 |
| `-p` | 处理器类型 | x86_64 |
| `-i` | 硬件平台 | x86_64 |
| `-o` | 操作系统 | GNU/Linux |

原稿给的输出示例：

```bash
uname -a
```

```text
Linux myhostname 4.15.0-29-generic #31-Ubuntu SMP Tue Jul 17 15:39:52 UTC 2018 x86_64 x86_64 x86_64 GNU/Linux
```

从左到右依次对应上表：内核是 Linux，主机名 myhostname，内核版本 4.15.0-29-generic，2018 年 7 月 17 日编译，硬件架构 x86_64，操作系统 GNU/Linux。

### 解答

下面是课件上的 Git 操作流程。课件示例用的仓库地址和目录是演示用的，做作业时要换成自己 Fork 后的仓库地址和题目要求的 `stucomm/csw2023/2022LT` 目录。

```bash
# 下面的 <学号> 是占位符，换成自己的学号，尖括号不要保留
# 安装 git（openEuler 上用 dnf，需要 root）

# 创建以学号命名的分支，再切换过去
```

（更正：原稿课件示例作 `cp command.cvs .../学号.cvs`，扩展名应为 `.csv`，与题目中的 command.csv 一致；提交说明原稿用的是中文弯引号，shell 里要用英文引号。）

命令说明和常见坑：

| 命令 | 说明 |
| --- | --- |
| `git clone 地址` | 把远程仓库完整下载到本地，并自动把这个地址记为远程仓库 `origin` |
| `git config user.name` | 不加 `--global` 时只对当前仓库生效；加上 `--global` 则对本机所有仓库生效 |
| `git branch 名称` | 只创建分支，不会切换过去；`git checkout 名称` 才切换。两步可以合成 `git checkout -b 名称` |
| `git add .` | 把当前目录下所有改动加入暂存区。作业只允许提交一个文件，更稳妥的写法是 `git add stucomm/csw2023/2022LT/<学号>.csv`，提交前用 `git status` 确认只有这一个文件 |
| `git commit -m "说明"` | 把暂存区的内容提交到本地版本库，`-m` 后面是提交说明 |
| `git push origin 分支名` | 把本地分支推送到远程仓库 `origin` 上的同名分支 |

推送成功后，在码云网页上从自己仓库的这个分支向官方仓库 aaa/LinuxAbc 发起 Pull Request。

## 第三次作业：date、who、cal 脚本

### 题目

原稿只保存了脚本和注释，没有题目原文。从内容看，是写一个脚本依次演示 `date`、`who`、`cal` 三个命令的几种用法，用 `bash p2.sh` 运行，再分别查看这三个命令的 man 和 info 帮助。

### 思路

每组命令前用 `echo` 打印标题，组与组之间用 `echo` 空一行、`sleep 5` 停 5 秒，方便看清输出。

### 解答

脚本内容（文件名 p2.sh）：

```bash
echo "command   date:"    # 打印字符串"command   date:"到终端
date                      # 显示当前日期和时间
date +%Y/%m/%d            # 以"年/月/日"的格式显示当前日期
date +%T                  # 以 24 小时制 HH:MM:SS 显示当前时间
date +%H-%M-%S            # 以 24 小时制 HH-MM-SS 显示当前时间
echo                      # 打印一个空行
sleep 5                   # 让脚本暂停执行 5 秒

echo "command    who:"    # 打印字符串"command    who:"到终端
who                       # 显示当前登录的用户信息
who -q                    # 显示当前登录的用户名称和用户数量
who -b                    # 显示系统最后一次启动的时间
echo
sleep 5

echo "command cal:"       # 打印字符串"command cal:"到终端
cal                       # 显示当前月份的日历
cal 7 1921                # 显示 1921 年 7 月的日历
cal -j                    # 显示当前月份的日历，日期用一年中的第几天表示
cal -y                    # 显示当前年份的完整日历
```

（更正：原稿第二组标题作 `echo"command    who:"`，echo 和引号之间缺空格，shell 会把整串当成一个不存在的命令名；原稿 `ca1 7 1921` 中 `ca1` 应为 `cal`；原稿把 `cal -j` 注释为"显示当前年份的日历"，实际显示的是当前月份。）

运行脚本和查看帮助：

```bash
bash p2.sh    # 用 bash 执行脚本 p2.sh，脚本不需要执行权限
man date      # 查看 date 的手册页，包含功能、选项和用法
man who
man cal
info date     # 查看 date 的 info 页，通常比手册页更详细
info who
info cal
```

### date 的格式控制符

`date +格式串` 按格式输出，格式串里以 `%` 开头的是控制符。整个格式串里有空格时要加引号，比如 `date "+%Y 年 %m 月"`。

| 控制符 | 含义 |
| --- | --- |
| `%Y` | 四位年份 |
| `%m` | 月（01 到 12） |
| `%d` | 日（01 到 31） |
| `%H` | 小时，24 小时制 |
| `%M` | 分钟 |
| `%S` | 秒 |
| `%T` | 时间，等同于 `%H:%M:%S` |
| `%A` | 星期几的全称 |
| `%a` | 星期几的缩写，作业四用到 |

## 第四次作业：条件判断脚本

### 题目

原稿只保存了脚本，没有题目原文。从脚本注释看，要求依次完成：

1. 判断当前用户是否为 root。
2. 检查当前目录是否为用户主目录，不是就回到主目录。
3. 检测工作目录中是否存在 bin 子目录，存在就删除后重建，不存在就创建。
4. 使用 set 命令将 date 命令执行的结果设置成位置参数，判断今天是否为休息日。

### 思路

四个小题都是 `if [ 条件 ]; then ...; else ...; fi`。字符串比较用 `==`（bash）或 `=`，目录判断用 `-d`。

### 解答

原稿脚本：

```bash
#!/bin/bash

# 1. 判断当前用户是否为 root
if [ "$USER" == "root" ]; then
  echo "Current user : root"
else
  echo "Current user : $USER"
fi

# 2. 检查当前目录是否为用户主目录
if [ "$PWD" == "$HOME" ]; then
  echo "You are in the home directory!"
else
  cd "$HOME"
  echo "You have gone back to your home directory!"
fi

# 3. 检测工作目录中是否存在 bin 子目录
if [ -d "bin" ]; then
  rm -rf "bin"
  mkdir "bin"
  echo "bin has been recreated!"
else
  mkdir "bin"
  echo "bin has been created!"
fi

# 4. 使用 set 命令将 date 命令执行的结果设置成位置参数
today=$(date +%a)  # 获取今天是星期几的前三位缩写

# 检查今天是否为休息日
if [ "$today" == "Sat" ] || [ "$today" == "Sun" ]; then
  echo "Today is a weekend!"
else
  echo "Today is $today."
fi
```

几个要注意的地方：

- 第 4 小题要求用 `set`，原稿脚本没有用。`set -- 词1 词2 ...` 会把后面的词依次设成 `$1`、`$2`……，所以可以这样写：

  ```bash
  set -- $(LC_ALL=C date)    # 英文环境下 date 输出形如 Sat Nov 18 10:00:00 CST 2023
  if [ "$1" = "Sat" ] || [ "$1" = "Sun" ]; then
    echo "Today is a weekend!"
  else
    echo "Today is $1."
  fi
  ```

  `LC_ALL=C` 不能省。中文环境下 `date` 的输出是"2023年 12月 04日 星期一 11:00:16 CST"（实验一里的真实输出），这时 `$1` 是"2023年"，星期在 `$4`，而且是中文"星期一"，和 Sat、Sun 比不上。`$(date +%a)` 在中文环境下同样会得到中文的星期名。
- `[ ... == ... ]` 是 bash 的写法。用 `sh 脚本名` 运行时，如果系统的 sh 是 dash（Ubuntu 就是），会报 unexpected operator，POSIX 写法是单个 `=`。
- 脚本里的 `cd "$HOME"` 只改变运行脚本的那个子 shell 的目录。脚本结束后，你自己终端里的当前目录不变。想让它影响当前 shell，要用 `source 脚本名` 运行。
- 变量引用都加了双引号，变量为空或含空格时 `[ ]` 不会报语法错误。
