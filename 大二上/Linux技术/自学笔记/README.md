# Linux 技术自学指南

这个文件夹是从课程目录下的 4 份资料整理出来的复习笔记：`LinuxPPT整理.docx`、`Linux整理（客观题）.docx`、`Linux作业.md`、`Linux实验.md`。原文件都还在课程目录里，没有改动。

## 资料清单

| 文件 | 内容 | 什么时候用 |
| --- | --- | --- |
| `01 Unix与Linux概述.md` | UNIX 历史，GNU、FSF、Copyleft、GPL，Linux 内核与发行版，类 Unix 系统的特征 | 开学第一周，或考前背客观题 |
| `02 命令行基础与shell.md` | 命令格式，tty 与 pts，内部命令与外部命令，man/info/help，快捷键，shell 种类与更换，dnf 装软件 | 刚开始上机的时候 |
| `03 vi与常用命令速查.md` | vi 按键，目录结构与路径，文件命令，文本处理命令，重定向，通配符，索引节点与链接，进程，shell 脚本语法 | 做实验时对照查，考前过一遍 |

| `20 作业解析.md` | 四次作业：装系统、Git 提交 PR、date/who/cal 脚本、条件判断脚本 | 写作业时参考，考前复习大题 |
| `21 实验解析.md` | 四次上机实验的逐题解答，含原稿错误的更正 | 做实验时参考，考前复习大题 |

## 建议学习顺序

1. 先读 `01` 和 `02`，了解背景，学会在终端里敲命令、查帮助。
2. 跟着课程进度做实验，边做边查 `03`，做完对照 `21` 检查。实验一练 vi 和目录操作，实验二练文件命令，实验三练文本处理、变量和进程，实验四练脚本。
3. 作业四和实验三、四的脚本题，先自己写，再看 `20`、`21` 的解答和更正。
4. 每学完一块，做 `10` 里对应主题的客观题。
5. 考前一周：`01`、`02` 背概念；`10` 整套刷一遍，重点看标红的题（单选 13、23、76、78，判断 130）和原稿注明"bing 错了"的题（判断 138、144、148、149）；把 `20`、`21` 里的脚本题再默写一遍。

## 整理说明

- 原稿中改正的错误都在原处写了"（更正：…）"。比较重要的几处：实验四 `user_exist` 脚本的 if 条件写错，无论输入什么都输出 not exists；实验三 `grep "^王.*女"` 会误匹配名字里带"女"字的男生；实验三的 `kill` 没能终止处于停止状态的 vi；实验一把 `who am i` 和 `whoami` 弄混了；作业三脚本里有 `echo"..."` 缺空格和 `ca1` 拼错。
- `10 客观题精编.md` 里单选 50 到 80 和大部分判断题原稿没有标答案，整理时补了答案并注明"整理补充"；判断 166、170、173、176 拿不准课程的标准答案，只给了提示。
- 原稿里的学号、登录用户名、密码、IP 地址、通讯录姓名和电话都已删除或打码。
