# vi 与常用命令速查

原稿 `LinuxPPT整理.docx` 只整理到第 3 章，vi、文件系统、文件命令、重定向这些内容散在 `Linux整理（客观题）.docx`、`Linux实验.md` 和 `Linux作业.md` 里。这份速查把它们按主题归拢，括号里的题号对应 `10 客观题精编.md`，实验和作业的完整过程见 `21 实验解析.md`、`20 作业解析.md`。

## 本章要点

- vi 有三种模式：命令模式、文本输入模式、末行模式。按 Esc 回命令模式，按 `:` 进末行模式。
- 光标：`0` 行首，`$` 行尾，`w` 右移一个字，`b` 左移一个字，`gg` 文件头，`G` 文件尾。
- 修改：`u` 撤销最近一次，`U` 撤销当前行所有修改，`.` 重复上一次修改。
- 存盘退出：`:wq`、`:x`、`ZZ`；强制不存盘退出 `:q!`。
- 目录：内核在 `/boot`，设备在 `/dev`，配置在 `/etc`，内核运行状态在 `/proc`，经常变动的日志在 `/var`。
- 重定向：`>` 覆盖，`>>` 追加，`<` 从文件输入；`|` 把前一个命令的输出交给后一个命令。
- 通配符由 shell 展开：`*` 任意多个字符，`?` 恰好一个字符，`[]` 恰好一个字符位置。
- 同一文件系统内 `mv` 不改变索引节点号，`cp` 产生新的索引节点，硬链接共用一个索引节点。

## 1. vi 编辑器

### 模式切换

| 模式 | 怎么进入 | 做什么 |
| --- | --- | --- |
| 命令模式 | 启动 vi 后默认就是；其他模式下按 Esc（单选 28） | 移动光标、删除、复制、撤销 |
| 文本输入模式 | 命令模式下按 `i`（光标前插入）、`a`（光标后追加）、`o`（在下面新开一行）等 | 输入文字 |
| 末行模式 | 命令模式下按 `:`（单选 37） | 存盘、退出、读写文件、替换、设置选项 |

- vi 打开已存在的文件时，会把文件复制到一个临时工作区（缓冲区），之后的修改只作用于这个副本，存盘时才写回原文件（判断 144）。
- 打开文件后以波浪号开头的行，课程答案是"表示该行尚未被编辑"（判断 138）。

### 移动光标

| 按键 | 作用 |
| --- | --- |
| `h` `j` `k` `l` | 左、下、上、右；前面加数字表示移动多次，如 `3k` 上移 3 行（单选 38） |
| 回车 | 下移一行（判断 139） |
| `0` | 行首（单选 30） |
| `$` | 行尾（单选 31） |
| `w` / `b` | 右移一个字 / 左移一个字，`2b` 左移 2 个字（单选 32、40） |
| `gg` | 文件头 |
| `G` | 文件尾（单选 62）；`2G` 表示跳到第 2 行 |

### 删除、撤销、替换

| 按键 | 作用 |
| --- | --- |
| `x` | 删除光标处的字符；`10x` 删除 10 个字符 |
| `dd` | 删除当前行；`3dd` 从当前行起删除 3 行（单选 39） |
| `dw` | 光标在单词首字母时，删除这个单词（判断 142） |
| `u` | 撤销最近一次修改（单选 33） |
| `U` | 撤销对当前行所做的所有修改（单选 34） |
| `.` | 重复上一次修改（单选 29） |
| `r` | 替换光标处的一个字符，替换完仍在命令模式（判断 141） |
| `R` | 进入替换模式，输入的字符逐个覆盖原有字符，按 Esc 结束（单选 41） |

命令模式下 Backspace 只是把光标左移，不删除字符，和 `x` 不一样（判断 140）。

### 搜索

| 命令 | 作用 |
| --- | --- |
| `/字符串` | 从光标处向后（向下）搜索 |
| `?字符串` | 从光标处向前（向上）搜索 |
| `n` | 跳到下一个匹配，方向和搜索命令相同（单选 42） |
| `N` | 跳到下一个匹配，方向和搜索命令相反 |

### 末行模式命令

| 命令 | 作用 |
| --- | --- |
| `:w` | 存盘 |
| `:w 文件名` | 把缓冲区内容写入指定文件；vi 不带参数启动时也用它存盘（单选 58、59） |
| `:3,55 w fileb` | 把第 3 到第 55 行写入 fileb（单选 61） |
| `:r 文件名` | 把文件内容读进来，插在光标所在行的下一行（单选 60） |
| `:wq`、`:x`，以及命令模式下的 `ZZ` | 存盘并退出；`:save` 不行（单选 35） |
| `:q` | 退出，有未保存的修改时会拒绝 |
| `:q!` | 不存盘，强制退出（单选 36） |
| `:s/旧串/新串/` | 替换当前行第一个匹配（单选 43） |
| `:s/旧串/新串/g` | `g` 表示整行全部替换（单选 44）；`:%s/旧串/新串/g` 对全文替换 |
| `:set 选项` | 设置选项，只对本次编辑有效（判断 156） |
| `:set 选项?` | 查看选项的当前值（单选 63） |

## 2. 目录结构与路径

### 根目录下的主要目录

| 目录 | 用途 |
| --- | --- |
| `/bin` | 最常用的命令程序，各种 shell 也在这里（单选 24） |
| `/boot` | 启动 Linux 用的核心文件，内核就放在这里（单选 45） |
| `/dev` | 设备文件，如 `sda`（单选 46） |
| `/etc` | 系统管理需要的配置文件（单选 50） |
| `/home` | 普通用户的主目录，用户 tom 的主目录是 `/home/tom`（单选 49） |
| `/root` | 管理员 root 的主目录（单选 48、51） |
| `/lib` | 系统最基本的动态链接共享库 |
| `/lost+found` | 一般为空，系统非法关机后存放一些文件 |
| `/media` | 系统自动识别的 U 盘、光驱等设备挂载在这里 |
| `/mnt` | 给用户临时挂载其他文件系统 |
| `/opt` | 额外安装的软件 |
| `/proc` | 虚拟目录，是内存的映射，查看内核运行状态（单选 47） |
| `/run` | 临时文件系统，存放系统启动以来的信息，重启后清除 |
| `/sbin` | 系统管理员用的系统管理程序 |
| `/srv` | 服务启动后需要提取的数据 |
| `/sys` | 2.6 内核引入的 sysfs 文件系统挂载点；它的父目录是 `/`（单选 52） |
| `/tmp` | 临时文件，任何人都能写，不适合放机密文件（判断 147） |
| `/usr` | 应用程序和文件，`/usr/local` 是它的子目录（单选 53） |
| `/var` | 经常变动的文件，比如日志（判断 146） |

### 路径

- UNIX 文件系统是以根目录 `/` 为根节点的树形结构（判断 145）。
- 绝对路径从根目录写起。`/home/david/bin` 中第一个 `/` 表示根目录，后面的 `/` 是父目录与子目录之间的分隔符（判断 148）。
- 相对路径从当前目录写起，`.` 是当前目录，`..` 是父目录。用 `..` 可以一层层往上走，所以相对路径同样能表示文件系统中任意位置（判断 149）。
- `cd`、`cp`、`mv`、`ln` 的参数既可以写绝对路径，也可以写相对路径（判断 151、161）。
- `cd` 不带参数、`cd ~` 都回到自己的主目录；`cd ..` 回到父目录。在 `/home/david/bin` 执行 `cd ..` 后，`pwd` 显示 `/home/david`（单选 54）。
- 文件名区分大小写（判断 150），实验一里 `xyz` 和 `XYZ` 是两个目录。

## 3. 文件与目录命令

### ls

| 写法 | 作用 |
| --- | --- |
| `ls -l` | 长格式，显示详细信息 |
| `ls -a` | 列出所有文件，包括以 `.` 开头的隐藏文件 |
| `ls -i` | 显示索引节点号 |
| `ls \| wc -l` | 统计当前目录的文件个数（不含隐藏文件，单选 76） |

`ls -l` 的一行输出（取自实验一）：

```bash
drwxr-xr-x 4 user group 4096 12月  4 16:12 exp1
```

| 字段 | 含义 |
| --- | --- |
| 第 1 字段 `drwxr-xr-x` | 第 1 个字符是文件类型（`d` 目录，`-` 普通文件，`b` 块设备文件，`c` 字符设备文件，`l` 链接）；第 2 到 10 个字符每三个一组，依次是属主、属组、其他用户的权限 |
| 第 2 字段 | 链接数 |
| 第 3、4 字段 | 属主、属组 |
| 第 5 字段 | 文件大小，单位是字节（判断 154） |
| 之后 | 修改时间、文件名 |

权限位里 `r` 可读，`w` 可写，`x` 可执行（单选 55），`-` 表示没有该项权限（单选 56）。

![ls -l 输出 drw-r--r-- 的第 2 到 10 个字符分成三组，第 2 到 4 位属于所有者，第 5 到 7 位属于组用户，第 8 到 10 位属于其他人；每组内三个位置依次是读、写、执行，r、w、x 各连到自己的位置，横线可以出现在任一位置](图/5-4_ls长格式权限位分组.png)

图中例子 `drw-r--r--`：第 1 位 `d` 说明 memos 是目录，所有者 `rw-` 可读可写，组用户和其他人都是 `r--` 只读。三组的位置是固定的，读永远在每组第 1 位，写在第 2 位，执行在第 3 位，没有哪项权限就在那个位置写 `-`，所以图里 `-` 同时连向读、写、执行三个位置。下方表格的表头写成了"代表文件类型"，是从上一页文件类型表照搬过来的，这里应读作"权限含义"。

### 建立、删除

| 命令 | 说明 |
| --- | --- |
| `mkdir 目录` | 新建目录，新目录里自带 `.` 和 `..`（判断 152） |
| `mkdir -p a/b/c` | 一次建多级目录，中间目录不存在时自动创建 |
| `rmdir 目录` | 只能删空目录，即只剩 `.` 和 `..` 的目录（判断 153）。实验一里 `rmdir xyz` 因目录非空而失败 |
| `rm 文件` | 删除文件；`-i` 删除前逐个确认，`-f` 强制删除不提示 |
| `rm -r 目录` | 删除目录必须加 `-r`（单选 57） |
| `touch 文件` | 文件不存在时创建一个空文件 |

### 复制、移动、链接

| 命令 | 说明 |
| --- | --- |
| `cp 源 目标` | 创建文件副本（单选 68）。复制目录要加 `-r`（单选 69） |
| `cp filea dir` | `dir` 是已存在的目录时，副本是 `dir/filea`（判断 160） |
| `mv 源 目标` | 移动文件（单选 70），也用来改名：`mv filea fileb`（单选 71）；`-v` 显示执行过程（单选 72） |
| `mv filea dir` | `dir` 是已存在的目录时，filea 移进去，名字不变（判断 163） |
| `mv dir dir1` | `dir1` 不存在时，结果是把 `dir` 改名为 `dir1`（判断 162） |
| `ln filea fileb` | 在已存在文件和新文件之间建立链接（单选 73） |

### 查看文件内容

| 命令 | 说明 |
| --- | --- |
| `cat 文件...` | 显示一个或多个文件的内容（判断 155）；`-n` 显示行号（单选 67） |
| `cat` | 不带参数时从标准输入（键盘）读（单选 66），按 Ctrl+D 结束 |
| `cat > 文件` | 结合输出重定向创建新文件（判断 159） |
| `more 文件` | 分页查看；`ls \| more` 分页显示目录内容（判断 177） |
| `less 文件` | 分页查看，操作方式和 man 页面一样 |
| `head -n N 文件` | 显示前 N 行 |
| `tail -n N 文件` | 显示最后 N 行；`tail -n +N` 从第 N 行显示到末尾 |

取中间几行要把 head 和 tail 串起来。显示第 21 到 30 行：

```bash
head -30 filea | tail -10     # 先取前 30 行，再取其中最后 10 行（单选 78）
head -n 15 first | tail -n 3  # 实验二：取第 13 到 15 行
tail -n +13 first | head -n 3 # 另一种写法：从第 13 行开始，取前 3 行
```

## 4. 文本处理命令

| 命令 | 常用写法 | 说明 |
| --- | --- | --- |
| `wc` | `-l` 行数、`-w` 字数、`-c` 字节数 | 选项见单选 74、75。不给文件名时从标准输入读（判断 167）。`wc -l < 文件` 只输出数字，不带文件名 |
| `cut` | `-c 1-5` 取第 1 到 5 个字符；`-d: -f7` 以冒号分隔取第 7 个域 | `-f` 取域（单选 79），`-c` 取字符（单选 80），`-d` 指定分隔符。默认分隔符是制表符（判断 175） |
| `paste` | `paste -d "@" f1 f2` | 把两个文件逐行拼接，`-d` 指定分隔符，不指定时用制表符 |
| `sort` | `-k 2` 按第 2 个字段，`-r` 逆序，`-n` 按数值 | 实验三用来给通讯录排序 |
| `grep` | `grep "模式" 文件` | 按正则表达式找行。`^` 匹配行首，`$` 匹配行尾，`.*` 匹配任意多个任意字符；`-c` 只输出匹配的行数 |
| `find` | `find 目录 -name "*.c"` | 按名字查找。`-exec 命令 {} \;` 对每个结果执行命令，`{}` 代表找到的文件；`-ok` 和 `-exec` 一样，但执行前逐个询问确认（判断 174） |
| `tee` | `命令 \| tee 文件` | 输出同时显示在屏幕上并保存到文件 |

几个容易踩的坑：

- `wc -c` 统计的是字节数。纯英文文件里字节数等于字符数；有中文时，按 UTF-8 一个汉字占 3 个字节，要数字符应该用 `wc -m`。
- `cut -d ' '` 遇到连续多个空格时，每个空格都算一次分隔，中间会切出空字段。
- `sort -k 2` 表示从第 2 个字段一直比到行尾，只按第 2 个字段排要写 `-k 2,2`。字段之间有多个空格时，字段开头会带着空格参与比较，加 `-b` 忽略前导空白更稳。
- `find` 的 `-name` 后面带通配符时要加引号，否则 shell 可能先把 `*.c` 展开成当前目录里的文件名（单选 77）。

## 5. 重定向与管道

| 写法 | 作用 |
| --- | --- |
| `命令 > 文件` | 输出重定向到文件（单选 64），文件原有内容被覆盖，屏幕上不再显示输出（判断 158） |
| `命令 >> 文件` | 追加到文件末尾，原有内容不会被覆盖（判断 157） |
| `命令 < 文件` | 从文件获得输入（单选 65） |
| `命令 > /dev/null 2>&1` | 标准输出丢弃，标准错误（2）也重定向到标准输出（1）去，整条命令不在屏幕上输出任何东西 |
| `命令1 \| 命令2` | 管道：命令 1 的输出作为命令 2 的输入 |

## 6. 通配符

| 通配符 | 匹配 |
| --- | --- |
| `*` | 任意多个（包括 0 个）字符 |
| `?` | 恰好 1 个字符，不能匹配 0 个（判断 168） |
| `[abc]` | 方括号里任意一个字符，这个位置必须有一个字符（判断 172） |

- 通配符由 shell 展开成文件名列表之后再交给命令，命令自己看不到通配符（判断 171）。
- `*.*` 只匹配名字里带点的文件，没有扩展名的文件匹配不上（判断 169）。
- `*` 不匹配以 `.` 开头的隐藏文件。

## 7. 索引节点与链接

- 系统给每个文件分配一个整数，即索引节点号（i 节点号），用它来标识文件（判断 178）。索引节点号和文件的基础信息保存在磁盘上的索引节点表中（判断 179）。`ls -i` 可以看到。
- `cp` 生成的新文件有自己的索引节点号（判断 180）。
- 在同一个文件系统内用 `mv` 移动或改名，索引节点号不变（判断 181、182）。
- `ln` 建立链接不会复制文件数据，两个文件名指向同一个索引节点（判断 183）。通过任何一个名字修改内容，另一个名字看到的内容也跟着变（判断 165）。
- `ln -s` 建立的是符号链接，`ls -l` 显示为 `l` 类型并带箭头，例如 `/bin/sh -> bash`。

## 8. 进程与作业

| 写法 | 作用 |

| `ps` | 查看当前终端的进程；`ps 进程号` 看指定进程，STAT 列为 `T` 表示已停止 |

## 9. shell 与脚本基础

实验三、实验四和作业四里用到的语法：

```bash
name=abc                  # 定义变量，等号两边不能有空格
echo $name                # 引用变量
today=$(date +%a)         # $(命令)：把命令的输出赋给变量
alias del='rm -i'         # 给命令起别名
PS1='\# '                 # 提示符中 \# 显示命令序号
read a1                   # 从键盘读入一个值存进变量 a1
echo -n "提示："          # -n 输出后不换行
echo -e "a\nb"            # -e 解释 \n 这类转义字符
```

脚本里的条件判断和循环：

```bash
if [ -d ~/exp4/FILE4 ]    # [ ] 两侧和运算符两侧都必须有空格
then
    echo "目录存在"
else
    echo "目录不存在"
fi

for ((i=$1; i<=$2; i++))  # $1、$2 是运行脚本时传入的第 1、2 个参数
do
    sum=$((sum + i))       # 算术运算
done
```

| 测试写法 | 含义 |
| --- | --- |
| `[ -d 路径 ]` | 路径存在并且是目录 |
| `[ "$a" = "$b" ]` | 字符串相等；bash 里也可以写 `==` |
| `[ $a -gt $b ]` | 整数大于；`-lt` 小于，`-eq` 等于 |
| `命令1 \|\| 命令2` | 命令 1 失败才执行命令 2；`[ ] \|\| [ ]` 表示"或" |

运行脚本的两种方式：

```bash
bash sum 57 90            # 用 bash 解释执行，不需要执行权限
chmod +x sum && ./sum 57 90   # 先加执行权限，再用路径运行
```

bash 作为登录 shell 启动时，会读主目录下的 `.profile` 并执行其中的命令。前提是主目录里没有 `.bash_profile` 和 `.bash_login`，这两个文件存在时 bash 优先读它们。实验三就是靠 `.profile` 在登录时显示问候语和时间。
