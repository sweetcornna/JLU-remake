## 本章要点

- 总线数据传输率 = 总线宽度（字节）÷ 总线传输周期。提高一倍的办法：加宽数据线，或提高总线时钟频率。
- 多体并行存储器的**低位交叉编址**（模 M 编址）能在不缩短单个模块存取周期的前提下提高**存储器带宽**。连续读 n 个字：低位交叉 $t_1=T+(n-1)\tau$，高位交叉 $t_2=nT$。
- 三种高性能 DRAM：SDRAM 与系统时钟同步、CPU 不用等待；RDRAM 用高速总线和 RamLink 解决带宽；CDRAM 在 DRAM 里集成一小块 SRAM 作 Cache。
- Cache 的依据是**程序访问的局部性**。三个公式要会用：命中率 $h$、平均访问时间 $t_a$、访问效率 $e$。
- Cache 由存储体、地址映射变换机构、替换机构组成，调入调出全由**硬件**完成，对用户透明。
- 地址格式计算是大题常客：先定"块内地址"位数，再定"Cache 块地址 / 组地址"位数，剩下的是"主存字块标记"。
- 写直达法与写回法的读写时间和一致性差别；单一缓存/两级缓存、统一缓存/分立缓存的选用条件。

## 概念与解释

### 总线与存储器读写的两个细节

- 对存储器做读操作还是写操作，在读周期和写周期内，**地址线上的地址始终不变**。
- 单体多字系统（一次访存取出连续多个字）的前提是指令和数据在主存内连续存放。遇到转移指令，或者操作数不能连续存放时，效果就不明显。

### 多体并行与交叉编址

- 多体模块结构中，**低位地址表示体号、高位地址表示体内地址**，叫低位交叉编址。程序连续存放在相邻的体中，所以又叫交叉存储；又称模 M 编址（M 为模块数），模块数一般取 2 的方幂以简化硬件。也有机器取质数个模块减少存储器冲突，例如银河机的 M 为 31，硬件实现复杂。
- 交叉访问时，CPU 依次启动 4 个存储体，各体的读写过程重叠进行。每个体的存取周期没有缩短，但除第一个存取周期外，每个存取周期内存储器能向 CPU 提供 4 个字。模块字长 32 位时，一个存取周期能提供 32×4=128 位，带宽大大增加。时序图见 `图/4-44_四体交叉访问时序.png`。
- 流水方式存取的条件：设低位交叉模块数为 n，存取周期为 T，总线传输周期为 τ，应满足 $T=n\tau$；为保证再次启动某体时它上次的存取已经完成，模块数要大于或等于 n。

### 高性能存储芯片

| 芯片 | 思路 | 要记的细节 |
| --- | --- | --- |
| SDRAM（同步 DRAM） | 与处理器的数据交换同步于系统时钟，按处理器-存储器总线最高速度运行，不插等待状态 | CPU 给出的地址和控制信号被 SDRAM **锁存**，CPU 可以去做别的事，到指定时钟周期数后取数据。例：时钟周期 10 ns，读出要 50 ns，异步 DRAM 要让 CPU 等 50 ns，SDRAM 则 5 个时钟周期后直接取。支持猝发访问（一个地址连续访问一个数据块，通常 32 字节）；DDR-SDRAM 每周期可两次送数据 |
| RDRAM（Rambus DRAM） | 专门的 DRAM 加高性能芯片接口，主要解决**存储器带宽** | 通过高速总线接收请求（地址、操作类型、字节数），最多寻址 320 块芯片，传输率可达 1.6 GBps；不用 $\overline{\text{RAS}}$、 $\overline{\text{CAS}}$、 $\overline{\text{WE}}$，采用异步的面向块的传输协议；各芯片经 RamLink 连成环，在主存控制器控制下以包为单位交换数据 |
| CDRAM（带 Cache 的 DRAM，又叫 EDRAM） | DRAM 芯片内集成一小块 SRAM | 以 1 M×4 位 CDRAM 为例：SRAM 512×4 位，DRAM 阵列 2048×512×4 位，地址引脚只有 11 根（ $A_{10}\sim A_0$），20 位地址分时送入 |

CDRAM 的读过程：

1. 行选通信号有效时，高 11 位地址输入，存入行地址锁存器和"最后读出行地址锁存器"，DRAM 中该行的 512×4 位全部读到 SRAM 暂存。
2. 列选通信号有效时，低 9 位地址输入列地址锁存器；读命令有效时，选中的 4 位组经 $D_3\sim D_0$ 输出。
3. 下一次读取，新行地址先和最后读出行地址做 11 位比较：相同就直接从 SRAM 按列地址输出；不同才驱动 DRAM 更新 SRAM 和锁存器。
4. 连续读同一行时只改 9 位列地址，叫**猝发式读取**，适合成块传送。
5. 输出路径（SRAM 到 I/O）和输入路径（I/O 到读放和列写选择）分开，写操作完成的同时可以启动同一行的读；SRAM 读出期间还能对 DRAM 刷新。

### Cache 的原理与性能指标

局部性原理：CPU 在一定时间内只访问主存的局部地址区域。原因是指令和数据在主存内连续存放，而且子程序、循环程序、常数会被多次调用，访存地址相对簇聚。只要把 CPU 近期要用的程序和数据提前送到 Cache，CPU 在一段时间内就只访问 Cache。Cache 用高速 SRAM 做，贵，但容量远小于主存，能兼顾速度和成本。

三个公式（ $N_c$ 为访问 Cache 命中次数， $N_m$ 为访问主存次数， $t_c$ 为命中时的 Cache 访问时间， $t_m$ 为未命中时的主存访问时间）：

$$h=\frac{N_c}{N_c+N_m}\qquad t_a=ht_c+(1-h)t_m\qquad e=\frac{t_c}{t_a}\times100\%$$

$t_a$ 越接近 $t_c$ 越好，所以命中率 h 越接近 1 越好。

影响命中率的两个因素：

- **容量**：容量越大命中率越高，但到一定值后提升不明显，还增加成本，所以容量是成本与命中率的折中。
- **块长**：块由小变大，起初因局部性命中率上升；继续变大，Cache 块数减少，新块覆盖旧块，可能出现刚装入就被替换，而且新增的字离被访问字更远，命中率反而下降。一般每块取 4～8 个可编址单位（字或字节）较好，也可取一个主存周期能调出的信息长度。例：CRAY-1 主存 16 体交叉、每体单字宽，指令 Cache 块长 16 个字；IBM 370/168 主存 4 体交叉、每体宽 64 位，Cache 块长 32 个字节。

### Cache 的基本结构

结构图见 `图/4-50_Cache基本结构.png`。

1. **Cache 存储体**：以块为单位与主存交换信息。为加快调动，主存大多采用多体结构，且 Cache 访存的优先级最高。
2. **地址映射变换机构**：把 CPU 送来的主存地址转换成 Cache 地址。主存块和 Cache 块大小相同，块内地址（低位）不变，所以变换的只是块号（高位）。
   - 命中：CPU 直接访问 Cache 存储体。
   - 不命中：CPU 访问主存取出该字，同时把它所在的主存块调入 Cache。Cache 未满直接装入，已满就要替换。
3. **替换机构**：Cache 已满时，按替换算法决定移出哪块。

Cache 对用户**透明**：用户编程用的是主存地址，主存块调入 Cache 全部由硬件自动完成。

直接映射的缺点：每个主存块只能对应固定的 Cache 块，Cache 里空着位置也不能用；如果程序反复访问映射到同一 Cache 块的不同主存块，就要不停替换，命中率下降。

### Cache 的读写与改进

- 写直达法：Cache 与主存始终一致。读失效时被替换的 Cache 块不用写回主存，更新策略容易实现；但写操作既写 Cache 又写主存，写操作时间等于访问主存的时间。
- 写回法：写操作只写 Cache，写操作时间就是访问 Cache 的时间，速度快；对主存的写只发生在块替换时，对同一块的多次写只需一次写回，减少写主存次数。但读失效时可能要把被替换块写回主存，Cache 更复杂。
- 单一缓存与两级缓存：CPU 和主存之间只设一个缓存叫单一缓存；把它和 CPU 做在同一芯片上叫**片内缓存**，访问不占系统总线、通路短、速度快（如 80486 片内有 8 KB 缓存）。片内缓存容量小，再在主存与片内缓存之间加一级由 SRAM 做的**片外缓存**，用独立数据通路连 CPU，这两级合称两级缓存（片内为第一级，片外为第二级）。现在不少处理器也把第二级 Cache 集成进芯片。
- 统一缓存与分立缓存：指令和数据放同一缓存叫统一缓存，分开放在指令 Cache 和数据 Cache 叫分立缓存。选用看两点：主存是否指令、数据分开存放；是否采用超前控制（指令预取）或流水线控制。采用后两者的机器必须分立，否则执行部件取数和预取机构取指会争用统一缓存，统一缓存只能先满足执行部件，预取就落空了。

## 易混对比

| 对比项 | 高位交叉编址 | 低位交叉编址 |
| --- | --- | --- |
| 体号在地址的 | 高位 | 低位 |
| 连续读 n 个字的时间 | $t_2=nT$ | $t_1=T+(n-1)\tau$ |
| 主要作用 | 扩充容量方便 | 提高带宽 |

| 对比项 | 写直达法 | 写回法 |
| --- | --- | --- |
| 写操作 | 同时写 Cache 和主存 | 只写 Cache，替换时写回 |
| 写操作时间 | 访问主存的时间 | 访问 Cache 的时间 |
| 一致性 | 始终一致 | 可能不一致，每块设"清/浊"标志位 |
| 读失效替换时 | 被替换块不用写回 | "浊"块要写回主存 |

| 对比项 | 直接映射 | 全相联映射 | 组相联映射 |
| --- | --- | --- | --- |
| 主存地址格式 | 标记 \| Cache 块地址 \| 块内地址 | 标记 \| 块内地址 | 标记 \| 组地址 \| 块内地址 |
| 标记位数 | 主存地址位数 − Cache 地址位数 | 主存地址位数 − 块内地址位数 | 主存地址位数 − 组地址位数 − 块内地址位数 |
| 灵活性、命中率 | 低 | 高 | 居中 |
| 硬件成本 | 低 | 高 | 居中 |

## 典型题

### 例 3.1 总线数据传输率

题：总线时钟频率 100 MHz，总线传输周期为 4 个时钟周期，总线宽度 32 位，求数据传输率。要提高一倍，可采取什么措施？

思路：先求一个总线传输周期的时长，再用每个周期传送的字节数去除。

解：

- 时钟周期 = 1/100 MHz = 0.01 μs，总线传输周期 = 0.01 μs × 4 = 0.04 μs。
- 32 位 = 4 B，数据传输率 = 4 B / 0.04 μs = 100 MBps。
- 提高一倍：时钟频率不变，把数据线宽度改为 64 位；或者保持 32 位，把时钟频率提高到 200 MHz。

### 例 4.6 顺序存储与交叉存储的带宽

题：4 个模块组成的四体存储器，每体存储字长 32 位，存取周期 200 ns；数据总线宽 32 位，总线传输周期 50 ns。求顺序存储和交叉存储的存储器带宽。

思路：两种方式连续读出 4 个字的信息量都是 128 位，差别只在时间。

解：

- 顺序存储（高位交叉编址）时间：200 ns × 4 = 800 ns = $8\times10^{-7}$ s，带宽 = 128 / $(8\times10^{-7})$ = $16\times10^7$ bps。
- 交叉存储（低位交叉编址）时间：200 ns + 50 ns × (4−1) = 350 ns = $3.5\times10^{-7}$ s，带宽 = 128 / $(3.5\times10^{-7})$ ≈ $37\times10^7$ bps。

### 例 4.7 命中率、效率和平均访问时间

题：CPU 执行一段程序，访问 Cache 命中 2000 次，访问主存 50 次。Cache 存取周期 50 ns，主存 200 ns。求命中率、效率和平均访问时间。

思路：命中率按定义算；主存时间是 Cache 的 4 倍，代入效率公式。

解（教材原解）：

- 命中率 = 2000 / (2000+50) = 0.97。
- 设 Cache 访问时间为 t，主存为 4t，效率 $e=\dfrac{t}{0.97t+(1-0.97)\times4t}\times100\%=91.7\%$。
- 平均访问时间 = 50 ns × 0.97 + 200 ns × (1−0.97) = 54.5 ns。

注：2000/2050 ≈ 0.9756，教材截断成 0.97，后两问也按 0.97 算。按精确值算，效率约 93.2%，平均访问时间约 53.7 ns。考试时按题目给的精度写即可。

### 例 4.8 直接映射的地址计算

题：主存 512 KB，Cache 4 KB，每字块 16 个字，每字 32 位。(1) Cache 地址多少位？多少块？(2) 主存地址多少位？多少块？(3) 直接映射下主存哪些块映射到 Cache 第 5 块（起始块为第 1 块）？(4) 画出直接映射的主存地址字段。

思路：按字节编址，每字 4 B，每块 16 字 = 64 B = $2^6$ B。

解：

1. Cache 4 KB = $2^{12}$，地址 12 位；共 4 KB / 4 B = 1 K 字，1 K / 16 = 64 块。
2. 主存 512 KB = $2^{19}$，地址 19 位；共 128 K 字，128 K / 16 = 8192 块。
3. Cache 64 块、主存 8192 块，主存的第 5，64+5，2×64+5，…， $2^{13}-64+5$ 块映射到 Cache 第 5 块。
4. 块内地址 6 位（4 位表示 16 个字，2 位表示每字 4 个字节），Cache 块地址 6 位，标记 19−12 = 7 位。

| 主存字块标记 | 缓存字块地址 | 字块内地址 |
| --- | --- | --- |
| 7 位 | 6 位 | 6 位 |

### 例 4.9 三种映射下的主存地址格式

题：主存 512 K×16 位，Cache 4096×16 位，块长 4 个 16 位的字，访存地址为字地址。设计 (1) 直接映射、(2) 全相联映射、(3) 二路组相联映射下的主存地址格式；(4) 若主存改为 512 K×32 位、块长不变，设计四路组相联下的地址格式。

思路：按字编址，块内地址 = log2(每块字数)。

解：

- Cache 4096 = $2^{12}$ 字，块内地址 b = 2 位，Cache 共 1024 = $2^{10}$ 块（c = 10）；主存 512 K = $2^{19}$ 字，地址 19 位。

| 情况 | 主存字块标记 | 中间字段 | 字块内地址 |
| --- | --- | --- | --- |
| (1) 直接映射 | 19−12 = 7 | Cache 字块地址 10 | 2 |
| (2) 全相联 | 19−2 = 17 | 无 | 2 |
| (3) 二路组相联 | 19−9−2 = 8 | 组地址 9（1024/2 = 512 组） | 2 |
| (4) 四路组相联，双字宽主存 | 20−8−2 = 10 | 组地址 8（1024/4 = 256 组） | 2 |

(4) 中 512 K×32 位按 16 位的字看就是 1024 K×16 位，所以主存地址 20 位。

### 例 4.10 Cache 带来的性能提升

题：Cache 速度是主存的 5 倍，命中率 95%，采用 Cache 后性能提高多少？

解：设 Cache 存取周期 t，主存 5t。平均访问时间 $t_a=0.95t+0.05\times5t=1.2t$。性能为原来的 5t/1.2t = 4.17 倍，即提高了 3.17 倍。

注意"是原来的几倍"和"提高了几倍"差 1。

### 例 4.11 四路组相联 Cache 设计

题：主存 16 MB，Cache 8 KB，每字块 8 个字，每字 32 位，四路组相联。(1) 画主存地址字段；(2) Cache 初态为空，CPU 依次读主存第 0～99 号单元的 100 个字，重复 10 次，求命中率；(3) Cache 速度是主存的 5 倍，有 Cache 比无 Cache 速度提高多少倍；(4) 系统效率。

思路：块内地址 = 3 位字地址 + 2 位字节地址；读 100 个字只在每块第一次访问时不命中。

解：

1. 块大小 $2^5$ B，Cache $2^{13}$ B 共 $2^8$ 块（c = 8）；四路 r = 2，组地址 q = 8−2 = 6 位；主存 $2^{24}$ B，标记 24−6−5 = 13 位。

   | 主存字块标记 | 组地址 | 字块内地址 |
   | --- | --- | --- |
   | 13 位 | 6 位 | 5 位 |

2. 读第 0 号单元不命中，调入该块后读 1～7 号命中；同理 8，16，…，96 号不命中，第一遍共 13 次不命中，后 9 遍全命中。命中率 = (100×10 − 13) / (100×10) = 0.987。
3. 无 Cache 时间 5t×1000；有 Cache 时间 t(1000−13) + 5t×13。提高倍数 = $\dfrac{5t\times1000}{t(1000-13)+5t\times13}-1\approx3.75$。
4. 效率 = $\dfrac{t}{0.987t+(1-0.987)\times5t}\times100\%\approx95\%$。

注：教材这张地址格式图的图题写作"例 4.10 主存地址字段"，按内容应是例 4.11。历年卷（2007～2010）的 Cache 计算题就是这道例题改了数字，见 `20 历年题（2007–2008）.md`。
