### 3. 简述一个 C 语言程序转换为可执行程序的 4 个步骤

复习资料 3、7。原笔记没有答这题，以下为整理补充。

1. **编译**：编译器把 C 程序翻译成汇编语言程序。
2. **汇编**：汇编器把汇编语言程序翻译成目标模块（机器语言，含重定位信息和符号表）。
3. **链接**：链接器把多个目标模块和库程序合并，解析外部引用、确定各模块的地址，生成可执行文件。
4. **装入**：加载器把可执行文件装入内存，准备运行。

### 4. 简述缩短 CPU 时间的方法

复习资料 6、15，讲题 4。

从性能公式出发：

$$\text{CPU 时间}=\text{指令数}\times\text{CPI}\times\text{时钟周期}=\frac{\text{指令数}\times\text{CPI}}{\text{时钟频率}}$$

三个因素里减小任何一个都能缩短 CPU 时间：

- 减少指令数：改进算法，选用合适的编程语言，使用更好的编译器（原笔记已答）。
- 降低 CPI：编译器优化、改进指令集体系结构和处理器组成（原笔记已答）。
- 缩短时钟周期（提高时钟频率）：采用更好的硬件工艺，改进处理器实现，如划分流水线（整理补充）。

## 第 2 章 指令：计算机的语言

### 5. MIPS 指令集的三项设计原则是什么？举例说明如何应用到具体指令中

复习资料 5（"硬件设计的三个基本原则"）、20。

1. **简单源于规整**：R 型指令如 `add $1, $2, $3` 都固定有 3 个操作数；所有指令都是 32 位。
2. **越小越快**：MIPS 的寄存器个数限制为 32 个。
3. **优秀的设计需要适宜的折中**：不同类型的指令用不同的格式（R、I、J 型）、不同的译码方式，但都保持 32 位相同长度。

### 6. MIPS 如何得到一个 32 位的立即数

复习资料 10。

原笔记只答了符号扩展：把 16 位立即数的最高位复制 16 次放到左半部，右半部保留原来的 16 位。这是 addi、lw 等指令把 16 位立即数用成 32 位时的做法。

（整理补充：教材讲"32 位立即数"时说的是另一件事。一个 32 位常数放不进 16 位的立即数字段，要分两步装：先用 `lui` 把高 16 位装进寄存器，再用 `ori` 把低 16 位拼进去。例如 `lui $s0, 61` 执行后 `$s0` = 003D0000H，再 `ori $s0, $s0, 2304` 得到 003D0900H。答题时两种都写上比较稳。）

### 7. I 型指令为什么没选择包括两个立即数的格式

复习资料 13，讲题 2。题目给出的 I 型格式为 Op | Rs | Rt | Constant or Address。

- MIPS 所有指令都是 32 位，立即数字段占 16 位。
- 如果放两个立即数，两个立即数就占满 32 位，操作码没地方放，只能加长指令。
- 这样 I 型指令就不再是 32 位，违反"简单源于规整"的原则。

### 8. 分支指令和跳转指令的区别

题型整理补充题。

1. 分支指令（beq、bne）是条件转移，采用 **PC 相对寻址**：16 位偏移量先符号扩展成 32 位，左移 2 位，再与 PC+4 相加得到目标地址。
2. 跳转指令（j）是无条件转移，采用 **伪直接寻址**：26 位地址字段左移 2 位得到 28 位，再与 PC+4 的高 4 位拼接得到 32 位目标地址。

（更正：手写原文写"与 PC 相加""与 PC 高 4 位拼接"，没有符号扩展这一步，而且用的应该是 PC+4。）

## 第 3 章 计算机的算术运算

### 11. 解释保护位、舍入位、粘贴位的作用

复习资料 1。

- **保护位**：浮点中间计算时在右边多保留两位，其中第一位是保护位，用来提高舍入精度。
- **舍入位**：多保留两位中的第二位，使中间结果满足浮点格式时能舍入到最接近的数。
- **粘贴位**：舍入位右边只要还有非零位，就把粘贴位置 1，让舍入更合理（比如区分"正好一半"和"超过一半"）。

### 12. 简要说明浮点加、减法运算的基本步骤

题型整理补充题。

1. 对阶：小阶向大阶看齐，阶码小的数尾数右移。
2. 尾数求和（差）。
3. 规格化：结果左移或右移，同时调整阶码。
4. 舍入：按保护位、舍入位、粘贴位舍入到规定位数。
5. 判断溢出：检查阶码是否上溢或下溢；舍入后若又不规格化，回到第 3 步。

### 14. 画出除法器原理图，并解释一个除法的执行过程

复习资料 9。

结构和改进版乘法器很像：32 位除数寄存器接 32 位 ALU，ALU 结果写入 64 位余数寄存器的高半部分；余数寄存器可左移、右移、写，由控制测试部件根据余数符号控制。初始时余数寄存器低 32 位放被除数，高 32 位为 0。

1. 余数寄存器高 32 位减去除数，结果写回高半部分。
2. 若结果小于 0，高半部分加回除数恢复原值，余数寄存器左移 1 位，最低位置 0；若结果大于等于 0，余数寄存器左移 1 位，最低位置 1。
3. 重复上述步骤（被除数 n 位就做 n+1 次，也可以先左移 1 位再做 n 次）。
4. 结束后，余数寄存器低半部分是商；高半部分右移 1 位得到余数。

（更正：手写原文第 2 步写"若余数大于 0"，差为 0 时商位也是 1，应为"大于等于 0"；另外原文漏了最后"高半部分右移 1 位"这一步。74÷8 的完整计算表见 `30 MIPS 计算题（性能、浮点、乘除法、指令地址）.md`。）

### 15. 简述流水线中三种冒险产生的原因，并分别指出至少一种解决方法

题型整理补充题。

| 冒险 | 原因 | 解决方法 |
| --- | --- | --- |
| 结构冒险 | 所需的硬件资源正被别的指令占用，硬件不支持多条指令同时使用 | 增加硬件资源，如指令存储器和数据存储器分开 |
| 数据冒险 | 指令执行要用到前面指令的结果，而前面指令还没写回 | 转发（旁路）、阻塞（插入气泡）、代码重排 |
| 控制冒险 | 取下一条指令要依赖分支指令的结果，分支还在执行，流水线不知道下一条指令在哪 | 分支阻塞、假定分支不发生、缩短分支延迟、分支预测 |

### 16. 简述控制冒险的三种解决方法

复习资料 11。

1. **假定分支不发生**：继续顺序取指；若分支真的发生，把已经取进来的指令清除掉。
2. **缩短分支的延迟**：把分支目标地址计算和条件判断提前到 ID 段完成，分支发生时只需清除 1 条指令。
3. **动态分支预测**：用分支预测缓存记录分支最近的执行情况，按历史预测这次是否发生，预测错了再清除并改走正确路径。

后两条的解释为整理补充，原笔记只写了名字。

### 17. 旁路是如何解决数据冒险的？是否能解决所有的数据冒险？举例说明

复习资料 21。

- 做法：需要的数据如果已经在流水线里算出来了（在 EX/MEM 或 MEM/WB 流水线寄存器中），就通过旁路从这些内部寄存器直接取到 ALU 输入端，不必等它写回程序员可见的寄存器。
- 旁路不能解决所有数据冒险。取数-使用型（load-use）冒险解决不了：lw 的数据要到 MEM 段结束才读出来，而紧跟着的下一条指令在同一时刻已经要在 EX 段用它，必须阻塞 1 个周期后再转发。

例子（整理补充）：

```text
lw  $s1, 0($s2)
sub $s3, $s1, $s4    # 需要 lw 读出的 $s1，必须先阻塞 1 个周期
```

## 第 5 章 存储器层次

### 18. 什么是局部性原理，具体包括哪些类型

复习资料 4、8、12，讲题 1。

局部性原理：在任意一段时间内，程序只访问地址空间中相对较小的一部分内容。分两类：

- **时间局部性**：某个数据项被访问后，可能很快再次被访问。例如循环里的指令和变量。
- **空间局部性**：某个数据项被访问后，与它地址相近的数据项可能很快被访问。例如顺序执行的指令、顺序访问的数组元素。

### 19. 数组访问的时间局部性和空间局部性分析

复习资料 18。C 语言数组按行优先分配存储空间，分析下面代码段中变量访问的时间局部性和空间局部性：

```c
for (i = 0; i < 8; i++)
    for (j = 0; j < 8000; j++)
        a[i][j] = b[i][0] + a[j][i];
```

- 时间局部性：内层循环里 i 不变，每次都读 `b[i][0]`，同一个数据项被反复访问；循环变量 i、j 也被反复访问。（更正：手写原文写成 `a[i][0]`，而 `a[i][0]` 只在 j=0 时写一次，反复访问的是 `b[i][0]`。）
- 空间局部性：`a[i][j]` 被访问后 j 自增，下一次访问相邻的 `a[i][j+1]`，按行连续访问，空间局部性好。
- （整理补充）`a[j][i]` 在内层循环里是 j 变、i 不变，按列访问。行优先存储时相邻两次访问相隔一整行，空间局部性差。

### 20. 写回和写直达分别用在哪里？为什么

复习资料 17、19，讲题 6。

- 写直达：写操作同时写 Cache 和主存，哪个字改了就立刻写出去。
- 写回：只写 Cache（或主存），并用脏位标记，块被替换时才把整块写出去。
- Cache 与主存之间两种方法都可以用。
- 主存与外存之间只能用写回。（整理补充原因：磁盘写入比主存慢几个数量级，每次写都直接写磁盘代价太大，所以虚拟存储器只在页面被替换时把脏页写回磁盘。）

### 21. 直接相联映射、组相联映射、全相联映射的共同点和关系

复习资料 22。

- 共同点：都以块为单位组织数据，主存和 Cache 都分成大小相同的块。
- 区别：直接相联映射中，每个主存块只能放到 Cache 中唯一的一个位置；全相联映射中，块可以放到 Cache 的任何位置。
- 关系：组相联映射是两者的折中，组间直接相联，组内全相联。换个角度看，直接相联就是每组 1 块的组相联，全相联就是只有 1 组的组相联。
